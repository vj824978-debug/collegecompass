If f(x) = log(1 +ax) + log(1−bx) x , for x̸= 0 k, for x = 0 is continuous at x = 0, then the value of k is: (A) a (B) a +b (C) a−b (D) b
Answer
Answer as text
(C) lim x→0 h log(1+ax) x + log(1−bx) x i =a−b =k.
