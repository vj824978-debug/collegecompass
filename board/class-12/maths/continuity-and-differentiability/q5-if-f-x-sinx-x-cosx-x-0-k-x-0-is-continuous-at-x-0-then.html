If f(x) = sinx x + cosx, x ̸= 0 k, x = 0 is continuous at x = 0, then the value of k is: (A) 0 (B) −2 (C) −1 (D) 2
Answer
Answer as text
(D) lim x→0 sinx x + cosx = 1 + 1 = 2 =k.
