Continuity and Differentiability — Question 20 (CBSE 2025)

CBSE 202565/7/1
Question 20 · Class 12 Mathematics · Continuity and Differentiability
Question as text
If f(x) = 1, if x≤ 3 ax +b, if 3 <x< 5 7, if 5≤x is continuous in R, then the values of a and b are: (A) a = 3, b=−8 (B) a = 3, b= 8 (C) a =−3, b=−8 (D) a =−3, b= 8
Answer
Answer as text
(A) 3 a +b = 1, 5a +b = 7⇒a = 3, b =−8.
