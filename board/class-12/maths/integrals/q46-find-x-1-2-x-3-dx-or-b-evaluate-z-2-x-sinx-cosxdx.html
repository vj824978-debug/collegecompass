Question 46 · Class 12 Mathematics · Integrals
Question as text
(a) Find: Z x2 + 1 (x− 1)2(x + 3)dx OR (b) Evaluate: Z π/2 x sinx + cosxdx
Answer
Answer as text
(a) x2+1 (x−1)2(x+3) = 3/8 x−1 + 1/2 (x−1)2 + 5/8 x+3; integral = 3 8 log|x− 1|− 1 2(x− 1) + 5 8 log|x + 3| +C. (b) Using Ra 0 f(x)dx = Ra 0 f(a−x)dx: 2I = π Rπ/2 dx sinx+cosx = π √ Rπ/2 0 sec x− π dx; I = π √ 2 log( √ 2 + 1).
