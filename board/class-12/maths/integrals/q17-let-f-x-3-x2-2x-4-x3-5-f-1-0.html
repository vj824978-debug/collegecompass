Question as text
Let f′(x) = 3(x2 + 2x)− 4 x3 + 5,f(1) = 0. Then, f(x) is: (A) x3 + 3x2 + 2 x2 + 5x + 11 (B) x3 + 3x2 + 2 x2 + 5x− 11 (C) x3 + 3x2− 2 x2 + 5x− 11 (D) x3− 3x2− 2 x2 + 5x− 11
Answer
Answer as text
(B) f =x3 + 3x2 + 2 x2 + 5x +C; f(1) = 11 +C = 0⇒C =−11.
