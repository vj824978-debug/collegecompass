CBSE 20196 marks
Question 47 · Class 12 Mathematics · Three Dimensional Geometry
Question as text
(a) Find the vector and Cartesian equations of the plane passing through the points (2, 2,−1), (3, 4, 2) and (7, 0, 6). Also find the vector equation of a plane passing through (4, 3, 1) and parallel to the plane obtained above. OR (b) Find the vector equation of the plane that contains the line ⃗ r= (ˆi + ˆj) +λ(ˆi + 2ˆj− ˆk) and the point (−1, 3,−4). Also, find the length of the perpendicular drawn from the point (2, 1, 4) to the plane thus obtained.
Answer
Answer as text
(a) Normal (1, 2, 3)× (5,−2, 7)∥ (5, 2,−3): ⃗ r· (5ˆi + 2ˆj− 3ˆk) = 17, i.e. 5x + 2y− 3z = 17; parallel plane through (4, 3, 1): ⃗ r· (5ˆi + 2ˆj− 3ˆk) = 23. (b) Normal (1, 2,−1)× (−2, 2,−4)∥ (1,−1,−1): ⃗ r· (ˆi− ˆj− ˆk) = 0; distance from (2, 1, 4): |2− 1− 4|√ 3 = √ 3 units.
