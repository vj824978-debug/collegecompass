Question 23 · Class 12 Mathematics · Differential Equations
Question as text
(a) Solve the following differential equation: xdy dx =y−x sin2 y x , given that y(1) = π 6. OR (b) Find the general solution of the differential equation: y logydx dy +x = 2 y .
Answer
Answer as text
(a) y =vx: xdv dx =− sin2v⇒ csc2vdv =−dx x ⇒ cot y x = log|x| +C; y(1) = π 6⇒C = √ 3: cot y x = log|x| + √ 3. (b) dx dy + x y logy = 2 y2 logy; IF = logy; x logy =−2 y +C.
