CBSE 202665/4/1
Question 8 · Class 12 Mathematics · Differential Equations
Question as text
Which of the following is not a Linear Differential Equation? (A) (1 + x2)dy + 2xydx = cotxdx (B) y + d dx(xy) =x(sinx + logx) (C) x(1 +y2)dx−y(1 +x2)dy = 0 (D) ydx− (x + 3y2)dy = 0
Answer
Answer as text
(C) dy dx = x(1+y2) y(1+x2) is non-linear in y (and in x); (A), (B) are linear in y, (D) is linear in x.
