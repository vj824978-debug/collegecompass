Determinants — Question 39 (CBSE 2018, 4 marks)

CBSE 20184 marks
Question 39 · Class 12 Mathematics · Determinants
Question as text
Using properties of determinants, prove that 1 1 1 + 3 x 1 + 3y 1 1 1 1 + 3 z 1 = 9(3xyz +xy +yz +zx).
Answer
Answer as text
Proof: C2→C2−C1, C3→C3−C1 gives rows (1, 0, 3x), (1 + 3y,−3y,−3y), (1, 3z, 0); expand along R1: 9yz + 3x(3z + 9yz + 3y) = 9(3xyz +xy +yz +zx).
