Determinants — Question 29 (CBSE 2025, 5 marks)

CBSE 202565/4/15 marks
Question 29 · Class 12 Mathematics · Determinants
Question as text
If A is a 3× 3 invertible matrix, show that for any scalar k̸= 0, (kA)−1 = 1 kA−1. Hence calculate (3A)−1, where A = 2 −1 1 −1 2 −1 1 −1 2 .
Answer
Answer as text
Proof: (kA) 1 kA−1 =AA−1 =I, so (kA)−1 = 1 kA−1.|A| = 4, adjA = 3 1 −1 1 3 1 −1 1 3 ; (3A)−1 = 1 3A−1 = 1 3 1 −1 1 3 1 −1 1 3 .
