If A is a non-singular matrix, then which of the following is not true?

CBSE 202665/5/1
Question 7 · Class 12 Mathematics · Determinants
Question as text
If A is a non-singular matrix, then which of the following is not true? (A) adj A is singular (B) (adj A)−1 = (adjA−1) (C) |A|̸ = 0 (D) A−1 exists
Answer
Answer as text
(A) | adjA| =|A|n−1̸= 0, so adjA is non-singular; (B), (C), (D) hold.
