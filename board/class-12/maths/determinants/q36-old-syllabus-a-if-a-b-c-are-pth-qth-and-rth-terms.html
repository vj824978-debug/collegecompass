Answer
Answer as text
(a) Proof: log a = logA + (p− 1) logR etc.; C1→C1− (logA− logR)C3− logRC 2 makesC1 zero, so the determinant is 0. (b) |A| =−1, A−1 = 0 1 −2 −2 9 −23 −1 5 −13 ; x = 1, y = 2, z = 3.
