Determinants — Question 38 (CBSE 2019, 6 marks)

CBSE 20196 marks
Question 38 · Class 12 Mathematics · Determinants
Question as text
(a) If A = 1 1 1 1 0 2 3 1 1 , find A−1. Hence, solve the system of equations x +y +z = 6, x + 2z = 7, 3x +y +z = 12. OR (b) [old syllabus] Find the inverse of the following matrix using elementary operations: A = 1 2 −2 −1 3 0 0 −2 1 .
Answer
Answer as text
(a)|A| = 4, A−1 = 1 −2 0 2 5 −2 −1 1 2 −1 ; X =A−1B with B = (6, 7, 12)T : x = 3, y = 1, z = 2. (b) |A| = 1, A−1 = 3 2 6 1 1 2 2 2 5 .
