Determinants — Question 27 (CBSE 2025, 5 marks)

CBSE 202565/2/15 marks
Question 27 · Class 12 Mathematics · Determinants
Question as text
(a) Given A = −4 4 4 −7 1 3 5 −3 −1 and B = 1 −1 1 1 −2 −2 2 1 3 , find AB. Hence, solve the system of linear equations: x−y +z = 4, x − 2y− 2z = 9, 2x +y + 3z = 1 OR (b) If A = 1 2 0 −2 −1 −2 0 −1 1 , then find A−1. Hence, solve the system of linear equations: x− 2y = 10, 2x−y−z = 8, −2y +z = 7
Answer
Answer as text
(a) AB = 8I, so B−1 = 1 8A; X =B−1 : x = 3, y =−2, z =−1. (b) |A| = 1, A−1 = −3 −2 −4 2 1 2 2 1 3 ; coefficient matrix is AT , so X = (A−1)T : x = 0, y =−5, z =−3.
