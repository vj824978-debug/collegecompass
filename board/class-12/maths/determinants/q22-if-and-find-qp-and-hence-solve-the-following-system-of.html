Determinants — Question 22 (CBSE 2026, 5 marks)

CBSE 202665/2/15 marks
Question 22 · Class 12 Mathematics · Determinants
Question as text
(a) If P = 1 −1 0 2 3 4 0 1 2 and Q = 2 2 −4 −4 2 −4 2 −1 5 , find (QP ) and hence solve the following system of equations using matrices: x−y = 3, 2x + 3y + 4z = 17, y + 2z = 7 OR (b) Obtain the value of ∆ = 1 +x 1 1 1 1 + y 1 1 1 1 + z in terms of x, y and z. Further, if ∆ = 0 and x, y, z are non-zero real numbers, prove that x−1 +y−1 +z−1 =−1.
Answer
Answer as text
(a) QP = 6I⇒P−1 = 1 6Q; system is PX =B with B = [3, 17, 7]T ; X = 1 6QB: x = 2, y =−1, z = 4. (b) ∆ = xyz +xy +yz +zx. Proof: ∆ = 0, divide by xyz̸= 0: 1 + 1 z + 1 x + 1 y = 0⇒x−1 +y−1 +z−1 =−1.
