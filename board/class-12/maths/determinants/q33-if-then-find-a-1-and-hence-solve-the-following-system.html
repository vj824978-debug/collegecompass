Determinants — Question 33 (CBSE 2024, 5 marks)

CBSE 20245 marks
Question 33 · Class 12 Mathematics · Determinants
Question as text
(a) If A = 1 2 −3 2 0 −3 1 2 0 , then find A−1 and hence solve the following system of equations: x + 2y− 3z = 1, 2x− 3z = 2, x + 2y = 3. OR (b) Find the product of the matrices 1 2 −3 2 3 2 3 −3 −4 −6 17 13 14 5 −8 −15 9 −1 and hence solve the system of linear equations: x + 2y− 3z =−4, 2x + 3y + 2z = 2, 3x− 3y− 4z = 11.
Answer
Answer as text
(a)|A| =−12, A−1 =− 1 6 −6 −6 −3 3 −3 4 0 −4 ; x = 2, y = 1 2, z = 2 3. (b) Product = 67I, so A−1 = 1 67B; solution x = 3, y =−2, z = 1.
