If A is a square matrix of order 3 such that the value of | adjA| = 8, then the value of |AT| is (A) √ 2 (B) − √ (C) 8 (D) 2 √
Answer
Answer as text
(D) | adjA| =|A|2 = 8⇒|AT| =|A| =±2 √ 2; the option listed is 2 √ 2.
