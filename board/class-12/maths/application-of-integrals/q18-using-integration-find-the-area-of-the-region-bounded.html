Application of Integrals — Question 18 (CBSE 2025, 5 marks)

CBSE 202565/2/15 marks
Question 18 · Class 12 Mathematics · Application of Integrals
Question as text
Using integration, find the area of the region bounded by the line y = 5x + 2, the x-axis and the ordinates x =−2 and x = 2.
Answer
Answer as text
Line meets x-axis at x =− 2 5; area = R−2/5 −2 −(5x + 2)dx + R 2 −2/5(5x + 2)dx = 32 5 + 72 5 = 104 5 sq. units.
