Question 44 · Class 12 Mathematics · Probability
Question as text
Let X be a random variable which assumes values x1,x 2,x 3,x 4 such that 2P (X = x1) = 3P (X = x2) =P (X =x3) = 5P (X =x4). Find the probability distribution of X.
Answer
Answer as text
P (x1) = k 2,P (x2) = k 3,P (x3) =k,P (x4) = k 5, sum = 61k 30 = 1⇒k = 30 61: P (X =x1,x 2,x 3,x 4) = 15 61, 10 61, 30 61, 6 61.
