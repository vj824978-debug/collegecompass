Probability — Question 41 (CBSE 2024, 3 marks)

CBSE 20243 marks
Question 41 · Class 12 Mathematics · Probability
Question as text
The random variable X has the following probability distribution where a and b are some constants: X 1 2 3 4 5 P (X) 0.2 a a 0.2 b If the mean E(X) = 3, then find values of a and b and hence determine P (X≥ 3).
Answer
Answer as text
2a +b = 0.6, 5a + 5b = 2: a = 0.2, b = 0.2; P (X≥ 3) = 0.6.
