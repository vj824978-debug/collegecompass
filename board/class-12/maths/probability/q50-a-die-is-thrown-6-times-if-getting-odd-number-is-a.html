Question as text
(a) A die is thrown 6 times. If “getting odd number” is a “success”, what is the probability of (i) 5 successes? (ii) atmost 5 successes? OR (b) The random variable X has a probability distribution P (X) of the following form, where k is some number: P (X =x) = k, if x = 0 2k, if x = 1 3k, if x = 2 0, otherwise Determine the value of k.
Answer
Answer as text
(a) n = 6, p = 1 2: (i) 6 1 26 = 3 32; (ii) 1− 1 64 = 63 64. (b) k + 2k + 3k = 1⇒k = 1 6.
