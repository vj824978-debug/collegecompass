CBSE 20202 marks
Question 47 · Class 12 Mathematics · Probability
Question as text
Given two independent events A and B such that P (A) = 0.3 and P (B) = 0.6, find P (A′∩B′).
Answer
Answer as text
P (A′)P (B′) = 0.7× 0.4 = 0.28.
