Assertion (A): Set of values of sec−1 √ ! is a null set.

CBSE 202565/7/1
Question 14 · Class 12 Mathematics · Inverse Trigonometric Functions
Question as text
Assertion (A): Set of values of sec−1 √ ! is a null set. Reason (R): sec−1x is defined for x∈ R− (−1, 1). (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(A) √ 2 ∈ (−1, 1), outside the domain of sec−1, so no value exists; R is true and explains A.
