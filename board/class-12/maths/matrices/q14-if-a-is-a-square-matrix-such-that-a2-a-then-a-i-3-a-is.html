Question as text
If A is a square matrix such that A2 =A, then (A−I)3−A is equal to: (A) I (B) −I (C) A (D) A2
Answer
Answer as text
(B) ( A−I)3 =A3− 3A2 + 3A−I =A−I (as An =A); so (A−I)3−A =−I.
