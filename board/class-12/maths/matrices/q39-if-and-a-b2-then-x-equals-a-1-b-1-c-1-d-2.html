Question as text
If A = 1 0 2 1 , B = x 0 1 1 and A =B2, then x equals: (A) ±1 (B) −1 (C) 1 (D) 2
Answer
Answer as text
(C) B2 = x2 0 x + 1 1 =A⇒x2 = 1, x+ 1 = 2⇒x = 1.
