Matrices — Question 40 (CBSE 2026, 3 marks)

CBSE 202665/4/13 marks
Question 40 · Class 12 Mathematics · Matrices
Question as text
If A = 3 2 0 1 4 0 0 0 5 , then compute A2− 7A + 10I.
Answer
Answer as text
A2 = 11 14 0 7 18 0 0 0 25 ; A2− 7A + 10I =O (the 3× 3 zero matrix).
