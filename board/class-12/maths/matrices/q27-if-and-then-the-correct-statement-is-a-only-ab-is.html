Question 27 · Class 12 Mathematics · Matrices
Question as text
If A = 1 2 3 −4 3 7 and B = 4 3 −1 2 0 5 , then the correct statement is: (A) Only AB is defined. (B) Only BA is defined. (C) AB and BA, both are defined. (D) AB and BA, both are not defined.
Answer
Answer as text
(C) A2×3B3×2 (2× 2) and B3×2A2×3 (3× 3) both defined.
