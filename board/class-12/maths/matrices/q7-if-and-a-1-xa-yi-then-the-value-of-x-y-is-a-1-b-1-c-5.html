If A2 = 4A + 3I and A−1 =xA +yI, then the value of (x +y) is: (A) −1 (B) 1 (C) 5 3 (D) 7
Answer
Answer as text
(A) A(A− 4I) = 3I⇒A−1 = 1 3A− 4 3I; x +y =−1.
