Matrices — Question 22 (CBSE 2025)

CBSE 202565/2/1
Question 22 · Class 12 Mathematics · Matrices
Question as text
If A and B are square matrices of order m such that A2−B2 = (A−B)(A +B), then which of the following is always correct? (A) A =B (B) AB =BA (C) A = 0 or B = 0 (D) A =I or B =I
Answer
Answer as text
(B) ( A−B)(A +B) =A2 +AB−BA−B2, so AB =BA.
