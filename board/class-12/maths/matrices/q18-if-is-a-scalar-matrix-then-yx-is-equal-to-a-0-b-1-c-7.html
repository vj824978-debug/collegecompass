Question as text
If A = 7 0 x 0 7 0 0 0 y is a scalar matrix, then yx is equal to: (A) 0 (B) 1 (C) 7 (D) ±7
Answer
Answer as text
(B) Scalar matrix: x = 0, y = 7; yx = 70 = 1.
