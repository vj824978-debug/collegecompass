Assertion (A): A = diag[3 5 2] is a scalar matrix of order 3 × 3.

CBSE 202565/2/1
Question 23 · Class 12 Mathematics · Matrices
Question as text
Assertion (A): A = diag[3 5 2] is a scalar matrix of order 3 × 3. Reason (R): If a diagonal matrix has all non-zero elements equal, it is known as a scalar matrix. (A) Both Assertion (A) and Reason (R) are true and the Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true but Reason (R) is false. (D) Assertion (A) is false but Reason (R) is true.
Answer
Answer as text
(D) Diagonal entries 3 , 5, 2 unequal, so A is false; R is the definition of a scalar matrix (true).
