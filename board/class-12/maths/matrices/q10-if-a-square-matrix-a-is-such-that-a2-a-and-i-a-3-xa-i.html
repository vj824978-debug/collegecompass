CBSE 202665/3/1
Question 10 · Class 12 Mathematics · Matrices
Question as text
If a square matrix A is such that A2 =A and (I−A)3 =xA +I, then value of x must be: (A) 7 (B) 5 (C) −7 (D) −1
Answer
Answer as text
(D) ( I−A)2 =I−A, so (I−A)3 =I−A⇒x =−1.
