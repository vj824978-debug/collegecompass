Question 28 · Class 12 Mathematics · Matrices
Question as text
Let both AB′ and B′A be defined for matrices A and B. If order of A is n×m, then the order of B is: (A) n×n (B) n×m (C) m×m (D) m×n
Answer
Answer as text
(B) AB′ defined⇒B′ has m rows;B′A defined⇒B′ has n columns; B′ is m×n, so B is n×m.
