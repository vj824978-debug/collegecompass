Matrices — Question 41 (CBSE 2025, 3 marks)

CBSE 202565/6/13 marks
Question 41 · Class 12 Mathematics · Matrices
Question as text
Let A = −2 and C = 3 4 2 12 16 8 −6 −8 −4 be two matrices. Then, find the matrix B if AB =C.
Answer
Answer as text
A is 3× 1, C is 3× 3, so B is 1× 3; first row gives B = 3 4 2 (rows 2, 3 check: 4B,−2B).
