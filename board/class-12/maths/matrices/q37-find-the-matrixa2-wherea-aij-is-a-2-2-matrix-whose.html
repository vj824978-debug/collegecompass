Find the matrixA2, whereA = [aij] is a 2×2 matrix whose elements are given byaij = maximum(i,j )− minimum(i,j ). (A) 0 0 0 0 (B) 0 1 1 0 (C) 1 0 0 1 (D) 1 1 1 1
Answer
Answer as text
(C) aij =|i−j|, A = 0 1 1 0 , A2 =I.
