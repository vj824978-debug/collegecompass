Question 35 · Class 12 Mathematics · Matrices
Question as text
If inverse of matrix 7 −3 −3 −1 1 0 −1 0 1 is the matrix 1 3 3 1 λ 3 1 3 4 , then value of λ is (A) −4 (B) 1 (C) 3 (D) 4
Answer
Answer as text
(D) (Row 1 of A)·(col 2 of A−1) = 21− 3λ− 9 = 0⇒λ = 4.
