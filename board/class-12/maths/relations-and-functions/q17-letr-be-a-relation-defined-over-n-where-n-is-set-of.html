Question as text
LetR be a relation defined over N, where N is set of natural numbers, defined as “mRn if and only if m is a multiple of n, m,n∈ N.” Find whether R is reflexive, symmetric and transitive or not.
Answer
Answer as text
Reflexive (m = 1·m); not symmetric (6R2 but 2̸R6); transitive (m =kn, n =lp⇒m =klp). So R is reflexive and transitive but not symmetric.
