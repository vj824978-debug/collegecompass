Check whether f : R−{ 3}→ R defined as f(x) = x− 2 x− 3 is onto or not.

CBSE 202665/2/12 marks
Question 12 · Class 12 Mathematics · Relations and Functions
Question as text
(a) Check whether f : R−{ 3}→ R defined as f(x) = x− 2 x− 3 is onto or not. OR (b) Check whether f : Z× Z→ Z× Z (where Z is the set of integers) defined as f(x,y ) = (2y, 3x) is injective or not.
Answer
Answer as text
(a) y = x−2 x−3⇒x = 3y−2 y−1 ; y = 1 has no pre-image, so f is not onto. (b) (2y1, 3x1) = (2y2, 3x2)⇒x1 =x2, y1 =y2, so f is injective.
