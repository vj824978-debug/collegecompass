Relations and Functions — Question 14 (CBSE 2026, 3 marks)

CBSE 202665/4/13 marks
Question 14 · Class 12 Mathematics · Relations and Functions
Question as text
(a) Let A = R−{ 3} and B = R−{ 1}. A function f :A→B is defined by f(x) = x− 2 x− 3 . Find whether f is one-one and onto. OR (b) Let n be a fixed positive integer. A relation R is defined in set Z such that R ={(x,y ) : (x−y) is divisible by n, x,y∈ Z}. Determine if R is an equivalence relation.
Answer
Answer as text
(a) f(x1) =f(x2)⇒x1 =x2 (one-one); for y̸= 1, x = 3y− 2 y− 1 ∈A with f(x) =y (onto). So f is one-one and onto (bijective). (b) Yes: n| 0 (reflexive);n| (x−y)⇒n| (y−x) (symmetric); n| (x−y), n| (y−z)⇒n| (x−z) (transitive); R is an equivalence relation.
