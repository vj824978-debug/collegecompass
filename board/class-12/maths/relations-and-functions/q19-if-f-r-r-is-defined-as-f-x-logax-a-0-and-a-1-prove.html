Relations and Functions — Question 19 (CBSE 2025, 3 marks)

CBSE 202565/4/13 marks
Question 19 · Class 12 Mathematics · Relations and Functions
Question as text
(a) If f : R+→ R is defined as f(x) = logax (a> 0 and a̸= 1), prove that f is a bijection. ( R+ is a set of all positive real numbers.) OR (b) Let A ={1, 2, 3} and B ={4, 5, 6}. A relation R from A to B is defined as R ={(x,y ) :x +y = 6, x∈A, y∈B}. (i) Write all elements of R. (ii) Is R a function? Justify. (iii) Determine domain and range of R.
Answer
Answer as text
(a) Proof: log ax1 = logax2⇒x1 =x2 (one-one); for any y∈ R, x =ay∈ R+ givesf(x) =y (onto); hence bijection. (b) (i) R ={(1, 5), (2, 4)}; (ii) not a function, since 3 ∈A has no image; (iii) domain{1, 2}, range{4, 5}.
