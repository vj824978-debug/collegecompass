CBSE 2023
Question 10 · Class 12 Mathematics · Relations and Functions
Question as text
Let A ={3, 5}. Then number of reflexive relations on A is: (A) 2 (B) 4 (C) 0 (D) 8
Answer
Answer as text
(B) Reflexive relations on an n-set: 2n2−n = 22 = 4.
