Relations and Functions — Question 32 (CBSE 2018, 6 marks)

CBSE 20186 marks
Question 32 · Class 12 Mathematics · Relations and Functions
Question as text
(a) Let A ={x∈ Z : 0 < x <12}. Show that R ={(a,b ) : a,b ∈ A, |a−b| is divisible by 4} is an equivalence relation. Find the set of all elements related to 1. Also write the equivalence class. OR (b) Show that the function f : R→ R defined by f(x) = x x2 + 1,∀x∈ R is neither one-one nor onto. Also, if g : R→ R is defined as g(x) = 2x− 1, find f◦g(x).
Answer
Answer as text
(a)|a−a| = 0;|a−b| =|b−a|; a−b = 4m, b−c = 4n⇒a−c = 4(m +n): equivalence. Elements related to 1: {1, 5, 9}, i.e. [1] ={1, 5, 9} (if the intended class is [2]: {2, 6, 10}; see note). (b) f(2) =f( 1 2) = 2 5, so not one-one; |f(x)|≤ 1 2, so e.g. 1 has no pre-image: not onto. f◦g(x) = 2x− 1 (2x− 1)2 + 1 = 2x− 1 4x2− 4x + 2.
