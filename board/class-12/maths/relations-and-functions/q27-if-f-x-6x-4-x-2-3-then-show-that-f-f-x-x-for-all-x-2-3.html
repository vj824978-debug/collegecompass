Relations and Functions — Question 27 (CBSE 2020, 2 marks)

CBSE 20202 marks
Question 27 · Class 12 Mathematics · Relations and Functions
Question as text
(a) If f(x) = 4x + 3 6x− 4, x̸= 2 3, then show that (f◦f)(x) =x, for all x̸= 2 3. Also, write inverse of f. OR (b) Check if the relationR in the set R of real numbers defined asR ={(a,b ) :a<b } is (i) symmetric, (ii) transitive.
Answer
Answer as text
(a) f(f(x)) = 4 4x+3 6x−4 + 3 6 4x+3 6x−4− 4 = 34x 34 =x; hence f−1 =f, i.e. f−1(x) = 4x + 3 6x− 4. (b) Not symmetric (1 < 2 but 2̸< 1); transitive (a<b, b<c ⇒a<c ).
