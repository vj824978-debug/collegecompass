Question as text
If a∗b denotes the larger of ‘ a’ and ‘b’ and if a◦b = (a∗b) + 3, then write the value of (5) ◦ (10), where∗ and◦ are binary operations.
Answer
Answer as text
5∗ 10 = 10, so 5◦ 10 = 10 + 3 = 13.
