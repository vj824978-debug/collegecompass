Assertion (A): Let A ={x∈ R :−1≤x≤ 1}.

CBSE 202565/5/1
Question 7 · Class 12 Mathematics · Relations and Functions
Question as text
Assertion (A): Let A ={x∈ R :−1≤x≤ 1}. If f :A→A be defined as f(x) =x2, then f is not an onto function. Reason (R): If y =−1∈A, then x =±√−1 /∈A. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(A) Range of x2 on [−1, 1] is [0, 1]̸=A, so not onto (A true); −1 has no pre-image since x2 =−1 gives x =±√−1 /∈A, which is exactly why (R true, explains A).
