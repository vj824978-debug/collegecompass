Question as text
(a) A relation R is defined on Z, the set of integers, as R ={(x,y ) :|x−y| is divisible by a prime number ‘p’, x,y∈ Z} Check whether R is an equivalence relation or not. OR (b) A function f : R− 3 −→ R− 3 is defined as f(x) = 3x + 2 5x− 3. Show that f is one-one and onto.
Answer
Answer as text
(a) For the fixed primep: reflexive (|x−x| = 0 divisible byp), symmetric (|x−y| =|y−x|), transitive (x−y =kp,y−z =lp⇒x−z = (k +l)p); hence R is an equivalence relation . (If “a prime” is read as “some prime”, transitivity fails: 1R3, 3R0 but|1− 0| = 1.) (b) Proof: f(x1) = f(x2)⇒ (3x1 + 2)(5x2− 3) = (3x2 + 2)(5x1− 3)⇒− 19x1 =−19x2, one-one; for y̸= 3 5, x = 3y+2 5y−3̸= 3 5 and f(x) =y, onto.
