Assertion (A): Letf(x) =ex andg(x) = logx.

CBSE 202565/6/1
Question 8 · Class 12 Mathematics · Relations and Functions
Question as text
Assertion (A): Letf(x) =ex andg(x) = logx. Then (f +g)x =ex + logx where domain of (f +g) is R. Reason (R): Dom(f +g) = Dom(f)∩ Dom(g). (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(D) Dom( f +g) = R∩ (0,∞) = (0,∞)̸= R, so A is false; R is true.
