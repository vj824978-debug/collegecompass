Case Study. An organization conducted bike race under two different categories – Boys and Girls. There were 28 participants in all. Among all of them, finally three from category 1 and two from category 2 were selected for the final race. Ravi forms two sets B and G with these participants for his college project. Let B ={b1,b 2,b 3} and G ={g1,g 2}, where B represents the set of Boys selected and G the set of Girls selected for the final race. Based on the above information, answer the following questions: (i) How many relations are possible from B to G? (ii) Among all the possible relations from B to G, how many functions can be formed from B to G? (iii) (a) Let R :B→B be defined by R ={(x,y ) : x and y are students of the same sex}. Check if R is an equivalence relation. OR (iii) (b) A function f : B→G be defined by f ={(b1,g 1), (b2,g 2), (b3,g 1)}. Check if f is bijective. Justify your answer.
Answer
Answer as text
(i) 23·2 = 64. (ii) 2 3 = 8. (iii)(a) All of b1,b 2,b 3 are boys, so R =B×B: reflexive, symmetric, transitive, hence an equivalence relation. (iii)(b) f(b1) =f(b3) =g1, so f is not one-one (though onto); hence f is not bijective.
