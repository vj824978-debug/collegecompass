A student wants to pair up natural numbers in such a way that they satisfy the equation 2x +y = 41,x,y∈ N.

CBSE 202565/6/13 marks
Question 21 · Class 12 Mathematics · Relations and Functions
Question as text
(a) A student wants to pair up natural numbers in such a way that they satisfy the equation 2x +y = 41,x,y∈ N. Find the domain and range of the relation. Check if the relation thus formed is reflexive, symmetric and transitive. Hence, state whether it is an equivalence relation or not. OR (b) Show that the function f : N → N, where N is a set of natural numbers, given by f(n) =( n− 1, if n is even n + 1, if n is odd is a bijection.
Answer
Answer as text
(a) R ={(x, 41− 2x) :x = 1,..., 20}; domain ={1, 2,..., 20}, range ={1, 3, 5,..., 39}. Not reflexive ((1, 1) /∈R), not symmetric ((1, 39)∈R, (39, 1) /∈R), not transitive ((20, 1), (1, 39)∈R, (20, 39) /∈R); not an equivalence relation. (b) Proof: f maps odd n to evenn + 1 and even n to odd n− 1; f(f(n)) =n for all n, so f is one-one and onto (each m has preimage f(m)), hence a bijection.
