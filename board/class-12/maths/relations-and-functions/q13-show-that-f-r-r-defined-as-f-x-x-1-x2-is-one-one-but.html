Show that f : R→ R defined as f(x) = x√ 1 +x2 is one-one but not onto.
Answer
Answer as text
Proof: one-one: f(x1) =f(x2)⇒x1,x 2 have the same sign and x2 1(1 +x2 2) =x2 2(1 +x2 1)⇒x2 1 =x2 2⇒x1 =x2. Not onto: |f(x)|< 1 for all x (range (−1, 1)), so e.g. 1∈ R has no pre-image.
