Examine whether the operation ∗ defined on R bya∗b =ab + 1 is (i) a binary operation or not, (ii) if a binary operation, is it associative or not?
Answer
Answer as text
(i) ab + 1∈ R for all a,b∈ R, so∗ is a binary operation. (ii) (a∗b)∗c =abc +c + 1,a∗ (b∗c) =abc +a + 1; not equal in general (e.g. a = 1,b = 2,c = 3: 10̸= 8), so not associative.
