Application of Derivatives — Question 41 (CBSE 2025, 2 marks)

CBSE 202565/6/12 marks
Question 41 · Class 12 Mathematics · Application of Derivatives
Question as text
Determine the values of x for which f(x) = x− 4 x + 1, x̸=−1 is an increasing or a decreasing function.
Answer
Answer as text
f′(x) = 5 (x + 1)2 > 0 for all x̸=−1: f is increasing on (−∞,−1) and on (−1,∞); never decreasing.
