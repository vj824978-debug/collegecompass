Find the least value of ‘a’ so that f(x) = 2x2−ax + 3 is an increasing function on [2, 4].

CBSE 202565/4/12 marks
Question 35 · Class 12 Mathematics · Application of Derivatives
Question as text
(a) Find the least value of ‘a’ so that f(x) = 2x2−ax + 3 is an increasing function on [2, 4]. OR (b) If f(x) =x + 1 x, x≥ 1, show that f is an increasing function.
Answer
Answer as text
(a) f′(x) = 4x−a≥ 0 on [2, 4] iff a≤ 8. see note: a has no least value; the extreme admissible value is a = 8 (greatest), which is the intended answer. (b) f′(x) = 1− 1 x2 = x2−1 x2 ≥ 0 for x≥ 1 (zero only at x = 1), so f is increasing on [1,∞).
