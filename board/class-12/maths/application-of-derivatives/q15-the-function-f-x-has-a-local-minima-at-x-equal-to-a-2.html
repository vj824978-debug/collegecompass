CBSE 2024
Question 15 · Class 12 Mathematics · Application of Derivatives
Question as text
The function f(x) = x 2 + 2 x has a local minima at x equal to (A) 2 (B) 1 (C) 0 (D) −2
Answer
Answer as text
(A) f′ = 1 2− 2 x2 = 0⇒x =±2; f′′(2) = 1 2 > 0.
