The least value of f(x) =x3− 12x, x∈ [0, 3] is (A) −16 (B) −9 (C) 0 (D) 16
Answer
Answer as text
(A) f′(x) = 3x2− 12 = 0⇒x = 2; f(0) = 0, f(2) =−16, f(3) =−9.
