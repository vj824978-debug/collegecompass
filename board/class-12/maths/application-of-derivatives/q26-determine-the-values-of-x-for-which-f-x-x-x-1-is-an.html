Application of Derivatives — Question 26 (CBSE 2026, 2 marks)

CBSE 202665/5/12 marks
Question 26 · Class 12 Mathematics · Application of Derivatives
Question as text
Determine the values of x for which f(x) = x− 3 x + 1, x̸=−1 is an increasing function.
Answer
Answer as text
f′(x) = 4 (x + 1)2 > 0 for all x̸=−1; f is increasing for all x∈ R−{− 1}, i.e. on (−∞,−1) and (−1,∞).
