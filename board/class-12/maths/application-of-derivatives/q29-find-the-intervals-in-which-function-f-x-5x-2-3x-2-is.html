Find the intervals in which function f(x) = 5x 2− 3x 2 is (i) increasing (ii) decreasing.
Answer
Answer as text
f′(x) = 15 √x(1−x) (domain x≥ 0): (i) increasing on [0 , 1]; (ii) decreasing on [1,∞).
