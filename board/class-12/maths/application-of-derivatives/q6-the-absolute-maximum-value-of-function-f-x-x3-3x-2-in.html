Question as text
The absolute maximum value of function f(x) =x3− 3x + 2 in [0, 2] is: (A) 0 (B) 2 (C) 4 (D) 5
Answer
Answer as text
(C) f′ = 3(x2− 1); f(0) = 2, f(1) = 0, f(2) = 4; max = 4.
