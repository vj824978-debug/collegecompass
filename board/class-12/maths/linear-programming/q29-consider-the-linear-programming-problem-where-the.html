Consider the Linear Programming Problem, where the objective function Z = (x + 4y) needs to be minimized subject to constraints 2x +y≥ 1000, x + 2y≥ 800, x,y ≥ 0. Draw a neat graph of the feasible region and find the minimum value of Z.
Answer
Answer as text
Unbounded region with corners (0, 1000), (400, 200), (800, 0): Z = 4000, 1200, 800. Half-plane x + 4y <800 has no common point with the region (there x + 4y≥x + 2y≥ 800), so minimum Z = 800 at (800, 0).
