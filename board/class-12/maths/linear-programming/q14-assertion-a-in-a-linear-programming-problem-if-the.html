Assertion (A): In a Linear Programming Problem, if the feasible region is empty, then the Linear Programming Problem has no solution. Reason (R): A feasible region is defined as the region that satisfies all the constraints. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(A) No point satisfies all constraints, so there is no feasible (hence no optimal) solution; R explains A.
