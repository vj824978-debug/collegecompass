CBSE 202565/5/1
Question 15 · Class 12 Mathematics · Linear Programming
Question as text
For a Linear Programming Problem (LPP), the given objective function Z = 3x + 2y is subject to constraints: x + 2y≤ 10, 3x +y≤ 15, x,y ≥ 0 The correct feasible region is: (A) ABC (B) AOEC (C) CED (D) Open unbounded region BCD
Answer
Answer as text
(B) Both constraints are “ ≤” with x,y≥ 0: bounded region O(0, 0), E(5, 0), C(4, 3), A(0, 5).
