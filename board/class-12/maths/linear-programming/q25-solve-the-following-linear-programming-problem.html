Linear Programming — Question 25 (CBSE 2025, 3 marks)

CBSE 202565/1/13 marks
Question 25 · Class 12 Mathematics · Linear Programming
Question as text
Solve the following linear programming problem graphically: Maximise Z =x + 2y Subject to the constraints: x−y≥ 0, x − 2y≥− 2, x ≥ 0, y≥ 0.
Answer
Answer as text
Feasible region is unbounded with corner points (0 , 0) and (2, 2) (Z = 0, 6); the half-plane x + 2y >6 meets the region (e.g. (10, 0)), so Z has no maximum value.
