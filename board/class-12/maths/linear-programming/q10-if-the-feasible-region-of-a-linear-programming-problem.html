If the feasible region of a linear programming problem with objective functionZ =ax+by, is bounded, then which of the following is correct? (A) It will only have a maximum value. (B) It will only have a minimum value. (C) It will have both maximum and minimum values. (D) It will have neither maximum nor minimum value.
Answer
Answer as text
(C) A bounded feasible region always gives both max and min (at corner points).
