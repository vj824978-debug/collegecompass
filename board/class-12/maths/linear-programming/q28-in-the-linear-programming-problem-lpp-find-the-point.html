Linear Programming — Question 28 (CBSE 2025, 3 marks)

CBSE 202565/5/13 marks
Question 28 · Class 12 Mathematics · Linear Programming
Question as text
In the Linear Programming Problem (LPP), find the point/points giving maximum value for Z = 5x + 10y subject to constraints x + 2y≤ 120, x +y≥ 60, x − 2y≥ 0, x,y ≥ 0.
Answer
Answer as text
Corners (60, 0), (120, 0), (60, 30), (40, 20): Z = 300, 600, 600, 400. Max Z = 600 at (120, 0) and (60, 30), i.e. at every point of the segment joining them.
