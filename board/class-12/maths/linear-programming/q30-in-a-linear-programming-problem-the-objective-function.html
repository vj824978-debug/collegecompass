In a Linear Programming Problem, the objective function Z = 5x + 4y needs to be maximised under constraints 3x +y≤ 6, x≤ 1, x,y ≥ 0. Express the LPP on the graph and shade the feasible region and mark the corner points.
Answer
Answer as text
Feasible region: quadrilateral with corner points (0 , 0), (1, 0), (1, 3), (0, 6) (Z = 0, 5, 17, 24; max 24 at (0, 6)).
