Linear Programming — Question 23 (CBSE 2026, 3 marks)

CBSE 202665/4/13 marks
Question 23 · Class 12 Mathematics · Linear Programming
Question as text
Solve the following Linear Programming Problem graphically: Maximise Z = 200x + 120y subject to the constraints x +y≤ 300, 3x +y≤ 600, x −y≥− 100, x,y ≥ 0.
Answer
Answer as text
Corner points (0, 0), (200, 0), (150, 150), (100, 200), (0, 100) with Z = 0, 40000, 48000, 44000, 12000; max Z = 48000 at x = 150, y = 150.
