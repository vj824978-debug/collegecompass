Linear Programming — Question 31 (CBSE 2025, 3 marks)

CBSE 202565/7/13 marks
Question 31 · Class 12 Mathematics · Linear Programming
Question as text
In the Linear Programming Problem for objective function Z = 18x + 10y subject to constraints 4x +y≥ 20, 2x + 3y≥ 30, x,y ≥ 0 find the minimum value of Z.
Answer
Answer as text
Unbounded region, corners (0, 20), (3, 8), (15, 0) with Z = 200, 134, 270; 18x + 10y <134 has no point in the region, so Zmin = 134 at (3, 8).
