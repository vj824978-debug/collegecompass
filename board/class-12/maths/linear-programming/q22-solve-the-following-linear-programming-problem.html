Linear Programming — Question 22 (CBSE 2026, 5 marks)

CBSE 202665/3/15 marks
Question 22 · Class 12 Mathematics · Linear Programming
Question as text
Solve the following Linear Programming Problem graphically: Maximise Z = 600x + 400y subject to the constraints x + 2y≤ 12, 4x + 5y≥ 20, 2x +y≤ 12, x,y ≥ 0.
Answer
Answer as text
Corner points (5, 0), (6, 0), (4, 4), (0, 6), (0, 4) with Z = 3000, 3600, 4000, 2400, 1600; maximum Z = 4000 at (4, 4).
