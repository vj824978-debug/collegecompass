Question 18 · Class 12 Mathematics · Linear Programming
Question as text
In a Linear Programming Problem (LPP), the objective function Z = 2x + 5y is to be maximised under the following constraints: x +y≤ 4, 3x + 3y≥ 18, x,y ≥ 0 Study the graph and select the correct option. (Note: The figure is not to scale) The solution of the given LPP: (A) lies in the shaded unbounded region. (B) lies in ∆ AOB. (C) does not exist. (D) lies in the combined region of ∆ AOB and unbounded shaded region.
Answer
Answer as text
(C) x +y≤ 4 and x +y≥ 6 have no common point: no feasible region, so no solution.
