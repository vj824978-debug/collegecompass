Linear Programming — Question 26 (CBSE 2025, 3 marks)

CBSE 202565/2/13 marks
Question 26 · Class 12 Mathematics · Linear Programming
Question as text
Solve the following linear programming problem graphically: Minimise Z =x− 5y subject to the constraints: x−y≥ 0, −x + 2y≥ 2, x ≥ 3, y≤ 4, y≥ 0.
Answer
Answer as text
Bounded feasible region with corners (3, 5 2), (3, 3), (4, 4), (6, 4): Z =− 19 2,−12,−16,−14. Minimum Z =−16 at (4, 4).
