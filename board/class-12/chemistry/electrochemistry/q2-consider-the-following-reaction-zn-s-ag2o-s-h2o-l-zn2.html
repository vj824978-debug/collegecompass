Question 2 · Class 12 Chemistry · Electrochemistry
Question as text
Consider the following reaction: Zn(s) + Ag2O(s) + H2O(l)−−→Zn2+(aq) + 2 Ag(s) + 2 OH– (aq) Given: E◦ Ag+/Ag = 0.80 V, E◦ Zn2+/Zn =−0.76 V, 1 F = 96500 C mol−1 ∆rG◦ for the above reaction is: (A) −301.080 kJ mol−1 (B) +310 .080 kJ mol−1 (C) −326.070 kJ mol−1 (D) −375.060 kJ mol−1
Answer
Answer as text
(A) E◦ cell = 0.80− (−0.76) = 1.56 V,n = 2; ∆rG◦ =−2× 96500× 1.56 =−301080 J =−301.080 kJ mol−1.
