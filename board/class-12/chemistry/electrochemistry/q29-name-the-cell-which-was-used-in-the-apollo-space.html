Name the cell which was used in the Apollo space programme for providing electrical power.

CBSE 202656/5/12 marks
Question 29 · Class 12 Chemistry · Electrochemistry
Question as text
(a) Name the cell which was used in the Apollo space programme for providing electrical power. (b) Define limiting molar conductivity.
Answer
Answer as text
(a) H2–O2 fuel cell. (b) Λ◦ m: molar conductivity when concentration approaches zero (infinite dilution).
