Name the cell used in hearing aids and watches.

CBSE 20201 mark
Question 49 · Class 12 Chemistry · Electrochemistry
Question as text
Name the cell used in hearing aids and watches.
Answer
Answer as text
Mercury cell (a primary cell; Zn–Hg amalgam anode, HgO + C cathode, 1.35 V).
