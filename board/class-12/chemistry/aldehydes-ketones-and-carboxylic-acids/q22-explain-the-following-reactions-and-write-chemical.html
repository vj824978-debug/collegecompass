(A) Explain the following reactions and write chemical equation involved: (a) Wolff-Kishner reduction (b) Etard reaction (c) Cannizzaro reaction OR (B) Write the structures of A, B and C in the following sequence of reactions: (a) CH3COOH SOCl2 −−−−→A H2, Pd–BaSO 4 −−−−−−−−−→B H2N–NH 2 −−−−−−→C (b) CH3CN 1. (DIBAL–H) −−−−−−−−−→2. H 2O A Dil. NaOH−−−−−−→B ∆−−→C
Answer
Answer as text
(A)(a) Wolff–Kishner: >C––O→ hydrazone with NH2NH2, then KOH in ethylene glycol on heating: >CH2 + N2; e.g. CH3COCH3 NH2NH2 −−−−−→–H 2O (CH3)2C––NNH2 KOH/glycol −−−−−−−→∆ CH3CH2CH3 + N2. (b) Etard: toluene + chromyl chloride (CrO 2Cl2) in CS 2 gives a chromium complex, hydrolysed (H 3O+) to benzaldehyde. (c) Cannizzaro: aldehydes without α-H disproportionate with conc. alkali: 2 HCHO + conc· KOH−−→CH3OH + HCOOK. (B)(a) A = CH 3COCl; B = CH 3CHO (Rosenmund); C = CH3CH––N–NH 2 (acetaldehyde hydrazone). (b) A = CH 3CHO; B = CH3CH(OH)CH2CHO (3-hydroxybutanal, aldol); C = CH3CH––CHCHO (but-2-enal).
