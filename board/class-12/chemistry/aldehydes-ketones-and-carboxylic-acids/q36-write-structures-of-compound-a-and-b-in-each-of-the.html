Question as text
Write structures of compound A and B in each of the following reactions: (i) (ii)
Answer
Answer as text
(i) A = potassium benzoate C 6H5COOK (side chain oxidised); B = benzoic acid C 6H5COOH. (ii) A = cyclohexanone; B = cyclohexanone semicarbazone C6H10 ––N–NH–CO–NH 2.
