(i) An organic compound (X) has the molecular formula C 5H10O.

CBSE 202656/1/15 marks
Question 11 · Class 12 Chemistry · Aldehydes, Ketones and Carboxylic Acids
Question as text
(a) (i) An organic compound (X) has the molecular formula C 5H10O. Draw structures for (X) if it: (I) does not give Tollen’s test but gives a positive iodoform test. (II) does not give Tollen’s test and iodoform test but undergoes Aldol condensation. (III) undergoes Cannizzaro’s reaction. (ii) Show how each of the following compounds can be converted to benzoic acid: (I) Acetophenone (II) Ethyl benzene OR (b) Answer the following questions: (i) Draw structure of the 2, 4-dinitrophenyl hyzdrazone derivative of benzaldehyde. (ii) Arrange the following in increasing order of their reactivity towards HCN: Di-tert. butyl ketone, Acetaldehyde, Acetone (iii) Give a simple chemical test to distinguish between benzoic acid and ethyl benzoate. (iv) Write the name of the reagent to convert Ethanenitrile to Ethanal. (v) Draw the structure of ‘X’ in the following reaction:
Answer
Answer as text
(a)(i)(I) Pentan-2-one CH3COCH2CH2CH3 (or 3-methylbutan-2-one); (II) pentan-3-one CH 3CH2COCH2CH3; (III) 2,2-dimethylpropanal (CH3)3C–CHO (no α-H). (ii)(I) Acetophenone NaOI (I2/NaOH) −−−−−−−−−−→C6H5COONa + CHI3, then H 3O+ → benzoic acid (or KMnO 4/KOH, heat; H3O+). (II) Ethylbenzene KMnO4/KOH −−−−−−−−→heat C6H5COOK, then H 3O+→ C6H5COOH. (b)(i) C6H5CH––N–NH–C 6H3(NO2)2 (2,4-dinitro on the phenyl ring). (ii) Di-tert-butyl ketone < Acetone < Acetaldehyde. (iii) NaHCO 3 solution: benzoic acid gives brisk effervescence of CO 2; ethyl benzoate does not. (iv) Stephen reagent: SnCl 2 + HCl, then H3O+ (or DIBAL-H, then H2O). (v) X = cyclohexanone.
