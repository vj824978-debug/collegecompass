Which one of the following has lowest pKa value?

CBSE 2023
Question 7 · Class 12 Chemistry · Aldehydes, Ketones and Carboxylic Acids
Question as text
Which one of the following has lowest pKa value? (A) CH 3 –COOH (B) O 2N–CH 2 –COOH (C) Cl–CH 2 –COOH (D) HCOOH
Answer
Answer as text
(B) –NO 2 has the strongest−I effect, so nitroacetic acid is the strongest acid (lowest pKa).
