Which of the following aldehydes will undergo Cannizzaro reaction?

CBSE 202556/5/1
Question 4 · Class 12 Chemistry · Aldehydes, Ketones and Carboxylic Acids
Question as text
Which of the following aldehydes will undergo Cannizzaro reaction? (A) CH 3 –CH(CH 3)–CHO (B) (CH 3)3C CHO (C) CH 3 –CH 2 –CHO (D) CH 3 –CH(CH 3)–CH(CH 3)–CHO
Answer
Answer as text
(B) (CH 3)3C–CHO has no α-hydrogen.
