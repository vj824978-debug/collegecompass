(a) (i) Identify A, B and C in the following reactions : (ii) Give reasons for the following : (I) Carboxylic acids do not give the characteristic reactions of carbonyl group. (II) Ethanoic acid is a stronger acid than ethanol. OR (b) (i) Write the product(s) in the following reactions : (I) 2 CH3COOH P4O10 −−−−→heat (II) (III) (ii) Write the reaction involved in the following reactions : (I) Wolff-Kishner Reduction (II) Decarboxylation Reaction
Answer
Answer as text
(a)(i) A = benzylidene diacetate C 6H5CH(OCOCH3)2; B = benzaldehyde C6H5CHO; C = benzyl alcohol C 6H5CH2OH (Cannizzaro). (ii)(I) The C=O of –COOH is in resonance with the lone pair of –OH, so the carbonyl carbon is less electrophilic. (II) Ethanoate ion is resonance-stabilised (charge on two equivalent O atoms); ethoxide is not (and is destabilised by +I of ethyl). (b)(i)(I) (CH3CO)2O + H2O (ethanoic anhydride). (II) 2 C 6H5COCl + (CH3)2Cd−−→2 C6H5COCH3 + CdCl2 (acetophenone). (III) Phthalimide + NH3. (ii)(I) R2C––O NH2NH2 −−−−−→–H 2O R2C––NNH2 KOH/ethylene glycol −−−−−−−−−−−−→heat R2CH2 + N2. (II) RCOONa NaOH + CaO−−−−−−−−→heat RH + Na2CO3.
