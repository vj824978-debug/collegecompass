Which of the following molecules has a chiral centre correctly labelled with an asterisk (*)?

CBSE 2023
Question 21 · Class 12 Chemistry · Haloalkanes and Haloarenes
Question as text
Which of the following molecules has a chiral centre correctly labelled with an asterisk (*)? (A) CH 3C*HBrCH3 (B) CH 3C*HClCH2Br (C) HOCHC *H(OH)CH2OH (D) CH 3C*Br2CH3
Answer
Answer as text
(B) C* in CH 3CHClCH2Br carries four different groups (H, Cl, CH3, CH2Br); the others have two identical groups (option (C), printed as HOCHC*H(OH)CH 2OH, is evidently glycerol HOCH2CH(OH)CH2OH, achiral).
