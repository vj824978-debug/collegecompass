Define ambident nucleophile with an example.

CBSE 20191 mark
Question 55 · Class 12 Chemistry · Haloalkanes and Haloarenes
Question as text
Define ambident nucleophile with an example.
Answer
Answer as text
A nucleophile with two nucleophilic (donor) sites, which can attack through either atom, e.g. CN – (via C→ cyanide, via N→ isocyanide) or NO2 – (via N→ nitro, via O→ nitrite).
