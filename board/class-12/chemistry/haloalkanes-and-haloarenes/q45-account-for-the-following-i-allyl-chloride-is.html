Account for the following : (i) Allyl chloride is hydrolysed more readily than n-propyl chloride.

CBSE 202556/4/13 marks
Question 45 · Class 12 Chemistry · Haloalkanes and Haloarenes
Question as text
(a) Account for the following : (i) Allyl chloride is hydrolysed more readily than n-propyl chloride. (ii) Isocyanides are formed when alkyl halides are treated with silver cyanide. (iii) Methyl chloride reacts faster with –OH ion in S N2 reaction than t-butyl chloride. OR (b) Complete the following reactions by writing the structural formulae of ‘A’ and ‘B’ : (i) CH3CH––CH2 HBr−−−−−→Peroxide ‘A’ aq· KOH −−−−−→‘B’ (ii) CH3CH2CH(Cl)CH3 alc· KOH−−−−−−→∆ ‘A’ HBr−−→‘B’ (iii) ‘A’ Mg −−→CH3CH2MgCl H2O−−−→ H+ ‘B’ (Main product)
Answer
Answer as text
(a)(i) Allyl carbocation CH 2 ––CH–CH 2+ is resonance-stabilised, so allyl chloride ionises readily. (ii) AgCN is covalent; only the N lone pair is available, so attack through N gives R–NC. (iii) S N2 needs back-side attack; CH3Cl has least steric hindrance, the three methyls of t-butyl chloride block it. (b)(i) A = CH 3CH2CH2Br (anti-Markovnikov), B = CH3CH2CH2OH. (ii) A = CH 3CH––CHCH3 (but-2-ene, Saytzeff), B = CH3CH2CHBrCH3. (iii) A = CH 3CH2Cl, B = CH 3CH3 (ethane).
