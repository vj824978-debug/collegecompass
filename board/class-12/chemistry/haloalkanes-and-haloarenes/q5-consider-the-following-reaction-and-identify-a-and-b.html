Haloalkanes and Haloarenes — Question 5 (CBSE 2026)

Question 5 · Class 12 Chemistry · Haloalkanes and Haloarenes
Question as text
Consider the following reaction and identify A and B : CH3Cl + NaI dry acetone −−−−−−−→A + B (A) A = CH 3I, B = NaCl (B) A = CH 3OH, B = NaCl (C) A = CH 3CHO, B = NaCl (D) A = C 2H6, B = CH 3I
Answer
Answer as text
(A) Finkelstein: CH 3Cl + NaI−−→CH3I + NaCl↓ (NaCl insoluble in acetone).
