Question as text
Write the structures of the main products of the following reactions : (a) (b) 6 (CH3)3C–OH + 2 Al−−→
Answer
Answer as text
(a) NaBH4 reduces only the ketone, not the ester: 2-(CH2CH2COOCH3)cyclohexan-1-ol, i.e. methyl 3-(2-hydroxycyclohexyl)propanoate. (b) 6 (CH3)3COH + 2 Al−−→2 [(CH3)3CO]3Al + 3 H2: aluminium tert-butoxide.
