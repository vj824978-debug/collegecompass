Write the structures of the main products in the following reactions: (i) (ii) (iii)
Answer
Answer as text
(i) NaBH4 reduces only the ketone, not the ester: methyl 2-(2-hydroxycyclohexyl)acetate (ring C=O→ CH–OH, –CH 2COOCH3 unchanged). (ii) Acid-catalysed hydration (Markovnikov, via benzylic cation): C6H5CH(OH)CH3 (1-phenylethanol). (iii) C6H5OC2H5 + HI−−→C6H5OH + C2H5I (phenol + iodoethane; aryl–O bond is not cleaved).
