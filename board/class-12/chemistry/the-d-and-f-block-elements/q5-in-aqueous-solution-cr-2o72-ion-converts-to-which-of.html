In aqueous solution, Cr 2O72– ion converts to which of the following in alkaline medium? (A) Cr 3+ (B) CrO 42– (C) CrO (D) CrO 3
Answer
Answer as text
(B) Cr 2O72– + 2 OH–−−→2 CrO42– + H2O.
