Question as text
Examine the following observations: (a) Transition elements generally form coloured compounds. (b) Zinc is not regarded as a transition element.
Answer
Answer as text
(a) Partly filled d orbitals: in a ligand field they split and d–d transitions absorb visible light; the complementary colour is seen. (b) Zn has a completely filled 3d10 configuration in the ground state as well as in its common oxidation state (+2), so it does not fit the definition (incompletely filled d subshell).
