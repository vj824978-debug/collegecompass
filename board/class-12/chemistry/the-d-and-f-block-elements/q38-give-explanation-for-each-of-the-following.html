Question as text
Give explanation for each of the following observations : (a) With the same d-orbital configuration ( d4), Mn3+ ion is an oxidising agent whereas Cr 2+ ion is a reducing agent. (b) Actinoid contraction is greater from element to element than that among lanthanoids. (c) Transition metals form large number of interstitial compounds with H, B, C and N.
Answer
Answer as text
(a) Mn3+ (d4)→ Mn2+ (d5, stable half-filled) so it is an oxidant; Cr 2+ (d4)→ Cr3+ (d3, stable half-filled t3 2g) so it is a reductant. (b) 5f electrons shield poorly (more than 4f), so the increase in effective nuclear charge per element is larger. (c) Small H, B, C, N atoms get trapped in the interstitial voids of the metal crystal lattice.
