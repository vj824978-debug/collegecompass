(i) Account for the following : (I) MnO is basic while Mn 2O7 is acidic.

CBSE 202656/4/15 marks
Question 32 · Class 12 Chemistry · The d- and f-Block Elements
Question as text
(a) (i) Account for the following : (I) MnO is basic while Mn 2O7 is acidic. (II) Iron has higher enthalpy of atomization than that of copper. (III) Mn 3+ is a stronger oxidising agent than Cr 3+. (ii) How do you prepare potassium dichromate from sodium chromate? Write balanced chemical equation for each step. OR (b) Answer the following questions : (i) Why is chemistry of actinoids more complicated as compared to lanthanoids? (ii) E◦ M2+/M values are not regular for first row transition elements (3d series). Why? (iii) Identify the following : (I) Oxoanion of chromium which is stable in acidic medium. (II) The lanthanoid element that exhibits +4 oxidation state. (iv) Write the products obtained on heating KMnO 4. (v) Predict which of the following ions will be coloured in aqueous solution : Cu+, Sc3+, Fe2+, Ti3+, Zn2+
Answer
Answer as text
(a) (i) (I) In MnO, Mn is in the low +2 state (ionic oxide, basic); in Mn2O7, +7 state, covalent oxide, acidic. (II) Fe (3 d64s2) has more unpaired electrons than Cu (3d104s1), giving stronger metallic bonding. (III) Mn 3+ (3d4)−−→Mn2+ (3d5) gives the stable half-filled d5 ion, whereas Cr3+ (t3 2g) is very stable and resists reduction. (ii) 2 Na2CrO4 + 2 H+−−→Na2Cr2O7 + 2 Na+ + H2O; Na2Cr2O7 + 2 KCl−−→K2Cr2O7 + 2 NaCl. (b) (i) Actinoids show a wide range of oxidation states and are radioactive (many short-lived, available in tiny amounts). (ii) Irregular variation of ionisation enthalpies (∆iH1 + ∆iH2) and of sublimation enthalpies across the series. (iii) (I) Dichromate, Cr 2O72– ; (II) Cerium (Ce4+). (iv) 2 KMnO 4 ∆−−→K2MnO4 + MnO2 + O2. (v) Fe 2+ (3d6) and Ti3+ (3d1) are coloured; Cu +, Zn2+ (d10) and Sc 3+ (d0) are colourless.
