Question 28 · Class 12 Chemistry · Coordination Compounds
Question as text
(a) Write the IUPAC name of the following complex : K3[Cr(C2O4)3] (b) Differentiate between homoleptic complex and heterolyptic complex. (c) Which type of isomerism is exhibited by the following complex : [Pt(NH3)2Cl2]
Answer
Answer as text
(a) Potassium trioxalatochromate(III). (b) Homoleptic: metal bound to only one kind of donor ligand, e.g. [Co(NH 3)6]3+; heteroleptic: more than one kind, e.g. [Co(NH 3)4Cl2]+. (c) Geometrical (cis–trans) isomerism.
