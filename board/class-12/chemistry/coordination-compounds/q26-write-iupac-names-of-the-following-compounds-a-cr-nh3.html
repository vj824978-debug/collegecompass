Question as text
Write IUPAC names of the following compounds : (a) [Cr(NH3)4(ONO)Cl]NO3 (b) Na[Ag(CN)2]
Answer
Answer as text
(a) Tetraamminechloridonitrito-O-chromium(III) nitrate. (b) Sodium dicyanidoargentate(I).
