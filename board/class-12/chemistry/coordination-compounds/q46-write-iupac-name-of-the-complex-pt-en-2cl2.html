Write IUPAC name of the complex [Pt(en) 2Cl2].

CBSE 20192 marks
Question 46 · Class 12 Chemistry · Coordination Compounds
Question as text
(a) Write IUPAC name of the complex [Pt(en) 2Cl2]. Draw structures of geometrical isomers for this complex. OR (b) Using IUPAC norms write the formulae for the following: (i) Hexaamminecobalt(III) sulphate (ii) Potassium trioxalatochromate(III)
Answer
Answer as text
(a) Dichloridobis(ethane-1,2-diamine)platinum(II) (as printed; the real compound is usually the Pt(IV) cation [Pt(en) 2Cl2]2+). Octahedral: cis isomer (two Cl adjacent, 90◦; optically active) and trans isomer (Cl opposite, 180◦; both en in one plane). (b) (i) [Co(NH 3)6]2(SO4)3; (ii) K 3[Cr(C2O4)3].
