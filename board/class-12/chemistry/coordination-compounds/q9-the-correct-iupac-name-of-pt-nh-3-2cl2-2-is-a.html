The correct IUPAC name of [Pt(NH 3)2Cl2]2+ is (A) Diamminedichloridoplatinum (II) (B) Diamminedichloridoplatinum (IV) (C) Diamminedichloridoplatinum (0) (D) Diamminedichloridoplatinate (IV)
Answer
Answer as text
(B) x + 0 + 2(−1) = +2⇒x = +4; cationic complex, so “platinum(IV)”.
