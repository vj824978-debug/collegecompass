Which of the following is heteroleptic complex?

CBSE 202656/2/1
Question 3 · Class 12 Chemistry · Coordination Compounds
Question as text
Which of the following is heteroleptic complex? (A) [Co(NH 3)6]3+ (B) [Cr(NH 3)6]3+ (C) [Ni(H 2O)6]2+ (D) [Co(NH 3)4Cl2]+
Answer
Answer as text
(D) [Co(NH 3)4Cl2]+ has two kinds of ligands (NH 3, Cl – ).
