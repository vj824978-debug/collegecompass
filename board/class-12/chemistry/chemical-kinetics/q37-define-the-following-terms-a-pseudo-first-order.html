Define the following terms: (a) Pseudo first order reaction (b) Half-life period of reaction ( t1/2)

Question as text
Define the following terms: (a) Pseudo first order reaction (b) Half-life period of reaction ( t1/2)
Answer
Answer as text
(a) A reaction of higher molecularity that behaves as first order because one reactant is in large excess (e.g. acid hydrolysis of ethyl acetate, inversion of cane sugar). (b) Time in which the concentration of a reactant falls to half its initial value.
