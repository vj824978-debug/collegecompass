Half-life (t1/2) of a first order reaction is 1386 s. The value of rate constant is : (A) 0 .5× 104 s−1 (B) 5 .0× 10−4 s−1 (C) 0 .5× 10−5 s−1 (D) 0 .5× 10−2 s−1
Answer
Answer as text
(B) k = 0.693/1386 = 5.0× 10−4 s−1.
