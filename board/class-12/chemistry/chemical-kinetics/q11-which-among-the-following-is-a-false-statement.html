Which among the following is a false statement?

CBSE 202556/2/1
Question 11 · Class 12 Chemistry · Chemical Kinetics
Question as text
Which among the following is a false statement? (A) Rate of zero order reaction is independent of initial concentration of reactant. (B) Half-life of a zero order reaction is inversely proportional to the rate constant. (C) Molecularity of a reaction may be zero. (D) For a first order reaction, t1/2 = 0.693/k.
Answer
Answer as text
(C) Molecularity is a whole number ≥ 1; it cannot be zero. (t1/2 = [R]0/2k for zero order, so (B) is true.)
