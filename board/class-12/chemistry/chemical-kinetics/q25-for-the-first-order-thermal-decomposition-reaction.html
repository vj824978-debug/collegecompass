Question 25 · Class 12 Chemistry · Chemical Kinetics
Question as text
For the first order thermal decomposition reaction, following data was obtained: C2H5Cl(g)−−→C2H4(g) + HCl(g) S. No. Time (s) Total Pressure (atm) 1 0 0.30 2 30 0.50 Calculate rate constant. [Given: log 3 = 0 .48]
Answer
Answer as text
Pt =P0 +p⇒p = 0.20 atm;PA =P0−p = 0.10 atm. k = 2.303 30 log 0.30 0.10 = 2.303× 0.48 30 ≈ 3.68× 10−2 s−1.
