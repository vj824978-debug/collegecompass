State a condition under which a bimolecular reaction is kinetically first order reaction.

CBSE 202556/7/12 marks
Question 44 · Class 12 Chemistry · Chemical Kinetics
Question as text
State a condition under which a bimolecular reaction is kinetically first order reaction. Give an example. For which type of reactions, do order and molecularity have the same value?
Answer
Answer as text
When one reactant is present in large excess, so its concentration stays practically constant (pseudo first order). Example: acid hydrolysis of ethyl acetate, CH3COOC2H5 + H2O H+ −−→CH3COOH + C2H5OH (or inversion of cane sugar), rate = k′[ester]. Order and molecularity are equal for elementary (single-step) reactions.
