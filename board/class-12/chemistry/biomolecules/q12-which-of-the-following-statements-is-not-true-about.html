Which of the following statements is not true about glucose?

CBSE 202556/1/1
Question 12 · Class 12 Chemistry · Biomolecules
Question as text
Which of the following statements is not true about glucose? (A) It is an aldohexose. (B) On heating with HI it forms n-hexane. (C) It exists in furanose form. (D) It does not give Schiff’s test.
Answer
Answer as text
(C) Glucose forms a six-membered (pyranose) ring; (D) is a true statement.
