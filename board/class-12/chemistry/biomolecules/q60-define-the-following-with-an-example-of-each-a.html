Question as text
(a) Define the following with an example of each: (a) Polysaccharides (b) Denatured protein (c) Essential amino acids OR (b) (a) Write the product when D-glucose reacts with conc. HNO 3. (b) Amino acids show amphoteric behaviour. Why? (c) Write one difference between α-helix and β-pleated structures of proteins.
Answer
Answer as text
(a) (a) Polysaccharides: carbohydrates giving a large number of monosaccharide units on hydrolysis (units joined by glycosidic links); e.g. starch, cellulose, glycogen. (b) Denatured protein: protein whose 2◦/3◦ structure is destroyed (H-bonds broken by heat, pH change) so that it loses biological activity; e.g. coagulation of egg white on boiling, curdling of milk. (c) Essential amino acids: those which cannot be synthesised in the body and must be supplied in the diet; e.g. valine, leucine, lysine. (b) (a) Saccharic (glucaric) acid HOOC–(CHOH) 4 –COOH. (b) Amino acids have both acidic (–COOH) and basic (–NH 2) groups and exist as zwitter ions H 3N+ –CHR–COO – , which react with both acids and bases. (c) α-helix: polypeptide chain coiled into a right-handed helix held by intramolecular H-bonds; β-pleated sheet: chains stretched and laid side by side, held by intermolecular H-bonds.
