On hydrolysis, which of the following carbohydrates gives only glucose?

CBSE 202656/3/1
Question 7 · Class 12 Chemistry · Biomolecules
Question as text
On hydrolysis, which of the following carbohydrates gives only glucose? (A) Sucrose (B) Galactose (C) Lactose (D) Maltose
Answer
Answer as text
(D) Maltose → 2 α-D-glucose; sucrose gives glucose + fructose, lactose gives glucose + galactose; galactose is a monosaccharide.
