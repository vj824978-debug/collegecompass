Question as text
Identify A and B in each of the following reaction sequence: (a) CH3CH2Cl NaCN− −−− →A H2/Ni − −−− →B (b) C6H5NH2 NaNO2/HCl −−−−−−−→0– –5 ◦C A C6H5NH2 −−−−−−→ H+ B
Answer
Answer as text
(a) A = CH 3CH2CN (propanenitrile), B = CH 3CH2CH2NH2 (propan-1-amine). (b) A = C 6H5N2+Cl– (benzenediazonium chloride), B = p-aminoazobenzene C6H5 –N ––N–C 6H4 –NH 2 (yellow dye).
