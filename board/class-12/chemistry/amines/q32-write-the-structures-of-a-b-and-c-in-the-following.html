Write the structures of A, B and C in the following reactions : (a) (b)
Answer
Answer as text
(a) A: acetanilide C 6H5NHCOCH3; B: p-bromoacetanilide; C: p-bromoaniline. (b) A: 3-bromo-4-methylaniline; B: 3-bromo-4-methylbenzenediazonium chloride; C: 2-bromotoluene (o-bromotoluene).
