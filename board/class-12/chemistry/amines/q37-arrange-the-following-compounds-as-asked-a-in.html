Question as text
Arrange the following compounds as asked : (a) in decreasing order of pKb values C2H5NH2, (C2H5)2NH, C6H5NHCH3, C6H5NH2 (b) increasing order of boiling point C2H5OH, C2H5NH2, (CH3)2NH (c) increasing order of solubility in water C6H5NH2, (C2H5)2NH, C2H5NH2
Answer
Answer as text
(a) pKb decreasing: C 6H5NH2 > C6H5NHCH3 > C2H5NH2 > (C2H5)2NH. (b) b.p. increasing: (CH 3)2NH < C2H5NH2 < C2H5OH. (c) Solubility increasing: C 6H5NH2 < (C2H5)2NH < C2H5NH2.
