How will you obtain the following from benzenediazonium chloride?

CBSE 202656/3/13 marks
Question 31 · Class 12 Chemistry · Amines
Question as text
How will you obtain the following from benzenediazonium chloride? Give chemical equations involved: [3×1=3] (a) Chlorobenzene (b) Benzene (c) Benzonitrile
Answer
Answer as text
(a) Sandmeyer: C 6H5N2+Cl– Cu2Cl2/HCl −−−−−−−→C6H5Cl + N2. (b) C6H5N2+Cl– + H3PO2 + H2O−−→C6H6 + N2 + H3PO3 + HCl (or ethanol). (c) C 6H5N2+Cl– CuCN/KCN −−−−−−−→C6H5CN + N2.
