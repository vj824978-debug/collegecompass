Which of the following amines has lowest pKb value?

CBSE 202656/1/1
Question 2 · Class 12 Chemistry · Amines
Question as text
Which of the following amines has lowest pKb value? (A) C 6H5 –N(CH 3)2 (B) C 6H5 –NH(CH 3) (C) C 6H5 –NH 2 (D)
Answer
Answer as text
(A) Lowest p Kb = strongest base: N,N-dimethylaniline (8.92) < N-methylaniline (9.30) < aniline (9.38); p-nitroaniline is weakest.
