Consider the following compounds : C2H5NH2, (C2H5)2NH, C6H5CH2NH2, NH3, C6H5NH2 The correct increasing order of the above compounds on the basis of their basic strength is : (A) C 6H5NH2 < NH3 < C6H5CH2NH2 < C2H5NH2 < (C2H5)2NH (B) NH 3 < C6H5NH2 < C6H5CH2NH2 < C2H5NH2 < (C2H5)2NH (C) C 6H5CH2NH2 < (C2H5)2NH < NH3 < C6H5NH2 < C2H5NH2 (D) C 2H5NH2 < C6H5NH2 < NH3 < C6H5CH2NH2 < (C2H5)2NH
Answer
Answer as text
(A) Aryl amine weakest; benzylamine > NH3; 2° > 1° ethylamines (aq).
