Which of the following reagent is used to distinguish between (C 2H5)2NH and (C 2H5)3N?

CBSE 202656/3/1
Question 5 · Class 12 Chemistry · Amines
Question as text
Which of the following reagent is used to distinguish between (C 2H5)2NH and (C 2H5)3N? (A) CHCl 3 + KOH (B) C 6H5SO2Cl (C) Conc. HCl + ZnCl 2 (D) NaOH + I 2
Answer
Answer as text
(B) Hinsberg’s reagent: 2 ◦ amine gives N,N-diethylbenzenesulphonamide (insoluble in alkali); 3◦ amine does not react.
