How will you obtain the following from aniline?

CBSE 202556/6/13 marks
Question 39 · Class 12 Chemistry · Amines
Question as text
How will you obtain the following from aniline? Give chemical equations only. (a) Sulphanilic acid (b) Phenylisocyanide (c) Acetanilide
Answer
Answer as text
(a) C6H5NH2 + H2SO4−−→C6H5NH3+HSO4 – 453-–473 K−−−−−−−→ p-H2NC6H4SO3H (sulphanilic acid). (b) C 6H5NH2 + CHCl3 + 3 KOH ∆−−→C6H5NC + 3 KCl + 3 H2O. (c) C 6H5NH2 + (CH3CO)2O pyridine −−−−−→C6H5NHCOCH3 + CH3COOH.
