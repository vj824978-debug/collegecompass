The IUPAC name for CH 3 –CH 2 –N(CH 3)–CH 2 –CH 2 –CH 3 is: (A) N-methylpentan-2-amine (B) N-ethyl-N-methylpropan-1-amine (C) N,N-diethylpropan-1-amine (D) N,N-dimethylpropan-1-amine
Answer
Answer as text
(B) Longest chain on N is propyl; ethyl and methyl are N-substituents.
