Question as text
(a) (a) Write the reactions involved in the following: (i) Hoffmann bromamide degradation reaction (ii) Diazotisation (iii) Gabriel phthalimide synthesis (b) Give reasons: (i) (CH3)2NH is more basic than (CH 3)3N in an aqueous solution. (ii) Aromatic diazonium salts are more stable than aliphatic diazonium salts. OR (b) (a) Write the structures of the main products of the following reactions: (i) (ii) (iii) (b) Give a simple chemical test to distinguish between aniline and N,N-dimethylaniline. (c) Arrange the following in the increasing order of their p Kb values: C6H5NH2, C2H5NH2, C6H5NHCH3
Answer
Answer as text
(a) (a)(i) RCONH2 + Br2 + 4 NaOH−−→RNH2 + Na2CO3 + 2 NaBr + 2 H2O. (ii) C 6H5NH2 + NaNO2 + 2 HCl 273–278 K−−−−−−→C6H5N2+Cl– + NaCl + 2 H2O. (iii) Phthalimide ethanolic KOH−−−−−−−−−→potassium phthalimide R–X− −− →N-alkylphthalimide NaOH(aq) −−−−−−→R–NH 2 + sodium phthalate. (b)(i) In water basicity depends on +I effect, solvation (H-bonding) of the ammonium ion and steric hindrance; (CH 3)2NH2+ is better hydrated than (CH3)3NH+, so (CH 3)2NH is more basic. (ii) In ArN 2+ the positive charge is delocalised over the benzene ring by resonance; no such stabilisation in aliphatic diazonium ions. (b) (a)(i) C 6H5NHCOCH3 (acetanilide). (ii) C 6H5SO2N(CH3)2 (N,N-dimethylbenzenesulphonamide). (iii) C 6H6 (benzene) + N 2 + HCl + CH3CHO. (b) Carbylamine test: aniline (1 ◦) with CHCl 3 + alcoholic KOH on heating gives foul-smelling phenyl isocyanide; N,N-dimethylaniline (3◦) does not (or Hinsberg’s reagent). (c) C 2H5NH2 < C6H5NHCH3 < C6H5NH2.
