Assertion (A): Fluorine forms only one oxoacid HOF.

CBSE 2022T erm IOut of current syllabus
Question 15 · Class 12 Chemistry · The p-Block Elements
Question as text
Assertion (A): Fluorine forms only one oxoacid HOF. Reason (R): Fluorine atom is highly electronegative. (A) Both A and R are true and R is the correct explanation of A. (B) Both A and R are true but R is not the correct explanation of A. (C) A is true but R is false. (D) A is false but R is true.
Answer
Answer as text
(A) High electronegativity (and small size, no d orbitals) of F allows only HOF; R explains A.
