Which of the following analogies is correct?

CBSE 2022T erm IOut of current syllabus
Question 16 · Class 12 Chemistry · The p-Block Elements
Question as text
Which of the following analogies is correct? (A) XeF 2: linear :: XeF 6: square planar (B) moist SO 2: Reducing agent :: Cl 2: bleaching agent (C) N 2: Highly reactive gas :: F 2: inert at room temperature (D) NH 3: strong base :: HI: weak acid
Answer
Answer as text
(B) Moist SO 2 reduces (nascent H), Cl 2 bleaches by oxidation. (XeF6 is distorted octahedral, N 2 is inert, F 2 reactive, NH3 weak base, HI strong acid.)
