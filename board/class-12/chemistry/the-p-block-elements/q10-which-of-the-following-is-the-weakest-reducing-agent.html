Which of the following is the weakest reducing agent in group 15?

Question 10 · Class 12 Chemistry · The p-Block Elements
Question as text
Which of the following is the weakest reducing agent in group 15? (A) NH 3 (B) PH 3 (C) AsH 3 (D) BiH 3
Answer
Answer as text
(A) E–H bond strength decreases down the group, so reducing power rises; NH3 is weakest.
