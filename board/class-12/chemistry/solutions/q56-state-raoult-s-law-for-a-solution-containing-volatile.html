State Raoult’s law for a solution containing volatile components.

CBSE 20192 marks
Question 56 · Class 12 Chemistry · Solutions
Question as text
State Raoult’s law for a solution containing volatile components. Write two characteristics of the solution which obey Raoult’s law at all concentrations.
Answer
Answer as text
For a solution of volatile liquids, the partial vapour pressure of each component is directly proportional to its mole fraction: pA =p◦ AxA, pB =p◦ BxB. Ideal solution: ∆ mixH = 0 and ∆ mixV = 0 (A–B interactions equal to A–A and B–B interactions).
