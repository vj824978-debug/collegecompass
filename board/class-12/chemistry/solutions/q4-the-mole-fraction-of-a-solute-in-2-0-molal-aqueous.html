The mole fraction of a solute in 2·0 molal aqueous solution is: (A) 1·87 (B) 0 ·347 (C) 0·0347 (D) 0 ·00347
Answer
Answer as text
(C) 2 mol solute per 1000 g (55.5 mol) water: x = 2/57.5≈ 0.0347.
