Which of the following formula represents Raoult’s law for a solution containing non-volatile solute?

CBSE 2022T erm I
Question 21 · Class 12 Chemistry · Solutions
Question as text
Which of the following formula represents Raoult’s law for a solution containing non-volatile solute? (A) psolute =p◦ solute·xsolute (B) p = KH·x (C) pTotal =psolvent (D) psolute =p◦ solvent·xsolvent
Answer
Answer as text
(C) Solute is non-volatile, so only the solvent contributes: pTotal =psolvent =p◦ solventxsolvent. (B) is Henry’s law; (D) wrongly writes psolute.
