Question 15 · Class 12 Physics · Atoms
Question as text
Assertion (A): An alpha particle is moving towards a gold nucleus. The impact parameter is maximum for the scattering angle of 180◦. Reason (R): The impact parameter in an alpha particle scattering experiment does not depend upon the atomic number of the target nucleus. (A) If both Assertion (A) and Reason (R) are true and Reason (R) is correct explanation of Assertion (A). (B) If both Assertion (A) and Reason (R) are true and Reason (R) is not the correct explanation of Assertion (A). (C) If Assertion (A) is true but Reason (R) is false. (D) If both Assertion (A) and Reason (R) are false.
Answer
Answer as text
(D) b = Ze2 cot(θ/2) 4πε0K : b = 0 (minimum) at θ = 180◦, and b∝Z. Both false.
