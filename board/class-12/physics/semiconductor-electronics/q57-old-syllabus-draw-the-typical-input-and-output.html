Question as text
[old syllabus] Draw the typical input and output characteristics of an n-p-n transistor in CE configuration. Show how these characteristics can be used to determine (a) the input resistance ( η), and (b) current amplification factor (β).
Answer
Answer as text
Diagram: input characteristic IB (µA) vs VBE at fixed VCE (rises sharply beyond≈ 0.7 V); output characteristicsIC (mA) vs VCE for several IB. (a) ri = ∆VBE ∆IB VCE from the slope of the input curve. (b) βac = ∆IC ∆IB VCE from the output curves at a fixed VCE . (The printed symbol ‘η’ is a misprint for ri.)
