Which of the following is an electrical conductor at room temperature?

CBSE 202555/4/1
Question 12 · Class 12 Physics · Semiconductor Electronics
Question as text
Which of the following is an electrical conductor at room temperature? (A) Sn (B) Mica (C) Si (D) C
Answer
Answer as text
(A) Tin (Sn) is metallic at room temperature; mica is an insulator; Si is a semiconductor; C (diamond) is an insulator.
