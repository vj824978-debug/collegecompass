Question 17 · Class 12 Physics · Current Electricity
Question as text
A heating element using nichrome is connected to a 220 V supply. Initially it draws a current of 2.9 A. After some time, the current attains a steady value of 2.5 A. Find the steady temperature of the heating element if the room temperature is 27 ◦C. The temperature coefficient of resistance of nichrome is 1.7× 10−4◦C−1.
Answer
Answer as text
R27 = 220/2.9, RT = 220/2.5; RT/R27 = 2.9/2.5 = 1.16 = 1 +α(T− 27); T− 27 = 0.16/(1.7× 10−4)≈ 941◦C; T≈ 968◦C.
