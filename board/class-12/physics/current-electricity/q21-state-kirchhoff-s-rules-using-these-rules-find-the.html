State Kirchhoff’s rules. Using these rules, find the current flowing through branch FC in the given circuit.
Answer
Answer as text
Junction rule: PI = 0 at a junction (charge conservation); loop rule:Pε =PIR round any closed loop (energy conservation). Taking node AFE at 0 V and node CD at V : top branch −5−I1(1) + 3− 3I1 =V , middle−2−I2(1) =V , bottom−4I3 =V , with I1 +I2 +I3 = 0 ⇒V =− 5 3 V, I1 =− 1 12 A, I2 =− 1 3 A, I3 = 5 12 A. Current in FC = 1 3 A ≈ 0.33 A, flowing from C to F (also 1/12 A from B to A in the top branch, 5/12 A from E to D).
