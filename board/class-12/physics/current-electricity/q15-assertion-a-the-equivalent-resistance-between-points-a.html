Assertion (A): The equivalent resistance between points A and B in the given network is 2R.

CBSE 202355/5/1
Question 15 · Class 12 Physics · Current Electricity
Question as text
Assertion (A): The equivalent resistance between points A and B in the given network is 2R. Reason (R): All the resistors are connected in parallel (A) Both Assertion (A) and Reason (R) are true and (R) is the correct explanation of (A). (B) Both Assertion (A) and Reason (R) are true and (R) is NOT the correct explanation of (A). (C) Assertion (A) is true and Reason (R) is false. (D) Assertion (A) is false and Reason (R) is also false.
Answer
Answer as text
(C) The network is a balanced Wheatstone bridge (all arms 2 R): RAB = 4R∥ 4R = 2R. The resistors are not all in parallel.
