State the basic principle behind the working of an ac generator.

CBSE 202355/5/13 marks
Question 33 · Class 12 Physics · Electromagnetic Induction
Question as text
State the basic principle behind the working of an ac generator. Briefly describe its working and obtain the expression for the instantaneous value of emf induced.
Answer
Answer as text
Principle: electromagnetic induction — a coil rotated in a uniform magnetic field has a changing flux linkage, inducing an emf. Working: armature coil (N turns, area A) rotated at ω between magnet poles; ends connected to slip rings with brushes feeding the external circuit; emf alternates each half rotation. Derivation: Φ = NBA cosωt, ε =−dΦ dt ⇒ε =NBAω sinωt =ε0 sinωt, ε0 =NBAω .
