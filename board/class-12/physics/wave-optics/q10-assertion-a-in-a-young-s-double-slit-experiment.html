Assertion (A): In a Young’s double-slit experiment, interference pattern is not observed when two coherent sources are infinitely close to each other. Reason (R): The fringe width is proportional to the separation between the two sources. (A) If both Assertion (A) and Reason (R) are true and Reason (R) is correct explanation of Assertion (A). (B) If both Assertion (A) and Reason (R) are true and Reason (R) is not the correct explanation of Assertion (A). (C) If Assertion (A) is true but Reason (R) is false. (D) If both Assertion (A) and Reason (R) are false.
Answer
Answer as text
(C) β =λD/d→∞ as d→ 0, so no pattern is seen (A true); β∝ 1/d, not∝d (R false).
