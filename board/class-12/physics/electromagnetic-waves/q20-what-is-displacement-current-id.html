What is displacement current ( id)?

CBSE 202655/5/13 marks
Question 20 · Class 12 Physics · Electromagnetic Waves
Question as text
What is displacement current ( id)? Considering the case of charging of a capacitor, show that id = ε0 dϕE dt . What is the value of id for a conductor across which a constant voltage is applied?
Answer
Answer as text
Displacement current is the current arising from a time-varying electric field (flux): id =ε0dϕE/dt. Derivation: between plates E =q/(ε0A), ϕE =EA =q/ε0, so ε0dϕE/dt =dq/dt =i, which continues the conduction current across the gap. For a constant voltage across a conductor, E is constant, so id = 0.
