Write the complete name of the diagnostic test for AIDS.

CBSE 2022Term II Outside Delhi Set 1Q73 marks
Question 36 · Class 12 Biology · Human Health and Disease
Question as text
(a) Write the complete name of the diagnostic test for AIDS. Explain the principle it works on. (b) Name the type of genetic material present in AIDS causing pathogen. [3]
Answer
Answer as text
(a) ELISA – Enzyme Linked Immuno-Sorbent Assay. Principle: antigen–antibody interaction; infection is detected by the presence of antigens or antibodies against the pathogen, using an enzyme-linked antibody that gives a colour reaction. (b) RNA (single-stranded RNA; HIV is a retrovirus).
