Which one of the following chromosomal event will not result in genetic variation amongst the offsprings?

CBSE 2024Delhi Set 3Q21 mark
Question 28 · Class 12 Biology · Principles of Inheritance and Variation
Question as text
Which one of the following chromosomal event will not result in genetic variation amongst the offsprings? [1] (A) Independent assortment (B) Crossing over (C) Linkage (D) Mutation
Answer
Answer as text
(C) Linkage (linked genes are inherited together and reduce new combinations).
