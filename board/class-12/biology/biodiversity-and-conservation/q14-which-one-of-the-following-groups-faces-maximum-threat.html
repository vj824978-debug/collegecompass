Which one of the following groups faces maximum threat of extinction?

CBSE 2023Delhi Set 2Q101 mark
Question 14 · Class 12 Biology · Biodiversity and Conservation
Question as text
Which one of the following groups faces maximum threat of extinction? [1] (A) Gymnosperms (B) Birds (C) Amphibian (D) Mammals
Answer
Answer as text
(C) Amphibian. (32% of amphibian species face threat of extinction, vs 31% gymnosperms, 23% mammals, 12% birds.)
