Name a distinguishing structure seen in a mature black pepper seed and not in a pea seed.

CBSE 2019Outside Delhi Set IIIQ92 marks
Question 51 · Class 12 Biology · Sexual Reproduction in Flowering Plants
Question as text
Name a distinguishing structure seen in a mature black pepper seed and not in a pea seed. State how does it develop.
Answer
Answer as text
Perisperm. It develops from the nucellus, which is not fully used up and persists as residual nucellus in the mature seed.
