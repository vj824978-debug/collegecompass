Which one of the following options shows the correct evolutionary order of the plants mentioned below?

CBSE 2025Outside Delhi Set 1Q51 mark
Question 3 · Class 12 Biology · Evolution
Question as text
Which one of the following options shows the correct evolutionary order of the plants mentioned below? (i) Ferns (ii) Ginkgo (iii) Zosterophyllum (iv) Gnetales Choose the correct option. (A) (i), (iii), (ii), (iv) (B) (iii), (i), (ii), (iv) (C) (i), (ii), (iii), (iv) (D) (iv), (ii), (i), (iii)
Answer
Answer as text
(B) (iii), (i), (ii), (iv): Zosterophyllum (early pteridophyte) → Ferns → Ginkgo → Gnetales.
