Write two differences between Homo erectus and Homo habilis.

CBSE 2019Delhi Set IQ173 marks
Question 24 · Class 12 Biology · Evolution
Question as text
(a) Write two differences between Homo erectus and Homo habilis. (b) Rearrange the following from early to late geologic periods: Carboniferous, Silurian, Jurassic. [3]
Answer
Answer as text
(a) Homo erectus: brain about 900 cc; probably ate meat (appeared about 1.5 mya). Homo habilis : brain 650–800 cc; probably did not eat meat (appeared about 2 mya). (b) [Out of the current syllabus.] Silurian → Carboniferous → Jurassic.
