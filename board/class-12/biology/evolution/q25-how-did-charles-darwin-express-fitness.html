How did Charles Darwin express ‘fitness’?

CBSE 2019Delhi Set IIQ21 mark
Question 25 · Class 12 Biology · Evolution
Question as text
How did Charles Darwin express ‘fitness’? [1]
Answer
Answer as text
Darwin expressed fitness as reproductive fitness: those better fit in an environment leave more progeny than others.
