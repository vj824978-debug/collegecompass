If the base adenine constitutes 31% of an isolated DNA fragment, then write what will be the expected percentage of the base cytosine in it. Explain how did you arrive at the answer given. [2]
Answer
Answer as text
Cytosine = 19%. By Chargaff’s rule A = T and G = C. A = 31% so T = 31%; A + T = 62%, so G + C = 38%, and C = 38/2 = 19%.
