Which of the chromosome in a human possesses the least number of genes?

CBSE 2024Outside Delhi Set 2Q111 mark
Question 28 · Class 12 Biology · Molecular Basis of Inheritance
Question as text
Which of the chromosome in a human possesses the least number of genes? [1] (A) 21st chromosome (B) 16 th chromosome (C) X–chromosome (D) Y–chromosome
Answer
Answer as text
(D) Y–chromosome (fewest genes, 231).
