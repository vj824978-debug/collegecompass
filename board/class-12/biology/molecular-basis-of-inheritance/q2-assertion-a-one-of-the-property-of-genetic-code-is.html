Assertion (A): One of the property of genetic code is degeneracy.

CBSE 2025Delhi Set 1Q141 mark
Question 2 · Class 12 Biology · Molecular Basis of Inheritance
Question as text
Assertion (A): One of the property of genetic code is degeneracy. Reason (R): Some amino acids can be coded by more than one codon. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(A) Both true; R is the correct explanation of A. Degeneracy means an amino acid is coded by more than one codon (e.g. leucine has six codons).
