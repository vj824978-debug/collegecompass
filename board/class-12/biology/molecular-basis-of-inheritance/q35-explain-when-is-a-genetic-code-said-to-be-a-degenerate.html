Explain when is a genetic code said to be (a) Degenerate (b) Universal

CBSE 2020Delhi Set 1Q72 marks
Question 35 · Class 12 Biology · Molecular Basis of Inheritance
Question as text
Explain when is a genetic code said to be (a) Degenerate (b) Universal [2]
Answer
Answer as text
(a) Degenerate: when an amino acid is coded by more than one codon (e.g. leucine by six codons). (b) Universal: when a codon codes for the same amino acid in all organisms (e.g. UUU codes for phenylalanine in bacteria and humans); few exceptions in mitochondria and some protozoans.
