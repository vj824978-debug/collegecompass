Write the contributions of the following scientists in deciphering the genetic code.

CBSE 2019Delhi Set IQ265 marks
Question 40 · Class 12 Biology · Molecular Basis of Inheritance
Question as text
(a) Write the contributions of the following scientists in deciphering the genetic code. George Gamow; Har Gobind Khorana; Marshall Nirenberg; Severo Ochoa. (b) State the importance of a Genetic code in protein biosynthesis. [4 + 1]
Answer
Answer as text
(a) George Gamow: proposed that the code is a triplet (3 bases code for one amino acid, since 43 = 64 combinations are needed for 20 amino acids). Har Gobind Khorana: chemically synthesised RNA molecules with defined base combinations (homopolymers and copolymers). Marshall Nirenberg: developed a cell-free system for protein synthesis that helped decipher the code. Severo Ochoa: discovered polynucleotide phosphorylase, which polymerises RNA with defined sequences in a template-independent manner. (b) The genetic code specifies which amino acid is placed at each position: the codon sequence of mRNA determines the amino acid sequence of the polypeptide.
