Write the palindromic nucleotide sequence EcoRI recognises.

CBSE 2020Delhi Set 3Q133 marks
Question 37 · Class 12 Biology · Biotechnology: Principles and Processes
Question as text
(a) Write the palindromic nucleotide sequence EcoRI recognises. (b) Draw the vector DNA and a foreign DNA showing the sites where EcoRI has acted to form the sticky ends. (c) Name the enzyme that helps in forming recombinant DNA.
Answer
Answer as text
(a) 5′-GAATTC-3′ 3′-CTTAAG-5′ (b) Diagram: vector DNA and foreign DNA each cut by EcoRI between G and A on both strands, showing the single-stranded AATT sticky ends (5′-G AATTC-3 ′ / 3′-CTTAA G-5 ′) on both, and their complementary ends pairing. (c) DNA ligase (joins the sticky ends of vector and foreign DNA). (Source key: restriction enzymes, DNA ligase and DNA-dependent DNA polymerase.)
