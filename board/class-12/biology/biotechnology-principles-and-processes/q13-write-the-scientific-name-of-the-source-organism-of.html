Write the scientific name of the source organism of the thermostable DNA polymerase used in PCR.

CBSE 2025Outside Delhi Set 3Q202 marks
Question 13 · Class 12 Biology · Biotechnology: Principles and Processes
Question as text
(a) Write the scientific name of the source organism of the thermostable DNA polymerase used in PCR. (b) State the advantage of using thermostable DNA polymerase.
Answer
Answer as text
(a) Thermus aquaticus . (b) It remains active at the high temperatures used for denaturation, so it does not need to be added again in every cycle and the reaction can be cycled repeatedly (automated).
