Name the first developed transgenic cow.

CBSE 2024Outside Delhi Set 3Q172 marks
Question 16 · Class 12 Biology · Biotechnology and its Applications
Question as text
(a) Name the first developed transgenic cow. (b) Explain the improvement in the quality of the milk produced by it. [2×1=2]
Answer
Answer as text
(a) Rosie (1997). (b) Its milk was human-protein-enriched (2.4 g per litre) and contained human α-lactalbumin, making it nutritionally more balanced for human babies than natural cow milk. (Source key adds that it raised essential amino acid levels; NCERT does not state this.)
