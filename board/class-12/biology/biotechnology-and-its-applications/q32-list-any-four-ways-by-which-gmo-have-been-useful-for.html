List any four ways by which GMO have been useful for enhanced crop output.

CBSE 2019Delhi Set IQ112 marks
Question 32 · Class 12 Biology · Biotechnology and its Applications
Question as text
List any four ways by which GMO have been useful for enhanced crop output. [2]
Answer
Answer as text
Any four: more tolerance to abiotic stresses (cold, drought, salt, heat); pest-resistant crops reducing reliance on chemical pesticides; reduced post-harvest losses; increased efficiency of mineral use by plants; enhanced nutritional value (e.g. vitamin A-enriched rice).
