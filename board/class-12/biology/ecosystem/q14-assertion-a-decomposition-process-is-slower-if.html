Assertion (A): Decomposition process is slower if detritus is rich in lignin and chitin.

CBSE 2023Delhi Set 1Q151 mark
Question 14 · Class 12 Biology · Ecosystem
Question as text
Assertion (A): Decomposition process is slower if detritus is rich in lignin and chitin. [1] Reason (R): Decomposition is largely an oxygen requiring process. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(B) Both (A) and (R) are true, but (R) is not the correct explanation of (A). Decomposition is slow for lignin/chitin-rich detritus because of its chemical nature; its need for oxygen does not explain this.
