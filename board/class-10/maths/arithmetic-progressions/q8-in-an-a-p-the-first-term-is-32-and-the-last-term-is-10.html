In an A.P., the first term is 32 and the last term is −10.

CBSE 2026QP 30/3/1Q222 marks
Question 8 · Class 10 Mathematics · Arithmetic Progressions
Question as text
(a) In an A.P., the first term is 32 and the last term is −10. If the common difference is −2, then find the number of terms and their sum. OR (b) Find the sum of the first 28 terms of an A.P. whose nth term is given by an = 3n− 2.
Answer
Answer as text
(a)−10 = 32 + ( n− 1)(−2)⇒ n = 22; S22 = 22 2 (32− 10) = 242. (b) a1 = 1, a28 = 82; S28 = 28 2 (1 + 82) = 1162.
