Pair of Linear Equations in Two Variables — Question 11 (CBSE 2025, 1 mark)

CBSE 2025QP 30/1/1Q21 mark
Question 11 · Class 10 Mathematics · Pair of Linear Equations in Two Variables
Question as text
If x = 1 and y = 2 is a solution of the pair of linear equations 2 x− 3y + a = 0 and 2 x + 3y− b = 0, then: (A) a = 2b (B) 2a = b (C) a + 2b = 0 (D) 2 a + b = 0
Answer
Answer as text
(B) 2a = b. 2 − 6 + a = 0⇒ a = 4; 2 + 6− b = 0⇒ b = 8.
