Question as text
Check whether the following pair of equations is consistent or not. If consistent, solve graphically x + 3y = 6 3y− 2x =−12
Answer
Answer as text
Write as x+3 y−6 = 0,−2x+3 y +12 = 0: a1 a2 =−1 2̸= b1 b2 = 1, so the lines intersect: consistent (unique solution). Points: x + 3y = 6: (0 , 2), (3, 1), (6, 0); 3y− 2x =−12: (0 ,−4), (3,−2), (6, 0). The lines meet at (6, 0): x = 6, y = 0.
