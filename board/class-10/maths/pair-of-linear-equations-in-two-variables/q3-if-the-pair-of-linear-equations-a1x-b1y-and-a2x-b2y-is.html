Pair of Linear Equations in Two Variables — Question 3 (CBSE 2026, 1 mark)

CBSE 2026QP 30/2/1Q61 mark
Question 3 · Class 10 Mathematics · Pair of Linear Equations in Two Variables
Question as text
If the pair of linear equations : a1x + b1y + c1 = 0 and a2x + b2y + c2 = 0 is consistent and dependent, then (A) a1 a2 ̸= b1 b2 (B) a1 a2 ̸= b1 b2 = c1 c2 (C) a1 a2 = b1 b2 ̸= c1 c2 (D) a1 a2 = b1 b2 = c1 c2
Answer
Answer as text
(D) a1 a2 = b1 b2 = c1 c2 .
