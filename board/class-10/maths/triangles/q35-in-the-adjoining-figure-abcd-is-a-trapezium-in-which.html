CBSE 2025QP 30/5/1Q91 mark
Question 35 · Class 10 Mathematics · Triangles
Question as text
In the adjoining figure, ABCD is a trapezium in which XY ∥ AB ∥ CD. If AX = 2 3AD, then CY :YB = (A) 2 : 3 (B) 3 : 2 (C) 1 : 3 (D) 1 : 2
Answer
Answer as text
(D) 1 : 2. DX :XA = 1 : 2 and the parallel lines cut AD and BC proportionally, so CY :YB = 1 : 2.
