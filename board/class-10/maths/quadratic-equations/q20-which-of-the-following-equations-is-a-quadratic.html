Quadratic Equations — Question 20 (CBSE 2025, 1 mark)

CBSE 2025QP 30/5/1Q41 mark
Question 20 · Class 10 Mathematics · Quadratic Equations
Question as text
Which of the following equations is a quadratic equation? (A) x2 + 1 = (x− 1)2 (B) (x +√x)2 = 2x√x (C) x3 + 3x2 = (x + 1)3 (D) (x + 1)(x− 1) = (x + 1)2
Answer
Answer as text
(B) (x +√x)2 = 2x√x: it simplifies to x2 + x = 0. (A), (C), (D) all reduce to linear equations.
