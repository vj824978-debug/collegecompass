CBSE 2025QP 30/6/1Q325 marks
Question 24 · Class 10 Mathematics · Quadratic Equations
Question as text
(a) There is a circular park of diameter 65 m as shown in the following figure, where AB is a diameter. An entry gate is to be constructed at a point P on the boundary of the park such that distance of P from A is 35 m more than the distance of P from B. Find distance of point P from A and B respectively. OR (b) Find the smallest value of p for which the quadratic equation x2− 2(p + 1)x + p2 = 0 has real roots. Hence, find the roots of the equation so obtained.
Answer
Answer as text
(a) ∠AP B = 90◦ (angle in a semicircle). Let P B = x, P A = x + 35: x2 + (x + 35)2 = 652⇒ x2 + 35x− 1500 = 0⇒ (x + 60)(x− 25) = 0⇒ x = 25. So PA = 60 m, PB = 25 m. (b) D = 4(p + 1)2− 4p2 = 4(2p + 1)≥ 0⇒ p≥− 1 2. Smallest p =− 1 2. Equation: x2− x + 1 4 = 0⇒ (x− 1 2)2 = 0, roots 1 2 , 1 2.
