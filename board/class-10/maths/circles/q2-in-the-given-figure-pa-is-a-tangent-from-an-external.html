Question as text
In the given figure, PA is a tangent from an external point P to a circle with centre O. If∠POB = 125◦, then ∠APO is equal to : (A) 25◦ (B) 65◦ (C) 90◦ (D) 35◦
Answer
Answer as text
(D) 35◦. ∠AOP = 180◦− 125◦ = 55◦, ∠OAP = 90◦, so ∠APO = 35◦.
