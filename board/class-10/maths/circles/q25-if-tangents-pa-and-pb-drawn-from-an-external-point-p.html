If tangents PA and PB drawn from an external point P to the circle with centre O are inclined to each other…

CBSE 2025QP 30/3/1Q81 mark
Question 25 · Class 10 Mathematics · Circles
Question as text
If tangents PA and PB drawn from an external point P to the circle with centre O are inclined to each other at an angle of 80◦ as shown in the given figure, then the measure of ∠POA is : (A) 40◦ (B) 50◦ (C) 60◦ (D) 80◦
Answer
Answer as text
(B) 50◦. ∠APO = 40◦, ∠OAP = 90◦, so ∠POA = 50◦.
