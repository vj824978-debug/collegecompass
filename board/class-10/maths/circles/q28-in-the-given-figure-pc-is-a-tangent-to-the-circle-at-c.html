CBSE 2025QP 30/3/1Q313 marks
Question 28 · Class 10 Mathematics · Circles
Question as text
In the given figure, PC is a tangent to the circle at C. AOB is the diameter which when extended meets the tangent at P. Find ∠CBA and ∠BCO , if ∠PCA = 110◦.
Answer
Answer as text
∠BCA = 90◦ (angle in a semicircle), so ∠PCB = 110◦− 90◦ = 20◦. ∠OCP = 90◦, so ∠BCO = 90◦− 20◦ = 70◦. OB =OC⇒ ∠CBA = ∠OBC = ∠BCO = 70◦. ∠CBA = 70◦, ∠BCO = 70◦.
