PQ is tangent to a circle with centre O.

CBSE 2026QP 30/4/1Q141 mark
Question 14 · Class 10 Mathematics · Circles
Question as text
PQ is tangent to a circle with centre O. If ∠POR = 65◦, then m∠PTR is (A) 65◦ (B) 58.5◦ (C) 57.5◦ (D) 45◦
Answer
Answer as text
(C) 57.5◦. ∠PSR = 1 2 ∠POR = 32.5◦; ∠SPT = 90◦ (tangent⊥ radius), so ∠PTR = 90◦−32.5◦ = 57.5◦.
