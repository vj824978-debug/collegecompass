Question 19 · Class 10 Mathematics · Circles
Question as text
In the given figure, PA is a tangent from an external point P to a circle with centre O. If ∠POB = 115◦, then ∠APO is equal to: (A) 25◦ (B) 65◦ (C) 90◦ (D) 35◦
Answer
Answer as text
(A) 25◦. ∠AOP = 180◦− 115◦ = 65◦, ∠OAP = 90◦, so ∠APO = 25◦.
