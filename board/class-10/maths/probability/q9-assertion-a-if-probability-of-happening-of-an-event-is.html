Assertion (A): If probability of happening of an event is 0 .2p, p > 0, then p can’t be more than 5.

CBSE 2026QP 30/4/1Q191 mark
Question 9 · Class 10 Mathematics · Probability
Question as text
Assertion (A): If probability of happening of an event is 0 .2p, p > 0, then p can’t be more than 5. Reason (R): P (E) = 1− P (E) for an event E. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(B). A is true since 0 .2p≤ 1⇒ p≤ 5 (because 0≤ P (E)≤ 1). R is true but does not explain A.
