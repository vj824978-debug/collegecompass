The number of red balls in a bag is three more than the number of black balls.

CBSE 2025QP 30/6/1Q252 marks
Question 32 · Class 10 Mathematics · Probability
Question as text
The number of red balls in a bag is three more than the number of black balls. If the probability of drawing a red ball at random from the given bag is 12 23, find the total number of balls in the given bag.
Answer
Answer as text
Black = x, red = x + 3, total = 2 x + 3. x + 3 2x + 3 = 12 23⇒ 23x + 69 = 24x + 36⇒ x = 33. Total = 69 balls.
