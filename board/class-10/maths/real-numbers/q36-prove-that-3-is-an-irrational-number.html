Prove that √ 3 is an irrational number.

CBSE 2025QP 30/5/1Q263 marks
Question 36 · Class 10 Mathematics · Real Numbers
Question as text
(a) Prove that √ 3 is an irrational number. OR (b) State true or false for each of the following statements and justify in each case: (i) 2× 3× 5× 7 + 7 is a composite number. (ii) 2× 3× 5× 7 + 1 is a composite number.
Answer
Answer as text
(a) Suppose √ 3 = a b ,a,b coprime integers,b̸= 0. Then a2 = 3b2, so 3 divides a2, hence 3 divides a; write a = 3c. Then 9c2 = 3b2⇒b2 = 3c2, so 3 divides b. So 3 is a common factor of a and b, a contradiction. Hence √ 3 is irrational. (b)(i) T rue: 2× 3× 5× 7 + 7 = 7(30 + 1) = 7× 31 = 217, which has factors other than 1 and itself. (ii) F alse: 2×3×5×7 + 1 = 211, which is prime (not divisible by 2, 3, 5, 7, 11, 13; 13< √ 211< 17).
