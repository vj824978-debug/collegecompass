Real Numbers — Question 28 (CBSE 2025, 3 marks)

CBSE 2025QP 30/3/1Q273 marks
Question 28 · Class 10 Mathematics · Real Numbers
Question as text
Prove that ( √ 3 + 2 ) is an irrational number given that √ 3 is an irrational number.
Answer
Answer as text
Suppose 5 √ 3 + 2 3 = r is rational. Then √ 3 = 3r− 2 15 , which is rational (rationals are closed under−,×,÷). This contradicts √ 3 being irrational. Hence 5 √ 3 + 2 3 is irrational.
