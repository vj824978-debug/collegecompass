Prove that √ 3 is an irrational number.

CBSE 2026QP 30/1/1Q263 marks
Question 4 · Class 10 Mathematics · Real Numbers
Question as text
Prove that √ 3 is an irrational number.
Answer
Answer as text
Suppose √ 3 = a b with a,b coprime integers, b̸= 0. Then a2 = 3b2, so 3 divides a2, hence 3 divides a; write a = 3c. Then 9c2 = 3b2⇒b2 = 3c2, so 3 divides b. Thus 3 is a common factor of a and b, a contradiction. Hence √ 3 is irrational.
