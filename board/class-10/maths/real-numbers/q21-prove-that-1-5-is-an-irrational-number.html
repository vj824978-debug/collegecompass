Prove that 1√ 5 is an irrational number.

CBSE 2025QP 30/1/1Q293 marks
Question 21 · Class 10 Mathematics · Real Numbers
Question as text
Prove that 1√ 5 is an irrational number.
Answer
Answer as text
First √ 5 is irrational: if √ 5 = a b (a,b coprime) thena2 = 5b2, so 5|a;a = 5c⇒b2 = 5c2⇒ 5|b, contradiction. Now if 1√ 5 = p q (rational, p̸= 0) then √ 5 = q p would be rational, contradiction. Hence 1√ 5 is irrational.
