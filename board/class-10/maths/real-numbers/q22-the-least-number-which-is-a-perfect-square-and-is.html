Real Numbers — Question 22 (CBSE 2025, 1 mark)

CBSE 2025QP 30/2/1Q41 mark
Question 22 · Class 10 Mathematics · Real Numbers
Question as text
The least number which is a perfect square and is divisible by each of 16, 20 and 50, is : (A) 1200 (B) 100 (C) 3600 (D) 2400
Answer
Answer as text
(C) 3600 (intended). Note: LCM(16, 20, 50) = 400 = 24·52 = 202 is itself a perfect square, so the true least number is 400, which is not among the options; of the options only 3600 is a perfect square divisible by 16, 20 and 50.
