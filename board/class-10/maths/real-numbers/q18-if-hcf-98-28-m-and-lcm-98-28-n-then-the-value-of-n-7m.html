CBSE 2025QP 30/1/1Q61 mark
Question 18 · Class 10 Mathematics · Real Numbers
Question as text
If HCF(98, 28) =m and LCM(98, 28) =n, then the value of n− 7m is: (A) 0 (B) 28 (C) 98 (D) 198
Answer
Answer as text
(C) 98. m = 14, n = 196; 196− 98 = 98.
