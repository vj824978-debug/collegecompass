Introduction to Trigonometry — Question 35 (CBSE 2025, 2 marks)

CBSE 2025QP 30/4/1Q242 marks
Question 35 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
(A) Find the value of x for which (sinA + cosecA)2 + (cosA + secA)2 =x + tan2A + cot2A OR (B) Evaluate the following: 3 sin 30◦− 4 sin3 30◦ 2 sin2 50◦ + 2 cos2 50◦
Answer
Answer as text
(A) LHS = sin 2A + cosec2A + 2 + cos2A + sec2A + 2 = 1 + 4 + (1 + cot2A) + (1 + tan2A) = 7 + tan2A + cot2A. So x = 7. (B) Numerator = 3· 1 2− 4· 1 8 = 1; denominator = 2(sin 2 50◦ + cos2 50◦) = 2. Value = 1 2.
