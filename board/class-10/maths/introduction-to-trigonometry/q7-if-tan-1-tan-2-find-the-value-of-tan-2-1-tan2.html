Introduction to Trigonometry — Question 7 (CBSE 2026, 2 marks)

CBSE 2026QP 30/2/1Q242 marks
Question 7 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
(a) If tanθ + 1 tanθ = 2, find the value of tan 2θ + 1 tan2θ. OR (b) Prove that : √ 1− sinθ 1 + sinθ = secθ− tanθ
Answer
Answer as text
(a) Squaring: tan 2θ + 1 tan2θ + 2 = 4⇒ tan2θ + 1 tan2θ = 2. (b) √ (1− sinθ)2 1− sin2θ = 1− sinθ cosθ = secθ− tanθ.
