Question as text
If 7 cos2θ + 3 sin2θ = 4, then the value of θ is : (A) 30◦ (B) 45◦ (C) 60◦ (D) 90◦
Answer
Answer as text
(C) 60◦. 3 + 4 cos 2θ = 4⇒ cos2θ = 1 4⇒ cosθ = 1 2.
