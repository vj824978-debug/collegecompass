If tanA = √ 3; where A is an acute angle, then find the value of sin2A 1 + cos2A.

CBSE 2025QP 30/2/1Q232 marks
Question 27 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
If tanA = √ 3; where A is an acute angle, then find the value of sin2A 1 + cos2A.
Answer
Answer as text
tanA = √ 3⇒A = 60◦, sin2A = 3 4, cos2A = 1 4. 3/4 1 + 1/4 = 3 5.
