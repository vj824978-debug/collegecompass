If x cos 60◦ +y cos 0◦ + sin 30◦− cot 45◦ = 5, then find the value of x + 2y.

CBSE 2025QP 30/1/1Q212 marks
Question 23 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
(a) If x cos 60◦ +y cos 0◦ + sin 30◦− cot 45◦ = 5, then find the value of x + 2y. OR (b) Evaluate: tan2 60◦ sin2 60◦ + cos2 30◦
Answer
Answer as text
(a) x 2 +y + 1 2− 1 = 5⇒ x 2 +y = 11 2 ⇒ x + 2y = 11. (b) 3 4 + 3 = 3 3/2 = 2.
