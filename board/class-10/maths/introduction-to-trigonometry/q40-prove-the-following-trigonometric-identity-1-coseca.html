Introduction to Trigonometry — Question 40 (CBSE 2025, 3 marks)

CBSE 2025QP 30/5/1Q303 marks
Question 40 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
(a) Prove the following trigonometric identity: 1 + cosecA cosecA = cos2A 1− sinA OR (b) Let 2A +B andA + 2B be acute angles such that sin(2A +B) = √ 2 and tan(A + 2B) = 1. Find the value of cot(4A− 7B).
Answer
Answer as text
(a) LHS = 1 + 1 sin A sin A = sinA + 1. RHS = 1− sin2A 1− sinA = (1− sinA)(1 + sinA) 1− sinA = 1 + sinA = LHS. (b) 2A +B = 60◦,A + 2B = 45◦. Adding: A +B = 35◦; subtracting: A−B = 15◦. So A = 25◦, B = 10◦. cot(4A− 7B) = cot(100◦− 70◦) = cot 30◦ = √ 3.
