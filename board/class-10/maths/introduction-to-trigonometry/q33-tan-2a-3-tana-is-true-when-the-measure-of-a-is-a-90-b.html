tan 2A = 3 tanA is true, when the measure of ∠A is: (A) 90◦ (B) 60◦ (C) 45◦ (D) 30◦
Answer
Answer as text
(D) 30◦. tan 60◦ = √ 3 = 3· 1√ 3 = 3 tan 30◦.
