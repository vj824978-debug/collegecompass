Assertion (A): tan 2θ is not defined at θ = 45◦.

CBSE 2026QP 30/3/1Q201 mark
Question 11 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
Assertion (A): tan 2θ is not defined at θ = 45◦. Reason (R): sin 90◦̸= cos 90◦. (A) Both Assertion (A) and Reason (R) are true and Reason (R) is the correct explanation of the Assertion (A). (B) Both Assertion (A) and Reason (R) are true, but Reason (R) is not the correct explanation of the Assertion (A). (C) Assertion (A) is true, but Reason (R) is false. (D) Assertion (A) is false, but Reason (R) is true.
Answer
Answer as text
(B). tan 90◦ is undefined because cos 90 ◦ = 0 (A true); sin 90 ◦ = 1̸= 0 = cos 90 ◦ is true but is not the reason.
