Which of the following statements is true?

CBSE 2025QP 30/4/1Q91 mark
Question 34 · Class 10 Mathematics · Introduction to Trigonometry
Question as text
Which of the following statements is true? (A) sin 20◦> sin 70◦ (B) sin 20◦> cos 20◦ (C) cos 20◦> cos 70◦ (D) tan 20◦> tan 70◦
Answer
Answer as text
(C) cos 20◦> cos 70◦ (cosine decreases from 0 ◦ to 90◦).
