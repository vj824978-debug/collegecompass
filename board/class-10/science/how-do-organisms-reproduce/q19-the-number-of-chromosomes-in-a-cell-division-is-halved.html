The number of chromosomes in a cell division is halved.

CBSE 2025QP 31/2/1Q101 mark
Question 19 · Class 10 Science · How do Organisms Reproduce?
Question as text
The number of chromosomes in a cell division is halved. This kind of cell division is observed in : (A) Only testis (B) Only ovary (C) Ovary and testis both (D) All cells of the body
Answer
Answer as text
(C) Ovary and testis both. Gametes (eggs and sperms) are formed in both by meiosis, which halves the chromosome number.
