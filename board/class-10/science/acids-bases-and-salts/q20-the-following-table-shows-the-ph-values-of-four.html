The following table shows the pH values of four solutions A, B, C and D on a pH scale : The solutions A, B, C and D respectively are of a (A) Strong acid, weak acid, neutral, strong base (B) Weak acid, neutral, weak base, strong base (C) Weak acid, neutral, strong base, weak base (D) Weak acid, neutral, strong base, strong acid
Answer
Answer as text
(D) Weak acid, neutral, strong base, strong acid. A (pH 5) weak acid, B (pH 7) neutral, C (pH 13) strong base, D (pH 3) strong(er) acid.
