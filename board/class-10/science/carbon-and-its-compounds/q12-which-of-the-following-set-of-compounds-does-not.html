Which of the following set of compounds does not belong to same homologous series ?

CBSE 2026QP 31/5/1Q181 mark
Question 12 · Class 10 Science · Carbon and its Compounds
Question as text
Which of the following set of compounds does not belong to same homologous series ? (A) CH4 and C4H10 (B) C2H6 and C3H8 (C) C3H8 and C5H12 (D) C4H8 and C5H12
Answer
Answer as text
(D) C4H8 is an alkene (C nH2n) while C 5H12 is an alkane (C nH2n+2).
