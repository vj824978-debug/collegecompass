A Hydrocarbon which does not belong to the same homologous series of carbon compounds is (A) C4H10 (B) C6H14 (C) C7H14 (D) C10H22
Answer
Answer as text
(C) C7H14. It fits C nH2n (alkene); the others fit C nH2n+2 (alkanes).
