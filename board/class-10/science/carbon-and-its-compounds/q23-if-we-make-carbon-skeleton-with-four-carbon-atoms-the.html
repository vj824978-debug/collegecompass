Question as text
If we make carbon skeleton with four carbon atoms, the two different possible skeletons will be (A) C C C C ; C C C C (B) C C C C; C C C C (C) C C C C; C C C C (D) C C C C; C C C C
Answer
Answer as text
(B). A straight chain (C–C–C–C) and a branched chain (a C attached to the middle C of C–C–C). In (A), (C) and (D) both skeletons are the same unbranched chain only drawn bent.
