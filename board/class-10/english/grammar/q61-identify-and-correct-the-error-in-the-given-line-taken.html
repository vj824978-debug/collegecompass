Identify and correct the error in the given line taken from a user manual of an ironing board.

CBSE 2025QP 2/3/1Q3(vii)1 mark
Question 61 · Class 10 English · Grammar
Question as text
Identify and correct the error in the given line taken from a user manual of an ironing board. Place the garment on the ironing board, smoothening out as many wrinkle as possible. Option No. Error Correction (A) on in (B) many any (C) wrinkle wrinkles (D) possible impossible
Answer
Answer as text
(C) wrinkle → wrinkles (‘many’ takes a plural noun)
