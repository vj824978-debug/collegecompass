Read the given sentence from a sales report.

CBSE 2026QP 2/5/1Q3(ii)1 mark
Question 110 · Class 10 English · Grammar
Question as text
Read the given sentence from a sales report. Identify the error and supply the correction in the given format: Being checked all the figures twice, she was sure there were no errors.
Answer
Answer as text
Error: Being Correction: Having (“Having checked all the figures twice, she was sure there were no errors.” — perfect participle for an action completed before the main action).
