Given, (A) n = 5, m_l = -1. (B) n = 3, l = 2, m_l = -1, m_s = +1/2. The maximum number of electron(s) in an atom that can have the quantum numbers as given in (A) and (B) respectively are:

  1. (1) 26 and 1
  2. (2) 4 and 1
  3. (3) 2 and 4
  4. (4) 8 and 1

Answer

Correct answer: Option 4

Solution

(A) n = 5 l = 0 m_l = 0 l = 1 m_l = -1, 0, 1 => 2 electrons l = 2 m_l = -2, -1, 0, 1, 2 => 2 electrons l = 3 m_l = -3, -2, -1, 0, 1, 2, 3 => 2 electrons l = 4 m_l = -4, -3, -2, -1, 0, 1, 2, 3, 4 => 2 electrons Total number of electrons = 8 (B) n = 3, l = 2, m_l = -1, m_s = +1/2 => only 1 electron is possible
