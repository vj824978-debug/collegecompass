Q.35 Which of the following reactions are disproportionation reactions? (A) Cu+ → Cu2+ + Cu (B) 3MnO4^2- + 4H+ → 2MnO4^- + MnO2 + 2H2O (C) 3KMnO4 → K2MnO4 + MnO2 + O2 (D) 2MnO4^- + 3Mn2+ + 2H2O → 5MnO2 + 4H+

  1. (1) (B), (C), (D)
  2. (2) (A), (D)
  3. (3) (A), (B)
  4. (4) (A), (B), (C)

Answer

Correct answer: Option 3

Solution

A disproportionation reaction is one where the same element is simultaneously oxidized and reduced. (A) Cu+ → Cu2+ + Cu: Cu+ is oxidized to Cu2+ and reduced to Cu0 - DISPROPORTIONATION. (B) 3MnO4^2- + 4H+ → 2MnO4^- + MnO2 + 2H2O: Mn goes from +6 to +7 (oxidation) and +6 to +4 (reduction) - DISPROPORTIONATION. (C) 3KMnO4 → K2MnO4 + MnO2 + O2: Mn goes from +7 to +6 (reduction) and O goes from -2 to 0 (oxidation), but not the same element - NOT disproportionation. (D) 2MnO4^- + 3Mn2+ + 2H2O → 5MnO2 + 4H+: Mn in MnO4^- is +7 going to +4 (reduction), Mn in Mn2+ goes to +4 (oxidation), but different oxidation states of same element - NOT disproportionation. Therefore (A) and (B) are disproportionation reactions.
