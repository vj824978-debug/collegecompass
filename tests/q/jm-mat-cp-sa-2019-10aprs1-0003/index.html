If alpha and beta are the roots of the quadratic equation, x^2 + x sin(theta) - 2 sin(theta) = 0, theta in [0, pi/2], then (alpha^12 + beta^12)/((alpha^(-12) + beta^(-12))*(alpha - beta)^24) is equal to:

  1. (1) 2^12/(sin(theta) - 8)^6
  2. (2) 2^6/(sin(theta) + 8)^12
  3. (3) 2^12/(sin(theta) + 8)^12
  4. (4) 2^12/(sin(theta) - 4)^12

Answer

Correct answer: Option 3

Solution

x^2 + x sin(theta) - 2 sin(theta) = 0 where alpha and beta are roots. By Vieta's formulas: alpha + beta = -sin(theta) alpha*beta = -2 sin(theta) Now, (alpha^12 + beta^12)/((alpha^(-12) + beta^(-12))*(alpha - beta)^24) = (alpha^12 + beta^12)/((1/alpha^12 + 1/beta^12)*(alpha - beta)^24) = (alpha^12 + beta^12)/((alpha^12 + beta^12)/(alpha*beta)^12 * (alpha - beta)^24) = (alpha*beta)^12/((alpha - beta)^24) = ((alpha*beta)^12)/((alpha - beta)^24) Note that (alpha - beta)^2 = (alpha + beta)^2 - 4*alpha*beta = (-sin(theta))^2 - 4*(-2 sin(theta)) = sin^2(theta) + 8 sin(theta) = sin(theta)(sin(theta) + 8) Therefore (alpha - beta)^24 = [(sin(theta)(sin(theta) + 8))]^12 = [sin(theta)]^12 * [sin(theta) + 8]^12 Also, (alpha*beta)^12 = (-2 sin(theta))^12 = 2^12 * sin^12(theta) Therefore: (alpha*beta)^12/((alpha - beta)^24) = (2^12 * sin^12(theta))/(sin^12(theta) * (sin(theta) + 8)^12) = 2^12/(sin(theta) + 8)^12
