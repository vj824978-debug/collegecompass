The current passing through a conducting loop in the form of equilateral triangle of side 4*sqrt(3) cm is 2A. The magnetic field at its centroid is alpha x 10^(-5) T. The value of alpha is ____. (Given: mu_0 = 4*pi x 10^(-7) SI units)

  1. (1) 2*sqrt(3)
  2. (2) sqrt(3)
  3. (3) 3*sqrt(3)
  4. (4) sqrt(3)/2

Answer

Correct answer: Option 3

Solution

For an equilateral triangle with side a = 4*sqrt(3) cm = 4*sqrt(3) x 10^(-2) m The distance from centroid to each side is d = a/(2*sqrt(3)) = (4*sqrt(3))/(2*sqrt(3)) = 2 cm = 2 x 10^(-2) m For an equilateral triangle, the centroid is equidistant from all three sides. Each side subtends equal angles at the centroid. The magnetic field at the centroid due to one side of the triangle is: B_side = (mu_0 * I)/(4*pi * d) * [sin(theta_1) + sin(theta_2)] where theta_1 and theta_2 are the angles subtended by the ends of the side at the perpendicular from centroid. For equilateral triangle, theta_1 = theta_2 = 60° B_side = (mu_0 * I)/(4*pi * d) * [sin(60°) + sin(60°)] Total magnetic field from all three sides: B = (mu_0)/(4*pi) * (1/d) * [sin(60°) + sin(60°)] x 3 B = 10^(-7) * (2)/(2 x 10^(-2)) * (sqrt(3)/2 + sqrt(3)/2) x 3 B = 10^(-7) * (2)/(2 x 10^(-2)) * (sqrt(3)) x 3 B = sqrt(3) x 10^(-5) x 3 B = 3*sqrt(3) x 10^(-5) T Therefore, alpha = 3*sqrt(3)
