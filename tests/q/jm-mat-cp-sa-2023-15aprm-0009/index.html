Let (a + bx + cx^2)^10 = sum from i=10 to 0 of p_i*x^i, where a, b, c ∈ N. If p_1 = 20 and p_2 = 210, then 2(a + b + c) is equal to

  1. (1) 6
  2. (2) 15
  3. (3) 12
  4. (4) 8

Answer

Correct answer: Option 3

Solution

General term: (10!)/(r_1! r_2! r_3!) * (a)^r_1 * (bx)^r_2 * (cx^2)^r_3. For coefficient of x: r_2 + 2r_3 = 1, giving r_1=9, r_2=1, r_3=0. Coefficient of x = (10!/9!1!0!) * a^9 * b = 10*a^9*b = 20, so a^9*b = 2, thus a=1, b=2. For coefficient of x^2: r_2 + 2r_3 = 2, giving two cases: (8,2,0) and (9,0,1). Sum = (10!/8!2!) * a^8*b^2 + (10!/9!1!) * a^9*c = 45*a^8*b^2 + 10*a^9*c = 210. With a=1, b=2: 45*4 + 10*c = 210, so 180 + 10*c = 210, thus c=3. Therefore 2(a+b+c) = 2(1+2+3) = 12.
