Consider the matrices: A = [[2, -5], [3, m]], B = [[20], [m]] and X = [[x], [y]]. Let the set of all m, for which the system of equations AX = B has a negative solution (i.e., x < 0 and y < 0), be the interval (a, b). Then 8∫[a to b]|A| dm is equal to ______.

Answer

Correct answer: 450

Solution

From AX = B: 2x - 5y = 20 and 3x + my = m. Solving: y = (2m - 60)/(2m + 15) and x = 25m/(2m + 15). For negative solution: y < 0 requires m ∈ (-15/2, 30) and x < 0 requires m ∈ (-15/2, 0). Combined: m ∈ (-15/2, 0). |A| = 2m + 15. Integral: 8∫[-15/2 to 0](2m + 15)dm = 8[m² + 15m][-15/2 to 0] = 8(0 - (-225/4 - 225/2)) = 8 × 225/4 = 450.
