The sum of the coefficients of three consecutive terms in the binomial expansion of (1 + x)^(n+2), which are in the ratio 1 : 3 : 5, is equal to

  1. (1) 92
  2. (2) 63
  3. (3) 41
  4. (4) 25

Answer

Correct answer: Option 2

Solution

Let the three consecutive terms be T_r, T_(r+1), T_(r+2). Given ratio 1:3:5. Using T_(r+1)/T_r = (n+2-r+1)/(r) = 3, we get n - 4r + 3 = 0 ... (1). Using T_(r+2)/T_(r+1) = (n+2-(r+1)+1)/(r+1) = 5/3, we get 3n - 8r + 1 = 0 ... (2). Solving (1) and (2): n = 5, r = 2. The coefficients are C(7,2) + C(7,3) + C(7,4) = 21 + 35 + 35 = 91. Wait, recalculating: 7 + 21 + 35 = 63.
