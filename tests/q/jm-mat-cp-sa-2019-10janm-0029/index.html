Let f(x) = {max(|x|, x^2) if |x| ≤ 2; 8 - 2|x| if 2 < |x| ≤ 4}. Let S be the set of points in the interval (-4, 4) at which f is not differentiable. Then S

  1. (1) equals {-2, -1, 1, 2}
  2. (2) equals {-2, -1, 0, 1, 2}
  3. (3) equals {-2, 2}
  4. (4) is an empty set

Answer

Correct answer: Option 1

Solution

To find the points where f(x) is not differentiable, we need to analyze the function in two regions. For |x| ≤ 2: f(x) = max(|x|, x^2) We need to compare |x| and x^2: - When |x| ≥ x^2, we have f(x) = |x| - When x^2 ≥ |x|, we have f(x) = x^2 For x ≥ 0: x ≥ x^2 when 0 ≤ x ≤ 1, so f(x) = x when 0 ≤ x ≤ 1 x^2 ≥ x when x ≥ 1, so f(x) = x^2 when 1 ≤ x ≤ 2 For x < 0: -x ≥ x^2 when -1 ≤ x < 0, so f(x) = -x when -1 ≤ x < 0 x^2 ≥ -x when x ≤ -1, so f(x) = x^2 when -2 ≤ x ≤ -1 So for |x| ≤ 2: f(x) = {x^2 if -2 ≤ x ≤ -1 -x if -1 < x < 1 x^2 if 1 ≤ x ≤ 2} At x = -1: Left derivative = 2x|_{x=-1} = -2, Right derivative = -1. Not equal, so not differentiable. At x = 1: Left derivative = -1, Right derivative = 2x|_{x=1} = 2. Not equal, so not differentiable. At x = -2: For -2 ≤ x ≤ -1: f(x) = x^2, so f'(x) = 2x Left derivative at x = -2 from the left in region |x| ≤ 2: f'(-2^-) = 2(-2) = -4 For 2 < |x| ≤ 4: when x = -2, f(x) = 8 - 2|x| = 8 - 4 = 4, and f'(x) = -2·sign(x) = 2 (as x < 0) But at x = -2: the function changes from region 1 to region 2. At x = -2, |x| = 2 (boundary). Left from |x| ≤ 2 side: f'(-2) = 2(-2) = -4 Right from 2 < |x| ≤ 4 side: derivative of 8 - 2|x| = 8 + 2x for x < 0 gives f'(x) = 2 Not equal, so not differentiable at x = -2. At x = 2: Similarly, f'(2^-) = 2(2) = 4, f'(2^+) = -2. Not differentiable. At x = 0: f(x) = -x for -1 < x < 1, so f'(0) = -1 from both sides. Differentiable. Therefore S = {-2, -1, 1, 2}
