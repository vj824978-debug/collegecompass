A triangle is formed by the tangents at the point (2, 2) on the curves y^2 = 2x and x^2 + y^2 = 4x, and the line x + y + 2 = 0. If r is the radius of its circumcircle, then r^2 is equal to ______.

Answer

Correct answer: 10

Solution

Tangent for y^2 = 2x at (2, 2) is L_1: 2y = x + 2 Tangent for x^2 + y^2 = 4x at (2, 2) is L_2: y = 2 L_3: x + y + 2 = 0 Finding vertices of the triangle: Intersection of L_1 and L_2: 2y = x + 2 and y = 2 x + 2 = 4, so x = 2 Point B = (2, 2) Intersection of L_2 and L_3: y = 2 and x + y + 2 = 0 x + 2 + 2 = 0, so x = -4 Point C = (-4, 2) Intersection of L_1 and L_3: 2y = x + 2 and x + y + 2 = 0 From second: x = -y - 2 2y = -y - 2 + 2 3y = 0, y = 0 x = -2 Point A = (-2, 0) Side lengths: a = |BC| = sqrt((2-(-4))^2 + (2-2)^2) = sqrt(36) = 6 b = |AC| = sqrt((-2-(-4))^2 + (0-2)^2) = sqrt(4 + 4) = sqrt(8) = 2sqrt(2) c = |AB| = sqrt((2-(-2))^2 + (2-0)^2) = sqrt(16 + 4) = sqrt(20) = 2sqrt(5) Area of triangle: Using vertices A(-2, 0), B(2, 2), C(-4, 2) Area = (1/2)|x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2)| = (1/2)|(-2)(2 - 2) + 2(2 - 0) + (-4)(0 - 2)| = (1/2)|0 + 4 + 8| = (1/2) × 12 = 6 Alternatively, base BC = 6, height from A to line y = 2 is |0 - 2| = 2 Area = (1/2) × 6 × 2 = 6 Radius of circumcircle using formula: R = (abc)/(4A) = (sqrt(20) × 6 × sqrt(8))/(4 × 6) = (2sqrt(5) × 6 × 2sqrt(2))/(24) = (24sqrt(10))/24 = sqrt(10) R^2 = 10
