For the system of linear equations x + y + z = 6 alpha*x + beta*y + 7z = 3 x + 2y + 3z = 14, which of the following is NOT true?

  1. (1) If alpha = beta and alpha ≠ 7, then the system has a unique solution
  2. (2) If alpha = beta = 7, then the system has no solution
  3. (3) There is a unique point (alpha, beta) on the line x + 2y + 18 = 0 for which the system has infinitely many solutions
  4. (4) For every point (alpha, beta) ≠ (7, 7) on the line x - 2y + 7 = 0, the system has infinitely many solutions

Answer

Correct answer: Option 4

Solution

The coefficient matrix is: Δ = |1 1 1 | |alpha beta 7 | |1 2 3 | Calculating the determinant by expanding along the first row: Δ = 1(3*beta - 14) - 1(3*alpha - 7) + 1(2*alpha - beta) = 3*beta - 14 - 3*alpha + 7 + 2*alpha - beta = 2*beta - alpha - 7 So, for alpha = beta ≠ 7, Δ ≠ 0, so unique solution. Statement (1) is TRUE. For alpha = beta = 7, equation (i) & (ii) represent 2 parallel planes so no solution. Statement (2) is TRUE. If alpha - 2*beta + 7 = 0, but (alpha, beta) ≠ (7, 7), then no solution (equations are inconsistent). Statement (4) is NOT TRUE. For the system to have infinitely many solutions, we need Δ = 0 and consistency: 2*beta - alpha - 7 = 0, which gives alpha = 2*beta - 7 or alpha + 2*y + 18 = 0 is NOT the correct line. Statement (3) needs verification and Statement (4) is the NOT true statement.
