Let the domain of the function f(x) = cos((4x+5)/(3x-7)) be [a, β] and the domain of g(x) = log₂(2 - 6log₂(2x+5)) be (γ, δ). Then |7(a + β) + 4(γ + δ)| is equal to ____.

Answer

Correct answer: 96

Solution

For f(x) = cos((4x+5)/(3x-7)), we need -1 ≤ (4x+5)/(3x-7) ≤ 1. Solving: (7x-2)/(3x-7) ≥ 0 and (x+12)/(3x-7) ≤ 0 gives x ∈ [-12, 2/7]. So a = -12, β = 2/7. For g(x) = log₂(2 - 6log₂(2x+5)), we need: 2x+5 > 0 and 2 - 6log₂(2x+5) > 0. From log₂(2x+5) < 1/3, we get (2x+5)^(1/3) < 27, so 2x+5 < 3, giving x < -1. Also 2x+5 > 0 gives x > -5/2. Thus x ∈ (-5/2, -1), so γ = -5/2, δ = -1. Therefore |7(-12 + 2/7) + 4(-5/2 + (-1))| = |7(-82/7) + 4(-7/2)| = |-82 - 14| = 96.
