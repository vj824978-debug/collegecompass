Two coherent monochromatic light beams of intensities I and 4I are superimposed. The difference between maximum and minimum possible intensities in the resulting beam is x I. The value of x is ____.

Answer

Correct answer: 8

Solution

For two coherent beams with intensities I₁ = I and I₂ = 4I: I_max = (sqrt(I) + sqrt(4I))^2 = (sqrt(I) + 2sqrt(I))^2 = (3sqrt(I))^2 = 9I I_min = (sqrt(4I) - sqrt(I))^2 = (2sqrt(I) - sqrt(I))^2 = (sqrt(I))^2 = I Difference = I_max - I_min = 9I - I = 8I Therefore, x = 8
