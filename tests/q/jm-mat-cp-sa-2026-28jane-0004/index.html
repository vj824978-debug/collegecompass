The probability distribution of a random variable X is given below: X: 4k, (30/7)k, (32/7)k, (34/7)k, (36/7)k, (38/7)k, (40/7)k, 6k P(X): 2/15, 1/15, 2/15, 1/5, 1/15, 2/15, 1/5, 1/15 If E(X) = 263/15, then P(X < 20) is equal to:

  1. (1) 3/5
  2. (2) 8/15
  3. (3) 11/15
  4. (4) 14/15

Answer

Correct answer: Option 3

Solution

E(X) = sum of X_i * P(X_i) = 526k/105 = 263/15 Solving: 526k/(15*7) = 263/15 526k/105 = 263/15 k = 7/2 With k = 7/2, the values of X are: X: 14, 15, 16, 17, 18, 19, 20, 21 P(X): 2/15, 1/15, 2/15, 1/5, 1/15, 2/15, 1/5, 1/15 P(X < 20) = 1 - P(X >= 20) = 1 - P(X = 20) - P(X = 21) = 1 - 1/5 - 1/15 = 1 - 3/15 - 1/15 = 1 - 4/15 = 11/15
