A organic compound has 42.1% carbon, 6.4% hydrogen and remainder is oxygen. If its molecular weight is 342, then its molecular formula is:

  1. (1) C11H18O12
  2. (2) C12H20O12
  3. (3) C14H20O10
  4. (4) C12H22O11

Answer

Correct answer: Option 4

Solution

First, find the empirical formula from percentages. Oxygen percentage = 100 - 42.1 - 6.4 = 51.5%. Convert to moles by dividing by atomic weights: C: 42.1/12 = 3.508, H: 6.4/1 = 6.4, O: 51.5/16 = 3.219. Divide by smallest (3.219): C: 1.09, H: 1.99, O: 1. This gives approximately CH2O as empirical formula with empirical mass = 12 + 2 + 16 = 30. n = 342/30 = 11.4 ≈ 11 for practical purposes, but checking option 4: C12H22O11 has mass = 12(12) + 22(1) + 11(16) = 144 + 22 + 176 = 342. Verify percentages: C = 144/342 = 42.1%, H = 22/342 = 6.4%, O = 176/342 = 51.5%. This matches perfectly.
