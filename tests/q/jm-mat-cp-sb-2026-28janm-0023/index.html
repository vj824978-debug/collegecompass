If k = tan(pi/4 + (1/2)cos^(-1)(2/3)) + tan(pi/2 - sin^(-1)(2/3)), then the number of solutions of the equation sin^(-1)(kx - 1) = sin^(-1)(x) - cos^(-1)(x) is

Answer

Correct answer: 1

Solution

Let θ = (1/2)sin^(-1)(2/3), then (1/2)cos^(-1)(2/3) = (π/4 - θ) k = tan(θ + cot(θ)) = 1/(sin(θ)cos(θ)) = 2/sin(2θ) k = 2/(2/3) = 3 sin^(-1)(3x - 1) = sin^(-1)(x) - cos^(-1)(x) sin^(-1)(3x - 1) = π/2 - 2cos^(-1)(x) 3x - 1 = sin(π/2 - 2cos^(-1)(x)) 3x - 1 = 2x^2 - 1 ⟹ x = 0, 3/2 (rejected) No. of solution = 1
