Let f : (0, 1) → ℝ be the function defined as f(x) = [4x](x - 1/4)(x - 1/2), where [x] denotes the greatest integer less than or equal to x. Then which of the following statements is/are true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) The function f is discontinuous exactly at one point in (0, 1)
  2. (B) There is exactly one point in (0, 1) at which the function f is continuous but NOT differentiable
  3. (C) The function f is NOT differentiable at more than three points in (0, 1)
  4. (D) The minimum value of the function f is -1/512

Answer

Correct answer: AB

Solution

f(x) = [4x](x - 1/4)²(x - 1/2) f(x) = { 0, 0 < x < 1/4 1(x - 1/4)²(x - 1/2), 1/4 ≤ x < 1/2 2(x - 1/4)²(x - 1/2), 1/2 ≤ x < 3/4 3(x - 1/4)²(x - 1/2), 3/4 ≤ x < 1 } f(3/4⁻) = -1/8; f(3/4⁺) = -3/16 so f(x) is discontinuous at x = 3/4. So, (A) option is correct f'(x) = { 0, 0 < x < 1/4 4(x - 1/4)² + 2(x - 1/4)(x - 1/2), 1/4 ≤ x < 1/2 4(x - 1/4)(x - 1/2) + 2(x - 1/4)², 1/2 ≤ x < 3/4 3(x - 1/4)² + 6(x - 1/4)(x - 1/2), 3/4 ≤ x < 1 } f'(1/4⁻) = 0, f'(1/4⁺) = 0 so differentiable at x = 1/4 f'(1/2⁻) = 1/16, f'(1/2⁺) = 2·1/16 - 1/8 so non-differentiable at x = 1/2. So, (B) option is correct f'(3/4⁻) = 4·1/2·1/4 + 2·1/4 = 1 f'(3/4⁺) = 3·1/16 + 6·1/4·x = 3/2 so non-differentiable at 3/4 ∴ f(x) is non-differentiable at 2 points in (0, 1). So, (C) option is incorrect [Graph showing curve with critical points at 1/4, 1/2, and 3/4] f(x) = (x - 1/4)²(x - 1/2), 1/4 ≤ x < 1/2 f'(x) = (x - 1/4)² + 2(x - 1/4)(x - 1/2) = (x - 1/4)[x - 1/4 + 2x - 1] = (x - 1/4)(3x - 5/4) [Sign diagram showing - and +] f_min = f(5/12) = (5/12 - 1/4)²(5/12 - 1/2) = -1/12 · 1/36 = -1/432. So, (D) option is wrong
