When the first electron gain enthalpy (Δ_eg H) of oxygen is –141 kJ/mol, its second electron gain enthalpy is:

  1. (1) a positive value
  2. (2) a more negative value than the first
  3. (3) almost the same as that of the first
  4. (4) negative, but less negative than the first

Answer

Correct answer: Option 1

Solution

Second electron gain enthalpy is always positive for every element due to repulsion between some charge. O(g) + 1e^- → e^-(g) ΔH_eg = –141 kJ/mol O^-(g) + 1e^- → O^2-(g) ΔH = ⊕ve The first electron is added to a neutral oxygen atom, which is relatively easy and releases energy (–141 kJ/mol). However, the second electron must be added to O^-(g), which already has a negative charge. The electron-electron repulsion between the incoming electron and the existing electrons in O^- makes it unfavorable to add another electron. Therefore, the second electron gain enthalpy is positive (endothermic process).
