A string 2.0 m long and fixed at its ends is driven by a 240 Hz vibrator. The string vibrates in its third harmonic mode. The speed of the wave and its fundamental frequency is:

  1. (1) 320 m/s, 80 Hz
  2. (2) 180 m/s, 120 Hz
  3. (3) 320 m/s, 120 Hz
  4. (4) 180 m/s, 80 Hz

Answer

Correct answer: Option 1

Solution

For a string fixed at both ends vibrating in the nth harmonic mode: Given: - Length of string: L = 2.0 m - Vibrator frequency: f_n = 240 Hz - Mode: n = 3 (third harmonic) For the third harmonic mode: 3V/(2L) = 240 where V is the wave velocity. Solving for V: V/(2L) = 240/3 = 80 Hz (this is the fundamental frequency f_1) Therefore: V/(2 × 2) = 80 V/4 = 80 V = 320 m/s The fundamental frequency is: f_1 = V/(2L) = 320/(2 × 2) = 320/4 = 80 Hz Alternatively, for nth harmonic: f_n = n × f_1 240 = 3 × f_1 f_1 = 80 Hz And from f_1 = V/(2L): 80 = V/4 V = 320 m/s
