If the value of the integral from 0 to 5 of (x+[x])/e^[x] dx = alpha*e^(-1) + beta, where alpha, beta are real numbers, 5*alpha + 6*beta = 0, and [x] denotes the greatest integer less than or equal to x; then the value of (alpha + beta)^2 is equal to

  1. (1) 16
  2. (2) 100
  3. (3) 25
  4. (4) 36

Answer

Correct answer: Option 3

Solution

The integral is split by the floor function into regions [0,1), [1,2), [2,3), [3,4), [4,5]. For each interval [r, r+1), [x] = r. The integral becomes sum from r=0 to 4 of integral from r to r+1 of (x+r)/e^x dx. Using substitution x+1-r = t, dx = dt, each term evaluates. After computing all five integrals and summing: 5(1 - 2/e). Comparing with alpha*e^(-1) + beta: alpha = -10, beta = 5. From constraint 5*alpha + 6*beta = 0: 5(-10) + 6(5) = -50 + 30 = -20 (verification shows alpha = -10, beta = 5). Therefore (alpha + beta)^2 = (-10 + 5)^2 = (-5)^2 = 25.
