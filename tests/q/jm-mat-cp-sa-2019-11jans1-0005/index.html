Let z be a complex number such that |z| + z = 3 + i (where i = sqrt(-1)). Then |z| is equal to

  1. (1) sqrt(34)/3
  2. (2) 5/3
  3. (3) 5/4
  4. (4) sqrt(41)/4

Answer

Correct answer: Option 2

Solution

|z| + z = 3 + i Let z = x + iy => sqrt(x^2 + y^2) + x + iy = 3 + i => (x + sqrt(x^2 + y^2)) + iy = 3 + i Comparing real and imaginary parts: y = 1 x + sqrt(x^2 + y^2) = 3 Substituting y = 1: x + sqrt(1 + x^2) = 3 sqrt(1 + x^2) = 3 - x Squaring both sides: 1 + x^2 = 9 + x^2 - 6x 1 = 9 - 6x 6x = 8 x = 4/3 |z| = sqrt(x^2 + y^2) = sqrt((4/3)^2 + 1^2) = sqrt(16/9 + 1) = sqrt(16/9 + 9/9) = sqrt(25/9) = 5/3
