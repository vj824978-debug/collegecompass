If the tangent to the curve, y = f(x) = xlog_e(x), (x > 0) at a point (c, f(c)) is parallel to the line-segment joining the points (1, 0) and (e, e), then c is equal to:

  1. (1) 1/(e-1)
  2. (2) e^(1/(1-e))
  3. (3) e^(1/(e-1))
  4. (4) (e-1)/e

Answer

Correct answer: Option 3

Solution

f(x) = xlog_e(x) The slope of the line segment joining points (1, 0) and (e, e) is: slope = (e - 0)/(e - 1) = e/(e - 1) Since the tangent at (c, f(c)) is parallel to this line segment, the slope of the tangent must equal this slope: f'(x)|_(c,f(c)) = e/(e - 1) Find the derivative: f'(x) = d/dx(xlog_e(x)) = log_e(x) + x · (1/x) = log_e(x) + 1 At x = c: f'(c) = 1 + log_e(c) = e/(e - 1) Solve for c: log_e(c) = e/(e - 1) - 1 log_e(c) = e/(e - 1) - (e - 1)/(e - 1) log_e(c) = (e - (e - 1))/(e - 1) log_e(c) = 1/(e - 1) Therefore: c = e^(1/(e-1))
