The shortest distance between the lines x + 1 = 2y = -12z and x = y + 2 = 6z - 6 is

  1. (1) 2
  2. (2) 3/2
  3. (3) 3
  4. (4) 5/2

Answer

Correct answer: Option 1

Solution

L1: (x+1)/1 = y/(1/2) = z/(-1/12) L2: x/1 = (y+2)/1 = (z-1)/1 For L1: direction vector d1 = (1, 1/2, -1/12) or proportionally (12, 6, -1) Point on L1: P1 = (-1, 0, 0) For L2: direction vector d2 = (1, 1, 1) Point on L2: P2 = (0, -2, 1) Vector P1P2 = (0-(-1), -2-0, 1-0) = (1, -2, 1) S.D = |(-i + 2j - k)·(2i - 3j + 6k)|/|(-i + 2j - k) × (2i - 3j + 6k)| Numerator: |(-1)(2) + (2)(-3) + (-1)(6)| = |-2 - 6 - 6| = |-14| = 14 For denominator, compute cross product: (-i + 2j - k) × (2i - 3j + 6k) = |i j k| |-1 2 -1| |2 -3 6| = i(2·6 - (-1)(-3)) - j((-1)·6 - (-1)·2) + k((-1)(-3) - 2·2) = i(12 - 3) - j(-6 + 2) + k(3 - 4) = 9i + 4j - k |cross product| = sqrt(81 + 16 + 1) = sqrt(98) = 7sqrt(2) S.D = 14/(7sqrt(2)) = 2/sqrt(2) = sqrt(2)... Alternatively using formula given: S.D = |-2 - 6 - 6|/7 = |-14|/7 = 2 units
