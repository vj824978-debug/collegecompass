The value of the integral from -π/2 to π/2 of dx / ((1 + e^x)(sin^6 x + cos^6 x)) is equal to

  1. (1) 2π
  2. (2) 0
  3. (3) π
  4. (4) π/2

Answer

Correct answer: Option 3

Solution

Let I = integral from -π/2 to π/2 of dx / ((1 + e^x)(sin^6 x + cos^6 x)). Using the property f(x) + f(-x) for the integrand, we split into two parts. After simplification using sin^6 x + cos^6 x = 1 - (3/4)sin^2(2x), we get 2I = integral from -π/2 to π/2 of dx / (sin^6 x + cos^6 x). Converting to 2I = integral from 0 to π/2 of 4sec^2(2x)dx / (4 + tan^2(2x)). Using substitution t = tan(2x), dt = 2sec^2(2x)dx, the integral becomes 2 * integral from 0 to infinity of 2dt / (4 + t^2) = 2 * [tan^(-1)(t/2)] from 0 to infinity = 2 * π/2 = π. Therefore I = π.
