If A = [2 3; 3 5], then the determinant of the matrix (A^2025 - 3A^2024 + A^2023) is

  1. (1) 28
  2. (2) 12
  3. (3) 24
  4. (4) 16

Answer

Correct answer: Option 4

Solution

A = [2 3; 3 5] A^2 = [13 21; 21 34] |A^2025 - 3A^2024 + A^2023| = |A^2023(A^2 - 3A + I)| = |A^2023| |A^2 - 3A + I| A^2 - 3A + I = [13 21; 21 34] - 3[2 3; 3 5] + [1 0; 0 1] = [13 21; 21 34] - [6 9; 9 15] + [1 0; 0 1] = [13 - 6 + 1, 21 - 9 + 0; 21 - 9 + 0, 34 - 15 + 1] = [8 12; 12 16] |A^2 - 3A + I| = |[8 12; 12 16]| = 8(16) - 12(12) = 128 - 144 = -16 |A| = 2(5) - 3(3) = 10 - 9 = 1 |A^2023| = |A|^2023 = 1^2023 = 1 |A^2025 - 3A^2024 + A^2023| = |A^2023| |A^2 - 3A + I| = 1 × |-16| = 16
