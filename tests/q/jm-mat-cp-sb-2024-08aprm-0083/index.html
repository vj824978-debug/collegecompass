Three balls are drawn at random from a bag containing 5 blue and 4 yellow balls. Let the random variables X and Y respectively denote the number of blue and Yellow balls. If X̄ and Ȳ are the means of X and Y respectively, then 7X̄ + 4Ȳ is equal to ___.

Answer

Correct answer: 17

Solution

Total balls = 9, drawing 3 balls. X = number of blue balls, Y = number of yellow balls. X + Y = 3. Calculate E(X) = 7X̄ using probability distribution: P(X=0) = C(5,0)C(4,3)/C(9,3) = 4/84, P(X=1) = C(5,1)C(4,2)/C(9,3) = 40/84, P(X=2) = C(5,2)C(4,1)/C(9,3) = 40/84, P(X=3) = C(5,3)C(4,0)/C(9,3) = 10/84. E(X) = (0×4 + 1×40 + 2×40 + 3×10)/84 = 140/84 = 5/3. So 7X̄ = 35/3. Similarly, E(Y) = 4/3, so 4Ȳ = 16/3. Therefore 7X̄ + 4Ȳ = 35/3 + 16/3 = 51/3 = 17.
