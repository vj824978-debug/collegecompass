If the equation of plane passing through the mirror image of a point (2,3,1) with respect to line (x+1)/2 = (y-3)/1 = (z+8)/(-1) and containing the line (x-2)/3 = (1-y)/2 = (z+1)/1 is, ax + by + cz = 24 then a + b + c is equal to:

  1. (1) 20
  2. (2) 19
  3. (3) 18
  4. (4) 21

Answer

Correct answer: Option 2

Solution

First find mirror image P' of point (2,3,1) with respect to given line. The line has direction ratios (2,1,-1). Using reflection formula, the foot of perpendicular O is at (0, 7/2, -5/2). Mirror image P' = (-2, 4, -6). The required plane contains line (x-2)/3 = (1-y)/2 = (z+1)/1 which passes through (-2, 4, -6) and has direction (3, -2, 1). Plane equation: a(x-2) + b(y-1) + c(z+1) = 0. Using point (-2, 4, -6) and direction perpendicularity conditions: -4a + 3b + 5c = 0 and 3a - 2b + c = 0. Solving: a/7 = b/11 = c/1. From ax + by + cz = 24: 7x + 11y + z = 24. Therefore a = 7, b = 11, c = 1, so a + b + c = 19.
