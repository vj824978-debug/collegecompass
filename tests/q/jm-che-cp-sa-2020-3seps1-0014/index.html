The antifertility drug "Novestrol" can react with

  1. (1) Br2/water ; ZnCl2/HCl ; FeCl3
  2. (2) Alcoholic HCN ; NaOCl ; ZnCl2/HCl
  3. (3) ZnCl2/HCl ; FeCl3 ; Alcoholic HCN
  4. (4) Br2/water ; ZnCl2/HCl ; NaOCl

Answer

Correct answer: Option 1

Solution

Ethynylestradiol (novestrol) contains the following functional groups: 1. A phenolic OH group on the benzene ring 2. An alkyne (C ≡ CH) group in the side chain 3. Secondary alcohols in the steroid structure Let us analyze each reaction: (1) Br2/water ; ZnCl2/HCl ; FeCl3 - Br2/water: Reacts with the alkyne (C ≡ CH) and the phenolic OH group (addition and substitution) - ZnCl2/HCl: Lucas test - reacts with alcohols to form alkyl chlorides - FeCl3: Ferric chloride test - gives purple/violet color with phenolic OH group This combination detects all three functional groups. ✓ (2) Alcoholic HCN ; NaOCl ; ZnCl2/HCl - Alcoholic HCN: Reacts with carbonyl groups (not present in significant amounts) - NaOCl: Oxidizes alcohols and phenols - ZnCl2/HCl: Lucas test for alcohols No detection of alkyne. ✗ (3) ZnCl2/HCl ; FeCl3 ; Alcoholic HCN - ZnCl2/HCl: Lucas test for alcohols - FeCl3: Test for phenols - Alcoholic HCN: No reaction with the functional groups present Does not detect alkyne effectively. ✗ (4) Br2/water ; ZnCl2/HCl ; NaOCl - Br2/water: Reacts with alkyne and phenol - ZnCl2/HCl: Lucas test for alcohols - NaOCl: Oxidizing agent, not a specific functional group test Lacks the specific phenolic test (FeCl3). ✗ The correct answer is [1] because it provides the three specific tests: - Br2/water for alkyne and phenol reactivity - ZnCl2/HCl for alcohol functional groups - FeCl3 for phenolic OH confirmation
