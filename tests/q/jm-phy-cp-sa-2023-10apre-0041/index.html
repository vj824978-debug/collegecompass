The ratio of intensities at two points P and Q on the screen in a Young's double slit experiment where phase difference between two waves of same amplitude are π/3 and π/2, respectively are -

  1. (1) 2:3
  2. (2) 1:3
  3. (3) 3:1
  4. (4) 3:2

Answer

Correct answer: Option 4

Solution

Using I = 4I₀ cos²(φ/2) for intensity in Young's double slit experiment. At point P: phase difference φ₁ = π/3, so I₁ = 4I₀ cos²(π/6) = 4I₀ × (√3/2)² = 4I₀ × (3/4) = 3I₀ At point Q: phase difference φ₂ = π/2, so I₂ = 4I₀ cos²(π/4) = 4I₀ × (1/√2)² = 4I₀ × (1/2) = 2I₀ Ratio I₁/I₂ = 3I₀/2I₀ = 3/2 = 3:2
