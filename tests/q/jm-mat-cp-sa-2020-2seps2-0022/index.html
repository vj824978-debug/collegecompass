If y = sum from k=1 to 6 of {k cos^(-1)(3/5 cos(kx) - 4/5 sin(kx))}, then dy/dx at x = 0 is ________.

Answer

Correct answer: 91

Solution

Put cos(alpha) = 3/5, sin(alpha) = 4/5, 0 < alpha < pi/2 Now 3/5 cos(kx) - 4/5 sin(kx) = cos(alpha) * cos(kx) - sin(alpha) * sin(kx) = cos(alpha + kx) As we have to find derivative at x = 0 We have cos^(-1)(cos(alpha + kx)) = (alpha + kx) => y = sum from k=1 to 6 of (alpha + kx) => dy/dx|_(at x=0) = sum from k=1 to 6 of k = (6 × 7 × 13)/6 = 91
