In the above conversion of compound (X) to product (Y), the sequence of reagents to be used will be (1) (i) Fe, H+ (ii) Br2(aq) (iii) HNO2 (iv) CuBr (2) (i) Br2(aq), (ii) LiAlH4 (iii) H2O+ (3) (i) Fe, H+ (ii) Br2(aq) (iii) HNO2 (iv) H3PO2 (4) (i) Br2, Fe (ii) Fe, H+ (iii) LiAlH4

  1. (1) (i) Fe, H+ (ii) Br2(aq) (iii) HNO2 (iv) CuBr
  2. (2) (i) Br2(aq), (ii) LiAlH4 (iii) H2O+
  3. (3) (i) Fe, H+ (ii) Br2(aq) (iii) HNO2 (iv) H3PO2
  4. (4) (i) Br2, Fe (ii) Fe, H+ (iii) LiAlH4

Answer

Correct answer: Option 3

Solution

To convert nitrobenzene (X) to 1,3,5-tribromobenzene (Y): Step 1: Reduce NO2 to NH2 using Fe and H+ (acidic reduction) nitrobenzene + Fe, H+ → aniline (C6H5NH2) Step 2: Brominate the aniline using Br2(aq) The amino group is a strong ortho/para directing group, but in acidic conditions (from step 1), we get the anilinium ion which is meta-directing when we protonate it. However, the bromination proceeds and multiple brominations can occur. aniline + Br2(aq) → dibrominated product Step 3: Convert amino group to diazonium ion using HNO2 Dibrominated aniline + HNO2 → diazonium salt Step 4: Replace diazonium with H using H3PO2 (hypophosphorous acid) This is a classic method for removing the diazonium group and replacing it with hydrogen. Diazonium salt + H3PO2 → final product (1,3,5-tribromobenzene) The sequence (i) Fe, H+ (ii) Br2(aq) (iii) HNO2 (iv) H3PO2 is the correct sequence. Note: Option (1) uses CuBr in the last step, which would replace the diazonium with Br (not H). Option (4) uses LiAlH4 which is a strong reducing agent and would reduce multiple functional groups. Option (2) doesn't include the proper reduction-bromination sequence.
