The number of different 5 digit numbers greater than 50000 that can be formed using the digits 0, 1, 2, 3, 4, 5, 6, 7, such that the sum of their first and last digits should not be more than 8, is

  1. (1) 4608
  2. (2) 5720
  3. (3) 5719
  4. (4) 4607

Answer

Correct answer: Option 4

Solution

Case I: 5 _ _ _ 0 First digit = 5, Last digit = 0, sum = 5 + 0 = 5 ≤ 8 ✓ Middle 3 digits can be filled from {0, 1, 2, 3, 4, 5, 6, 7} with repetition allowed Number of ways = 8 × 8 × 8 = 512 Case II: 5 _ _ _ 1 First digit = 5, Last digit = 1, sum = 5 + 1 = 6 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case III: 5 _ _ _ 2 First digit = 5, Last digit = 2, sum = 5 + 2 = 7 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case IV: 5 _ _ _ 3 First digit = 5, Last digit = 3, sum = 5 + 3 = 8 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case V: 6 _ _ _ 0 First digit = 6, Last digit = 0, sum = 6 + 0 = 6 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case VI: 6 _ _ _ 1 First digit = 6, Last digit = 1, sum = 6 + 1 = 7 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case VII: 6 _ _ _ 2 First digit = 6, Last digit = 2, sum = 6 + 2 = 8 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case VIII: 7 _ _ _ 0 First digit = 7, Last digit = 0, sum = 7 + 0 = 7 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Case IX: 7 _ _ _ 1 First digit = 7, Last digit = 1, sum = 7 + 1 = 8 ≤ 8 ✓ Number of ways = 8 × 8 × 8 = 512 Total = 9 × (8 × 8 × 8) = 9 × 512 = 4608 But 50000 is not included in the valid numbers (it would be case 5 _ _ _ 0 but we need numbers greater than 50000, not equal to 50000). However, the number 50000 itself is not formed by our digits since we use {0,1,2,3,4,5,6,7}. Actually, we need to subtract 1 for the case where the number equals exactly 50000 if it was counted, but since we're counting numbers greater than 50000 and our structure starts with 5 or higher, we have: Total numbers = 4608 - 1 = 4607
