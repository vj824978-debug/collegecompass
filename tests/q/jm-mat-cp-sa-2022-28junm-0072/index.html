The number of real solutions of x^7 + 5x^3 + 3x + 1 = 0 is equal to ______.

  1. (1) 0
  2. (2) 1
  3. (3) 3
  4. (4) 5

Answer

Correct answer: Option 1

Solution

Let f(x) = x^7 + 5x^3 + 3x + 1. Taking derivative: f'(x) = 7x^6 + 15x^2 + 3. Since 7x^6 >= 0, 15x^2 >= 0, and 3 > 0 for all x in R, we have f'(x) > 0 for all x in R. This means f(x) is strictly increasing (always increasing) on R. A strictly monotonic function can intersect the x-axis at most at one point. Since f(0) = 1 > 0 and f(x) → -∞ as x → -∞, by the Intermediate Value Theorem, f(x) = 0 has exactly one real solution.
