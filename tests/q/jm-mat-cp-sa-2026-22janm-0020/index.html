If the sum of the first four terms of an A.P. is 6 and the sum of its first six terms is 4, then the sum of its first twelve terms is

  1. (1) -20
  2. (2) -24
  3. (3) -26
  4. (4) -22

Answer

Correct answer: Option 4

Solution

Sum of first 4 terms S_4 = 6 (4/2)(2a + 3d) = 6 => 2a + 3d = 3 .....(1) Sum of first 6 terms S_6 = 4 (6/2)(2a + 5d) = 4 => 2a + 5d = 4/3 .....(2) eq.(2) - eq.(1) (2a + 5d) - (2a + 3d) = 4/3 - 3 2d = 4/3 - 9/3 2d = -5/3 => d = -5/6 Substituting in equation (1): 2a + 3(-5/6) = 3 2a - 5/2 = 3 2a = 3 + 5/2 2a = 11/2 => a = 11/4 S_12 = (12/2){2 × (11/4) + (12-1)(-5/6)} S_12 = 6{(22/4) + 11(-5/6)} S_12 = 6{(11/2) - (55/6)} S_12 = 6{(33/6) - (55/6)} S_12 = 6(-22/6) S_12 = -22
