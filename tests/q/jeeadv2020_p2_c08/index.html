Which of the following plots is (are) correct for the given reaction? ([P]₀ is the initial concentration of P) [Chemical reaction showing: H₃C-Br + NaOH → H₃C-OH + NaBr, with Br and OH groups attached to central carbon with two CH₃ groups] P is the reactant (tert-butyl bromide), Q is the product (tert-butyl alcohol)

Multiple correct (MSQ) · Marks: +4 / -1.0

  1. (A) [Plot A: Y-axis labeled t₁/₂, X-axis labeled [P]₀. Horizontal line at height t₁/₂ across all [P]₀ values]
  2. (B) [Plot B: Y-axis labeled 'initial rate', X-axis labeled [P]₀. Horizontal line at constant initial rate across all [P]₀ values]
  3. (C) [Plot C: Y-axis labeled [Q]/[P]₀, X-axis labeled 'time'. Curved line increasing from origin with decreasing slope (exponential-like growth)]
  4. (D) [Plot D: Y-axis labeled ln([P]/[P]₀), X-axis labeled 'time'. Straight line with negative slope passing through origin]

Answer

Correct answer: A

Solution

Sol. A CH₃ | H₃C—C—Br+NaOH → H₃C—C—OH+NaBr | | CH₃ CH₃ (P) (Q) The order of the above reaction is one (SN1) because substrate is a 3°-halide So, for a first order reaction. P = P₀×e^(-kt) or P/P₀ = e^(-kt) ln(P/P₀) = -kt y = mx So, the slope of the graph ln(P/P₀) versus time (t) should be negative. Hence option D is incorrect. Also P/P₀ = e^(-kt) (1 - P/P₀) = (1 - e^(-kt)) P₀ - P/P₀ = (1 - e^(-kt)) Or [Q]/P₀ = (1 - e^(-kt)) So, graph between [Q]/P₀ vs. t. should be as shown in figure (1), so, option (C)is incorrect [Fig 1: Curved line starting at origin, increasing and leveling off horizontally] For a first order reaction r = k[P]¹ At t = 0, r = k[P₀] So, initial rate of reaction is directly proportional to initial conc. of P. Hence option B is also incorrect. For a first order reaction t₁/₂ = (ln 2/k)[P₀]⁰ So, t₁/₂ is independent of initial conc. of reactant. So, option (A) is correct. [Fig 2: Linear graph with ri on y-axis and [P₀] on x-axis] [Fig 3: Horizontal line at height t₁/₂ with [P₀] on x-axis]
