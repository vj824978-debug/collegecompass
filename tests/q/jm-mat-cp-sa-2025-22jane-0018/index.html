The sum of all values of θ ∈ [0, 2π] satisfying 2sin^2(θ) = cos(2θ) and 2cos^2(θ) = 3sin(θ) is

  1. (1) π/2
  2. (2) 4π
  3. (3) 5π/6
  4. (4) π

Answer

Correct answer: Option 4

Solution

2sin^2(θ) = cos(2θ) 2sin^2(θ) = 1 - 2sin^2(θ) 4sin^2(θ) = 1 sin^2(θ) = 1/4 sin(θ) = ±1/2 2cos^2(θ) = 3sin(θ) 2(1 - sin^2(θ)) = 3sin(θ) 2 - 2sin^2(θ) = 3sin(θ) 2sin^2(θ) + 3sin(θ) - 2 = 0 (2sin(θ) - 1)(sin(θ) + 2) = 0 sin(θ) = 1/2 or sin(θ) = -2 Since -1 ≤ sin(θ) ≤ 1, we reject sin(θ) = -2 So common equation which satisfy both equations is sin(θ) = 1/2 θ = π/6, 5π/6 (θ ∈ [0, 2π]) Sum = π/6 + 5π/6 = π
