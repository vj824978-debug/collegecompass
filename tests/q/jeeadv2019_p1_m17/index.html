Let AP(a; d) denote the set of all the terms of an infinite arithmetic progression with first term a and common difference d > 0. If AP(1; 3) ∩ AP(2; 5) ∩ AP(3; 7) = AP (a; d) then a + d equals____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 157.00

Solution

AP (1, 3) = {1, 4, 7, 10, ....} = {n / n = 3k + 1, k ∈ W} AP (2, 5) = {2, 7, 12, .... } = {n / n = 5k + 2, k ∈ W} AP (3, 7) = {3, 10, 17, ...} = {n / n = 7k + 3, k ∈ W} Let common term is M M ≡ 1 (mod 3), M ≡ 2(mod 5), M ≡ 3(mod 7) ⟹ M ≡ 52(mod 105) so a = 52, d = 105 and a + d = 157
