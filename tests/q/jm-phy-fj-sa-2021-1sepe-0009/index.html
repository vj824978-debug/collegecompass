A block of mass m slides on the wooden wedge, which in turn slides backward on the horizontal surface. The acceleration of the block with respect to the wedge is: Given m = 8 kg, M = 16 kg. Assume all the surfaces shown in the figure to be frictionless.

  1. (1) (A) (5/9)g
  2. (2) (B) (3/5)g
  3. (3) (C) (2/3)g
  4. (4) (D) (4/3)g

Answer

Correct answer: Option 3

Solution

For the system, wedge angle = 30°. Using constraint equations for the block and wedge accelerations: For block w.r.t. wedge: N = 8g sin(30°) = 4g cos(30°) and N = 8g cos(30°) - 8a sin(30°). From the force analysis on block and wedge separately with constraint that wedge acceleration is a: Setting up equations: 32a = 4*sqrt(3)*g - 4a, which gives 36a = 4*sqrt(3)*g, so a = (sqrt(3)/9)g. For the 8 kg block: 8g sin(30°) - 8a cos(30°) = m*a_rel, leading to a_rel = (2/9)g
