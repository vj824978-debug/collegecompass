If the first term of an A.P. is 3 and the sum of its first four terms is equal to one-fifth of the sum of the next four terms, then the sum of the first 20 terms is equal to

  1. (1) -1200
  2. (2) -1080
  3. (3) -1020
  4. (4) -120

Answer

Correct answer: Option 2

Solution

a = 3 S_4 = (1/5)(S_8 - S_4) => 5S_4 = S_8 - S_4 => 6S_4 = S_8 => 6. (4/2)[2 × 3 + (4 - 1) × d] = (8/2)[2 × 3 + (8 - 1)d] => 12(6 + 3d) = 4(6 + 7d) => 18 + 9d = 6 + 7d => d = -6 S_20 = (20/2)[2 × 3 + (20 - 1)(-6)] = 10[6 - 114] = -1080
