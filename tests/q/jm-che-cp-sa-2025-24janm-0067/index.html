Consider the given plots of vapour pressure (VP) vs temperature (T/K) Which amongst the following options is correct graphical representation showing ΔT_f depression in the freezing point of solvent in a solution ?

  1. (1) Graph showing Solution and Liquid Solvent curves with Solution curve above Liquid Solvent curve, with ΔT_f marked between T_f and T_f° on temperature axis
  2. (2) Graph showing Frozen Solution, Solution, and Liquid Solvent curves with Frozen Solution below other curves, with ΔT_f marked between T_f and T_f° on temperature axis
  3. (3) Graph showing Frozen Solution, Liquid Solvent, and Solution curves with Frozen Solution on left, and ΔT_f marked between T_f and T_f° on temperature axis
  4. (4) Graph showing Solution and Frozen Solvent curves with Frozen Solvent below Solution curve, with ΔT_f marked between T_f and T_f° on temperature axis

Answer

Correct answer: Option 3

Solution

On adding non-volatile solute in a solvent, the freezing point of solution decreases. T_f < T_f° F.P. of solution < F.P. of pure solvent Also V.P. of solution decreases on adding nonvolatile solute in a solvent. The correct representation should show: 1. The Liquid Solvent curve at the highest position (highest VP) 2. The Solution curve below the Liquid Solvent curve (lower VP due to dissolved solute) 3. The Frozen Solution curve below both, representing the solid phase 4. The freezing point depression ΔT_f shown as the horizontal distance between T_f (freezing point of solution) and T_f° (freezing point of pure solvent) 5. T_f should be to the LEFT of T_f° (lower temperature for solution) Option [3] correctly shows all these features: Frozen Solution on the left, with curves positioned appropriately showing VP differences, and ΔT_f marked between T_f and T_f° where T_f < T_f°.
