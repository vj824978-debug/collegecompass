The vector a = i + 2j + k is rotated through a right angle, passing through the y-axis in its way and the resulting vector is b. Then the projection of 3a + sqrt(26) on c = 5i + 4j + 3k is

  1. (1) sqrt(6)
  2. (2) 2*sqrt(3)
  3. (3) 1
  4. (4) 3*sqrt(2)

Answer

Correct answer: Option 4

Solution

Let b = μi + λj Now b·a = 0 ⇒ (μi + λj)·a = 0 ⇒ μ|a|^2 + 2λ = 0 ⇒ 6μ + 2λ = 0 ......(i) ⇒ b = λ(3 - 3i) = λ(-i - j + k) ⇒ |b| = a ⇒ λ = ±sqrt(2) ∴ b = -sqrt(2)(-i - j + k) ∴ 3a + sqrt(26) = 3(-i + 2j + k) - 2(-i - j + k) = -i + 8j + k ∴ projection = 3*sqrt(2)
