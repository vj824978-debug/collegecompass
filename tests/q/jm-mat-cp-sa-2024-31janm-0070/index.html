Let g(x) be a linear function and f(x) = ((1+x)/(2+x))^(1/x), is continuous at x = 0. If f(1) = f(-1), then the value g(3) is

  1. (1) log_e(4/9) - 1
  2. (2) log_e(4/9^(1/3))
  3. (3) (1/3)log_e(4/9) + 1
  4. (4) (1/3)log_e(4/9^(1/3))

Answer

Correct answer: Option 2

Solution

Using continuity at x=0: lim(x→0) ((1+x)/(2+x))^(1/x) = (1/2)^0 = 1. For g(x) = ax+b to be continuous, b=0. Computing f'(1) using logarithmic differentiation: f(1) = (2/3)[1/6 - ln(2/3)]. From f(1)=f(-1): -a = (2/3)[1/6 - ln(2/3)], giving a = (2/3)ln(2/3) - 1/9. Therefore g(x) = ax, and g(3) = 3a = 2ln(2/3) - 1/3 = ln(4/9) - 1/3 = ln(4/(9e^(1/3))) = log_e(4/9^(1/3))
