Let R denote the set of all real numbers. Let f : R → R be defined by f(x) = {(6x + sin x)/(2x + sin x) if x ≠ 0, 7/3 if x = 0} Then which of the following statements is (are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) The point x = 0 is a point of local maxima of f
  2. (B) The point x = 0 is a point of local minima of f
  3. (C) Number of points of local maxima of f in the interval [π, 6π] is 3
  4. (D) Number of points of local minima of f in the interval [2π, 4π] is 1

Answer

Correct answer: BCD

Solution

f(x) = (6x + sin x)/(2x + sin x), x ≠ 0 = 7/3, x ≠ 0 f'(x) = (4 sin x - 4x cos x)/(2x + sin x)², x ≠ 0 = (4 cos x(tan x - x))/(2x + sin x)², x ≠ 0 [Graph showing a function with vertical asymptotes at regular intervals (π, 2π, 3π, etc.), with the function appearing to have local maxima and minima between asymptotes] Now to check x = 0 is point of local maxima or minima f'(0⁻) < 0 and f'(0⁺) > 0 ⟹ x = 0 is point of local minima. From the graph, we can say in the interval [π, 6π] there is three point of local maxima and in the interval [2π, 4π] there is one point of local minima.
