The plane 2x - y + z = 4 intersects the line segment joining the points A(a, -2, 4) and B(2, b, -3) at the point C in the ratio 2:1 and the distance of the point C from the origin is sqrt(5). If ab < 0 and P is the point (a - b, b, 2b - a) then CP^2 is equal to

  1. (1) 73/3
  2. (2) 16/3
  3. (3) 97/3
  4. (4) 17/3

Answer

Correct answer: Option 4

Solution

C divides AB in the ratio 2:1, so C = ((a + 4)/3, (-2 + 2b)/3, (4 - 6)/3) = ((a + 4)/3, (2b - 2)/3, -2/3) c lies on plane 2x - y + z = 4 2((a + 4)/3) - (2b - 2)/3 - 2/3 = 4 => 2a + 8 - 2b + 2 - 2 = 12 => a - b = 2 ... (i) Now, OP = sqrt(5) ((a + 4)/3)^2 + ((2b - 2)/3)^2 + 4/9 = 5 and using (i) Solving: a = 11/5, 1 or b = 1/5, -1 Also from (i) a - b = 2, we get: as also => a = 1, b = -1 Therefore P(2, -1, -3), C(5/3, -4/3, -2/3) CP^2 = (2 - 5/3)^2 + (-1 - (-4/3))^2 + (-3 - (-2/3))^2 CP^2 = (1/3)^2 + (1/3)^2 + (-7/3)^2 CP^2 = 1/9 + 1/9 + 49/9 = 51/9 = 17/3 Therefore, Option (4) is correct.
