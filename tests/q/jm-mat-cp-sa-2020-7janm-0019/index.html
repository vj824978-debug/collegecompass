If the system of linear equations 2x + 2ay + az = 0, 2x + 3by + bz = 0, 2x + 4cy + cz = 0 where a, b, c ∈ R are non-zero and distinct; has a non-zero solution, then:

  1. (1) a, b, c are in G.P.
  2. (2) a, b, c are in A.P.
  3. (3) 1/a, 1/b, 1/c are in A.P.
  4. (4) a + b + c = 0

Answer

Correct answer: Option 3

Solution

For non-zero solution, the determinant must equal zero: Δ = |2 2a a | |2 3b b | = 0 |2 4c c | Expanding the determinant: 2(3bc - 4bc) - 2a(2c - 2b) + a(8c - 6b) = 0 2(-bc) - 2a(2c - 2b) + a(8c - 6b) = 0 -2bc - 4ac + 4ab + 8ac - 6ab = 0 -2bc + 4ac - 2ab = 0 Dividing by -2abc: 1/a - 2/b + 1/c = 0 1/a + 1/c = 2/b This shows that 1/a, 1/b, 1/c are in A.P.
