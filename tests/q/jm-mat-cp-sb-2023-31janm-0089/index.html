Let a₁, a₂, ..., aₙ be in A.P. If a₅ = 2a₇ and a₁₁ = 18, then 12(1/(sqrt(a₁₀) + sqrt(a₁₁)) + 1/(sqrt(a₁₁) + sqrt(a₁₂)) + .... + 1/(sqrt(a₁₇) + sqrt(a₁₈))) is equal to ______.

Answer

Correct answer: 8

Solution

a₁₁ = 18 a + 10d = 18 ...(i) a₅ = 2a₇ a + 4d = 2(a + 6d) a + 4d = 2a + 12d a = -8d ...(ii) From (i) and (ii) ⟹ a = -72, d = 9 On rationalising the denominator, given expression = 12[(sqrt(a₁₀) - sqrt(a₁₁))/(-d) + (sqrt(a₁₁) - sqrt(a₁₂))/(-d) + .... + (sqrt(a₁₇) - sqrt(a₁₈))/(-d)] = 12[(sqrt(a₁₀) - sqrt(a₁₈))/(-d)] = 12[(sqrt(a₁₁ - d) - sqrt(a₁₁ + 7d))/(-d)] = 12[(sqrt(18 - 9) - sqrt(18 + 63))/(-9)] = 12[(sqrt(9) - sqrt(81))/(-9)] = 12[(3 - 9)/(-9)] = 12 × (-6)/(-9) = 12 × 2/3 = 8
