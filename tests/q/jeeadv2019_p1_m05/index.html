Let α and β be the roots of x^2 - x - 1 = 0, with α > β. For all positive integers n, define a_n = (α^n - β^n)/(α - β), n ≥ 1, b_1 = 1 and b_n = a_{n-1} + a_{n+1}, n ≥ 2. Then which of the following options is/are correct?

Multiple correct (MSQ) · Marks: +4 / -1.0

  1. (A) ∑_{n=1}^∞ b_n/10^n = 8/89
  2. (B) b_n = α^n + β^n for all n ≥ 1
  3. (C) a_1 + a_2 + a_3 + ... + a_n = a_{n+2} - 1 for all n ≥ 1
  4. (D) ∑_{n=1}^∞ a_n/10^n = 10/89

Answer

Correct answer: BCD

Solution

Sol. B, C, D Clearly we have α + β = 1 & αβ = -1 α, β = (1 ± √5)/2 As bₙ = aₙ₊₁ + aₙ₊₁ = (αⁿ⁺¹ - βⁿ⁺¹)/(α - β) + (αⁿ⁺¹ - βⁿ⁺¹)/(α - β) = (αⁿ⁻¹(1 + α²) - βⁿ⁻¹(1 + β²))/(α - β) = (αⁿ⁻¹(α + 2) - βⁿ⁻¹(β + 2))/(α - β) = (αⁿ⁻¹((5 + √5)/2) - βⁿ⁻¹((5 - √5)/2))/(α - β) = (√5(αⁿ + βⁿ))/(α - β) = αⁿ + βⁿ : As α - β = √5 (D) ∑(n=1 to ∞) aₙ/10ⁿ = ∑(n=1 to ∞) (αⁿ - βⁿ)/((α - β)10ⁿ) = (α/10)/(1 - α/10) - (β/10)/(1 - β/10) / (α - β) = (α(10 - β) - β(10 - α))/((10 - α)(10 - β)(α - β)) = 10/89 (A) ∑(n=1 to ∞) bₙ/10ⁿ = ∑(n=1 to ∞) (αⁿ + βⁿ)/10ⁿ = α/10/(1 - α/10) + β/10/(1 - β/10) = (α(10 - β) + β(10 - α))/((10 - α)(10 - β)) = (10(α + β) - 2αβ)/(100 - (α + β)10 + αβ) = 12/89 (C) a₁ + a₂ + a₃ + ... + aₙ = ∑(r=1 to n) aᵣ = ∑(r=1 to n) (αʳ - βʳ)/(α - β) = (α(1 - αⁿ))/(1 - α) - (β(1 - βⁿ))/(1 - β) / (α - β) = ((α - αβ)(1 - αⁿ) - β(1 - α)(1 - βⁿ))/((α - β)(1 - α)(1 - β)) = ((α - β) - αⁿ⁺²(1 + α) + βⁿ⁺²(1 + β))/(-（α - β)) = ((α - β) - αⁿ⁺²+ βⁿ⁺²)/(-(α - β)) : As 1 + x = x² = -1 + (αⁿ⁺² - βⁿ⁺²)/(α - β) = -1 + aₙ₊₂
