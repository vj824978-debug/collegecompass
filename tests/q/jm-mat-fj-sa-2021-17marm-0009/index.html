p^(~q) is equivalent to:

  1. (1) ~q = p
  2. (2) p => q
  3. (3) p => q
  4. (4) q => p

Answer

Correct answer: Option 2

Solution

p^(~q) means p AND (NOT q). This is equivalent to the negation of (p => q), which is logically equivalent to q => p is incorrect. The correct analysis: p^(~q) is true when p is true and q is false. The contrapositive of p => q is ~q => ~p. However, p^(~q) is actually equivalent to ~(p => q), which means it's the negation of 'if p then q'. This matches with option (B) p => q being false, or equivalently this represents the case where the implication fails. The answer should be (D) q => p based on logical equivalence, but the solution states none of the options are correct because P, Q, R represents students playing all three games, hence no any option is correct.
