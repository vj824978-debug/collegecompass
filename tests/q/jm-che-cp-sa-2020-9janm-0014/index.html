A chemist has 4 samples of artificial sweetener A, B, C and D. To identify these samples, he performed certain experiments and noted the following observations: (i) A and D both form blue-violet colour with ninhydrin. (ii) Lassaigne extract of C gives positive AgNO3 test and negative Fe4[Fe(CN)6]3 test. (iii) Lassaigne extract of B and D gives positive sodium nitroprusside test. Based on these observations which option is correct?

  1. (1) A : Aspartame; B : Alitame; C : Saccharin; D : Sucralose
  2. (2) A : Aspartame; B : Saccharin; C : Sucralose; D : Alitame
  3. (3) A : Alitame; B : Saccharin; C : Aspartame; D : Sucralose
  4. (4) A : Saccharin; B : Alitame; C : Sucralose; D : Aspartame

Answer

Correct answer: Option 2

Solution

A – Aspartame B – Saccharin C – Sucralose D – Alitame (i) A & D give positive test with ninhydrin because both have free carboxylic and amine group. Aspartame has both -COOH and -NH2 groups, so it gives positive ninhydrin test. Alitame also has both -COOH and -NH2 groups, so it gives positive ninhydrin test. (ii) C form precipitate with AgNO3 because it has chlorine atoms. Sucralose contains chlorine atoms, so it gives positive AgNO3 test. The negative Fe4[Fe(CN)6]3 test indicates absence of Fe2+ ions, which rules out compounds containing iron. (iii) B & D give positive test because Both have S-atom. Saccharin contains S-atom in its structure, so it gives positive sodium nitroprusside test. Alitame contains S-atom in its structure, so it gives positive sodium nitroprusside test.
