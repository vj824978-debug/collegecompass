A circular table is rotating with an angular velocity of ω rad/s about its axis. There is a smooth groove along a radial direction on the table. A steel ball is gently placed at a distance of 1m on the groove. All the surfaces are smooth. If the radius of the table is 3 m, the radial velocity of the ball w.r.t. the table at the time ball leaves the table is x*sqrt(2) m/s, where the value of x is.........

Answer

Correct answer: 2

Solution

In the rotating reference frame, the ball experiences a centrifugal force. The centrifugal acceleration is a_c = ω^2*x. Using v*dv/dx = ω^2*x and integrating from x=1 to x=3 (when ball leaves table): ∫v*dv from 0 to v = ∫ω^2*x*dx from 1 to 3. This gives v^2/2 = ω^2[x^2/2] evaluated from 1 to 3, so v^2/2 = ω^2(9-1)/2 = 4ω^2. Therefore v = 2ω = 2*sqrt(2)*ω, giving x = 2.
