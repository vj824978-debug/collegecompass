Let f: R → R and g: R → R be two non-constant differentiable functions. If f'(x) = (e^(f(x)-g(x))) g'(x) for all x ∈ R, and f(1) = g(2) = 1, then which of the following statement(s) is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) f(2) < 1 - log_e 2
  2. (B) f(2) > 1 - log_e 2
  3. (C) g(1) > 1 - log_e 2
  4. (D) g(1) < 1 - log_e 2

Answer

Correct answer: BC

Solution

Sol. B, C f'(x) = e^(f(x)-g(x)) · g'(x) given f(1) = g(2) = 1 ∫-f'(x) · e^(-f(x)) dx = ∫-e^(-g(x)) · g'(x) dx ∫d(e^(-f(x))) = ∫d(e^(-g(x))) + C e^(-f(x)) = e^(-g(x)) + C put x = 1 ⇒ C = 1/e - 1/e^(g(1)) x = 2 ⇒ e^(f(2)) = e^(1+g(1))/(2e^(g(1)) - e) ⇒ g(1) > 1 - log_e 2 & f(2) > 1 - log_e 2
