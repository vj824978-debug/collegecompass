To get output '1' at R, for the given logic gate circuit the input values must be -

  1. (1) X = 0, Y = 0
  2. (2) X = 1, Y = 0
  3. (3) X = 0, Y = 1
  4. (4) X = 1, Y = 1

Answer

Correct answer: Option 2

Solution

From the circuit diagram, we need to analyze the logic gates: The circuit has: - X input going through a NOT gate (producing X̄) - Y input going directly - Top AND gate: takes X̄ and Y as inputs, produces X̄.Y - Bottom AND gate: takes X and Ȳ as inputs, produces X.Ȳ - OR gate (labeled P and Q): takes outputs from both AND gates The output P from the OR gate is: P = X̄.Y + X.Ȳ (This is XOR function) For output R to be 1, we need P = 1 Let's check each case: (1) X = 0, Y = 0: X̄ = 1, Ȳ = 1 P = X̄.Y + X.Ȳ = (1)(0) + (0)(1) = 0 + 0 = 0 R = 0 ✗ (2) X = 1, Y = 0: X̄ = 0, Ȳ = 1 P = X̄.Y + X.Ȳ = (0)(0) + (1)(1) = 0 + 1 = 1 R = 1 ✓ (3) X = 0, Y = 1: X̄ = 1, Ȳ = 0 P = X̄.Y + X.Ȳ = (1)(1) + (0)(0) = 1 + 0 = 1 R = 1 ✗ (But this also gives 1) (4) X = 1, Y = 1: X̄ = 0, Ȳ = 0 P = X̄.Y + X.Ȳ = (0)(1) + (1)(0) = 0 + 0 = 0 R = 0 ✗ From the truth table provided in the solution: Only when X = 1, Y = 0, R = 1 Therefore, Answer: X = 1, Y = 0
