If the normal at an end of a latus rectum of an ellipse passes through an extremity of the minor axis, then the eccentricity e of the ellipse satisfies:

  1. (1) e^2 + 2e - 1 = 0
  2. (2) e^2 + e - 1 = 0
  3. (3) e^4 + 2e^2 - 1 = 0
  4. (4) e^4 + e^2 - 1 = 0

Answer

Correct answer: Option 4

Solution

Consider the ellipse x^2/a^2 + y^2/b^2 = 1 where a > b. The latus rectum passes through the foci at (±c, 0) where c = ae. An end of the latus rectum has coordinates (ae, b^2/a). The equation of the normal at point (x₁, y₁) on the ellipse is: a^2x/x₁ - b^2y/y₁ = a^2e^2 At the end of latus rectum (ae, b^2/a), the normal equation becomes: a^2x/(ae) - b^2y/(b^2/a) = a^2e^2 Simplifying: ax/e - ay = a^2e^2 Dividing by a: x/e - y = ae^2 Or: x/e - y = ae^2 This normal passes through the extremity of the minor axis (0, b). Substituting (0, b): 0/e - b = ae^2 -b = ae^2 b = -ae^2 Since b^2 = a^2(1 - e^2): ae^2 = -b is incorrect. Let me recalculate. Passing through (0, b): 0 - b = ae^2 -b = ae^2 ... (i) From the ellipse property: b^2 = a^2(1 - e^2) From (i): b = -ae^2 is not possible since b > 0. Correction: The normal equation at (ae, b^2/a) passing through (0, b): Substituting the normal passes through (0, -b) (lower extremity): 0/e - (-b) = ae^2 b = ae^2 Since b^2 = a^2(1 - e^2): (ae^2)^2 = a^2(1 - e^2) a^2e^4 = a^2(1 - e^2) e^4 = 1 - e^2 e^4 + e^2 - 1 = 0
