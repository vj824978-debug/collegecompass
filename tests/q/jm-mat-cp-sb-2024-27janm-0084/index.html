If the solution of the differential equation (2x + 3y - 2)dx + (4x + 6y - 7)dy = 0, y(0) = 3, is αx + βy + 3log_e|2x + 3y - γ| = 6, then α + 2β + 3γ is equal to ____.

Answer

Correct answer: 29

Solution

Rewrite the differential equation as dy/dx = -(2x + 3y - 2)/(4x + 6y - 7). Substitute t = 2x + 3y, so dt/dx = 2 + 3(dy/dx). This gives dt/dx - 2 = -(t - 2)/(2t - 7). Simplify to dt/dx = (t - 8)/(2t - 7). Separate variables: (2t - 7)/(t - 8)dt = dx. Integrate: 2t + 9ln|t - 8| = x + c. Substitute back t = 2x + 3y: 2(2x + 3y) + 9ln|2x + 3y - 8| = x + c, which simplifies to x + 2y + 3ln|2x + 3y - 8| = 6 using y(0) = 3 to find c = 18. Comparing with αx + βy + 3log_e|2x + 3y - γ| = 6: α = 1, β = 2, γ = 8. Therefore α + 2β + 3γ = 1 + 4 + 24 = 29.
