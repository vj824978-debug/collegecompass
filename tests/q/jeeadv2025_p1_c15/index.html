The major products obtained from the reactions in List-II are the reactants for the named reactions mentioned in List-I. Match each entry in List-I with the appropriate entry in List-II and choose the correct option. [TABLE: List-I | List-II (P) Stephen reaction | (1) Toluene with (i) CrO₂Cl₂/CS₂ (ii) H₃O⁺ (Q) Sandmeyer reaction | (2) Benzoic acid with (i) PCl₅ (ii) NH₃ (iii) P₄O₁₀, Δ (R) Hoffmann bromamide degradation reaction | (3) Nitrobenzene with (i) Fe, HCl (ii) HCl/NaNO₂ (273-278 K), H₂O (S) Cannizzaro reaction | (4) Toluene with (i) Cl₂/hν, H₂O (ii) Tollen's reagent (iii) SO₂Cl₂ (iv) NH₃ | (5) Aniline with (i) (CH₃CO)₂O, Pyridine (ii) HNO₃, H₂SO₄, 288 K (iii) aq. NaOH ] (A) P → 2; Q → 4; R → 1; S → 3 (B) P → 2; Q → 3; R → 4; S → 1 (C) P → 5; Q → 3; R → 4; S → 2 (D) P → 5; Q → 4; R → 2; S → 1

Matrix match · Marks: +4 / -1.0

  1. (A) P → 2; Q → 4; R → 1; S → 3
  2. (B) P → 2; Q → 3; R → 4; S → 1
  3. (C) P → 5; Q → 3; R → 4; S → 2
  4. (D) P → 5; Q → 4; R → 2; S → 1

Answer

Correct answer: B

Solution

P - 2 C₆H₅ - COOH + PCl₅ → C₆H₅ - C(=O) - Cl --NH₃--> C₆H₅ - C(=O) - NH₂ --(-H₂O, P₄O₁₀/Δ)--> Ph - C≡N (Reactant for Stephen reaction) Q - 3 C₆H₅ - NO₂ --Fe, HCl--> C₆H₅ - NH₂ --[(HCl + NaNO₂), H₂O]--> C₆H₅ - N≡C Cl⁻ (Reactant for Sandmeyer reaction) R - 4 [Benzene ring with CH₃] --Cl₂/hν, H₂O--> [Benzene ring with CHO] --Aq.O, (Tolleris reagent)--> [Benzene ring with COOH] --SO₂Cl₂--> [Benzene ring with COCl] --NH₃--> [Benzene ring with C(=O)NH₂] (Reactant for Hoffmann bromamide reaction) S - 1 [Benzene ring with CH₃] --CrO₂Cr₂/Cl₂, H₂O--> [Benzene ring with CHO] (Reactant for Cannizaro reaction)
