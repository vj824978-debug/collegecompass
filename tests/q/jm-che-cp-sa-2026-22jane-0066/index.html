[Ni(PPh3)2]Cl2 is a paramagnetic complex. Identify the INCORRECT statements about this complex.

  1. (1) A and B only
  2. (2) A, B and D only
  3. (3) C and D only
  4. (4) C, D and E only

Answer

Correct answer: Option 2

Solution

[Ni(PPh3)2]Cl2 Given: Paramagnetic complex hence it must be tetrahedral so Crystal field splitting: E_t (with 4 upward arrows in one set and 2 upward, 1 upward, 1 downward in another set labeled e^4) Delta_t (with 4 upward arrows in one set and 2 upward, 1 upward, 1 downward in another set labeled e^4) Ni^(+2) = (Ar) 3d^8 (A) Tetrahedral complex not show geometrical isomerism. - TRUE (Tetrahedral complexes do not show geometrical isomerism) (B) Complex is Blue colour - FALSE (Tetrahedral Ni^(+2) complexes are typically blue, but this needs verification based on ligand field theory) (C) Calculated spin only magnetic moment of the complex is 2.84 B.M. - TRUE (For d^8 configuration in tetrahedral: μ = sqrt(n(n+2)) = sqrt(2(2+2)) = sqrt(8) = 2.83 ≈ 2.84 B.M.) (D) C.F.S.E = -0.6Δ1(4) + 0.4Δ1(4) = -0.8Δ1 (not -0.8Δ0) - TRUE (E) Ni(CO)4 also tetrahedral Hence only A, B, D correct. The INCORRECT statements are C and D only.
