The internal energy (U), pressure (P) and volume (V) of an ideal gas are related as U = 3PV + 4. The gas is

  1. (1) polyatomic only
  2. (2) diatomic only
  3. (3) either mono-atomic or diatomic
  4. (4) mono-atomic only

Answer

Correct answer: Option 1

Solution

Given U = 3PV + 4. Using U = nC_v*T and ideal gas law PV = nRT: nC_v*T = 3PV + 4 becomes nC_v*(PV/nR) = 3PV + 4, which gives (f/2)*PV = 3PV + 4. This yields f = 6 + 8/PV. As PV increases, f approaches 6, which corresponds to polyatomic gas. However, analyzing the relationship more carefully with the constant term, f = 6 indicates polyatomic gas.
