If x^2 - y^2 + 2hxy + 2gx + 2fy + c = 0 is the locus of a point, which moves such that it is always equidistant from the lines x + 2y + 7 = 0 and 2x - y + 8 = 0, then the value of g + c + h - f equals

  1. (1) 29
  2. (2) 8
  3. (3) 14
  4. (4) 6

Answer

Correct answer: Option 3

Solution

The locus of points equidistant from two lines L1: x + 2y + 7 = 0 and L2: 2x - y + 8 = 0 is given by: (x + 2y + 7)^2/(1^2 + 2^2) = (2x - y + 8)^2/(2^2 + 1^2). Both denominators equal 5, so: (x + 2y + 7)^2 = (2x - y + 8)^2. Expanding and simplifying: x^2 - y^2 + (8/3)xy + (18/3)x + (-44/3)y + 5 = 0. Comparing with x^2 - y^2 + 2hxy + 2gx + 2fy + c = 0: h = -4/3, g = 9/3 = 3, f = -22/3, c = 5. Therefore: g + c + h - f = 3 + 5 + (-4/3) - (-22/3) = 8 + 18/3 = 8 + 6 = 14.
