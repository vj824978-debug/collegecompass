Let f and g be twice differentiable functions on such that f''(x) = g''(x) + 6x, f'(1) = 4g(1) - 3 = 9, f(2) = 3g(2) = 12. Then which of the following is NOT true?

  1. (1) There exists x_0 in (1, 3/2) such that f(x_0) = g(x_0)
  2. (2) |f'(x) - g'(x)| < 6 implies -1 < x < 1
  3. (3) g(-2) - f(-2) = 20
  4. (4) If -1 < x < 2, then |f(x) - g(x)| < 8

Answer

Correct answer: Option 4

Solution

f''(x) = g''(x) + 6x Integrating: 2f'(x) = g'(x) + 3x^2 + C From f'(1) = 4g(1) - 3 = 9: f'(1) = 9, so 4g(1) = 12, thus g(1) = 3 2(9) = g'(1) + 3 + C 18 = g'(1) + 3 + C Since g(1) = 3, we need to find g'(1). From the relation: 2f'(1) = g'(1) + 3(1)^2 + C 2(9) = g'(1) + 3 + C 18 = g'(1) + 3 + C ... (i) From f(2) = 3g(2) = 12: f(2) = 12, g(2) = 4 Integrating f'(x) = g(x)/2 + (3x^2/2) + C/2: f(x) = g(x) + x^3 + (C/2)x + C' At x = 1: f(1) = g(1) + 1 + C/2 + C' At x = 2: f(2) = g(2) + 8 + C + C' 12 = 4 + 8 + C + C' C' = 0 From f'(x) = g'(x) + 3x^2 + 3: f(x) = g(x) + x^3 + 3x + C' At x = 2: 12 = 4 + 8 + 6 + C' C' = -6 Thus f(x) = g(x) + x^3 + 3x - 6 f(-2) = g(-2) - 8 - 6 - 6 g(-2) - f(-2) = 20 ✓ (Option 3 is TRUE) f'(x) - g'(x) = 3x^2 + 3 For x in (-1, 1): 3x^2 + 3 in (3, 6) ✓ (Option 2 is TRUE) f(x) - g(x) = x^3 + 3x - 6 At x = -1: |f(-1) - g(-1)| = |-1 - 3 - 6| = 10 Since 10 > 8, Option (4) is FALSE ✓
