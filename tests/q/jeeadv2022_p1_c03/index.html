A solution is prepared by mixing 0.01 mol each of H₂CO₃, NaHCO₃, Na₂CO₃, and NaOH in 100 mL of water. pH of the resulting solution is ______. [Given: pKa₁ and pKa₂ of H₂CO₃ are 6.37 and 10.32, respectively; log 2 = 0.30]

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 10.02

Solution

H₂CO₃ + NaOH → NaHCO₃ + H₂O Initial mol: H₂CO₃ = 0.01, NaOH = 0.01, NaHCO₃ = 0.01 After neutralization: H₂CO₃ = 0, NaOH = 0, NaHCO₃ = 0.01 + 0.01 = 0.02 Now, mixture contains 0.01 mole Na₂CO₃ and 0.02 mol of NaHCO₃ so it is a buffer. pH = pKₐ₂ + log([CO₃²⁻]/[HCO₃⁻]) pH = 10.32 + log(0.01/0.02) = 10.32 + log(1/2) = 10.32 - 0.30 = 10.02
