Let the line L: (x-1)/2 = (y+1)/(-1) = (z-3)/1 intersect the plane 2x + y + 3z = 16 at the point P. Let the point Q be the foot of perpendicular from the point R(1, -1, -3) on the line L. If α is the area of the triangle PQR then α^2 is equal to ______.

Answer

Correct answer: 180

Solution

L: (x-1)/2 = (y+1)/(-1) = (z-3)/1 = r (say) Let P = (2r_1 + 1, -r_1 - 1, r_1 + 3) P lies on 2x + y + 3z = 16 ∴ 2(2r_1 + 1) + (-r_1 - 1) + 3(r_1 + 3) = 16 r_1 = 1 P = (3, -2, 4) R = (1, -1, -3) Let Q = (2r_2 + 1, -r_2 - 1, r_2 + 3) DRs of QR = (2r_2 - r_2 + 6) = (2r_2 - r_2 + 6) DRs of L = (2, -1, 1) QR ⊥ L ⟹ 4r_2 + r_2 + r_2 + 6 = 0 r_2 = -1 Q = (-1, 0, 2) vector QP × vector RP = |i j k| |4 -2 2| |2 -1 7| = -12i - 24j + 0k α = [PQR] = (1/2)|vector QP × vector RP| = (1/2) × 12√5 = 6√5 α^2 = 180
