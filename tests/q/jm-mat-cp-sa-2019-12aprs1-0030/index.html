If the line (x-2)/3 = (y+1)/2 = (z-1)/(-1) intersects the plane 2x + 3y - z + 13 = 0 at a point P and the plane 3x + y + 4z = 16 at a point Q, then PQ is equal to:

  1. (1) 2*sqrt(7)
  2. (2) 14
  3. (3) 2*sqrt(14)
  4. (4) sqrt(14)

Answer

Correct answer: Option 3

Solution

Let (x-2)/3 = (y+1)/2 = (z-1)/(-1) = lambda General point on the line: (3*lambda + 2, 2*lambda - 1, -lambda + 1) Line intersects plane 2x + 3y - z + 13 = 0 at P: 2(3*lambda + 2) + 3(2*lambda - 1) - (-lambda + 1) + 13 = 0 6*lambda + 4 + 6*lambda - 3 + lambda - 1 + 13 = 0 13*lambda + 13 = 0 lambda = -1 P(-1, -3, 2) Line intersects plane 3x + y + 4z = 16 at Q: 3(3*lambda + 2) + (2*lambda - 1) + 4(-lambda + 1) = 16 9*lambda + 6 + 2*lambda - 1 - 4*lambda + 4 = 16 7*lambda + 9 = 16 7*lambda = 7 lambda = 1 Q(5, 1, 0) PQ = sqrt((5 - (-1))^2 + (1 - (-3))^2 + (0 - 2)^2) PQ = sqrt((6)^2 + (4)^2 + (-2)^2) PQ = sqrt(36 + 16 + 4) PQ = sqrt(56) PQ = sqrt(4 * 14) PQ = 2*sqrt(14)
