For 0 < c < b < a, let (a + b - 2c)x^2 + (b + c - 2a)x + (c + a - 2b) = 0 and α ≠ 1 be one of its root. Then, among the two statements (I) If α ∈ (-1, 0), then b cannot be the geometric mean of a and c (II) If α ∈ (0, 1) then b may be the geometric mean of a and c

  1. (1) Only (I) is true
  2. (2) Only (II) is true
  3. (3) Neither (I) nor (II) is true
  4. (4) Both (I) and (II) are true

Answer

Correct answer: Option 4

Solution

f(x) = (a + b - 2c)x^2 + (b + c - 2a)x + (c + a - 2b). Clearly f(1) = 0, so x = 1 is a root. Coefficient of x^2 = a + b - 2c = (a - c) + (b - c) > 0. For I: If α ∈ (-1, 0) and f(1)·f(0) < 0, then 2(2a - b - c)(c + a - 2b) < 0. This gives (c + a)/(2) < b, so A.M. of a and c is less than b, hence b cannot be G.M. of a and c. For II: If α ∈ (0, 1) and f(0)·f(1) < 0, then c + a - 2b > 0, which means (c + a)/(2) > b, so b can be G.M. of a and c. Both statements are true.
