The smallest value of k, for which both the roots of the equation x² - 8kx + 16(k² - k + 1) = 0 are real, distinct and have values at least 4, is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 2

Solution

Sol. 2 x² - 8kx + 16(k² - k + 1) = 0 D > 0 ⇒ k > 1 ... (1) -b/2a > 4 ⇒ 8k/2 > 4 ⇒ k > 1 ... (2) f(4) ≥ 0 ⇒ 16 - 32k + 16(k² - k + 1) ≥ 0 k² - 3k + 2 ≥ 0 k ≤ 1 ∪ k ≥ 2 ... (3) Using (1), (2) and (3) k_min = 2. [Parabola graph showing a U-shaped curve with vertex at x = 4, opening upward]
