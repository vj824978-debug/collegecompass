Let f: R → R and g: R → R be functions defined by f(x) = {|x|sin(1/x), x ≠ 0; 0, x = 0} and g(x) = {1-2x, 0 ≤ x ≤ 1/2; 0, otherwise} Let a, b, c, d ∈ R. Define the function h: R → R by h(x) = af(x) + b(g(x) + g(1/2 - x)) + c(x - g(x)) + dg(x), x ∈ R Match each entry in List-I to the correct entries in List-II. List-I: (P) If a = 0, b = 1, c = 0 and d = 0, then (Q) If a = 1, b = 0, c = 0 and d = 0, then (R) If a = 0, b = 0, c = 1 and d = 0, then (S) If a = 0, b = 0, c = 0 and d = 1, then List-II: (1) h is one-one. (2) h is onto. (3) h is differentiable on R. (4) the range of h is [0, 1]. (5) the range of h is [0, 1]. The correct option is: (A) (P) → (4) (Q) → (3) (R) → (1) (S) → (2) (B) (P) → (5) (Q) → (2) (R) → (4) (S) → (3) (C) (P) → (5) (Q) → (3) (R) → (2) (S) → (4) (D) (P) → (4) (Q) → (2) (R) → (1) (S) → (3)

Answer

Correct answer: C

Solution

We have g(x) + g(1/2 - x) = 0 ; x ∈ ℝ - [0, 1/2] g(x) + g(1/2 - x) = 1 ; x ∈ [0, 1/2] ⇒ h(x) = { af(x) + (d - c)g(x) + cx ; x < 0 af(x) + b + (d - g)g(x) + cx ; x ∈ [0, 1/2] af(x) + (d - c)g(x) + cx ; x > 1/2 } for a = c = d = 0 and b = 1 ; h(x) = { 0 ; x < 0 1 ; x ∈ [0, 1/2] 0 ; x > 1/2 } ⇒ h(x) has range {0, 1} for a = 1, b = c = d = 0 ⇒ h(x) = f(x) ∀ x ∈ ℝ ⇒ h(x) is differentiable. for c = 1, a = b = d = 0 ⇒ h = x - g(x) ; ∀ x ∈ ℝ ⇒ h(x) = { x ; x < 0 3x - 1 ; x ∈ [0, 1/2] x ; x > 1/2 } ⇒ h(x) is onto for d = 1 ; a = b = c = 0 ⇒ h(x) = g(x) ∀ x ∈ ℝ ⇒ h(x) has range [0, 1]
