Let f(x) = |ax a -1; ax^2 ax a|, a ∈ R. Then the sum of the square of all the values of a, for which 2f'(10) - f'(5) + 100 = 0, is-

  1. (1) 117
  2. (2) 106
  3. (3) 125
  4. (4) 136

Answer

Correct answer: Option 3

Solution

Evaluate the determinant: f(x) = a(a^2 + ax) + 1(a^2x + ax^2) = a(x + a)^2. Find derivative: f'(x) = 2a(x + a). Substitute into condition: 2·2a(10 + a) - 2a(5 + a) + 100 = 0. Simplify: 4a(10 + a) - 2a(5 + a) + 100 = 0, which gives a^2 + 15a + 50 = 0. Solve: a = -10, -5. Sum of squares: (-10)^2 + (-5)^2 = 100 + 25 = 125.
