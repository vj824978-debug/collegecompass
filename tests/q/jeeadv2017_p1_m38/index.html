If a chord, which is not a tangent, of the parabola y^2 = 16x has the equation 2x + y = p, and midpoint (h, k), then which of the following is(are) possible value(s) of p, h and k?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) p = 5, h = 4, k = -3
  2. (B) p = -1, h = 1, k = -3
  3. (C) p = -2, h = 2, k = -4
  4. (D) p = 2, h = 3, k = -4

Answer

Correct answer: D

Solution

Sol. D y² = 16x 2x + y = p ... (i) Equation of chord having mid point (h, k) is T = S₁ yk - 8(x + h) = k² - 16h ⇒ yk - 8x = k² - 8h ... (ii) Comparing (i) and (ii) k/1 = 8/2 = (k² - 8h)/p ⇒ k = -4 and k² - 8h = -4p ⇒ 16 - 8h = -4p ⇒ 2h - p = 4 Clearly h = 3, p = 2.
