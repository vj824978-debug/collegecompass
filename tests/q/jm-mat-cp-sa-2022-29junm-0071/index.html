Let a set A = A₁ ∪ A₂ ∪ ... ∪ Aₖ, where Aᵢ ∩ Aⱼ = φ for i ≠ j, 1 ≤ i,j ≤ k. Define the relation R from A to A by R = {(x, y) : y ∈ Aᵢ if and only if x ∈ Aᵢ, 1 ≤ i ≤ k}. Then, R is:

  1. (1) reflexive, symmetric but not transitive
  2. (2) reflexive, transitive but not symmetric
  3. (3) reflexive but not symmetric and transitive
  4. (4) an equivalence relation

Answer

Correct answer: Option 4

Solution

(1) Reflexive: (a,a) ∈ R ⟺ a ∈ Aᵢ iff a ∈ Aᵢ. True for all a ∈ A. (2) Symmetric: (a,b) ∈ R ⟺ a ∈ Aᵢ iff b ∈ Aᵢ. Then (b,a) ∈ R as b ∈ Aᵢ iff a ∈ Aᵢ. Symmetric. (3) Transitive: (a,b) ∈ R and (b,c) ∈ R ⟹ a ∈ Aᵢ iff b ∈ Aᵢ and b ∈ Aᵢ iff c ∈ Aᵢ ⟹ a ∈ Aᵢ iff c ∈ Aᵢ ⟹ (a,c) ∈ R. Transitive. Since R is reflexive, symmetric, and transitive, R is an equivalence relation.
