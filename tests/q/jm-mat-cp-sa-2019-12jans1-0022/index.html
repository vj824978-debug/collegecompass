Let f be a differentiable function such that f(1) = 2 and f'(x) = f(x) for all x in R. If h(x) = f(f(x)), then h'(1) is equal to:

  1. (1) 4e
  2. (2) 2e^2
  3. (3) 4e^2
  4. (4) 2e

Answer

Correct answer: Option 1

Solution

f'(x) = f(x) ln(f(x)) = x + c f(x) = e^(x + c) f(x) = ke^x f(1) = k.e^1 2 = k.e k = 2/e f(x) = ke^x f'(x) = k.e^x h'(x) = f'(f(x)).f'(x) h'(1) = f'(f(1)).f'(1) = f'(2).(2/e × e) = (2/e).e^2.2 = 4e
