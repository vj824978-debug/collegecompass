Let the mean and the variance of 6 observations a, b, 68, 44, 48, 60 be 55 and 194, respectively. If a > b, then a + 3b is

  1. (1) 180
  2. (2) 210
  3. (3) 190
  4. (4) 200

Answer

Correct answer: Option 1

Solution

From mean = 55: (a + b + 68 + 44 + 48 + 60)/6 = 55, so a + b + 220 = 330, thus a + b = 110. From variance = 194: sum(x_i^2)/6 - (55)^2 = 194, so sum(x_i^2) = 19314. This gives a^2 + b^2 = 6850. Solving: a + b = 110 and a^2 + b^2 = 6850. From (a+b)^2 = a^2 + b^2 + 2ab: 12100 = 6850 + 2ab, so ab = 2625. The quadratic equation is t^2 - 110t + 2625 = 0, giving t = 75 or t = 35. Since a > b, we have a = 75, b = 35. Therefore a + 3b = 75 + 105 = 180.
