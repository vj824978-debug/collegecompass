There are two infinitely long straight current carrying conductors and they are held at right angles to each other so that their common ends meet at the origin as shown in the figure given below. The ratio of current in both conductor is 1 : 1. The magnetic field at point P is

  1. (1) (mu_0 I)/(4*pi*y) * [sqrt(x^2 + y^2) - (x + y)]
  2. (2) (mu_0 I)/(4*pi*y) * [sqrt(x^2 + y^2) + (x + y)]
  3. (3) (mu_0 I*x*y)/(4*pi) * [sqrt(x^2 + y^2) - (x + y)]
  4. (4) (mu_0 I*x*y)/(4*pi) * [sqrt(x^2 + y^2) + (x + y)]

Answer

Correct answer: Option 2

Solution

The magnetic field at point P due to two perpendicular current carrying conductors is calculated using Biot-Savart law. For OX wire: B_x = (mu_0 I)/(4*pi*y) * [sin(theta_1) + sin(90°)]. For OY wire: B_y = (mu_0 I)/(4*pi*x) * [sin(theta_2) + sin(90°)]. Both fields point downward. Net field B = B_x + B_y = (mu_0 I)/(4*pi) * [1/y * (1 + x/sqrt(x^2 + y^2)) + 1/x * (1 + y/sqrt(x^2 + y^2))]. Simplifying: B = (mu_0 I)/(4*pi*x*y) * [(x + y) + sqrt(x^2 + y^2)]
