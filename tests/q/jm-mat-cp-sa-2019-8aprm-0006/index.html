If the lengths of the sides of a traingle are in A.P. and the greatest angle is double the smallest then a ratio of lengths of the sides of this triangle is -

  1. (1) 5:6:7
  2. (2) 4:5:6
  3. (3) 3:4:5
  4. (4) 5:9:13

Answer

Correct answer: Option 2

Solution

Let length of sizes are a = A - D (D > 0) b = A C = A + D sinA, sinB, sinC are in AP 2 sin B = sin A + sin C let A = 2θ C = 2θ B = π - (θ + 2θ) B = π - 3θ 2 sin(π - 3θ) = sin θ + sin2θ 2 sin(3θ) = sin θ + 2 sin θ cosθ 2(3 - 4 sin²θ) = 1 +2 cos θ 2(4 cos²θ - 1) = 1 + 2 cosθ 8 cos²θ - 2 cos θ - 3 = 0 8 cos²θ - 6cosθ + 4 cosθ - 3 = 0 (2 cos θ + 1)(4 cosθ - 3) = 0 cosθ = -1/2, cosθ = 3/4 Not possible cosθ = (A + D)² + A²(A - D)² / 2A(A + D) = 3/4 4AD + A² / 2A(A + D) = 3/4 4AD + A² / 2A(A + D) = 3/4 => A = 5D a = A - D = 4D b = A = 5D C = A + D = 6D a : b : C : : 4 : 5 : 6
