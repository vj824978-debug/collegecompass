Consider a sphere of radius R which carries a uniform charge density ρ. If a sphere of radius R/2 is carved out of it, as shown, the ratio |E_A|/|E_B| of magnitude of electric field E_A and E_B, respectively, at points A and B due to the remaining portion is-

  1. (1) 17/54
  2. (2) 18/54
  3. (3) 18/34
  4. (4) 21/34

Answer

Correct answer: Option 3

Solution

E_A = ρR/2 / (3ε_0) = ρR / (6ε_0) For E_B, we use superposition: E_B = E(ρ · (4/3)πR^3) / R^2 - k(ρ · (4/3)π(R^3/8)) / (3R/2)^2 E_B = (4ρπR/3ε_0) - (17ρR/54ε_0) = 17ρR / (54ε_0) E_A / E_B = (ρR/6ε_0) / (17ρR/54ε_0) = (ρR/6ε_0) × (54ε_0/17ρR) = 54/(6×17) = 54/102 = 9/17 Correct ans. is 18/34
