If the solution curve y = y(x) of the differential equation (1 + y^2)(1 + log x) dx + x dy = 0, x > 0 passes through the point (1, 1) and y(e) = (α - tan(3/2))/(β + tan(3/2)), then α + 2β is.

Answer

Correct answer: 3

Solution

Starting with (1 + y^2)(1 + log x) dx + x dy = 0, separate into integrals: ∫((1 + log x)/x) dx + ∫(dy/(1 + y^2)) = 0. Substitute t = 1 + log x, so (1/x) dx = dt. This gives ∫t dt + tan^(-1) y + C = 0, or (1 + log x)^2/2 + tan^(-1) y + C = 0. Using the condition y(1) = 1: 1/2 + π/4 + C = 0, so C = -1/2 - π/4. The solution is (1 + log x)^2/2 = -tan^(-1) y + 1/2 + π/2. At x = e: 4 = -2tan^(-1)(y(e)) + 1 + π/2, giving tan^(-1)(y(e)) = π/4 - 3/2. Using the tangent subtraction formula: y(e) = (1 - tan(3/2))/(1 + tan(3/2)). Comparing with (α - tan(3/2))/(β + tan(3/2)): α = 1 and β = 1, therefore α + 2β = 3.
