Let S be the reflection of a point Q with respect to the plane given by r = -(t + p)i + tj + (1 + p)k where t, p are real parameters and i, j, k are the unit vectors along the three positive coordinate axes. If the position vectors of Q and S are 10i + 15j + 20k and αi + βj + γk respectively, then which of the following is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) 3(α + β) = -101
  2. (B) 3(β + γ) = -71
  3. (C) 3(γ + α) = -86
  4. (D) 3(α + β + γ) = -121

Answer

Correct answer: ABC

Solution

A, B, C Clearly plane is given by x + y + z = 1 using mirror image formula ⟹ (α-10)/1 = (β-15)/1 = (γ-20)/1 = -2(10+15+20-1)/(1² + 1² + 1²) = -88/3 ⟹ α = -58/3, β = -43/3 and γ = -28/3
