A volume of x mL of 5M NaHCO3 solution was mixed with 10 mL of 2M H2CO3 solution to make an electrolytic buffer. If the same buffer was used in the following electrochemical cell to record a cell potential of 235.3 mV, then the value of x = ____ mL (nearest integer). Sn(s)|Sn(OH)2^2-(0.5M)|HSnO2^-(0.05M)|OH^-|BiO3^-|Bi(s) Consider up to one place of decimal for intermediate calculations Given: E°[Sn(OH)2^2-]/HSnO2^- = -0.9 V E°Bi2O3/Bi = -0.44 V pKa(H2CO3) = 6.11 2.303RT/F = 0.059 V Anti log(1.29) = 19.5

Answer

Correct answer: 78

Solution

We have considered E°[Sn(OH)2^2-]/HSnO2^- = -0.9 V Pt|HSnO2^-(aq),[Sn(OH)2^2-](aq),OH^-(aq)|BiO3^-(s)|Bi(s)| 0.5M 0.05M E°cell = +0.9 - 0.44 = 0.46 V Oxidation Half: HSnO2^- + H2O + 3OH^- → [Sn(OH)2^2-]^+ + 2e^- Reduction Half: BiO3^- + 3H2O + 6e^- → 2Bi + 6OH^- 3HSnO2^-(aq) + BiO3^-(s) + 6H2O + 3OH^-(aq) → 3[Sn(OH)2^2-](aq) + 2Bi(s) Ecell = E°cell - (0.059/6)log[(0.5)^3/((0.05)^3 × [OH^-]^3)] 0.2353 = 0.46 - (0.059/6) × 3log[10/[OH^-]] log[10/[OH^-]] = (2 × 0.2247)/0.059 = 7.6 1 + pOH = 7.6 pOH = 6.6 pH = 14 - 6.6 = 7.4 Using Henderson-Hasselbalch equation: pH = pKa + log([HCO3^-]/[H2CO3]) 7.4 = 6.11 + log(5x/20) 1.29 = log(5x/4) 5x/4 = 19.5 x = 78
