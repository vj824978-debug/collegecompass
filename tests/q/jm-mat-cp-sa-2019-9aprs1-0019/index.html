If one end of a focal chord of the parabola, y^2 = 16x is at (1, 4), then the length of this focal chord is:

  1. (1) 24
  2. (2) 20
  3. (3) 25
  4. (4) 22

Answer

Correct answer: Option 3

Solution

Parabola y^2 = 16x {4a = 16 => a = 4} For a parabola y^2 = 4ax, a point on the parabola can be written as P(at^2, 2at) One end (at^2, 2at) = (1, 4) => at^2 = 1 => 2at = 4 => 2(4)t = 4 => t = 1/2 For a focal chord, if one end corresponds to parameter t, the other end corresponds to parameter -1/t. Length of focal chord = a(t + 1/t)^2 = 4(1/2 + 2)^2 = 4(5/2)^2 = 4(25/4) = 25 Ans.
