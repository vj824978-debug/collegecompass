Let S be the set of all non-zero real numbers α such that the quadratic equation αx² - x + α = 0 has two distinct real roots x₁ and x₂ satisfying the inequality |x₁ - x₂| < 1. Which of the following intervals is(are) a subset(s) of S?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (-1/2, -1/√5)
  2. (B) (-1/√5, 0)
  3. (C) (0, 1/√5)
  4. (D) (1/√5, 1/2)

Answer

Correct answer: AD

Solution

Here, 0 < (x₁ - x₂)² < 1 ⇒ 0 < (x₁ + x₂)² - 4x₁x₂ < 1 ⇒ 0 < 1/a² - 4 < 1 ⇒ a ∈ (-1/2, -1/√5) ∪ (1/√5, 1/2) [A horizontal line segment with tick marks at π, 3π, 3π, 5π on a number line]
