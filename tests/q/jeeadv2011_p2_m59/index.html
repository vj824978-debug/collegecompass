Match the statements given in Column I with the values given in Column II (A) If a = i + sqrt(3)k, b = -i + sqrt(3)k and c = 2*sqrt(3)k form a triangle, then the internal angle of the triangle between a and b is (B) If integral from a to b of (f(x) - 3x) dx = a^2 - b^2, then the value of f(pi/6) is (C) The value of (pi^2)/(ln 3) * integral from pi/6 to 5*pi/6 of sec(pi*x) dx is (D) The maximum value of |Arg(1/(1-z))| for |z| = 1, z ≠ 1 is given by Column II options: (p) pi/6, (q) 2*pi/3, (r) pi/3, (s) pi, (t) pi/2

Matrix match · Marks: +4 / -1.0

  1. (A) (A) → (r) ( (B) → (q) (C) → (p) (D) → (s)
  2. (B) (A) → (q) ( (B) → (p) (C) → (s) (D) → (t)
  3. (C) (A) → (q) ( (B) → (r) (C) → (p) (D) → (t)
  4. (D) (A) → (r) ( (B) → (p) (C) → (q) (D) → (s)

Answer

Correct answer: B

Solution

Sol. (A). a⃗ - b⃗ = -1 + 3 = 2 |a⃗| = 2, |b⃗| = 2 cosθ = 2/(2·2) = 1/2 θ = π/3, 2π/3 but its 2π/3 as its opposite to side of maximum length. (B). ∫[a to b](f(x) - 3x)dx = a² - b² ∫[a to b]f(x)dx = (3/2)(b² - a²) + a² - b² = -a² + b²)/2 ⇒ f(x) = x. (C). (π²/ln 3)(ln|sec πx + tan πx||[5/6 to 7/6])/π = (π/ln 3)(ln|sec(5π/6) + tan(5π/6)| - ln|sec(7π/6) + tan(7π/6)|) = π. (D). Let u = 1/(1-z) ⇒ z = 1 - 1/u |z| = 1 ⇒ |1 - 1/u| = 1 ⇒ |u - 1| = |u| ∴ locus of u is perpendicular bisector of line segment joining 0 and 1 ⇒ maximum arg u approaches π/2 but will not attain.
