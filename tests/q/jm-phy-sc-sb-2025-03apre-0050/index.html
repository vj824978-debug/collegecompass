An electron in the hydrogen atom initially in the fourth excited state makes a transition to n^th energy state by emitting a photon of energy 2.86 eV. The integer value of n will be ______.

Answer

Correct answer: 2

Solution

Initial state: n_i = 4 (fourth excited state). Energy of hydrogen atom: E_n = -13.6/n^2 eV. Energy of photon emitted: E_photon = E_i - E_f = 2.86 eV. Therefore: -13.6/16 - (-13.6/n_f^2) = 2.86. This gives: -0.85 + 13.6/n_f^2 = 2.86. So: 13.6/n_f^2 = 3.71. Thus: n_f^2 = 13.6/3.71 ≈ 3.67 ≈ 4. But checking: if n_f = 2, then 13.6/4 = 3.4 eV difference, giving -0.85 + 3.4 = 2.55 eV (close). Recalculating more precisely: E_4 = -0.85 eV, and -0.85 - E_f = -2.86, so E_f = -0.85 + 2.86 = 2.01... Actually: E_photon = |E_4 - E_f| = |-0.85 - (-13.6/n_f^2)| = 2.86. This gives 13.6/n_f^2 = 2.01, so n_f^2 ≈ 6.76, thus n_f = 2.6 ≈ 2 or checking n = 2: 13.6/4 = 3.4, and 3.4 - 0.85 = 2.55 eV. For exact answer n = 2.
