Let S = {z ∈ C: 4z^2 + z = 0}. Then sum of |z|^2 for z ∈ S is equal to:

  1. (1) 3/16
  2. (2) 7/64
  3. (3) 1/16
  4. (4) 5/64

Answer

Correct answer: Option 1

Solution

4z^2 + z = 0 let z = x + iy 4(x + iy)^2 + x - iy = 0 4x^2 - 4y^2 + 8xyi + x - iy = 0 4x^2 - 4y^2 + x = 0 & y(8x - 1) = 0 => y = 0 or x = 1/8 If y = 0, 4x^2 + x = 0 x = 0, -1/4 ∴ z_1 = 0 + 0i, |z_1|^2 = 0 z_2 = -1/4 + 0i, |z_2|^2 = 1/16 If x = 1/8: 4 × 1/64 - 4y^2 + 1/8 = 0 => 4y^2 = 3/16 => y = ± sqrt(3)/8 ∴ z_3 = 1/8 + sqrt(3)/8 i, |z_3|^2 = 1/64 + 3/64 = 1/16 z_4 = 1/8 - sqrt(3)/8 i, |z_4|^2 = 1/64 + 3/64 = 1/16 ∴ sum of |z|^2 = 0 + 1/16 + 1/16 + 1/16 = 3/16
