For a transparent prism, if the angle of minimum deviation is equal to its refracting angle, the refractive index 'n' of the prism satisfies.

  1. (1) sqrt(2) < n < 2*sqrt(2)
  2. (2) 1 < n < 2
  3. (3) n >= 2
  4. (4) sqrt(2) < n < 2

Answer

Correct answer: Option 4

Solution

delta_min = 2i - A => i = delta_min = A Also, mu = sin((delta_min + A)/2) / sin(A/2) => mu = sin(A) / sin(A/2) = 2*cos(A/2) 1 < mu < 2 ...(1) delta_min = 2i - A A = 2i - A => i = A i < 90° (grazing incidence) A < 90° mu = 2*cos(A/2) & A < 90° mu > sqrt(2) ...(2) From (1) & (2) sqrt(2) < mu < 2
