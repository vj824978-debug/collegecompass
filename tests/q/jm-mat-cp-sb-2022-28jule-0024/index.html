If 1 + (2 + 49C1 + 49C2 + ... + 49C49)(50C2 + 50C4 + ... + 50C50) is equal to 2^n, m where m is odd, then n + m is equal to

Answer

Correct answer: 99

Solution

Let I = 1 + (1 + 49C0 + 49C1 + ... + 49C49)(50C2 + 50C4 + ... + 50C50). Since 49C0 + 49C1 + ... + 49C49 = 2^49 and 50C0 + 50C2 + 50C4 + ... + 50C50 = 2^49, we have 50C2 + 50C4 + ... + 50C50 = 2^49 - 1. Therefore I = 1 + (2^49 + 1)(2^49 - 1) = 1 + (2^98 - 1) = 2^98. Thus m = 1 and n = 98, giving m + n = 99.
