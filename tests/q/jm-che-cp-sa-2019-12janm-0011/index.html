For diatomic ideal gas in a closed system, which of the following plots does not correctly describe the relation between various thermodynamic quantities?

  1. (1) Plot (1): C_v vs V (horizontal line)
  2. (2) Plot (2): C_v vs T (curve starting low and leveling off at high temperature)
  3. (3) Plot (3): U vs T (curved line increasing with temperature)
  4. (4) Plot (4): C_p vs P (straight line with positive slope)

Answer

Correct answer: Option 4

Solution

For a diatomic ideal gas in a closed system: Plot (1) C_v vs V: C_v is independent of volume for an ideal gas. For a diatomic gas, C_v = (5/2)R (constant). This plot correctly shows C_v as constant regardless of volume. CORRECT Plot (2) C_v vs T: At low temperatures, vibrational modes are not excited, so C_v ≈ (5/2)R. At very high temperatures, vibrational modes become excited, and C_v increases towards (7/2)R. This S-shaped curve is correct. CORRECT Plot (3) U vs T: For an ideal gas, U = nC_v T. Since C_v varies with temperature (as shown in plot 2), the relationship between U and T is nonlinear, showing a curve as depicted. CORRECT Plot (4) C_p vs P: Using the relation C_p = (7/2)R for a diatomic gas (at moderate temperatures), C_p is independent of pressure P. The plot shows C_p increasing linearly with P, which is INCORRECT. The key insight: C_p = (7/2)R which is independent of P at high temperature (as stated in the solution). The graph shows C_p depending on P with a positive slope, which violates this fundamental property. Therefore, graph number 4 is incorrect.
