Let f(x) be a real differentiable function such that f(0) = 1 and f(x + y) = f(x)f'(y) + f'(x) f(y) for all x, y ∈ ℝ. Then ∑(n=1 to 100) log_e f(n) is equal to :

  1. (1) 2384
  2. (2) 2525
  3. (3) 5220
  4. (4) 2406

Answer

Correct answer: Option 2

Solution

f(x + y) = f(x)f'(y) + f'(x) f(y) Put x = y = 0 f(0) = f(0)f'(0) + f'(0)f(0) 1 = 2f'(0) f'(0) = 1/2 Put y = 0 f(x) = f(x) f'(0) + f'(x)f(0) f(x) = (1/2) f(x) + f'(x) f'(x) = f(x)/2 dy/dx = y/2 ⟹ ∫(dy/y) = ∫(dx/2) ⟹ ℓny = x/2 + c ∴ f(0) = 1 ⟹ C = 0 ℓny = x/2 ⟹ f(x) = e^(x/2) ℓn f(n) = n/2 ∑(n=1 to 100) ℓnf(n) = (1/2) ∑(n=1 to 100) n = (1/2) · (100 · 101)/2 = 5050/2 = 2525
