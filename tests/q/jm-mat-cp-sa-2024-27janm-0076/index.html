Consider the function f(x) = { a(7x - 12 - x²) / (b|x² - 7x + 12|), x < 3; sin(x - 3) / (2^(x - [x])), x > 3; b, x = 3 } Where [x] denotes greatest integer less than or equal to, if S denotes the set of all ordered pairs (a, b) such that f(x) is continuous at x = 3, then the number of elements in S is:

  1. (1) Infinitely many
  2. (2) 2
  3. (3) 1
  4. (4) 4

Answer

Correct answer: Option 3

Solution

For continuity at x = 3: f(3) = f(3⁻) = f(3⁺). From f(3⁺): b = lim(x→3⁺) 2^(sin(x-3)/(x-[x])) = 2^(lim sin(x-3)/(x-[x])) = 2¹ = 2 using standard limit. For x < 3: (7x - 12 - x²) = -(x² - 7x + 12) = -(x-3)(x-4), which is positive for 3 < x < 4 (near x=3 from left). Thus |x² - 7x + 12| opens positive. lim(x→3⁻) a(7x - 12 - x²)/(b(x² - 7x + 12)) = lim(x→3⁻) (-a)/b = 2. So -a = 2b = 4, giving a = -4, b = 2. Therefore (a,b) = (-4, 2), only 1 ordered pair.
