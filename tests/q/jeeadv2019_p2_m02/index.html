Let x ∈ ℝ and let P = [1 1 1; 0 2 2; 0 0 3], Q = [2 x x; 0 4 0; x x 6], and R = PQP^(-1). Then which of the following options is/are correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) For x = 0, if R [1; a; b] = 6 [1; a; b], then a + b = 5
  2. (B) For x = 1, there exists a unit vector αi + βj + γk for which R [α; β; γ] = [0; 0; 0]
  3. (C) det R = det [2 x x; 0 4 0; x x 5] + 8, for all x ∈ ℝ
  4. (D) There exists a real number x such that PQ = QP

Answer

Correct answer: AC
