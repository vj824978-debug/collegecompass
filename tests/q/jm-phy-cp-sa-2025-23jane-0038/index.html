The width of one of the two slits in Young's double slit experiment is d while that of the other slit is xd. If the ratio of the maximum to the minimum intensity in the interference pattern on the screen is 9 : 4 then what is the value of x? (Assume that the field strength varies according to the slit width.)

  1. (1) 2
  2. (2) 3
  3. (3) 5
  4. (4) 4

Answer

Correct answer: Option 3

Solution

I ∝ (width)^2 Let I1 ∝ d^2 and I2 ∝ (xd)^2 So sqrt(I1) ∝ d and sqrt(I2) ∝ xd For constructive interference (maximum intensity): I_max = (sqrt(I1) + sqrt(I2))^2 For destructive interference (minimum intensity): I_min = (sqrt(I1) - sqrt(I2))^2 Given: I_max/I_min = 9/4 (sqrt(I1) + sqrt(I2))^2 / (sqrt(I1) - sqrt(I2))^2 = 9/4 (sqrt(I1) + sqrt(I2)) / (sqrt(I1) - sqrt(I2)) = 3/2 Substituting sqrt(I1) ∝ d and sqrt(I2) ∝ xd: (d + xd) / (d - xd) = 3/2 (1 + x) / (1 - x) = 3/2 2(1 + x) = 3(1 - x) 2 + 2x = 3 - 3x 5x = 1 Wait, let me recalculate: (x + 1)d / (x - 1)d = 3/2 (x + 1) / (x - 1) = 3/2 2(x + 1) = 3(x - 1) 2x + 2 = 3x - 3 2 + 3 = 3x - 2x 5 = x Therefore x = 5
