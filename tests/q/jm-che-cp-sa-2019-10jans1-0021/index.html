Which is the most suitable reagent for the following transformation? CH3 - CH = CH - CH2 - CH(OH) - CH2 → CH3 - CH = CH - CH2CO2H

  1. (1) alkaline KMnO4
  2. (2) Tollen's neagent
  3. (3) I2/NaOH
  4. (4) CrO2Cl2/CS2

Answer

Correct answer: Option 3

Solution

The starting material is CH3-CH=CH-CH2-CH(OH)-CH2 with a secondary alcohol group. The product is CH3-CH=CH-CH2CO2H, a carboxylic acid. Analysis of each reagent: (1) Alkaline KMnO4: This is a strong oxidizing agent that would oxidize the C=C double bond as well as the alcohol group, leading to multiple oxidation products. Not suitable. (2) Tollen's reagent: This oxidizes aldehydes to carboxylic acids, but the starting material contains a secondary alcohol (not an aldehyde), so Tollen's reagent would not be suitable. (3) I2/NaOH (Iodoform reaction): First step: I2/NaOH oxidizes the secondary alcohol (-CH(OH)-CH2) to a ketone (-CO-CH2). Second step: The ketone undergoes iodoform reaction (I2/NaOH with basic conditions). The methyl ketone structure (CH3-CO-) undergoes cleavage, producing the carboxylate ion (CH3-CH=CH-CH2-COONa) and CHI3 (iodoform). Third step: Acidification (H+) converts the carboxylate to carboxylic acid CH3-CH=CH-CH2-CO2H. The sequence shown in the Sol. confirms this mechanism. (4) CrO2Cl2/CS2: This is a mild oxidizing agent primarily for alcohols to aldehydes/ketones, but would not convert to carboxylic acid efficiently. The answer is I2/NaOH (iodoform reaction), which oxidizes the secondary alcohol to a ketone, then cleaves the methyl ketone to form a carboxylic acid.
