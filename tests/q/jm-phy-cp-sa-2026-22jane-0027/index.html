Using a simple pendulum experiment g is determined by measuring its time period T. Which of the following plots represent the correct relation between the pendulum length L and time period T?

  1. (1) Plot (1): 1/T^2 vs L showing decreasing curve
  2. (2) Plot (2): 1/T^2 vs L showing decreasing curve
  3. (3) Plot (3): 1/T^2 vs L showing increasing curve
  4. (4) Plot (4): 1/T^2 vs L showing linear decreasing relation

Answer

Correct answer: Option 2

Solution

For a simple pendulum, the time period is given by: T = 2*pi*sqrt(L/g) Squaring both sides: T^2 = (4*pi^2*L)/g Taking reciprocal: 1/T^2 = g/(4*pi^2*L) This can be written as: 1/T^2 = (g/(4*pi^2)) * (1/L) This is a linear relationship of the form y = k*x where: - y = 1/T^2 - x = 1/L - k = g/(4*pi^2) (constant) Wait, the question asks about 1/T^2 vs L (not 1/L). From 1/T^2 = g/(4*pi^2*L), we can write: 1/T^2 is inversely proportional to L Therefore, as L increases, 1/T^2 decreases in a hyperbolic manner (1/L type curve). The correct plot should show 1/T^2 decreasing as L increases, with a hyperbolic curve that is steeper at smaller L values and flattens out at larger L values. Plot (2) shows this behavior: a decreasing hyperbolic curve where 1/T^2 decreases as L increases.
