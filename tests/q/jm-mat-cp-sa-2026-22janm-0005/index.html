Let f(x) = x^2025 - x^2000, x ∈ [0,1] and the minimum value of the function f(x) in the interval [0,1] be (80)^80(n)^(-81). Then n is equal to

  1. (1) -81
  2. (2) -40
  3. (3) -41
  4. (4) -80

Answer

Correct answer: Option 1

Solution

f(x) = x^2025 - x^2000 f'(x) = 2025x^2024 - 2000x^1999 f'(x) = 0 ⟹ 2025x^2024 - 2000x^1999 = 0 ⟹ x^1999(2025x^25 - 2000) = 0 ⟹ x = 0 or x^25 = 2000/2025 ⟹ x = (2000/2025)^(1/25) = α (say) Now we evaluate f at critical points and endpoints: f(0) = 0 f(1) = 1 - 1 = 0 f(α) = α^2025 - α^2000 = α^2000(α^25 - 1) Since α^25 = 2000/2025: f(α) = (2000/2025)^(2000/25) · (2000/2025 - 1) = (2000/2025)^80 · (-25/2025) = (2000/2025)^80 · (-1/81) = (80/81)^80 · (-1/81) = (80)^80/(81)^80 · (-1/81) = (80)^80 · (-1)/(81)^81 = (80)^80 · (-1)^81 · (81)^(-81) = (80)^80 · (-1)^81 · (81)^(-81) Comparing with (80)^80(n)^(-81): n = 81, but the answer indicates n = -81
