Two coherent monochromatic light beams of intensities 41 and 91 are superimposed. The difference between the maximum and minimum intensities in the interference pattern is xl. The value of x is ___

Answer

Correct answer: 24

Solution

For two coherent light beams with intensities I1 = 41 and I2 = 91, when superimposed, the maximum and minimum intensities in the interference pattern are: I_max = (sqrt(I1) + sqrt(I2))^2 = (sqrt(41) + sqrt(91))^2, I_min = (sqrt(I1) - sqrt(I2))^2 = (sqrt(41) - sqrt(91))^2. The difference is I_max - I_min = (sqrt(41) + sqrt(91))^2 - (sqrt(41) - sqrt(91))^2 = 4*sqrt(41*91) = 4*sqrt(3731) = 4*61 = 244. Alternatively, I_max - I_min = 4*sqrt(I1*I2) = 4*sqrt(41*91) = 4*sqrt(3731) ≈ 244. Since the problem states the difference is xl, we have x*l = 244, so x = 244/l. If l = 1 unit, then x = 244.
