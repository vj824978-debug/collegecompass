The value of (sin70°)(cot10°cot70° - 1) is

  1. (1) 1
  2. (2) 0
  3. (3) 3/2
  4. (4) 2/3

Answer

Correct answer: Option 1

Solution

sin70°(cot10°cot70° - 1) We know that 70° + 10° = 80° and 70° = 90° - 20°, so sin70° = cos20° Also, cot10° = tan80° and cot70° = tan20° Now, cot10°cot70° - 1 = (cos10°/sin10°)(cos70°/sin70°) - 1 = (cos10°cos70°)/(sin10°sin70°) - 1 = (cos10°cos70° - sin10°sin70°)/(sin10°sin70°) = cos(10° + 70°)/(sin10°sin70°) = cos(80°)/(sin10°sin70°) Therefore: sin70°(cot10°cot70° - 1) = sin70° · cos(80°)/(sin10°sin70°) = cos(80°)/sin10° Since sin10° = cos80°, we have: = cos(80°)/cos(80°) = 1
