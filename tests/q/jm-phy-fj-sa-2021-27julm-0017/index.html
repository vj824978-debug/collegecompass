A ball is thrown up with a certain velocity so that it reaches a height 'h'. Find the ratio of the two different times of the ball reaching h/3 in both the directions.

  1. (1) (sqrt(2) - 1) / (sqrt(2) + 1)
  2. (2) (sqrt(3) - sqrt(2)) / (sqrt(3) + sqrt(2))
  3. (3) (sqrt(3) - 1) / (sqrt(3) + 1)
  4. (4) 1/3

Answer

Correct answer: Option 2

Solution

Given: h = u^2/(2g), u = sqrt(2gh). Ball reaches height h/3. Using S = ut + (1/2)at^2, we get h/3 = sqrt(2gh)t - (1/2)gt^2. Solving: 0 = t((9/2) - sqrt(2gh) + h/3). This gives two times t1 and t2. From the quadratic equation: t1 = (sqrt(2gh) - sqrt(4gh/3)) / g and t2 = (sqrt(2gh) + sqrt(4gh/3)) / g. Therefore, t1/t2 = (sqrt(2gh) - sqrt(4gh/3)) / (sqrt(2gh) + sqrt(4gh/3)) = (sqrt(3) - sqrt(2)) / (sqrt(3) + sqrt(2)).
