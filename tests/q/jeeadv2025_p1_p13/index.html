Consider an electron in the n = 3 orbit of a hydrogen-like atom with atomic number Z. At absolute temperature T, a neutron having thermal energy k_B T has the same de Broglie wavelength as that of this electron. If this temperature is given by T = z²h²/(πα²a₀²m_n k_B), (where h is the Planck's constant, k_B is the Boltzmann constant, m_n is the mass of the neutron and a₀ is the first Bohr radius of hydrogen atom) then the value of α is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 72

Solution

λₙ = λₑ ⟹ h/√(2mkₙ) = h/(mₑv) h/√(2mₙkᵦT) = h/(mₑv) ⟹ (mₑv) = √(2mₙkᵦT) ...(i) (mₑv)r = nh/(2π) ...(ii) Solving Equation (ii) and (i) r = (nh/2π)/√(2mₙkᵦT) r² = n²h²/(4π²) × 1/(2mₙkᵦT) ⟹ T = n²h²/(8π²mₙkᵦr²) and r = a₀ n²/z T = n²h²/(8π²mₙkᵦ) × z²/(a₀²n⁴) ⟹ T = z²h²/(8π²mₙkᵦa₀²n²) n = 3 T = z²h²/(72π²mₙkᵦa₀²)
