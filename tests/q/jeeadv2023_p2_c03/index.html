In the following reactions, P, Q, R, and S are the major products. [Starting material: (CH3)2CHCH2Cl] (i) Mg, dry ether (ii) H2O → P [Starting material: (CH3)2CHCH2Cl] (i) Mg, dry ether (ii) CO2, dry ether (iii) H3O+ (iv) NaOH → Q [Starting material: (CH3)2CHCH2Cl] (i) Mg, dry ether (ii) CH3CHO, then H2O (iii) CrO3 → R [Starting material: (CH3)2CHCH2Cl] (i) ethanolic NaCN (ii) H2/ Ni (iii) CHCl3/KOH, Δ (iv) LiAlH4, then H2O → S The correct statement about P, Q, R, and S is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) P is a primary alcohol with four carbons.
  2. (B) Q undergoes Kolbe's electrolysis to give an eight-carbon product.
  3. (C) R has six carbons and it undergoes Cannizzaro reaction.
  4. (D) S is a primary amine with six carbons.

Answer

Correct answer: B

Solution

Sol. B [isobutyl group with CH₂Cl] undergoes the following transformations: 1. Top pathway: B + Mg/dry ether → Grignard intermediate (CH₂MgCl) + H₂O → P [isobutyl-CH₃] 2. Middle-upper pathway: B + Mg/dry ether → CH₂MgCl + CO₂ → [magnesium carboxylate intermediate] + H₃O⁺ → [carboxylic acid intermediate] + NaOH → Q [isobutyl-COONa⁺] 3. Middle-lower pathway: B + Mg/dry ether → CH₂MgCl + CH₃CHO → [alkoxide intermediate] + H₂O → [secondary alcohol] + CrO₃ → R [isobutyl ketone with C=O] 4. Bottom pathway: B + Ethanolic NaCN → [nitrile intermediate CN] + H₂/Ni → [amine NH₂] + CHCl₃/KOH → [isocyanide intermediate NC] + (i) LiAlH₄ (ii) H₂O → S [isobutyl group with CH₂NHCH₃] Each pathway demonstrates different Grignard reactions: hydrolysis, carboxylation, aldehyde addition, and nucleophilic substitution followed by reduction.
