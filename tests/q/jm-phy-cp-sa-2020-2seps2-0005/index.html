A heat engine is involved with exchange of heat of 1915 J, -40 J, +125 J and QJ, during one cycle achieving an efficiency of 50.0%. The value of Q is:

  1. (1) 640 J
  2. (2) 400 J
  3. (3) 980 J
  4. (4) 40 J

Answer

Correct answer: Option 3

Solution

eta = Work done / Heat supplied 0.5 = eta = (1915 - 40 + 125 - Q)/(1915 + 125) 0.5 = (2000 - Q)/2040 2040 × 0.5 = 2000 - Q 1020 = 2000 - Q 2040 = 4000 - 2Q 2Q = 1960 Q = 980 J
