Which of the following is the only CORRECT combination?

Matrix match · Marks: +4 / -1.0

Passage:

  1. (A) (II), (R), (S)
  2. (B) (I), (Q), (U)
  3. (C) (II), (Q), (T)
  4. (D) (I), (P), (R)

Answer

Correct answer: C

Solution

Sol. 1. C f(x) = 0 ⟹ sin(π cosx) = 0 ⟹ π cosx = n₁π, n₁ ∈ I ⟹ cosx = -1, cosx = 0, cosx = 1 ⟹ x = n₂π/2, n₂ ∈ I ⟹ X = {π/2, π, 3π/2, 2π, .....} f'(x) = 0 ⟹ -cos(π cosx) π sinx = 0 ⟹ sinx = 0 or cos(π cosx) = 0 ⟹ x = n₃π or π cosx = (2x₄ + 1)π/2 ⟹ cosx = -1/2, 1/2 ⟹ x = n₅π ± π/3 Y = {π/3, 2π/3, 3π/3, 4π/3, 5π/3, 6π/3, .....} g(x) = 0 ⟹ cos(2π sinx) = 0 ⟹ 2π sinx = (2n₆ + 1)π/2 ⟹ sinx = (2n₆ + 1)/4 = -3/4, -1/4, 1/4, 3/4 ⟹ Z = {x | sinx = ±1/4, ±3/4, x > 0} g'(x) = 0 ⟹ -2π cosx sin(2π sinx) = 0 cosx = 0 or sin(2π sinx) = 0 ⟹ x = (2n₇ + 1)π/2 or 2π sinx = n₈π ⟹ sinx = -1, -1/2, 0, 1/2, 1 W = {x | sinx = ±1, ±1/2, 0, x > 0} ⟹ I - (P), (Q) II - (Q), (T) III - (R) IV - (P), (R), (S)
