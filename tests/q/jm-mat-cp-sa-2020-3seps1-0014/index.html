The foot of the perpendicular drawn from the point (4, 2, 3) to the line joining the points (1, -2, 3) and (1, 1, 0) lies on the plane.

  1. (1) x + 2y - z = 1
  2. (2) x - y - 2z = 1
  3. (3) x - 2y + z = 1
  4. (4) 2x + y - z = 1

Answer

Correct answer: Option 4

Solution

Equation of AB: vector r = (i + j) + lambda(3j - 3k) Let coordinates of M = (1, (1 + 3lambda), -3lambda), vector PM = -3i + (3lambda - 1)j - 3(lambda + 1)k vector AB = 3j - 3k Since PM is perpendicular to AB: vector PM · vector AB = 0 => 3(3lambda - 1) + 9(lambda + 1) = 0 => 9lambda - 3 + 9lambda + 9 = 0 => 18lambda + 6 = 0 => lambda = -1/3 Therefore M = (1, 0, 1) Clearly M lies on 2x + y - z = 1. Verification: 2(1) + 0 - 1 = 2 - 1 = 1 ✓
