For non-negative integers n, let f(n) = [sum_{k=0}^{n} sin((k+1)/(n+2) * pi) * sin((k+2)/(n+2) * pi)] / [sum_{k=0}^{n} sin^2((k+1)/(n+2) * pi)] Assuming cos^(-1) takes values in [0, pi], which of the following options is/are correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) f(4) = sqrt(3)/2
  2. (B) If alpha = tan(cos^(-1)(f(6))), then alpha^2 + 2*alpha - 1 = 0
  3. (C) sin(7 * cos^(-1)(f(5))) = 0
  4. (D) lim_{n->infinity} f(n) = 1/2

Answer

Correct answer: ABC

Solution

f(x) = Σ(k=0 to n) 2sin((k+1)/(n+2)π)sin((k+2)/(n+2)π) / Σ(k=0 to n) 2sin²((k+1)/(n+2)π) = [Σ(k=0 to n) cos(π/(n+2)) - Σ(k=0 to n) cos((2k+3)/(n+2)π)] / [Σ(k=0 to n) (1-cos((2k+2)/(n+2)π))] = [(n+1)cos(π/(n+2)) - cos((n+3)/(n+2)π)sin((n+1)/(n+2)π)/sin(π/(n+2))] / [(n+1) - cos(π)sin((n+1)/(n+2)π)/sin(π/(n+2))] = [(n+1)cos(π/(n+2)) - cos(π + π/(n+2))sin(π - π/(n+2))/sin(π/(n+2))] / [(n+1) - cos(π)sin(π - π/(n+2))/sin(π/(n+2))] = [(n+1)cos(π/(n+2)) + cos(π/(n+2))] / (n+1+1) = (n+2)cos(π/(n+2)) / (n+2) = cos(π/(n+2)) (A) f(4) = cos(π/(4+2)) = cos(π/6) = √3/2 (B) α = tan(cos⁻¹(cos(π/8))) = tan(π/8) tan(π/4) = 2tan(π/8)/(1-tan²(π/8)) ⟹ 1 = 2α/(1-α²) ⟹ α² + 2α - 1 = 0 (C) sin(7cos⁻¹(cos(π/7))) = sin(7 × π/7) = sin(π) = 0 (D) lim(n→∞) f(n) = lim(n→∞) cos(π/(n+2)) = cos(0) = 1
