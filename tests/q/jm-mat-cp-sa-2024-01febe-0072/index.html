Consider the relations R1 and R2 defined as aR1b ↔ a² + b² = 1 for all a, b ∈ ℝ and (a, b) R2 (c, d) ↔ a + d = b + c for all (a, b), (c, d) ∈ ℕ × ℕ. Then:

  1. (1) Neither R1 nor R2 is an equivalence relation
  2. (2) Only R2 is an equivalence relation
  3. (3) R1 and R2 both are equivalence relations
  4. (4) Only R1 is an equivalence relation

Answer

Correct answer: Option 2

Solution

For R1: aR1b ↔ a² + b² = 1. For reflexive property, if aR1a then a² + a² = 1, so 2a² = 1, giving a = ±1/sqrt(2). This is not true for all a ∈ ℝ, so R1 is not reflexive. Therefore R1 is not an equivalence relation. For R2: (a,b)R2(c,d) ↔ a + d = b + c. Reflexive: (a,b)R2(a,b) ⟹ a + b = b + a ✓. Symmetric: if (a,b)R2(c,d) then a + d = b + c ⟹ c + b = d + a ⟹ (c,d)R2(a,b) ✓. Transitive: if (a,b)R2(c,d) and (c,d)R2(e,f) then a + d = b + c and c + f = d + e. Adding: a + d + c + f = b + c + d + e ⟹ a + f = b + e ⟹ (a,b)R2(e,f) ✓. So R2 is an equivalence relation.
