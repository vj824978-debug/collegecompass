Q.20 Match List I with List II List I (Current configuration): A. A loop with current I on both sides, labeled with distance l on each side B. A loop with current I on left side, point O marked at distance r below the loop, with current continuing right C. A loop with current I on top, point O marked at distance r below the loop, with current continuing left D. A configuration with current I flowing left, then down and right in a semicircular arc, then right List II (Magnitude of Magnetic Field at point O): I. B_0 = (mu_0 * I)/(4*pi) * [pi + 2] II. B_0 = (mu_0 * I)/(4*r) III. B_0 = (mu_0 * I)/(2*pi) * [pi - 1] IV. B_0 = (mu_0 * I)/(4*pi) * [pi + 1]

  1. (1) A-III, B-IV, C-I, D-II
  2. (2) A-I, B-III, C-IV, D-II
  3. (3) A-III, B-I, C-IV, D-II
  4. (4) A-I, B-I, C-IV, D-III

Answer

Correct answer: Option 3

Solution

Sol. A → B_0 = (mu_0*I)/(4*pi*r) + (mu_0*I)/(2*r) - (mu_0*I)/(4*pi*r) B_0 = (mu_0*I)/(2*pi) * (pi - 1) → A → III B → B_0 = (mu_0*I)/(4*pi*r) + (mu_0*I)/(4*r) + (mu_0*I)/(4*pi*r) B_0 = (mu_0*I)/(4*pi*r) * (pi + 2) → B → I C → B_0 = (mu_0*I)/(4*pi*r) + (mu_0*I)/(4*r) + 0 B_0 = (mu_0*I)/(4*pi*r) * (pi + 1) → C → IV D → B_0 = (mu_0*I)/(4*r) → D → II
