The number of arrangements of the letters of the word INDEPENDENCE in which all the vowels always occur together is -

  1. (1) 16800
  2. (2) 33600
  3. (3) 18000
  4. (4) 14800

Answer

Correct answer: Option 1

Solution

Vowels: I, E, E, E (4 vowels with E repeated 3 times). Consonants: N, N, D, D, P, C (6 consonants with N and D each repeated twice). Treat all vowels as one unit: [IEEE], 3N, 2D, P, C. This gives 8 objects with 3N repeated and 2D repeated. Arrangements = 8!/(3!×2!) = 40320/12 = 3360. Within the vowel block, arrange 4 vowels (I, E, E, E): 4!/3! = 4. Total arrangements = 3360 × 5 = 16800
