Let f(x) be a polynomial of degree 3 such that f(-1) = 10, f(1) = -6, f(x) has a critical point at x = -1 and f'(x) has a critical point at x = 1. Then f(x) has a local minima at x = _______.

Answer

Correct answer: 3

Solution

Since f(x) is a polynomial of degree 3, f'(x) is of degree 2. Given that f(x) has a critical point at x = -1, we have f'(-1) = 0. Given that f'(x) has a critical point at x = 1, we have f''(1) = 0. Since f''(x) = a(x - 1) for some constant a (as f'(x) is degree 2, so f''(x) is degree 1). Integrating: f'(x) = a(x^2/2 - x) + b From f'(-1) = 0: a(1/2 + 1) + b = 0 3a/2 + b = 0 b = -3a/2 Therefore: f'(x) = a(x^2/2 - x - 3/2) = (a/2)(x^2 - 2x - 3) = (a/2)(x + 1)(x - 3) The critical points of f(x) are at x = -1 and x = 3. To determine which is a local minima, examine the sign of f'(x): - For x < -1: f'(x) = (a/2)(negative)(negative) = (a/2)(positive), sign depends on a - For -1 < x < 3: f'(x) = (a/2)(positive)(negative) = (a/2)(negative), opposite sign - For x > 3: f'(x) = (a/2)(positive)(positive) = (a/2)(positive), same as x < -1 From the diagram shown, which displays the behavior of f(x), we can see that a < 0. With a < 0: - f'(x) < 0 for x < -1 (decreasing) - f'(x) > 0 for -1 < x < 3 (increasing) - f'(x) < 0 for x > 3 (decreasing) Therefore, x = -1 is a local maximum and x = 3 is a local minimum. So local minima is at x = 3
