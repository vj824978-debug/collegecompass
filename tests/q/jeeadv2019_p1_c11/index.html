A tin chloride Q undergoes the following reactions (not balanced) Q + Cl⁻ ⟶ X Q + Me₃N ⟶ Y Q + CuCl₂ ⟶ Z + CuCl X is a monoanion having pyramidal geometry. Both Y and Z are neutral compounds. Choose the correct option(s)

Multiple correct (MSQ) · Marks: +4 / -1.0

  1. (A) The central atom in Z has one lone pair of electrons
  2. (B) The central atom in X is sp³ hybridized
  3. (C) There is a coordinate bond in Y
  4. (D) The oxidation state of the central atom in Z is +2

Answer

Correct answer: BC

Solution

SnCl₂ + Cl⁻ ⟶ SnCl₃⁻ (Q) (X) SnCl₂ + Me₃N ⟶ SnCl₂·[N(CH₃)₃] (Q) (Y) SnCl₂ + 2CuCl₅ ⟶ SnCl₄ + CuCl (Q) (Z)
