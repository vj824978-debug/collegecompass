If integral from 0 to 1 of (x^21 + x^14 + x^7)(2x^14 + 3x^7 + 6)^(1/7) dx = (1/l)(11)^(m/n) where l, m, n ∈ N, m and n are coprime then l + m + n is equal to ___

Answer

Correct answer: 63

Solution

l = integral from 0 to 1 of (x^21 + x^14 + x^7)(2x^14 + 3x^7 + 6)^(1/7) dx l = integral from 0 to 1 of (x^20 + x^13 + x^6)(2x^21 + 3x^14 + 6x^7)^(1/7) dx Let 2x^21 + 3x^14 + 6x^7 = t ⟹ 42(x^20 + x^13 + x^6) dx = dt l = (1/42) integral from 0 to 11 of t^(1/7) dt = (1/42) × (7/8)[t^(8/7)] from 0 to 11 = (1/48) × 11^(8/7) ∴ l = 48, m = 8, n = 7 ∴ l + m + n = 63
