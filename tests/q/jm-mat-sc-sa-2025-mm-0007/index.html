If lim(x→1) [(x-1)(6 + λcos(x-1)) + μsin(1-x)] / (x-1)³ = -1, where λ, μ ∈ ℝ, then λ + μ is equal to

  1. (1) 17
  2. (2) 20
  3. (3) 18
  4. (4) 19

Answer

Correct answer: Option 3

Solution

Let u = x - 1, so as x → 1, u → 0. The limit becomes: lim(u→0) [u(6 + λcos(u)) + μsin(-u)] / u³ = lim(u→0) [u(6 + λcos(u)) - μsin(u)] / u³. Expanding: cos(u) = 1 - u²/2 + u⁴/24 - ..., sin(u) = u - u³/6 + ... Numerator = u(6 + λ(1 - u²/2 + ...)) - μ(u - u³/6 + ...) = 6u + λu - λu³/2 - μu + μu³/6 + ... = (6 + λ - μ)u + (-λ/2 + μ/6)u³ + ... For the limit to equal -1, the coefficient of u must be 0: 6 + λ - μ = 0, so λ - μ = -6. The u³ term gives: (-λ/2 + μ/6)/1 = -1, so -λ/2 + μ/6 = -1, or -3λ + μ = -6. From λ - μ = -6: λ = μ - 6. Substituting: -3(μ - 6) + μ = -6, so -3μ + 18 + μ = -6, giving -2μ = -24, so μ = 12. Then λ = 6. Therefore λ + μ = 18.
