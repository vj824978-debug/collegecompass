If the set of all a ∈ R, for which the equation 2x^2 + (a - 5)x + 15 = 3a has no real root, is the interval (α, β), and X = {x ∈ Z : α < x < β}, then ∑(x∈X) x^2 is equal to

  1. (1) 2109
  2. (2) 2129
  3. (3) 2139
  4. (4) 2119

Answer

Correct answer: Option 3

Solution

(a - 5)^2 - 8(15 - 3a) < 0 a^2 + 14a + 25 - 120 < 0 a^2 + 14a - 95 < 0 (a + 19)(a - 5) < 0 a ∈ (-19, 5) ∴ -19 < x < 5 ∴ ∑(x∈X) x^2 = (1^2 + 2^2 + ... + 4^2) + (1^2 + 2^2 + ... + 18^2) = (4 × 5 × 9)/6 + (18 × 19 × 37)/6 = 30 + 2109 = 2139
