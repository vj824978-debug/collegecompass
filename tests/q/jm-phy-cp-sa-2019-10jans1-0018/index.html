The electric field of a plane polarized electromagnetic wave in free space at time t = 0 is given by an expression E(x,y) = 10j cos[(6x + 8z)]. The magnetic field B(x,z,t) is given by – (c is the velocity of light)

  1. (1) (1/c)(6k + 8i)cos[(6x + 8z - 10ct)]
  2. (2) (1/c)(6k - 8i)cos[(6x + 8z - 10ct)]
  3. (3) (1/c)(6k + 8i)cos[(6x - 8z + 10ct)]
  4. (4) (1/c)(6k - 8i)cos[(6x + 8z + 10ct)]

Answer

Correct answer: Option 2

Solution

E = 10j cos(6x + 8z) Phase angle of E at t = 0 is 6x + 8z. As E and B oscillate in same phase at t = 0 Phase angle of B must be 6x + 8z Direction of wave propagation = (6j + 8k)/sqrt(36 + 64) = (6j + 8k)/10 Let B = ai + bj + dk and unit vector in direction of propagation of EM wave is (E × B)/(|E||B|) (E × B)/(|E||B|) = (6i + 8k)/10 10di + k(-10a)/(10 × sqrt(a^2 + b^2 + a^2)) = (6i + 8k)/10 |B| = E/c = 10/c c[10di - 10ak]/(10 × 10) = (6i + 8k)/10 c|di - ak| = 6i + 8k d = 6/c a = -8/c Therefore B = -(8/c)j + (6/c)k B = (6k - 8i)/c cos(6x + 8z - 10ct)
