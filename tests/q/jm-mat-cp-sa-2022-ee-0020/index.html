Let λ* be the largest value of λ for which the function fλ(x) = 4λx^3 - 36λx^2 + 36x + 48 is increasing for all x ∈ R. Then fλ*(1) + fλ*(-1) is equal to

  1. (1) 36
  2. (2) 48
  3. (3) 64
  4. (4) 72

Answer

Correct answer: Option 4

Solution

fλ(x) = 4λx^3 - 36λx^2 + 36x + 48. For increasing function, f'λ(x) ≥ 0 for all x. f'λ(x) = 12λ(x^2 - 6x + 3) ≥ 0. For this to hold for all x, discriminant (6λ)^2 - 12λ ≤ 0, which gives λ ∈ [0, 1/3]. So λ* = 1/3. With λ* = 1/3, fλ*(x) = (4/3)x^3 - 12x^2 + 36x + 48. fλ*(1) = 4/3 - 12 + 36 + 48 = 73.33, fλ*(-1) = -4/3 - 12 - 36 + 48 = -1.33. Sum = 72.
