Let the point A divide the line segment joining the points P(-1, -1, 2) and Q(5, 5, 10) internally in the ratio r : 1 (r > 0). If O is the origin and (vector OQ × vector OA)^2 - (1/5)|vector OP × vector OA|^2 = 10, then the value of r is :

  1. (1) 14
  2. (2) 3
  3. (3) sqrt(7)
  4. (4) 7

Answer

Correct answer: Option 4

Solution

A = ((5r - 1)/(r + 1), (5r - 1)/(r + 1), (10r + 2)/(r + 1)) (vector OQ × vector OA) - |vector OP × vector OA|^2/5 = 10 ...(i) vector OQ × vector OA = 5/(r + 1)(30r + 2) |vector OP × vector OA|^2 = r^2/(r + 1)^2(800) So by equation (i): 10/(r + 1)(15r + 1) - 1/5 · r^2(800)/(r + 1)^2 = 10 2r^2 - 14r = 0 r = 7, r ≠ 0
