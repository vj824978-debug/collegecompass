A particle oscillates along the x-axis according to the law, x(t) = x_0 sin^2(t/2) where x_0 = 1 m. The kinetic energy (K) of the particle as a function of x is correctly represented by the graph.

  1. (1) Graph (1): K vs x showing a peak at x = 1/2 and K = 0 at x = 0 and x = 1
  2. (2) Graph (2): K vs x showing K = 0 at x = 0, minimum around x = 1/2, and increasing toward x = 1
  3. (3) Graph (3): K vs x showing a U-shaped curve with minimum at x = 1/2
  4. (4) Graph (4): K vs x showing a sharp peak at x = 1/2

Answer

Correct answer: Option 1

Solution

x = x_0 sin^2(t/2) = x_0 (1 - cos(t))/2 where x_0 = 1 x - x_0/2 = -cos(t)/2 where x_0 = 1 x - 1/2 = -cos(t)/2 Particle is oscillating between x = 0 to x = 1. Velocity: v = dx/dt = d/dt[x_0 sin^2(t/2)] v = x_0 · 2sin(t/2)cos(t/2) · (1/2) = x_0 sin(t/2)cos(t/2) = (x_0/2)sin(t) Kinetic energy: K = (1/2)m v^2 = (1/2)m[(x_0/2)sin(t)]^2 = (m x_0^2/8)sin^2(t) From x - 1/2 = -cos(t)/2, we get cos(t) = 1 - 2x Therefore: sin^2(t) = 1 - cos^2(t) = 1 - (1 - 2x)^2 = 1 - 1 + 4x - 4x^2 = 4x(1 - x) K = (m x_0^2/8) · 4x(1 - x) = (m x_0^2/2) x(1 - x) With x_0 = 1: K = (m/2) x(1 - x) At x = 0: K = 0 At x = 1/2: K = (m/2) · (1/2) · (1/2) = m/8 (maximum) At x = 1: K = 0 This represents a parabolic shape with maximum at x = 1/2, which matches graph (1).
