Considering the principal values of inverse trigonometric functions, the value of the expression tan(2sin^(-1)(2/sqrt(13)) - 2cos^(-1)(3/sqrt(10))) is equal to:

  1. (1) -33/56
  2. (2) 33/56
  3. (3) 16/63
  4. (4) -16/63

Answer

Correct answer: Option 2

Solution

Let sin^(-1)(2/sqrt(13)) = theta and cos^(-1)(3/sqrt(10)) = phi sin(theta) = 2/sqrt(13) and cos(phi) = 3/sqrt(10) tan(2theta - 2phi) = (tan(2theta) - tan(2phi))/(1 + tan(2theta)tan(2phi)) Since tan(2theta) = 2tan(theta)/(1 - tan^2(theta)) From sin(theta) = 2/sqrt(13), we get cos(theta) = sqrt(1 - 4/13) = sqrt(9/13) = 3/sqrt(13) So tan(theta) = 2/3 tan(2theta) = 2(2/3)/(1 - 4/9) = (4/3)/(5/9) = (4/3) * (9/5) = 12/5 From cos(phi) = 3/sqrt(10), we get sin(phi) = sqrt(1 - 9/10) = sqrt(1/10) = 1/sqrt(10) So tan(phi) = (1/sqrt(10))/(3/sqrt(10)) = 1/3 tan(2phi) = 2(1/3)/(1 - 1/9) = (2/3)/(8/9) = (2/3) * (9/8) = 3/4 tan(2theta - 2phi) = (12/5 - 3/4)/(1 + (12/5)(3/4)) = (48/20 - 15/20)/(1 + 36/20) = (33/20)/(20/20 + 36/20) = (33/20)/(56/20) = 33/56
