When the position vector r = xi + yj + zk changes sign as -r, which one of the following vector will not flip under sign change?

  1. (1) Linear momentum
  2. (2) Velocity
  3. (3) Acceleration
  4. (4) Angular momentum

Answer

Correct answer: Option 4

Solution

r = xi + yj + zk v = dr/dt = v_x i + v_y j + v_z k p = mv L = m(r x v) = (xi + yj + zk) x m(v_x i + v_y j + v_z k) When sign of r changes, L remains same. Explanation: (1) Linear momentum p = mv: Since velocity v depends on dr/dt and r changes sign, p will also change sign (flips). (2) Velocity v = dr/dt: As position r changes sign, velocity will also change sign (flips). (3) Acceleration a = dv/dt: As velocity v changes sign, acceleration will also change sign (flips). (4) Angular momentum L = m(r x v): When r changes to -r and v changes to -v, we have: L' = m((-r) x (-v)) = m(r x v) = L The cross product of two vectors that both change sign gives the same result. Therefore, angular momentum does not flip under sign change.
