Let f(t) = ∫ (1 - sin(log_e(t)))/(1 - cos(log_e(t))) dt, t > 1. If f(e^(π/2)) = -e^(π/2) and f(e^(π/4)) = αe^(π/4), then α equals

  1. (1) -1 - sqrt(2)
  2. (2) -1 - 2sqrt(2)
  3. (3) 1 + sqrt(2)
  4. (4) -1 + sqrt(2)

Answer

Correct answer: Option 1

Solution

f(t) = ∫ (1 - sin(ln t))/(1 - cos(ln t)) dt Let ln t = x ⟹ t = e^x ⟹ dt = e^x dx = (1/2) ∫ (cosec^2(x/2) - 2cot(x/2))e^x dx = -e^x · cot(x/2) + C (Using ∫(f(x) + f'(x))e^x dx = f(x) · e^x + c) = -t · cot(ln t/2) + C Now f(e^(π/2)) = -e^(π/2) · cot(π/4) + C = -e^(π/2) (given) ⟹ C = 0 Now f(e^(π/4)) = -e^(π/4) · cot(π/8) = -e^(π/4) · (sqrt(2) + 1) Therefore α = -1 - sqrt(2)
