Let the circle S: 36x^2 + 36y^2 - 108x + 120y + C = 0 be such that it neither intersects nor touches the co-ordinate axes. If the point of intersection of the lines x - 2y - 4 = 0 and 2x - y - 5 = 0 lies inside the circle S, then:

  1. (1) 81 < C < 156
  2. (2) 100 < C < 165
  3. (3) 100 < C < 156
  4. (4) 25/9 < C < 13/3

Answer

Correct answer: Option 3

Solution

First simplify the circle equation to x^2 + y^2 - 3x + (10/3)y + C/36 = 0. For the circle to not intersect or touch either axis: g^2 < c (from x-axis condition) and f^2 < c (from y-axis condition). This gives 9/4 < C/36, so C > 81, and 25/9 < C/36, so C > 100. Thus C > 100. Find the intersection point of x - 2y - 4 = 0 and 2x - y - 5 = 0, which is (2, -1). For this point to lie inside the circle, substitute into the circle equation: 4 + 1 - 6 - 10/3 + C/36 < 0, which gives 4 + 1 - 6 - 10/3 + C/36 < 0, leading to C < 156. Combining all conditions: 100 < C < 156.
