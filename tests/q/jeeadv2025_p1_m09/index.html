For any two points M and N in the XY-plane, let MN denote the vector from M to N, and 0 denote the zero vector. Let P, Q and R be three distinct points in the XY-plane. Let S be a point inside the triangle ΔPQr such that SP + 5SQ + 6SR = 0. Let E and F be the mid-points of the sides PR and QR, respectively. Then the value of length of the line segment EF / length of the line segment ES is _______.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 1.20

Solution

SP + 5SQ + 6SR = 0 P - S + 5Q - 5S + 6R - 6S = 0 ⟹ S = (P + 5Q + 6R)/12 E = (P + R)/2, F = (Q + R)/2 |EF|/|ES| = |F - E|/|S - E| = |(Q + R)/2 - (P + R)/2| / |(P + 5Q + 6R)/12 - (P + R)/2| = |(Q - P)/2| / |5Q - 5P|/12 = (Q - P)/2 / (5Q - 5P)/12 = 6/5 = 1.20 [Triangle diagram with vertices Q, P, R. Points F on QR, E on PR, S inside triangle. Line segments connecting these points shown.]
