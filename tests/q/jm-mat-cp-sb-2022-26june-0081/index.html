Let f: R → R satisfy f(x + y) = 2^y f(y) + 4^y f(x), ∀ x, y ∈ R. If f(2) = 3, then 14 · f'(4)/f'(2) is equal to ___.

Answer

Correct answer: 248

Solution

From the functional equation f(x + y) = 2^y f(y) + 4^y f(x), substituting y for x: f(y + x) = 2^x f(x) + 4^x f(y). Comparing both equations: 2^y f(y) + 4^y f(x) = 2^x f(x) + 4^x f(y). This simplifies to (4^y - 2^y)f(x) = (4^x - 2^x)f(y), so f(x)/(4^x - 2^x) = f(y)/(4^y - 2^y) = k (constant). Thus f(x) = k(4^x - 2^x). Using f(2) = 3: k(16 - 4) = 3, so k = 1/4. Therefore f(x) = (4^x - 2^x)/4. Taking derivative: f'(x) = (4^x ln 4 - 2^x ln 2)/4 = (2·4^x - 2^x)ln 2/4. Computing f'(4)/f'(2) = (2·256 - 16)/(2·4 - 2) = 496/6 = 248/3. Thus 14 · f'(4)/f'(2) = 248.
