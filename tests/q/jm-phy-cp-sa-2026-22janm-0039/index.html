A thin convex lens of focal length 5 cm and a thin concave lens of focal length 4 cm are combined together (without any gap) and this combination has magnification m₁ when an object is placed 10 cm before the convex lens. Keeping the positions of convex lens and object undisturbed a gap of 1 cm is introduced between the lenses by moving the concave lens away, which lead to a change in magnification of total lens system to m₂. The value of |m₁|/|m₂| is ____.

  1. (1) 2026-05-06 00:00:00
  2. (2) 5/27
  3. (3) 3/2
  4. (4) 25/27

Answer

Correct answer: Option 1

Solution

Initial configuration: Convex lens: f₁ = +5 cm Concave lens: f₂ = -4 cm Object distance from convex lens: u = -10 cm For combined lens system (no gap): 1/f = 1/f₁ + 1/f₂ = 1/5 - 1/4 = -1/20 f = -20 cm Using lens formula: 1/v = 1/f + 1/u 1/v = 1/(-20) + 1/(-10) = -1/20 - 1/10 = -3/20 v = -20/3 cm m₁ = v/u = (-20/3)/(-10) = 2/3 New configuration (1 cm gap introduced): 1st refraction (convex lens): u = -10 cm, f = 5 cm v = uf/(u + f) = (-10)(5)/(-10 + 5) = -50/(-5) = +10 cm m' = v/u = 10/(-10) = -1 2nd refraction (concave lens): Object for concave lens is at distance: u = -(10 + 1) = -9 cm (virtual object) f = -4 cm m' = f/(u + f) = -4/(-9 - 4) = -4/(-13) = 4/13 m₂ = m × m' = (-1) × (4/13) = -4/13 Alternatively using correct calculation: For 2nd refraction: u = +9 cm (real object from concave lens) Using 1/v - 1/u = 1/f: 1/v = 1/f + 1/u = 1/(-4) + 1/9 = -9 + 4/(36) = -5/36 v = -36/5 cm m₂ = m × m' = (-1) × (-36/5)/(9) = (36/5)/9 = 4/5 |m₁|/|m₂| = (2/3)/(4/5) = (2/3) × (5/4) = 10/12 = 5/6
