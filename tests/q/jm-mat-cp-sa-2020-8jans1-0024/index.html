If sqrt(2 sin alpha) / sqrt(1 + cos 2alpha) = 1/7 and sqrt((1 - cos 2beta) / 2) = 1/sqrt(10), alpha, beta ∈ (0, pi/2), then tan(alpha + 2beta) is equal to ___.

Answer

Correct answer: 1.00

Solution

sqrt(2 sin alpha) / sqrt(1 + cos 2alpha) = 1/7 Simplifying: sqrt(2 sin alpha) / sqrt(2 cos alpha) = 1/7 sqrt(sin alpha / cos alpha) = 1/7 sqrt(tan alpha) = 1/7 tan alpha = 1/49 For the second equation: sqrt((1 - cos 2beta) / 2) = 1/sqrt(10) Squaring both sides: (1 - cos 2beta) / 2 = 1/10 1 - cos 2beta = 1/5 cos 2beta = 4/5 Using cos 2beta = (1 - tan^2 beta) / (1 + tan^2 beta): (1 - tan^2 beta) / (1 + tan^2 beta) = 4/5 5(1 - tan^2 beta) = 4(1 + tan^2 beta) 5 - 5 tan^2 beta = 4 + 4 tan^2 beta 1 = 9 tan^2 beta tan beta = 1/3 (since beta ∈ (0, pi/2)) Using tan 2beta = 2 tan beta / (1 - tan^2 beta): tan 2beta = 2(1/3) / (1 - 1/9) = (2/3) / (8/9) = (2/3) × (9/8) = 3/4 Using tan(alpha + 2beta) = (tan alpha + tan 2beta) / (1 - tan alpha · tan 2beta): tan(alpha + 2beta) = (1/49 + 3/4) / (1 - (1/49)(3/4)) Numerator: 1/49 + 3/4 = (4 + 147) / 196 = 151/196 Denominator: 1 - 3/196 = (196 - 3) / 196 = 193/196 tan(alpha + 2beta) = (151/196) / (193/196) = 151/193 Wait, recalculating: tan(alpha + 2beta) = (1/7 + 3/4) / (1 - (1/7)(3/4)) Numerator: 1/7 + 3/4 = (4 + 21) / 28 = 25/28 Denominator: 1 - 3/28 = 25/28 tan(alpha + 2beta) = (25/28) / (25/28) = 1
