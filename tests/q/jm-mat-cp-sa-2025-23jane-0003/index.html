The system of equations x + y + z = 6, x + 2y + 5z = 9, x + 5y + lambda*z = mu, has no solution if

  1. (1) lambda = 17, mu ≠ 18
  2. (2) lambda ≠ 17, mu = 18
  3. (3) lambda = 15, mu ≠ 17
  4. (4) lambda = 17, mu = 18

Answer

Correct answer: Option 1

Solution

D = |1 1 1; 1 2 5; 1 5 lambda| = 0 Expanding the determinant: D = 1(2*lambda - 5*5) - 1(1*lambda - 5*1) + 1(1*5 - 2*1) D = 1(2*lambda - 25) - 1(lambda - 5) + 1(5 - 2) D = 2*lambda - 25 - lambda + 5 + 3 D = lambda - 17 For D = 0: lambda = 17 When lambda = 17: D_z = |1 1 6; 1 2 9; 1 5 mu| Expanding: D_z = 1(2*mu - 45) - 1(1*mu - 9) + 6(5 - 2) D_z = 2*mu - 45 - mu + 9 + 18 D_z = mu - 18 For the system to have no solution: D = 0 but D_z ≠ 0 This requires: lambda = 17 and mu ≠ 18
