The number of elements in the set {n ∈ ℕ : 10 ≤ n ≤ 100 and 3^n - 3 is a multiple of 7}

Answer

Correct answer: 15

Solution

To find when 3^n - 3 is a multiple of 7, we need 3^n - 3 ≡ 0 (mod 7), or 3^n ≡ 3 (mod 7). Finding the pattern of powers of 3 mod 7: 3^1 ≡ 3 (mod 7), 3^2 ≡ 2 (mod 7), 3^3 ≡ -1 (mod 7), 3^4 ≡ -3 ≡ 4 (mod 7), 3^5 ≡ 5 (mod 7), 3^6 ≡ 1 (mod 7), 3^7 ≡ 3 (mod 7). The pattern repeats with period 6. So 3^n ≡ 3 (mod 7) when n ≡ 1 (mod 6). For 10 ≤ n ≤ 100, we need n = 1 + 6k where 10 ≤ 1 + 6k ≤ 100. This gives 9 ≤ 6k ≤ 99, or 1.5 ≤ k ≤ 16.5, so k ∈ {2, 3, 4, ..., 16}. Thus n ∈ {13, 19, 25, ..., 97}. The number of such values is 16 - 2 + 1 = 15.
