Consider the following cases of standard enthalpy of reaction (ΔH_f° in kJ mol^(-1)) C2H6(g) + (7/2)O2(g) → 2CO2(g) + 3H2O(l) ΔH1° = -1550 C(graphite) + O2(g) → CO2(g) ΔH2° = -393.5 H2(g) + (1/2)O2(g) → H2O(l) ΔH3° = -286 The magnitude of ΔH_f°(C2H6(g)) is _______ kJ mol^(-1) (Nearest integer).

Answer

Correct answer: 95

Solution

2C(graphite) + 3H2(g) → C2H6(g) ΔHf = ? Given equations: C2H6(g) + (7/2)O2(g) → 2CO2(g) + 3H2O(l) ΔH1° = -1550 C(graphite) + O2(g) → CO2(g) ΔH2° = -393.5 H2(g) + (1/2)O2(g) → H2O(l) ΔH3° = -286 Using Hess's Law: ΔHf = 2ΔH2 + 3ΔH3 - ΔH1 ΔHf = 2(-393.5) + 3(-286) - (-1550) ΔHf = -787 - 858 + 1550 ΔHf = 1550 - 787 - 858 ΔHf = 1550 - 1645 ΔHf = -95 kJ/mole The magnitude is 95 kJ mol^(-1)
