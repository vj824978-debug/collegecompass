If the equation of the parabola, whose vertex is (5, 4) and the directrix is 3x + y - 29 = 0, is x^2 + ay^2 + bxy + cx + dy + k = 0, then a + b + c + d + k is equal to

  1. (1) 575
  2. (2) -575
  3. (3) 576
  4. (4) -576

Answer

Correct answer: Option 4

Solution

Given vertex (5, 4) and directrix 3x + y - 29 = 0. Find foot of perpendicular from (5, 4) on directrix: (x1, y1) = (8, 5). Focus S = (2, 3). For any point P(x, y) on parabola: (x-2)^2 + (y-3)^2 = (3x + y - 29)^2/10. Expanding: 10(x^2 + y^2 - 4x - 6y + 13) = 9x^2 + y^2 + 841 + 6xy - 58y - 174x. Simplifying: x^2 + 9y^2 - 6xy + 134x - 2y - 711 = 0. Comparing with x^2 + ay^2 + bxy + cx + dy + k = 0: a = 9, b = -6, c = 134, d = -2, k = -711. Therefore a + b + c + d + k = 9 - 6 + 134 - 2 - 711 = -576
