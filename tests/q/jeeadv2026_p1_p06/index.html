A particle is thrown with a speed v from a point O at an angle θ with the horizontal plane such that it passes through the point P at a height of 1 m and horizontal distance of 5 m from O, as shown in the figure. If acceleration due to gravity is g ms⁻², then the correct statement(s) is/are:

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) If θ = 45°, then v = (5√g)/2 ms⁻¹.
  2. (B) If θ = 45°, the particle reaches its maximum height before it reaches P.
  3. (C) If θ = 30°, the particle reaches its maximum height after reaching P.
  4. (D) If θ = tan⁻¹(1/5), then v = 125√g ms⁻¹.

Answer

Correct answer: A, B

Solution

Solution: The equation of trajectory of a projectile is given by: y = x tan θ - gx²/(2v² cos² θ) The particle passes through point P(5,1). Substituting x = 5 and y = 1: 1 = 5 tan θ - 25g/(2v² cos² θ) For option (A), substituting θ = 45°: 1 = 5 tan 45° - 25g/(2v² cos² 45°) 1 = 5(1) - 25g/(2v²(1/2)) 1 = 5 - 25g/v² 25g/v² = 4 ⟹ v² = 25g/4 ⟹ v = 5√g/2 ms⁻¹ Thus, option (A) is correct. For option (B), the horizontal distance to the maximum height is x_m = R/2 = v² sin(2θ)/(2g). For θ = 45° and v² = 25g/4: x_m = (25g/4) sin 90°/(2g) = 25/8 ≈ 3.125 m Since x_m = 3.125 m < 5 m, the particle reaches its maximum height before it reaches P. Thus, option (B) is correct. For option (C), substituting θ = 30° into the trajectory equation: 1 = 5 tan 30° - 25g/(2v² cos² 30°) 1 = 5/√3 - 25g/(2v²(3/4)) = 50g/(3v²) - 5/√3 v² = 50√3g/(3(5 - √3)) The horizontal distance to the maximum height is: x_m = v² sin 60°/(2g) = v²√3/(4g) = 50√3g/(3(5 - √3)) · √3/(4g) = 25/(2(5 - √3)) ≈ 3.82 m Since x_m < 5 m, the particle reaches its maximum height before reaching P. Thus, option (C) is incorrect. For option (D), substituting θ = tan⁻¹(1/5), so tan θ = 1/5: 1 = 5(1/5) - 25g/(2v² cos² θ) ⟹ 1 = 1 - 25g/(2v² cos² θ) 25g/(2v² cos² θ) = 0 This is only possible if v → ∞. Thus, option (D) is incorrect. Answer: If θ = 45°, then v = 5√g/2 ms⁻¹; If θ = 45°, the particle reaches its maximum height before it reaches P.
