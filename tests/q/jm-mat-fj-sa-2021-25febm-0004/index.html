If Rolle's theorem holds for the function f(x) = x^3 - ax^2 + bx - 4, x in [1, 2] with f'(4/3) = 0, then ordered pair (a, b) is equal to:

  1. (1) (A) (5, 8)
  2. (2) (B) (5, -8)
  3. (3) (C) (-5, 8)
  4. (4) (D) (-5, -8)

Answer

Correct answer: Option 1

Solution

Given f(x) = x^3 - ax^2 + bx - 4 on [1, 2] with f'(4/3) = 0. By Rolle's theorem, f(1) = f(2). From f(1) = f(2): 1 - a + b - 4 = 8 - 4a + 2b - 4, which gives 3a - b = 7 (equation i). The derivative is f'(x) = 3x^2 - 2ax + b. At x = 4/3: f'(4/3) = 3(16/9) - 2a(4/3) + b = 16/3 - 8a/3 + b = 0, which simplifies to 16 - 8a + 3b = 0, or 8a = 16 + 3b (equation ii). Solving equations (i) and (ii): From (i): b = 3a - 7. Substituting into (ii): 8a = 16 + 3(3a - 7) = 16 + 9a - 21 = 9a - 5, so a = 5. Then b = 3(5) - 7 = 8. Therefore (a, b) = (5, 8).
