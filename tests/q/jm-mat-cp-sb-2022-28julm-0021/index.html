Let S be the set of all passwords which are six to eight characters long, where each character is either an alphabet from {A, B, C, D, E} or a number from {1, 2, 3, 4, 5}; with the repetition of characters allowed. If the number of passwords in S whose at least one character is a number from {1, 2, 3, 4, 5} is alpha × 5^6, then alpha is equal to ______.

Answer

Correct answer: 7073

Solution

For 6 character password: Total ways with at least one number = 10^6 - 5^6. For 7 character password: 10^7 - 5^7. For 8 character password: 10^8 - 5^8. Total number of passwords = (10^6 + 10^7 + 10^8) - (5^6 + 5^7 + 5^8) = 5^6(2^6 + 5×2^7 + 25×2^8 - 1 - 5 - 25) = 5^6(64 + 640 + 6400 - 31) = 5^6 × 7073. Therefore alpha = 7073.
