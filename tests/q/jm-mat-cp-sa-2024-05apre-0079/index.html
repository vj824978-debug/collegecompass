If y(0) = (2cos(theta) + cos(2*theta))/(cos(3*theta) + 4*cos(2*theta) + 5*cos(theta) + 2), then at theta = pi/2, y'' + y' + y is equal to:

  1. (1) 3/2
  2. (2) 1
  3. (3) 1/2
  4. (4) 2

Answer

Correct answer: Option 4

Solution

Simplify y by factoring numerator and denominator. y = (1/2) * (1/(1 + cos(theta))). Find y' using quotient rule: y' = (1/2) * (-1/(1 + cos(theta))^2) * (-sin(theta)). At theta = pi/2: y = 1/2, y' = 1/2. Find y'' using product rule on y': y'' = (1/2) * [cos(theta)(1 + cos(theta))^2 - sin(theta)(2)(1 + cos(theta))(-sin(theta))] / (1 + cos(theta))^4. At theta = pi/2: y'' = 1. Therefore y'' + y' + y = 1 + 1/2 + 1/2 = 2. However, the answer key shows [4], indicating there may be an alternative interpretation or calculation method.
