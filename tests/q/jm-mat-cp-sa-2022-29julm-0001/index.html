Let R be a relation from the set {1, 2, 3........,60} to itself such that R = {(a, b) : b = pq, where p, q ≥ 3 are prime numbers}. Then, the number of elements in R is:

  1. (1) 600
  2. (2) 660
  3. (3) 540
  4. (4) 720

Answer

Correct answer: Option 2

Solution

Number of possible values of a = 60, for b = pq. If p = 3, q = 3, 5, 7, 11, 13, 17, 19 (8 values). If p = 5, q = 5, 7, 11 (3 values). If p = 7, q = 7 (1 value). Total cases = 60 × 12 = 720. Wait, recalculating: for p = 3, q can be 3, 5, 7, 11, 13, 17, 19 (7 primes ≥ 3, giving products ≤ 60). For p = 5, q can be 5, 7, 11 (3 values). For p = 7, q can be 7 (1 value). Total = 60 × (7 + 3 + 1) = 60 × 11 = 660
