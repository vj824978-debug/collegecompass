A monochromatic light is incident at a certain angle on an equilateral triangular prism and suffers minimum deviation. If the refractive index of the material of the prism is sqrt(3), then the angle of incidence is:

  1. (1) 60°
  2. (2) 45°
  3. (3) 90°
  4. (4) 30°

Answer

Correct answer: Option 1

Solution

For minimum deviation in a prism, we use the formula: n = sin((A + delta_m)/2) / sin(A/2) Where: - A = prism angle = 60° (equilateral triangle) - delta_m = minimum deviation - n = sqrt(3) Substituting the values: sqrt(3) = sin((60 + delta_m)/2) / sin(60/2) sqrt(3) = sin((60 + delta_m)/2) / sin(30°) sqrt(3) = sin((60 + delta_m)/2) / (1/2) sqrt(3)/2 = sin((60 + delta_m)/2) Since sin(60°) = sqrt(3)/2: sin(60°) = sin((60 + delta_m)/2) Therefore: 60° = (60 + delta_m)/2 120° = 60 + delta_m delta_m = 60° At minimum deviation, the ray inside the prism is parallel to the base, which means: i = e (angle of incidence = angle of emergence) Also, at minimum deviation: i = (A + delta_m)/2 i = (60 + 60)/2 = 120/2 = 60°
