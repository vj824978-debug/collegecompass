Let P be the plane passing through the line (x-1)/1 = (y-2)/(-3) = (z+5)/7 and the point (2, 4, -3). If the image of the point (-1, 3, 4) in the plane P is (α, β, γ), then α + β + γ is equal to

  1. (1) 10
  2. (2) 12
  3. (3) 9
  4. (4) 11

Answer

Correct answer: Option 1

Solution

Equation of plane is formed using the determinant: |x-2, y-4, z+3; 1, -3, 7; 1, 2, 2| = 0. Expanding: (x-2)(-20) - (y-4)(-5) + (z+3)(5) = 0, which gives 4x - y - z - 7 = 0. To find the image of (-1, 3, 4) in this plane, use the reflection formula. The perpendicular from (-1, 3, 4) to the plane has direction ratios (4, -1, -1). The foot of perpendicular and reflection point give: α = 7, β = 1, γ = 2. Therefore α + β + γ = 10.
