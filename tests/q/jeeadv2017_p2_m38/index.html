Let O be the origin and let PQR be an arbitrary triangle. The point S is such that OP·OQ + OR·OS = OR·OP + OQ·OS = OQ·OR + OP·OS Then the triangle PQR has S as its

Single correct MCQ · Marks: +3 / -1.0

  1. (A) centroid
  2. (B) circumcentre
  3. (C) incentre
  4. (D) orthocenter

Answer

Correct answer: D

Solution

OP·OQ + OR·OS = OR·OP + OQ·OS ⟹ OP·(OQ - OR) = OS·(OQ - OR) ⟹ (OP - OS)·(RQ) = 0 ⟹ (SP)·(RQ) = 0 ⟹ SP ⊥ RQ Similarly SR ⊥ OP and SQ ⊥ PR Hence, S is orthocentre
