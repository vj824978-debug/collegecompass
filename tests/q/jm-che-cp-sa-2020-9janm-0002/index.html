The compound that cannot act both as oxidising and reducing agent is:

  1. (1) H2O2
  2. (2) H2SO3
  3. (3) HNO2
  4. (4) H3PO4

Answer

Correct answer: Option 4

Solution

To determine which compound cannot act both as oxidising and reducing agent, we need to check the oxidation states of the elements in each compound. (1) H2O2: Contains O in -1 oxidation state. O can be oxidised to 0 or reduced to -2. So H2O2 can act both as oxidising and reducing agent. (2) H2SO3: Contains S in +4 oxidation state. S can be oxidised to +6 or reduced to lower states. So H2SO3 can act both as oxidising and reducing agent. (3) HNO2: Contains N in +3 oxidation state. N can be oxidised to +5 or reduced to lower states. So HNO2 can act both as oxidising and reducing agent. (4) H3PO4: Contains P in +5 oxidation state. Phosphorus is in maximum oxidation state so it can only be reduced, not oxidised. Therefore, H3PO4 can only act as oxidising agent and cannot act as reducing agent. In H3PO4, phosphorous is in maximum oxidation state so can not increase its oxidation no.
