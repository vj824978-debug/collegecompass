Choose the correct length (L) versus square of time period (T2) graph for a simple pendulum executing simple harmonic motion.

  1. (1) Graph showing curved line increasing from origin with increasing slope
  2. (2) Graph showing curved line decreasing from a point on T2 axis, approaching L axis asymptotically
  3. (3) Graph showing straight line with negative slope from T2 axis to L axis
  4. (4) Graph showing straight line with positive slope passing through origin

Answer

Correct answer: Option 4

Solution

For a simple pendulum executing simple harmonic motion, the period T is given by: T = 2*pi*sqrt(L/g) Squaring both sides: T^2 = (2*pi)^2 * L / g T^2 = (4*pi^2 / g) * L Rearranging: T^2 = ((2*pi)^2 / g) * L This can be written as: y = ((2*pi)^2 / g) * x where y-axis represents T^2 and x-axis represents L. This is the equation of a straight line passing through the origin with slope = (4*pi^2 / g), which is a positive constant. Therefore, the graph of T^2 versus L is a straight line with positive slope passing through the origin. The correct answer is graph (4).
