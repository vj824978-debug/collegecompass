For the process H₂O(l) (1 bar, 373 K) → H₂O(g) (1 bar, 373 K), the correct set of thermodynamic parameters is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) ΔG = 0, ΔS = +ve
  2. (B) ΔG = 0, ΔS = −ve
  3. (C) ΔG = +ve, ΔS = 0
  4. (D) ΔG = −ve, ΔS = +ve

Answer

Correct answer: A

Solution

H₂O(ℓ) ⇌ H₂O(g) (1 bar, 373 K) (1 bar, 373 K) At 100°C H₂O(ℓ) has equilibrium with H₂O(g) therefore ΔG = 0. Because liquid molecules are converting into gases molecules therefore ΔS = +ve Hence (A) is correct.
