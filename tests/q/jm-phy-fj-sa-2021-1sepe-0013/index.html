The ranges and heights for two projectiles projected with the same initial velocity at angles 42° and 48° with the horizontal are R1, R2 and H1, H2 respectively. Choose the correct option:

  1. (1) R1 < R2 and H1 < H2
  2. (2) R1 > R2 and H1 = H2
  3. (3) R1 = R2 and H1 = H2
  4. (4) R1 = R2 and H1 < H2

Answer

Correct answer: Option 4

Solution

Range R = u^2 sin(2θ)/g. For 42° and 48°: sin(2*42°) = sin(84°) and sin(2*48°) = sin(96°) = sin(84°), so R1 = R2. Maximum height H_max = u^2 sin^2(θ)/(2g). For 42°: H1 = u^2 sin^2(42°)/(2g). For 48°: H2 = u^2 sin^2(48°)/(2g). Since sin(48°) > sin(42°), we have H2 > H1, therefore H1 < H2.
