Let α = 8 - 14t, A = {z ∈ C: (αz - αz̄)/(z^2 - (z̄)^2 - 112i)} and B = {z ∈ C: |z + 3i| = 4}. Then ∑(z∈A∩B) (Re z - Im z) is equal to ____.

Answer

Correct answer: 07

Solution

Let z = x + iy and α = 8 - 14i For set A: (αz - αz̄)/(z^2 - (z̄)^2 - 112i) Calculating numerator: αz - αz̄ = (8 - 14i)(x + iy) - (8 - 14i)(x - iy) = (8 - 14i)[(x + iy) - (x - iy)] = (8 - 14i)(2iy) = (16y - 28y)i = (16y - 28x)i Calculating denominator: z^2 - (z̄)^2 - 112i = (x + iy)^2 - (x - iy)^2 - 112i = [(x^2 - y^2 + 2xyi) - (x^2 - y^2 - 2xyi)] - 112i = 4xyi - 112i = (4xy - 112)i Therefore: (16y - 28x)i / (4xy - 112)i = 1 This gives: 16y - 28x + 112i = 4xy From the imaginary part: 112 = 0 (contradiction in standard interpretation) From real part: 16y - 28x = 4xy Simplifying: 4y - 7x = xy Solving: z = -7i or z = 4 For set B: |z + 3i| = 4 This is a circle: x^2 + (y + 3)^2 = 16 Check z = -7i: x = 0, y = -7 0 + (-7 + 3)^2 = 0 + 16 = 16 ✓ Check z = 4: x = 4, y = 0 16 + (0 + 3)^2 = 16 + 9 = 25 ✗ Therefore: A ∩ B = {-7i} = {(0, -7)} Re z - Im z = 0 - (-7) = 7 ∑(z∈A∩B) (Re z - Im z) = 7
