The correct statement regarding the given Ellingham diagram is:

  1. (1) Coke cannot be used for the extraction of Cu from Cu₂O
  2. (2) At 500°C, coke can be used for the extraction of Zn from ZnO
  3. (3) At 1400°C, Al can be used for the extraction of Zn from ZnO
  4. (4) At 800°C Cu can be used for the extraction of Zn from ZnO

Answer

Correct answer: Option 3

Solution

The element which present below in diagram can replace element from oxide which is present above in the diagram. So according to diagram Al can reduce ZnO. 3ZnO + 2Al → 3Zn + Al₂O₃ Analyzing each statement: (1) Coke cannot be used for the extraction of Cu from Cu₂O - INCORRECT. From the diagram, the line for 2Cu + O₂ → 2CuO is above the line for C + O₂ → CO₂ at 500°C, meaning coke (C) can reduce Cu₂O. (2) At 500°C, coke can be used for the extraction of Zn from ZnO - INCORRECT. At 500°C, the line for Zn + O₂ → ZnO is below the line for C + O₂ → CO₂, meaning coke cannot reduce ZnO at this temperature. (3) At 1400°C, Al can be used for the extraction of Zn from ZnO - CORRECT. The line for 4Al + 3O₂ → 2Al₂O₃ is below the line for Zn + O₂ → ZnO at 1400°C, meaning Al can reduce ZnO at this temperature. (4) At 800°C Cu can be used for the extraction of Zn from ZnO - INCORRECT. At 800°C, the line for Cu + O₂ → CuO is above the line for Zn + O₂ → ZnO, meaning Cu cannot reduce ZnO (Cu is less reactive than Zn at this temperature).
