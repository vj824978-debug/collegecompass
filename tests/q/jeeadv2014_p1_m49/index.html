Let f: [a, b] → [1, ∞) be a continuous function and let g: ℝ → ℝ be defined as g(x) = { 0 if x < a, integral_a^x f(t)dt if a ≤ x ≤ b, integral_a^b f(t)dt if x > b Then

Multiple correct (MSQ) · Marks: +4 / -1.0

  1. (A) g(x) is continuous but not differentiable at a
  2. (B) g(x) is differentiable on ℝ
  3. (C) g(x) is continuous but not differentiable at b
  4. (D) g(x) is continuous and differentiable at either a or b but not both

Answer

Correct answer: AC

Solution

Since f(x) ≥ 1 ∀ x ∈ [a, b] for g(x) LHD at x = a is zero ∫[a to x] f(t) dt - 0 and RHD at (x = a) = lim[x→a⁺] ─────────────── = lim[x→a⁺] f(x) ≥ 1 x - a Hence g(x) is not differentiable at x = a Similarly LHD at x = b is greater than 1 g(x) is not differentiable at x = b
