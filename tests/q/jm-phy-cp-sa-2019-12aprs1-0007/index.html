Two identical parallel plate capacitors, of capacitance C each, have plates of area A, separated by a distance d. The space between the plates of the two capacitors is filled with three dielectrics, of equal thickness and dielectric constants K1, K2 and K3. The first capacitor is filled as shown in fig.I, and the second one is filled as shown in fig.II. If these two modified capacitors are charged by the same potential V, the ratio of the energy stored in the two, would be (E1 refers to capacitor (I) and E2 to capacitor (II)):

  1. (1) E1/E2 = (K1 + K2 + K3)(K1K3 + K3K1 + K1K2) / (K1K2K3)
  2. (2) E1/E2 = (K1K2K3) / ((K1 + K2 + K3)(K2K3 + K3K1 + K1K2))
  3. (3) E1/E2 = (K1 + K2 + K3)(K2K3 + K3K1 + K1K2) / (9K1K2K3)
  4. (4) E1/E2 = (9K1K2K3) / ((K1 + K2 + K3)(K2K3 + K3K1 + K1K2))

Answer

Correct answer: Option 4

Solution

For configuration (I) with dielectrics in series: 1/C1 = 1/(K1 * ε0A/(d/3)) + 1/(K2 * ε0A/(d/3)) + 1/(K3 * ε0A/(d/3)) 1/C1 = d/(3ε0A) * [1/K1 + 1/K2 + 1/K3] 1/C1 = d/(3ε0A) * [(K2K3 + K3K1 + K1K2)/(K1K2K3)] C1 = 3ε0A * K1K2K3 / (d(K1K2 + K2K3 + K3K1)) For configuration (II) with dielectrics in parallel: C2 = K1 * ε0A/(d/3) + K2 * ε0A/(d/3) + K3 * ε0A/(d/3) C2 = ε0A/3d * [K1 + K2 + K3] Energy stored: E1 = (1/2)C1V^2 E2 = (1/2)C2V^2 E1/E2 = C1/C2 = [3ε0A * K1K2K3 / (d(K1K2 + K2K3 + K3K1))] / [ε0A(K1 + K2 + K3) / (3d)] E1/E2 = [3ε0A * K1K2K3 / (d(K1K2 + K2K3 + K3K1))] * [3d / (ε0A(K1 + K2 + K3))] E1/E2 = 9K1K2K3 / ((K1 + K2 + K3)(K1K2 + K2K3 + K3K1))
