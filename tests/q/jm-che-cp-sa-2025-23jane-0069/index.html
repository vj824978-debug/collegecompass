Given below are two statements about X-ray spectra of elements : Statement (I) : A plot of sqrt(ν) (ν = frequency of X-rays emitted) vs atomic mass is a straight line. Statement (II) : A plot of ν(ν = frequency of X-rays emitted) vs atomic number is a straight line. In the light of the above statements choose the correct answer from the options given below :

  1. (1) Statement I is true but Statement II is false
  2. (2) Both Statement I and Statement II are true
  3. (3) Both Statement I and Statement II are false
  4. (4) Statement I is false but Statement II is true

Answer

Correct answer: Option 3

Solution

To evaluate these statements, we need to consider Moseley's Law for X-ray spectra. Moseley's Law states that the frequency of characteristic X-rays is given by: ν = R*c*(Z - σ)^2*(1/n1^2 - 1/n2^2) For a specific X-ray line, this simplifies to: ν ∝ (Z - σ)^2 where Z is the atomic number and σ is the screening constant. Statement (I): A plot of sqrt(ν) vs atomic mass is a straight line. From Moseley's Law: ν ∝ (Z - σ)^2 Therefore: sqrt(ν) ∝ (Z - σ) However, atomic mass A is not directly proportional to atomic number Z. While for lighter elements there is an approximate relationship, it is not a strict linear relationship. Atomic mass also depends on the number of neutrons, which varies. Therefore, a plot of sqrt(ν) vs atomic mass would NOT be a straight line. Statement (I) is FALSE. Statement (II): A plot of ν vs atomic number is a straight line. From Moseley's Law: ν ∝ (Z - σ)^2 This means ν is proportional to (Z - σ)^2, not (Z - σ). Therefore, ν vs Z would give a parabolic curve, not a straight line. Statement (II) is FALSE. Both statements are false.
