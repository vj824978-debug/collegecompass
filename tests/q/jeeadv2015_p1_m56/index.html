Consider the family of all circles whose centers lie on the straight line y = x. If this family of circles is represented by the differential equation Py'' + Qy' + 1 = 0, where P, Q are functions of x, y and y'(here y' = dy/dx, y'' = d²y/dx²), then which of the following statements is (are) true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) P = y + x
  2. (B) P = y - x
  3. (C) P + Q = 1 - x + y + y' + (y')²
  4. (D) P - Q = x + y - y' - (y')²

Answer

Correct answer: BC

Solution

Let the family of circles be x² + y² - ax - ay + c = 0 On differentiation 2x + 2yy' - a - ay' = 0 Again on differentiation and substituting 'a' we get 2 + 2y'² + 2yy'' - ((2x + 2yy')/(1 + y')) y'' = 0 ⇒ (y - x)y'' + y'(1 + y' + y'²) + 1 = 0
