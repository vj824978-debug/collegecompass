A particle of mass m, and angular momentum ℓ is moving in a circular orbit of radius r₀ under the influence of an attractive force F⃗(r) = -k/r² r̂. Keeping its angular momentum unchanged, the particle is displaced radially by a small distance δr ≪ r₀, due to which its radial distance varies periodically. The corresponding time period is:

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 2πℓ³/(mk²)
  2. (B) 2π√(m/k)
  3. (C) 2πℓ³/(3mk²)
  4. (D) 2πℓ³/(5mk²)

Answer

Correct answer: A

Solution

Solution: The equation of motion for the radial distance r is given by: m d²r/dt² = F(r) + ℓ²/mr³ = -k/r² + ℓ²/mr³ For a circular orbit of radius r₀, the radial acceleration is zero: -k/r₀² + ℓ²/mr₀³ = 0 ⟹ r₀ = ℓ²/mk Let the particle be displaced by a small distance x such that r = r₀ + x. The restoring force is: m d²x/dt² = -k/(r₀ + x)² + ℓ²/m(r₀ + x)³ Using the binomial expansion for x ≪ r₀: m d²x/dt² ≈ -k/r₀²(1 - 2x/r₀) + ℓ²/mr₀³(1 - 3x/r₀) Since k/r₀² = ℓ²/mr₀³, the constant terms cancel out: m d²x/dt² ≈ (2k/r₀³ - 3ℓ²/mr₀⁴)x Substituting ℓ²/mr₀³ = k/r₀³ into the equation: m d²x/dt² = (2k/r₀³ - 3k/r₀³)x = -k/r₀³ x This represents simple harmonic motion with angular frequency ω = √(k/mr₀³). The time period is T = 2π/ω = 2π√(mr₀³/k). Substituting r₀ = ℓ²/mk: T = 2π√(m/k(ℓ²/mk)³) = 2π√(mℓ⁶/km³k³) = 2π√(mℓ⁶/km³k³) = 2πℓ³/mk² Answer: 2πℓ³/mk²
