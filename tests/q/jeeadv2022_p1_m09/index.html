Consider the equation integral from 1 to a of (log_e(x))^2 / (x(a-(log_e(x))^3)^(2/3)) dx = 1, a ∈ (-∞, 0) ∪ (1, ∞). Which of the following statements is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) No a satisfies the above equation
  2. (B) An integer a satisfies the above equation
  3. (C) An irrational number a satisfies the above equation
  4. (D) More than one a satisfy the above equation

Answer

Correct answer: CD

Solution

C, D ∫[1 to e] (ln x)^(1/2) / (x(a - (ln x)^(3/2))) dx = 1 Let a - (ln x)^(3/2) = t -3/2(ln x)^(1/2) × 1/x dx = dt ∫[a to a-1] (-2/3) / t² dt = 1 [-2/3 × (-1/t)]|[a to a-1] = 1 2/3[1/(a-1) - 1/a] = 1 (a - a + 1)/(a(a-1)) = 3/2 1/(a(a-1)) = 3/2 3(a² - a) = 2 3a² - 3a - 2 = 0 a = (3 ± √(9 + 24))/6 = (3 ± √33)/6
