Let in a series of 2n observations, half of them are equal to a and remaining half are equal to -a. Also by adding a constant b in each of these observations, the mean and standard deviation of the new set become 5 and 20, respectively. Then the value of a^2 + b^2 is equal to:

  1. (1) 650
  2. (2) 925
  3. (3) 425
  4. (4) 250

Answer

Correct answer: Option 3

Solution

Original series has n observations equal to a and n observations equal to -a. Mean = (na - na)/(2n) = 0. Variance = (1/2n) * sum(x_i^2) - x_bar^2 = 2na^2/(2n) = a^2. After adding constant b to all observations: new mean = 0 + b = b = 5, so b = 5. New (S.D.)^2 = a^2 = (20)^2 = 400. Therefore a^2 + b^2 = 400 + 25 = 425.
