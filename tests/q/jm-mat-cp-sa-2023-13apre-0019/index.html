Let N be the foot of perpendicular from the point P(1, -2, 3) on the line passing through the points (4, 5, 8) and (1, -7, 5). Then the distance of N from the plane 2x - 2y + z + 5 = 0 is:

  1. (1) 8
  2. (2) 6
  3. (3) 9
  4. (4) 7

Answer

Correct answer: Option 4

Solution

Direction vector of line L: (4-1, 5-(-7), 8-5) = (3, 12, 3) or (1, 4, 1). Line L: (x-1)/1 = (y+7)/4 = (z-5)/1 = r. Point N on line: (r+1, 4r-7, r+5). Vector PN = (r, 4r-5, r+2). Since PN is perpendicular to L: r(1) + (4r-5)(4) + (r+2)(1) = 0. r + 16r - 20 + r + 2 = 0. 18r = 18, r = 1. So N = (2, -3, 6). Distance from N to plane 2x - 2y + z + 5 = 0: |2(2) - 2(-3) + 6 + 5|/sqrt(4+4+1) = |4 + 6 + 6 + 5|/3 = 21/3 = 7.
