Let f,g:(1,∞) → ℝ be defined as f(x) = (2x+3)/(5x+2) and g(x) = (2-3x)/(1-x). If the range of the function fog: [2,4] → ℝ is [α,β], then 1/(β-α) is equal to

  1. (1) 29
  2. (2) 2
  3. (3) 56
  4. (4) 68

Answer

Correct answer: Option 3

Solution

Find fog(x) = f(g(x)). First compute g(x) = (2-3x)/(1-x). Then f(g(x)) = f((2-3x)/(1-x)) = (2·(2-3x)/(1-x) + 3)/(5·(2-3x)/(1-x) + 2). Simplify numerator: 2(2-3x) + 3(1-x) = 4-6x+3-3x = 7-9x. Simplify denominator: 5(2-3x) + 2(1-x) = 10-15x+2-2x = 12-17x. So fog(x) = (7-9x)/(12-17x). Find the range on [2,4]. At x=2: fog(2) = (7-18)/(12-34) = -11/-22 = 1/2. At x=4: fog(4) = (7-36)/(12-68) = -29/-56 = 29/56. Check if fog is monotonic on [2,4] by computing derivative. fog'(x) = [(-9)(12-17x) - (7-9x)(-17)]/[(12-17x)^2] = [-108+153x+119-153x]/[(12-17x)^2] = 11/[(12-17x)^2] > 0. So fog is increasing. Range is [29/56, 1/2]. Thus α = 29/56, β = 1/2. β - α = 1/2 - 29/56 = 28/56 - 29/56 = -1/56. Take absolute value: 1/56. Then 1/(β-α) = 56.
