Let R denote the set of all real numbers. Let f: R → R be a function such that f(x) > 0 for all x ∈ R, and f(x + y) = f(x) f(y) for all x, y ∈ R. Let the real numbers a₁, a₂, ..., a₅₀ be in an arithmetic progression. If f(a₃₁) = 64 f(a₂₅), and sum_{i=1}^{50} f(aᵢ) = 3(2^{25} + 1), then the value of sum_{i=6}^{30} f(aᵢ) is ______.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 96

Solution

f(x) = k^x, (k > 0) f(a₃₁) = k^(a+30d), f(a₂₅) = k^(a+24d) SO, k^(a+30d) = 6.4·k^(a+24d) or k^(6d) = 2^6 ⟹ k^d = 2 ...(i) now, f(a₁) + f(a₂) + ..... + f(a₅₀) = 3(2²⁵ + 1) ⟹ k^a + k^(a+d) + .....+k^(a+49d) = 3(2²⁵ + 1) k^a((k^d)⁵⁰ - 1)/(k^d - 1) = 3(2²⁵ + 1) from equation (i), k^a = 3(2²⁵ + 1)/(2⁵⁰ - 1) = 3/(2²⁵ - 1) now, Σ(i=6 to 30) f(aᵢ) = [k^(a+5d)((k^d)²⁵ - 1)]/(2⁵⁰ - 1) = [2⁵ × (2²⁵ - 1)]/(2²⁵ - 1) × 3/(2 - 1) = 96
