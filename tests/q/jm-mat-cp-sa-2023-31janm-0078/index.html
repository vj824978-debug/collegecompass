If the sum and product of four positive consecutive terms of a G.P., are 126 and 1296, respectively, then the sum of common ratio of all such GPs is

  1. (1) 14
  2. (2) 7
  3. (3) 3
  4. (4) 9/2

Answer

Correct answer: Option 3

Solution

Let the terms be a/r^3, a/r, ar, ar^3 Product: (a/r^3) * (a/r) * ar * ar^3 = 1296 => a^4 = 1296 => a = 6 Now, a/r^3 + a/r + ar + ar^3 = 126 => 6/r^3 + 6/r + 6r + 6r^3 = 126 => 1/r^3 + 1/r + r + r^3 = 21 => (r + 1/r)((r + 1/r)^2 - 3) + (r + 1/r) = 21 Let r + 1/r = t t(t^2 - 3) + t = 21 => t^3 - 3t + t = 21 => t^3 - 2t - 21 = 0 => (t - 3)(t^2 + 3t + 7) = 0 => t = 3 r + 1/r = 3 => r^3 - 3r + 1 = 0 => r1 + r2 = 3 The sum of common ratios of all such GPs is r1 + r2 = 3
