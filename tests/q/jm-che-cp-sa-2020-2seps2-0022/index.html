For the disproportionation reaction 2Cu^+(aq) ⇌ Cu(s) + Cu^2+(aq) at 298 K, ln K (where K is the equilibrium constant) is ___ × 10^(-1). Given: E°(Cu^2+/Cu^+) = 0.16 V, E°(Cu^+/Cu) = 0.52 V, RT/F = 0.025

Answer

Correct answer: 144.00

Solution

For the disproportionation reaction: 2Cu^+ → Cu^2+ + Cu The half-reactions are: Reduction: Cu^+ + e^- → Cu (E° = 0.52 V) Oxidation: Cu^+ → Cu^2+ + e^- (E° = 0.16 V) Cell potential: E°(cell) = E°(cathode) - E°(anode) = 0.52 - 0.16 = 0.36 V At equilibrium, E(cell) = 0 Using Nernst equation at equilibrium: E°(cell) = (RT/nF) ln K For this reaction, n = 1 (one electron transferred) ln K = E°(cell) × nF / (RT) = E°(cell) / (RT/F) ln K = 0.36 / 0.025 = 14.4 = 144 × 10^(-1) Therefore, ln K = 144 × 10^(-1)
