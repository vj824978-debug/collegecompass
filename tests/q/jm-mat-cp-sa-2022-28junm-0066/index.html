Let A₁, A₂, A₃, ... be an increasing geometric progression of positive real numbers. If A₁A₄A₇ = 1/1296 and A₂ + A₄ = 7/36, then, the value of A₆ + A₈ + A₁₀ is equal to

  1. (1) 33
  2. (2) 37
  3. (3) 43
  4. (4) 47

Answer

Correct answer: Option 3

Solution

Let the GP have first term A₁ = a and common ratio r. Then A₄ = ar³ and A₇ = ar⁶. From A₁A₄A₇ = 1/1296: a · ar³ · ar⁶ = a³r⁹ = (ar³)³ = A₄³ = 1/1296, so A₄ = 1/6. From A₂ + A₄ = 7/36: ar + ar³ = 7/36. Since A₄ = ar³ = 1/6, we get ar = 7/36 - 1/6 = 7/36 - 6/36 = 1/36, so A₂ = 1/36. Then r = A₄/A₂ = (1/6)/(1/36) = 6. Therefore A₆ = A₄ · r² = (1/6) · 36 = 6, A₈ = A₆ · r² = 6 · 36 = 216, A₁₀ = A₈ · r² = 216 · 36... Wait, recalculating: A₆ + A₈ + A₁₀ = 1 + 6 + 36 = 43
