In a triangle the sum of two sides is x and the product of the same two sides is y. If x^2 - c^2 = y, where c is the third side of the triangle, then the ratio of the in-radius to the circum-radius of the triangle is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 3y / (2x(x + c))
  2. (B) 3y / (2c(x + c))
  3. (C) 3y / (4x(x + c))
  4. (D) 3y / (4c(x + c))

Answer

Correct answer: B

Solution

x = a + b y = ab x² - c² = y ⟹ (a² + b² - c²)/(2ab) = -1/2 = cos(120°) ⟹ ∠C = 2π/3 ⟹ R = abc/(4Δ), r = Δ/s ⟹ r/R = s(abc)/(4Δ²) = [4(1/2 ab sin(2π/3))²]/[(x+c)/2 · y · c] r/R = 3y/(2c(x+c))
