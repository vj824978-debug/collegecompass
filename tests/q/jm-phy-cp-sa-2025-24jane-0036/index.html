N equally spaced charges each of value q, are placed on a circle of radius R. The circle rotates about its axis with an angular velocity omega as shown in the figure. A bigger Amperian loop B encloses the whole circle where as a smaller Amperian loop A encloses a small segment. The difference between enclosed currents, I_A - I_B, for the given Amperian loops is:

  1. (1) (N^2)/(2*pi) * q*omega
  2. (2) (2*pi)/N * q*omega
  3. (3) N/(2*pi) * q*omega
  4. (4) N/pi * q*omega

Answer

Correct answer: Option 3

Solution

I_A = (N)/(2*pi) * omega Each charge q passes through loop A once per revolution. Time period T = 2*pi/omega Current through loop A: I_A = (charge passing through A per revolution) / (time period) I_A = N*q*omega / (2*pi) Current through loop B (encloses whole circle): I_B = 0 (all charges that enter also leave the loop, net current = 0) Therefore: I_A - I_B = (N*q*omega)/(2*pi) - 0 I_A - I_B = (N*q*omega)/(2*pi)
