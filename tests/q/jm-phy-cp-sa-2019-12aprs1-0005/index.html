A uniform rod of length ℓ is being rotated in a horizontal plane with a constant angular speed about an axis passing through one of its ends. If the tension generated in the rod due to rotation is T(x) at a distance x from the axis, then which of the following graphs depicts it most closely?

  1. (1) Graph showing constant tension T(x) across the length, dropping to zero at x = ℓ
  2. (2) Graph showing linear decrease in tension from maximum at x = 0 to zero at x = ℓ
  3. (3) Graph showing parabolic increase in tension, starting near zero and increasing to maximum at x = ℓ
  4. (4) Graph showing parabolic curve with maximum tension at x = 0, decreasing parabolically to zero at x = ℓ

Answer

Correct answer: Option 4

Solution

Consider a small element of the rod at distance L from the axis with length dL. Mass of element: dm = (m/ℓ)dL The tension T(x) at position x must provide the centripetal force for all the mass beyond position x. For the element at distance L: Centripetal force needed = dm·ω²·L = (m/ℓ)dL·ω²·L The tension at position x is obtained by integrating the centripetal force requirements of all elements from x to ℓ: T(x) = ∫[from x to ℓ] (dm)ω²L = ∫[from x to ℓ] (m/ℓ)dL·ω²·L = (m·ω²/ℓ) ∫[from x to ℓ] L dL = (m·ω²/ℓ)[L²/2] from x to ℓ = (m·ω²/2ℓ)(ℓ² - x²) T(x) = (m·ω²/2ℓ)(ℓ² - x²) This can be written as: T(x) = A - B·x² where A = (m·ω²·ℓ)/2ℓ and B = (m·ω²)/2ℓ This is a parabola opening downward (parabola, mouth down): - At x = 0: T(0) = (m·ω²/2ℓ)·ℓ² = maximum tension - At x = ℓ: T(ℓ) = (m·ω²/2ℓ)(ℓ² - ℓ²) = 0 - The function T(x) = A - Bx² is a downward-opening parabola Therefore, graph (4) depicts this most closely.
