For the frequency distribution: Variate (x): x₁, x₂, x₃, ..., x₁₅; Frequency (f): f₁, f₂, f₃, ..., f₁₅; where 0 < x₁ < x₂ < x₃ < ... < x₁₅ = 10 and sum from t=1 to 15 of f_t > 0, the standard deviation cannot be

  1. (1) 1
  2. (2) 4
  3. (3) 2
  4. (4) 6

Answer

Correct answer: Option 4

Solution

For a frequency distribution with variates x₁, x₂, x₃, ..., x₁₅ where 0 < x₁ < x₂ < x₃ < ... < x₁₅ = 10, we need to find the maximum possible value of standard deviation. The standard deviation is given by: σ² = (1/N) * Σ f_i(x_i - m)² where m is the mean. For a discrete distribution, the variance is bounded by: σ² ≤ (1/4)(M - m)² where M is the upper bound and m is the lower bound of the values. Since 0 < x₁ and x₁₅ = 10, we have: - Lower bound: m = 0 - Upper bound: M = 10 Therefore: σ² ≤ (1/4)(10 - 0)² = (1/4)(100) = 25 This gives: σ ≤ 5 So: 0 < σ < 5 This means σ ≠ 6. Among the given options: (1) σ = 1: Possible (0 < 1 < 5) (2) σ = 4: Possible (0 < 4 < 5) (3) σ = 2: Possible (0 < 2 < 5) (4) σ = 6: NOT Possible (6 > 5) Therefore, the standard deviation cannot be 6.
