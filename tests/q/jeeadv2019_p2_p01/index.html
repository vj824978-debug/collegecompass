In a Young's double slit experiment, the slit separation d is 0.3 mm and the screen distance D is 1 m. A parallel beam of light of wavelength 600 nm is incident on the slits at an angle α as shown in figure. [Figure shows two slits separated by distance d, with light incident at angle α, and a screen at distance D showing point O equidistant from slits and point P above O] On the screen, the point O is equidistant from the slits and distance PO is 11.0 mm. Which of the following statement(s) is/are correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) For α = 0.36/π degree, there will be destructive interference at point O.
  2. (B) Fringe spacing depends on α.
  3. (C) For α = 0.36/π degree, there will be destructive interference at point P.
  4. (D) For α = 0, there will be constructive interference at point P.

Answer

Correct answer: C

Solution

Sol. C [Diagram showing two light rays from a source converging at point d on a screen setup, with angles α and θ marked, and a coordinate system with origin O and point P on a vertical screen at distance D] Given α = 0.36/π degree = 1/500 radian. Path difference at O = d sin α = 0.3 × 10⁻³ × 1/500 = 6 × 10⁻⁷ = λ Path difference at P = d(sin α + sin θ) = d(1/500 + 11/1000) = d/500(1 + 11/2) = λ(6.5) For α = 0, path difference at P = 5.5 λ ∴ option C is correct
