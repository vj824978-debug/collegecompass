Let R = [0 y 0; 0 0 z; 0 0 z] be a non-zero 3×3 matrix, where sin(theta) = ysin(theta + 2*pi/3) = zsin(theta + 4*pi/3) ≠ 0, theta ∈ (0, 2*pi). For a square matrix M, let trace(M) denote the sum of all the diagonal entries of M. Then, among the statements: (I) Trace(R) = 0. (II) If trace(adj(adj(R))) = 0, then R has exactly one non-zero entry.

  1. (1) Only (II) is true
  2. (2) Only (I) is true
  3. (3) Both (I) and (II) are true
  4. (4) Neither (I) nor (II) is true

Answer

Correct answer: Option 4

Solution

From the given condition sin(theta) = ysin(theta + 2*pi/3) = zsin(theta + 4*pi/3), we get y = x*sin(theta)/sin(theta + 2*pi/3) and z = x*sin(theta)/sin(theta + 4*pi/3). Computing x + y + z = -3x/(4sin(theta + 2*pi/3)sin(theta + 4*pi/3)) ≠ 0. The matrix R has diagonal entries x, y, z with x + y + z ≠ 0, so trace(R) ≠ 0, making statement (I) false. For the adjugate matrices, trace(adj(adj(R))) = xyz(x + y + z) ≠ 0, making statement (II) false. Therefore, neither (I) nor (II) is true.
