Let f(x) = [x]^2 - [x + 3] - 3, x ∈ ℝ where [•] is the greatest integer function. Then

  1. (1) f(x) > 0 only for x ∈ [4, ∞)
  2. (2) f(x) < 0 only for x ∈ [-1, 3)
  3. (3) ∫_0^2 f(x)dx = -6
  4. (4) f(x) = 0 for finitely many values of x

Answer

Correct answer: Option 2

Solution

f(x) = [x]^2 - [x + 3] - 3 = ([x] + 2)([x] - 3) (1) f(x) > 0 ⇒ [x] ∈ (-∞, -2) ∪ (3, ∞) ⇒ x ∈ (-∞, -2) ∪ [4, ∞) So option (1) is incorrect. (2) f(x) < 0 ⇒ [x] ∈ (-2, 3) ⇒ x ∈ [-1, 3) option (2) is correct (3) ∫_0^2 f(x)dx = ∫_0^1 (0 - 0 - 3)dx + ∫_1^2 (1 - 1 - 3)dx = -6 - 6 = -12 So option (3) is incorrect. (4) f(x) = 0 ⇒ [x] = 3 or [x] = -2 infinitely many solutions So option (4) is incorrect.
