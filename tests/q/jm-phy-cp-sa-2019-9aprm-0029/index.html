A convex lens of focal length 20 cm produces images of the same magnification 2 when an object is kept at two distance x₁ and x₂ (x₁ > x₂) from the lens. The ratio of x₁ and x₂ is:

  1. (1) 4 : 3
  2. (2) 3 : 1
  3. (3) 2 : 1
  4. (4) 5 : 3

Answer

Correct answer: Option 2

Solution

Magnification = 2 Using lens formula: 1/f = 1/v + 1/u Magnification m = -v/u = 2 (considering magnitude) So v/u = 2, which means v = 2u Substituting in lens formula: 1/20 = 1/(2u) + 1/u 1/20 = 1/(2u) + 2/(2u) 1/20 = 3/(2u) 2u = 60 u = 30 cm For the first position (real image): u₁ = x₁ Using 1/f = 1/v₁ + 1/u₁ 1/20 = 1/v₁ + 1/x₁ With magnification m = 2: v₁ = 2x₁ 1/20 = 1/(2x₁) + 1/x₁ 1/20 = 1/(2x₁) + 2/(2x₁) = 3/(2x₁) x₁ = 30 cm For the second position (virtual image): u₂ = x₂ With same magnification magnitude of 2, but virtual image: v₂ = 2x₂ (virtual, on same side as object) 1/20 = 1/(-2x₂) + 1/x₂ 1/20 = -1/(2x₂) + 1/x₂ 1/20 = -1/(2x₂) + 2/(2x₂) = 1/(2x₂) x₂ = 10 cm Therefore: x₁/x₂ = 30/10 = 3/1 = 3:1
