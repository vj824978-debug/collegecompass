A square is inscribed in the circle x^2 + y^2 - 6x + 8y - 103 = 0 with its sides parallel to the coordinate axes. Then the distance of the vertex of this square which is nearest to the origin is:

  1. (1) sqrt(137)
  2. (2) 6
  3. (3) sqrt(41)
  4. (4) 13

Answer

Correct answer: Option 3

Solution

First, rewrite the circle equation in standard form: x^2 + y^2 - 6x + 8y - 103 = 0 (x^2 - 6x) + (y^2 + 8y) = 103 (x^2 - 6x + 9) + (y^2 + 8y + 16) = 103 + 9 + 16 (x - 3)^2 + (y + 4)^2 = 128 Center: (3, -4) Radius: R = sqrt(128) = 8*sqrt(2) For a square inscribed in a circle with sides parallel to the coordinate axes, the vertices lie on the circle and are equidistant from the center. If the side of the square is 'a', then the diagonal is a*sqrt(2), which equals the diameter 2R = 16*sqrt(2). So a*sqrt(2) = 16*sqrt(2), giving a = 16. The half-side length is 8. The vertices of the square are at distances of 8 from the center in the horizontal and vertical directions. Vertices: (3-8, -4-8) = (-5, -12) = A (3+8, -4-8) = (11, -12) = B (3+8, -4+8) = (11, 4) = C (3-8, -4+8) = (-5, 4) = D Distances from origin: OA = sqrt((-5)^2 + (-12)^2) = sqrt(25 + 144) = sqrt(169) = 13 OB = sqrt(11^2 + (-12)^2) = sqrt(121 + 144) = sqrt(265) OC = sqrt(11^2 + 4^2) = sqrt(121 + 16) = sqrt(137) OD = sqrt((-5)^2 + 4^2) = sqrt(25 + 16) = sqrt(41) The nearest vertex to origin has distance sqrt(41).
