Let û = u₁i + u₂j + u₃k be a unit vector in R³ and ŵ = 1/sqrt(6)(i + j + 2k). Given that there exists a vector v̂ in R³ such that |û × v̂| = 1 and ŵ · (û × v̂) = 1. Which of the following statement(s) is(are) correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) There is exactly one choice for such v̂
  2. (B) There are infinitely many choices for such v̂
  3. (C) If û lies in the xy-plane then |u₁| = |u₂|
  4. (D) If û lies in the xz-plane then 2|u₁| = |u₃|

Answer

Correct answer: BC

Solution

w·(ū×v̄)=1 ⇒|w̄||ū×v̄|cos α=1 cos α=1 ⇒w̄⊥ū and w̄⊥v̄ as it is given there exist a vector v̄ ⇒w̄ must be ⊥ to ū hence infinite many such v̄ exists. if ū=u₁ī+u₂ĵ ū·w̄=0 ⇒(u₁+u₂)=0 ⇒|u₁|=|u₂| if u=u₁ī+u₃k̄ ū·w̄=0 u₁+2u₃=0 ⇒|u₁|=2|u₃|.
