Let the lines 3x - 4y - alpha = 0, 8x - 11y - 33 = 0, and 2x - 3y + lambda = 0 be concurrent. If the image of the point (1,2) in the line 2x - 3y + lambda = 0 is (57/13, -40/13), then |alpha*lambda| is equal to:

  1. (1) 84
  2. (2) 91
  3. (3) 113
  4. (4) 101

Answer

Correct answer: Option 2

Solution

P(1,2) M 2x - 3y + lambda Q(57/13, -40/13) Since PM = QM (P and Q are reflections across the line) So, M = ((57/13 + 1)/2, (-40/13 + 2)/2) = ((57/13 + 13/13)/2, (-40/13 + 26/13)/2) = ((70/13)/2, (-14/13)/2) = (35/13, -7/13) M lies on the line 2x - 3y + lambda = 0 2(35/13) - 3(-7/13) + lambda = 0 70/13 + 21/13 + lambda = 0 91/13 + lambda = 0 lambda = -7 For the three lines to be concurrent, we use the determinant condition: |3 -4 -alpha| |8 -11 -33| = 0 |2 3 lambda| Expanding: 3(-11*lambda - 3*(-33)) - (-4)(8*lambda - 2*(-33)) + (-alpha)(8*3 - 2*(-11)) = 0 3(-11*lambda + 99) + 4(8*lambda + 66) - alpha(24 + 22) = 0 -33*lambda + 297 + 32*lambda + 264 - 46*alpha = 0 -lambda + 561 - 46*alpha = 0 -lambda + 2*alpha - 33 = 0 (from the determinant expansion) Substituting lambda = -7: -(-7) + 2*alpha - 33 = 0 7 + 2*alpha - 33 = 0 2*alpha = 26 alpha = 13 Therefore: |alpha*lambda| = |13 × (-7)| = |-91| = 91
