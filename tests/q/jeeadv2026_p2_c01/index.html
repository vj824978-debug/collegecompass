At 300 K, the molar conductivities of the aqueous solutions of three salts at two different concentrations are given below: | Salt | Concentration (M) | Molar conductivity (S cm² mol⁻¹) | |------|-------------------|----------------------------------| | NaNO₃ | 0.01 | 111 | | | 0.04 | 101 | | NaCl | 0.01 | 117 | | | 0.04 | 107 | | AgNO₃ | 0.01 | 125 | | | 0.04 | 116 | The conductivity of a saturated aqueous solution of AgCl is 1.40 × 10⁻⁶ S cm⁻¹ at 300 K. If the solubility of AgCl in water at 300 K is X mol L⁻¹, then log₁₀(X⁻¹) is (Assume that AgCl dissolved in water ionizes completely and that the molar conductivity of saturated AgCl solution is equal to its limiting molar conductivity.)

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 3
  2. (B) 4
  3. (C) 5
  4. (D) 6

Answer

Correct answer: C

Solution

Solution: Using the Debye-Hückel-Onsager equation, Λₘ = Λ°ₘ - b√C, we can find the limiting molar conductivity (Λ°ₘ) for each salt. For NaNO₃: Λ°ₘ - b√0.01 = 111 ⇒ Λ°ₘ - 0.1b = 111 Λ°ₘ - b√0.04 = 101 ⇒ Λ°ₘ - 0.2b = 101 Subtracting the two equations gives 0.1b = 10 ⇒ b = 100. Λ°ₘ(NaNO₃) = 111 + 100(0.1) = 121 S cm² mol⁻¹. For NaCl: Λ°ₘ - 0.1b = 117 Λ°ₘ - 0.2b = 107 Subtracting gives 0.1b = 10 ⇒ b = 100. Λ°ₘ(NaCl) = 117 + 100(0.1) = 127 S cm² mol⁻¹. For AgNO₃: Λ°ₘ - 0.1b = 125 Λ°ₘ - 0.2b = 116 Subtracting gives 0.1b = 9 ⇒ b = 90. Λ°ₘ(AgNO₃) = 125 + 90(0.1) = 134 S cm² mol⁻¹. According to Kohlrausch's law of independent migration of ions: Λ°ₘ(AgCl) = Λ°ₘ(AgNO₃) + Λ°ₘ(NaCl) - Λ°ₘ(NaNO₃) Λ°ₘ(AgCl) = 134 + 127 - 121 = 140 S cm² mol⁻¹. The molar conductivity of the saturated AgCl solution is equal to its limiting molar conductivity, so Λₘ(AgCl) = 140 S cm² mol⁻¹. The relationship between molar conductivity, conductivity (κ), and solubility (X in mol L⁻¹) is: Λₘ = (κ × 1000)/X Substituting the given values: 140 = (1.40 × 10⁻⁶ × 1000)/X 140 = (1.40 × 10⁻³)/X X = (1.40 × 10⁻³)/140 = 10⁻⁵ mol L⁻¹. We need to find log₁₀(X⁻¹): X⁻¹ = 1/(10⁻⁵) = 10⁵ log₁₀(X⁻¹) = log₁₀(10⁵) = 5. Answer: 5
