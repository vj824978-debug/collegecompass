Let f be a non-negative function in [0, 1] and twice differentiable in (0, 1). If integral from 0 to x of sqrt(1 - (f'(t))^2) dt = integral from 0 to x of f(t) dt, 0 <= x <= 1 and f(0) = 0, then lim as x approaches 0+ of (1/x^2) * integral from 0 to x of f(t) dt

  1. (1) does not exist
  2. (2) equals 1
  3. (3) equals 1/2
  4. (4) equals 0

Answer

Correct answer: Option 3

Solution

Applying Leibniz theorem: sqrt(1 - (f'(x))^2) = f(x). Rearranging: f'(x)/sqrt(1 - (f'(x))^2) = 1. Integrating both sides: f(x) = sin(x) + C. Using initial condition f(0) = 0, we get C = 0, so f(x) = sin(x). Now lim as x approaches 0+ of (1/x^2) * integral from 0 to x of f(t) dt. By L'Hôpital's rule: lim as x approaches 0+ of f(x)/(2x) = lim as x approaches 0+ of sin(x)/(2x) = 1/2
