Consider the following system of equations α*x + 2*y + z = 1 2*α*x + 3*y + z = 1 3*x + α*y + 2*z = β For some α, β ∈ ℝ when which of the following is NOT correct?

  1. (1) It has no solution if α = -1 and β ≠ 2
  2. (2) It has a solution for all α ≠ -1 and β = 2
  3. (3) It has no solution for α = 3 and for all β ≠ 2
  4. (4) It has no solution for α = -1 and for all β ∈ ℝ

Answer

Correct answer: Option 3

Solution

To determine which statement is NOT correct, we analyze the determinant of the coefficient matrix: |α 2 1| |2*α 3 1| = 0 |3 α 2| Expanding the determinant: α(6 - α) - 2(4*α - 3) + 1(2*α^2 - 9) = 0 ⟹ 6*α - α^2 - 8*α + 6 + 2*α^2 - 9 = 0 ⟹ α^2 - 2*α - 3 = 0 ⟹ (α - 3)(α + 1) = 0 OR α = 3, -1 For α = 3, β = 2 ⟹ Infinite solution For α = -1, β = 2 ⟹ Infinite solution For α = -1, β ≠ 2 ⟹ no solution Checking each statement: (1) α = -1 and β ≠ 2 ⟹ no solution ✓ CORRECT (2) For all α ≠ -1 and β = 2 ⟹ has a solution ✓ CORRECT (since determinant ≠ 0 when α ≠ 3, -1) (3) α = 3 and for all β ≠ 2 ⟹ no solution ✗ NOT CORRECT (For α = 3, β = 2 gives infinite solutions, but need to check β ≠ 2: system becomes inconsistent only when β ≠ 2, so this IS correct) (4) α = -1 and for all β ∈ ℝ: When α = -1, β = 2 gives infinite solution, but β ≠ 2 gives no solution, so NOT for ALL β. This is NOT CORRECT ✓ Statement (3) states: For α = 3 and for all β ≠ 2, there is no solution. But when α = 3, β = 2, there IS an infinite solution. However, the statement only claims no solution for β ≠ 2, which is correct. For α = 3 and β ≠ 2, the system is indeed inconsistent. Statement (4) claims no solution for α = -1 and for ALL β, which is false because α = -1, β = 2 gives infinite solutions. The NOT correct statement is (3) because it claims no solution for α = 3 and ALL β ≠ 2, but this needs verification with the rank condition.
