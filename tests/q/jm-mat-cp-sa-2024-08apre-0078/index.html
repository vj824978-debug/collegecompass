Let A = {2, 3, 6, 8, 9, 11} and B = {1, 4, 5, 10, 15}. Let R be a relation on A × B defined by (a, b)R(c, d) if and only if 3ad - 7bc is an even integer. Then the relation R is:

  1. (1) reflexive but not symmetric
  2. (2) transitive but not symmetric
  3. (3) reflexive and symmetric but not transitive
  4. (4) an equivalence relation

Answer

Correct answer: Option 3

Solution

Reflexive: (a,b)R(a,b) ⟹ 3ab - 7ba = -4ab which is always even. So reflexive. Symmetric: If 3ad - 7bc is even, then 3bc - 7ad must also be even. For odd-odd or even-even cases, both expressions have the same parity, so symmetric. Transitive: (3,4)R(6,4) gives 3(3)(4) - 7(6)(4) = 36 - 168 = -132 (even). (6,4)R(3,1) gives 3(6)(1) - 7(3)(4) = 18 - 84 = -66 (even). But (3,4)R(3,1) gives 3(3)(1) - 7(3)(4) = 9 - 84 = -75 (odd), so not transitive.
