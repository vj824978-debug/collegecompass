Given a thin convex lens (refractive index μ₂), kept in a liquid (refractive index μ₁, μ₁ < μ₂) having radii of curvature |R₁| and |R₂|. Its second surface is silver polished. Where should an object be placed on the optic axis so that a real and inverted image is formed at the same place?

  1. (1) μ₁|R₁|.|R₂|/(μ₂(|R₁|+|R₂|)-μ₁|R₁|)
  2. (2) μ₁|R₁|.|R₂|/(μ₂(|R₁|+|R₂|)-μ₁|R₂|)
  3. (3) μ₁|R₁|.|R₂|/(μ₂(2|R₁|+|R₂|)-μ₁√(|R₁|.|R₂|))
  4. (4) (μ₂+μ₁)|R₁|/((μ₂-μ₁))

Answer

Correct answer: Option 2

Solution

For a silvered lens system, we need to find the object distance u such that the image coincides with the object (real and inverted image at same place). The system consists of: - A lens of refractive index μ₂ in a medium of refractive index μ₁ - Second surface is silvered (acts as mirror) For the lens in liquid: Power of lens: 1/f_L = (μ₂/μ₁ - 1)(1/R₁ + 1/R₂) Power of silvered surface (mirror): f_m = -|R₂|/2 For equivalent system: 1/f_eq = 2(μ₂-μ₁)/μ₁ · (R₁+R₂)/(R₁R₂) + 2/R₂ Simplifying: 1/f_eq = 2[μ₁R₁ + μ₂R₂ - μ₁R₂]/(μ₁R₁R₂) For image to coincide with object (same size, real, inverted): u = 2f Therefore: u = μ₁R₁R₂/(μ₂R₁ + μ₂R₂ - μ₁R₂) This can be rewritten as: u = μ₁|R₁|.|R₂|/(μ₂(|R₁|+|R₂|)-μ₁|R₂|)
