If 0 < a < b < 1, and tan^(-1) a + tan^(-1) b = pi/4, then the value of (a+b) - ((a^2+b^2)/2) + ((a^3+b^3)/3) - ((a^4+b^4)/4) + ........... is

  1. (1) log_e 2
  2. (2) e
  3. (3) e^2 - 1
  4. (4) log_e (e/2)

Answer

Correct answer: Option 1

Solution

Given tan^(-1) a + tan^(-1) b = pi/4. Using the addition formula, tan((a+b)/(1-ab)) = pi/4, so (a+b)/(1-ab) = 1, which gives a + b = 1 - ab or a + b - 1 = -ab. The series (a+b) - ((a^2+b^2)/2) + ((a^3+b^3)/3) - ((a^4+b^4)/4) + ... can be rewritten using the expansion log(1+x) = x - x^2/2 + x^3/3 - x^4/4 + .... The series equals log(1+a) + log(1+b) = log((1+a)(1+b)) = log(1 + a + b + ab) = log(1 + (1-ab) + ab) = log(2) = log_e 2.
