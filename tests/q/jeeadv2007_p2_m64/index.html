Let f(x) = (x^2 - 6x + 5)/(x^2 - 5x + 6). Match the conditions/expressions in Column I with statements in Column II . Column I: (A) If -1 < x < 1, then f(x) satisfies (B) If 1 < x < 2, then f(x) satisfies (C) If 3 < x < 5, then f(x) satisfies (D) If x > 5, then f(x) satisfies Column II: (p) 0 < f(x) < 1 (q) f(x) < 0 (r) f(x) > 0 (s) f(x) < 1

Matrix match · Marks: +4 / -1.0

  1. (A) A → p, r, s ; B → q, s ; C → p,r, s ; D → q, s
  2. (B) A → p, q ; B → q, s ; C → q, s ; D → p, q
  3. (C) A → p, r, s ; B → q, s ; C → q, s ; D → p, r, s
  4. (D) A → p, r, s ; B → p, r ; C → p,r ; D → p, r, s

Answer

Correct answer: C

Solution

f(x) = (x - 1)(x - 5) / (x - 2)(x - 3) The graph of f(x) is shown (A) If -1 < x < 1 ⇒ 0 < f(x) < 1 (B) If 1 < x < 2 ⇒ f(x) < 0 (C) If 3 < x < 5 ⇒ f(x) < 0 (D) If x > 5 ⇒ 0 < f(x) < 1 [Graph shows a rational function with vertical asymptotes at x = 2 and x = 3, horizontal asymptote at y = 1, and zeros at x = 1 and x = 5. The function is positive on (-∞, 1), negative on (1, 2), negative on (2, 3), positive on (3, 5), and positive on (5, ∞), approaching y = 1 from below as x → ∞]
