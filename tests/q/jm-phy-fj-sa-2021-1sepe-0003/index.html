The half life period of radioactive element x is same as the mean life time of another radioactive element y. Initially they have the same number of atoms. Then:

  1. (1) x and y have same decay rate initially and later on different decay rate.
  2. (2) x and y decay at the same rate always.
  3. (3) x-will decay faster than y.
  4. (4) y-will decay faster than x.

Answer

Correct answer: Option 4

Solution

Given: (t_1/2)_x = (t_mean)_y. We know t_1/2 = (ln2)/λ and t_mean = 1/λ. So (ln2)/λ_x = 1/λ_y, which gives λ_x = (ln2)λ_y = 0.693λ_y. Given N_x = N_y = N_0. Activity A = λN. Initially A_x = λ_x N and A_y = λ_y N. As λ_x < λ_y, we have A_x < A_y. Therefore y will decay faster than x initially. Since λ values are constants, y will always decay faster than x.
