Let a = i + 4j + 2k, b = 3i - 2j + 7k and c = 2i - j + 4k. If a vector d satisfies d × b = c × b and d · a = 24, then |d|^2 is equal to

  1. (1) 323
  2. (2) 423
  3. (3) 313
  4. (4) 413

Answer

Correct answer: Option 4

Solution

From d × b = c × b, we get (d - c) × b = 0, which implies d - c = λb (since d and c are not parallel to b). So d = c + λb. Using d · a = 24: (c + λb) · a = 24. Calculate c · a = 2(1) + (-1)(4) + 4(2) = 2 - 4 + 8 = 6. Calculate b · a = 3(1) + (-2)(4) + 7(2) = 3 - 8 + 14 = 9. So 6 + 9λ = 24, giving λ = 2. Thus d = c + 2b = (2i - j + 4k) + 2(3i - 2j + 7k) = 8i - 5j + 18k. Therefore |d|^2 = 64 + 25 + 324 = 413.
