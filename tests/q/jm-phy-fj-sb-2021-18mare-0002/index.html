A TV transmission tower antenna is at a height of 20m. Suppose that the receiving antenna is at ground level (i) and (ii) a height of 5m. The increase in the antenna range in case (ii) relative to case (i) is in %. The value of n, to the nearest integer, is...........

Answer

Correct answer: 50

Solution

Using the formula d_tm = sqrt(2*R*h_transmitting) + sqrt(2*R*h_receiving), where R = 6.4 x 10^6 m. For case (i) with h_receiving = 0: d_tm = sqrt(2 x 64 x 10^5 x 20) = 16000 m. For case (ii) with h_receiving = 5m: d_tm = sqrt(2 x 64 x 10^5 x 20) + sqrt(2 x 64 x 10^5 x 5) = 16000 + 8000 = 24000 m. Percentage increment = (8000/16000) x 100 = 50
