Let x = m/n (m, n are co-prime natural numbers) be a solution of the equation cos(2sin^(-1) x) = 1/9 and let α, β (α > β) be the roots of the equation mx^2 - nx - m + n = 0. Then the point (α, β) lies on the line

  1. (1) 5x + 8y = 9
  2. (2) 5x - 8y = -9
  3. (3) 3x + 2y = 2
  4. (4) 3x - 2y = -2

Answer

Correct answer: Option 1

Solution

From cos(2sin^(-1) x) = 1/9, let sin^(-1) x = θ. Then cos(2θ) = 1/9. Using cos(2θ) = 1 - 2sin^2(θ) = 1/9, we get sin^2(θ) = 4/9, so x^2 = 4/9, thus x = 2/3 (since x > 0). Therefore m = 2, n = 3. The equation becomes 2x^2 - 3x - 2 + 3 = 0, or 2x^2 - 3x + 1 = 0. The roots are α = 1, β = 1/2. Point (1, 1/2) satisfies 5x + 8y = 5 + 4 = 9.
