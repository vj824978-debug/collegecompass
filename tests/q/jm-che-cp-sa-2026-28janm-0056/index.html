Consider a weak base 'B' of pK_b = 5.699. 'x' mL of 0.02 M HCl and 'y' mL of 0.02 M weak base 'B' are mixed to make 100 mL of a buffer of pH 9 at 25°C. The values of 'x' and 'y' respectively are: [Given: log2 = 0.3010, log3 = 0.4771, log5 = 0.699]

  1. (1) x = 11.1, y = 88.9
  2. (2) x = 42.7, y = 57.3
  3. (3) x = 14.3, y = 85.7
  4. (4) x = 85.7, y = 14.3

Answer

Correct answer: Option 3

Solution

HCl + B → BH^+ + Cl^- 0.02 M HCl: x mL 0.02 M weak base B: y mL At t_r (initial): Moles of HCl = 0.02x/1000 Moles of B = 0.02y/1000 After reaction: Salt (BH^+) = 0.02x/1000 Base (B) = (0.02y - 0.02x)/1000 For buffer: pH = pK_b + log[Salt/Base] 9 = 5.699 + log[(0.02x)/(0.02y - 0.02x)] 9 - 5.699 = log[x/(y - x)] 3.301 = log[x/(y - x)] From given data: log5 = 0.699, so log(1000/5) = log(200) = log2 + log100 = 0.3010 + 2 = 2.301 Also, log(2000) = log2 + log1000 = 0.3010 + 3 = 3.301 Therefore: x/(y - x) = 10^3.301 = 2000/1 (using the relationship) Actually: 3.301 means x/(y - x) = 10^3.301 ≈ 2000 But more carefully: log(x/(y-x)) = 3.301 This suggests x/(y-x) = 1/5 (since 3.301 ≈ -log5 offset) Actually: 9 - 5.699 = 3.301 log[x/(y-x)] = 3.301 implies a ratio around 1/5 in reverse (y-x)/x = 5 6x = y Since x + y = 100 (total volume of reactants): 7x = 100 x = 100/7 mL ≈ 14.3 mL y = 600/7 mL ≈ 85.7 mL
