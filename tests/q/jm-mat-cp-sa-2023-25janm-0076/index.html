Let vector a, vector b and vector c be three non zero vectors such that vector b · vector c = 0 and vector a × (vector b × vector c) = (vector b - vector c)/2. If vector d be a vector such that vector b · vector d = vector a · vector b, then (vector a × vector b) · (vector c × vector d) is equal to

  1. (1) 1/4
  2. (2) 1/2
  3. (3) -1/4
  4. (4) 3/4

Answer

Correct answer: Option 1

Solution

vector b(vector a · vector c) - vector c(vector a · vector b) = (vector b - vector c)/2 vector a · vector c = 1/2, vector a · vector b = 1/2 (vector a × vector b) · (vector c × vector d) = (vector b · vector d)(vector a · vector c) - (vector a · vector d)(vector b · vector c) = (vector a · vector b)(vector a · vector c) = 1/2 × 1/2 = 1/4
