If f(x) = ∫ 1/(x^(1/4)(1+x^(1/4))) dx, f(0) = -6, then f(1) is equal to:

  1. (1) log_e 2 + 2
  2. (2) 4(log_e 2 - 2)
  3. (3) 2 - log_e 2
  4. (4) 4(log_e 2 + 2)

Answer

Correct answer: Option 2

Solution

Let x = t^4, dx = 4t^3 dt. Then ∫ 1/(x^(1/4)(1+x^(1/4))) dx = ∫ 4t^3/(t(1+t)) dt = ∫ 4t/(1+t) dt = 4∫ ((t^2-1)+1)/(1+t) dt = 4∫ (t-1) + 1/(t+1) dt = 4[(t-1)^2/2 + ln(t+1)] + c. Substituting t = x^(1/4): f(x) = 2(x^(1/4)-1)^2 + 4ln(1+x^(1/4)) + c. Using f(0) = -6: 2 + 0 + c = -6, so c = -8. Thus f(1) = 2(1-1)^2 + 4ln(2) - 8 = 4ln(2) - 8 = 4(ln 2 - 2).
