The option(s) with the values of a and L that satisfy the following equation is(are) integral from 0 to 4π of e^t (sin^6 at + cos^4 at) dt ―――――――――――――――――――――――――――― = L ? integral from 0 to π of e^t (sin^6 at + cos^4 at) dt

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (A) a = 2, L = (e^(4π) - 1)/(e^π - 1)
  2. (B) (B) a = 2, L = (e^(4π) + 1)/(e^π + 1)
  3. (C) (C) a = 4, L = (e^(4π) - 1)/(e^π - 1)
  4. (D) (D) a = 4, L = (e^(4π) + 1)/(e^π + 1)

Answer

Correct answer: AC

Solution

Let ∫₀^π e^t(sin^a at + cos^4 at)dt = A I = ∫_π^(2π) e^t(sin^a at + cos^4 at)dt Put t = π + x dt = dx for a = 2 as well as a = 4 I = e^π ∫₀^π e^x(sin^a ax + cos^4 ax)dx I = e^π A Similarly ∫_(2π)^(3π) e^t(sin^a at + cos^4 at)dt = e^(2π)A So, L = (A + e^π A + e^(2π)A + e^(3π)A)/A = (e^(4π) - 1)/(e^π - 1) For both a = 2, 4
