Let in a triangle ABC, the length of the side AC be 6, the vertex B be (1, 2, 3) and the vertices A, C lie on the line (x - 6)/3 = (y - 7)/2 = (z - 7)/(-2). Then the area (in sq. units) of triangle ABC is

  1. (1) 42
  2. (2) 21
  3. (3) 56
  4. (4) 17

Answer

Correct answer: Option 2

Solution

Let M(3λ + 6, 2λ + 7, -2λ + 7) be a point on the line where vertices A and C lie. Vector BM = (3λ + 6 - 1, 2λ + 7 - 2, -2λ + 7 - 3) = (3λ + 5, 2λ + 5, -2λ + 4) Vector AC is along the direction of the line, so the direction vector is (3, 2, -2). For M to be the foot of perpendicular from B to line AC, we need: Vector AC · Vector BM = 0 3(3λ + 5) + 2(2λ + 5) + (-2)(-2λ + 4) = 0 9λ + 15 + 4λ + 10 + 4λ - 8 = 0 17λ + 17 = 0 λ = -1 So Vector BM = 3(-1) + 5, 2(-1) + 5, -2(-1) + 4 = (2, 3, 6) |Vector BM| = sqrt(4 + 9 + 36) = sqrt(49) = 7 The perpendicular distance from B to line AC is 7. Area of triangle ABC = (1/2) × base × height = (1/2) × AC × perpendicular distance from B = (1/2) × 6 × 7 = 21 sq. units
