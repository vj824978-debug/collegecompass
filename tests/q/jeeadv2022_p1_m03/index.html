In a study about a pandemic, data of 900 persons was collected. It was found that 190 persons had symptom of fever, 220 persons had symptom of cough, 220 persons had symptom of breathing problem, 330 persons had symptom of fever or cough or both, 350 persons had symptom of cough or breathing problem or both, 340 persons had symptom of fever or breathing problem or both, 30 persons had all three symptoms (fever, cough and breathing problem). If a person is chosen randomly from these 900 persons, then the probability that the person has at most one symptom is ________. Expression given: 2 + 3√7 + 4·2²

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 0.80

Solution

Let A denote the persons having symptoms of fever. B denote the persons having symptoms of cough C denote the persons having symptoms of breathing problem Given that n(A) = 190 n(B) = 220 n(C) = 220 n(A ∩ B ∩ C) = 30 n(A ∪ B) = 330 n(B ∪ C) = 350 n(C ∪ A) = 340 n(A ∪ B) = n(A) + n(B) - n(A ∩ B) ⟹ 330 = 190 + 220 - n(A ∩ B) ⟹ n(A ∩ B) = 80 Similarly n(B ∩ C) = 90 and n(C ∩ A) = 70 If we make the Venn diagram [Three overlapping circles representing sets A (fever), B (cough), and C (breathing problem). The regions show: A only = 70, B only = 80, C only = 90, A∩B only = 40, B∩C only = 60, A∩C only = 30, A∩B∩C = 50. Outside all circles = 480] n(A ∪ B ∪ C) = n(A) + n(B) + n(C) - n(A ∩ B) - n(B ∩ C) - n(C ∩ A) + n(A ∩ B ∩ C) = 190 + 220 + 220 - 80 - 90 - 70 + 30 = 420 ∴ Number of person having atmost one symptom = 480 + 70 + 80 + 90 = 720 ∴ Probability = 720/900 = 4/5 = 0.80
