Consider a curve y = y(x) in the first quadrant as shown in the figure. Let the area A₁ is twice the area A₂. Then the normal to the curve perpendicular to the line 2x - 12y = 15 does NOT pass through the point

  1. (1) (6, 21)
  2. (2) (8, 9)
  3. (3) (10, -4)
  4. (4) (12, -15)

Answer

Correct answer: Option 3

Solution

From the given condition A₁ = 2A₂ and A₁ + A₂ = xy - 8, we get A₁ = 2(xy - 8)/3. Differentiating ∫f(x)dx = 2(xf(x) - 8)/3 with respect to x gives f(x) = 2/3(xf'(x) + f(x)). This simplifies to 2f'(x)/f(x) = 1/x, which integrates to f'(x) = cx. Using the point (4, 2), we get c = 1, so y² = x. The slope of the curve is dy/dx = 1/(2y). The line 2x - 12y = 15 has slope 1/6, so the normal (perpendicular to this line) has slope -6. The equation of the normal is y = -6x + 57. Checking the options: (10, -4) gives -4 ≠ -6(10) + 57 = -3, so this point does NOT lie on the normal.
