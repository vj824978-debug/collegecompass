The increasing order of boiling points of the following compounds is -

  1. (1) (1) < (IV) < (II) < (I)
  2. (2) (2) (IV) < (I) < (II) < (III)
  3. (3) (3) (I) < (III) < (IV) < (II)
  4. (4) (4) (III) < (I) < (II) < (IV)

Answer

Correct answer: Option 1

Solution

BP ∝ dipolement(μ) Compound (I): para-cresol (4-methylphenol) ⇒ Shows hydrogen bonding from -O-H group only BP value = 202°C Compound (II): 4-nitrophenol ⇒ Shows strongest hydrogen bonding from both sides of -OH group as well as -NO2 group BP value = 279° Compound (III): 4-aminophenol ⇒ Shows stronger hydrogen from both side of -OH group as well as -NH2 group BP value = 284°C Compound (IV): 4-methoxyphenol (hydroquinone monomethyl ether) ⇒ Shows stronger hydrogen from one side -OH group and another side of -OCH3 group shows only dipole-dipole interaction BP value = 243°C Intermolecular forces strength: - Compound (II) has strongest hydrogen bonding (both OH and NO2 groups act as H-bond acceptors) - Compound (III) has very strong hydrogen bonding (both OH and NH2 groups can act as H-donors and acceptors) - Compound (IV) has moderate hydrogen bonding (only OH is strong H-bonding group; OCH3 is weak) - Compound (I) has weakest hydrogen bonding (only OH group) Hence correct order of boiling point is: (I) < (IV) < (III) < (II)
