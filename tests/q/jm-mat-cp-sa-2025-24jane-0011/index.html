If the system of equations x + 2y - 3z = 2, 2x + lambda*y + 5z = 5, 14x + 3y + mu*z = 33 has infinitely many solutions, then lambda + mu is equal to:

  1. (1) 13
  2. (2) 10
  3. (3) 11
  4. (4) 12

Answer

Correct answer: Option 4

Solution

For a system of linear equations to have infinitely many solutions, the determinant of the coefficient matrix must be zero and all cofactors (or minors related to the constants) must also be zero. D = |1 2 -3| |2 lambda 5| = 0, lambda*mu + 42*lambda - 4*mu + 107 = 0 |14 3 mu| D_1 = |2 2 -3| |5 lambda 5| = 2*lambda*mu + 99*lambda - 10*mu + 255 |33 3 mu| D_2 = |1 2 -3| |2 5 5| = 13 - mu |14 33 mu| D_3 = |1 2 2| |2 lambda 5| = 5*lambda + 5 |14 3 33| For infinitely many solutions: D = 0, D_1 = 0, D_2 = 0, D_3 = 0 From D_2 = 0: 13 - mu = 0 => mu = 13 From D_3 = 0: 5*lambda + 5 = 0 => lambda = -1 Check & verify for these values D & D_1 = 0: D = lambda*mu + 42*lambda - 4*mu + 107 = (-1)(13) + 42(-1) - 4(13) + 107 = -13 - 42 - 52 + 107 = 0 ✓ D_1 = 2*lambda*mu + 99*lambda - 10*mu + 255 = 2(-1)(13) + 99(-1) - 10(13) + 255 = -26 - 99 - 130 + 255 = 0 ✓ Therefore, lambda + mu = -1 + 13 = 12
