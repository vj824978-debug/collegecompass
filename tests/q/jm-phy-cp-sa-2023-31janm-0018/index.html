If R, XL and XC represent resistance, inductive reactance and capacitive reactance. Then which of the following is dimensionless:

  1. (1) R * XL / XC
  2. (2) R * XL * XC
  3. (3) R / sqrt(XL * XC)
  4. (4) R / (XL * XC)

Answer

Correct answer: Option 3

Solution

R = Resistance [XL] = [R] [XC] = [R] So, R / sqrt(XL * XC) is dimensionless. Dimensional analysis: [R / sqrt(XL * XC)] = [R] / sqrt([R] * [R]) = [R] / sqrt([R]^2) = [R] / [R] = [Dimensionless] Therefore, option (3) is dimensionless.
