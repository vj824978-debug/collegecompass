Let a line L pass through the point P(2, 3, 1) and be parallel to the line x + 3y - 2z - 2 = 0 = x - y + 2z. If the distance of L from the point (5, 3, 8) is alpha, then 3alpha^2 is equal to _________.

Answer

Correct answer: 158

Solution

L: (x - 2)/1 = (y - 3)/(-1) = (z - 1)/(-1) = lambda Any point on L can be taken as B(lambda + 2, -lambda + 3, -lambda + 1) Let A(5, 3, 8) So, AB · (i - j - k) = 0 [(lambda - 3) i - lambda j - (lambda + 7) k] · [i - j - k] = 0 lambda - 3 + lambda + lambda + 7 = 0 Therefore, lambda = -4/3 AB = (13/3) i + (4/3) j - (17/3) k |AB| = sqrt(169/9 + 16/9 + 289/9) = sqrt(474/3) = alpha 3alpha^2 = (474/3) × 3 = 474
