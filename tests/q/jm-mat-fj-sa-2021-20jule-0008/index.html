The sum of all the local minimum values of the twice differentiable function f: R → R defined by f(x) = x^3 - 3x^2 - 3f''(2)/2 x + f''(1) is:

  1. (1) -22
  2. (2) 5
  3. (3) 0
  4. (4) -27

Answer

Correct answer: Option 4

Solution

Given f(x) = x^3 - 3x^2 - 3f''(2)/2 x + f''(1). Taking derivatives: f'(x) = 3x^2 - 6x - 3f''(2)/2, f''(x) = 6x - 6. From f''(x) = 6x - 6, we get f''(2) = 12 - 6 = 6 and f''(1) = 6 - 6 = 0. Using f'(x) = 3x^2 - 6x - 9 = 0, solving gives x = 3 or x = -1. Since f''(2) = 6 > 0 and f''(-1) = -12 < 0, x = 3 is a local minimum and x = -1 is a local maximum. The local minimum value at x = 3 is f(3) = 27 - 27 - 27 + 0 = -27. Sum of all local minimum values = -27.
