The number of functions f, from the set A = {x ∈ N : x^2 - 10x + 9 ≤ 0} to the set B = {n^2 : n ∈ N} such that f(x) ≤ (x - 3)^2 + 1, for every x ∈ A, is ________.

Answer

Correct answer: 1440

Solution

First, find set A: x^2 - 10x + 9 ≤ 0 → (x-1)(x-9) ≤ 0 → A = {1, 2, 3, 4, 5, 6, 7, 8, 9}. Set B = {1, 4, 9, 16, 25, ...}. For each x ∈ A, find f(x) ≤ (x-3)^2 + 1: f(1) ≤ 5, f(2) ≤ 2, f(3) ≤ 1, f(4) ≤ 2, f(5) ≤ 5, f(6) ≤ 10, f(7) ≤ 17, f(8) ≤ 26, f(9) ≤ 37. Count valid values in B for each x: x=1 has 2 choices {1,4}, x=2 has 1 choice {1}, x=3 has 1 choice {1}, x=4 has 1 choice {1}, x=5 has 2 choices {1,4}, x=6 has 3 choices {1,4,9}, x=7 has 4 choices {1,4,9,16}, x=8 has 5 choices {1,4,9,16,25}, x=9 has 6 choices {1,4,9,16,25,36}. Total = 2 × 1 × 1 × 1 × 2 × 3 × 4 × 5 × 6 = 1440.
