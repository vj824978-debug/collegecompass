A KCl solution of conductivity 0.14 S m^(-1) shows a resistance of 4.19 Ω in a conductivity cell. If the same cell is filled with an HCl solution, the resistance drops to 1.03Ω. The conductivity of the HCl solution is ___×10^(-2) S m^(-1). (Round off to the nearest integer).

Answer

Correct answer: 57

Solution

Given: For KCl solution, κ = 0.14 S m^(-1), R = 4.19 Ω. For HCl solution, R = 1.03 Ω. Using κ = G'/R where G' = cell constant. Since G' is constant for the same cell: (κ × R)_KCl = (κ × R)_HCl. Therefore: 0.14 × 4.19 = κ × 1.03. κ for HCl = (0.14 × 4.19)/1.03 = 0.5869 S m^(-1) = 56.9 × 10^(-2) S m^(-1). Rounded to nearest integer: 57 × 10^(-2) S m^(-1).
