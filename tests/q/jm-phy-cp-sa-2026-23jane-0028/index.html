A block is sliding down on an inclined plane of slope theta and at an instant t = 0 this block is given an upward momentum so that it starts moving up on the inclined surface with velocity u. The distance (S) travelled by the block before its velocity become zero, is ____. (g = gravitational acceleration)

  1. (1) u^2/(2g*sin(theta))
  2. (2) 2u^2/(g*cos(theta))
  3. (3) u^2/(sqrt(2)*g*cos(theta))
  4. (4) u^2/(2g*cos(theta))

Answer

Correct answer: Option 1

Solution

The block is moving up the inclined plane with initial velocity u. The acceleration acting on the block is due to gravity component along the plane, acting downward (opposite to motion). Acceleration: a = -g*sin(theta) Using the kinematic equation: V^2 = U^2 + 2as Where: - Final velocity V = 0 (when velocity becomes zero) - Initial velocity U = u - Acceleration a = -g*sin(theta) - Distance s = S (to be found) Substituting: 0 = u^2 + 2*(-g*sin(theta))*S 0 = u^2 - 2g*sin(theta)*S 2g*sin(theta)*S = u^2 S = u^2/(2g*sin(theta)) Note: None of the given options match this answer. The correct answer should be u^2/(2g*sin(theta)), which is not among options (1), (2), (3), or (4).
