Let ABC be a triangle with A(-3, 1) and angle AGB = 0, 0 < θ < π/2. If the equation of the median through B is 2x + y - 3 = 0 and the equation of angle bisector of C is 7x - 4y - 1 = 0, then tan θ is equal to:

  1. (1) 4/3
  2. (2) 3/4
  3. (3) 1/2
  4. (4) 2

Answer

Correct answer: Option 1

Solution

Line BM: 2x + y - 3 = 0 has M(0,3). Line CD: 7x - 4y - 1 = 0 has C(3,5). Mirror image of A(-3,1) in the line CD is (-13/5, -11/5) and it will lie on BC. Slope of AC is 2/3. Slope of BC is 18. Using the angle formula: tan θ = (18 - 2/3)/(1 + 18·(2/3)) = (52/3)/(13) = 4/3
