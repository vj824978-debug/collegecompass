Let a₁, a₂, a₃, ..... be an arithmetic progression with a₁ = 7 and common difference 8. Let T₁, T₂, T₃, ..... be such that T₁ = 3 and T_{n+1} - T_n = a_n for n ≥ 1. Then, which of the following is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) T₂₀ = 1604
  2. (B) sum_{k=1}^{20} T_k = 10510
  3. (C) T₃₀ = 3454
  4. (D) sum_{k=1}^{30} T_k = 35610

Answer

Correct answer: BC

Solution

B, C ∑(n=1 to n)[T(n+1) - T_n] = ∑a_n ⇒ T(n+1) - T_1 = ∑a_n = (n/2)[2×7 + (n-1)8] T(n+1) = n(4n + 3) + T_1 T(n+1) = 4n² + 3n + 3 (A) T_20 = 4 × 19² + 3 × 9 + 3 = 1444 + 27 + 3 = 1474 (B) ∑(k=0 to 19)T(n+1) = ∑(k=0 to 19)k(4k + 3) + 3 = ∑(k=0 to 19)(4k² + 3k + 3) = 10510 (C) T_30 = 29(4 × 29 + 3) + 3 = 3454 (D) ∑(k=1 to 30)T_k = ∑(n=0 to 29)T(n+1) = ∑(n=0 to 29)n(4n + 3) + 3 = 4 × (29 × 30 × 59)/6 + 3(29 × 30)/2 + 90 = 35615
