In a class of 140 students numbered 1 to 140, all even numbered students opted Mathematics course, those whose number is divisible by 3 opted Physics course and those whose number is divisible by 5 opted Chemistry course. Then the number of students who did not opt for any of the three courses is:

  1. (1) 42
  2. (2) 102
  3. (3) 1
  4. (4) 38

Answer

Correct answer: Option 4

Solution

Maths = {2, 4, 6, 8, ......, 138, 140} => n(M) = 70 Physics = {3, 6, 9, ......, 138} => n(P) = 46 Maths & physics = {6, 12, 18, ......, 138} => n(M ∩ P) = 23 Chem. = {5, 10, 15, 20, ......, 140} => n(C) = 28 Maths & Chem = {10, 20, ......, 140} => n(M ∩ C) = 14 Phy & Chem = {15, 30, ......, 135} => n(P ∩ C) = 9 All three subject = {30, 60, ......120} = 4 => n(P ∩ C ∩ M) = 4 = n(U) - n(P ∪ C ∪ M) Number of students without any subject opted = 140 - (70) - 46 - 28 + 23 + 14 + 9 - 4 = 0 = 42 - 4 = 38
