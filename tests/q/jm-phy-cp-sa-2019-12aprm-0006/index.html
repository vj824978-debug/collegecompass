A smooth wire of length 2π is bent into a circle and kept in a vertical plane. A bead can slide smoothly on the wire. When the circle is rotating with angular speed ω about the vertical diameter AB as shown in figure, the bead is at rest with respect to the circular ring at position P as shown. Then the value of ω^2 is equal to -

  1. (1) (g√3)/r
  2. (2) 2g/r
  3. (3) √(3g)/(2r)
  4. (4) 2g/(r√3)

Answer

Correct answer: Option 4

Solution

From the geometry of the circle with wire of length 2π: Radius r = 2π/(2π) = 1, but from circumference 2πr = 2π, so r is the radius. At position P, the bead is at rest with respect to the circular ring. The bead experiences: - Weight: mg (downward) - Normal force: N from the wire - Required centripetal force: mω^2·r·sin(θ) where θ is angle from vertical diameter AB From the figure, point P is at angle θ from the vertical axis where the horizontal distance from axis is r·sin(θ). Force balance: Horizontal (centripetal): mω^2·r·sin(θ) = N·sin(θ) Vertical: mg = N·cos(θ) + mω^2·r·sin(θ)·tan(θ) From the geometry shown, P is at position where r/2 is the distance from B (bottom), so: cos(θ) from center O means the vertical drop is r·cos(θ) The key equation from equilibrium: mω^2·(r/2)·sin(θ) = mg·cos(θ) From geometry: tan(θ) = √(r^2 - r^2/4)/(r/2) = √(3r^2/4)/(r/2) = (r√3/2)/(r/2) = √3 Therefore tan(θ) = √3, which gives θ = 60° From force balance: mω^2·r·sin(θ) = mg·cos(θ) ω^2 = (g·cos(θ))/(r·sin(θ)) = (g·cos(θ))/(r·sin(θ)) With tan(θ) = √3: sin(θ) = √3/2, cos(θ) = 1/2 ω^2 = (g·(1/2))/(r·(√3/2)) = g/(r√3) = g√3/(3r) = 2g/(r√3·2/√3) Simplifying: ω^2 = 2g/(r√3)
