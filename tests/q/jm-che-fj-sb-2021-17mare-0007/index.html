The number of chlorine atoms in 20 mL of chlorine gas at STP is _____×10^21 (Round off to the nearest integer) [Assume chlorine is an ideal gas at STP. R = 0.083 L bar mol^(-1) K^(-1), N_A = 6.023×10^23]

Answer

Correct answer: 1

Solution

Using ideal gas law PV = nRT: n = PV/(RT) = (1 bar × 0.020 L)/(0.083 L bar mol^(-1) K^(-1) × 273 K) = 8.8×10^(-4) mol. Number of Cl2 molecules = n × N_A = 8.8×10^(-4) × 6.023×10^23 = 5.3×10^20 molecules of Cl2. Since each Cl2 molecule has 2 chlorine atoms, number of Cl atoms = 5.3×10^20 × 2 = 1.06×10^21
