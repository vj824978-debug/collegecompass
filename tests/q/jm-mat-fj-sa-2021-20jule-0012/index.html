Let f:R - {α/6} → R be defined by f(x) = (5x+3)/(6x-α). Then the value of α for which (f of f)(x) = x, for all x ∈ R - {α/6}, is:

  1. (1) 6
  2. (2) 8
  3. (3) No such α exists
  4. (4) 5

Answer

Correct answer: Option 4

Solution

Given f(x) = (5x+3)/(6x-α). To find α such that f(f(x)) = x for all x in the domain. Let y = f(x) = (5x+3)/(6x-α), then solving for x: x = (αy+3)/(6y-5), so f^(-1)(x) = (αx+3)/(6x-5). According to the question, f(x) = f^(-1)(x), which means (5x+3)/(6x-α) = (αx+3)/(6x-5). Comparing coefficients: 5 = α and -α = -5, which gives α = 5.
