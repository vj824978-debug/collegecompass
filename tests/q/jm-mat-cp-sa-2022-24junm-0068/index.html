The set of all values of k for which (tan^(-1) x)^3 + (cot^(-1) x)^3 = kx^3, x ∈ ℝ, is the interval:

  1. (1) [1/32, 7/8]
  2. (2) [1/24, 13/16]
  3. (3) [1/48, 13/16]
  4. (4) [1/32, 9/8]

Answer

Correct answer: Option 1

Solution

Let tan^(-1) x = t, where t ∈ (-π/2, π/2). Then cot^(-1) x = π/2 - t. Define f(t) = t^3 + (π/2 - t)^3. Taking derivative: f'(t) = 3t^2 - 3(π/2 - t)^2. Setting f'(t) = 0 gives t = π/4. Find the range of f(t)/x^3 by analyzing critical points. The minimum occurs at t = π/4 and maximum occurs as t → ±π/2. Computing: f(t)_min = π^3/64 + π^3/64 = π^3/32 and f(t)_max = 7π^3/8. Therefore k ∈ [π^3/32, 7π^3/8] after dividing by x^3 and simplifying to [1/32, 7/8].
