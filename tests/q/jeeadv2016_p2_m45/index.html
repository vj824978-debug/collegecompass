Let f: ℝ → (0, ∞) and g: ℝ → ℝ be twice differentiable functions such that f' and g' are continuous functions on ℝ. Suppose f(2) = g(2) = 0, f'(2) ≠ 0 and g'(2) ≠ 0. If lim_{x→2} [f(x)g(x)]/[f'(x)g'(x)] = 1, then

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (A) f has a local minimum at x = 2
  2. (B) (B) f has a local maximum at x = 2
  3. (C) (C) f'(2) > f(2)
  4. (D) (D) f(x) - f''(x) = 0 for at least one x ∈ ℝ

Answer

Correct answer: AD

Solution

f(x)g(x) / [f'(x)g'(x)] = 1 ⟹ lim(x→2) [f'(x)g(x) + g'(x)f(x)] / [f''(x)g'(x) + f'(x)g''(x)] ⟹ g'(2)f(2) / [f''(2)g'(2)] = 1 ⟹ f(2) = f'(2) Since f(2) > 0, f'(2) > 0 ⟹ f has a local minimum at x = 2.
