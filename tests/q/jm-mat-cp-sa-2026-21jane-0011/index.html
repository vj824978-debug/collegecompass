If the area of the region {(x, y): 1 - 2x ≤ y ≤ 4 - x^2, x ≥ 0, y ≥ 0} is alpha/beta where alpha, beta ∈ N, gcd(alpha, beta) = 1, then the value of (alpha + beta) is:

  1. (1) 73
  2. (2) 85
  3. (3) 91
  4. (4) 67

Answer

Correct answer: Option 1

Solution

The region is bounded by: - Lower curve: y = 1 - 2x - Upper curve: y = 4 - x^2 - Constraints: x ≥ 0, y ≥ 0 Find intersection points: 1 - 2x = 4 - x^2 x^2 - 2x - 3 = 0 (x - 3)(x + 1) = 0 x = 3 or x = -1 Since x ≥ 0, we consider x = 3 (but we need to check where y = 0) For y = 1 - 2x = 0: x = 1/2 For y = 4 - x^2 = 0: x = 2 The region is divided: - From x = 0 to x = 1/2: bounded by y = 1 - 2x (lower) and y = 4 - x^2 (upper) - From x = 1/2 to x = 2: bounded by y = 0 (lower) and y = 4 - x^2 (upper) Required area = ∫[0 to 1/2] (4 - x^2 - (1 - 2x)) dx + ∫[1/2 to 2] (4 - x^2 - 0) dx = ∫[0 to 1/2] (3 + 2x - x^2) dx + ∫[1/2 to 2] (4 - x^2) dx First integral: [3x + x^2 - x^3/3] from 0 to 1/2 = 3(1/2) + (1/2)^2 - (1/2)^3/3 = 3/2 + 1/4 - 1/24 = 36/24 + 6/24 - 1/24 = 41/24 Second integral: [4x - x^3/3] from 1/2 to 2 = (8 - 8/3) - (2 - 1/24) = 24/3 - 8/3 - 2 + 1/24 = 16/3 - 2 + 1/24 = 16/3 - 6/3 + 1/24 = 10/3 + 1/24 = 80/24 + 1/24 = 81/24 Total area = 41/24 + 81/24 = 122/24 = 61/12 Wait, recalculating using the given formula: Required area = (2/3) × 8 - (1/2) × (1/2) × 1 = 16/3 - 1/4 = 64/12 - 3/12 = 61/12 So alpha/beta = 61/12 alpha = 61, beta = 12 gcd(61, 12) = 1 ✓ alpha + beta = 61 + 12 = 73
