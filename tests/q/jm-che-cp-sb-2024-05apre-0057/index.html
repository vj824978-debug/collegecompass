Consider the following single step reaction in gas phase at constant temperature. 2A(g) + B(g) → C(g). The initial rate of the reaction is recorded as r1 when the reaction starts with 1.5 atm pressure of A and 0.7 atm pressure of B. After some time, the rate r2 is recorded when the pressure of C becomes 0.5 atm. The ratio r1 : r2 is _______ × 10^(-1). (Nearest integer)

Answer

Correct answer: 315

Solution

For single step reaction: r = K[P_A]^2[P_B]. At initial state: r1 = K[1.5]^2[0.7]. When C = 0.5 atm, from stoichiometry 2A + B → C, we have: A decreases by 2×0.5 = 1.0 atm, B decreases by 0.5 atm. So P_A = 1.5 - 1.0 = 0.5 atm, P_B = 0.7 - 0.5 = 0.2 atm. r2 = K[0.5]^2[0.2]. r1/r2 = [1.5]^2[0.7] / [0.5]^2[0.2] = (2.25 × 0.7) / (0.25 × 0.2) = 1.575 / 0.05 = 31.5 = 315 × 10^(-1)
