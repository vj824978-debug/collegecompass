A(g) ⇌ 2B(g) + C(g). For the given reaction, if the initial pressure is 450 mm Hg and the pressure at time t is 720 mm Hg at a constant temperature T and constant volume V. The fraction of A(g) decomposed under these conditions is x × 10^(-1). The value of x is (nearest integer)

Answer

Correct answer: 3

Solution

Using ICE table for reaction A(g) ⇌ 2B(g) + C(g). Initial pressure of A = 450 mm Hg. Let x mm Hg of A decompose. At equilibrium: A has pressure (450-x), B has pressure 2x, C has pressure x. Total pressure = (450-x) + 2x + x = 450 + 2x = 720 mm Hg. Solving: 2x = 270, so x = 135 mm Hg. Fraction decomposed = 135/450 = 0.3 = 3 × 10^(-1). Therefore x = 3
