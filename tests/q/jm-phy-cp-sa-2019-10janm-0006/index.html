In the cube of side 'a' shown in the figure, the vector from the central point of the face ABOD to the central point of the face BEFO will be -

  1. (1) (1/2)a(k - i)
  2. (2) (1/2)a(j - i)
  3. (3) (1/2)a(j - k)
  4. (4) (1/2)a(i - k)

Answer

Correct answer: Option 2

Solution

Let side of cube is a coordinates of point 1 (central point of face ABOD): (a/2, 0, a/2) Vector r_1 = (a/2)i + (a/2)k coordinates of point 2 (central point of face BEFO): (0, a/2, a/2) Vector r_2 = (a/2)j + (a/2)k Vector from point 1 to point 2: vector r_2 - vector r_1 = (a/2)j + (a/2)k - (a/2)i - (a/2)k vector r_2 - vector r_1 = (a/2)j - (a/2)i vector r_2 - vector r_1 = (a/2)(j - i)
