Let f : R → R be a function defined as f(x) = { 5, if x ≤ 1; a + bx, if 1 < x < 3; b + 5x, if 3 ≤ x < 5; 30, if x ≥ 5 }. Then, f is

  1. (1) continuous if a = 0 and b = 5
  2. (2) continuous if a = -5 and b = 10
  3. (3) continuous if a = 5 and b = 5
  4. (4) not continuous for any values of a and b

Answer

Correct answer: Option 4

Solution

For f to be continuous at x = 1 f(1^-) = f(1^+) 5 = a + b ...(1) For f to be continuous at x = 3 f(3^-) = f(3^+) a + 3b = b + 15 a + 2b = 15 ...(2) From (1) & (2) 5 + b = 15 ⇒ b = 10 & a = -5 For f to be continuous at x = 5 f(5^-) = f(5^+) b + 25 = 30 b = 5 not continuous
