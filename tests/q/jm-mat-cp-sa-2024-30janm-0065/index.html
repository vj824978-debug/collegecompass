Let M denote the median of the following frequency distribution. Class: 0-4, 4-8, 8-12, 12-16, 16-20. Frequency: 3, 9, 10, 8, 6. Then 20M is equal to:

  1. (1) 52
  2. (2) 104
  3. (3) 208
  4. (4) 416

Answer

Correct answer: Option 3

Solution

Total frequency N = 3 + 9 + 10 + 8 + 6 = 36. N/2 = 18. Cumulative frequencies: 3, 12, 22, 30, 36. Median class is 8-12 (since CF = 22 > 18). Using median formula: M = l₁ + ((N/2 - C.f)/f) × h where l₁ = 8, N/2 = 18, C.f = 12, f = 10, h = 4. M = 8 + ((18-12)/10) × 4 = 8 + (6/10) × 4 = 8 + 12/5 = 8 + 2.4 = 10.4 = 52/5. Therefore 20M = 20 × (52/5) = 4 × 52 = 208.
