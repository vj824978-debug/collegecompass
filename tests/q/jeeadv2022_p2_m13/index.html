Let i, j and k be the unit vectors along the three positive coordinate axes. Let a = 3i + j - k, b = i + b₂j + b₃k, b₂,b₃ ∈ ℝ c = c₁i + c₂j + c₃k, c₁,c₂,c₃ ∈ ℝ be the vectors such that b₂·b₃ > 0, a·b = 0 and [0 -c₃ c₂] [1] [3-c₁] [c₃ 0 -c₁] [b₂] = [1-c₂] [-c₂ c₁ 0] [b₃] [-1-c₃] Then, which of the following is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) a·c = 0
  2. (B) b·c = 0
  3. (C) |b| > sqrt(10)
  4. (D) |c| ≤ sqrt(11)

Answer

Correct answer: BCD

Solution

ā · b̄ = 0 ⇒ 3 + b₂ - b₃ = 0 ⇒ |b̄| = √(1 + b₂² + b₃²) ⇒ |b̄| = √(2b₂² + 6b₂ + 10) = √(2(b₂)(b₂ + 3) + 10) ⇒ |b̄| = √(2b₂b₃ + 10) ⇒ |b̄| > 10 (∵ b₂b₃ > 0) Also, c̄ × b̄ = ā - c̄ ⇒ ā · b̄ = b̄ · c̄ = 0 Also, ā · c̄ = |c̄|² ⩽ |ā||c̄| ⇒ |c̄| ⩽ |ā| ⇒ |c̄| ⩽ √11 If ā · c̄ = 0 ⇒ |c̄| = 0 ⇒ c̄ = 0 ⇒ ā = 0 (which is not possible)
