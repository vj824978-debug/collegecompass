The correct order of ligands arranged in increasing field strength.

  1. (1) Cl^- < OH^- < Br^- < CN^-
  2. (2) F^- < Br^- < I^- < NH3
  3. (3) Br^- < F^- < H2O < NH3
  4. (4) H2O < OH^- < CN^- < NH3

Answer

Correct answer: Option 3

Solution

The spectrochemical series gives the order of ligands based on their field strength. The order is: I^- < Br^- < SCN^- < Cl^- < NO3^- < F^- < OH^- < H2O < NCS^- < NH3 < en < NO2^- < CN^-. Comparing option (3): Br^- < F^- < H2O < NH3 follows this order correctly with increasing field strength.
