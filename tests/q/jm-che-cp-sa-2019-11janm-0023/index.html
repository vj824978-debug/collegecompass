For the chemical reaction X ⇌ Y, the standard reaction Gibbs energy depends on temperature T (in K) as ΔrG° (in kJ mol^(-1)) = 120 - (3/8)T. The major component of the reaction mixture at T is:

  1. (1) Y if T = 300 K
  2. (2) Y if T = 280 K
  3. (3) X if T = 350 K
  4. (4) X if T = 315 K

Answer

Correct answer: Option 4

Solution

ΔrG° = 120 - (3/8)T For non spontaneous reaction ΔG° > 0 120 - (3/8)T > 0 120 > (3/8)T T < (120 × 8)/3 T < 320 K → X is major product For spontaneous reaction ΔG° < 0 120 - (3/8)T < 0 120 < (3/8)T T > (120 × 8)/3 T > 320 K → Y is major product At T = 300 K: ΔG° = 120 - (3/8)(300) = 120 - 112.5 = 7.5 > 0 (non-spontaneous) → X is major At T = 280 K: ΔG° = 120 - (3/8)(280) = 120 - 105 = 15 > 0 (non-spontaneous) → X is major At T = 350 K: ΔG° = 120 - (3/8)(350) = 120 - 131.25 = -11.25 < 0 (spontaneous) → Y is major At T = 315 K: ΔG° = 120 - (3/8)(315) = 120 - 118.125 = 1.875 > 0 (non-spontaneous) → X is major Therefore, option (4) X if T = 315 K is correct.
