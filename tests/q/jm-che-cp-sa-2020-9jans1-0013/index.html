A, B and C are three biomolecules. The results of the tests performed on them are given below: A: Molisch's Test Positive, Barfood Test Negative, Biuret Test Negative. B: Molisch's Test Positive, Barfood Test Positive, Biuret Test Negative. C: Molisch's Test Negative, Barfood Test Negative, Biuret Test Positive. A, B and C are respectively:

  1. (1) A = Lactose, B = Glucose, C = Alanine
  2. (2) A = Lactose, B = Glucose, C = Albumin
  3. (3) A = Glucose, B = Fructose, C = Albumin
  4. (4) A = Lactose, B = Fructose, C = Alanine

Answer

Correct answer: Option 2

Solution

To identify the biomolecules, we need to understand what each test detects: Molisch's Test: Detects carbohydrates (reduces phenol-H2SO4 to give purple ring) Barfood Test: Detects reducing sugars (aldehyde group present) Biuret Test: Detects proteins (peptide bonds present) Analyzing the results: Compound A: Molisch's Positive, Barfood Negative, Biuret Negative - Molisch's positive indicates it is a carbohydrate - Barfood negative indicates it is NOT a reducing sugar - Therefore, A must be a non-reducing sugar like Lactose Compound B: Molisch's Positive, Barfood Positive, Biuret Negative - Molisch's positive indicates it is a carbohydrate - Barfood positive indicates it is a reducing sugar - Therefore, B must be a reducing sugar like Glucose Compound C: Molisch's Negative, Barfood Negative, Biuret Positive - Molisch's negative indicates it is NOT a carbohydrate - Biuret positive indicates it is a protein - Therefore, C must be a protein like Albumin Thus: A = Lactose, B = Glucose, C = Albumin
