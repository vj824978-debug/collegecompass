Let a and b be two unit vectors such that |(a + b) + 2(a × b)| = 2. If θ ∈ (0, π) is the angle between a and b, then among the statements: (S1): 2(a × b) = |a - b| (S2): The projection of a on (a + b) is 1/2

  1. (1) Only (S1) is true
  2. (2) Only (S2) is true
  3. (3) Both (S1) and (S2) are true
  4. (4) Both (S1) and (S2) are false

Answer

Correct answer: Option 3

Solution

Given: |(a + b) + 2(a × b)| = 2 where |a| = |b| = 1. Squaring: |a + b + 2(a × b)|^2 = 4. Expanding: |a|^2 + |b|^2 + 4|a × b|^2 + 2a·b = 4. Since |a × b| = sin(θ) and a·b = cos(θ): 1 + 1 + 4sin^2(θ) + 2cos(θ) = 4. This gives cos(θ) = cos(2θ), so θ = 2π/3. For (S1): 2|a × b| = 2sin(2π/3) = √3 and |a - b| = sqrt(2 - 2cos(2π/3)) = √3. So (S1) is true. For (S2): projection = a·(a + b)/|a + b| = (1 + cos(2π/3))/|a + b| = (1/2)/1 = 1/2. So (S2) is true.
