Given (b+c)/11 = (c+a)/12 = (a+b)/13 for a triangle ABC with usual notation. If cos(A)/alpha = cos(B)/beta = cos(C)/gamma, then the ordered triad (alpha, beta, gamma) has a value

  1. (1) (19, 7, 25)
  2. (2) (7, 19, 25)
  3. (3) (5, 12, 13)
  4. (4) (3, 4, 5)

Answer

Correct answer: Option 1

Solution

b + c = 11k a + c = 12k a + b = 13k 2(a + b + c) = 36k a + b + c = 18k From the equations: a = 18k - 11k = 7k c = 18k - 13k = 5k b = 18k - 12k = 6k Using the law of cosines: cos(A) = (b^2 + c^2 - a^2)/(2bc) = (36k^2 + 25k^2 - 49k^2)/(2 × 6k × 5k) = 12k^2/(60k^2) = 1/5 cos(B) = (c^2 + a^2 - b^2)/(2ca) = (25k^2 + 49k^2 - 36k^2)/(2 × 5k × 7k) = 38k^2/(70k^2) = 19/35 cos(C) = (b^2 + a^2 - c^2)/(2ab) = (36k^2 + 49k^2 - 25k^2)/(2 × 7k × 6k) = 60k^2/(84k^2) = 5/7 Given: cos(A)/alpha = cos(B)/beta = cos(C)/gamma = lambda (1/5)/alpha = (19/35)/beta = (5/7)/gamma alpha = 1/(5lambda) beta = 19/(35lambda) gamma = 5/(7lambda) alpha : beta : gamma = (1/5) : (19/35) : (5/7) Multiplying by common denominator 35: alpha : beta : gamma = 7 : 19 : 25 Therefore, (alpha, beta, gamma) = (7, 19, 25)
