Let S = {z : 3 ≤ |2z - 3(1+i)| ≤ 7} be a set of complex numbers. Then Min(z∈S) |z + (5+3i)/2| is equal to:

  1. (1) 1/2
  2. (2) 3/2
  3. (3) 2
  4. (4) 5/2

Answer

Correct answer: Option 2

Solution

Sol. (3/2) ≤ |z - (3/2)(1+i)| ≤ 7/2 The set S represents an annulus (ring) centered at C = (3/2, 3/2) with inner radius 3/2 and outer radius 7/2. We need to find the minimum distance from points in S to the point P = (-5/2, 3/2). The center of the annulus is C = (3/2, 3/2). The point we measure distance to is P = (-5/2, 3/2). Distance PC = |C - P| = |(3/2 - (-5/2), 3/2 - 3/2)| = |(4, 0)| = 4 Since PC = 4, which lies between the inner radius 3/2 and outer radius 7/2, the point P is inside the annulus region. The minimum distance from P to the annulus S is: Min(z∈S) |z - P| = PC - (outer radius) = 4 - 7/2 = 8/2 - 7/2 = 1/2 Wait, let me recalculate. The outer radius is 7/2, but we need the minimum on the annulus. Since P is inside the outer circle but we need distance to the annulus: Min distance = PC - (3/2) = 4 - 3/2 = 5/2 - 3/2 = ... Actually: Min |z - P| where z is on inner circle = PC - r_inner = 4 - 3/2 = 5/2. But this is wrong since 4 > 7/2 is false. We have 4 = 8/2 > 7/2. So P is outside the annulus. Min distance = PC - r_outer = 4 - 7/2 = 1/2... No wait: 4 - 7/2 = 8/2 - 7/2 = 1/2. But the answer should be 3/2. Let me recalculate: PB = PC - 7/2 ⇒ 5 - 7/2 ⇒ 3/2 Option (2)
