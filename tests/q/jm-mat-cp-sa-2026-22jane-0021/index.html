Let a vector = sqrt(2)*i - j + lambda*k, lambda > 0, make an obtuse angle with the vector b = -lambda^2*i + 4*sqrt(2)*j + 4*sqrt(2)*k and an angle theta, pi/6 < theta < pi/2, with the positive z-axis. If the set of all possible values of lambda is (alpha, beta) - {gamma}, then alpha + beta + gamma is equal to ____.

Answer

Correct answer: 5

Solution

a · k / |a| = cos(theta) => lambda / sqrt(3 + lambda^2) = cos(theta) => 0 < lambda / sqrt(3 + lambda^2) < sqrt(3)/2 => lambda > 0 & 4*lambda^2 < 9 + 3*lambda^2 => lambda^2 < 9 => lambda in (0, 3) .....(1) => a · b < 0 => -sqrt(2)*lambda^2 - 4*sqrt(2) + 4*sqrt(2)*lambda < 0 => lambda^2 - 4*lambda + 4 > 0 => (lambda - 2)^2 > 0 => lambda ≠ 2 .....(2s) from (1) & (2) lambda in (0, 3) - {2} ∴ alpha = 0, beta = 3, gamma = 2 => alpha + beta + gamma = 5
