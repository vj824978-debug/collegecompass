The Boolean expression Y = ABC + AC can be realised with which of the following gate configurations. A. One 3-input AND gate, 3 NOT gates and one 2-input OR gate, One 2-input AND gate. B. One 3-input AND gate, 1 NOT gate and one 2-input NOR gate one 2-input OR gate. C. 3-input OR gate, 3 NOT gates and one 2-input AND gate.

  1. (1) A,C only
  2. (2) A,B,C only
  3. (3) A,B only
  4. (4) B,C only

Answer

Correct answer: Option 3

Solution

Simplify Y = ABC + AC. Factor out A: Y = A(BC + C). Factor out C: Y = A(C(B + 1)). Since B + 1 = 1, Y = AC. Now check which configurations can realize Y = AC: Configuration A uses 3-input AND, 3 NOTs, 2-input OR, 2-input AND - can realize AC. Configuration B uses 3-input AND, 1 NOT, NOR, OR - cannot efficiently realize simple AC. Configuration C uses 3-input OR, 3 NOTs, 2-input AND - can realize AC using De Morgan's laws. Verify A and C work.
