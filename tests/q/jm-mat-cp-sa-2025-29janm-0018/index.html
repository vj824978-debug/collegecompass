Let x₁, x₂,....,x₁₀ be ten observations such that Σ(xᵢ - 2) = 30, Σ(xᵢ - β)² = 98, β > 2 and their variance is 4/5. If μ and σ² are respectively the mean and the variance of 2(x₁ - 1) + 4β, 2(x₂ - 1) + 4β, ...., 2(x₁₀ - 1) + 4β, then βμ/σ² is equal to:

  1. (1) 100
  2. (2) 110
  3. (3) 120
  4. (4) 90

Answer

Correct answer: Option 1

Solution

Given: Σ(xᵢ - 2) = 30 Σ(xᵢ - β)² = 98 Variance = 4/5 β > 2 From Σ(xᵢ - 2) = 30: Σxᵢ - 20 = 30 Σxᵢ = 50 Mean of xᵢ = 50/10 = 5 Using variance formula: 4/5 = Σx²ᵢ/10 - (Σxᵢ/10)² 4/5 = Σx²ᵢ/10 - 25 Σx²ᵢ/10 = 4/5 + 25 Σx²ᵢ = 10(4/5 + 25) = 8 + 250 = 258 Now, Σ(xᵢ - β)² = 98 Σ(x²ᵢ - 2βxᵢ + β²) = 98 258 - 2β(50) + 10β² = 98 258 - 100β + 10β² = 98 10β² - 100β + 160 = 0 β² - 10β + 16 = 0 (β - 2)(β - 8) = 0 β = 2 or β = 8 Since β > 2, we have β = 8 For the new observations: 2(xᵢ - 1) + 4β, 2(x₂ - 1) + 4β,...., 2(x₁₀ - 1) + 4β = 2xᵢ + (4β - 2), 2x₂ + (4β - 2),...., 2x₁₀ + (4β - 2) Mean μ = 2(mean of xᵢ) + (4β - 2) μ = 2(5) + 4(8) - 2 μ = 10 + 32 - 2 = 40 Variance σ² = 2²(variance of xᵢ) σ² = 4 × 4/5 = 16/5 Therefore: βμ/σ² = (8 × 40)/(16/5) = 320 × 5/16 = 1600/16 = 100
