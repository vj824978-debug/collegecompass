In a series LR circuit, power of 400 W is dissipated from a source of 250 V, 50 Hz. The power factor of the circuit is 0.8. In order to bring the power factor to unity, a capacitor of value C is added in series to the L and R. Taking the value of C as (n/(3*pi)) µF, then value of n is ________.

Answer

Correct answer: 400.00

Solution

Given: Power dissipated, P = 400 W Voltage, E_rms = 250 V Frequency, f = 50 Hz Power factor, cos(phi) = 0.8 From the power equation: P = E_rms^2 * cos(phi) / Z 400 = (250)^2 * 0.8 / Z 400 = 62500 * 0.8 / Z 400 = 50000 / Z Z = 125 Ω From the impedance triangle: cos(phi) = 0.8 sin(phi) = sqrt(1 - cos^2(phi)) = sqrt(1 - 0.64) = sqrt(0.36) = 0.6 Resistance: R = Z * cos(phi) = 125 * 0.8 = 100 Ω Reactance: X_L - X_C = Z * sin(phi) = 125 * 0.6 = 75 Ω Since initially only L and R are in circuit: X_L = 75 Ω To bring power factor to unity (cos(phi) = 1), we need X_L = X_C X_L = 2*pi*f*L = 75 L = 75 / (2*pi*50) = 75 / (100*pi) = 0.75 / pi H For unity power factor: X_C = X_L = 75 Ω X_C = 1 / (2*pi*f*C) = 75 C = 1 / (2*pi*f*75) = 1 / (2*pi*50*75) C = 1 / (7500*pi) F C = 1000000 / (7500*pi) µF C = 133.33... / pi µF C = 400 / (3*pi) µF Comparing with C = (n / (3*pi)) µF: n = 400
