Let R^2 denote R × R. Let S = {(a,b,c) : a,b,c ∈ R and ax^2 + 2bxy + cy^2 > 0 for all (x,y) ∈ R^2 − {(0,0)}} Then which of the following statements is (are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (2, 7/2, 6) ∈ S
  2. (B) If (3, b, 1/12) ∈ S, then |2b| < 1
  3. (C) For any given (a,b,c) ∈ S, then the system of linear equations ax + by = 1 bx + cy = −1 has a unique solution.
  4. (D) For any given (a,b,c) ∈ S, then the system of linear equations (a + 1)x + by = 0 bx + (c + 1)y = 0 has a unique solution.

Answer

Correct answer: BCD

Solution

6. ax² + 2bxy + cy² > 0 a, c > 0, b² < ac (A) (2, 7/2, 6) ∈ S is incorrect (B) (3, b, 1/12) ∈ S then |2b| < 1 b² < 1/4 ⟹ |2b| < 1 (C) ax + by = 1 bx + cy = -1 Δ = ac - b² ≠ 0 unique solution. (D) (a + 1)x + by = 0 bx + (c + 1)y = 0 Δ = |a + 1 b | |b (c + 1)| = (a + 1)(c + 1) - b² ⟹ at - b² + a + c + 1 > 0 hence unique solution.
