Given below is the plot of the molar conductivity vs sqrt(C) concentration for KCl in aqueous solution. If, for the higher concentration of KCl solution, the resistance of the conductivity cell is 100 Ohm, then the resistance of the same cell with the dilute solution is "x" Ohm. The value of x is ________ (Nearest integer)

Answer

Correct answer: 150

Solution

R = rho * ℓ/A From the graph: - For higher concentration at sqrt(C) = 0.1 (mol/L)^(1/2), A_m (molar conductivity) = 150 S·cm·mol^(-1) - For dilute solution at sqrt(C) = 0.15 (mol/L)^(1/2), A_m = 100 S·cm·mol^(-1) Given: R_c = 100 Ohm (for concentrated solution) Using the relationship: K_d/K_c = R_c/R_d Where K = A_m * C (conductance) For the conductivity cell: (A_m,d * C_d) / (A_m,c * C_c) = R_c / R_d From graph at sqrt(C) = 0.1: C_c = 0.01 mol/L, A_m,c = 150 S·cm·mol^(-1) From graph at sqrt(C) = 0.15: C_d = 0.0225 mol/L, A_m,d = 100 S·cm·mol^(-1) (100 × 0.0225) / (150 × 0.01) = 100 / R_d 2.25 / 1.5 = 100 / R_d 1.5 = 100 / R_d R_d = 100 / 1.5 = 66.67 Ohm Alternatively, using the linear relationship from the plot: 100 × (0.15)^2 / (150 × (0.1)^2) = R_d / 100 100 × 0.0225 / (150 × 0.01) = R_d / 100 2.25 / 1.5 = R_d / 100 1.5 = R_d / 100 R_d = 150 Ohm
