Which of the following electronegativity order is incorrect?

  1. (1) Al < Mg < B < N
  2. (2) Al < Si < C < N
  3. (3) Mg < Be < B < N
  4. (4) S < Cl < O < F

Answer

Correct answer: Option 1

Solution

To determine which electronegativity order is incorrect, we need to check the electronegativity values on the Pauling scale: Li (E.N.) = 1, Be = 1.5, B = 2, C = 2.5, N = 3, O = 3.5, F = 4.0 Na = 0.9, Mg = 1.2, Al = 1.5, Si = 1.8, P = 2.1, S = 2.5, Cl = 3.0 Checking each option: (1) Al < Mg < B < N Al = 1.5, Mg = 1.2, B = 2, N = 3 This gives 1.5 < 1.2 < 2 < 3, which is INCORRECT because 1.5 is NOT less than 1.2 The correct order should be Mg < Al < B < N (1.2 < 1.5 < 2 < 3) (2) Al < Si < C < N Al = 1.5, Si = 1.8, C = 2.5, N = 3 This gives 1.5 < 1.8 < 2.5 < 3, which is CORRECT (3) Mg < Be < B < N Mg = 1.2, Be = 1.5, B = 2, N = 3 This gives 1.2 < 1.5 < 2 < 3, which is CORRECT (4) S < Cl < O < F S = 2.5, Cl = 3.0, O = 3.5, F = 4.0 This gives 2.5 < 3.0 < 3.5 < 4.0, which is CORRECT Therefore, option (1) is incorrect.
