Let a and b be two unit vectors such that the angle between them is pi/4. If θ is the angle between the vectors (a + b) and (a + 2b + 2(a × b)), then the value of 164 cos² θ is equal to:

  1. (1) 90 + 27√2
  2. (2) 45 + 18√2
  3. (3) 90 + 3√2
  4. (4) 54 + 90√2

Answer

Correct answer: Option 1

Solution

Given |a| = |b| = 1 and angle between them is π/4. So a·b = cos(π/4) = 1/√2. Let c = a × b, then c·a = 0 and c·b = 0. |c| = sin(π/4) = 1/√2. Calculate |a + b|² = 2 + 2(1/√2) = 2 + √2. Calculate |a + 2b + 2c|² = 1 + 4 + 4(4) + 4a·b + 8b·c + 4c·a = 7 + 2√2. Find (a + b)·(a + 2b + 2c) = 1 + 2/√2 + 1/√2 + 2 = 3 + 3/√2. Then cos θ = (3 + 3/√2)/[√(2 + √2)·√(7 + 2√2)]. After simplification, 164 cos² θ = 90 + 27√2.
