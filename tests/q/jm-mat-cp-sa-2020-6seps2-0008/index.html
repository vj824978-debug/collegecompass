Let z = x + iy be a non-zero complex number such that z^2 = i|z|^2, where i = sqrt(-1), then z lies on the:

  1. (1) imaginary axis
  2. (2) real axis
  3. (3) line, y = x
  4. (4) line, y = -x

Answer

Correct answer: Option 3

Solution

z = x + iy z^2 = i|z|^2 (x + iy)^2 = i(x^2 + y^2) (x^2 - y^2) - i(x^2 + y^2 - 2xy) = 0 (x^2 - y^2) - i(x - y)^2 = 0 (x - y)(x + y) - i(x - y)^2 = 0 (x - y)((x + y) - i(x - y)) = 0 Since z is non-zero, x - y = 0 => x = y z lies on y = x
