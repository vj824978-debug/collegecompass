For any complex number w = c + id, let arg(w) ∈ (-π, π], where i = sqrt(-1). Let α and β be real numbers such that for all complex numbers z = x + iy satisfying arg((z + α)/(z + β)) = π/4, then ordered pair (x, y) lies on the circle x^2 + y^2 + 5x - 3y + 4 = 0. Then which of the following statements is(are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) α = -1
  2. (B) αβ = 4
  3. (C) αβ = -4
  4. (D) β = 4

Answer

Correct answer: BD

Solution

Sol. B, D w = c + id, arg(w) ∈ (-π, π] arg((z + α)/(z + β)) = π/4 ; z₀ = -5/2 + 3i/2 z₀ + α = (z₀ + β)i ; z₀ + α = z₀i + βi ; z₀(1 - i) = βi - α (by Rotation) -5/2 + 3i/2 + α = (-5/2 + 3i/2)i + βi ; -5/2 + 3i/2 + α = -5i/2 - 3/2 + βi -5/2 + 3/2 + α = -5/2 - 3/2 + βi ; -1 + 4i = βi - α (As α, β are real number) ⟹ -α = -1, α = 1 ; β = 4 [Circle diagram showing point z at angle π/4 on circle, with radius marked as √(5/2)² + (3/2)² = √(25/4 + 9/4) = √(34/4), and points marked at (-β) and (-α) on real axis]
