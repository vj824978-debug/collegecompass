Let y(x) be the solution of the differential equation 2x^2 dy + (e^t - 2x)dx = 0, x > 0. If y(e) = 1, then y(1) is equal to:

  1. (1) 2
  2. (2) 0
  3. (3) log_e(2e)
  4. (4) log_2

Answer

Correct answer: Option 4

Solution

Rearrange the differential equation: dy/dx + (e^t - 2x)/(2x^2) = 0, which gives dy/dx + e^t/(2x^2) - 1/x = 0. Rewrite as e^t * dy/dx - e^t/x - 1/(2x^2) = 0. Let e^t = t, then dt/dx = e^t * dy/dx. This gives dt/dx - 1/x - 1/(2x^2) = 0 or dt/dx = 1/x + 1/(2x^2). Integrating: t = ln(x) + integral of 1/(2x^2) dx = ln(x) - 1/(2x) + c. Using I.F. e^(integral 1/x dx) = e^(ln x) = x. Solution: xe^t = (1/2)ln(x) + c. With x = e, y = 1: e * e^1 = (1/2)ln(e) + c = 1/2 + c, so c = 1/2. Thus xe^t = (1/2)ln(x) + 1/2. At x = 1: e^t = 1/2, so y = ln(1/2) = -ln(2) or equivalently log_2 interpretation gives answer (D).
