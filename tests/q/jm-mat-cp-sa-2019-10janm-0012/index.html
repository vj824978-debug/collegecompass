Let f : R → R be a function such that f(x) = x^3 + x^2f'(1) + xf''(2) + f'''(3), x ∈ R. Then f(2) equals

  1. (1) 30
  2. (2) -2
  3. (3) -4
  4. (4) 8

Answer

Correct answer: Option 2

Solution

f(x) = x^3 + x^2f'(1) + xf''(2) + f'''(3), x ∈ R f'(x) = 3x^2 + 2xf'(1) + f''(2) ⇒ f'(1) = 3 + 2f'(1) + f''(2) ⇒ f'(1) + f''(2) + 3 = 0 f''(x) = 6x + 2f'(1) ⇒ f''(2) = 12 + 2f'(1) ⇒ -f'(1) - 3 = 12 + 2f'(1) ⇒ f'(1) = -5 ; f''(2) = 2 f'''(x) = 6 ⇒ f'''(3) = 6 f(x) = x^3 - 5x^2 + 2x + 6 f(2) = 8 - 20 + 4 + 6 = -2
