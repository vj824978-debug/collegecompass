Let x = x(t) and y = y(t) be solutions of the differential equations dx/dt + ax = 0 and dy/dt + by = 0 respectively, where a, b ∈ R. Given that x(0) = 2; y(0) = 1 and 3y(1) = 2x(1), the value of t, for which x(t) = y(t), is:

  1. (1) log₄
  2. (2) log₂(2/3)
  3. (3) log₄(2/3)
  4. (4) log₃

Answer

Correct answer: Option 3

Solution

Solving dx/dt + ax = 0: x = 2e^(-at). Solving dy/dt + by = 0 with y(0) = 1: y = e^(-bt). Using 3y(1) = 2x(1): 3e^(-b) = 2(2e^(-a)) = 4e^(-a), so e^(b-a) = 4/3. For x(t) = y(t): 2e^(-at) = e^(-bt), so e^(b-a)t = 2. Taking logarithm: (b-a)t = ln 2, thus t·ln(4/3) = ln 2, giving t = ln₄(2/3) = log₄(2/3)
