The number of terms of an A.P is even, the sum of all odd terms is 24, the sum of all the even terms is 30 and the last term exceeds the first by 21/2. Then the number of terms which are integer in the A.P is:

  1. (1) 4
  2. (2) 8
  3. (3) 6
  4. (4) 10

Answer

Correct answer: Option 1

Solution

Let n be the number of terms (even). Let a be first term and d be common difference. Odd positioned terms: a, a+2d, a+4d, ... (n/2 terms). Even positioned terms: a+d, a+3d, a+5d, ... (n/2 terms). Sum of odd terms: (n/2)a + d(0+2+4+...+(n-2)) = (n/2)a + d*n(n-2)/4 = 24. Sum of even terms: (n/2)a + d(1+3+5+...+(n-1)) = (n/2)a + d*(n/2)^2 = 30. Last term - first term = a+(n-1)d - a = (n-1)d = 21/2. From equations: 30-24 = d*[(n/2)^2 - n(n-2)/4] = d*n/2 = 6, so d*n = 12. From (n-1)d = 21/2: nd - d = 21/2, so 12 - d = 21/2, giving d = 3/2. Then n = 8. Sum of odd terms gives: 4a + 3(0+1+2+3) = 4a + 18 = 24, so a = 3/2. Terms: 3/2, 3, 9/2, 6, 15/2, 9, 21/2, 12. Integer terms: 3, 6, 9, 12 = 4 terms.
