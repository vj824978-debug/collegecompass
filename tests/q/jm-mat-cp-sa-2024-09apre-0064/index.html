Let z be a complex number such that the real part of (z - 2i)/(z + 2i) is zero. Then, the maximum value of |z - (6 + 8i)| is equal to:

  1. (1) 12
  2. (2) ∞
  3. (3) 10
  4. (4) 8

Answer

Correct answer: Option 1

Solution

Given that real part of (z - 2i)/(z + 2i) = 0. Let z = x + yi. Then (z - 2i)/(z + 2i) = (x + (y-2)i)/(x + (y+2)i). Multiplying by conjugate and equating real part to zero: zz - 2iz + 2iz + 4(−1) + zz + 2zi + 2zi + 4(−1) = 0 gives 2|z|^2 = 8, so |z| = 2. This means z lies on a circle of radius 2 centered at origin. Maximum value of |z - (6 + 8i)| occurs when z is on the circle at the point farthest from (6 + 8i). Distance from origin to (6 + 8i) is sqrt(36 + 64) = 10. Maximum distance = 10 + 2 = 12.
