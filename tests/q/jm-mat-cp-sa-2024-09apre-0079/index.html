Let α, β; α > β, be the roots of the equation x^2 - sqrt(2)x - sqrt(3) = 0. Let P_n = α^n - β^n, n ∈ N. Then (11*sqrt(3) - 10*sqrt(2))P_10 + (11*sqrt(2) + 10)P_11 - 11*P_12 is equal to:

  1. (1) 10*sqrt(2)*P_9
  2. (2) 10*sqrt(3)*P_9
  3. (3) 11*sqrt(2)*P_9
  4. (4) 11*sqrt(3)*P_9

Answer

Correct answer: Option 2

Solution

From the given equation x^2 - sqrt(2)x - sqrt(3) = 0, both α and β satisfy it. For P_n = α^n - β^n, we can derive: α^(n+2) - sqrt(2)α^(n+1) - sqrt(3)α^n = 0 and β^(n+2) - sqrt(2)β^(n+1) - sqrt(3)β^n = 0. Subtracting these equations gives: P_(n+2) - sqrt(2)P_(n+1) - sqrt(3)P_n = 0, or P_(n+2) = sqrt(2)P_(n+1) + sqrt(3)P_n. For n=10: P_12 = sqrt(2)P_11 + sqrt(3)P_10. Substituting this into the given expression and simplifying yields 10*sqrt(3)*P_9.
