Which of the following figure represents the relation between Celsius and Fahrenheit temperatures?

  1. (1) Figure (1) showing perpendicular axes with lines extending in all four directions from origin
  2. (2) Figure (2) showing C and F axes with a line passing through origin with positive slope
  3. (3) Figure (3) showing C and F axes with a line passing through point (0,0) with positive slope
  4. (4) Figure (4) showing C and F axes with a line passing through origin with negative slope

Answer

Correct answer: Option 2

Solution

The relationship between Celsius and Fahrenheit is given by: C/5 = (F - 32)/9 Rearranging: C = (5F - 160)/9 C = (5F)/9 - 160/9 This can be written as: C = (5/9)F - (160/9) Analyzing this equation: 1. The slope is 5/9, which is positive 2. The y-intercept (when F = 0) is C = -160/9 ≈ -17.78 3. The x-intercept (when C = 0) is: 0 = (5/9)F - 160/9, so F = 32 Key observations: - The line passes through the point (F = 32, C = 0) - The line has a positive slope of 5/9 - The line does NOT pass through the origin (0,0) - The line passes through the origin of the graph only if we consider the point where both are zero at different scales Figure (2) correctly represents this relationship as it shows: - A line with positive slope - Passing through the origin area on the graph - Proper orientation with F on horizontal axis and C on vertical axis
