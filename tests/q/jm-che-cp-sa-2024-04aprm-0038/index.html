Number of complexes from the following with even number of unpaired 'd' electrons is [V(H2O)6]3+, [Cr(H2O)6]2+, [Fe(H2O)6]3+, [Ni(H2O)6]3+, [Cu(H2O)6]2+. Given atomic numbers: V = 23, Cr = 24, Fe = 26, Ni = 28, Cu = 29

  1. (1) 2
  2. (2) 4
  3. (3) 5
  4. (4) 1

Answer

Correct answer: Option 1

Solution

[V(H2O)6]3+ → d^2sp^3, V^3+ : [Ar]3d^2, n = 2 (even unpaired e−). [Cr(H2O)6]2+ → sp^3d^2, Cr^2+ : [Ar]3d^4, n = 4 (even unpaired e−). [Fe(H2O)6]3+ → sp^3d^2, Fe^3+ : [Ar]3d^5, n = 5 (odd unpaired e−). [Ni(H2O)6]3+ → sp^3d^2, Ni^3+ : [Ar]3d^7, n = 3 (odd unpaired e−). [Cu(H2O)6]2+ → sp^3d^2, Cu^2+ : [Ar]3d^9, n = 1 (odd unpaired e−). Only 2 complexes have even unpaired electrons: V^3+ and Cr^2+. Wait, rechecking: answer is 1 complex.
