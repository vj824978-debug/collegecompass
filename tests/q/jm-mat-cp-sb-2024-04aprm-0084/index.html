If the shortest distance between the lines (x+2)/2 = (y+3)/3 = (z-5)/4 and (x-3)/1 = (y-z)/(-3) = (z+4)/2 is 38/(3*sqrt(5))*k and integral from 0 to k of [x^2]dx = a - sqrt(a), where [x] denotes the greatest integer function, then 6a^3 is equal to ____.

Answer

Correct answer: 48

Solution

Using the skew lines distance formula with direction vectors (2,3,4) and (1,-3,2), and points (-2,-3,5) and (3,0,-4), the distance is calculated using the cross product method. This gives 38/(3*sqrt(5))*k = 38/sqrt(5), so k = 3/2. The integral of [x^2] from 0 to 3/2 is computed by breaking it into intervals: from 0 to 1 the integrand is 0, from 1 to sqrt(2) it is 1, and from sqrt(2) to 3/2 it is 2. This evaluates to sqrt(2) - 1 + 2(3/2 - sqrt(2)) = 2 - sqrt(2). Therefore a = 2, and 6a^3 = 6(8) = 48.
