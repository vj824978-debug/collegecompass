Passage: Consider the ellipses given by x² + 4y² = 1 and 4x² + y² = 1. Question: If α is the area of the common region that lies inside both the given ellipses, then the value of cot α is _____.

Comprehension · Marks: +3 / 0.0

Passage:

Answer

Correct answer: 0.75

Solution

Solution: The given ellipses are E₁ : x² + 4y² = 1 and E₂ : 4x² + y² = 1. By symmetry, the common region is symmetric about both the coordinate axes and the lines y = x and y = -x. The total area α is 8 times the area of the region in the first quadrant bounded by θ = 0 and θ = π/4. In polar coordinates, substituting x = r cos θ and y = r sin θ into the equation of E₂ (which is the inner boundary for 0 ≤ θ ≤ π/4), we get: 4r² cos² θ + r² sin² θ = 1 ⟹ r² = 1/(4cos² θ + sin² θ) The area of this sector is given by: A = 1/2 ∫₀^(π/4) r² dθ = 1/2 ∫₀^(π/4) 1/(4cos² θ + sin² θ) dθ Dividing the numerator and the denominator by cos² θ: A = 1/2 ∫₀^(π/4) sec² θ/(4 + tan² θ) dθ Substituting t = tan θ, we have dt = sec² θ dθ. The limits change from 0 to 1: A = 1/2 ∫₀¹ dt/(4 + t²) = 1/2 [1/2 arctan(t/2)]₀¹ = 1/4 arctan(1/2) The total area α of the common region is: α = 8A = 8 × 1/4 arctan(1/2) = 2 arctan(1/2) We need to find the value of cot α: cot α = cot(2 arctan(1/2)) Let φ = arctan(1/2), which implies tan φ = 1/2. Using the double angle formula for tangent: tan(2φ) = 2 tan φ/(1 - tan² φ) = 2(1/2)/(1 - (1/2)²) = 1/(1 - 1/4) = 1/(3/4) = 4/3 Therefore, cot α = 1/tan(2φ) = 3/4. Answer: 3/4
