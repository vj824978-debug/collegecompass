For some a, b, c ∈ N, let f(x) = ax - 3 and g(x) = x^b + c, x ∈ R. If (fog)^(-1)(x) = ((x - 7)/2)^(1/3), then (fog)(ac) + (gof)(b) is equal to ___.

Answer

Correct answer: 2039

Solution

f(x) = ax - 3 g(x) = x^b + c (fog)^(-1) = ((x - 7)/2)^(1/3) (fog)^(-1)(x) = ((x + 3 - ca)/a)^(1/b) = ((x - 7)/2)^(1/3) Comparing both sides: ⟹ a = 2, b = 3, c = 5 f(x) = 2x - 3 g(x) = x^3 + 5 fog(ac) + gof(b) = fog(10) + gof(3) = f(g(10)) + g(f(3)) = f(1000 + 5) + g(6 - 3) = f(1005) + g(3) = 2(1005) - 3 + 3^3 + 5 = 2010 - 3 + 27 + 5 = 2007 + 32 = 2039
