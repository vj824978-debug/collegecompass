Let {a_n} be a sequence such that a_0 = a_1 = 0 and a_{n+2} = 2a_{n+1} - a_n + 1 for all n ≤ 0. Then sum from n=2 to infinity of a_n/7^n is equal to:

  1. (1) 6/343
  2. (2) 7/216
  3. (3) 8/343
  4. (4) 49/216

Answer

Correct answer: Option 2

Solution

Using the recurrence relation a_{n+2} = 2a_{n+1} - a_n + 1 with a_0 = a_1 = 0, we compute: a_2 = 1, a_3 = 3, a_4 = 6, a_5 = 10. The sum S = sum(a_n/7^n) from n=2 to infinity. Writing S = 1/7^2 + 3/7^3 + 6/7^4 + 10/7^5 + ..., we manipulate using geometric series. Computing S/7 and finding 6S/7, we get 36S/49 = 7/(49×6), yielding S = 7/216.
