Let a line y = mx (m > 0) intersect the parabola, y^2 = x at a point P, other than the origin. Let the tangent to it at P meet the x-axis at the point Q. If area (triangle OQP) = 4 sq. units, then m is equal to ____.

Answer

Correct answer: 0.50

Solution

Given: Line y = mx (m > 0) intersects parabola y^2 = x at point P (other than origin). Find intersection point P: Substitute y = mx into y^2 = x (mx)^2 = x m^2 x^2 = x m^2 x^2 - x = 0 x(m^2 x - 1) = 0 So x = 0 or x = 1/m^2 Since P is not at origin, x = 1/m^2 Then y = mx = m(1/m^2) = 1/m So P = (1/m^2, 1/m) or P = (t^2, t) where t = 1/m Find tangent at P: For parabola y^2 = x, differentiating: 2y(dy/dx) = 1 dy/dx = 1/(2y) At point P(t^2, t), slope = 1/(2t) Tangent equation: y - t = (1/(2t))(x - t^2) 2ty - 2t^2 = x - t^2 2ty = x + t^2 Or: x = 2ty - t^2 Find point Q where tangent meets x-axis: Set y = 0 in tangent equation: x = 2t(0) - t^2 = -t^2 So Q = (-t^2, 0) Calculate area of triangle OQP: Vertices: O(0, 0), Q(-t^2, 0), P(t^2, t) Base OQ = |−t^2 − 0| = t^2 Height = perpendicular distance from P to x-axis = t Area = (1/2) × base × height = (1/2) × t^2 × t = t^3/2 Given area = 4: t^3/2 = 4 t^3 = 8 t = 2 Find m: Since t = 1/m: 2 = 1/m m = 1/2 = 0.50
