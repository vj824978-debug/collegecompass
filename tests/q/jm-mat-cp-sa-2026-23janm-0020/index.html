Let the direction cosines of two lines satisfy the equations: 4l + m - n = 0 and 2mn + 10nl + 3/m = 0. Then the cosine of the acute angle between these lines is:

  1. (1) 10/sqrt(38)
  2. (2) 20/(3*sqrt(38))
  3. (3) 10/(7*sqrt(38))
  4. (4) 10/(3*sqrt(38))

Answer

Correct answer: Option 4

Solution

Direction cosines of two lines satisfy the equations: => 4l + m - n = 0 ....(1) => 2mn + 10nl + 3/m = 0 ....(2) & we know => l^2 + m^2 + n^2 = 1 ....(3) => n = 4l + m putting in eqn. (2) => n(2m + 10l) + 3/m = 0 => (4l + m)(2m + 10l) + 3/m = 0 => 8l*m + 40l^2 + 2*m^2 + 10l*m + 3/m = 0 => 40l^2 + 21l/m + 2*m^2 = 0 => (8l + m)(5l + 2m) = 0 Case 1: 8l + m = 0 => m = -8l Case 2: 5l + 2m = 0 => m = -5l/2 So direction ratio of L_1 is l, -8l, -4l & direction ratio of L_2 is l, -5l/2, 3l/2 cos(theta) = |l^2 + 20l^2 - 6l^2| / (sqrt(l^2 + 64l^2 + 16l^2) * sqrt(l^2 + 25l^2/4 + 9l^2/4)) = 15l^2 / ((9l)*sqrt(38l^2/2)) = 15l^2 / ((9l)*sqrt(38)*l/sqrt(2)) = 10 / (3*sqrt(38)) Ans. = 10/(3*sqrt(38))
