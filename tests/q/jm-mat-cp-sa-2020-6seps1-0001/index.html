lim(x→1) [0 / ((x-1)sin(x-1))]

  1. (1) is equal to 1
  2. (2) is equal to 1/2
  3. (3) is equal to -1/2
  4. (4) does not exist

Answer

Correct answer: Option 4

Solution

lim(x→1) [∫[0 to (x-1)^2] t cos(t^2)dt] / [(x-1)sin(x-1)] (0/0) Apply L Hospital Rule lim(x→1) [2(x-1)·(x-1)^2·cos(x-1)^4 - 0] / [(x-1)·cos(x-1) + sin(x-1)] (0/0) = lim(x→1) [2(x-1)^3·cos(x-1)^4] / [(x-1)·cos(x-1) + sin(x-1)] = lim(x→1) [2(x-1)^3·cos(x-1)^4] / [(x-1)·[cos(x-1) + sin(x-1)/(x-1)]] = lim(x→1) [2(x-1)^2·cos(x-1)^4] / [cos(x-1) + sin(x-1)/(x-1)] On taking limit = 0 / (1 + 1) = 0
