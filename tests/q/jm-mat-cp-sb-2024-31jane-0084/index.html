Let y = y(x) be the solution of the differential equation sec^2(x) dx + (e^(2y) tan^2(x) + tanx)dy = 0, 0 < x < pi/2, y(pi/4) = 0. If y(pi/6) = alpha, then e^(8a) is equal to ______.

Answer

Correct answer: 9

Solution

Rewrite the differential equation as sec^2(x) dx/dy + e^(2y) tan^2(x) + tanx = 0. Substitute tanx = t, so sec^2(x) dx/dy = dt/dy. This gives dt/dy + e^(2y) t^2 + t = 0. Divide by t^2: (1/t^2) dt/dy + 1/t = -e^(2y). Substitute u = 1/t: -du/dy - u = -e^(2y), which gives du/dy - u = e^(2y). Using integrating factor e^(-y): (1/tanx) * e^(-y) = e^y + C. At x = pi/4, y = 0: 1 * 1 = 1 + C, so C = 0. At x = pi/6, y = alpha: sqrt(3) * e^(-alpha) = e^alpha. This gives e^(2alpha) = sqrt(3), so e^(8a) = (e^(2a))^4 = (sqrt(3))^4 = 9.
