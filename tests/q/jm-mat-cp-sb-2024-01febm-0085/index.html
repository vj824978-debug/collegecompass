Let A = {1, 2, 3, ..., 20}. Let R₁ and R₂ two relation on A such that R₁ = {(a, b) : b is divisible by a} and R₂ = {(a, b) : a is an integral multiple of b}. Then, number of elements in R₁ - R₂ is equal to ____.

Answer

Correct answer: 46

Solution

S = {1, 2, 3, ..., 20}. R₁ contains pairs (a,b) where b is divisible by a. Listed: (1,1), (1,2), ..., (1,20), (2,2), (2,4), ..., (2,20), (3,3), (3,6), ..., (3,18), (4,4), (4,8), ..., (4,20), (5,5), (5,10), ..., (5,20), (6,6), (6,12), (6,18), (7,7), (7,14), (8,8), (8,16), (9,9), (9,18), (10,10), (10,20), (11,11), (12,12), ..., (20,20). n(R₁) = 66. R₂ = {(a,b) : a is integral multiple of b}. R₁ ∩ R₂ = {(1,1), (2,2), ..., (20,20)}, n(R₁ ∩ R₂) = 20. Therefore, n(R₁ - R₂) = n(R₁) - n(R₁ ∩ R₂) = 66 - 20 = 46.
