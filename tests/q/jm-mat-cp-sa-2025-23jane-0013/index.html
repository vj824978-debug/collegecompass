Let the shortest distance from (a, 0), a > 0, to the parabola y^2 = 4x be 4. Then the equation of the circle passing through the point (a, 0) and the focus of the parabola, and having its centre on the axis of the parabola is:

  1. (1) x^2 + y^2 - 6x + 5 = 0
  2. (2) x^2 + y^2 - 4x + 3 = 0
  3. (3) x^2 + y^2 - 10x + 9 = 0
  4. (4) x^2 + y^2 - 8x + 7 = 0

Answer

Correct answer: Option 1

Solution

For parabola y^2 = 4x, we have 4a = 4, so a = 1. Focus is at (1, 0). For a point P on the parabola, let P(t^2, 2t). Shortest distance from R(a, 0) to parabola occurs along the normal at P. Normal at P: y + tx = 2t + t^3 This passes through (a, 0): 0 + ta = 2t + t^3 a = 2 + t^2 Distance PR = sqrt((a - t^2)^2 + (0 - 2t)^2) = sqrt((2 + t^2 - t^2)^2 + 4t^2) = sqrt(4 + 4t^2) = 2sqrt(1 + t^2) Given this distance = 4: 2sqrt(1 + t^2) = 4 sqrt(1 + t^2) = 2 1 + t^2 = 4 t^2 = 3 Therefore: a = 2 + t^2 = 2 + 3 = 5 So R(5, 0) Circle passes through R(5, 0) and Focus F(1, 0). Centre is on the x-axis, so centre is at (h, 0). Since (1, 0) and (5, 0) are endpoints of a diameter: Centre = ((1 + 5)/2, 0) = (3, 0) Radius = (5 - 1)/2 = 2 Equation of circle: (x - 3)^2 + y^2 = 4 Expanding: x^2 - 6x + 9 + y^2 = 4 x^2 + y^2 - 6x + 5 = 0
