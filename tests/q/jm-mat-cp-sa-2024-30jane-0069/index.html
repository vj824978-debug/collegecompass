If z is a complex number, then the number of common roots of the equations z^1985 + z^100 + 1 = 0 and z^3 + 2z^2 + 2z + 1 = 0, is equal to

  1. (1) 2
  2. (2) 1
  3. (3) 0
  4. (4) 3

Answer

Correct answer: Option 1

Solution

Given z^1985 + z^100 + 1 = 0 and z^3 + 2z^2 + 2z + 1 = 0. Factoring the second equation: (z + 1)(z^2 + z + 1) = 0, giving z = -1, ω, ω^2 where ω is a cube root of unity. Check z = -1: (-1)^1985 + (-1)^100 + 1 = -1 + 1 + 1 = 1 ≠ 0, so -1 is not a root. For z^1985 + z^100 + 1 = 0, the roots must be ω and ω^2 (cube roots of unity). Both ω and ω^2 satisfy z^1985 + z^100 + 1 = 0 since 1985 ≡ 1 (mod 3) and 100 ≡ 1 (mod 3). Therefore ω and ω^2 are common roots, giving 2 common roots.
