A parallel plate capacitor is filled equally (half) with two dielectrics of dielectric constants ε₁ and ε₂, as shown in figures. The distance between the plates is d and area of each plate is A. If capacitance in first configuration and second configuration are C₁ and C₂ respectively, then C₁/C₂ is:

  1. (1) 4ε₁ε₂/(ε₁+ε₂)²
  2. (2) ε₀(ε₁+ε₂)/2
  3. (3) ε₁ε₂/(ε₁+ε₂)²
  4. (4) ε₁ε₂/(ε₁+ε₂)

Answer

Correct answer: Option 1

Solution

First configuration (series): Dielectrics are in series, so 1/C₁ = (d/2)/(ε₀ε₁A) + (d/2)/(ε₀ε₂A) = d(ε₁+ε₂)/(2ε₀ε₁ε₂A), giving C₁ = 2ε₀ε₁ε₂A/[d(ε₁+ε₂)]. Second configuration (parallel): Dielectrics are in parallel, so C₂ = ε₀ε₁A/(d/2) + ε₀ε₂A/(d/2) = 2ε₀(ε₁+ε₂)A/d. Therefore C₁/C₂ = [2ε₀ε₁ε₂A/(d(ε₁+ε₂))]/[2ε₀(ε₁+ε₂)A/d] = ε₁ε₂/(ε₁+ε₂)²
