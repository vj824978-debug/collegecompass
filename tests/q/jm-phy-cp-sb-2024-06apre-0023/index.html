A particle moves in a straight line so that its displacement x at any time t is given by x^2 = 1 + t^2. Its acceleration at any time t is x^(-n) where n = ____.

Answer

Correct answer: 3

Solution

Given: x^2 = 1 + t^2 Differentiating with respect to t: 2x(dx/dt) = 2t xv = t, where v = dx/dt Differentiating again: x(dv/dt) + v(dx/dt) = 1 x·a + v^2 = 1 where a = dv/dt is acceleration From xv = t, we get v = t/x Substituting into x·a + v^2 = 1: x·a + (t/x)^2 = 1 x·a + t^2/x^2 = 1 Since x^2 = 1 + t^2, we have t^2 = x^2 - 1 x·a + (x^2 - 1)/x^2 = 1 x·a = 1 - (x^2 - 1)/x^2 x·a = (x^2 - x^2 + 1)/x^2 x·a = 1/x^2 a = 1/x^3 = x^(-3) Therefore, n = 3
