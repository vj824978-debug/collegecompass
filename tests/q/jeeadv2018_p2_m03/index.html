Let S be the set of all column matrices [b₁, b₂, b₃]ᵀ such that b₁, b₂, b₃ ∈ ℝ and the system of equations (in real variables) -x + 2y + 5z = b₁ 2x - 4y + 3z = b₂ x - 2y + 2z = b₃ has at least one solution. Then, which of the following system(s) (in real variables) has (have) at least one solution for each [b₁, b₂, b₃]ᵀ ∈ S?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) x + 2y + 3z = b₁, 4y + 5z = b₂ and x + 2y + 6z = b₃
  2. (B) x + y + 3z = b₁, 5x + 2y + 6z = b₂ and -2x - y - 3z = b₃
  3. (C) -x + 2y - 5z = b₁, 2x - 4y + 10z = b₂ and x - 2y + 5z = b₃
  4. (D) x + 2y + 5z = b₁, 2x + 3z = b₂ and x + 4y - 5z = b₃

Answer

Correct answer: AD
