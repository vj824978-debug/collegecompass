Match List-I with List-II. List-I contains complexes: A. [Ti(H2O)6]^2+, B. [V(H2O)6]^2+, C. [Mn(H2O)6]^3+, D. [Fe(H2O)6]^3+. List-II contains Crystal Field splitting energy (Δ0): I. -1.2, II. -0.6, III. 0, IV. -0.8

  1. (1) A-II, B-IV, C-I, D-III
  2. (2) A-IV, B-I, C-III, D-II
  3. (3) A-IV, B-I, C-II, D-III
  4. (4) A-II, B-IV, C-III, D-I

Answer

Correct answer: Option 3

Solution

Analyze electron configurations and CFSE: (A) Ti^2+: 3d^2, Δ0 = 2(-0.4Δ0) = -0.8Δ0 → IV. (B) V^2+: 3d^3, Δ0 = 3(-0.4Δ0) = -1.2Δ0 → I. (C) Mn^3+: 3d^4, Δ0 = 3(-0.4Δ0) + 1(0.6Δ0) = -0.6Δ0 → II. (D) Fe^3+: 3d^5, Δ0 = 3(-0.4Δ0) + 2(0.6Δ0) = 0 → III. Therefore: A-IV, B-I, C-II, D-III
