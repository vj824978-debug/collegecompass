Let a function f : [0, 5] → R be continuous, f(1) = 3 and F be defined as F(x) = ∫[1 to x] t²g(t) dt, where g(t) = ∫[1 to t] f(u) du. Then for the function F, the point x = 1 is

  1. (1) not a critical point
  2. (2) a point of local maxima
  3. (3) a point of local minima
  4. (4) a point of inflection

Answer

Correct answer: Option 3

Solution

F(x) = ∫[1 to x] t²g(t) dt Using the Fundamental Theorem of Calculus: F'(x) = x²g(x) at F'(1) = (1)²g(1) = 0 {∵ g(1) = 0} Now, F''(x) = 2xg(x) + x²g'(x) F''(1) = 2g(1) + g'(1) F''(1) = 0 + g'(1) {g'(t) = f(t); g'(1) = f'(1) = 3} F''(1) = 3 So, at x = 1, F'(1) = 0 but F''(1) > 0 ∴ For the function F(x), x = 1 is a point of local minima.
