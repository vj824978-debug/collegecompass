The correct order of the atomic radii of C, Cs, Al, and S is:

  1. (1) S < C < Al < Cs
  2. (2) S < C < Cs < Al
  3. (3) C < S < Al < Cs
  4. (4) C < S < Cs < Al

Answer

Correct answer: Option 1

Solution

Size order 3rd period: C < S < Al < Cs 2nd period (more zeff) ↓ 6th period Explanation: - C is in the 2nd period - S is in the 3rd period - Al is in the 3rd period - Cs is in the 6th period Within the same period (2nd and 3rd), atomic radius increases from right to left (from non-metals to metals). C is in group 14 (2nd period) and S is in group 16 (3rd period). However, C has more effective nuclear charge (zeff) compared to elements below it in the same group, so C is smaller than S even though S is in a higher period. Al is in group 13 (3rd period), so it is larger than S (group 16, 3rd period) due to fewer protons in the valence shell. Cs is in group 1 (6th period), which has the largest atomic radius among all these elements due to being in the 6th period and having only one valence electron. Therefore: S < C < Al < Cs
