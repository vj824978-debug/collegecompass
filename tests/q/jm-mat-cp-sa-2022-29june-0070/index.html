Let P: y^2 = 4ax, a > 0 be a parabola with focus S. Let the tangents to the parabola P make an angle of π/4 with the line y = 3x + 5 touch the parabola P at A and B. Then the value of a for which A, B and S are collinear is

  1. (1) 8 only
  2. (2) 2 only
  3. (3) 1/4 only
  4. (4) any a > 0

Answer

Correct answer: Option 4

Solution

For parabola y^2 = 4ax, tangent equation is y = mx + a/m. Given tangents make angle π/4 with line y = 3x + 5 (slope = 3). Using tan(π/4) = |m - 3|/(1 + 3m) = 1, we get m = -2 or m = 1/2. Tangent equations: y = -2x - a/2 and y = (x/2) + 2a. Points of contact: A(a/4, a) and B(4a, -4a). Focus S is at (a, 0). For collinearity of A, B, S, using determinant condition: (1/2)|a/4, a, 1; 4a, -4a, 1; a, 0, 1| = 0. This simplifies to -a^2 - 3a^2 + 4a^2 = 0, which is always true for any a > 0.
