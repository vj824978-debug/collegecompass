The total number of real solutions of the equation θ = tan^(-1)(2tan θ) - (1/2)sin^(-1)(6tan θ/(9 + tan^2 θ)) is (Here, the inverse trigonometric functions sin^(-1) x and tan^(-1) x assume values in [-π/2, π/2] and (-π/2, π/2), respectively.)

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 1
  2. (B) 2
  3. (C) 3
  4. (D) 5

Answer

Correct answer: C

Solution

θ = tan⁻¹(2tanθ) - (1/2)sin⁻¹(6tanθ/(9 + tan²θ)) = tan⁻¹(2tanθ) - (1/2)sin⁻¹(2(tanθ/3)/(1 + (tanθ/3)²)) Let tanθ/3 = tanα = tan⁻¹(2tanθ) - (1/2)sin⁻¹(2tanα/(1 + tan²α)) = tan⁻¹(2tanθ) - (1/2)sin⁻¹(sin2α) = tan⁻¹(2tanθ) - tan⁻¹(tanθ/3) tanθ = (2tanθ - tanθ/3)/(1 + 2tan²θ/3) = 5tanθ/(3 + 2tan²θ) so tanθ = 0 or tan²θ = 1 θ = 0, π/4 and -π/4 In another case we did not get any solution.
