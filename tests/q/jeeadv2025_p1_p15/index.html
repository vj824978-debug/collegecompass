A circuit with an electrical load having impedance Z is connected with an AC source as shown in the diagram. The source voltage varies in time as V(t) = 300 sin(400t) V, where t is time in s. List-I shows various options for the load. The possible currents i(t) in the circuit as a function of time are given in List-II. Choose the option that describes the correct match between the entries in List-I to those in ListII. [Circuit diagram showing AC source V(t) connected to impedance Z] List-I (P) 30 Ω [resistor symbol] (Q) 30 Ω and 100 mH [resistor and inductor in series] (R) 50 μF, 30 Ω, and 25 mH [capacitor, resistor, and inductor in series] (S) 50 μF, 60 Ω, and 125 mH [capacitor, resistor, and inductor in series] List-II (1) [Graph showing sinusoidal current with peak ≈5 A, in phase with voltage] (2) [Graph showing sinusoidal current with peak ≈5 A, lagging voltage by ~π/2] (3) [Graph showing sinusoidal current with peak ≈10 A, leading voltage by small phase angle] (4) [Graph showing sinusoidal current with peak ≈20 A, leading voltage by ~π/2] (5) [Graph showing sinusoidal current with peak ≈5 A, leading voltage by small phase angle]

Matrix match · Marks: +4 / -1.0

  1. (A) P→3, Q→5, R→2, S→1
  2. (B) P→1, Q→5, R→2, S→3
  3. (C) P→3, Q→4, R→2, S→1
  4. (D) P→1, Q→4, R→2, S→5

Answer

Correct answer: A

Solution

V = 300 sin(400t) (P) Z = R φ = 0 → phase difference between current and voltage i₀ = 300/30 = 10A ⇒ i = 10 sin(400t) (Q) xₗ = ωL = 400 × 100 × 10⁻³ = 40m z = √((30)² + (40)²) = 50m u₀ = 300/50 = 6A tan φ = ωL/R = 4/3 φ = tan⁻¹(4/3) i = 6sin(400t - tan⁻¹(4/3)) at t = 0, I = -6 × 4/5 = -4.8A
