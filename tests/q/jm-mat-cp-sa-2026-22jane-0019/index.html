Let f and g be functions satisfying f(x+y) = f(x)f(y), f(1) = 7 and g(x+y) = g(xy), g(1) = 1, for all x,y in N. Sum from x=1 to n of (f(x)/g(x)) = 19607, then n is equal to:

  1. (1) 7
  2. (2) 5
  3. (3) 6
  4. (4) 4

Answer

Correct answer: Option 2

Solution

f(x+y) = f(x)f(y) => f(x) = a^x (since f(1) = 7 => a^1 = 7) So f(x) = 7^x Now g(x+y) = g(xy) (put y = 1) => g(x+1) = g(x) so g(1) = g(2) = g(3) = ... = g(n) = 1 Given Sum from x=1 to n of f(x)/g(x) = 19607 Sum from x=1 to n of 7^x/1 = 19607 => 7(7^n - 1)/(7-1) = 19607 7^n - 1 = (6/7) × 19607 7^n = 16807 => n = 5
