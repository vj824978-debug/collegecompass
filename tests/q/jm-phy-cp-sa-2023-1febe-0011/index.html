Two objects A and B are placed at 15 cm and 25 cm from the pole in front of a concave mirror having radius of curvature 40 cm. The distance between images formed by the mirror is

  1. (1) 100 cm
  2. (2) 40 cm
  3. (3) 160 cm
  4. (4) 60 cm

Answer

Correct answer: Option 3

Solution

Given: Radius of curvature R = 40 cm Focal length f = R/2 = 20 cm Object A at distance u_A = 15 cm from pole Object B at distance u_B = 25 cm from pole Using mirror formula: 1/f = 1/u + 1/v For object A: 1/v_A - 1/u_A = 1/f 1/v_A - 1/15 = 1/20 1/v_A = 1/20 + 1/15 = (3+4)/(60) = 7/60 v_A = 60 cm (positive, virtual image) For object B: 1/v_B - 1/u_B = 1/f 1/v_B - 1/25 = 1/20 1/v_B = 1/20 + 1/25 = (5+4)/(100) = 9/100 v_B = 100/9 cm Wait, recalculating for B: 1/v_B = 1/20 + 1/25 1/v_B = (25+20)/(500) = 45/500 = 9/100 Actually using correct formula: 1/f = 1/u + 1/v, so 1/v = 1/f - 1/u For object A at u_A = 15 cm: 1/v_A = 1/20 - 1/15 = (3-4)/(60) = -1/60 v_A = -60 cm (real image) For object B at u_B = 25 cm: 1/v_B = 1/20 - 1/25 = (5-4)/(100) = 1/100 v_B = 100 cm (virtual image) Distance between images = |v_A - v_B| = |-60 - 100| = |-160| = 160 cm
