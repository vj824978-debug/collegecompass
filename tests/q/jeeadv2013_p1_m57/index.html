Of the three independent events E₁, E₂, and E₃, the probability that only E₁ occurs is α, only E₂ occurs is β and only E₃ occurs is γ. Let the probability p that none of events E₁, E₂ or E₃ occurs satisfy the equations (α - 2β) p = αβ and (β - 3γ) p = 2βγ. All the given probabilities are assumed to lie in the interval (0, 1). Then Probability of occurrence of E₁ / Probability of occurrence of E₃ = ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 6

Solution

Sol. (6) Let P(E₁) = x, P(E₂) = y and P(E₃) = z then (1 - x)(1 - y)(1 - z) = p x(1 - y)(1 - z) = α (1 - x)y(1 - z) = β (1 - x)(1 - y)(1 - z) = γ so (1 - x)/x = p/α ⟹ x = α/(α + p) similarly z = γ/(γ + p) so P(E₁)/P(E₃) = (α/(α + p))/(γ/(γ + p)) = (α/(α + p)) · ((γ + p)/γ) = (1 + p/γ)/(1 + p/α) also given αβ/(α - 2β) = p = 2βγ/(β - 3γ) ⟹ β = 5αγ/(α + 4γ) Substituting back (α - 2(5αγ/(α + 4γ)))p = α · 5αγ/(α + 4γ) ⟹ αp - 6pγ = 5αγ ⟹ (p/γ + 1) = 6(p/α + 1) ⟹ (p/γ + 1)/(p/α + 1) = 6
