The complex number z = (1-i)/(cos(pi/3) + i*sin(pi/3)) is equal to:

  1. (1) sqrt(2)(cos(5*pi/12) + i*sin(5*pi/12))
  2. (2) cos(pi/12) - i*sin(pi/12)
  3. (3) sqrt(2)(cos(pi/12) + i*sin(pi/12))
  4. (4) sqrt(2i)(cos(5*pi/12) - i*sin(5*pi/12))

Answer

Correct answer: Option 1

Solution

z = (1-i)/(cos(pi/3) + i*sin(pi/3)) Numerator: 1-i In polar form: |1-i| = sqrt(1^2 + (-1)^2) = sqrt(2) Argument: tan^(-1)(-1/1) = -pi/4 So, 1-i = sqrt(2)*e^(-i*pi/4) = sqrt(2)(cos(-pi/4) + i*sin(-pi/4)) Denominator: cos(pi/3) + i*sin(pi/3) = e^(i*pi/3) |denominator| = 1 Argument = pi/3 Dividing: z = (sqrt(2)*e^(-i*pi/4))/(e^(i*pi/3)) = sqrt(2)*e^(-i*pi/4 - i*pi/3) = sqrt(2)*e^(i*(-pi/4 - pi/3)) = sqrt(2)*e^(i*(-3*pi/12 - 4*pi/12)) = sqrt(2)*e^(i*(-7*pi/12)) = sqrt(2)*e^(-i*7*pi/12) Since e^(-i*theta) = e^(i*(2*pi - theta)) = e^(i*(-theta + 2*pi)) = sqrt(2)*e^(i*(2*pi - 7*pi/12)) = sqrt(2)*e^(i*(24*pi/12 - 7*pi/12)) = sqrt(2)*e^(i*17*pi/12) Alternatively: -7*pi/12 is equivalent to -7*pi/12 + 2*pi = 17*pi/12 But we can also write: e^(-i*7*pi/12) = cos(-7*pi/12) + i*sin(-7*pi/12) Note: -7*pi/12 = -(7*pi/12) = -pi + 5*pi/12, or equivalently 5*pi/12 in the principal range after adjustment Actually: -7*pi/12 + 2*pi = 17*pi/12 Or: cos(-7*pi/12) = cos(7*pi/12) and sin(-7*pi/12) = -sin(7*pi/12) cos(7*pi/12) = cos(pi - 5*pi/12) = -cos(5*pi/12) sin(7*pi/12) = sin(pi - 5*pi/12) = sin(5*pi/12) So z = sqrt(2)(cos(5*pi/12) + i*sin(5*pi/12))
