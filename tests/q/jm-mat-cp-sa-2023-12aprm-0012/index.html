Let the plane P: 4x - y + z = 10 be rotated by an angle π/2 about its line of intersection with the plane x + y - z = 4. If a is the distance of the point (2, 3, -4) from the new position of the plane P, then 35a is equal to

  1. (1) 85
  2. (2) 105
  3. (3) 126
  4. (4) 90

Answer

Correct answer: Option 3

Solution

Equation of plane after rotation: (4x - y + z - 10) + λ(x + y - z - 4) = 0. The normal vectors n1 and n2 are perpendicular, so n1·n2 = 0, which gives (4 + λ)(1) + (-1 - λ)(1) + (1 - λ)(1) = 0. Solving: 16 + 4λ - λ + 1 + 1 - λ = 0, so 2λ = -18, thus λ = -9. The new plane equation is -5x - 10y + 10z + 26 = 0. Distance from (2, 3, -4) to this plane: a = |-10 - 30 - 40 + 26|/sqrt(25 + 100 + 100) = 54/15. Therefore, 35a = 35 × (54/15) = 7 × 18 = 126.
