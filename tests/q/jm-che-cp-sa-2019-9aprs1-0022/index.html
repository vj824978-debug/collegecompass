For a reaction, N2(g) + 3H2(g) → 2NH3(g); identify dihydrogen (H2) as a limiting reagent in the following reaction mixtures.

  1. (1) (1) 14 g of N2 + 4g of H2
  2. (2) (2) 28 g of N2 + 6g of H2
  3. (3) (3) 56 g of N2 + 10g of H2
  4. (4) (4) 35 g of N2 + 8g of H2

Answer

Correct answer: Option 3

Solution

N2 + 3H2 → 2NH3 1. 14gm N2 + 4gm H2 14gm = 1/2 mole N2 4gm = 2 mole H2 Mole ratio required = (1/2)/(1) : (2)/(3) L.R (N2) N2 requires 3/2 mole of H2, but only 2 mole available. So H2 is in excess. 2. 28 gm N2 + 6gm H2 28gm = 1 mole N2 6gm = 3 mole H2 Mole ratio = (1)/(1) : (3)/(3) N2 requires exactly 3 mole of H2. Stoichiometric amounts. 3. 56 gm N2 + 10gm H2 56gm = 2 mole N2 10gm = 5 mole H2 Mole ratio = (2)/(1) : (5)/(3) = (1.66) H2 N2 requires 6 mole of H2, but only 5 mole available. So H2 is limiting. 4. 35 gm N2 + 8gm H2 35/28 mole = 1.25 mole N2 8gm = 4 mole H2 Mole ratio for stoichiometry: 35/28 : 4/3 = 1.25 : 1.33 N2 requires 3.75 mole of H2, but only 4 mole available. So N2 is limiting, H2 is in excess.
