Let x_0 be the point of local maxima of f(x) = vector a . (vector b × vector c), where vector a = xi - 2j + 3k, vector b = -2i + xj - k and vector c = 7i - 2j + xk. Then the value of vector a . vector b + vector b . vector c + vector c . vector a at x = x_0 is :

  1. (1) -4
  2. (2) -30
  3. (3) -22
  4. (4) 14

Answer

Correct answer: Option 3

Solution

f(x) = vector a . (vector b × vector c) = |x -2 3| = x^3 - 27x + 26 |-2 x -1| |7 -2 x| f'(x) = 3x^2 - 27 = 0 ⟹ x = ±3 and f''(-3) < 0 ⟹ local maxima at x = x_0 = -3 Thus, vector a = -3i - 2j + 3k, vector b = -2i - 3j - k and vector c = 7i - 2j - 3k ⟹ vector a . vector b + vector b . vector c + vector c . vector a = 9 - 5 - 26 = -22
