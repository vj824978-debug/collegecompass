If wavelength of the first line of the Paschen series of hydrogen atom is 720 nm, then the wavelength of the second line of this series is ___ nm. (Nearest integer)

Answer

Correct answer: 492

Solution

For Paschen series, the first line corresponds to transition from n=4 to n=3, and the second line corresponds to transition from n=5 to n=3. Using Rydberg formula: 1/lambda = R × (1/n1^2 - 1/n2^2) For first line (n=4 to n=3): 1/720 = R × (1/9 - 1/16) Solving for R: 1/720 = R × (16-9)/(9×16) 1/720 = R × 7/144 R = 144/(720×7) = 144/5040 = 1/35 Actually, calculating more carefully: R = (9×16)/(720×7) = 144/5040 For second line (n=5 to n=3): 1/lambda' = R × (1/9 - 1/25) 1/lambda' = (9×16)/(720×7) × (1/9 - 1/25) 1/lambda' = (9×16)/(720×7) × (25-9)/(9×25) 1/lambda' = (9×16)/(720×7) × 16/(9×25) 1/lambda' = (9×16×16)/(720×7×9×25) 1/lambda' = (16×16)/(720×7×25) lambda' = (720×7×25)/(16×16) lambda' = (720×7×25)/256 lambda' = 126000/256 lambda' = 492.1875 nm lambda' = 492 nm (nearest integer)
