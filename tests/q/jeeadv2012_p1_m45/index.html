The integral integral [sec^2(x) / (sec x + tan x)^(1/2)] dx equals (for some arbitrary constant K)

Single correct MCQ · Marks: +3 / -1.0

  1. (A) (A) -1/(sec x + tan x)^(1/2) [1/11 - 1/7(sec x + tan x)^2] + K
  2. (B) (B) 1/(sec x + tan x)^(1/2) [1/11 - 1/7(sec x + tan x)^2] + K
  3. (C) (C) -1/(sec x + tan x)^(1/2) [1/11 + 1/7(sec x + tan x)^2] + K
  4. (D) (D) 1/(sec x + tan x)^(1/2) [1/11 + 1/7(sec x + tan x)^2] + K

Answer

Correct answer: C

Solution

Sol. (C) I = ∫ (sec² x)/(sec x + tan x)^(9/2) dx Let sec x + tan x = t ⟹ sec x - tan x = 1/t Now (sec x tan x + sec² x) dx = dt sec x (sec x + tan x) dx = dt sec x dx = dt/t · 1/2(t + 1/t) = sec x I = 1/2 ∫ (t + 1/t) dt/t^(9/2) = 1/2 ∫ (t^(-9/2) + t^(-13/2)) dt = 1/2 [t^(-9/2+1)/(-9/2+1) + t^(-13/2+1)/(-13/2+1)] = 1/2 [t^(-7/2)/(-7/2) + t^(-11/2)/(-11/2)] = 1/2 [t^(-7/2)·(-2/7) + t^(-11/2)·(-2/11)] = -1/7·t^(-7/2) - 1/11·t^(-11/2) = -1/(7t^(7/2)) - 1/(11t^(11/2)) = -1/t^(11/2) · (1/11 + 1/7·t²) = -1/((sec x + tan x)^(11/2)) · {1/11 + 1/7(sec x + tan x)²} + k
