Let P = [4 1 0; 16 4 1] and I be the identity matrix of order 3. If Q = [q_ij] is a matrix such that P^50 - Q = I, then (q_31 + q_32)/q_21 equals

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 52
  2. (B) 103
  3. (C) 201
  4. (D) 205

Answer

Correct answer: B

Solution

Sol. (B) P = [1 0 0; 4 1 0; 16 4 1] = [0 0 0; 4 0 0; 16 4 0] + [1 0 0; 0 1 0; 0 0 1] let A = [0 0 0; 4 0 0; 16 4 0] ⟹ A² = [0 0 0; 0 0 0; 16 0 0] and A³ = [0 0 0; 0 0 0; 0 0 0] ⟹ Aⁿ is a null matrix ∀ n ≥ 3. P⁵⁰ = (I + A)⁵⁰ = I + 50A + (50×49)/2 A² Q + I = [1 0 0; 0 1 0; 0 0 1] + 50[0 0 0; 4 0 0; 16 4 0] + 25×49[0 0 0; 0 0 0; 16 0 0] ⟹ (q₃₁ + q₃₂)/q₂₁ = (16(50 + 25×49) + 50×4)/(50×4) = (16×51 + 8)/8 = 102 + 1 = 103
