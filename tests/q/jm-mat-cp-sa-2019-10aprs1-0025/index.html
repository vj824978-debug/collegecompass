If for some x in R, the frequency distribution of the marks obtained by 20 students in a test is: Marks: 2, 3, 5, 7 with Frequency: (x+1)^2, 2x-5, x^2-3x, x respectively, then the mean of the marks is

  1. (1) 3.0
  2. (2) 2.8
  3. (3) 2.5
  4. (4) 3.2

Answer

Correct answer: Option 2

Solution

Mean x̄ = (∑ x_i f_i)/(∑ f_i) ∴ ∑ f_i = (x+1)^2 + (2x-5) + (x^2-3x) + x = 20 Expanding (x+1)^2 + 2x - 5 + x^2 - 3x + x = 20 x^2 + 2x + 1 + 2x - 5 + x^2 - 3x + x = 20 2x^2 + 2x - 4 = 20 2x^2 + 2x - 24 = 0 x^2 + x - 12 = 0 (x + 4)(x - 3) = 0 ⇒ x = 3, -4(rejected) When x = 3: Frequencies are: (3+1)^2 = 16, 2(3)-5 = 1, 3^2-3(3) = 0, 3 = 3 Total = 16 + 1 + 0 + 3 = 20 ✓ ∑ x_i f_i = 2(16) + 3(1) + 5(0) + 7(3) = 32 + 3 + 0 + 21 = 56 ∴ x̄ = 56/20 = 2.8
