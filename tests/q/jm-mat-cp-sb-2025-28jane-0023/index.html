The interior angles of a polygon with n sides, are in an A.P. with common difference 6°. If the largest interior angle of the polygon is 219°, then n is equal to ___.

Answer

Correct answer: 20

Solution

Interior angles in A.P. with first term a and common difference 6°. Sum of interior angles = (n/2)(2a + (n-1)6) = (n-2)180°. This gives: an + 3n² - 3n = (n-2)180°. Largest angle = a + (n-1)6 = 219°, so a = 225° - 6n. Substituting into the sum equation: (225n - 6n²) + 3n² - 3n = 180n - 360. Simplifying: 3n² - 42n - 360 = 0, or n² - 14n - 120 = 0. Solving: n = 20 or n = -6 (rejected). Therefore n = 20.
