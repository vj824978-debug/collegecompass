The reaction between X and Y is first order with respect to X and zero order with respect to Y. Examine the data of table and calculate ratio of numerical values of M and L. (Nearest Integer). Table: Experiment I: [X]=0.1 mol L^-1, [Y]=0.1 mol L^-1, Initial rate=2×10^-3 mol L^-1 min^-1. Experiment II: [X]=L, [Y]=0.2 mol L^-1, Initial rate=4×10^-3 mol L^-1 min^-1. Experiment III: [X]=0.4 mol L^-1, [Y]=0.4 mol L^-1, Initial rate=M×10^-3 mol L^-1 min^-1. Experiment IV: [X]=0.1 mol L^-1, [Y]=0.2 mol L^-1, Initial rate=2×10^-3 mol L^-1 min^-1.

Answer

Correct answer: 40

Solution

Rate law: r = k[x][y]^0 = k[x]. Using experiments I & II: (4×10^-3)/(2×10^-3) = L/0.1, therefore L = 0.2. Using experiments I & III: (M×10^-3)/(2×10^-3) = 0.4/0.1, therefore M = 8. M/L = 8/0.2 = 40
