If the area of the region {(x, y) : |4 - x^2| ≤ y ≤ x^2, y ≤ 4, x ≥ 0} is (80*sqrt(2))/a - beta, a, beta ∈ N, then alpha + beta is equal to ___

Answer

Correct answer: 22

Solution

The region is bounded by y = x^2 (lower), y = 4 - x^2 (upper for 4 - x^2 ≥ 0), and y = x^2 - 4 (upper for x^2 ≥ 4), with y ≤ 4 and x ≥ 0. For 0 ≤ x ≤ 2: area between y = x^2 and y = 4 - x^2. For 2 ≤ x ≤ 2*sqrt(2): area between y = x^2 - 4 and y = 4. Integration: ∫₀² (4 - 2x^2)dx + ∫₂^(2√2) (4 - (x^2 - 4))dx = ∫₀² (4 - 2x^2)dx + ∫₂^(2√2) (8 - x^2)dx = [4x - (2x^3)/3]₀² + [8x - x^3/3]₂^(2√2) = (8 - 16/3) + (16√2 - 16√2/3 - 16 + 8/3) = 8/3 + 32√2/3 - 8 = 32√2/3 - 16/3. Total area = (80√2)/3 - 16, so alpha = 3, beta = 16, alpha + beta = 19
