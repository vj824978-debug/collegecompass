Let q be the maximum integral value of p in [0, 10] for which the roots of the equation x^2 - px + (5/4)p = 0 are rational. Then the area of the region {(x, y) : 0 <= y <= (x - q)^2, 0 <= x <= q} is

  1. (1) 125/3
  2. (2) 164
  3. (3) 243
  4. (4) 25

Answer

Correct answer: Option 3

Solution

Given equation: 4x^2 - 4px + 5p = 0 For rational roots, D must be a perfect square D = 16p^2 - 4 × 4 × 5p = 16p^2 - 80p = 16p(p - 5) So, max. integral value of p = 9 for making D a perfect square ∴ q = 9 Area of shaded region: ∫[0 to 9] (x - 9)^2 dx = [(x - 9)^3/3] from 0 to 9 = [0 - (-9)^3/3] = -(-729/3) = 729/3 = 243 sq. units
