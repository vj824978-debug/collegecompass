Let P₁ and P₂ be two planes given by P₁: 10x + 15y + 12z - 60 = 0, P₂: -2x + 5y + 4z - 20 = 0. Which of the following straight lines can be an edge of some tetrahedron whose two faces lie on P₁ and P₂?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (x-1)/0 = (y-1)/0 = (z-1)/5
  2. (B) (x-6)/(-5) = y/2 = z/3
  3. (C) x/(-2) = (y-4)/5 = z/4
  4. (D) x/1 = (y-4)/(-2) = z/3

Answer

Correct answer: ABD

Solution

The line should be either coincident on P₁ or on P₂ or intersect on P₁ and P₂ on different points. (D) x/1 = (y-4)/(-2) = z/3 = λ ⟹ (λ, -2λ + 4, 3λ) lie on P₂ (A) (x-1)/0 = (y-1)/0 = (z-1)/5 intersects P₁ and P₂ on different points. (B) (x-6)/5 = y/2 = z/3 also intersects P₁ and P₂ on different points.
