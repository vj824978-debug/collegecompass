Let the lines L₁: vector r = i + 2j + 3k + λ(2i + 3j + 4k), λ ∈ ℝ and L₂: vector r = (4i + j) + μ(5i + 2j + k), μ ∈ ℝ, intersect at the point R. Let P and Q be the points lying on lines L₁ and L₂, respectively, such that |PR| = sqrt(29) and |PQ| = sqrt(47/3). If the point P lies in the first octant, then 27(QR)² is equal to

  1. (1) 340
  2. (2) 360
  3. (3) 320
  4. (4) 348

Answer

Correct answer: Option 2

Solution

For POI (point of intersection): 2λ + 1 = 5μ + 4; 3λ + 2 = 2μ + 1; 4λ + 3 = μ ⟹ λ = μ = -1 R(-1, -1, -1) P(2λ + 1, 3λ + 2, 4λ + 3) PR² = 29 ⟹ (2λ + 1)² + (3λ + 3)² + (4λ + 4)² = 29 ⟹ λ = 0 or λ = -2 (Reject) ⟹ P(1, 2, 3) Q(5μ + 4, 2μ + 1, μ) |PQ| = sqrt(47/3) ⟹ PQ² = 47/3 ⟹ (5μ + 3)² + (2μ - 1)² + (μ - 3)² = 47/3 ⟹ μ = -1/3 Q = (7/3, 1/3, -1/3) (QR)² = (7/3 + 1)² + (1/3 + 1)² + (-1/3 + 1)² = (10/3)² + (4/3)² + (2/3)² = 100/9 + 16/9 + 4/9 = 120/9 ⟹ 27 × (QR)² = 27 × 120/9 = 360
