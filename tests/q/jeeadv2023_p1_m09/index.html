Let n ≥ 2 be a natural number and f:[0,1] → R be the function defined by f(x) = { n(1 - 2nx) if 0 ≤ x ≤ 1/(2n) 2n(2nx - 1) if 1/(2n) ≤ x ≤ 3/(4n) 4n(1 - nx) if 3/(4n) < x ≤ 1/n n/(n-1) · (nx - 1) if 1/n ≤ x ≤ 1 } If n is such that the area of the region bounded by the curves x = 0, x = 1, y = 0 and y = f(x) is 4, then the maximum value of the function f is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 8

Solution

Area = 1/4 + 1/8 + 1/8 + (n-1)/2 = 4 = 1/2 + (n-1)/2 = 4 ⟹ n = 8 So maximum value of f(x) is 8 [Figure shows a piecewise linear function on a coordinate plane with vertices at (0,n), (1/(2n),0), (1/n,0), and (1,0).
