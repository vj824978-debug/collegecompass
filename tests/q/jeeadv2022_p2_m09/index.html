Let PQRS be a quadrilateral in a plane, where QR = 1, ∠PQR = ∠QRS = 70°, ∠PQS = 15° and ∠PRS = 40°. If ∠RPS = 0°, PQ = α and PS = β, then the interval(s) that contain(s) the value of 4αβ sin0° is/are

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (0, sqrt(2))
  2. (B) (1, 2)
  3. (C) (sqrt(2), 3)
  4. (D) (2sqrt(2), 3sqrt(2))

Answer

Correct answer: AB

Solution

In △PQR: α/sin 30° = 1/sin 9° ⟹ α = 1/(2cos10°) ... (i) In △PSR: β/sin 40° = 1/sin 9° ⟹ βsin9° = sin40° ... (ii) From equation (i) and (ii): αβsin θ = sin40°/(2cos10°) 4αβsin θ = (2sin40°)/sin80° = (2sin40°)/(2sin40°cos40°) = sec40° 2/√3 < sec40° < √2 [Diagram shows quadrilateral PQRS with point intersections.
