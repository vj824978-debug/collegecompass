If 3x + 4y = 12*sqrt(2) is a tangent to the ellipse x^2/a^2 + y^2/9 = 1 for some a in R, then the distance between the foci of the ellipse is:

  1. (1) 4
  2. (2) 2*sqrt(2)
  3. (3) 2*sqrt(5)
  4. (4) 2*sqrt(7)

Answer

Correct answer: Option 4

Solution

3x + 4y = 12*sqrt(2) y = -(3x)/4 + 3*sqrt(2) line is tangent to ellipse Using tangency condition: c^2 = a^2*m^2 + b^2 where m = -3/4, b^2 = 9, c = 12*sqrt(2) (3*sqrt(2))^2 = a^2*(-3/4)^2 + 9 18 = a^2*(9/16) + 9 18 - 9 = 9a^2/16 9 = 9a^2/16 1 = a^2/16 a^2 = 16 For ellipse: c^2 = 1 - b^2/a^2 c^2 = 1 - 9/16 c^2 = 7/16 c = sqrt(7)/4 Distance between foci = 2ae = 2 × 4 × sqrt(7)/4 = 2*sqrt(7)
