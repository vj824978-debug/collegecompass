Mock Tests › JEE Advanced · Matrices › JEE Advanced 2019 Paper 2

Let P₁ = I = [0 1 0; 0 0 1; 0 0 1], P₂ = [0 0 1; 0 1 0; 0 1 0], P₃ = [1 0 0; 0 0 1; 0 0 1], P₄ = [0 1 0; 0 0 1; 1 0 0], P₅ = [0 0 1; 1 0 0; 0 1 0], P₆ = [0 0 1; 0 1 0; 1 0 0], and X = Σ(k=1 to 6) Pₖ [2 1 3; 1 0 2; 3 2 1] Pₖᵀ where Pₖᵀ denotes the transpose of the matrix Pₖ. Then which of the following options is/are correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) X - 30I is an invertible matrix
  2. (B) X is a symmetric matrix
  3. (C) The sum of diagonal entries of X is 18
  4. (D) If X [1; 1; 1] = α [1; 1; 1], then α = 30

Answer

Correct answer: BCD

Solution

Sol. B, C, D P₁ = [1 0 0; 0 1 0; 0 0 1], P₂ = [1 0 0; 0 0 1; 0 1 0], P₃ = [0 1 0; 1 0 0; 0 0 1], P₄ = [0 1 0; 0 0 1; 1 0 0], P₅ = [0 0 1; 1 0 0; 0 1 0], P₆ = [0 0 1; 0 1 0; 1 0 0] X = ∑Pₖ [2 1 3; 1 0 2; 3 2 1] Pₖᵀ Let A = [2 1 3; 1 0 2; 3 2 1] A = Aᵀ. Xᵀ = (P₁APᵀ₁ + P₂APᵀ₂ + ... + P₆APᵀ₆)ᵀ = X So X is symmetric matrix Let Q = [1; 1; 1] XQ = P₁APᵀ₁Q + P₂APᵀ₂Q + ... + P₆APᵀ₆Q = P₁AQ + P₂AQ + ... + P₆AQ = (P₁ + P₂ + ... + P₆)AQ, AQ = [6; 3; 6] = [2 2 2; 2 2 2; 2 2 2][6; 3; 6] = [30; 30; 30] = 30Q XQ = 30Q ⟹ (X - 30I)Q = 0 So, |X - 30I| = 0, has non-trivial solution. So, not invertible. Where trace(Pₖ A Pₖᵀ) = 3 ⟹ Trace X = 3 × 6 = 18.
