Let lambda ≠ 0 be a real number. Let alpha, beta be the roots of the equation 14x^2 - 31x + 3lambda = 0 and alpha, gamma be the roots of the equation 35x^2 - 53x + 4lambda = 0. Then 3alpha/beta and 4alpha/gamma are the roots of the equation

  1. (1) 7x^2 + 245x - 250 = 0
  2. (2) 49x^2 + 245x + 250 = 0
  3. (3) 7x^2 - 245x + 250 = 0
  4. (4) 49x^2 - 245x + 250 = 0

Answer

Correct answer: Option 4

Solution

35x^2 - 53x + 4lambda = 0 ...(i) (14x^2 - 31x + 3lambda = 0) × 2.5 ...(ii) (i) and (ii) gives x = lambda/7 = alpha alpha*beta = 3lambda/14 => beta = (3lambda/14) / (lambda/7) = (3lambda/14) × (7/lambda) = 3/2 alpha*gamma = 4lambda/35 => gamma = (4lambda/35) / (lambda/7) = (4lambda/35) × (7/lambda) = 4/5 alpha + beta = 31/14 => alpha = 5/7 3alpha/beta = (3 × 5/7) / (3/2) = (15/7) × (2/3) = 10/7 4alpha/gamma = (4 × 5/7) / (4/5) = (20/7) × (5/4) = 25/7 Equation formed will be x^2 - 5x + 250/49 = 0 49x^2 - 245x + 250 = 0
