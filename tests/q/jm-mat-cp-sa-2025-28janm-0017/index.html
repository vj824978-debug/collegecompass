Let C(r-1) = 28, C(r) = 56 and C(r+1) = 70. Let A(4cost, 4sint), B(2sint, -2cost) and C(3r - n, r^2 - n - 1) be the vertices of a triangle ABC, where t is a parameter. If (3x - 1)^2 + (3y)^2 = α, is the locus of the centroid of triangle ABC, then α equals:

  1. (1) 20
  2. (2) 8
  3. (3) 6
  4. (4) 18

Answer

Correct answer: Option 1

Solution

C(r-1) = 28, C(r) = 56 C(r-1)/C(r) = 28/56 = 1/2 n!/(r-1)!(n-r+1)! / [n!/r!(n-r)!] = 1/2 r/(n-r+1) = 1/2 2r = n + 1 3r = n + 1 ...(i) C(r)/C(r+1) = 56/70 [n!/r!(n-r)!] / [n!/(r+1)!(n-r-1)!] = 56/70 (r+1)/(n-r) = 56/70 70(r+1) = 56(n-r) 70r + 70 = 56n - 56r 126r + 70 = 56n 9r = 4n - 5 ...(ii) From (i): n = 3r - 1 Substituting in (ii): 9r = 4(3r - 1) - 5 9r = 12r - 4 - 5 9r = 12r - 9 -3r = -9 r = 3, n = 8 Vertices: A(4cost, 4sint) B(2sint, -2cost) C(3r - n, r^2 - n - 1) = C(9 - 8, 9 - 8 - 1) = C(1, 0) Centroid G = ((4cost + 2sint + 1)/3, (4sint - 2cost + 0)/3) Let x = (4cost + 2sint + 1)/3 and y = (4sint - 2cost)/3 3x - 1 = 4cost + 2sint 3y = 4sint - 2cost (3x - 1)^2 + (3y)^2 = (4cost + 2sint)^2 + (4sint - 2cost)^2 = 16cos^2(t) + 16cost·sint + 4sin^2(t) + 16sin^2(t) - 16sint·cost + 4cos^2(t) = 16cos^2(t) + 4sin^2(t) + 16sin^2(t) + 4cos^2(t) = 20cos^2(t) + 20sin^2(t) = 20(cos^2(t) + sin^2(t)) = 20 Therefore α = 20
