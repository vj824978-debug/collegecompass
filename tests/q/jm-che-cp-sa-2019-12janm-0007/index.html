Iodine reacts with concentrated HNO3 to yield Y along with other products. The oxidation state of iodine in Y, is -

  1. (1) 3
  2. (2) 1
  3. (3) 7
  4. (4) 5

Answer

Correct answer: Option 4

Solution

I2 + 10HNO3 → 2HIO3 + 10NO2 + 4H2O In the reaction, iodine is oxidized from 0 oxidation state (in I2) to +5 oxidation state (in HIO3). To find the oxidation state of I in HIO3: Let oxidation state of I = x H: +1 O: -2 (+1) + x + 3(-2) = 0 1 + x - 6 = 0 x = +5 Therefore, Y is HIO3 and the oxidation state of iodine in Y is +5.
