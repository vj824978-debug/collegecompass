The product of three consecutive terms of a G.P. is 512. If 4 is added to each of the first and the second of these terms, the three terms now form an A.P. Then the sum of the original three terms of the given G.P. is:

  1. (1) 36
  2. (2) 28
  3. (3) 32
  4. (4) 24

Answer

Correct answer: Option 2

Solution

Let the three consecutive terms of G.P. be a/r, a, ar Given: (a/r) × a × ar = 512 a^3 = 512 a = 8 After adding 4 to first and second terms, the three terms are: a/r + 4, a + 4, ar These form an A.P., so: 2(a + 4) = (a/r + 4) + ar 2(a + 4) = a/r + 4 + ar Substituting a = 8: 2(8 + 4) = 8/r + 4 + 8r 2(12) = 8/r + 4 + 8r 24 = 8/r + 4 + 8r 20 = 8/r + 8r Multiplying by r: 20r = 8 + 8r^2 8r^2 - 20r + 8 = 0 2r^2 - 5r + 2 = 0 Factoring: 2r^2 - 4r - r + 2 = 0 2r(r - 2) - 1(r - 2) = 0 (2r - 1)(r - 2) = 0 So r = 2 or r = 1/2 If r = 2: terms are 8/2, 8, 8(2) = 4, 8, 16 Sum = 4 + 8 + 16 = 28 If r = 1/2: terms are 8/(1/2), 8, 8(1/2) = 16, 8, 4 Sum = 16 + 8 + 4 = 28 Therefore, sum of original three terms = 28
