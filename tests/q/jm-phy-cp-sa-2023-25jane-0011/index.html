A particle executes simple harmonic motion between x = -A and x = +A. If time taken by particle to go from x = 0 to x = A/2 is 2 s; then time taken by particle in going from x = A/2 to A is

  1. (1) 3s
  2. (2) 2s
  3. (3) 1.5 s
  4. (4) 4s

Answer

Correct answer: Option 4

Solution

x = A sin(ωt) For x = A/2: A/2 = A sin(ωt) 1/2 = sin(ωt) ωt = π/6 t = (π/6)/ω = 2 s (given) Therefore: π/(6ω) = 2 π/ω = 12 sec For x = A: A = A sin(ωt) sin(ωt) = 1 ωt = π/2 t = (π/2)/ω = 6 second Time to go from x = A/2 to x = A: time = 6 - 2 = 4 seconds
