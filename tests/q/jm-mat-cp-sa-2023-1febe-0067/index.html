Let S = {x ∈ R : 0 < x < 1 and 2tan^(-1)((1-x)/(1+x)) = cos^(-1)((1-x^2)/(1+x^2))}. If n(S) denotes the number of elements in S then:

  1. (1) n(S) = 0
  2. (2) n(S) = 2 and only one element in S is less than 1/2
  3. (3) n(S) = 1 and the element in S is less than 1/2
  4. (4) n(S) = 1 and the elements is S is more than 1/2

Answer

Correct answer: Option 3

Solution

2tan^(-1)((1-x)/(1+x)) = cos^(-1)((1-x^2)/(1+x^2)) Put tan^(-1)(x) = θ, θ ∈ (0, π/4) 2tan^(-1)(tan(π/4 - θ)) = cos^(-1)(cos(2θ)) 2(π/4 - θ) = 2θ π/2 - 2θ = 2θ π/2 = 4θ or θ = π/8 x = tan(π/8) = √2 - 1 < 1/2
