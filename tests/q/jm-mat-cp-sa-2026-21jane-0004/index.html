If the line ax + 4y = sqrt(7), where a ∈ R, touches the ellipse 3x^2 + 4y^2 = 1 at the point P in the first quadrant, then one of the focal distances of P is:

  1. (1) 1/sqrt(3) - 1/(2*sqrt(11))
  2. (2) 1/sqrt(3) + 1/(2*sqrt(5))
  3. (3) 1/sqrt(3) - 1/(2*sqrt(5))
  4. (4) 1/sqrt(3) + 1/(2*sqrt(7))

Answer

Correct answer: Option 4

Solution

ax + 4y - sqrt(7) = 0 touches 3x^2 + 4y^2 = 1 For a line to touch an ellipse: c^2 = a^2*m^2 + b^2 7/16 = 1/3 × a^2/16 + 1/4 ⟹ a = 3, -3 Tangent is 3x + 4y - sqrt(7) = 0 Let the point of contact is P(x₁, y₁) ∴ Tangent is 3x₁x + 4y₁y = 1 ∴ 3x₁/3 = 4y₁/4 = 1/sqrt(7) ∴ P(1/sqrt(7), 1/sqrt(7)) e = sqrt(1 - 3/4) = 1/2 PS = e(PM) = e(a/e - x₁) = e(a/e - 1/sqrt(7)) = 1/2(2/sqrt(3) - 1/sqrt(7)) = 1/sqrt(3) - 1/(2*sqrt(7)) PS' = e(PM') = e(a/e + x₁) = e(a/e + 1/sqrt(7)) = 1/2(2/sqrt(3) + 1/sqrt(7)) = 1/sqrt(3) + 1/(2*sqrt(7))
