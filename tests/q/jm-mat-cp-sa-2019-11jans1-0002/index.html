Let K be the set of all real values of x where the function f(x) = sin|x| - |x| + 2(x - π) cos|x| is not differentiable. Then the set K is equal to:

  1. (1) {0, π}
  2. (2) φ (an empty set)
  3. (3) {π}
  4. (4) {0}

Answer

Correct answer: Option 2

Solution

f(x) = sin|x| - |x| + 2(x - π) cos|x| To find where f(x) is not differentiable, we need to analyze the differentiability of each component. The function contains |x| and cos|x| terms, which may cause non-differentiability at x = 0. Let's check differentiability at x = 0: For x > 0: f(x) = sin(x) - x + 2(x - π) cos(x) For x < 0: f(x) = sin(-x) - (-x) + 2(x - π) cos(-x) = -sin(x) + x + 2(x - π) cos(x) Left derivative at x = 0: f'(0-) = lim(h→0-) [f(0+h) - f(0)]/h = lim(h→0-) [-sin(h) + h + 2(h - π) cos(h) - 0]/h = lim(h→0-) [-sin(h) + h + 2(h - π) cos(h)]/h = lim(h→0-) [-sin(h)/h + 1 + 2cos(h) - 2π cos(h)/h] = -1 + 1 + 2 - 2π = 2 - 2π Right derivative at x = 0: f'(0+) = lim(h→0+) [f(0+h) - f(0)]/h = lim(h→0+) [sin(h) - h + 2(h - π) cos(h) - 0]/h = lim(h→0+) [sin(h) - h + 2(h - π) cos(h)]/h = lim(h→0+) [sin(h)/h - 1 + 2cos(h) - 2π cos(h)/h] = 1 - 1 + 2 - 2π = 2 - 2π Since the left and right derivatives are equal, sin|x| - |x| is differentiable at x = 0. The term 2(x - π) cos|x| is also differentiable everywhere including at x = 0. Therefore, f(x) is differentiable at x = 0 and at all other points. ∴ K = φ
