Three blocks A, B and C are lying on a smooth horizontal surface, as shown in the figure. A and B have equal masses, m while C has mass M. Block A is given an initial speed v towards B due to which it collides with B perfectly inelastically. 5/6 th of the initial kinetic energy is lost in whole process. What is value of M/m?

  1. (1) 2
  2. (2) 3
  3. (3) 5
  4. (4) 4

Answer

Correct answer: Option 4

Solution

p^2/(2m) - p^2/(2(2m + M)) = (5/6) × p^2/(2m) 1/m - 1/(2m + M) = 5/(6m) (2m + M - m)/(m(2m + M)) = 5/(6m) (m + M)/(m(2m + M)) = 5/(6m) 6(m + M) = 5(2m + M) 6m + 6M = 10m + 5M 4m = M m/M = 1/4 M/m = 4 Option (4) is correct.
