Particle A of mass m1 moving with velocity (sqrt(3)i + j)ms^(-1) collides with another particle B of mass m2 which is at rest initially. Let vector v1 and vector v2 be the velocities of particles A and B after collision respectively. If m1 = 2m2 and after collision vector v1 = (i + sqrt(3)j)ms^(-1), the angle between vector v1 and vector v2 is:

  1. (1) 60°
  2. (2) 15°
  3. (3) -45°
  4. (4) 105°

Answer

Correct answer: Option 4

Solution

vector v01 = (sqrt(3)i + j)m/s vector v02 = 0 m1 = 2m2 After collision, vector v1 = (i + sqrt(3)j)m/s vector v2 = ? Applying conservation of linear momentum, m1*vector v01 + m2*vector v02 = m1*vector v1 + m2*vector v2 2m2(sqrt(3)i + j) + 0 = 2m2(i + sqrt(3)j) + m2*vector v2 vector v2 = 2(sqrt(3)i + j) - 2(i + sqrt(3)j) = 2(sqrt(3)i - j) + 2(i - sqrt(3)j) vector v2 = 2(sqrt(3) - 1)(i - j) For angle between vector v1 and vector v2, cos(theta) = (vector v1 · vector v2)/(|vector v1||vector v2|) = 2(sqrt(3) - 1)(i - sqrt(3))/(2x*2*sqrt(2)(sqrt(3) - 1)) cos(theta) = (1 - sqrt(3))/(2*sqrt(2)) cos(theta) = (1 - sqrt(3))/(2sqrt(2)) => theta = 105° Alternatively, from the diagram: vector v1 is at 60° from x-axis vector v2 is at -45° from x-axis Angle between them = 60° - (-45°) = 105°
