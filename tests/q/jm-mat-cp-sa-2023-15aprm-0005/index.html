Let the foot of perpendicular of the point P(3, -2, -9) on the plane passing through the points (-1, -2, -3), (9, 3, 4), (9, -2, 1) be Q(α, β, γ). Then the distance Q from the origin is

  1. (1) sqrt(42)
  2. (2) sqrt(38)
  3. (3) sqrt(35)
  4. (4) sqrt(29)

Answer

Correct answer: Option 1

Solution

Find equation of plane through three given points using cross product. AC = 10i + 4k, AB = 10i + 5j + 7k. Normal vector = AC × AB = -20i - 30j + 50k, which simplifies to 2x + 3y - 5z = 7. Find foot of perpendicular from P(3, -2, -9) to this plane using parametric form: (x-3)/2 = (y+2)/3 = (z+9)/(-5) = -38/38 = -1. Substituting: x = 1, y = -5, z = -4. So Q(1, -5, -4). Distance from origin = sqrt(1 + 25 + 16) = sqrt(42).
