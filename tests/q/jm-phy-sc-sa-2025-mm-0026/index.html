Two liquids A and B have θ_A and θ_B as contact angles in a capillary tube. If K = cos(θ_A) / cos(θ_B), then identify the correct statement

  1. (1) K is negative, then liquid A and liquid B have concave meniscus.
  2. (2) K is zero, then liquid A has convex meniscus and liquid B has concave meniscus.
  3. (3) K is negative, then liquid A has concave meniscus and liquid B has convex meniscus.
  4. (4) K is negative, then liquid A and liquid B have convex meniscus.

Answer

Correct answer: Option 3

Solution

For a contact angle θ: if θ < 90°, cos(θ) > 0 (concave meniscus, wetting liquid). If θ > 90°, cos(θ) < 0 (convex meniscus, non-wetting liquid). For K = cos(θ_A)/cos(θ_B) to be negative, one cosine must be positive and one negative, meaning one liquid has concave meniscus and the other has convex meniscus. If cos(θ_A) < 0 and cos(θ_B) > 0, then liquid A has convex meniscus and liquid B has concave meniscus. The correct statement is option 3.
