The number of terms common to the two A.P.'s 3, 7, 11, ..... 407 and 2, 9, 16, .... 709 is ________.

Answer

Correct answer: 14

Solution

First A.P. is 3, 7, 11, 15, 19, 23, ..... 407 Second A.P. is 2, 9, 16, 23, ..... 709 First common term = 23 Common difference d = L.C.M. (4, 7) = 28 Last term ≤ 407 => 23 + (n - 1)(28) ≤ 407 => n ≤ 14.7 So, n = 14
