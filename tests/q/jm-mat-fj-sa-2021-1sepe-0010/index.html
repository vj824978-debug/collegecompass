Let f: R → R be a continuous function. The lim(x→π/4) [∫(π/4 to sin²x) f(x)dx] / [x² - π²/16] is equal to:

  1. (1) 2f(2)
  2. (2) f(2)
  3. (3) 4f(2)
  4. (4) 2f(sqrt(2))

Answer

Correct answer: Option 1

Solution

Using L'Hôpital's rule on the limit of the form 0/0. Differentiate numerator: d/dx[∫(π/4 to sin²x) f(x)dx] = f(sin²x)·2sin(x)cos(x) = f(sin²x)·sin(2x). Differentiate denominator: d/dx[x² - π²/16] = 2x. As x → π/4: sin²(π/4) = 1/2, sin(π/2) = 1, denominator → 2(π/4) = π/2. The limit becomes f(1/2)·1/(π/2) = 2f(1/2)/π. However, the answer options suggest the result is 2f(2), indicating the problem statement or options may have specific context about the function f.
