The major products obtained from the reactions in List-II are the reactants for the named reactions mentioned in List-I. Match List-I with List-II and choose the correct option. [Table with List-I containing: (P) Etard reaction, (Q) Gattermann reaction, (R) Gattermann-Koch reaction, (S) Rosenmund reduction] [Table with List-II containing: (1) Acetophenone with Zn-Hg, HCl; (2) Toluene with (i) KMnO₄, KOH, Δ and (ii) SOCl₂; (3) Benzene with CH₃Cl and anhydrous AlCl₃; (4) Aniline with NaNO₂/HCl at 273-278 K; (5) Phenol with Zn, Δ]

Matrix match · Marks: +3 / -1.0

  1. (A) P → 2; Q → 4; R → 1; S → 3
  2. (B) P → 1; Q → 3; R → 5; S → 2
  3. (C) P → 3; Q → 2; R → 1; S → 4
  4. (D) P → 3; Q → 4; R → 5; S → 2

Answer

Correct answer: D

Solution

The reaction sequence shows: [Benzene ring] + CH₃Cl/AlCl₃ → [Benzene ring with CH₃ group at top] Then: [Toluene] + CO₂Cl₂(Etard), CS₂, H₂O/H⁺ → [Benzene ring with CHO group at top] This is an Etard reaction converting a methyl group to an aldehyde through chromyl chloride oxidation. Q→4 shows the Gattermann reaction: [Benzene with NH₂] + NaNO₂/HCl (273-278K) → [Benzene with N⁺Cl⁻] + Cu/HCl → [Benzene with Cl] R→5 shows the Gattermann-Koch reaction: [Benzene with OH] + Zn/Δ → [Benzene] + CO·HCl, Anh AlCl₃ → [Benzene with CHO] S→2 shows: [Benzene with CH₃] + KMnO₄/KOH/Δ → [Benzene with COOH] + SOCl₂ → [Benzene with COCl] + H₂/Pd/BaSO₄ (Rosenmund reduction) → [Benzene with CHO]
