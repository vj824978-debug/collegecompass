The temperature at which the rate constants of the given below two gaseous reactions become equal is ____ K. (Nearest integer). X → Y k₁ = 10^6 e^(-30000/T) P → Q k₂ = 10^4 e^(-24000/T) Given: ln 10 = 2.303

Answer

Correct answer: 1303

Solution

For the rate constants to be equal: k₁ = k₂ 10^4 e^(-24000/T) = 10^6 e^(-30000/T) e^(6000/T) = 100 6000/T = ln(100) 6000/T = 2 ln(10) 6000/T = 2 × 2.303 T = 6000/(2 × 2.303) T = 6000/4.606 T = 1302.64 K T ≈ 1303 K
