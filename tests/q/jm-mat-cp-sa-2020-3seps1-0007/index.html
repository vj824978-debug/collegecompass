Consider the two sets: A = {m in R : both the roots of x^2 - (m+1)x + m + 4 = 0 are real} and B = {-3, 5}. Which of the following is not true?

  1. (1) A ∩ B = {-3}
  2. (2) A ∪ B = R
  3. (3) A - B = (-∞, -3) ∪ (5, ∞)
  4. (4) B - A = (-3, 5)

Answer

Correct answer: Option 3
