In an atom, the total number of electrons having quantum numbers n = 4, |m_l| = 1 and m_s = -1/2 is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 6

Solution

n = 4 ℓ = 0,1,2,3 |m_ℓ| = l ⟹ ±1 m_s = -1/2 For ℓ = 0, m_ℓ = 0 ℓ = 1, m_ℓ = -1, 0, +1 ℓ = 2, m_ℓ = -2, -1, 0, +1, +2 ℓ = 3, m_ℓ = -3, -2, -1, 0, +1, +2, +3 So, six electrons can have |m_ℓ| = 1 & m_s = -1/2 37. k = R/N_A R = kN_A = 1.380×10^-23 × 6.023×10^23 = 8.31174 ≈ 8.312 MX ⟶ M^2+ + 2X^-
