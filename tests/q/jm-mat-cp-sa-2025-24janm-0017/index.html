The product of all the rational roots of the equation (x^2 - 9x + 11)^2 - (x - 4)(x - 5) = 3, is equal to :

  1. (1) 14
  2. (2) 7
  3. (3) 28
  4. (4) 21

Answer

Correct answer: Option 1

Solution

(x^2 - 9x + 11)^2 - (x^2 - 9x + 20) = 3 Let x^2 - 9x = t => t^2 + 22t + 121 - t - 20 - 3 = 0 => t^2 + 21t + 98 = 0 => (t + 14)(t + 7) = 0 => t = -7, -14 So, x^2 - 9x = -7, -14 x^2 - 9x + 7 = 0 or x^2 - 9x + 14 = 0 For x^2 - 9x + 7 = 0: x = (9 ± sqrt(81 - 4(7)))/(2 × 1) = (9 ± sqrt(53))/2 For x^2 - 9x + 14 = 0: x = (9 ± sqrt(81 - 4(14)))/2 = (9 ± sqrt(81 - 56))/2 = (9 ± sqrt(25))/2 = (9 ± 5)/2 So x = 7 or x = 2 Product of all rational roots = 7 × 2 = 14 Option (1)
