Two blocks of masses m and M (M > m) are placed on a frictionless table. A massless spring with spring constant k is attached with the lower block. If the system is slightly displaced and released, then which of the following statements are correct? (μ = Coefficient of friction between the two blocks) A. The time period of small oscillation of the two blocks is T = 2*pi*sqrt((m+M)/k) B. The acceleration of the blocks is a = -kx/(M+m) C. The magnitude of frictional force on the upper block is μ*m*|x|/(M+m) D. The maximum amplitude of the upper block, if it does not slip, is μ*(M+m)*g/k E. Maximum frictional force can be μ*(M+m)*g

  1. (1) C, D, E Only
  2. (2) A, B, C Only
  3. (3) A, B, D Only
  4. (4) B, C, D Only

Answer

Correct answer: Option 3

Solution

When the system oscillates together without slipping: The blocks move as a combined system with acceleration a = -kx/(M+m). Option A: T = 2*pi*sqrt((m+M)/k) is correct. Option B: a = -kx/(M+m) is correct. For the upper block to not slip, friction provides the required force: f = m*a = -m*kx/(M+m). Option C: |f| = m*k*|x|/(M+m), not μ*m*|x|/(M+m). This is incorrect. For maximum amplitude before slipping, the maximum friction is μ*m*g, so μ*m*g = m*k*A_max/(M+m), giving A_max = μ*(M+m)*g/k. Option D is correct. Option E: Maximum friction between blocks is μ*m*g, not μ*(M+m)*g. This is incorrect. Correct statements: A, B, D
