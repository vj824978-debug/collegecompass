Let the domain of the function f(x) = log_5(log_7(log_7(9x - x^2 - 13))) be the interval (m, n). Let the hyperbola x^2/a^2 - y^2/b^2 = 1 have eccentricity n/3 and the length of the latus rectum 8m/3. Then b^2 - a^2 is equal to:

  1. (1) 5
  2. (2) 11
  3. (3) 9
  4. (4) 7

Answer

Correct answer: Option 4

Solution

log_5(log_7(log_7(9x - x^2 - 13))) > 0 => log_7(log_7(9x - x^2 - 13)) > 7 => log_7(9x - x^2 - 13) > 7^7 For domain restriction: 9x - x^2 - 13 > 0 => x^2 - 9x + 20 < 0 => (x - 4)(x - 5) < 0 => 4 < x < 5 m = 4, n = 5 For hyperbola: e = n/3 = 5/3 e = sqrt(1 + b^2/a^2) = 5/3 => 1 + b^2/a^2 = 25/9 => b^2/a^2 = 25/9 - 1 = 16/9 => b/a = 4/3 Length of latus rectum = 2b^2/a = 8m/3 = 8(4)/3 = 32/3 => 2b^2/a = 32/3 => 2b^2 = 32/3 × a × 3/4 = 8a From b/a = 4/3, we have b = 4a/3 => 2(4a/3)^2 = 32a/3 => 2 × 16a^2/9 = 32a/3 => 32a^2/9 = 32a/3 => a = 3 => b = 4 b^2 - a^2 = 16 - 9 = 7
