The maximum value of the function f(x) = 3x^3 - 18x^2 + 27x - 40 on the set S = {x ∈ R : x^2 + 30 ≤ 11x} is :

  1. (1) -222
  2. (2) -122
  3. (3) 122
  4. (4) 222

Answer

Correct answer: Option 3

Solution

S : x^2 - 11x + 30 ≤ 0 (x - 6)(x - 5) ≤ 0 5 ≤ x ≤ 6 f'(x) = 3·3x^2 - 18·2x + 27 = 9x^2 - 36x + 27 = 9(x^2 - 4x + 3) For maximum & minimum f'(x) = 0 at x = 1, x = 3 But in [5, 6] f'(x) > 0 So f(x) ↑ function maximum at x = 6 3(6)^3 - 18(6)^2 + 27(6) - 40 = 122
