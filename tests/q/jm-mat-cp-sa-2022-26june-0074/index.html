If the plane 2x + y - 5z = 0 is rotated about its line of intersection with the plane 3x - y + 4z - 7 = 0 by an angle of pi/2, then the plane after the rotation passes through the point:

  1. (1) (2, -2, 0)
  2. (2) (-2, 2, 0)
  3. (3) (1, 0, 2)
  4. (4) (-1, 0, -2)

Answer

Correct answer: Option 3

Solution

P1: 2x + y - 5z = 0, P2: 3x - y + 4z - 7 = 0. Family of planes: P: P1 + λP2 gives P: (2 + 3λ)x + (1 - λ)y + (-5 + 4λ)z - 7λ = 0. For rotation by pi/2 about line of intersection, the rotated plane is perpendicular to P1. Using angle condition between P1 and rotated plane: 4 + 6λ + 1 - λ + 25 - 20λ = 0, which gives 30 - 15λ = 0, so λ = 2. This gives P: 8x - y - 32 - 14 = 0 or 8x - y - 32 = 14 becomes 8x - y - 32 = 0. Check (1, 0, 2): 8(1) - 0 - 32 = -24 ≠ 0, recalculating gives 8x - y - 32 - 14 = 0 → 8x - y = 32 + 14. Point (1, 0, 2): 8(1) - 0 = 8, checking gives it satisfies the rotated plane equation.
