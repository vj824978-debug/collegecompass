Let a1, a2, ....., an be a given A.P. whose common difference is an integer and Sn = a1 + a2 + ..... + an. If a1 = 1, an = 300 and 15 ≤ n ≤ 50, then the ordered pair (Sn-4, an-4) is equal to:

  1. (1) (2490, 249)
  2. (2) (2490, 248)
  3. (3) (2480, 249)
  4. (4) (2480, 248)

Answer

Correct answer: Option 1

Solution

an = a1 + (n-1)d ⇒ 300 = 1 + (n-1)d ⇒ (n-1)d = 299 = 13 × 23 since, n ∈ [15, 50] ∴ n = 24 and d = 13 an-4 = a20 = 1 + 19 × 13 = 248 ⇒ an-4 = 248 Sn-4 = (20/2){1 + 248} = 2490
