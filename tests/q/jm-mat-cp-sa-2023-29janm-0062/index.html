Let the tangents at the points A(4, -11) and B(8, -5) on the circle x^2 + y^2 - 3x + 10y - 15 = 0, intersect at the point C. Then the radius of the circle, whose centre is C and the line joining A and B is its tangent, is equal to

  1. (1) sqrt(13)
  2. (2) (3*sqrt(3))/4
  3. (3) (2*sqrt(13))/3
  4. (4) 2*sqrt(13)

Answer

Correct answer: Option 3

Solution

First, find the center and radius of the given circle x^2 + y^2 - 3x + 10y - 15 = 0. Rewriting: (x - 3/2)^2 + (y + 5)^2 = 15 + 9/4 + 25 = 169/4 So center O = (3/2, -5) and radius = 13/2 Verify A(4, -11) and B(8, -5) lie on the circle: For A: (4 - 3/2)^2 + (-11 + 5)^2 = (5/2)^2 + 36 = 25/4 + 144/4 = 169/4 ✓ For B: (8 - 3/2)^2 + (-5 + 5)^2 = (13/2)^2 + 0 = 169/4 ✓ OA = OB = 13/2 Find AB: AB = sqrt((8-4)^2 + (-5-(-11))^2) = sqrt(16 + 36) = sqrt(52) = 2*sqrt(13) Therefore AM = sqrt(13), where M is the midpoint of AB. In triangle AMO: angle OAM = theta where sin(theta) = OM/OA Also, AM = OA*cos(theta), so cos(theta) = sqrt(13)/(13/2) = 2*sqrt(13)/13 sin(theta) = sqrt(1 - cos^2(theta)) = sqrt(1 - 52/169) = sqrt(117/169) = 3*sqrt(13)/13 = 3/sqrt(13) Since CA is tangent to circle at A: angle CAO = 90° In triangle AMO: angle OAM = angle ACO = theta (since angle CAM = 90° - theta and triangle AMC has angle CAM = 90° - theta) In triangle AMO: tan(theta) = OM/AM tan(theta) = OM/sqrt(13) From sin(theta) = 3/sqrt(13), we get cos(theta) = 2/sqrt(13) tan(theta) = 3/2 So OM = sqrt(13) * (3/2) = 3*sqrt(13)/2 OC = 13/(2*sin(theta)) = 13/(2 * 3/sqrt(13)) = 13*sqrt(13)/6 CM = OC - OM = 13*sqrt(13)/6 - 3*sqrt(13)/2 = (13*sqrt(13) - 9*sqrt(13))/6 = 4*sqrt(13)/6 = 2*sqrt(13)/3 The radius of circle with center C and tangent to line AB (which passes through A and B) is the perpendicular distance from C to line AB. This distance is CM = 2*sqrt(13)/3
