Let alpha > 0, beta > 0 be such that alpha^3 + beta^2 = 4. If the maximum value of the term independent of x in the binomial expansion of (alpha*x^(1/9) + beta*x^(-1/6))^10 is 10k, then k is equal to:

  1. (1) 176
  2. (2) 336
  3. (3) 352
  4. (4) 84

Answer

Correct answer: Option 2

Solution

let t_(r+1) denotes r+1 th term of (alpha*x^(1/9) + beta*x^(-1/6))^10 t_(r+1) = C(10,r) * alpha^(10-r) * (x)^((10-r)/9) * beta^r * x^(r/6) = C(10,r) * alpha^(10-r) * beta^r * x^((10-r)/9 + r/6) If t_(r+1) is independent of x: (10-r)/9 - r/6 = 0 => r = 4 maximum value of t_5 is 10K (given) => C(10,4) * alpha^6 * beta^4 is maximum By AM >= GM (for positive numbers): (alpha^3 + alpha^3 + beta^2 + beta^2)/4 >= (alpha^3 * alpha^3 * beta^2 * beta^2)^(1/4) => (2*alpha^3 + 2*beta^2)/4 >= (alpha^6 * beta^4)^(1/4) => alpha^6 * beta^4 <= 16 So, 10K = C(10,4) * 16 => K = 336
