The complex(es), which can exhibit the type of isomerism shown by [Pt(NH₃)₂Br₂], is(are) [en = H₂NCH₂CH₂NH₂]

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) [Pt(en)(SCN)₂]
  2. (B) [Zn(NH₃)₂Cl₂]
  3. (C) [Pt(NH₃)₂Cl₄]
  4. (D) [Cr(en)₂(H₂O)(SO₄)]⁺

Answer

Correct answer: CD

Solution

Sol. [Pt(NH₃)₄Br₂] is a square planar complex. The given compound can show geometrical isomerism (cis-trans form) Option (A): [Pt(en)(SCN)₂] cannot show geometrical isomerism. Option (B): [Zn(NH₃)₄Cl₂] is a tetrahedral complex, cannot show geometrical isomerism. Option (C): [Pt(NH₃)₂Cl₄] is a octahedral complex, can show geometrical isomerism.
