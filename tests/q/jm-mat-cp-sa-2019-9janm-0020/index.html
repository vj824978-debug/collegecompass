If A = [e^t, -e^(-t)*cos(t), -e^(-t)*sin(t) + e^t*cos(t); e^t, -e^(-t)*cos(t) - e^(-t)*sin(t), -e^(-t)*sin(t) + e^t*cos(t); e^t, 2*e^(-t)*sin(t), -2*e^(-t)*cos(t)] then A is:

  1. (1) invertible only if t = pi
  2. (2) invertible for all t in R
  3. (3) invertible only if t = pi/2
  4. (4) not invertible for any t in R

Answer

Correct answer: Option 2

Solution

A = [e^t, -e^(-t)*cos(t), -e^(-t)*sin(t) + e^t*cos(t); e^t, -e^(-t)*cos(t) - e^(-t)*sin(t), -e^(-t)*sin(t) + e^t*cos(t); e^t, 2*e^(-t)*sin(t), -2*e^(-t)*cos(t)] |A| = e^t * e^(-t) * e^t * |1, cos(t), sin(t); 1, -cos(t) - sin(t), -sin(t) + cos(t); 1, 2*sin(t), -2*cos(t)| Apply operations R2 < R2 - R1, R3 < R3 - R1, R1 < R1 |A| = e^t * |1, cos(t), sin(t); 0, -sin(t) - 2*cos(t), -2*sin(t) + cos(t); 0, 2*sin(t) - cos(t), -2*cos(t) - sin(t)| Open the determinant by R1: |A| = 5*e^(-t) Since e^(-t) > 0 for all t in R, we have |A| = 5*e^(-t) ≠ 0 for all t in R. Therefore, A is invertible for all t in R.
