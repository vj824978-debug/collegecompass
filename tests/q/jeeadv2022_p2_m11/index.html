Let z̄ denote the complex conjugate of a complex number z. If z is a non-zero complex number for which both real and imaginary parts of (z)^2 + 1/z^2 are integers, then which of the following is/are possible value(s) of |z|?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (43 + 3*sqrt(205))^(1/4) / 2
  2. (B) (7 + sqrt(33))^(1/4) / 4
  3. (C) (9 + sqrt(65))^(1/4) / 4
  4. (D) (7 + sqrt(13))^(1/4) / 6

Answer

Correct answer: A

Solution

Let ω = I₁ + iI₂ = (z̄)² + 1/z², I₁, I₂ ∈ Integers ⟹ |ω| = √(I₁² + I₂²) = |z|² + 1/|z|² ⟹ |z|⁴ + 1/|z|⁴ = I₁² + I₂² - 2 ⟹ |z|⁸ - (I₁² + I₂² - 2)|z|⁴ + 1 = 0 ⟹ |z|⁴ = ((I₁² + I₂² - 2) ± √((I₁² + I₂² - 2)² - 4))/2 ⟹ |z| = ((43 ± 3√205)/2)^(1/4) where I₁ = 6, I₂ = 3
