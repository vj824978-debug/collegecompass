For a first order reaction A(g) → 2B(g) + C(g) at constant volume and 300 K, the total pressure at the beginning (t = 0) and at time t are P₀ and Pₜ, respectively. Initially, only A is present with concentration [A]₀, and t₁/₃ is the time required for the partial pressure of A to reach 1/3^rd of its initial value. The correct option(s) is(are) (Assume that all these gases behave as ideal gases) [Four graphs labeled A, B, C, D showing various relationships: (A) ln(3p_A) vs Time showing negative linear relationship, (B) t₁/₃ vs [A]₀ showing negative linear relationship, (C) ln(p_A - p_∞) vs Time showing negative linear relationship, (D) Rate constant vs [A]₀ showing horizontal line]

Multiple correct (MSQ) · Marks: +4 / -2.0

Answer

Correct answer: AD

Solution

A(g) → 2B(g) + C(g) at t = 0: p₀ 0 0 (p₀ - p) 2p p p_t = p₀ - p + 2p + p = p₀ + 2p p = (p_t - p₀)/2 t = (1/k)ln(2p₀/(3p₀ - p_t)) kt = ln 2p₀ - ln(3p₀ - p_t) ln(3p₀ - p_t) = ln 2p₀ - kt y = mx + c So, m = -k c = ln(2p₀) [Graph 1: Linear plot showing ln(3p₀ - p_t) on y-axis versus t on x-axis, with negative slope] kt₁/₃ = ln([A₀]/([A₀]/3)) ln 3 t₁/₃ = ln 3/k [Graph 2: Step function showing t₁/₃ on y-axis versus [A₀] on x-axis, with constant horizontal line]
