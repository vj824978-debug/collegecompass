If the function f(x) = { (1/x)log_a((1+x/a)/(1+x/b)), x<0; k, x=0; (cos^2(x)-sin^2(x)-1)/(sqrt(x^2+1)-1), x>0 } is continuous at x=0, then 1/a + 1/b + 4/k is equal to:

  1. (1) 4
  2. (2) -5
  3. (3) 5
  4. (4) -4

Answer

Correct answer: Option 2

Solution

For continuity at x=0, we need LHS = RHS = f(0) = k. LHS: lim(x→0-) (1/x)log_a((1+x/a)/(1+x/b)) = lim(h→0) (1/-h)log_a((1-h/a)/(1-h/b)) = lim(h→0) (1/(-h))[log_a(1-h/a) - log_a(1-h/b)] = (1/a - 1/b). RHS: lim(x→0+) (cos^2(x)-sin^2(x)-1)/(sqrt(x^2+1)-1) = lim(x→0+) (cos(2x)-1)/(sqrt(x^2+1)-1) = lim(x→0+) (-2sin^2(x))/(sqrt(x^2+1)-1) × (sqrt(x^2+1)+1)/(sqrt(x^2+1)+1) = lim(x→0+) (-2sin^2(x))(sqrt(x^2+1)+1)/x^2 = -2×2 = -4. From continuity: 1/a - 1/b = -4 = k. Therefore: 1/a + 1/b + 4/k = 1/a + 1/b + 4/(-4) = 1/a + 1/b - 1 = -5
