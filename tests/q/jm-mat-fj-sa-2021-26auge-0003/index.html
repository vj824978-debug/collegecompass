A 10 inches long pencil AB with mid point C and a small eraser P are placed on the horizontal top of a table such that PC = sqrt(5) inches and angle PCB = tan^(-1)(2). The acute angle through which the pencil must be rotated about C so that the perpendicular distance between eraser and pencil becomes exactly 1 inch is:

  1. (1) tan^(-1)(1/2)
  2. (2) tan^(-1)(4/3)
  3. (3) tan^(-1)(1)
  4. (4) tan^(-1)(3/4)

Answer

Correct answer: Option 4

Solution

Given: PC = sqrt(5), angle PCB = tan^(-1)(2) so tan(theta) = 2. The perpendicular distance from P to line AB must become 1 inch after rotation by angle alpha. Using sin(theta - alpha) = 1/sqrt(5) and the condition that tan(theta - alpha) = (sqrt(5)/2 - 1)/sqrt(5). From tan(theta) - tan(alpha))/(1 + tan(theta)tan(alpha)) = 1/2, we get (2 - tan(alpha))/(1 + 2tan(alpha)) = 1/2. Solving: 4 - 2tan(alpha) = 1 + 2tan(alpha), so 2tan(alpha) = 3/4, thus tan(alpha) = 3/4 and alpha = tan^(-1)(3/4).
