Let f be a differentiable function satisfying f(x) = 1 - 2x + integral from 0 to x of e^(x-t) f(t) dt, x in R and let g(x) = integral from 0 to x of (f(t) + 2)^15 (t-4)^6 (t+12)^17 dt, x in R. If p and q are respectively the points of local minima and local maxima of g, then the value of |p + q| is equal to ____.

Answer

Correct answer: 9

Solution

f(x) = 1 - 2x + e^x integral from 0 to x of e^(-t) f(t) dt Multiplying by e^(-x): e^(-x) f(x) = (1 - 2x) e^(-x) + integral from 0 to x of e^(-t) f(t) dt Differentiating both sides: e^(-x) f'(x) - e^(-x) f(x) = -2e^(-x) + (1 - 2x) e^(-x) (-1) + e^(-x) f(x) Simplifying: f'(x) - 2f(x) = 2x - 3 This is a linear differential equation: dy/dx - 2y = 2x - 3 Using integrating factor e^(-2x): y e^(-2x) = integral of e^(-2x) (2x - 3) dx With f(0) = 1, solving gives: f(x) = 1 - x Now for g(x): g(x) = integral from 0 to x of (f(t) + 2)^15 (t - 4)^6 (t + 12)^17 dt Substituting f(t) = 1 - t: g(x) = integral from 0 to x of (3 - t)^15 (t - 4)^6 (t + 12)^17 dt Finding g'(x): g'(x) = (3 - x)^15 (x - 4)^6 (x + 12)^17 = -(x - 3)^15 (x - 4)^6 (x + 12)^17 Analyzing the sign of g'(x) using critical points x = -12, 3, 4: Sign chart: (-∞, -12): negative (-12, 3): positive (3, 4): negative (4, ∞): positive Therefore: - Local minimum at x = -12 (sign changes from - to +) - Local maximum at x = 3 (sign changes from + to -) So p = -12 and q = 3 |p + q| = |-12 + 3| = |-9| = 9
