For the given cell Fe^(2+)(aq) + Ag^+(aq) → Fe^(3+)(aq) + Ag(s). The standard cell potential of the above reaction is Given: Ag^+ + e^- → Ag, E^0 = x V; Fe^(2+) + 2e^- → Fe, E^0 = y V; Fe^(3+) + 3e^- → Fe, E^0 = z V

  1. (1) x + y - z
  2. (2) x + 2y - 3z
  3. (3) y - 2x
  4. (4) x + 2y

Answer

Correct answer: Option 2

Solution

Fe^(2+)(aq) + Ag^+(aq) → Fe^(3+)(aq) + Ag(s) We need to construct this overall reaction from the given half-reactions. The overall reaction can be written as: Fe → Fe^(2+) → Fe^(3+) Using the given half-reactions: Ag^+ + e^- → Ag, E^0 = x V ... (1) Fe^(2+) + 2e^- → Fe, E^0 = y V ... (2) Fe^(3+) + 3e^- → Fe, E^0 = z V ... (3) We can express: ΔG_3^0 = ΔG_1^0 + ΔG_2^0 where ΔG_3^0 corresponds to: -3F(z) = -2F(y) + ΔG_2^0 ΔG_2^0 = 3Fz - 2Fy Also ΔG_2^0 = -nFE_{Fe^(2+)/Fe^(3+)}^0 3Fz - 2Fy = -1F(E_{Fe^(2+)/Fe^(3+)}^0) E_{Fe^(2+)/Fe^(3+)}^0 = 2y - 3z E_Cell^0 for reaction will be: E_Ag^+/Ag^0 + E_{Fe^(2+)/Fe^(3+)}^0 = x + 2y - 3z Option (2)
