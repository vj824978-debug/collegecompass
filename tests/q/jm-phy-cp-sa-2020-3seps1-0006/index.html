When the wavelength of radiation of falling on a metal is changed from 500 nm to 200 nm, the maximum kinetic energy of the photoelectrons becomes three times larger. The work function of the metal is close to

  1. (1) 0.61 eV
  2. (2) 0.81 eV
  3. (3) 1.02 eV
  4. (4) 0.52 eV

Answer

Correct answer: Option 1

Solution

Using Einstein's photoelectric equation: KE_max = hc/lambda - phi For lambda1 = 500 nm: KE1 = hc/500 - phi For lambda2 = 200 nm: KE2 = hc/200 - phi Given that KE2 = 3*KE1: hc/200 - phi = 3(hc/500 - phi) hc/200 - phi = 3hc/500 - 3*phi hc/200 - 3hc/500 = phi - 3*phi hc(1/200 - 3/500) = -2*phi hc(5/(1000) - 6/(1000)) = -2*phi hc(-1/1000) = -2*phi hc/1000 = 2*phi phi = hc/2000 With hc = 1240 eV-nm: phi = 1240/(2000) = 0.62 eV ≈ 0.61 eV
