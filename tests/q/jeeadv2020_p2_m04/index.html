The trace of a square matrix is defined to be the sum of its diagonal entries. If A is a 2 × 2 matrix such that the trace of A is 3 and the trace of A³ is -18, then the value of the determinant of A is ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 5

Solution

Let A = [a b; c d], a + d = 3 ⟹ A² = [a b; c d][a b; c d] = [a² + bc, ab + bd; ac + cd, bc + d²] ⟹ A³ = [a³ + 2abc + bcd, a²b + abd + b²c + bd²; a²c + acd + bc² + cd², abc + 2bcd + d³] ⟹ a³ + d³ + 3abc + 3bcd = -18 ⟹ (a + d)(a² + d² - ad) + 3bc(a + d) = -18 ⟹ (a + d)((a + d)² - 3ad) + 3bc(a + d) = -18 ⟹ 3(9 - 3ad) + 9bc = -18 ⟹ ad - bc = 5 ⟹ |A| = 5
