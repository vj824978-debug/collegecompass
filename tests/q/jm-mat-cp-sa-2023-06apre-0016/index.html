Let the line L pass through the point (0, 1, 2), intersect the line (x-1)/2 = (y-2)/3 = (z-3)/4 and be parallel to the plane 2x + y - 3z = 4. Then the distance of the point P(1, -9, 2) from the line L is

  1. (1) sqrt(74)
  2. (2) sqrt(69)
  3. (3) sqrt(54)
  4. (4) 9

Answer

Correct answer: Option 1

Solution

Direction ratios of given line are <2, 3, 4>. Line L passes through (0, 1, 2) with direction ratios <a, b, c>. Since L is parallel to plane 2x + y - 3z = 4, we have 2a + b - 3c = 0. Since L intersects the given line, the direction vector must satisfy: a - 2b + c = 0 and 2a + b - 3c = 0. Solving these gives a = b = c, so direction ratios are <1, 1, 1>. Line L: (x-0)/1 = (y-1)/1 = (z-2)/1 = λ. Any point on L is A(λ, 1+λ, 2+λ). Vector AP = <1-λ, -10-λ, -λ>. For minimum distance, AP · <1,1,1> = 0, giving λ = -3. So A(-3, -2, -1). Distance = sqrt((1-(-3))^2 + (-9-(-2))^2 + (2-(-1))^2) = sqrt(16 + 49 + 9) = sqrt(74).
