If the sum of the second, third and fourth terms of a positive term G.P. is 3 and the sum of its sixth, seventh and eighth terms is 243, then the sum of the first 50 terms of this G.P. is:

  1. (1) (2/13)(3^50 - 1)
  2. (2) (1/26)(3^50 - 1)
  3. (3) (1/13)(3^50 - 1)
  4. (4) (1/26)(3^49 - 1)

Answer

Correct answer: Option 2

Solution

Let first term = a > 0 Common ratio = r > 0 ar + ar^2 + ar^3 = 3 .....(i) ar^5 + ar^6 + ar^7 = 243 .....(ii) From equation (ii): r^4(ar + ar^2 + ar^3) = 243 r^4(3) = 243 => r^4 = 81 => r = 3 as r > 0 From equation (i): 3a + 9a + 27a = 3 39a = 3 a = 1/13 S_50 = a(r^50 - 1)/(r - 1) = (1/13)(3^50 - 1)/(3 - 1) = (1/13)(3^50 - 1)/2 = (1/26)(3^50 - 1)
