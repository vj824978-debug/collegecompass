If the process carried out on one mole of monatomic ideal gas is as shown in figure in the PV-diagram with P₀V₀ = (1/3)RT₀, the correct match is, [PV-diagram showing a process with three states: State 1 at (V₀, P₀), State 2 at (2V₀, P₀), and State 3 at (2V₀, 3P₀/2). Process 1→2 is isobaric (horizontal), process 2→3 is isochoric (vertical).]

Matrix match · Marks: +4 / -1.0

Passage:

  1. (A) I → Q, II → R, III → S, IV → U
  2. (B) I → Q, II → S, III → R, IV → U
  3. (C) I → Q, II → R, III → P, IV → U
  4. (D) I → S, II → R, III → Q, IV → T

Answer

Correct answer: A

Solution

W₁→₂→₃ = P₀V₀ = (1/3)RT₀ ΔU₁→₂→₃ = nCᵥ(Tf - Ti) = 1×(3/2)(3P₀V₀ - P₀V₀) = RT₀ ΔQ₁→₂→₃ = ΔU + W = (4/3)RT₀ ΔQ₁→₂ = nCₚΔT = (5/2)(2P₀V₀ - P₀V₀) = (5/6)RT₀
