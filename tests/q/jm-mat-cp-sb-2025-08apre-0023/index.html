Let r be the radius of the circle, which touches x-axis at point (a, 0), a < 0 and the parabola y^2 = 9x at the point (4, 6). Then r is equal to ____.

Answer

Correct answer: 30

Solution

Equation of tangent to y^2 = 9x at (4, 6) is 3x - 4y + 12 = 0. Circle touches x-axis at (a, 0) where a < 0, so center is at (a, r). Circle equation: (x - a)^2 + (y - r)^2 = lambda(3x - 4y + 12) = 0. Expanding and comparing coefficients: x^2 + y^2 + (3*lambda - 8)x + (-12 - 4*lambda)y + 52 + 12*lambda = 0. Using condition 2*sqrt(g^2 - c) = 0 gives g^2 = c. From ((3*lambda - 8)/2)^2 = 52 + 12*lambda, solving gives lambda = 12 or -2/3. For lambda = 12: f = -30, g^2 - c = 0. Therefore r = sqrt(g^2 + f^2 - c) = |f| = |-30| = 30. Since center lies in 2nd quadrant, 3*lambda - 8 > 0 requires lambda = 12.
