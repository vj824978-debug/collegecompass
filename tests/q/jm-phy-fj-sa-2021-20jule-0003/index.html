If time (t), velocity (v), and angular momentum (r) are taken as the fundamental units. Then the dimension of mass (m) in terms of t, v, and r is:

  1. (1) [t^3 v^-1 r^-1]
  2. (2) [t^1 v^1 r^-1]
  3. (3) [t^-1 v^-4 r^1]
  4. (4) [t^1 v^-1 c^-1]

Answer

Correct answer: Option 3

Solution

Using dimensional analysis: Let m = [t^a v^b r^c]. Angular momentum has dimension [M L^2 T^-1]. Since r represents angular momentum: [r] = [M L^2 T^-1]. We need [M L T^-1]^a * [L T^-1]^b * [M L^2 T^-1]^c to equal mass [M]. This gives: a - b - c = 0, c = 1, and b + 2c = -2. Solving: b = -2c = -2, a = b + c = -2 + 1 = -1. Therefore m = [t^-1 v^-2 r^1]
