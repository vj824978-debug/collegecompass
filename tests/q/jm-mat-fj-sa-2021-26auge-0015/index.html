If (sqrt(3)+i)^100 = 2^99 (p+iq), then p and q are roots of the equation:

  1. (1) x^2 + (sqrt(3)+1)x + sqrt(3) = 0
  2. (2) x^2 - (sqrt(3)+1)x + sqrt(3) = 0
  3. (3) x^2 + (sqrt(3)-1)x - sqrt(3) = 0
  4. (4) x^2 - (sqrt(3)-1)x - sqrt(3) = 0

Answer

Correct answer: Option 4

Solution

Convert sqrt(3)+i to polar form: sqrt(3)+i = 2(sqrt(3)/2 + i/2) = 2(cos(pi/6) + i*sin(pi/6)). Then (sqrt(3)+i)^100 = 2^100(cos(100pi/6) + i*sin(100pi/6)) = 2^100(cos(50pi/3) + i*sin(50pi/3)). Simplifying: 50pi/3 = 16pi + 2pi/3, so cos(50pi/3) = cos(2pi/3) = -1/2 and sin(50pi/3) = sin(2pi/3) = sqrt(3)/2. Thus (sqrt(3)+i)^100 = 2^100(-1/2 + i*sqrt(3)/2) = 2^99(-1 + i*sqrt(3)). Comparing with 2^99(p+iq): p = -1 and q = sqrt(3). These are roots of x^2 - (sqrt(3)-1)x - sqrt(3) = 0.
