In hydrogen atom spectrum, ( R → Rydberg's constant) A. the maximum wavelength of the radiation of Lyman series is 4/(3R) B. the Balmer series lies in the visible region of the spectrum C. the minimum wavelength of the radiation of Paschen series is 9/R D. the minimum wavelength of Lyman series is 5/(4R) Choose the correct answer from the options given below:

  1. (1) B, D Only
  2. (2) A, B and C Only
  3. (3) A, B and D Only
  4. (4) A, B Only

Answer

Correct answer: Option 2

Solution

Using Rydberg formula: 1/lambda = R(1/n1^2 - 1/n2^2) For Lyman series (n1 = 1): Maximum wavelength occurs when n2 = 2 (minimum energy difference): 1/lambda = R(1/1^2 - 1/2^2) = R(1 - 1/4) = 3R/4 lambda = 4/(3R) ✓ Statement A is CORRECT. For Balmer series (n1 = 2): Transitions occur from n2 = 3, 4, 5, ... Minimum wavelength (n2 → ∞): 1/lambda_min = R(1/4 - 0) = R/4 lambda_min = 4/R ≈ 656 nm (in visible region) Maximum wavelength (n2 = 3): 1/lambda_max = R(1/4 - 1/9) = 5R/36 lambda_max ≈ 656 nm The Balmer series lies in the visible region. Statement B is CORRECT. For Paschen series (n1 = 3): Minimum wavelength occurs when n2 → ∞: 1/lambda_min = R(1/9 - 0) = R/9 lambda_min = 9/R ✓ Statement C is CORRECT. For Lyman series (n1 = 1): Minimum wavelength occurs when n2 → ∞: 1/lambda_min = R(1/1 - 0) = R lambda_min = 1/R Statement D says minimum wavelength is 5/(4R), which is INCORRECT. Statement D is WRONG. Correct statements: A, B, and C
