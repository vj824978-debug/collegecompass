Let A be a 3 × 3 real matrix such that A[1,1,0]^T = [1,1,0]^T; A[1,0,1]^T = [-1,0,1]^T and A[0,0,1]^T = [1,1,2]^T. If X = (x1, x2, x3)^T and I is an identity matrix of order 3, then the system (A - 2I)X = [4,1,1]^T has:

  1. (1) no solution
  2. (2) Infinitely many solutions
  3. (3) Unique solution
  4. (4) Exactly two solutions

Answer

Correct answer: Option 2

Solution

From the given conditions, we determine matrix A by solving the three equations. Setting up A = [a b c; d e f; g h i] and using the three conditions gives us the system: a+b=1, d+e=1, g+h=0, a+c=-1, d+f=0, g+i=1, c=1, f=1, i=2. Solving yields A = [-2 3 1; -1 2 1; -1 1 2]. Then A-2I = [-4 3 1; -1 0 1; -1 1 0]. The system (A-2I)X = [4,1,1]^T gives: -4x1+3x2+x3=4, -x1+x3=1, -x1+x2=1. From equations (ii) and (iii), we get x2 = x3. Checking with equation (i): -4x1+3x2+x2=4, which with x1=x3-1 gives 3x2(iii)+(ii)=(i), so the equations are dependent. This means infinitely many solutions.
