In case of vertical circular motion of a particle by a thread of length r if the tension in the thread is zero at an angle 30° shown in figure, the velocity at the bottom point (A) of the circular path is (g = gravitational acceleration)

  1. (1) sqrt(5gr)
  2. (2) sqrt(7/2 gr)
  3. (3) sqrt(4gr)
  4. (4) sqrt(5/2 gr)

Answer

Correct answer: Option 2

Solution

At the point where tension T = 0 and the angle is 60° from the vertical (or 30° from horizontal as shown): The centripetal force is provided by the component of weight: T + mg cos(60°) = mV^2/r Since T = 0: mg cos(60°) = mV^2/r g(1/2) = V^2/r V^2 = gr/2 Now using energy conservation between the point (at 60° from vertical) and point A (bottom): Height difference: h = r - r cos(60°) = r - r(1/2) = r/2 Using M.E.C.: (1/2)mu^2 = mg(r + r cos(60°)) + (1/2)mV^2 Where u is the speed at point A: (1/2)u^2 = g(r + r/2) + (1/2)(gr/2) (1/2)u^2 = g(3r/2) + gr/4 (1/2)u^2 = 3gr/2 + gr/4 (1/2)u^2 = (6gr + gr)/4 (1/2)u^2 = 7gr/4 u^2 = 7gr/2 u = sqrt(7gr/2)
