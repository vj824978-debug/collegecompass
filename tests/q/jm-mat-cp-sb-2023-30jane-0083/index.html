50th root of a number x is 12 and 50th root of another number y is 18. Then the remainder obtained on dividing (x + y) by 25 is ______.

Answer

Correct answer: 23

Solution

Given x^(1/50) = 12 => x = 12^50 y^(1/50) = 18 => y = 18^50 We need to find the remainder when (x + y) is divided by 25, i.e., find 12^50 + 18^50 (mod 25) For 12^50 (mod 25): 12 ≡ 13 (mod 25) 12^2 ≡ 19 (mod 25) 12^3 ≡ -3 (mod 25) 12^9 ≡ -2 (mod 25) 12^10 ≡ -1 (mod 25) 12^50 ≡ -1 (mod 25) ...(i) For 18^50 (mod 25): 18 ≡ 7 (mod 25) 18^2 ≡ -1 (mod 25) 18^50 ≡ -1 (mod 25) ...(ii) Therefore: 12^50 + 18^50 ≡ -1 + (-1) (mod 25) ≡ -2 (mod 25) ≡ 23 (mod 25) Answer: 23
