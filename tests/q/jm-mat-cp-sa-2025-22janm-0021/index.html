Let the function f(x) = {-3ax^2 - 2, x < 1; a^2 + bx, x >= 1} be differentiable for all x in R, where a > 1, b in R. If the area of the region enclosed by y = f(x) and the line y = -20 is alpha + beta*sqrt(3), alpha, beta in Z, then the value of alpha + beta is ____.

Answer

Correct answer: 34

Solution

f(x) is continuous and differentiable at x = 1; LHL = RHL, LHD = RHD Continuity at x = 1: -3a - 2 = a^2 + b ... (1) Differentiability at x = 1: f'(x) = {-6x, x < 1; b, x >= 1} -6a = b ... (2) From equation (2): b = -6a Substituting in equation (1): -3a - 2 = a^2 - 6a a^2 - 3a + 2 = 0 (a - 1)(a - 2) = 0 Since a > 1, we have a = 2, b = -12 Therefore: f(x) = {-6x^2 - 2, x < 1; 4 - 12x, x >= 1} Finding intersection points with y = -20: For x < 1: -6x^2 - 2 = -20 -6x^2 = -18 x^2 = 3 x = -sqrt(3) (since x < 1) For x >= 1: 4 - 12x = -20 -12x = -24 x = 2 At x = 1: f(1) = 4 - 12(1) = -8 The region is enclosed by y = f(x) and y = -20 between x = -sqrt(3) and x = 2. Area = integral from -sqrt(3) to 1 of [(-6x^2 - 2) - (-20)] dx + integral from 1 to 2 of [(4 - 12x) - (-20)] dx Area = integral from -sqrt(3) to 1 of (-6x^2 + 18) dx + integral from 1 to 2 of (24 - 12x) dx First integral: [-2x^3 + 18x] from -sqrt(3) to 1 = [-2(1) + 18(1)] - [-2(-sqrt(3))^3 + 18(-sqrt(3))] = [-2 + 18] - [2(3sqrt(3)) - 18sqrt(3)] = 16 - [6sqrt(3) - 18sqrt(3)] = 16 - (-12sqrt(3)) = 16 + 12sqrt(3) Second integral: [24x - 6x^2] from 1 to 2 = [24(2) - 6(4)] - [24(1) - 6(1)] = [48 - 24] - [24 - 6] = 24 - 18 = 6 Total Area = 16 + 12sqrt(3) + 6 = 22 + 12sqrt(3) Comparing with alpha + beta*sqrt(3): alpha = 22, beta = 12 alpha + beta = 22 + 12 = 34
