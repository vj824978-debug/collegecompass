Let y = y(x) be the solution of the differential equation (x^2 - 3y^2)dx + 3xy dy = 0, y(1) = 1. Then 6y^2(e) is equal to

  1. (1) 3e^2
  2. (2) (3/2)e^2
  3. (3) e^2
  4. (4) 2e^2

Answer

Correct answer: Option 4

Solution

(x^2 - 3y^2)dx + 3xy dy = 0, y(1) = 1 => 3xy (dy/dx) - 3y^2 = -x^2 => y (dy/dx) - y^2/x = -x/3 => 2y (dy/dx) - 2y^2/x = -2x/3 Let y^2 = t => 2y (dy/dx) = dt/dx => dt/dx - 2t/x = -2x/3 IF = 1/x^2 => y^2/x^2 = (-2/3) ln|x| + c x = 1, y = 1 => c = 1 => y^2 = (-2/3)x^2 ln|x| + c x = 1, y = 1, => c = 1 => y^2 = (-2/3)x^2 ln|x| + x^2 Now, x = e y^2 = (-2e^2/3) + e^2 = e^2/3 ∴ 6y^2 = 2e^2
