Resistance of a wire at 0°C, 100°C and t°C is found to be 10Ω, 10.2Ω and 10.95Ω respectively. The temperature t in Kelvin scale is ______.

Answer

Correct answer: 748

Solution

Using R = R₀(1 + αΔT), where ΔR/R₀ = αΔT. From 0°C to 100°C: (10.2 - 10)/10 = α(100 - 0), giving α = 0.2/100 = 0.002/°C. From 0°C to t°C: (10.95 - 10)/10 = α(t - 0), so 0.95/10 = 0.002 × t, giving t/100 = 0.95/0.2 = 4.75, thus t = 475°C. Converting to Kelvin: t = 475 + 273 = 748 K.
