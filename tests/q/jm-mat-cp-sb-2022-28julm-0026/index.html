For p, q in R, consider the real valued function f(x) = (x - p)^2 - q, x in R and q > 0. Let a1, a2, a3 and a4 be in an arithmetic progression with mean p and positive common difference. If |f(ai)| = 500 for all i = 1, 2, 3, 4, then the absolute difference between the roots of f(x) = 0 is

Answer

Correct answer: 50

Solution

Since a1, a2, a3, a4 are in A.P. with mean p and common difference d > 0: a1 = p - 3d, a2 = p - d, a3 = p + d, a4 = p + 3d. From |f(ai)| = 500: |9d^2 - q| = 500 and |d^2 - q| = 500. This gives either 9d^2 - q = d^2 - q (which gives d = 0, not acceptable) or 9d^2 - q = -(d^2 - q), which gives 5d^2 = q. The roots of f(x) = 0 are p + sqrt(q) and p - sqrt(q). Absolute difference between roots = |2*sqrt(q)| = 50.
