Given is a thin convex lens of glass (refractive index μ) and each side having radius of curvature R. One side is polished for complete reflection. At what distance from the lens, an object be placed on the optic axis so that the image gets formed on the object itself.

  1. (1) R/μ
  2. (2) R/(2μ-3)
  3. (3) μR
  4. (4) R/(2μ-1)

Answer

Correct answer: Option 4

Solution

P_eq = 2P_r + P_m 1/f_Q = 2/f_r - 1/f_m = 4(μ-1)/R - 2/(-R) = 1/R(4μ - 4 + 2) 1/f_eq = 1/R(4μ - 2) ⟹ 1/f_eq = -1/R(4μ - 2) f_eq = R/2 R = 2f_eq = -2(R/(4μ-2)) = -R/(2μ-1) For image to form on object itself, the object must be placed at the center of curvature of the equivalent mirror system, which gives the distance as R/(2μ-1).
