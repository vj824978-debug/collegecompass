Match the thermodynamic processes taking place in a system with the correct conditions. In the table: ΔQ is the heat supplied, ΔW is the work done and ΔU is change in internal energy of the system. Process (I) Adiabatic (II) Isothermal (III) Isochoric (IV) Isobaric Condition (A) ΔW = 0 (B) ΔQ = 0 (C) ΔU ≠ 0, ΔW ≠ 0, ΔQ ≠ 0 (D) ΔU = 0 Match the following: (1) (I)-(B), (II)-(A), (III)-(D), (IV)-(C) (2) (I)-(A), (II)-(A), (III)-(B), (IV)-(C) (3) (I)-(A), (II)-(B), (III)-(D), (IV)-(D) (4) (I)-(B), (II)-(D), (III)-(A), (IV)-(C)

  1. (1) (1) (I)-(B), (II)-(A), (III)-(D), (IV)-(C)
  2. (2) (2) (I)-(A), (II)-(A), (III)-(B), (IV)-(C)
  3. (3) (3) (I)-(A), (II)-(B), (III)-(D), (IV)-(D)
  4. (4) (4) (I)-(B), (II)-(D), (III)-(A), (IV)-(C)

Answer

Correct answer: Option 4

Solution

(I) Adiabatic process ⟹ ΔQ = 0 No exchange of heat takes place with surroundings (II) Isothermal process ⟹ Temperature remains constant (ΔT = 0) Δu = (F/2)nRΔT ⟹ ΔU = 0 No change in internal energy [ΔU = 0] (III) Isochoric process Volume remains constant ΔV = 0 W = ∫p.dV = 0 Hence work done is zero. (IV) Isobaric process ⟹ Pressure remains constant W = P.ΔV ≠ 0 Δu = (F/2)nRΔT = (F/2)[PΔV] ≠ 0 ΔQ = nCpΔT ≠ 0
