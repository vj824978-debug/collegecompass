Let 5 digit numbers be constructed using the digits 0, 2, 3, 4, 7, 9 with repetition allowed, and are arranged in ascending order with serial numbers. Then the serial number of the number 42923 is ___.

Answer

Correct answer: 2997

Solution

We need to find the serial number of 42923 when all 5-digit numbers formed from digits {0, 2, 3, 4, 7, 9} are arranged in ascending order. Available digits: 0, 2, 3, 4, 7, 9 (6 digits total) Numbers starting with 2: First digit = 2, remaining 4 digits can be any of 6 digits Count = 6^4 = 1296 Numbers starting with 3: First digit = 3, remaining 4 digits can be any of 6 digits Count = 6^4 = 1296 Numbers starting with 40: First digit = 4, second digit = 0, remaining 3 digits can be any of 6 digits Count = 6^3 = 216 Numbers starting with 42 and third digit < 9: - 420__: 6^2 = 36 numbers - 422__: 6^2 = 36 numbers - 423__: 6^2 = 36 numbers - 424__: 6^2 = 36 numbers - 427__: 6^2 = 36 numbers Total for 42 (up to third digit 7) = 5 × 6^2 = 5 × 36 = 180 Numbers starting with 429 and fourth digit < 2: - 4290_: 6 numbers Count = 6 Numbers starting with 4292 and fifth digit < 3: - 42920: 1 number - 42922: 1 number Count = 2 Number 42923: +1 Total serial number = 1296 + 1296 + 216 + 180 + 6 + 1 + 1 + 1 = 2997
