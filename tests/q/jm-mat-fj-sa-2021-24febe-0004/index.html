Let a, b ∈ R. If the mirror image of the point P(a, 6, 9) with respect to the line x/7 = y/5 = z/(-9) = (20, b, -a-9), then |a+b| is equal to:

  1. (1) 90
  2. (2) 86
  3. (3) 84
  4. (4) 88

Answer

Correct answer: Option 4

Solution

Using the mirror image formula for a point with respect to a line, we set up equations. From the parametric form of the line, the mirror image point P'(20, b, -a-9) satisfies: (a+20)/2 = 3+7r, (b+6)/2 = 2+5r, (-a-9+9)/2 = 1-9r. From these equations: a+20 = 6+14r (i), b+6 = 4+10r, b = -2+10r (ii), -a-9 = 2-18r, a = 18r-2 (iii). Solving (i) and (iii): 20+18r-2 = 6+14r, 4r = -12, r = -3. Therefore a = 14+14(-3) = -56 and b = -2-30 = -32. Thus |a+b| = |-56-32| = 88
