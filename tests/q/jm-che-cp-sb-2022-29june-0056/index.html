Spin only magnetic moment of [MnBr6]^4- is _____ B.M. [round off to the closest integer]

Answer

Correct answer: 6

Solution

[MnBr6]^4- has Mn in +2 oxidation state with configuration 3d^5 4s^0. With 5 unpaired electrons (n=5), the spin only magnetic moment is calculated using μ = sqrt(n(n+2)) = sqrt(5(5+2)) = sqrt(35) ≈ 5.92 ≈ 6 B.M.
