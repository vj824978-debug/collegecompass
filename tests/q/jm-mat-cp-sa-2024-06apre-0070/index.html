If the function f(x) = (1/x)^x ; x > 0 attains the maximum value at x = 1/e then:

  1. (1) e^e < π^e
  2. (2) e^(2π) < (2π)^e
  3. (3) e^π > π^e
  4. (4) (2e)^π > π^(2e)

Answer

Correct answer: Option 3

Solution

Let y = (1/x)^(2x). Taking logarithm: ln(y) = 2x·ln(1/x) = -2x·ln(x). Differentiating: (1/y)·(dy/dx) = -2(1 + ln(x)). For maximum, dy/dx = 0, which gives x = 1/e. For x > 1/e, f'(x) < 0, so f is decreasing. Since e < π and f is decreasing for x > 1/e: (1/e)^(2e) > (1/π)^(2π), which gives e^π > π^e.
