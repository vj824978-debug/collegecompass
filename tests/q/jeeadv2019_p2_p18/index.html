If the process on one mole of monatomic ideal gas is as shown in the TV-diagram with P₀V₀ = (1/3)RT₀, the correct match is, [TV-diagram showing: State 1 at (V₀, T₀/3), State 2 at (2V₀, T₀/3), State 3 at (2V₀, T₀)]

Matrix match · Marks: +4 / -1.0

Passage:

  1. (A) I → P, II → T, III → Q, IV → T
  2. (B) I → S, II → T, III → Q, IV → U
  3. (C) I → P, II → R, III → T, IV → S
  4. (D) I → P, II → R, III → T, IV → P

Answer

Correct answer: D

Solution

Sol. W₁→₂→₃ = W₁→₂ + W₂→₃ = R(T₀/3)ln(2V₀/V₀) + 0 = RT₀/3 ln 2 ΔU₁→₂→₃ = ΔU₁→₂ + ΔU₂→₃ = 0 + nCᵥ(T₀ - T₀/3) = 0 + 1 × (3R/2) × (2T₀/3) = RT₀ ΔQ₁→₂ = ∫Tdx = ∫(3R/2T dT + R/2 dV) = 3R/2 ∫dT + ∫(RT/V)dV = 0 + RT ln 2 ΔQ₂→₃ = ∫Tdx = (3R/2)∫[T₀ to T₀/3] dT + ∫(RT/V)dV = (3R/2) × (2T₀/3) + 0 = RT₀ ΔQ₁→₂→₃ = RT ln 2 + RT₀ - 1/3 RT₀(3 + ln 2)
