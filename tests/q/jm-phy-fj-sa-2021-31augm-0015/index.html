A sample of a radioactive nucleus A disintegrates to another radioactive nucleus B, which in turn disintegrates to some other stable nucleus C. Plot of a graph showing the variation of number of atoms of nucleus B versus time is: (Assume that at t = 0, there are no B atoms in the sample)

  1. (1) Graph (A) showing a flat horizontal line after initial rise
  2. (2) Graph (B) showing a single peak that rises to maximum then stays constant
  3. (3) Graph (C) showing a rise to peak then exponential decay
  4. (4) Graph (D) showing only exponential decay from start

Answer

Correct answer: Option 2

Solution

For sequential radioactive decay A → B → C, nucleus B is produced from A decay and simultaneously decays to C. The number of B atoms follows: N_B = K(e^(-λ_A*t) - e^(-λ_B*t)) where K = (λ_A*N_{A0})/(λ_B - λ_A). At t=0, N_B=0. N_B increases as B is produced from A decay. N_B reaches maximum when d(N_B)/dt = 0, then decreases exponentially as B decays to C faster than it is produced from A. This produces a bell curve (rise to peak then decay). The answer is Graph (C).
