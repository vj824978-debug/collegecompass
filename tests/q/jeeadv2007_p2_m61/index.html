Which one of the following statements is correct?

Comprehension · Marks: +4 / -1.0

Passage:

  1. (A) G₁ > G₂ > G₃ > …
  2. (B) G₁ < G₂ < G₃ < …
  3. (C) G₁ = G₂ = G₃ = …
  4. (D) G₁ < G₃ < G₅ < … and G₂ > G₄ > G₆ > …

Answer

Correct answer: C

Solution

Sol. (C) A₁ = (a + b)/2, G₁ = √(ab), H₁ = 2ab/(a + b) Aₙ = (Aₙ₋₁ + Hₙ₋₁)/2, Gₙ = √(Aₙ₋₁Hₙ₋₁), Hₙ = 2Aₙ₋₁Hₙ₋₁/(Aₙ₋₁ + Hₙ₋₁) Clearly, G₁ = G₂ = G₃ = ... = √(ab)
