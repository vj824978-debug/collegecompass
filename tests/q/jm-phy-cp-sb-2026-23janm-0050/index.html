The space between the plates of a parallel-plate capacitor of capacitance C (without any dielectric) is now filled with three dielectric slabs of dielectric constants K_1 = 2, K_2 = 3, and K_3 = 5 (as shown in the figure). If new capacitance is (n/3)C then the value of n is ____.

Answer

Correct answer: 8

Solution

From the figure, the three dielectric slabs are arranged in parallel with the following configuration: - K_1 = 2 occupies width A/2 and thickness d/2 - K_2 = 3 occupies width A/2 and thickness d/2 - K_3 = 5 occupies width A/2 and thickness d/2 For the slab with K_1 = 2 and dimensions A/2 × d/2: C_1 = (epsilon_0 K_1 A/2)/(d/2) = (epsilon_0 × 2 × A)/(d) = 5C For the slab with K_2 = 3 and dimensions A/2 × d/2: C_2 = (epsilon_0 K_2 A/2)/(d/2) = (epsilon_0 × 2 × 3 × A)/(d) = 2C C_1 & C_2 are in series: C' = (C_1 × C_2)/(C_1 + C_2) = ((5C)(2C))/(7C) = (10C)/7 For the slab with K_3 = 5 and dimensions A/2 × d/2: C_3 = (epsilon_0 K_3 A/2)/(d/2) = (epsilon_0 × 3 × A)/(d) = 3C For the slab with K_4 = 2 and dimensions A/2 × d/2: C_4 = (epsilon_0 × 2 × A)/(d) = 2C C_4 & C_3 are in series: C'' = ((2C)(3C))/(5C) = (6C)/5 C' & C'' are in parallel: C_eq = C' + C'' = C((6/5) + (10/7)) = C((42 + 50)/35) = C(92/35) Since C_eq = (nC)/3: (92/35)C = (nC)/3 n = (92 × 3)/35 = 276/35 = 7.9 ≈ n = 8
