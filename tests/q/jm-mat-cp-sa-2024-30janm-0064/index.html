If the domain of the function f(x) = cos^(-1)((2-|x|)/4) + {log_x(3-x)}^(-1) is [-α, β) - {γ}, then α + β + γ is equal to

  1. (1) 8
  2. (2) 12
  3. (3) 9
  4. (4) 11

Answer

Correct answer: Option 4

Solution

For cos^(-1)((2-|x|)/4): -1 ≤ (2-|x|)/4 ≤ 1 gives |x| ≤ 6, so x ∈ [-6, 6]. For log_x(3-x) to be defined: x > 0, x ≠ 1, and 3-x > 0, so x < 3. Combined with domain restriction x ∈ [-6, 6), we get x ∈ [-6, 3) - {2} (excluding x=2 where 3-x=1). Therefore α = 6, β = 3, γ = 2. Thus α + β + γ = 6 + 3 + 2 = 11.
