For a given reaction R → P, t1/2 is related to [A]0 as given in table: [A]0 | t1/2 0.100 | 200 0.025 | 100 Given: log 2 = 0.30 Which of the following is true? A. The order of the reaction is 1/2 B. If [A]0 is 1M, then t1/2 is 200√10 min C. The order of the reaction changes to 1 if the concentration of reactant changes from 0.100 M to 0.500 M. D. t1/2 is 800 min for [A]0 = 1.6 M Choose the correct answer from the options given below:

  1. (1) A and C only
  2. (2) A and B only
  3. (3) A, B and D only
  4. (4) C and D only

Answer

Correct answer: Option 3

Solution

t1/2 ∝ 1/A0^(n-1) (t1/2)1 / (t1/2)2 = (A0)2^(n-1) / (A0)1^(n-1) 200/100 = (0.025/0.100)^(n-1) 2 = (1/4)^(n-1) 2 = (1/4)^(n-1) n - 1 = -1/2 n = 1/2 (order) ⟹ t1/2 ∝ √A0 When A0 = 1M: 200/t1/2 = (0.1)^(1/2) / (1)^(1/2) t1/2 = 200√10 min When A0 = 1.6 M: 200/t1/2 = (0.1)^(1/2) / (1.6)^(1/2) t1/2 = 800 min A is TRUE: The order of the reaction is 1/2 B is TRUE: If [A]0 is 1M, then t1/2 is 200√10 min C is FALSE: For a given reaction, the order does not change with concentration. First order kinetics have t1/2 independent of their concentration. So upon changing the concentration t1/2 should not change for first order reaction. D is TRUE: t1/2 is 800 min for [A]0 = 1.6 M
