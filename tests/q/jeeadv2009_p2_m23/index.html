If the sum of first n terms of an A.P. is cn², then the sum of squares of these n terms is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) n(4n² - 1)c² / 6
  2. (B) n(4n² + 1)c² / 3
  3. (C) n(4n² - 1)c² / 3
  4. (D) n(4n² + 1)c² / 6

Answer

Correct answer: C

Solution

Sol. (C) t_n = c{n² - (n-1)²} = c(2n - 1) ⟹ t_n² = c²(4n² - 4n + 1) ⟹ ∑(n=1 to n) t_n² = c²{4n(n+1)(2n+1)/6 - 4n(n+1)/2 + n} = (c²n/6){4(n+1)(2n+1) - 12(n+1) + 6} = (c²n/3){4n² + 6n + 2 - 6n - 6 + 3} = (c²n/3)(4n² - 1)
