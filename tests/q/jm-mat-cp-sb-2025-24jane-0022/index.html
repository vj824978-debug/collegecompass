Let P be the image of the point Q(7, -2, 5) in the line L: (x-1)/2 = (y+1)/3 = z/4 and R(5, p, q) be a point on L. Then the square of the area of triangle PQR is ____

Answer

Correct answer: 1957

Solution

The line L can be written parametrically as: (x, y, z) = (1, -1, 0) + lambda(2, 3, 4) = (2lambda + 1, 3lambda - 1, 4lambda) Let R(2lambda + 1, 3lambda - 1, 4lambda) be a point on L. Given R(5, p, q) is on L: 2lambda + 1 = 5 lambda = 2 So R(5, 5, 8) To find P (the image of Q in line L), we need the foot of perpendicular from Q to L. Let T(2lambda + 1, 3lambda - 1, 4lambda) be the foot of perpendicular from Q(7, -2, 5) to L. vector QT = (2lambda + 1 - 7, 3lambda - 1 - (-2), 4lambda - 5) = (2lambda - 6, 3lambda + 1, 4lambda - 5) vector b = (2, 3, 4) (direction vector of L) For perpendicularity: vector QT · vector b = 0 (2lambda - 6)(2) + (3lambda + 1)(3) + (4lambda - 5)(4) = 0 4lambda - 12 + 9lambda + 3 + 16lambda - 20 = 0 29lambda - 29 = 0 lambda = 1 T(3, 2, 4) P is the image of Q in line L, so T is the midpoint of QP: P = 2T - Q = 2(3, 2, 4) - (7, -2, 5) = (6, 4, 8) - (7, -2, 5) = (-1, 6, 3) Now for triangle PQR: vector PQ = (7 - (-1), -2 - 6, 5 - 3) = (8, -8, 2) vector PR = (5 - (-1), 5 - 6, 8 - 3) = (6, -1, 5) vector PQ × vector PR = |i j k| |8 -8 2| |6 -1 5| = i(-8·5 - 2·(-1)) - j(8·5 - 2·6) + k(8·(-1) - (-8)·6) = i(-40 + 2) - j(40 - 12) + k(-8 + 48) = i(-38) - j(28) + k(40) = (-38, -28, 40) |vector PQ × vector PR| = sqrt(38^2 + 28^2 + 40^2) = sqrt(1444 + 784 + 1600) = sqrt(3828) = 2sqrt(957) = 2·sqrt(957) Area of triangle PQR = (1/2)|vector PQ × vector PR| = (1/2)·2sqrt(957) = sqrt(957) (Area)^2 = 957
