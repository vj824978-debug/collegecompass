An object is placed beyond the centre of curvature C of the given concave mirror. If the distance of the object is d_i from C and the distance of the image formed is d_s from C, the radius of curvature of this mirror is:

  1. (1) 2d_i*d_s/(d_i + d_s)
  2. (2) d_i*d_s/(d_i + d_s)
  3. (3) 2d_i*d_s/(d_i - d_s)
  4. (4) d_i*d_s/(d_i - d_s)

Answer

Correct answer: Option 3

Solution

Using Newton's formula: (f + d_i)(f - d_s) = f^2, which simplifies to f = (d_i*d_s)/(d_i - d_s). Since R = 2f, therefore R = 2d_i*d_s/(d_i - d_s)
