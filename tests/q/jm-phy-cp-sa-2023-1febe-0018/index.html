As shown in the figure a block of mass 10 kg lying on a horizontal surface is pulled by a force F acting at an angle 30°, with horizontal. For μ_s = 0.25, the block will just start to move for the value of F : [Given g = 10 ms^(-2)]

  1. (1) 25.2 N
  2. (2) 33.3 N
  3. (3) 20 N
  4. (4) 35.7 N

Answer

Correct answer: Option 1

Solution

Given: m = 10 kg μ_s = 0.25 g = 10 ms^(-2) Force F is applied at angle 30° with horizontal For the block to just start moving, the applied horizontal force must equal the maximum static friction force. Vertical direction (equilibrium): N + F sin(30°) = mg N = mg - F sin(30°) N = (10 × 10) - F sin(30°) N = 100 - F/2 Horizontal direction (at limiting friction): F cos(30°) = μ_s × N F cos(30°) = 0.25(100 - F/2) Substituting cos(30°) = √3/2: (√3/2)F = 0.25(100 - F/2) (√3/2)F = 25 - F/8 (√3/2)F + F/8 = 25 F(√3/2 + 1/8) = 25 F((4√3 + 1)/8) = 25 F = (25 × 8)/(4√3 + 1) F = 200/(4√3 + 1) Rationalizing: F = 200(4√3 - 1)/((4√3 + 1)(4√3 - 1)) F = 200(4√3 - 1)/(48 - 1) F = 200(4√3 - 1)/47 With √3 ≈ 1.732: F ≈ 200(6.928 - 1)/47 F ≈ 200(5.928)/47 F ≈ 1185.6/47 F ≈ 25.22 N ≈ 25.2 N
