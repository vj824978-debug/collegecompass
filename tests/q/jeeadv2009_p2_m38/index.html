Let (x, y, z) be points with integer coordinates satisfying the system of homogeneous equations: 3x - y - z = 0 -3x + z = 0 -3x + 2y + z = 0. Then the number of such points for which x² + y² + z² ≤ 100 is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 7

Solution

Sol. 7 3x - y - z = 0 -3x + z = 0 ⟹ y = 0 and z = 3x ⟹ x² + y² + z² = x² + z² = x² + 9x² = 10x² ≤ 100 ⟹ x² ≤ 10 ⟹ x = 0, ±1, ±2, ±3 There are such seven points.
