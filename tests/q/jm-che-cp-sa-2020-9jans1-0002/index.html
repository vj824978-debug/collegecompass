The correct order of the spin-only magnetic moments of the following complexes is: (I) [Cr(H2O)6]Br2 (II) Na4[Fe(CN)6] (III) Na3[Fe(C2O4)3](Δ0 > P) (IV) (Et4N)2[CoCl4]

  1. (1) (I) > (IV) > (III) > (II)
  2. (2) (II) ≈ (I) > (IV) > (III)
  3. (3) (III) > (I) > (IV) > (II)
  4. (4) (III) > (I) > (II) > (IV)

Answer

Correct answer: Option 1

Solution

[Cr(H2O)6]Br2 : Cr^(2+) = [Ar] 4s^0 3d^4 t2g^3 eg^1 n = 4, μ = sqrt(n(n+2)) = sqrt(24) BM Na4[Fe(CN)6] : Fe^(2+) = [Ar] 4s^0 3d^6 t2g^6 eg^0 n = 0, μ = 0 Na3[Fe(C2O4)3] : Fe^(3+) = [Ar] 3d^5 t2g^5 eg^0 n = 1, μ = sqrt(3) BM (Et4N)2[CoCl4] : Co^(2+) = [Ar] 3d^7 e_g^3 t2g^3 n = 3, μ = sqrt(15) BM Order of magnetic moments: sqrt(24) > sqrt(15) > sqrt(3) > 0 (I) > (IV) > (III) > (II)
