Let f(x) = 2x + tan^(-1)(x) and g(x) = log_2(sqrt(1 + x^2 + x)), x ∈ [0, 3]. Then

  1. (1) min f(x) = 1 + max g'(x)
  2. (2) there exist 0 < x_1 < x_2 < 3 such that f(x) < g(x), ∀ x ∈ (x_1, x_2)
  3. (3) there exists x̄ ∈ [0, 3] such that f'(x̄) < g'(x̄)
  4. (4) max f(x) > max g(x)

Answer

Correct answer: Option 4

Solution

f(x) = 2x + tan^(-1)(x) and g(x) = log_2(sqrt(1 + x^2 + x)), x ∈ [0, 3] Finding derivatives: f'(x) = 2 + 1/(1 + x^2), g'(x) = 1/sqrt(x^2 + 1) f'(x) = 2 + 1/(1 + x^2) g'(x) = d/dx[log_2(sqrt(1 + x^2 + x))] = 1/sqrt(x^2 + 1) Analyzing f(x): Since f'(x) = 2 + 1/(1 + x^2) > 0 for all x, f(x) is strictly increasing on [0, 3] f(x)|_min = f(0) = 0 + tan^(-1)(0) = 0 f(x)|_max = f(3) = 6 + tan^(-1)(3) Analyzing g(x): g'(x) = 1/sqrt(x^2 + 1) < 0 can be checked: Actually g'(x) = (2x + 1)/(2sqrt(1 + x^2 + x)·ln(2)) More carefully: g(x) = log_2(sqrt(1 + x^2 + x)) = (1/2)log_2(1 + x^2 + x) g'(x) = (1/2) · 1/(ln(2)) · (2x + 1)/(1 + x^2 + x) = (2x + 1)/(2(1 + x^2 + x)ln(2)) At x = 0: g(0) = log_2(1) = 0, g'(0) = 1/(2ln(2)) At x = 3: g(3) = log_2(sqrt(10 + 3)) = log_2(sqrt(13)) = (1/2)log_2(13), and log_2(13) < log_2(16) = 4, so g(3) < 2 Also g(3) = log_2(sqrt(13)) ≈ log_2(3.6) ≈ 1.85 f(3) = 6 + tan^(-1)(3) ≈ 6 + 1.249 ≈ 7.249 Checking each option: (1) min f(x) = 0, max g'(x) = g'(0) = 1/(2ln(2)) ≈ 0.72, so 0 ≠ 1 + 0.72. FALSE (2) f and g both start at 0, but f grows much faster. Need to check if they cross twice. FALSE (3) f'(x) = 2 + 1/(1 + x^2) ≥ 2.5, while g'(x) = (2x + 1)/(2(1 + x^2 + x)ln(2)) at x = 0 gives 1/(2ln(2)) ≈ 0.72. So f'(x) > g'(x) for all x ∈ [0, 3]. FALSE (4) max f(x) = f(3) = 6 + tan^(-1)(3) ≈ 7.249, max g(x) = g(3) ≈ 1.85. Since 7.249 > 1.85, this is TRUE.
