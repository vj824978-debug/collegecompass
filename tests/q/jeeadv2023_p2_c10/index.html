Consider the following molecules: Br₃O₈, F₂O, H₂S₂O₆, H₂S₂O₆, and C₃O₂. Count the number of atoms existing in their zero oxidation state in each molecule. Their sum is____.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 06

Solution

[Chemical structures showing:] (i) [Br-O structure with three Br atoms bonded to O atoms in a linear arrangement] O=Br-Br=Br=O with additional O atoms above and below each Br (ii) [Oxygen atom bonded to two fluorine atoms] F-O-F (iii) [Sulfur chain structure] HO-S-S-S-OH with double bonded O atoms above each S ║ ║ O O (iv) [Sulfur chain structure] HO-S-S-S-S-OH with double bonded O atoms above first and last S ║ ║ O O (v) [Linear structure] O=C=C=C=O Total number of atoms having zero oxidation state = 6
