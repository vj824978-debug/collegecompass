Let H₁, H₂, ..., Hₙ be mutually exclusive and exhaustive events with P(Hᵢ) > 0, i = 1, 2, ..., n. Let E be any other event with 0 < P(E) < 1. STATEMENT -1: P(Hᵢ | E) > P(E | Hᵢ) · P(Hᵢ) for i = 1, 2, ..., n because STATEMENT -2: ∑ᵢ₌₁ⁿ P(Hᵢ) = 1

Assertion–Reason · Marks: +3 / -1.0

  1. (A) Statement -1 is True, Statement -2 is True; Statement-2 is a correct explanation for Statement-1
  2. (B) Statement -1 is True, Statement -2 is True; Statement-2 is NOT a correct explanation for Statement-1
  3. (C) Statement -1 is True, Statement -2 is False
  4. (D) Statement -1 is False, Statement -2 is True

Answer

Correct answer: D

Solution

Sol. Statement : 1 If P(H_i ∩ E) = 0 for some i, then P(H_i/E) = P(E/H_i) = 0 If P(H_i ∩ E) ≠ 0 for ∀ i = 1, 2 ... n, then P(H_i/E) = P(H_i ∩ E)/P(H_i) × P(H_i)/P(E) = P(E/H_i) × P(H_i)/P(E) > P(E/H_i) · P(H_i) [as 0 < P(E) < 1] Hence statement 1 may not always be true. Statement : 2 Clearly H_1 ∪ H_2 ... ∪H_n = S (sample space) ⇒ P(H_1) + P(H_2) + ... + P(H_n) = 1.
