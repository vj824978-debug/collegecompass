Equivalent resistance between the adjacent corners of a regular n-sided polygon of uniform wire of resistance R would be

  1. (1) (n-1)R/(2n-1)
  2. (2) (n-1)R/(n^2)
  3. (3) (n-1)R/n
  4. (4) n^2*R/(n-1)

Answer

Correct answer: Option 2

Solution

Consider a regular n-sided polygon with uniform wire of resistance R. When we need to find equivalent resistance between two adjacent corners A and B: From A to B, current can flow through two paths: 1. Direct path: resistance = R/n (one side of n sides) 2. Through remaining (n-1) sides: resistance = R(n-1)/n These two paths are in parallel between points A and B. Using parallel resistance formula: 1/R_eq = n/R + n/(R(n-1)) = n/R + n/(R(n-1)) = (n(n-1) + n^2)/(R*n(n-1)) = (n^2 - n + n^2)/(R*n(n-1)) = (2n^2 - n)/(R*n(n-1)) = n(2n-1)/(R*n(n-1)) = (2n-1)/(R(n-1)) Alternatively: 1/R_eq = 1/(R/n) + 1/(R(n-1)/n) = n/R + n/(R(n-1)) = n/R[1 + 1/(n-1)] = (n/R)[(n-1+1)/(n-1)] = n^2/(R(n-1)) Therefore: R_eq = R(n-1)/n^2
