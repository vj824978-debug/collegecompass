The number of real solution(s) of the equation x^2 + 3x + 2 = min{|x - 3|, |x + 2|} is :

  1. (1) 2
  2. (2) 0
  3. (3) 3
  4. (4) 1

Answer

Correct answer: Option 1

Solution

We need to find the number of real solutions to x^2 + 3x + 2 = min{|x - 3|, |x + 2|}. First, let's analyze min{|x - 3|, |x + 2|}: - |x - 3| = x - 3 when x >= 3, and 3 - x when x < 3 - |x + 2| = x + 2 when x >= -2, and -x - 2 when x < -2 The minimum of these two absolute values changes at x = -2 and x = 3. For x < -2: min{3 - x, -x - 2} = -x - 2 For -2 <= x < 3: min{3 - x, x + 2} = 3 - x (since 3 - x >= x + 2 when x <= 1/2) For x >= 3: min{x - 3, x + 2} = x - 3 Actually, at x = 1/2: |x - 3| = 5/2 and |x + 2| = 5/2, so they are equal. The equation becomes: 1. For x < -2: x^2 + 3x + 2 = -x - 2, so x^2 + 4x + 4 = 0, (x + 2)^2 = 0, x = -2 (boundary, not in this region) 2. For -2 <= x <= 1/2: x^2 + 3x + 2 = 3 - x, so x^2 + 4x - 1 = 0, x = (-4 ± sqrt(16 + 4))/2 = (-4 ± sqrt(20))/2 = -2 ± sqrt(5). Only x = -2 + sqrt(5) ≈ 0.236 is in [-2, 1/2] 3. For 1/2 < x < 3: x^2 + 3x + 2 = 3 - x, so x^2 + 4x - 1 = 0, gives x = -2 + sqrt(5) ≈ 0.236 (already found) and x = -2 - sqrt(5) ≈ -4.236 (not in this interval) 4. For x >= 3: x^2 + 3x + 2 = x - 3, so x^2 + 2x + 5 = 0. Discriminant = 4 - 20 = -16 < 0, no real solutions. Verification shows that only x = -2 + sqrt(5) is a valid solution. Therefore, there is only 1 real solution.
