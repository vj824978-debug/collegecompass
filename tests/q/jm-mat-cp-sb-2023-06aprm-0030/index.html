Let the point (p, p + 1) lie inside the region E = {(x,y): 3 - x ≤ y ≤ sqrt(9 - x^2), 0 ≤ x ≤ 3}. If the set of all values of p is the interval (a, b), then b^2 + b - a^2 is equal to ______.

Answer

Correct answer: 3

Solution

The point (p, p+1) must satisfy: 3 - p ≤ p + 1 ≤ sqrt(9 - p^2) and 0 ≤ p ≤ 3. From 3 - p ≤ p + 1, we get p ≥ 1. From (p+1)^2 ≤ 9 - p^2, we get p^2 + 2p + 1 ≤ 9 - p^2, which gives 2p^2 + 2p - 8 = 0 or p^2 + p - 4 = 0. Using quadratic formula: p = (-1 + sqrt(17))/2. So p ∈ (1, (-1 + sqrt(17))/2). Thus a = 1, b = (-1 + sqrt(17))/2. From p^2 + p - 4 = 0, we have b^2 + b = 4. Therefore b^2 + b - a^2 = 4 - 1 = 3.
