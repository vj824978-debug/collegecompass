P(α, β, γ) is the foot of perpendicular from (3,2,1) on L, then the value of 21(α + β + γ) equals:

  1. (1) 102
  2. (2) 142
  3. (3) 136
  4. (4) 68

Answer

Correct answer: Option 2

Solution

For x > 0, if f(x) = ∫[log_x(1/(1+t))] dt, then f(e) + f(1/e) is equal to 1/2. Given f(x) = ∫[log_x/(1+t)] dt. Using substitution t = 1/z, dt = -1/z^2 dz, we get f(1/x) = ∫[log_z/(z(1+z))] dz. Combining f(x) + f(1/x) = ∫[(log_t(1+t))/(t(1+t))] dt - ∫[log_t/t] dt = [(log_t)^2/2] - [(log_x)^2/2]. Hence f(e) + f(1/e) = 1/2.
