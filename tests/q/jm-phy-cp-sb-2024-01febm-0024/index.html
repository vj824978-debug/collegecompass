A particle is moving in one dimension (along x-axis) under the action of a variable force. It's initial position was 16 m right of origin. The variation of its position (x) with time (t) is given as x = -3t^3 + 18t^2 + 16t, where x is in m and t is in s. The velocity of the particle when its acceleration becomes zero is ______ m/s.

Answer

Correct answer: 52

Solution

Given x = -3t^3 + 18t^2 + 16t. First find velocity by differentiating: v = dx/dt = -9t^2 + 36t + 16. Then find acceleration: a = dv/dt = -18t + 36. Set acceleration to zero: -18t + 36 = 0, which gives t = 2 sec. Substitute t = 2 in velocity equation: v(t=2) = -9(2)^2 + 36(2) + 16 = -36 + 72 + 16 = 52 m/s.
