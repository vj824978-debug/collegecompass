Let P = [2 0 α; 3 -5 0], where α ∈ ℝ. Suppose Q = [q_ij] is a matrix such that PQ = kI, where k ∈ ℝ, k ≠ 0 and I is the identity matrix of order 3. If q_23 = -k/8 and det(Q) = k^2/2, then

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) α = 0, k = 8
  2. (B) 4α - k + 8 = 0
  3. (C) det(P adj(Q)) = 2^9
  4. (D) det(Q adj(P)) = 2^13

Answer

Correct answer: BC

Solution

Sol. (B, C) P(Q/k) = 1 P⁻¹ = (Q/k) (P⁻¹)₂₃ = q₂₃/k = 1/8 (3α + 4)/(20 + 12α) = 1/8, α = -1 ⟹ det(P) = 20 + 12α = 8 (det P) · det(Q/k) = 1 8 det(Q)/k³ = 1 ⟹ |Q| = k³/8 ⟹ k³/8 = k²/2 ⟹ k = 4 ⟹ det(Q) = 8 det(P·adj Q) = det P · det adj Q = det P(det Q)² = 8 × 8² = 2⁹ det Q · adj P = det Q(det P)² = 8 × 8² = 2⁹ Alternate |P||Q| = k³ ⟹ |P| = 2k ⟹ 6α + 10 = k ..... (1) Also PQ = kI |P|Q = k adj(P) 2kQ = k adj(P) Comparing q₂₃ we get k/4 = -3α - 4 ..... (2) Solving (1) and (2) we get α = -1 and k = 4
