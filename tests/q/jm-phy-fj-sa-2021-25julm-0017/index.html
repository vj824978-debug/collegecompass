A parallel plate capacitor with plate area 'A' and distance of separation 'd' is filled with a dielectric. What is the capacitance of the capacitor when permittivity of the dielectric varies as: ε(x) = ε₀ + kx for (0 ≤ x ≤ d/2) and ε(x) = ε₀ + k(d-x) for (d/2 ≤ x ≤ d)?

  1. (1) 0
  2. (2) (kA/2)ln(2ε₀/(2ε₀-kd))
  3. (3) (kA/(2ln))((2ε₀+kd)/(2ε₀))
  4. (4) (ε₀+kd/2)^(A/kA)

Answer

Correct answer: Option 3

Solution

For 0 < x ≤ d/2: dC₁ = (ε₀+kx)A/dx. Integrating: 1/C₁ = (1/(kA))ln(1+kd/(2ε₀)). For d/2 < x ≤ d: dC₂ = (ε₀+k(d-x))A/dx. Integrating: 1/C₂ = (1/(kA))ln(1+kd/(2ε₀)). Since C₁ = C₂ = C, the capacitors in series give: C_total/(C₁+C₂) = C/2 = (kA/(2ln))((2ε₀+kd)/(2ε₀))
