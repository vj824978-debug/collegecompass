Use the following data: Substance AB(g) has ΔfH° (500 K) = 32 kJmol⁻¹ and S° (500 K) = 222 JK⁻¹ mol⁻¹. Substance A₂(g) has ΔfH° (500 K) = 6 kJmol⁻¹ and S° (500 K) = 146 JK⁻¹ mol⁻¹. Substance B₂(g) has ΔfH° (500 K) = x kJmol⁻¹ and S° (500 K) = 280 JK⁻¹ mol⁻¹. One mole each of A₂(g) and B₂(g) are taken in a 1L closed flask and allowed to establish the equilibrium at 500 K. A₂(g) + B₂(g) ⇌ 2AB(g). The value of x (in kJ mol⁻¹) is ____ (Nearest integer). Given: log K = 2.2, R = 8.3JK⁻¹ mol⁻¹

Answer

Correct answer: 70

Solution

For the reaction A₂(g) + B₂(g) ⇌ 2AB(g): ΔH° = (2×32) - (6+x) = (58-x) kJ. ΔS° = (2×222) - (146+280) = 18 J. Using ΔG° = -RT ln K: ΔG° = -8.314×500×2.2×2.303/1000 = -21.06 kJ. From ΔH° - TΔS° = ΔG°: 58 - x - 500(18/1000) = -21.06. Solving: x = 70.06 ≈ 70 kJ/mol
