Four combinations of two thin lenses are given in List I. The radius of curvature of all curved surfaces is r and the refractive index of all the lenses is 1.5. Match lens combinations in List I with their focal length in List II and select the correct answer using the code given below the lists. List I P. [Two convex lenses in contact] Q. [Two convex lenses separated] R. [One convex lens and one concave lens in contact] S. [One convex lens on left, one concave lens on right, separated] List II 1. 2r 2. r/2 3. −r 4. r

Matrix match · Marks: +4 / -1.0

  1. (A) (A) P-1, Q-2, R-3, S-4
  2. (B) (B) P-2, Q-4, R-3, S-1
  3. (C) (C) P-4, Q-1, R-2, S-3
  4. (D) (D) P-2, Q-1, R-3, S-4

Answer

Correct answer: B

Solution

1/f = (μ-1)(1/R₁ - 1/R₂) [Three lens diagrams shown: convex lens labeled f=R, convex lens labeled f=2R, and concave lens labeled f=-2R] Use 1/f_eq = 1/f₁ + 1/f₂ (P) 1/f_eq = 1/R + 1/R = 2/R; f_eq = R/2 (Q) 1/f_eq = 1/2R + 1/2R = 1/R; f_eq = R (R) 1/f_eq = -1/2R - 1/2R = -1/R; f_eq = -R (S) 1/f_eq = 1/R - 1/2R = 1/2R; f_eq = 2R
