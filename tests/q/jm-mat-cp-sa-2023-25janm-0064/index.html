Consider the lines L1 and L2 given by L1: (x-1)/2 = (y-3)/1 = (z-2)/2 L2: (x-2)/1 = (y-2)/2 = (z-3)/3 A line L having direction ratios 1, -1, -2, intersects L1 and L2 at the points P and Q respectively. Then the length of line segment PQ is

  1. (1) 3*sqrt(2)
  2. (2) 2*sqrt(6)
  3. (3) 4*sqrt(3)
  4. (4) 4

Answer

Correct answer: Option 2

Solution

Let P ≡ (2λ + 1, λ + 3, 2λ + 2) and Q ≡ (μ + 2, 2μ + 2, 3μ + 3) d.r's of PQ = <2λ - μ - 1, λ - 2μ + 1, 2λ - 3μ - 1> Since PQ has direction ratios 1, -1, -2: (2λ - μ - 1)/1 = (λ - 2μ + 1)/(-1) = (2λ - 3μ - 1)/(-2) ∴ -2λ + μ + 1 = λ - 2μ + 1 and -2λ + 4μ - 2 = -2λ + 3μ + 1 ⟹ 3λ - 3μ = 0 and μ = 3 ∴ λ = ±3 and μ = 3 ∴ P = (7, 6, 8) and Q = (5, 8, 12) ∴ |PQ| = sqrt(2^2 + 2^2 + 4^2) = sqrt(24) = 2*sqrt(6)
