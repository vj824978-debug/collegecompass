The position vectors of two 1 kg particles, (A) and (B), are given by vector r_A = (alpha_1*t^2*i + alpha_2*t*j + alpha_3*t*k) m and vector r_B = (beta_1*t*i + beta_2*t^2*j + beta_3*t*k) m, respectively (alpha_1 = 1 m/s^2, alpha_2 = 3n m/s, alpha_3 = 2 m/s, beta_1 = 2 m/s, beta_2 = -1 m/s^2, beta_3 = 4p m/s), where t is time, n and p are constants. At t = 1 s, |vector V_A| = |vector V_B| and velocities vector V_A and vector V_B of the particles are orthogonal to each other. At t = 1 s, the magnitude of angular momentum of particle (A) with respect to the position of particle (B) is sqrt(L) kg*m^2*s^(-1). The value of L is ____.

Answer

Correct answer: 90

Solution

vector V_A = (2*i + 3n*j + 2*k) vector V_B = (2*i - 2t*j + 4p*k) Vector V_A · Vector V_B = 0 4 - 6n + 8p = 0 2 - 3n + 4p = 0 3n = 2 + 4p |vector V_A| = |vector V_B| 4 + 9n^2 + 4 = 4 + 4 + 16p^2 p = -1/4 => n = 1/3 vector L = m_A * (vector r_A/B × vector V_A) vector r_A/B = (alpha_1 - beta_1)*i + (alpha_2 - beta_2)*j + (alpha_3 - beta_3)*k = (1 - 2)*i + (1 + 1)*j + 3*k = -1*i + 2*j + 3*k | i j k | | -1 2 3 | = i + 8j - 5k | 2 1 2 | = sqrt(1 + 64 + 25) = sqrt(90)
