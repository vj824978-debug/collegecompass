Three circles of radii a, b, c (a < b < c) touch each other externally. If they have x-axis as a common tangent, then:

  1. (1) 1/sqrt(b) = 1/sqrt(a) + 1/sqrt(c)
  2. (2) a, b, c are in A.P.
  3. (3) sqrt(a), sqrt(b), sqrt(c) are in A.P.
  4. (4) 1/sqrt(a) = 1/sqrt(b) + 1/sqrt(c)

Answer

Correct answer: Option 4

Solution

Since the three circles touch the x-axis and touch each other externally, let the centers be at A, C, B respectively with radii a, b, c. The centers lie at heights equal to their respective radii from the x-axis. Center A is at (x_A, a), Center C is at (x_C, b), Center B is at (x_B, c). Since circles A and C touch externally: distance AC = a + b Since circles C and B touch externally: distance CB = b + c Since circles A and B touch externally: distance AB = a + c From geometry: AB = AC + CB sqrt((b+c)^2 + (b-c)^2) = sqrt((b+a)^2 - (b-a)^2) + sqrt((a+c)^2 - (a-c)^2) Simplifying each term: (b+c)^2 + (b-c)^2 = b^2 + 2bc + c^2 + b^2 - 2bc + c^2 = 2b^2 + 2c^2 (b+a)^2 - (b-a)^2 = (b+a+b-a)(b+a-b+a) = 2b·2a = 4ab (a+c)^2 - (a-c)^2 = (a+c+a-c)(a+c-a+c) = 2a·2c = 4ac So: sqrt(2b^2 + 2c^2) = 2sqrt(ab) + 2sqrt(ac) Dividing by 2: sqrt(b^2 + c^2) = sqrt(ab) + sqrt(ac) Let sqrt(b^2 + c^2) = sqrt(a)(sqrt(b) + sqrt(c)) Squaring both sides and solving: b^2 + c^2 = a(b + c + 2sqrt(bc)) This leads to: 1/sqrt(a) = 1/sqrt(b) + 1/sqrt(c)
