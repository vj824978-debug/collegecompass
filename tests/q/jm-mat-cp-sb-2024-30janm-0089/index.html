Let y = y(x) be the solution of the differential equation (1 - x^2)dy = [xy + (x^3 + 2)sqrt(3(1 - x^2))]dx, -1 < x < 1, y(0) = 0. If y(1/2) = m/n, m and n are co-prime numbers, then m + n is equal to ______.

Answer

Correct answer: 97

Solution

Rewrite as dy/dx + (x/(x^2-1))y = ((x^3+2)sqrt(3))/sqrt(1-x^2). Find integrating factor: I.F. = e^(integral of x/(x^2-1)dx) = e^(-(1/2)ln|x^2-1|) = sqrt(1-x^2). Multiply both sides by I.F. to get y·sqrt(1-x^2) = integral of sqrt(3)(x^3+2)dx + C = sqrt(3)(x^4/4 + 2x) + C. Using y(0) = 0, we get C = 0. At x = 1/2: y(1/2)·sqrt(1-1/4) = sqrt(3)(1/64 + 1) = sqrt(3)·(65/64). So y(1/2)·sqrt(3)/2 = 65sqrt(3)/64, giving y(1/2) = 65/32. Thus m = 65, n = 32, and m + n = 97.
