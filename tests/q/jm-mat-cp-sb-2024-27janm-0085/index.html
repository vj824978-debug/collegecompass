A fair die is tossed repeatedly until a six is obtained. Let X denote the number of tosses required and let a = P(X = 3), b = P(X ≥ 3) and c = P(X ≥ 6|X > 3). Then (b + c)/a is equal to ____.

Answer

Correct answer: 12

Solution

P(A) = 1/6 (obtaining a six), P(A') = 5/6 (not obtaining a six). a = P(X = 3) = (5/6) × (5/6) × (1/6) = 25/216 = 5^2/6^3. b = P(X ≥ 3) is a G.P. with first term 25/216 and common ratio 5/6, sum = (25/216)/(1 - 5/6) = 25/36 = (5/6)^2. P(X > 3) = 5^3/6^3 = 5^3/6^3. P(X ≥ 6) = 5^5/6^5 = (5/6)^5. c = P(X ≥ 6|X > 3) = P(X ≥ 6)/P(X > 3) = (5^5/6^5)/(5^3/6^3) = 5^2/6^2 = (5/6)^2. (b + c)/a = (25/36 + 25/36)/(25/216) = (50/36)/(25/216) = 2 × (25/36) × (216/25) = 2 × 6 = 12
