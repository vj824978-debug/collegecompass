The number of elements in the relation R = {(x, y) : 4x^2 + y^2 < 52, x, y ∈ Z} is

  1. (1) 77
  2. (2) 89
  3. (3) 67
  4. (4) 86

Answer

Correct answer: Option 1

Solution

4x^2 + y^2 < 52, x, y ∈ Z For x = 0: y^2 < 52 y can be 0, ±1, ±2, ±3, ±4, ±5, ±6, ±7 Number of values = 1 × 15 = 15 For x = ±1: 4 + y^2 < 52 y^2 < 48 y can be 0, ±1, ±2, ±3, ±4, ±5, ±6 Number of values = 2 × 13 = 26 For x = ±2: 16 + y^2 < 52 y^2 < 36 y can be 0, ±1, ±2, ±3, ±4, ±5 Number of values = 2 × 11 = 22 For x = ±3: 36 + y^2 < 52 y^2 < 16 y can be 0, ±1, ±2, ±3 Number of values = 2 × 7 = 14 Total number of elements = 15 + 26 + 22 + 14 = 77
