If ∫(sin(x))^2 (cos(x))^2 dx = -p1/q1 (cot(x))^(9/2) - p2/q2 (cot(x))^(5/2) - p3/q3 (cot(x))^(1/2) + p4/q4 (cot(x))^(-3/2) + C, where p_i and q_i are positive integers with gcd(p_i, q_i) = 1 for i = 1, 2, 3, 4 and C is the constant of integration, then 15p1p2p3p4/(q1q2q3q4) is equal to ____.

Answer

Correct answer: 16

Solution

∫(tan(x))^(-11/2) · sec^8(x)dx = ∫(tan(x))^(-11/2)(1 + tan^2(x))^3 sec^2(x)dx Put tan(x) = t, sec^2(x) dx = dt ⇒ ∫t^(-11/2)(1 + t^2)^3 dt = ∫t^(-11/2)(1 + t^6 + 3t^2 + 3t^4)dt = ∫(t^(-11/2) + t^(1/2) + 3t^(-7/2) + 3t^(-3/2))dt = -2/9 (cot(x))^(9/2) - 6/5 (cot(x))^(5/2) - 6(cot(x))^(1/2) + 2/3 (cot(x))^(-3/2) + C ⇒ p1 = 2, p2 = 6, p3 = 6, p4 = 2 & q1 = 9, q2 = 5, q3 = 1, q4 = 3 15p1p2p3p4/(q1q2q3q4) = (15 · 2 · 6 · 6 · 2)/(9 · 5 · 1 · 3) = 16
