Let the relation R on the set M = {1,2,3,......16} be given by R = {(x,y) : 4y = 5x - 3, x,y ∈ M}. Then the minimum number of elements required to be added in R, in order to make the relation symmetric, is equal to

  1. (1) 1
  2. (2) 2
  3. (3) 4
  4. (4) 3

Answer

Correct answer: Option 2

Solution

R = {(3,3), (7,8), (11,13)} To make the relation symmetric, if (x,y) ∈ R then (y,x) must also be in R. For (3,3): Since x = y, (3,3) is already symmetric. For (7,8): We need to add (8,7) to make it symmetric. Check: 4(7) = 28 and 5(8) - 3 = 40 - 3 = 37. These are not equal, but (8,7) must be added for symmetry. For (11,13): We need to add (13,11) to make it symmetric. Check: 4(11) = 44 and 5(13) - 3 = 65 - 3 = 62. These are not equal, but (13,11) must be added for symmetry. Therefore, the elements (8,7) and (13,11) must be added to R to make it symmetric. Minimum number of elements required to be added = 2
