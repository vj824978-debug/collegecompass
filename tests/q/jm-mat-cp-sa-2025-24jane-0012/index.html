Let (2, 3) be the largest open interval in which the function f(x) = 2 log(x - 2) - x^2 + ax + 1 is strictly increasing and (b, c) be the largest open interval in which the function g(x) = (x - 1)^3(x + 2 - a)^2 is strictly decreasing. Then 100(a + b - c) is equal to:

  1. (1) 280
  2. (2) 360
  3. (3) 420
  4. (4) 160

Answer

Correct answer: Option 2

Solution

f(x) = 2 log(x - 2) - x^2 + ax + 1 f'(x) = 2/(x - 2) - 2x + a >= 0 f''(x) = -2/(x - 2)^2 - 2 < 0 Since f''(x) < 0, f'(x) is strictly decreasing. For f(x) to be strictly increasing on (2, 3), we need f'(x) >= 0 on this interval. The largest such interval is (2, 3), which means f'(3) = 0. f'(3) >= 0 2/(3 - 2) - 2(3) + a >= 0 2 - 6 + a >= 0 a >= 4 Since (2, 3) is the largest interval, a_min = 4. g(x) = (x - 1)^3(x + 2 - a)^2 With a = 4: g(x) = (x - 1)^3(x - 2)^2 g'(x) = (x - 1)^2 * 2(x - 2) + (x - 2)^2 * 3(x - 1)^2 = (x - 1)^2(x - 2)[2(x - 2) + 3(x - 1)] = (x - 1)^2(x - 2)(2x - 4 + 3x - 3) = (x - 1)^2(x - 2)(5x - 8) For g(x) to be strictly decreasing, g'(x) < 0: (x - 1)^2(x - 2)(5x - 8) < 0 Analyzing sign: (x - 1)^2 >= 0 always (and equals 0 at x = 1) For the product to be negative: (x - 2)(5x - 8) < 0 This occurs when 8/5 < x < 2 or equivalently when x is between the roots. Since 8/5 = 1.6 and 2 are the critical points: The largest open interval where g'(x) < 0 is (8/5, 2). Therefore: b = 8/5, c = 2 100(a + b - c) = 100(4 + 8/5 - 2) = 100(4 - 2 + 8/5) = 100(2 + 8/5) = 100(10/5 + 8/5) = 100(18/5) = 1800/5 = 360
