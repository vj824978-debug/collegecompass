Let a = 2i + αj + k, b = -i + k, c = βj - k, where α and β are integers and αβ = -6. Let the values of the ordered pair (α, β) for which the area of the parallelogram of diagonals a + b and b + c is sqrt(21)/2, be (α₁, β₁) and (α₂, β₂). Then α₁² + β₁² - α₂β₂ is equal to

  1. (1) 17
  2. (2) 24
  3. (3) 21
  4. (4) 19

Answer

Correct answer: Option 4

Solution

Area of parallelogram = (1/2)|d₁ × d₂| = sqrt(21)/2. Vector a + b = i + αj + 2k, b + c = -i + βj. Cross product (a+b) × (b+c) = i(-2β) - j(2) + k(β + α) with magnitude sqrt(4β² + 4 + (α+β)²) = sqrt(21). This gives 4β² + 4 + α² + β² + 2αβ = 21, so α² + 5β² + 2αβ = 17. With αβ = -6 and both integers: α² + 5β² - 12 = 17, so α² + 5β² = 29. Solutions: (α₁, β₁) = (-3, 2) and (α₂, β₂) = (3, -2). Therefore α₁² + β₁² - α₂β₂ = 9 + 4 - (-6) = 19.
