Suppose that p̄, q̄ and r̄ are three non-coplanar vectors in R³. Let the components of a vector s̄ along p̄, q̄ and r̄ be 4, 3 and 5, respectively. If the components of this vector s̄ along (-p̄ + q̄ + r̄), (p̄ - q̄ + r̄) and (-p̄ - q̄ + r̄) are x, y and z, respectively, then the value of 2x + y + z is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 9

Solution

s̄ = 4p̄ + 3q̄ + 5r̄ s̄ = x(-p̄ + q̄ + r̄) + y(p̄ - q̄ + r̄) + z(-p̄ - q̄ + r̄) s̄ = (-x + y - z)p̄ + (x - y - z)q̄ + (x + y + z)r̄ ⟹ -x + y - z = 4 ⟹ x - y - z = 3 ⟹ x + y + z = 5 On solving we get x = 4, y = 9/2, z = -7/2 ⟹ 2x + y + z = 9
