Three lines L₁: r⃗ = λi⃗, λ ∈ ℝ L₂: r⃗ = k̂ + μĵ, μ ∈ ℝ and L₃: r⃗ = î + ĵ + vk̂, v ∈ ℝ are given. For which point(s) Q on L₂ can we find a point P on L₁ and a point R on L₃ so that P, Q, R are collinear?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) k̂ - 1/2 ĵ
  2. (B) k̂ + 1/2 ĵ
  3. (C) k̂
  4. (D) k̂ + ĵ

Answer

Correct answer: AB

Solution

P.V. of point P, p̄ = λî P.V. of point Q, q̄ = μĵ + k̂ P.V. of point R, r̄ = î + ĵ + rk̂ PQR are collinear. Hence x(P̄Q) = y(P̄R) ⟹ x/y = (1-λ)/(-λ) = 1/μ = r ⟹ q̄ = -1/r ĵ + k̂ or q̄ = λ/(λ-1) ĵ + k̂, where r ≠ 0, λ ≠ 0, λ/(λ-1) ≠ 1 ⟹ μ ≠ 0, 1. Hence, q̄ ≠ k̂ or ĵ + k̂ [Diagram showing three parallel lines L₁, L₂, L₃ intersected by a transversal line. Points P, Q, R are marked on the transversal and the parallel lines respectively.]
