If a curve passes through the point (1, -2) and has slope of the tangent at any point (x, y) on it as (x - 2y)/x, then the curve also passes through the point:

  1. (1) (-1, 2)
  2. (2) (-sqrt(2), 1)
  3. (3) (sqrt(3), 0)
  4. (4) (3, 0)

Answer

Correct answer: Option 3

Solution

dy/dx = (x^2 - 2y)/x Rearranging: dy/dx + (2/x)y = x This is a linear differential equation of the form dy/dx + P(x)y = Q(x) Integrating factor: I.F. = e^(integral of 2/x dx) = e^(2ln x) = e^(ln x^2) = x^2 Multiplying both sides by x^2: x^2 * dy/dx + 2xy = x^3 Integrating: y*x^2 = integral of x^2 * x dx + C y*x^2 = integral of x^3 dx + C y*x^2 = x^4/4 + C ... (i) The curve passes through (1, -2): -2 * 1^2 = 1^4/4 + C -2 * 1 = 1/4 + C C = -2 - 1/4 = -9/4 Therefore: y*x^2 = x^4/4 - 9/4 4x^2*y = x^4 - 9 Checking which point satisfies this equation: For (sqrt(3), 0): 4 * (sqrt(3))^2 * 0 = (sqrt(3))^4 - 9 0 = 9 - 9 0 = 0 ✓ The curve satisfies (sqrt(3), 0)
