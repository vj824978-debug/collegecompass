The minimum value of the function f(x) = ∫[0 to 2] e^(x*t-1) dt is

  1. (1) e(e-1)
  2. (2) 2e-1
  3. (3) 2(e-1)
  4. (4) 2

Answer

Correct answer: Option 3

Solution

f(x) = ∫[0 to 2] e^(x*t-1) dt For x > 2: f(x) = ∫[0 to 2] e^(x*t-1) dt = e^x(1-e^(-2)) For x < 0: f(x) = ∫[0 to 2] e^(t-x) dt = e^(-x)(e^2-1) For x ∈ [0,2]: f(x) = ∫[0 to x] e^(x*t-1) dt + ∫[x to 2] e^(t-x) dt = e^(2-x) + e^x - 2 For x > 2: f(x)|_{min} = e^2 - 1 For x < 0: f(x)|_{min} = e^2 - 1 For x ∈ [0,2]: f(x)|_{min} = 2(e-1) Comparing all critical values, the overall minimum value is 2(e-1).
