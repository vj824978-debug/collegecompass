Consider the hyperbola x^2/a^2 - y^2/b^2 = 1 having one of its focus at P(-3, 0). If the latus rectum through its other focus subtends a right angle at P and a^2*b^2 = alpha*sqrt(2) - beta, alpha, beta ∈ N, then alpha + beta is ________.

Answer

Correct answer: 1944

Solution

Given: One focus at P(-3, 0), so ae = 3. For hyperbola, c^2 = a^2 + b^2, so ae = 3 means c = 3. The latus rectum through the other focus subtends a right angle at P, which means tan(45°) = ae/3 = 1, giving ae = 3. From the right angle condition: a*sqrt(1 + b^2/a^2) = 3, so a^2 + b^2 = 9. Since b^2/a = 6 from geometry: a^2 - 6a + 9 = 0, giving a = 3(sqrt(2) - 1). Then a^2*b^2 = 9(3 - 2*sqrt(2))*6.3(sqrt(2) - 1) = 162(5*sqrt(2) - 7). Therefore alpha = 162 × 5 = 810, beta = 162 × 7 = 1134, so alpha + beta = 1944.
