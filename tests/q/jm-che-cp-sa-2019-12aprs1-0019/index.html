An element has a face-centred cubic (fcc) structure with a cell edge of a. The distance between the centres of two nearest tetrahedral voids in the lattice is:

  1. (1) a
  2. (2) (3/2)a
  3. (3) a/2
  4. (4) sqrt(2)a

Answer

Correct answer: Option 3

Solution

In a face-centred cubic (fcc) structure with cell edge a: Tetrahedral voids are located at positions: - (a/4, a/4, a/4) - (a/4, 3a/4, 3a/4) - (3a/4, a/4, 3a/4) - (3a/4, 3a/4, a/4) - And similar positions in adjacent cells In the fcc lattice, there are 8 tetrahedral voids per unit cell. The nearest tetrahedral voids are located at positions like: - TV1 at (a/4, a/4, a/4) - TV2 at (a/4, 3a/4, 3a/4) Distance between these two nearest tetrahedral voids: d = sqrt[(a/4 - a/4)^2 + (a/4 - 3a/4)^2 + (a/4 - 3a/4)^2] d = sqrt[0 + (-a/2)^2 + (-a/2)^2] d = sqrt[a^2/4 + a^2/4] d = sqrt[a^2/2] d = a/sqrt(2) d = a*sqrt(2)/2 d = a/2 Alternatively, considering tetrahedral voids along body diagonal: The distance between nearest tetrahedral voids = a/2
