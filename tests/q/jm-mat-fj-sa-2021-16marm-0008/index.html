If y = y(x) is the solution of the differential equation dy/dx + 2y tan x = sin x, y(pi/3) = 0, then the maximum value of the function y(x) over R is equal to:

  1. (1) 1/2
  2. (2) 1/8
  3. (3) 15/4
  4. (4) 8

Answer

Correct answer: Option 2

Solution

Solve the differential equation dy/dx + 2y tan x = sin x. The integrating factor is e^(2ln sec x) = sec^2 x. Multiply through: d/dx(y sec^2 x) = sin x sec^2 x. Integrating: y sec^2 x = sec x + c. Using initial condition y(pi/3) = 0: 0 = sec(pi/3) + c, so c = -2. Thus y = (sec x - 2)/sec^2 x. Let g(t) = 1/t - 2/t^2 where t = sec x, t >= 1. Find g'(t) = -1/t^2 + 4/t^3. Setting g'(t) = 0: t = 4. Calculate g(4) = 1/4 - 2/16 = 1/4 - 1/8 = 1/8.
