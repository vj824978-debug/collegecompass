Consider the equation x^2 + 4x - n = 0, where n ∈ [20, 100] is a natural number. Then the number of all distinct values of n, for which the given equation has integral roots, is equal to

  1. (1) 5
  2. (2) 7
  3. (3) 8
  4. (4) 6

Answer

Correct answer: Option 4

Solution

For the equation x^2 + 4x - n = 0 to have integral roots, let the roots be p and q. By Vieta's formulas: p + q = -4 and pq = -n. So n = -pq. Since n ∈ [20, 100], we need 20 ≤ -pq ≤ 100. Let p + q = -4. Then q = -4 - p, so n = -p(-4 - p) = p(4 + p) = p^2 + 4p. We need 20 ≤ p^2 + 4p ≤ 100. Solving p^2 + 4p ≥ 20: p^2 + 4p - 20 ≥ 0, giving p ≤ -2 - 2√6 or p ≥ -2 + 2√6 ≈ 2.9. Solving p^2 + 4p ≤ 100: p^2 + 4p - 100 ≤ 0, giving -2 - 2√26 ≤ p ≤ -2 + 2√26, approximately -12.2 ≤ p ≤ 8.2. For integer p: p ∈ {-12, -11, -10, -9, -8, -7, -6, -5, 3, 4, 5, 6, 7, 8}. Computing n = p^2 + 4p for each: distinct values are 20, 21, 24, 28, 33, 39, 40, 45, 56, 72, 84. However, checking which n values in [20,100] give distinct counts yields 8 distinct values.
