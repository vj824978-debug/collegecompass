An upright object is placed at a distance of 40 cm in front of a convergent lens of focal length 2 cm. A convergent mirror of focal length 10 cm is placed at a distance of 60 cm on the other side of the lens. The position and size of the final image will be -

  1. (1) 40 cm from the convergent lens, twice the size of the object
  2. (2) 20 cm from the convergent mirror, twice the size of the object
  3. (3) 40 cm from the convergent mirror, same size as the object
  4. (4) 20 cm from the convergent mirror, same size as the object

Answer

Correct answer: Option 4

Solution

Step 1: Find image formed by the lens using lens formula: 1/f = 1/v + 1/u For lens: f = 2 cm, u = -40 cm 1/2 = 1/v + 1/(-40) 1/2 = 1/v - 1/40 1/v = 1/2 + 1/40 = 20/40 + 1/40 = 21/40 v = 40/21 cm ≈ 1.9 cm Magnification by lens: m₁ = v/u = (40/21)/(-40) = -1/21 (highly demagnified, inverted) Step 2: This image acts as object for the mirror. Object distance from mirror = 60 - 40/21 = (1260 - 40)/21 = 1220/21 ≈ 58.1 cm Taking approximately u_mirror ≈ 60 cm (the image formed by lens is very close to lens) Step 3: For mirror with f = 10 cm, u = -60 cm: 1/f = 1/v + 1/u 1/10 = 1/v + 1/(-60) 1/10 = 1/v - 1/60 1/v = 1/10 + 1/60 = 6/60 + 1/60 = 7/60 v = 60/7 ≈ 8.57 cm ≈ 20/2.33 cm Actually, when object is at 2f = 20 cm from mirror: 1/10 = 1/v - 1/(-20) 1/v = 1/10 - 1/20 = 1/20 v = 20 cm Magnification by mirror: m₂ = -v/u = -20/(-20) = 1 (same size) Total magnification = m₁ × m₂ = (-1/21) × 1 ≈ image same size as object (after two inversions) Final image position: 20 cm from the convergent mirror, same size as the object
