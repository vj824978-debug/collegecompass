For which of the following ordered pairs (μ, δ), the system of linear equations x + 2y + 3z = 1, 3x + 4y + 5z = μ, 4x + 4y + 4z = σ is inconsistent?

  1. (1) (3, 4)
  2. (2) (4, 6)
  3. (3) (4, 3)
  4. (4) (1, 0)

Answer

Correct answer: Option 3

Solution

For given system of linear equation Δ = |1 2 3| = 0 |3 4 5| |4 4 4| For equation to be consistent Δ_x = 0, Δ_y = 0, Δ_z = 0 Δ_x = |1 2 3| = 0 |μ 4 5| |δ 4 4| ⇒ 2μ - δ = 2 .....(i) Δ_y = |1 1 3| = 0 |3 μ 5| |4 δ 4| ⇒ 2μ - δ = 2 Δ_z = |1 2 1| = 0 |3 4 μ| |4 4 δ| ⇒ 2μ - δ = 2 For 2μ - δ = 2, only option (3) → (4, 3) does not satisfy this equation. For answering this question only Δ_x needs to be calculated.
