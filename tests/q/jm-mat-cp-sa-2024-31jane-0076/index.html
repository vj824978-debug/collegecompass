Let z1 and z2 be two complex numbers such that z1 + z2 = 5 and z1^3 + z2^3 = 20 + 15i. Then |z1^4 + z2^4| equals

  1. (1) 75
  2. (2) 25*sqrt(3)
  3. (3) 15*sqrt(15)
  4. (4) 30*sqrt(3)

Answer

Correct answer: Option 1

Solution

Given: z1 + z2 = 5 and z1^3 + z2^3 = 20 + 15i. Using the identity z1^3 + z2^3 = (z1 + z2)^3 - 3*z1*z2*(z1 + z2), we get 20 + 15i = 125 - 15*z1*z2, so z1*z2 = 7 - i. From (z1 + z2)^2 = 25, we get z1^2 + z2^2 = 25 - 2(7 - i) = 11 + 2i. Then (z1^2 + z2^2)^2 = z1^4 + z2^4 + 2*z1^2*z2^2 = 117 + 44i, so z1^4 + z2^4 = 21 + 72i. Therefore |z1^4 + z2^4| = sqrt(21^2 + 72^2) = sqrt(441 + 5184) = sqrt(5625) = 75.
