A vector a has components 3p and 1 with respect to a rectangular Cartesian system. This system is rotated through a certain angle about the origin in the counter clockwise sense. If, with respect to new system, a has components p + 1 and sqrt(10), then a value of p is equal to:

  1. (1) -1
  2. (2) 4/5
  3. (3) -5/4
  4. (4) 1

Answer

Correct answer: Option 1

Solution

Since magnitude of vector is invariant under rotation: |a| = |a'|. Original vector a = 3pi + j has magnitude sqrt((3p)^2 + 1^2) = sqrt(9p^2 + 1). Rotated vector a' = (p+1)i + sqrt(10)j has magnitude sqrt((p+1)^2 + (sqrt(10))^2) = sqrt((p+1)^2 + 10). Setting magnitudes equal: sqrt(9p^2 + 1) = sqrt((p+1)^2 + 10). Squaring: 9p^2 + 1 = (p+1)^2 + 10. Expanding: 9p^2 + 1 = p^2 + 2p + 1 + 10. Simplifying: 9p^2 + 1 = p^2 + 2p + 11. Therefore: 8p^2 - 2p - 10 = 0, or 4p^2 - p - 5 = 0. Factoring: (4p - 5)(p + 1) = 0. Solutions: p = 5/4 or p = -1. From the diagram and context, p = -1 is the answer.
