Let A₁ be the bounded area enclosed by the curves y = x² + 2, x + y = 8 and y-axis that lies in the first quadrant. Let A₂ be the bounded area enclosed by the curves y = x² + 2, y² = x, x = 2, and y-axis that lies in the first quadrant. Then A₁ - A₂ is equal to

  1. (1) (2/3)(2√2 + 1)
  2. (2) (2/3)(4√2 + 1)
  3. (3) (2/3)(√2 + 1)
  4. (4) (2/3)(3√2 + 1)

Answer

Correct answer: Option 1

Solution

For A₁: The region is bounded by y = x² + 2, x + y = 8 (i.e., y = 8 - x), and the y-axis. First, find intersection points: - y = x² + 2 and y = 8 - x intersect when x² + 2 = 8 - x x² + x - 6 = 0 (x + 3)(x - 2) = 0 x = 2 (since x ≥ 0 in first quadrant) At x = 2: y = 6 - y = x² + 2 intersects y-axis at (0, 2) - y = 8 - x intersects y-axis at (0, 8) A₁ = ∫₀²[(8 - x) - (x² + 2)]dx A₁ = ∫₀²(6 - x - x²)dx A₁ = [6x - x²/2 - x³/3]₀² A₁ = 12 - 2 - 8/3 A₁ = 10 - 8/3 = 22/3 For A₂: The region is bounded by y = x² + 2, y² = x, x = 2, and the y-axis. First, find intersection points: - y² = x and y = x² + 2 intersect when y² = (y - 2)² + 2 (from y² = x, so x = y²) Wait, from y² = x, we get x = y². From y = x² + 2, substituting x = y²: y = (y²)² + 2 = y⁴ + 2 This is incorrect. Let me reconsider. From y² = x and y = x² + 2: y = (y²)² + 2 = y⁴ + 2 is not right. Actually, x = y² and y = x² + 2 So y = (y²)² + 2 gives y = y⁴ + 2, which has no real solution in the first quadrant. The curves intersect at x = 2: - From y² = x: y = √2 at x = 2 - From y = x² + 2: y = 6 at x = 2 A₂ = ∫₀²(x² + 2)dx - (2/3)(2√2) Where (2/3)(2√2) represents the area under y² = x from y = 0 to y = √2. A₂ = [x³/3 + 2x]₀² - (4√2)/3 A₂ = 8/3 + 4 - (4√2)/3 A₂ = 20/3 - (4√2)/3 A₁ - A₂ = 22/3 - (20/3 - (4√2)/3) A₁ - A₂ = 22/3 - 20/3 + (4√2)/3 A₁ - A₂ = 2/3 + (4√2)/3 A₁ - A₂ = (2/3)(1 + 2√2) A₁ - A₂ = (2/3)(2√2 + 1)
