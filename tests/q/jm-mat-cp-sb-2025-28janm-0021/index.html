Let M denote the set of all real matrices of order 3 × 3 and let S = {-3, -2, -1, 1, 2}. Let S1 = {A = [aij] ∈ M : A = A^T and aij ∈ S, ∀ i, j}, S2 = {A = [aij] ∈ M : A = -A^T and aij ∈ S, ∀ i, j}, S3 = {A = [aij] ∈ M : a11 + a22 + a33 = 0 and aij ∈ S, ∀ i,j}. If n(S1 ∪ S2 ∪ S3) = 125α, then α equals.

Answer

Correct answer: 1613

Solution

A 3×3 matrix has 9 elements: [a11 a12 a13] [a21 a22 a23] [a31 a32 a33] For S1: A = A^T (symmetric matrices) No. of elements in S1: A = A^T ⇒ 5^3 × 5^3 Since a11, a22, a33 can each take 5 values and a12 = a21, a13 = a31, a23 = a32 can each take 5 values No. of symmetric matrices = 5^6 For S2: A = -A^T (skew-symmetric matrices) No. of elements in A = -A^T ⇒ 0 Since diagonal elements must be 0 and aij = -aji No. of skew-symmetric matrices = 5^3 For S3: a11 + a22 + a33 = 0 and aij ∈ S Choosing a11 and a22 freely: (1, 2, -3) ⇒ 31 ways or (1, 1, -2) ⇒ 3 ways or (-1, -1, 2) ⇒ 3 ways ⇒ 12 × 5^6 ways n(S1 ∩ S3) = 12 × 5^3 n(S1 ∪ S2 ∪ S3) = 5^6(1 + 12) - 12 × 5^3 ⇒ 5^3 × [13 × 5^3 - 12] = 125α α = 1613
