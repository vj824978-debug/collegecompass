If a random variable x has the probability distribution: x: 0, 1, 2, 3, 4, 5, 6, 7 and p(x): 0, 2k, k, 3k, 2k^2, 2k, k^2+k, 7k^2, then P(3 < x ≤ 6) is equal to

  1. (1) 0.34
  2. (2) 0.22
  3. (3) 0.64
  4. (4) 0.33

Answer

Correct answer: Option 4

Solution

Using the condition that sum of all probabilities equals 1: ∑P(x_i) = 1 0 + 2k + k + 3k + 2k^2 + 2k + k^2 + k + 7k^2 = 1 9k + 10k^2 = 1 10k^2 + 9k - 1 = 0 Using quadratic formula or factoring: k = 1/10 Now, P(3 < x ≤ 6) includes x = 4, 5, 6 P(3 < x ≤ 6) = P(x=4) + P(x=5) + P(x=6) = 2k^2 + 2k + k^2 + k = 3k^2 + 3k = 3k(k + 1) = 3(1/10)(1/10 + 1) = 3(1/10)(11/10) = 33/100 = 0.33
