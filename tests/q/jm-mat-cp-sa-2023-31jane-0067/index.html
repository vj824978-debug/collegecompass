Let P be the plane, passing through the point (1,-1,-5) and perpendicular to the line joining the points (4,1,-3) and (2,4,3). Then the distance of P from the point (3,-2,2) is:

  1. (1) 4
  2. (2) 7
  3. (3) 5
  4. (4) 6

Answer

Correct answer: Option 3

Solution

The direction vector of the line joining (4,1,-3) and (2,4,3) is: vector n = (2-4)i + (4-1)j + (3-(-3))k = -2i + 3j + 6k Or vector n = 2i - 3j - 6k Since plane P is perpendicular to this line, the normal vector to the plane is: vector n = 2i - 3j - 6k Equation of plane passing through point (1,-1,-5) with normal vector (2,-3,-6) is: 2(x - 1) - 3(y - (-1)) - 6(z - (-5)) = 0 2(x - 1) - 3(y + 1) - 6(z + 5) = 0 2x - 2 - 3y - 3 - 6z - 30 = 0 2x - 3y - 6z - 35 = 0 Or 2x - 3y - 6z = 35 Distance from point (3,-2,2) to the plane 2x - 3y - 6z - 35 = 0 is: = |2(3) - 3(-2) - 6(2) - 35| / sqrt(2^2 + (-3)^2 + (-6)^2) = |6 + 6 - 12 - 35| / sqrt(4 + 9 + 36) = |6 + 6 - 12 - 35| / sqrt(49) = |-35| / 7 = 35 / 7 = 5 units
