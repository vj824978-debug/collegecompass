Let l₁, l₂, ..., l₁₀₀ be consecutive terms of an arithmetic progression with common difference d₁, and let w₁, w₂, ..., w₁₀₀ be consecutive terms of another arithmetic progression with common difference d₂, where d₁d₂ = 10. For each i = 1, 2, ..., 100, let Rᵢ be a rectangle with length lᵢ, width wᵢ and area Aᵢ. If A₅₁ - A₅₀ = 1000, then the value of A₁₀₀ - A₉₀ is _____.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 18900

Solution

A₅₁ - A₅₀ = 1000 l₅₁w₅₁ - l₅₀w₅₀ = 100 (l₁ + 50d₁) (w₁ + 50d₂) - (l₁ + 49d₁) (w₁ + 49d₂) = 1000 l₁w₁ + 50l₁d₂ + 50d₁w₁ + 2500d₁d₂ - l₁w₁ - 49l₁d₂ - 49d₁w₁ - 2440d₁d₂ = 1000 ⟹ l₁d₂ + d₁w₁ + 99d₁d₂ = 1000 ⟹ l₁d₂ + d₁w₁ = 10 A₁₀₀ - A₉₀ = (l₁₀₀w₁₀₀) - (l₉₀w₉₀) = (l₁ + 99d₁) (w₁ + 99d₂) - (l₁ + 89d₁) (w₁ + 89d₂) = 10d₁w₁ + 10l₁d₂ + 1880d₁d₂ = 10 × 10 + 18800 = 18900
