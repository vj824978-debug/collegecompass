If the area of the region bounded by the curves y^2 - 2y = -x, x + y = 0 is A, then 8A is equal to _______.

Answer

Correct answer: 36

Solution

Area enclosed by y^2 - 2y = -x and x + y = 0. From the diagram, the curves intersect at point (-3, 3). From x + y = 0, we get x = -y. Substituting into y^2 - 2y = -x: y^2 - 2y = -(-y) = y y^2 - 2y - y = 0 y^2 - 3y = 0 y(y - 3) = 0 So y = 0 or y = 3 When y = 0: x = 0, giving point (0, 0) When y = 3: x = -3, giving point (-3, 3) For the parabola y^2 - 2y = -x, we get x = 2y - y^2 For the line x + y = 0, we get x = -y The area is: Area = ∫[0 to 3] [(2y - y^2) - (-y)] dy = ∫[0 to 3] (2y - y^2 + y) dy = ∫[0 to 3] (3y - y^2) dy = [3y^2/2 - y^3/3]|[0 to 3] = 3(3)^2/2 - (3)^3/3 - 0 = 27/2 - 9 = 27/2 - 18/2 = 9/2 = A Therefore, 8A = 8 × 9/2 = 36
