Let the length of the latus rectum of an ellipse x^2/a^2 + y^2/b^2 = 1, (a > b), be 30. If its eccentricity is the maximum value of the function f(t) = -3/4 + 2t - t^2, then (a^2 + b^2) is equal to

  1. (1) 516
  2. (2) 256
  3. (3) 496
  4. (4) 276

Answer

Correct answer: Option 3

Solution

f(t) = -3/4 + 2t - t^2 To find maximum, take derivative: f'(t) = 2 - 2t = 0 t = 1 f(t)|_maximum = -3/4 + 2(1) - (1)^2 = -3/4 + 2 - 1 = 1/4 So e = 1/4 e^2 = 1/16 For an ellipse, e^2 = (a^2 - b^2)/a^2 = 1/16 .....(1) Length of latus rectum = 2b^2/a = 30 Therefore: 2b^2/a = 30 => b^2 = 15a .....(2) From equation (1): 16(a^2 - b^2) = a^2 16a^2 - 16b^2 = a^2 15a^2 = 16b^2 Substituting b^2 = 15a from equation (2): 15a^2 = 16(15a) 15a^2 = 240a a = 16 From equation (2): b^2 = 15(16) = 240 Therefore: a^2 + b^2 = 256 + 240 = 496
