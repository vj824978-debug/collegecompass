Let a, b be two non-zero real numbers. If p and r are the roots of the equation x^2 - 8ax + 2a = 0 and q and s are the roots of the equation x^2 + 12bx + 6b = 0, such that 1/p + 1/q + 1/r + 1/s are in A.P., then a^(-1) - b^(-1) is equal to __

Answer

Correct answer: 38

Solution

From x^2 - 8ax + 2a = 0: p + r = 8a, pr = 2a. From x^2 + 12bx + 6b = 0: q + s = -12b, qs = 6b. Calculate 1/p + 1/r = (p+r)/pr = 8a/(2a) = 4 and 1/q + 1/s = (q+s)/qs = -12b/(6b) = -2. Since 1/p, 1/q, 1/r, 1/s are in A.P., the common difference gives 2/q = 4, so q = 1/2 and 2/r = -2, so r = -1. From pr = 2a with r = -1: p = -2a, and p + r = 8a gives -2a - 1 = 8a, so a = -1/10. From q + s = -12b with q = 1/2: s = -12b - 1/2, and qs = 6b gives (1/2)(-12b - 1/2) = 6b. Solving: -6b - 1/4 = 6b, so b = -1/48. Therefore a^(-1) - b^(-1) = -10 - (-48) = 38.
