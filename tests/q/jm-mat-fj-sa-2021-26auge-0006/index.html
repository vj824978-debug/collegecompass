The local maximum value of the function f(x) = (2/x)^x, x > 0, is:

  1. (1) (2*sqrt(e))^(1/e)
  2. (2) (e)^(2/e)
  3. (3) (4/sqrt(e))^(4/e)
  4. (4) 1

Answer

Correct answer: Option 2

Solution

Taking logarithm: ln(f(x)) = x*ln(2/x) = x(ln2 - lnx). Differentiating: f'(x)/f(x) = ln2 - lnx - 1, so f'(x) = (2/x)^x * [2(ln2 - lnx) - 1]. Setting f'(x) = 0: 2(ln2 - lnx) - 1 = 0, which gives 2lnx = ln4 - 1, so x^2 = 4/e, thus x = 2/sqrt(e). Checking second derivative shows this is a maximum. Substituting x = 2/sqrt(e) into f(x): f(x)_max = (2/(2/sqrt(e)))^(2/sqrt(e)) = (sqrt(e))^(2/sqrt(e)) = e^(2/e).
