Let f(x) = |(x - 1)(x^2 - 2x - 3)| + x - 3, x ∈ R. If m and M are respectively the number of points of local minimum and local maximum of f in the interval (0, 4), then m + M is equal to

Answer

Correct answer: 3.00

Solution

Rewrite f(x) = |(x - 1)(x + 1)(x - 3)| + (x - 3). Break into cases based on sign of (x - 1)(x + 1)(x - 3): For 3 ≤ x ≤ 4: f(x) = (x - 3)(x^2), For 1 ≤ x < 3: f(x) = (x - 3)(2 - x^2), For 0 < x < 1: f(x) = (x - 3)(x^2). Find f'(x) in each interval: For 3 < x < 4: f'(x) = 3x^2 - 6x, For 1 < x < 3: f'(x) = -3x^2 + 6x + 2, For 0 < x < 1: f'(x) = 3x^2 - 6x. Check sign changes: f'(3^+) > 0, f'(3^-) < 0 → local minimum at x = 3. f'(1^+) > 0, f'(1^-) < 0 → local minimum at x = 1. In interval (1, 3), f'(x) = 0 at one point → local maximum. No critical points in (3, 4) and (0, 1) with sign changes. Therefore: m = 2 (minima at x = 1 and x = 3), M = 1 (maximum in (1, 3)). m + M = 3.
