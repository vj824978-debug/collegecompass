A linearly polarized electromagnetic wave in vacuum is E = 3.1 cos[(1.8)z - (5.4×10^7)t]j N/C is incident normally on a perfectly reflecting wall at z = a. Choose the correct option

  1. (1) The frequency of electromagnetic wave is 54×10^6 Hz.
  2. (2) The transmitted wave will be 3.1 cos[(1.8)z - (5.4×10^7)t]j N/C
  3. (3) The reflected wave will be 3.1 cos[(1.8)z + (5.4×10^7)t]j N/C
  4. (4) The wavelength is 5.4 m

Answer

Correct answer: Option 3

Solution

From the given wave equation E = 3.1 cos[(1.8)z - (5.4×10^7)t]j, we can identify k = 1.8 m^(-1) and ω = 5.4×10^7 rad/s. Using k = 2π/λ, we get λ = 2π/1.8 = 2π/1.8 ≈ 3.49 m ≈ 3.14 m. The frequency f = ω/(2π) = (5.4×10^7)/(2π) ≈ 8.59×10^6 Hz (not 54×10^6 Hz). For a perfectly reflecting wall, there is no transmitted wave. The reflected wave will have the same amplitude but opposite sign in the argument (z changes sign in spatial term), giving 3.1 cos[(1.8)z + (5.4×10^7)t]j N/C. The correct answer is option (C).
