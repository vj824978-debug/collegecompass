Let y = y(x) be the solution curve of the differential equation, (y^2 - x) dy/dx = 1, satisfying y(0) = 1. This curve intersects the x-axis at a point whose abscissa is:

  1. (1) 2
  2. (2) 2 + e
  3. (3) 2 - e
  4. (4) -e

Answer

Correct answer: Option 3

Solution

From the given differential equation (y^2 - x) dy/dx = 1 Rearranging: dx/dy = y^2 - x This can be written as: dy/dx + x = y^2 This is a linear differential equation in x as a function of y. Integrating factor: I.F. = e^(∫1 dy) = e^y Multiplying both sides by e^y: x.e^y = ∫y^2.e^y dy Using integration by parts twice: ∫y^2.e^y dy = y^2.e^y - ∫2y.e^y dy = y^2.e^y - 2y.e^y + ∫2.e^y dy = y^2.e^y - 2y.e^y + 2e^y + C Therefore: x.e^y = y^2.e^y - 2y.e^y + 2e^y + C Applying initial condition y(0) = 1: 0.e^1 = 1.e^1 - 2(1).e^1 + 2e^1 + C 0 = e - 2e + 2e + C 0 = e + C C = -e So: x.e^y = y^2.e^y - 2y.e^y + 2e^y - e The curve intersects the x-axis when y = 0: x.e^0 = 0.e^0 - 2(0).e^0 + 2e^0 - e x = 0 - 0 + 2 - e x = 2 - e
