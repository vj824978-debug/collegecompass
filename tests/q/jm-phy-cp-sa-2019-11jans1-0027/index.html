If speed (V), acceleration (A) and force (F) are considered as fundamental units, the dimension of Young's modulus will be:

  1. (1) V^(-2)A^2F^2
  2. (2) V^(-1)A^(-2)F
  3. (3) V^(-4)A^2F
  4. (4) V^(-2)A^2F^(-2)

Answer

Correct answer: Option 3

Solution

Y = K v^x F^y A^z ; K is dimension less constant ML^(-1)T^(-2) = [LT^(-1)]^x [MLT^(-2)]^y [LT^(-2)]^z ML^(-1)T^(-2) = L^(x+y+z) T^(-x-2y-2z) M^y y = 1; x + y + z = -1; x + z = -2 and -x - 2y - 2z = -2 -x - 2z = 0; x + 2z = 0; so x = -4, y = 1, z = 2 Y = V^(-4)A^2F
