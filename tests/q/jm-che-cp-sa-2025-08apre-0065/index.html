In a first order decomposition reaction, the time taken for the decomposition of reactant to one fourth and one eighths of its initial concentration are t1 and t2(s), respectively. The ratio t1/t2 will be:

  1. (1) 4/3
  2. (2) 3/2
  3. (3) 3/4
  4. (4) 2/3

Answer

Correct answer: Option 4

Solution

For first order reaction: t = (1/k) ln(A0/A). When A = A0/4: t1 = (1/k) ln(4). When A = A0/8: t2 = (1/k) ln(8). Therefore t1/t2 = ln(4)/ln(8) = ln(4)/(3ln(2)) = 2ln(2)/(3ln(2)) = 2/3
