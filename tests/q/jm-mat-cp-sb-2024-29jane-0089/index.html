Let α, β be the roots of the equation x^2 - sqrt(6)x + 3 = 0 such that Im(α) > Im(β). Let a, b be integers not divisible by 3 and n be a natural number such that α^99/β + α^98 = 3^n(a + ib), i = sqrt(-1). Then n + a + b is equal to ___.

Answer

Correct answer: 49

Solution

From x^2 - sqrt(6)x + 3 = 0, we get x = (sqrt(6) ± sqrt(6-12))/2 = (sqrt(6) ± sqrt(-6))/2. So α = (sqrt(6)/2)(1+i) and β = (sqrt(6)/2)(1-i). Here α + β = sqrt(6), αβ = 3. We compute S = α^99/β + α^98 = α^99(1/β + 1/α) = α^99((α+β)/(αβ)) = α^99(sqrt(6)/3). Since (1+i) = sqrt(2)e^(iπ/4), we have (1+i)^99 = (√2)^99 e^(i99π/4) = (√2)^99(-1+i). Therefore S = (sqrt(6)/2)^100 × (√2)^99 × (-1+i)/3.2^99 = (√3)^100/3 × (-1+i) = 3^49(-1+i). Thus n = 49, a = -1, b = 1, and n + a + b = 49.
