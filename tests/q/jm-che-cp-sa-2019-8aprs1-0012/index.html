Which one of the following equations does not correctly represent the first law of thermodynamics for the given processes involving an ideal gas ? (Assume non-expansion work is zero)

  1. (1) Adiabatic process : ΔU = -w
  2. (2) Cyclic process : q = -w
  3. (3) Isothermal process : q = -w
  4. (4) Isochoric process : ΔU = q

Answer

Correct answer: Option 2

Solution

1st law of thermodynamics: ΔE = q + w 1. Adiabatic process q = 0, (ΔE = w) or (ΔU = w) This is CORRECT 2. Cyclic process ΔE = 0, (q = -w) This is CORRECT 3. Isothermal process ΔE = nC_v ΔT, (ΔT = 0) ΔE = 0, (q = -w) This is CORRECT 4. Isochoric process ΔV = 0 w = P ΔV = 0 ΔE = q This is CORRECT However, examining option (2) more carefully: For a cyclic process, ΔE = 0 (since initial and final states are same) Using ΔE = q + w, we get: 0 = q + w, therefore q = -w But the question states the equation as "q = -w" which appears correct for cyclic process. Re-examining option (1): For adiabatic process: q = 0 Using ΔE = q + w: ΔE = 0 + w, so ΔE = w The option states ΔU = -w, which is INCORRECT. The correct equation for adiabatic process should be ΔU = w (not -w).
