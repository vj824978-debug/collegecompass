Let C be the set of all complex numbers. Let S₁ = {z ∈ C | |z - 3 - 2i| = 8}, S₂ = {z ∈ C | Re(z) ≥ 5} and S₃ = {z ∈ C | |z - z̄| ≥ 8}. Then the number of element in S₁ ∩ S₂ ∩ S₃ is equal to:

  1. (1) 0
  2. (2) 2
  3. (3) 1
  4. (4) infinite

Answer

Correct answer: Option 3

Solution

S₁: |z - 3 - 2i| = 8 represents a circle with center (3, 2) and radius 2√2. For z = x + iy: (x - 3)² + (y - 2)² = (2√2)². S₂: Re(z) ≥ 5 means x ≥ 5, a vertical half-plane. S₃: |z - z̄| ≥ 8 means |2iy| ≥ 8, so 2|y| ≥ 8, giving |y| ≥ 4, which means y ≥ 4 or y ≤ -4. The intersection S₁ ∩ S₂ ∩ S₃ requires points on the circle with x ≥ 5 and (y ≥ 4 or y ≤ -4). Checking the circle equation with x ≥ 5 and y ≥ 4 or y ≤ -4 yields exactly 1 point in the intersection.
