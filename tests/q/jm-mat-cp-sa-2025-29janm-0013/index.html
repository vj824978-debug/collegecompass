Consider an A.P. of positive integers, whose sum of the first three terms is 54 and the sum of the first twenty terms lies between 1600 and 1800. Then its 11th term is:

  1. (1) 84
  2. (2) 122
  3. (3) 90
  4. (4) 108

Answer

Correct answer: Option 3

Solution

S_3 = 3a + 3d = 54 => a + d = 18 S_20 = 10(2a + 19d) = 10(2(18-d) + 19d) = 10(36 - 2d + 19d) = 10(36 + 17d) Given: 1600 < 10(36 + 17d) < 1800 => 160 < 36 + 17d < 180 => 124 < 17d < 144 => 124/17 < d < 144/17 => 7 + 5/17 < d < 8 + 8/17 Since common difference must be a natural number: => d = 8 => a = 18 - 8 = 10 Therefore, a_11 = a + 10d = 10 + 10(8) = 10 + 80 = 90
