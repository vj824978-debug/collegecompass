In the given P-V diagram, a monoatomic gas (gamma = 5/3) is first compressed adiabatically from state A to state B. Then it expands isothermally from state B to state C. [Given: (1/3)^0.6 = 0.5, ln 2 = 0.7]. [P-V diagram showing: State A at approximately (0.80 m³, 100 kPa), State B at approximately (0.80 m³, 300 kPa) connected by adiabatic curve, State C at higher volume and 300 kPa connected by isothermal curve from B] Which of the following statement(s) is(are) correct?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) The magnitude of the total work done in the process A → B → C is 144kJ.
  2. (B) The magnitude of the work done in the process B→ C is 84kJ.
  3. (C) The magnitude of the work done in the process A → B is 60kJ.
  4. (D) The magnitude of the work done in the process C → A is zero.

Answer

Correct answer: BCD

Solution

B, C, D Volume of gas at B is VB = (100/300)^(1/3) (0.8) = 0.4 m³ WAB = (PA VA - PB VB)/(γ - 1) = -60 kJ WBC = PB VB ln2 = 84 kJ WCA = 0
