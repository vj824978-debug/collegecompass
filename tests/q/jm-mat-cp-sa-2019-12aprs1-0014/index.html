Consider the differential equation: y^2 dx + (x - 1/y) dy = 0. If value of y is 1 when x = 1, then the value of x for which y = 2, is:

  1. (1) 3/2 - 1/sqrt(e)
  2. (2) 3/2 - sqrt(e)
  3. (3) 1/2 + 1/sqrt(e)
  4. (4) 5/2 + 1/sqrt(e)

Answer

Correct answer: Option 1

Solution

dx/dy + x/y^2 = 1/y^3 I.F. = e^(∫(1/y^2)dy) = e^(-1/y) sol. xe^(-1/y) = ∫e^(-1/y)(1/y^3)dy Let -1/y = t ⟹ (1/y^2)dy = dt xe^t = ∫e^t(-t).dt x.e^t = -[te^t - e^t] + c x = -t + 1 + c.e^(-t) x = 1/y + 1 + c.e^(1/y) give y(1) = 1 1 = 1 + 1 + c.e^(1/1) 1 = 1 + 1 + c.e^1 c = -e^(-1) x = 1/y + 1 + (-e^(-1)).e^(1/y) at y = 2 x = 3/2 - 1/sqrt(e)
