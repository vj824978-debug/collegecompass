Let f(x) and g(x) be two real polynomials of degree 2 and 1 respectively. If f(g(x)) = 8x^2 - 2x and g(f(x)) = 4x^2 + 6x + 1, then the value of f(2) + g(2) is ___.

Answer

Correct answer: 18.00

Solution

Let f(x) = cx^2 + dx + e (degree 2) and g(x) = ax + b (degree 1). From f(g(x)) = c(ax + b)^2 + d(ax + b) + e = 8x^2 - 2x, we get: ac = 4, 2abc + ad = -2, ae + b = 1. From g(f(x)) = a(cx^2 + dx + e) + b = 4x^2 + 6x + 1, we get: ac = 4, ad = 6, ae + b = 1. Solving: a = 2, c = 2, d = 3, b = -1, e = 1. Therefore f(x) = 2x^2 + 3x + 1 and g(x) = 2x - 1. So f(2) + g(2) = 2(4) + 3(2) + 1 + 2(2) - 1 = 8 + 6 + 1 + 4 - 1 = 18.
