Let PQ and MN be two straight lines touching the circle x^2 + y^2 - 4x - 6y - 3 = 0 at the points A and B respectively. Let O be the centre of the circle and angle AOB = pi/3. Then the locus of the point of intersection of the lines PQ and MN is:

  1. (1) 3(x^2 + y^2) - 18x - 12y + 25 = 0
  2. (2) x^2 + y^2 - 12x - 18y - 25 = 0
  3. (3) x^2 + y^2 - 18x - 12y - 25 = 0
  4. (4) 3(x^2 + y^2) - 12x - 18y - 25 = 0

Answer

Correct answer: Option 4

Solution

Circle: x^2 + y^2 - 4x - 6y - 3 = 0, Centre C(2,3), radius r = 4. Since angle AOB = pi/3, and PQ, MN are tangents at A, B respectively, if P is intersection point of tangents, then angle OPA = angle OPB = 90°. In triangle OPA: angle AOP = pi/3, so angle OPA = 90°, angle OAP = pi/6. Using cos(30°) = r/OR = 4/OR, we get OR = 8/sqrt(3). The locus of P satisfies: OR^2 = (h-2)^2 + (k-3)^2 = 64/3, which simplifies to 3(x^2 + y^2) - 12x - 18y - 25 = 0.
