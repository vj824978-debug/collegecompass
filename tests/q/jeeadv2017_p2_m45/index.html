Let α and β be nonzero real numbers such that 2(cos β - cos α) + cos α cos β = 1. Then which of the following is/are true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) tan(α/2) + sqrt(3) tan(β/2) = 0
  2. (B) sqrt(3) tan(α/2) + tan(β/2) = 0
  3. (C) tan(α/2) - sqrt(3) tan(β/2) = 0
  4. (D) sqrt(3) tan(α/2) - tan(β/2) = 0

Answer

Correct answer: AC

Solution

cosβ (2 + cosα) = 1 + 2 cos α cosβ / 1 = (1 + 2cosα) / (2 + cosα) (cosβ + 1) / (cosβ - 1) = 3(cosα + 1) / (cosα - 1) (2cos²(β/2)) / (-2sin²(β/2)) = (3 × 2cos²(α/2)) / (-2sin²(α/2)) tan²(α/2) = 3tan²(β/2) ⟹ tan(α/2) = ±√3 tan(β/2)
