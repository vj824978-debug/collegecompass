For a > 0, let the curves C₁: y² = ax and C₂: x² = ay intersect at origin O and a point P. Let the line x = b (0 < b < a) intersect the chord OP and the x-axis at points Q and R, respectively. If the lines x = b bisects the area bounded by the curves, C₁ and C₂, and the area of triangle OQR = 1/2, then 'a' satisfies the equation-

  1. (1) x^6 - 6x^3 + 4 = 0
  2. (2) x^6 + 6x^3 - 4 = 0
  3. (3) x^6 - 12x^3 - 4 = 0
  4. (4) x^6 - 12x^3 + 4 = 0

Answer

Correct answer: Option 4

Solution

C₁: y² = ax C₂: x² = ay (a > 0) L: x = b P: intersection point of y² = ax and x² = ay ⟹ x^4/a² = ax ⟹ x(x³ - a³) = 0 ⟹ x = 0 and x = a ⟹ Point P: (a, a) ⟹ Line OP: y = x ⟹ Point Q = (b, b) Area ΔOQR = 1/2 = 1/2 × b × b = 1/2 ⟹ b = 1 Now line x = b bisect the area between curve ∫₀^b (√(ax) - x²/a) dx = ∫_b^a (√(ax) - x²/a) dx √a [x^(3/2)/(3/2) - x³/(3a)]₀^b = √a [x^(3/2)/(3/2) - x³/(3a)]_b^a (2/3)√a - 1/(3a) = (2a²/3 - a²/3) - (2/3)√a - 1/(3a)) (4/3)√a - 2/(3a) = 2a²/3 - a²/3 4√a - 2/a = a² 4a^(3/2) - 2 = a³ 4a^(3/2) = a³ + 2 16a³ = a^6 + 4 + 4a³ a^6 - 12a³ + 4 = 0
