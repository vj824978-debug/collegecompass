Match the reactions (in the given stoichiometry of the reactants) in List-I with one of their products given in List-II and choose the correct option. List-I: (P) P₂O₅ + 3H₂O → (Q) P₄ + 3NaOH + 3H₂O → (R) PCl₅ + CH₃COOH → (S) H₃PO₂ + 2H₂O + 4AgNO₃ → List-II: (1) P(O)(OCH₃)Cl₂ (2) H₃PO₄ (3) PH₃ (4) POCl₃ (5) H₃PO₄

Matrix match · Marks: +3 / -1.0

  1. (A) P → 2; Q → 3; R → 1; S → 5
  2. (B) P → 3; Q → 5; R → 4; S → 2
  3. (C) P → 5; Q → 2; R → 1; S → 3
  4. (D) P → 2; Q → 3; R → 4; S → 5

Answer

Correct answer: D

Solution

Sol. (D) P₂O₅ + 3H₂O ⟶ 2H₃PO₄ P₄ + 3NaOH + 3H₂O ⟶ PH₃ + 3NaH₂PO₂ PCl₅ + CH₃COOH ⟶ CH₃COCl + POCl₃ + HCl H₃PO₂ + 2H₂O + 4AgNO₃ ⟶ H₃PO₄ + 4Ag + 4HNO₃ P → 2, Q → 3, R → 4, S → 5
