Let the system of equations x + 2y + 3z = 5, 2x + 3y + z = 9, 4x + 3y + λz = μ have infinite number of solutions. Then λ + 2μ is equal to:

  1. (1) 15
  2. (2) 28
  3. (3) 22
  4. (4) 17

Answer

Correct answer: Option 4

Solution

For infinite solutions, the system must be dependent, so Δ = 0. Computing the determinant: Δ = 1(3λ - 3) - 2(2λ - 4) + 3(6 - 12) = 3λ - 3 - 4λ + 8 + 18 - 36 = -λ - 13. Setting Δ = 0: λ = -13. For consistency, Δ_3 = 0: Computing with third column as (5, 9, μ): 1(3μ - 27) - 2(2μ - 36) + 5(6 - 12) = 3μ - 27 - 4μ + 72 + 30 - 60 = -μ + 15 = 0, so μ = 15. Therefore λ + 2μ = -13 + 2(15) = -13 + 30 = 17.
