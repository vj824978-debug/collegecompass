Let P = alpha^n + beta^n, n ∈ N. If P_0 = 123, P_1 = 76, P_2 = 47 and P_1 = 1, then the quadratic equation having roots 1/alpha and 1/beta is:

  1. (1) x^2 - x + 1 = 0
  2. (2) x^2 - x - 1 = 0
  3. (3) x^2 + x + 1 = 0
  4. (4) x^2 + x - 1 = 0

Answer

Correct answer: Option 4

Solution

From the recurrence relation P_n = (alpha + beta)P_(n-1) - (alpha*beta)P_(n-2), using P_0 = 123, P_1 = 76: 47 = 76*S - 123*P where S = alpha + beta and P = alpha*beta. From P_2 = 47: 47 = 76*S - 123*P. We get S = 1 and P = 1. The equation with roots alpha and beta is t^2 - t + 1 = 0. For roots 1/alpha and 1/beta: sum = 1/alpha + 1/beta = (alpha + beta)/(alpha*beta) = 1/1 = 1, product = 1/(alpha*beta) = 1. Equation: x^2 - x + 1 = 0
