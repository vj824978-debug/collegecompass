If a and b are real numbers such that (2 + α)^4 = a + bα, where α = (-1 + i*sqrt(3))/2, then a + b is equal to:

  1. (1) 9
  2. (2) 24
  3. (3) 57
  4. (4) 33

Answer

Correct answer: Option 1

Solution

α = ω ⇒ (2 + ω)^4 = a + bω (ω^3 = 1) ⇒ 2^4 + 4.2^3·ω + 6.2^2·ω^2 + 4.2.ω^3 + ω^4 = a + bω ⇒ 16 + 32·ω + 24·ω^2 + 8 + ω = a + bω ⇒ 24 + 24·ω^2 + 33·ω = a + bω ⇒ -24·ω + 33·ω = a + bω ⇒ a = 0, b = 9
