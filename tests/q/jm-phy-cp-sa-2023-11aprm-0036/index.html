A metallic surface is illuminated with radiation of wavelength λ, the stopping potential is V₀. If the same surface is illuminated with radiation of wavelength 2λ, the stopping potential becomes V₀/4. The threshold wavelength for this metallic surface will be:

  1. (1) 3λ
  2. (2) 4λ
  3. (3) (3/2)λ
  4. (4) λ/4

Answer

Correct answer: Option 1

Solution

Using photoelectric equation: V₀ = hc/λ₀ - φ for wavelength λ. For wavelength 2λ: V₀/4 = hc/(2λ₀) - φ. Subtracting: V₀ - V₀/4 = hc/λ₀ - hc/(2λ₀), which gives 3V₀/4 = hc/(2λ₀). From first equation: φ = hc/λ₀ - V₀. At threshold, stopping potential = 0, so hc/λ_th = φ = 3V₀/2. Since hc/λ₀ = 3V₀/2, we get λ_th = 2hc/(3V₀) = (1/2) × (2hc/3λ₀) × (λ/λ) = λ/3. Wait, recalculating: hc/λ_th = (1/2) × (2hc)/(3λ₀). Since hc/λ = 3V₀/2 from the algebra, λ_th = (3V₀/2) × (2/(hc/λ)) = 3λ.
