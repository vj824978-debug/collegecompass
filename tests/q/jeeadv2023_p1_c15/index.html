Match the electronic configurations in List-I with appropriate metal complex ions in List-II and choose the correct option. [Atomic Number: Fe = 26, Mn = 25, Co = 27] List-I: (P) t_{2g}^6 e_g^0 (Q) t_{2g}^5 e_g^2 (R) e^2 t_g^3 (S) t_{2g}^4 e_g^2 List-II: (1) [Fe(H₂O)₆]^3+ (2) [Mn(H₂O)₆]^2+ (3) [Co(NH₃)₆]^3+ (4) [FeCl₄]^- (5) [CoCl₄]^2-

Matrix match · Marks: +3 / -1.0

  1. (A) P → 1; Q → 4; R → 2; S → 3
  2. (B) P → 1; Q → 2; R → 4; S → 5
  3. (C) P → 3; Q → 2; R → 5; S → 1
  4. (D) P → 3; Q → 2; R → 4; S → 1

Answer

Correct answer: D

Solution

Sol.
