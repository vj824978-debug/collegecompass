Let R₁ = {(a, b) ∈ N × N : |a - b| ≤ 13} and R₂ = {(a, b) ∈ N × N : |a - b| ≠ 13}. Then on N:

  1. (1) Both R₁ and R₂ are equivalence relations
  2. (2) Neither R₁ nor R₂ is an equivalence relation
  3. (3) R₁ is an equivalence relation but R₂ is not
  4. (4) R₂ is an equivalence relation but R₁ is not

Answer

Correct answer: Option 2

Solution

For R₁: |2 - 11| = 9 ≤ 13, so (2, 11) ∈ R₁ and (11, 19) ∈ R₁ (since |11 - 19| = 8 ≤ 13), but |2 - 19| = 17 > 13, so (2, 19) ∉ R₁. Hence R₁ is not transitive and not equivalence. For R₂: (13, 3) ∈ R₂ and (3, 26) ∈ R₂, but |13 - 26| = 13, so (13, 26) ∉ R₂. Hence R₂ is not transitive and not equivalence. Therefore neither R₁ nor R₂ is an equivalence relation.
