In a single slit diffraction pattern, a light of wavelength 6000 A is used. The distance between the first and third minima in the diffraction pattern is found to be 3 mm when the screen is placed 50 cm away from slits. The width of the slit is __________ × 10^(-4) m.

Answer

Correct answer: 2

Solution

For single slit diffraction, minima occur at d sin(theta) = n*lambda. For small angles, sin(theta) ≈ tan(theta) = y/D, where y is distance on screen and D is distance to screen. For 1st minimum: y1 = lambda*D/d. For 3rd minimum: y3 = 3*lambda*D/d. Distance between 1st and 3rd minima: Delta(y) = y3 - y1 = 2*lambda*D/d = 3 mm. Given: lambda = 6000×10^(-10) m, D = 0.5 m. Solving: d = 2*lambda*D/Delta(y) = (2 × 6000×10^(-10) × 0.5)/(3×10^(-3)) = (6×10^(-7))/(3×10^(-3)) = 2×10^(-4) m
