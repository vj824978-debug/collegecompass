If the sum of the coefficients of all the positive powers of x, in the Binomial expansion of (x^n + 2/x^5)^7 is 939, then the sum of all the possible integral values of n is ___________.

Answer

Correct answer: 57

Solution

Expanding (x^n + 2/x^5)^7 = sum from r=0 to 7 of C(7,r) * 2^r * x^(7n-nr-5r). For positive powers of x, we need 7n - nr - 5r > 0, which gives 7n - r(n+5) > 0. The sum of coefficients of positive powers = C(7,0)*2^0 + C(7,1)*2^1 + C(7,2)*2^2 + C(7,3)*2^3 + C(7,4)*2^4 = 939. This gives r = 4. From 7n - nr - 5r = 0, we get 7n - 4n - 20 = 0, so 3n = 20 or n > 20/3. Also r should not be 5, so n < 25/2. Therefore 20/3 < n < 25/2, giving possible integer values n = 7, 8, 9, 10, 11, 12. Sum = 7 + 8 + 9 + 10 + 11 + 12 = 57.
