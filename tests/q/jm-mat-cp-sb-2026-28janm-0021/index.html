In a G.P., if the product of the first three terms is 27 and the set of all possible values for the sum of its first three terms is R - (a, b), then a^2 + b^2 is equal to ____.

Answer

Correct answer: 90

Solution

Let first three terms of G.P. are A/r, A, Ar (A/r) · A · Ar = 27 A^3 = 27 A = 3 Sum of first three terms = A/r + A + Ar = 3/r + 3 + 3r = 3(1/r + 1 + r) = 3 + 3(r + 1/r) We know, r + 1/r ≥ 2 or r + 1/r ≤ -2 Therefore, S ∈ R - (-3, 9) So a = -3 and b = 9 a^2 + b^2 = 9 + 81 = 90
