A source, approaching with speed u towards the open end of a stationary pipe of length L, is emitting a sound of frequency f_s. The farther end of the pipe is closed. The speed of sound in air is v and f_0 is the fundamental frequency of the pipe. For which of the following combination(s) of u and f_s, will the sound reaching the pipe lead to a resonance?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) u = 0.8v and f_s = f_0
  2. (B) u = 0.8v and f_s = 2f_0
  3. (C) u = 0.8v and f_s = 0.5f_0
  4. (D) u = 0.5v and f_s = 1.5f_0

Answer

Correct answer: AD

Solution

Natural frequency of closed pipe f = (2n + 1)f₀ f₀ is fundamental frequency n = 0, 1, 2, ......... frequency of source received by pipe f' = fₛ[v - 0]/[v - u] For resonance f' = f fₛ[v]/[v - u] = (2n + 1)f₀ If u = 0.8 v fₛ = f₀ f' = v/(0.2 v) · f₀ = 5f₀ for n = 2 pipe can be in resonance Hence, option (A) is correct. If u = 0.8v fₛ = 2f₀ f' = v/(0.2v) × 2f₀ = 10f₀ If u = 0.8 v, fₛ = 0.5 f₀ f' = v/(0.2v) × 0.5f₀ = 2.5f₀ Not possible If u = 0.5 v, fₛ = 1.5 f₀ f' = v/(0.5v) × 1.5f₀ = 3f₀ for n = 1 f = 3f₀ pipe can be in resonance Hence, option (D) is correct.
