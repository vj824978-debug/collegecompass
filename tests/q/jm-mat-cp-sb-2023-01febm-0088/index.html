Let A be the area bounded by the curve y = x|x - 3|, the x-axis and the ordinates x = -1 and x = 2. Then 12A is equal to ____.

Answer

Correct answer: 62

Solution

We need to find the area bounded by y = x|x - 3|, the x-axis, and the lines x = -1 and x = 2. First, analyze the function y = x|x - 3|: - When x < 3: |x - 3| = 3 - x, so y = x(3 - x) = 3x - x^2 - When x >= 3: |x - 3| = x - 3, so y = x(x - 3) = x^2 - 3x For the interval [-1, 2], we have x < 3, so y = 3x - x^2. However, we need to check where y changes sign: 3x - x^2 = 0 x(3 - x) = 0 x = 0 or x = 3 So on [-1, 0], y = 3x - x^2 < 0 (below x-axis) On [0, 2], y = 3x - x^2 > 0 (above x-axis) The area is: A = ∫_{-1}^{0} |3x - x^2| dx + ∫_{0}^{2} |3x - x^2| dx A = ∫_{-1}^{0} (x^2 - 3x) dx + ∫_{0}^{2} (3x - x^2) dx For the first integral: ∫_{-1}^{0} (x^2 - 3x) dx = [x^3/3 - 3x^2/2]_{-1}^{0} = 0 - ((-1)^3/3 - 3(-1)^2/2) = 0 - (-1/3 - 3/2) = 0 - (-1/3 - 3/2) = 1/3 + 3/2 = 2/6 + 9/6 = 11/6 For the second integral: ∫_{0}^{2} (3x - x^2) dx = [3x^2/2 - x^3/3]_{0}^{2} = (3(4)/2 - 8/3) - 0 = 6 - 8/3 = 18/3 - 8/3 = 10/3 Total area: A = 11/6 + 10/3 = 11/6 + 20/6 = 31/6 Therefore: 12A = 12 × 31/6 = 2 × 31 = 62
