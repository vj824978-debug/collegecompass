Increasing order of reactivity of the following compounds for SN1 substitution is: (A) (CH3)2CH-CH2-Cl (B) Cyclopropyl-CH2-Cl (C) 4-methoxybenzyl chloride (p-CH3O-C6H4-CH2-Cl) (D) Benzyl chloride (C6H5-CH2-Cl)

  1. (1) (A) < (B) < (D) < (C)
  2. (2) (B) < (C) < (D) < (A)
  3. (3) (B) < (C) < (A) < (D)
  4. (4) (B) < (A) < (D) < (C)

Answer

Correct answer: Option 4

Solution

For SN1 substitution, the rate of reaction depends on the stability of the carbocation formed. The order of reactivity is inversely proportional to the stability of the carbocation formed. Analyzing each compound: (A) (CH3)2CH-CH2-Cl: Forms a primary carbocation (CH3)2CH-CH2(+). This is a primary carbocation with some hyperconjugation from adjacent CH groups. (B) Cyclopropyl-CH2-Cl: Forms a primary carbocation attached to a cyclopropyl ring. The cyclopropyl group is electron-withdrawing due to ring strain, making this carbocation relatively unstable. (C) p-CH3O-C6H4-CH2-Cl: Forms a benzyl carbocation with an electron-donating methoxy group (-OCH3) in the para position. The methoxy group donates electron density through resonance and inductive effects, stabilizing the carbocation significantly. (D) C6H5-CH2-Cl: Forms a benzyl carbocation. The phenyl ring provides resonance stabilization through the aromatic pi system, making it relatively stable. Order of carbocation stability: Cyclopropylmethyl < Primary alkyl < Benzyl < p-Methoxybenzyl Therefore: B < A < D < C Since SN1 reactivity is inversely proportional to carbocation stability, the order of reactivity (from least to most) is: B < A < D < C
