Let A = [a_ij] be a square matrix of order 2 with entries either 0 or 1. Let E be the event that A is an invertible matrix. Then the probability P(E) is:

  1. (1) 5/8
  2. (2) 3/16
  3. (3) 1/8
  4. (4) 3/8

Answer

Correct answer: Option 4

Solution

For a 2×2 matrix A to be invertible, its determinant must be non-zero. Total possible 2×2 matrices with entries 0 or 1: 2^4 = 16 ways For invertibility, det(A) ≠ 0 Case I: Matrices of form [1 1; 0 1] det = 1(1) - 1(0) = 1 ≠ 0 Number of such matrices: 4 ways (considering all positions) Case II: Matrices [1 0; 0 1] and [0 1; 1 0] For [1 0; 0 1]: det = 1(1) - 0(0) = 1 ≠ 0 For [0 1; 1 0]: det = 0(0) - 1(1) = -1 ≠ 0 Number of such matrices: 2 ways Total favourable outcomes = 6 (from both cases) P(E) = favourable/total = 6/16 = 3/8
