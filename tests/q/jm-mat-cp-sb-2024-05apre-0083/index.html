The number of solutions of sin²x + (2 + 2x - x²)sinx - 3(x - 1)² = 0, where -π ≤ x ≤ π, is

Answer

Correct answer: 2

Solution

Rearrange the equation as: sin²x - (x² - 2x - 2)sinx - 3(x - 1)² = 0. This factors as: [sinx + 3][sinx - (x - 1)²] = 0. Since sinx = -3 is impossible (sinx must be in [-1, 1]), we need sinx = (x - 1)². The equation sinx = (x - 1)² is solved graphically by finding intersections between the sine curve and the parabola y = (x - 1)² centered at (1, 0). In the interval [-π, π], there are exactly 2 intersection points.
