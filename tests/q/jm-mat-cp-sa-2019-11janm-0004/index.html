The sum of an infinite geometric series with positive terms is 3 and the sum of the cubes of its terms is 27/19. Then the common ratio of this series is:

  1. (1) 4/9
  2. (2) 1/3
  3. (3) 2/3
  4. (4) 2/9

Answer

Correct answer: Option 3

Solution

Let the first term be a and common ratio be r where |r| < 1. Given: a/(1-r) = 3 For the series a, ar, ar^2, ar^3, ..., the cubes are a^3, a^3r^3, a^3r^6, a^3r^9, ... This is a geometric series with first term a^3 and common ratio r^3. Sum of cubes: a^3/(1-r^3) = 27/19 From first equation: a = 3(1-r) Substituting into second equation: [3(1-r)]^3/(1-r^3) = 27/19 27(1-r)^3/(1-r^3) = 27/19 (1-r)^3/(1-r^3) = 1/19 19(1-r)^3 = 1-r^3 19(1-r)^3 = (1-r)(1+r+r^2) Dividing both sides by (1-r) where r ≠ 1: 19(1-r)^2 = 1+r+r^2 19(1-2r+r^2) = 1+r+r^2 19-38r+19r^2 = 1+r+r^2 18r^2-39r+18 = 0 6r^2-13r+6 = 0 Using quadratic formula or factoring: (2r-3)(3r-2) = 0 r = 3/2 or r = 2/3 Since |r| < 1, we have r = 2/3
