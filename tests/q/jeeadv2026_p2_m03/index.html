Let y : (−∞, ∞) → (0, ∞) be the solution of the differential equation dy/dx = (e^(5x)y³ + y³)/(eˣ + e²ˣy⁴) satisfying y(0) = 1/√2. Then the value of y(log₈ 2) is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) √[(5 + √35)/2]
  2. (B) √[(7 + √53)/2]
  3. (C) (7 + √53)/2
  4. (D) (5 + √35)/2

Answer

Correct answer: B

Solution

Solution: The given differential equation is dy/dx = (e^(2y)y³ + y³)/(e^x + e^(y)4) Factoring the numerator and denominator, we get dy/dx = y³(e^(2y) + 1)/(e^x(1 + y⁴)) Separating the variables y and dy, we obtain (1 + y⁴)/y³ dy = (e^(2x) + 1)/e^x dx (1/y³ + y) dy = (e^x + e^(-x))dx Integrating both sides yields ∫(y^(-3) + y) dy = ∫(e^x + e^(-x))dx -1/(2y²) + y²/2 = e^x/4 - e^(-x) + C Multiplying by 2, we get y² - 1/y² = e^(4x)/2 - 2e^(-x) + 2C Using the initial condition y(0) = 1/√2, we substitute x = 0 and y = 1/√2: (1/√2)² - 1/(1/√2)² = e⁰/2 - 2e⁰ + 2C 1/2 - 2 = 1/2 - 2e⁰ + 2C 1/2 - 2 = 1/2 - 2 + 2C This gives 2C = 0, so C = 0. The equation becomes y² - 1/y² = e^(4x)/2 - 2e^(-x) To find y(log₂ 2), we substitute x = log₂ 2 into the equation. We have e^x = e^(log₂ 2) = 16 and e^(-x) = e^(-log₂ 2) = 1/2. y² - 1/y² = 16/2 - 2(1/2) y² - 1/y² = 8 - 1 = 7 Let y² = t. Since y ∈ (0, ∞), t > 0. t - 1/t = 7 t² - 7t - 1 = 0 Solving for t using the quadratic formula gives t = (7 ± √(49 - 4(1)(-1)))/2 = (7 ± √53)/2 Since t = y² > 0, we must choose the positive root: y² = (7 + √53)/2 Taking the positive square root since y > 0, we get y = √((7 + √53)/2)
