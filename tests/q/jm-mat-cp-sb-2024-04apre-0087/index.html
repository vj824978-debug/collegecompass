In a tournament, a team plays 10 matches with probabilities of winning and losing each match as 1/3 and 2/3 respectively. Let x be the number of matches that the team wins, and y be the number of matches that team loses. If the probability P(|x - y| ≤ 2) is p, then 3^9 p equals......

Answer

Correct answer: 8288

Solution

Given: P(W) = 1/3, P(L) = 2/3, x + y = 10, |x - y| ≤ 2 means |x - y| = 0, 1, or 2. Case-I: |x - y| = 0 → x = y = 5. P(|x - y| = 0) = C(10,5) * (1/3)^5 * (2/3)^5. Case-III: |x - y| = 2 → x = 6, y = 4 or x = 4, y = 6. P(|x - y| = 2) = C(10,6) * (1/3)^6 * (2/3)^4 + C(10,4) * (1/3)^4 * (2/3)^6. Total: p = C(10,5) * 2^5/3^10 + C(10,6) * 2^4/3^10 + C(10,4) * 2^6/3^10. Therefore: 3^9 * p = (1/3)[C(10,5) * 2^5 + C(10,6) * 2^4 + C(10,4) * 2^6] = 8288
