Let A = [a_ij] be a 3 × 3 matrix such that A[1, 0, 0]^T = [0, 1, 1]^T, A[1, 1, 0]^T = [1, 0, 0]^T and A[1, 1, 2]^T = [0, 0, 0]^T, then a_23 equals:

  1. (1) -1
  2. (2) 0
  3. (3) 2
  4. (4) 1

Answer

Correct answer: Option 1

Solution

Let A = [a_11 a_12 a_13] [a_21 a_22 a_23] [a_31 a_32 a_33] From A[1, 0, 0]^T = [0, 1, 1]^T: [a_12] [0] [a_22] = [0] ⟹ a_22 = 0; a_12 = 0 [a_32] [1] a_32 = 1 From A[1, 1, 3]^T = [1, 0, 0]^T: [4a_11 + a_12 + 3a_13] [0] [4a_21 + a_22 + 3a_23] = [1] ⟹ 4a_21 + 3a_23 = 1 ...(1) [4a_31 + a_32 + 3a_33] [0] From A[2, 1, 2]^T = [1, 0, 0]^T: [2a_11 + a_12 + 2a_13] [1] [2a_21 + a_22 + 2a_23] = [0] ⟹ 2a_21 + a_23 = 0 ...(2) [2a_31 + a_32 + 2a_33] [0] Solve (1) & (2): From (2): a_21 = -a_23/2 Substitute into (1): 4(-a_23/2) + 3a_23 = 1 -2a_23 + 3a_23 = 1 a_23 = -1
