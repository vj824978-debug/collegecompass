Let p, q ∈ R. If 2 - sqrt(3) is a root of the quadratic equation, x^2 + px + q = 0, then:

  1. (1) p^2 - 4q + 12 = 0
  2. (2) q^2 - 4p - 16 = 0
  3. (3) q^2 + 4p + 14 = 0
  4. (4) p^2 - 4q - 12 = 0

Answer

Correct answer: Option 4

Solution

If one root of equation x^2 + px + q = 0 is 2 - sqrt(3) then other root will be 2 + sqrt(3) ∴ equation x^2 - 4x + 1 = 0 ⇒ p = -4 and q = 1 ⇒ p^2 - 4q - 12 = 0
