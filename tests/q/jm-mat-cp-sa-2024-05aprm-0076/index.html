If 1/(sqrt(1)+sqrt(2)) + 1/(sqrt(2)+sqrt(3)) + ... + 1/(sqrt(99)+sqrt(100)) = m and 1/(1·2) + 1/(2·3) + ... + 1/(99·100) = n, then the point (m, n) lies on the line

  1. (1) 11(x - 1) - 100(y - 2) = 0
  2. (2) 11(x - 2) - 100(y - 1) = 0
  3. (3) 11(x - 1) - 100y = 0
  4. (4) 11x - 100y = 0

Answer

Correct answer: Option 4

Solution

For m: Rationalize each term: 1/(sqrt(k)+sqrt(k+1)) = (sqrt(k+1)-sqrt(k))/((k+1)-k) = sqrt(k+1)-sqrt(k). Sum telescopes: (sqrt(2)-sqrt(1)) + (sqrt(3)-sqrt(2)) + ... + (sqrt(100)-sqrt(99)) = sqrt(100)-1 = 10-1 = 9. So m = 9. For n: Use partial fractions: 1/(k(k+1)) = 1/k - 1/(k+1). Sum telescopes: (1/1 - 1/2) + (1/2 - 1/3) + ... + (1/99 - 1/100) = 1 - 1/100 = 99/100. So n = 99/100. Point (m,n) = (9, 99/100). Check option (4): 11(9) - 100(99/100) = 99 - 99 = 0. ✓
