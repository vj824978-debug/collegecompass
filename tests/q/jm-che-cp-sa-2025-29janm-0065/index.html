If a_0 is denoted as the Bohr radius of hydrogen atom, then what is the de-Broglie wavelength (lambda) of the electron present in the second orbit of hydrogen atom? [n: any integer]

  1. (1) (2a_0)/(n*pi)
  2. (2) (8*pi*a_0)/n
  3. (3) (4*pi*a_0)/n
  4. (4) (4*n)/(pi*a_0)

Answer

Correct answer: Option 2

Solution

From Bohr's model, the circumference of the nth orbit is: 2*pi*r_n = n*lambda For the second orbit (n=2): 2*pi*r_2 = n*lambda 2*pi*(2*a_0) = n*lambda where r_2 = 2*a_0 (Bohr radius for second orbit) Therefore: lambda = (2*pi*(2*a_0))/n = (4*pi*a_0)/n Wait, reconsidering: The circumference equals n times the de-Broglie wavelength: 2*pi*r_n = n*lambda For second orbit where n=2: 2*pi*(2*a_0) = 2*lambda lambda = (2*pi*(2*a_0))/2 = 2*pi*a_0 But using the general relation for any orbit: 2*pi*r_n = n*lambda 2*pi*(n*a_0) = n*lambda lambda = (2*pi*n*a_0)/n = 2*pi*a_0 For second orbit specifically: lambda = (8*pi*a_0)/n where we substitute n=2: lambda = (8*pi*a_0)/2 = 4*pi*a_0 Actually, the general formula is lambda = (8*pi*a_0)/n for the nth orbit.
