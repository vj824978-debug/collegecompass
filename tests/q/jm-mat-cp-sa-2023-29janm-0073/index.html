A light ray emits from the origin making an angle 30° with the positive x-axis. After getting reflected by the line x + y = 1, if this ray intersects x-axis at Q, then the abscissa of Q is

  1. (1) 2/(3 - sqrt(3))
  2. (2) 2/(3 + sqrt(3))
  3. (3) sqrt(3)/(2(sqrt(3) + 1))
  4. (4) 2/(sqrt(3) - 1)

Answer

Correct answer: Option 2

Solution

Let Q(h, 0) be the point where the reflected ray intersects the x-axis. The incident ray from origin O makes an angle 30° with positive x-axis, so its equation is: y = x/sqrt(3) Since OP is reflected by x + y = 1, the image of Q lies on y = x/sqrt(3). For reflection of point Q(h, 0) across the line x + y = 1: Using the reflection formula, if Q reflects to Q', then: (x - h)/1 = y/1 = -2(h - 1)/2 Therefore: x = 1, y = 1 - h Since the image of Q lies on y = x/sqrt(3): 1 - h = 1/sqrt(3) Solving for h: h = 1 - 1/sqrt(3) h = (sqrt(3) - 1)/sqrt(3) h = (sqrt(3) - 1)/sqrt(3) × sqrt(3)/sqrt(3) h = (3 - sqrt(3))/3 Rationalizing: h = (sqrt(3) - 1) × sqrt(3)/3 = (3 - sqrt(3))/3 Multiplying numerator and denominator by appropriate terms: h = 2/(3 + sqrt(3)) Option (2) is correct.
