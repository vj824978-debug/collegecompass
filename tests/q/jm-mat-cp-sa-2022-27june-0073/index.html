Let the foot of the perpendicular from the point (1, 2, 4) on the line (x+2)/4 = (y-1)/2 = (z+1)/3 be P. Then the distance of P from the plane 3x + 4y + 12z + 23 = 0 is-

  1. (1) 5
  2. (2) 50/13
  3. (3) 4
  4. (4) 63/13

Answer

Correct answer: Option 1

Solution

Line L: (x+2)/4 = (y-1)/2 = (z+1)/3 = t. So any point on line is P = (4t-2, 2t+1, 3t-1). Since P is foot of perpendicular from (1,2,4), the vector from P to (1,2,4) must be perpendicular to direction vector (4,2,3) of line. So 4(4t-3) + 2(2t-1) + 3(3t-5) = 0. Solving: 16t-12+4t-2+9t-15=0, 29t=29, t=1. Therefore P = (2, 3, 2). Distance from plane 3x+4y+12z+23=0 is |3(2)+4(3)+12(2)+23|/sqrt(9+16+144) = |6+12+24+23|/sqrt(169) = 65/13 = 5.
