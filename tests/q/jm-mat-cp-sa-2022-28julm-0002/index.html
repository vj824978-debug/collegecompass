Considering only the principal values of the inverse trigonometric functions, the domain of the function f(x) = cos^(-1)((x^2 - 4x + 2)/(x^2 + 3)) is

  1. (1) (-∞, 1/4]
  2. (2) [-1/4, ∞)
  3. (3) (-1/3, ∞)
  4. (4) (-∞, 1/3]

Answer

Correct answer: Option 2

Solution

For cos^(-1) to be defined, we need -1 ≤ (x^2 - 4x + 2)/(x^2 + 3) ≤ 1. Left inequality: -1 ≤ (x^2 - 4x + 2)/(x^2 + 3) gives -3 ≤ x^2 - 4x + 2, so 2x^2 - 4x + 5 ≥ 0, which is always true. Right inequality: (x^2 - 4x + 2)/(x^2 + 3) ≤ 1 gives x^2 - 4x + 2 ≤ x^2 + 3, so -4x ≤ 1, thus x ≥ -1/4. Domain is [-1/4, ∞).
