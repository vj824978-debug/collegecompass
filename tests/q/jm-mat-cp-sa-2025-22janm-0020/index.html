Let the foci of a hyperbola be (1, 14) and (1, -12). If it passes through the point (1, 6), then the length of its latus-rectum is:

  1. (1) 25/6
  2. (2) 24/5
  3. (3) 288/5
  4. (4) 144/5

Answer

Correct answer: Option 3

Solution

The foci are F1 = (1, 14) and F2 = (1, -12). The center of the hyperbola is the midpoint of the foci: Center = ((1+1)/2, (14-12)/2) = (1, 1) Since the foci lie on a vertical line (x = 1), this is a vertical hyperbola with vertical transverse axis. The distance between foci is: 2c = |14 - (-12)| = 26 So c = 13 For a point (1, 6) on the hyperbola: Distance from (1, 6) to F1(1, 14) = |14 - 6| = 8 Distance from (1, 6) to F2(1, -12) = |6 - (-12)| = 18 By the definition of hyperbola: |d1 - d2| = 2a |8 - 18| = 2a 10 = 2a a = 5 Using the relation c^2 = a^2 + b^2 for a hyperbola: 13^2 = 5^2 + b^2 169 = 25 + b^2 b^2 = 144 b = 12 Alternatively: a^2 = b^2(c^2 - 1) = b^2 * c^2 - b^2 = 169 - 25 = 144 The length of the latus-rectum is: l(LR) = 2a^2/b = (2 × 144)/5 = 288/5
