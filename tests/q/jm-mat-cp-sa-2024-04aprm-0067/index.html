If the system of equations x + (sqrt(2) sin alpha)y + (sqrt(2) cos alpha)z = 0, x + (cos alpha)y + (sin alpha)z = 0, x + (sin alpha)y - (cos alpha)z = 0 has a non-trivial solution, then alpha in (0, pi/2) is equal to-

  1. (1) 3pi/4
  2. (2) 7pi/24
  3. (3) 5pi/24
  4. (4) 11pi/24

Answer

Correct answer: Option 3

Solution

For non-trivial solution, determinant of coefficient matrix = 0. Setting up determinant: |1, sqrt(2) sin alpha, sqrt(2) cos alpha; 1, sin alpha, -cos alpha; 1, cos alpha, sin alpha| = 0. Expanding: 1 - sqrt(2) sin alpha(sin alpha + cos alpha) + sqrt(2) cos alpha(cos alpha - sin alpha) = 0. Simplifying: 1 + sqrt(2) cos 2alpha - sqrt(2) sin 2alpha = 0. This gives: cos 2alpha - sin 2alpha = -1/sqrt(2). Converting to: cos(2alpha + pi/4) = -1/2. Solving: 2alpha + pi/4 = 2n*pi ± 2pi/3. For n = 0: alpha = pi/3 - pi/8 = 5pi/24
