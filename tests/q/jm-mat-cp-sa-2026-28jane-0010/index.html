Let the ellipse E: x^2/144 + y^2/169 = 1 and the hyperbola H: x^2/16 - y^2/lambda^2 = -1 have the same foci. If e and L respectively denote the eccentricity and the length of the latus rectum of H, then the value of 24(e + L) is:

  1. (1) 296
  2. (2) 126
  3. (3) 148
  4. (4) 67

Answer

Correct answer: Option 1

Solution

Equation of hyperbola: y^2/lambda^2 - x^2/16 = 1 Equation of ellipse: x^2/144 + y^2/169 = 1 e' = sqrt(1 - 144/169) = 5/13 focus => (0, ±5) → Taking (0, 5) => lambda * sqrt(1 + 16/lambda^2) = 5 => lambda^2 + 16 = 25 => lambda = 3 Eccentricity of hyperbola = sqrt(1 + 16/lambda^2) = sqrt(1 + 16/9) = 5/3 Length of latus rectum of hyperbola = 2(16)/3 = 32/3 24(e + L) = 24[5/3 + 32/3] = 8 × 37 = 296
