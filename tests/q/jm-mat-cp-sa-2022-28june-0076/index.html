Let the plane ax + by + cz = d pass through (2, 3, -5) and is perpendicular to the planes 2x + y - 5z = 10 and 3x + 5y - 7z = 12. If a, b, c, d are integers d > 0 and gcd(|a|, |b|, |c|, |d|) = 1, then the value of a + 7b + c + 20d is equal to:

  1. (1) 18
  2. (2) 20
  3. (3) 24
  4. (4) 22

Answer

Correct answer: Option 4

Solution

Find normal vector perpendicular to both given planes using cross product of (2, 1, -5) and (3, 5, -7). Computing: (2, 1, -5) × (3, 5, -7) = (18, -1, 7). Since plane passes through (2, 3, -5): 18(2) - 1(3) + 7(-5) = 36 - 3 - 35 = -2. So equation is 18x - y + 7z = -2 or -18x + y - 7z = 2. With d > 0: -18x + y - 7z = 2. Thus a = -18, b = 1, c = -7, d = 2. gcd(18, 1, 7, 2) = 1. Therefore a + 7b + c + 20d = -18 + 7(1) + (-7) + 20(2) = -18 + 7 - 7 + 40 = 22.
