Let A = {(x, y) ∈ R × R : |x + y| ≥ 3} and B = {(x, y) ∈ R × R : |x| + |y| ≤ 3}. If C = {(x, y) ∈ A ∩ B : x = 0 or y = 0}, then ∑(x,y)∈C |x + y| is

  1. (1) 15
  2. (2) 18
  3. (3) 24
  4. (4) 12

Answer

Correct answer: Option 4

Solution

First, we need to find set C = {(x, y) ∈ A ∩ B : x = 0 or y = 0} Set A: |x + y| ≥ 3 means x + y ≥ 3 or x + y ≤ -3 Set B: |x| + |y| ≤ 3 For points where x = 0: - From B: |0| + |y| ≤ 3 ⟹ |y| ≤ 3 ⟹ -3 ≤ y ≤ 3 - From A: |0 + y| ≥ 3 ⟹ |y| ≥ 3 ⟹ y ≤ -3 or y ≥ 3 - Combined: y = 3 or y = -3 - Points: (0, 3) and (0, -3) For points where y = 0: - From B: |x| + |0| ≤ 3 ⟹ |x| ≤ 3 ⟹ -3 ≤ x ≤ 3 - From A: |x + 0| ≥ 3 ⟹ |x| ≥ 3 ⟹ x ≤ -3 or x ≥ 3 - Combined: x = 3 or x = -3 - Points: (3, 0) and (-3, 0) Therefore: C = {(3, 0), (-3, 0), (0, 3), (0, -3)} Now calculate ∑(x,y)∈C |x + y|: - For (3, 0): |3 + 0| = 3 - For (-3, 0): |-3 + 0| = 3 - For (0, 3): |0 + 3| = 3 - For (0, -3): |0 + (-3)| = 3 ∑|x + y| = 3 + 3 + 3 + 3 = 12
