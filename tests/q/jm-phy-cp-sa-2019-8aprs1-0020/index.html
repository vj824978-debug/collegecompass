A circular coil having N turns and radius r carries a current I. It is held in the XZ plane in a magnetic field B i. The torque on the coil due to the magnetic field is -

  1. (1) B pi r^2 I / N
  2. (2) Zero
  3. (3) B pi r^2 I N
  4. (4) B r^2 I / (pi N)

Answer

Correct answer: Option 3

Solution

tau = N I A B sin(theta) Where: - N = number of turns - I = current - A = pi r^2 (area of circular coil) - B = magnetic field - theta = angle between normal to the coil plane and magnetic field direction The coil is held in the XZ plane and the magnetic field is along the y-direction (B i means B in the y-direction). The normal to the XZ plane is along the y-direction. Therefore, the angle between the normal and the magnetic field is theta = 90° sin(90°) = 1 tau = N I (pi r^2) B sin(90°) = N I pi r^2 B (1) = B pi r^2 I N
