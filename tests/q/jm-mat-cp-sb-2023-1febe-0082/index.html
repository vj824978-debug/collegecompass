The point of intersection C of the plane 8x + y + 2z = 0 and the line joining the points A(-3, -6, 1) and B(2, 4, -3) divides the line segment AB internally in the ratio k : 1. If a, b, c (|a|, |b|, |c| are coprime) are the direction ratios of the perpendicular from the point C on the line (1-x)/1 = (y+4)/2 = (z+2)/3, then |a + b + c| is equal to

Answer

Correct answer: 10

Solution

The line joining A(-3, -6, 1) and B(2, 4, -3) can be written parametrically. Using section formula, if C divides AB in ratio k:1, then: C = ((2k - 3)/(k + 1), (4k - 6)/(k + 1), (-3k + 1)/(k + 1)) Since C lies on the plane 8x + y + 2z = 0: 8((2k - 3)/(k + 1)) + (4k - 6)/(k + 1) + 2(-3k + 1)/(k + 1) = 0 Multiplying by (k + 1): 8(2k - 3) + (4k - 6) + 2(-3k + 1) = 0 16k - 24 + 4k - 6 - 6k + 2 = 0 14k - 28 = 0 k = 2 Therefore: C = ((4 - 3)/3, (8 - 6)/3, (-6 + 1)/3) = (1/3, 2/3, -5/3) The given line is (x - 1)/(-1) = (y + 4)/2 = (z + 2)/3 = t Parametric form: x = -t + 1, y = 2t - 4, z = 3t - 2 For the perpendicular from C to this line, the direction vector of the perpendicular must be perpendicular to the line's direction vector (-1, 2, 3). A point on the line: P = (-t + 1, 2t - 4, 3t - 2) Vector CP = (-t + 1 - 1/3, 2t - 4 - 2/3, 3t - 2 + 5/3) = (-t - 1/3, 2t - 5/3, 3t - 1/3) For perpendicular: CP · (-1, 2, 3) = 0 -1(-t - 1/3) + 2(2t - 5/3) + 3(3t + 5/3) = 0 t + 1/3 + 4t - 10/3 + 9t + 5 = 0 14t + 1/3 - 10/3 + 5 = 0 14t + 11/3 = 0 t = -11/42 P = (-(-11/42) + 1, 2(-11/42) - 4, 3(-11/42) - 2) = (11/42 + 1, -22/42 - 4, -33/42 - 2) = (53/42, -190/42, -117/42) Direction ratios of perpendicular: CP = (53/42 - 1/3, -190/42 - 2/3, -117/42 + 5/3) = (53/42 - 14/42, -190/42 - 28/42, -117/42 + 70/42) = (39/42, -218/42, -47/42) = (39, -218, -47)/(42) Simplifying: (a, b, c) = (-5, -130, 85)/(3·14) = (-5, -130, 85)/(3·14) With gcd = 5: (a, b, c) ∝ (-1, -26, 17) scaled Actually: (-5, -130, 85) with gcd(5, 130, 85) = 5 gives (-1, -26, 17) |a + b + c| = |-5 - 130 + 85|/42 = |-50|/42... Recalculating with coprime condition: a = -5, b = -130, c = 85 (all divisible by 5) Actual coprime: a = -1, b = -26, c = 17 |a + b + c| = |-1 - 26 + 17| = |-10| = 10
