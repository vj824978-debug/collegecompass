Let α be a positive real number. Let f: R → R and g: [α, ∞) → R be the functions defined by f(x) = sin(πx/12) and g(x) = 2*log_e(sqrt(x) - sqrt(α)) / log_e(e^sqrt(x) - e^sqrt(α)). Then the value of lim_{x→α^+} f(g(x)) is ________.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 0.5

Solution

lim f(g(x)) = f(lim g(x)) x→a x→a Now lim g(x) = lim [2ln(√x - √a) / ln(e^√x - e^√a)] = (-∞/-∞) x→a x→a Apply D'L Hospital lim + [2 · 1/(√x - √a) · 1/(2√x)] / [1/(e^√x - e^√a) · e^√x · 1/(2√x)] x→a = lim [2(e^√x - e^√a)] / [e^√x(√x - √a)] x→a = lim [2e^√a(e^(√x-√a) - 1)] / [e^√x(√x - √a)] = 2 x→a Now f(x) = sin(πx/12) given f(2) = sin(π(2)/12) = sin(π/6) = 1/2 = 0.5
