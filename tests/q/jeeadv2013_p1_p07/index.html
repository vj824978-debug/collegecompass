In the Young's double slit experiment using a monochromatic light of wavelength λ, the path difference (in terms of an integer n) corresponding to any point having half the peak intensity is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) (2n + 1)λ/2
  2. (B) (2n + 1)λ/4
  3. (C) (2n + 1)λ/8
  4. (D) (2n + 1)λ/16

Answer

Correct answer: B

Solution

Sol. (B) I_max/2 = I_m cos²(φ/2) ⟹ cos(φ/2) = 1/√2 ⟹ φ/2 = π/4 ⟹ φ = (π/2)(2n+1) ⟹ Δx = (λ/2π)φ = (λ/2π) × (π/2)(2n+1) = (λ/4)(2n+1)
