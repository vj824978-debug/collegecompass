Let α, β(α > β) be the roots of the quadratic equation x^2 - x - 4 = 0. If P_n = α^n - β^n, n ∈ N, then (P_15*P_16 - P_14*P_16 - P_15^2 + P_14*P_15)/(P_13*P_14) is equal to ____.

Answer

Correct answer: 16

Solution

Given P_n = α^n - β^n. From x^2 - x - 4 = 0, we have α + β = 1 and αβ = -4. Using the recurrence relation P_n - P_(n-1) = (α^n - β^n) - (α^(n-1) - β^(n-1)) = α^(n-2)(α^2 - α) - β^(n-2)(β^2 - β) = 4(α^(n-2) - β^(n-2)) = 4P_(n-2). So P_n - P_(n-1) = 4P_(n-2). The numerator simplifies to P_16(P_15 - P_14) - P_15(P_15 - P_14) = (P_15 - P_14)(P_16 - P_15) = (4P_13)(4P_14) = 16P_13*P_14. Therefore the expression equals 16P_13*P_14 / (P_13*P_14) = 16.
