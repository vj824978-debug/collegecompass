Consider the function f: R → R defined by f(x) = 2x/sqrt(1+9x^2). If the composition of f, (f o f o f o...o f)(x) = 2^10 x/sqrt(1+9ax^2) (10 times), then the value of sqrt(3a+1) is equal to......

Answer

Correct answer: 1024

Solution

First find pattern of compositions: f(f(x)) = 4x/sqrt(1+9x^2+9·2^2·x^2). Observing the pattern, after 10 compositions: f^(10)(x) = 2^10·x/sqrt(1+9a·x^2) where a = 1+2^2+2^4+...+2^18 = (2^20-1)/(2^2-1) = (2^20-1)/3. Therefore 3a+1 = 2^20, so sqrt(3a+1) = 2^10 = 1024.
