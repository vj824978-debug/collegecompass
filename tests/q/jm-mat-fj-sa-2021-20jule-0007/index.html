Let P be a variable point on the parabola y = 4x^2 + 1. Then, the locus of the mid-point of the point P and the foot of the perpendicular drawn from the point P to the line y = x is:

  1. (1) 2(x - 3y)^2 + (3x - y) + 2 = 0
  2. (2) (3x - y)^2 + (x - 3y) + 2 = 0
  3. (3) 2(3x - y)^2 + (x - 3y) + 2 = 0
  4. (4) (3x - y)^2 + 2(x - 3y) + 2 = 0

Answer

Correct answer: Option 3

Solution

Let P(a, 4a^2 + 1) be a point on the parabola y = 4x^2 + 1. The foot of perpendicular from P to line y = x is Q. Since PQ is perpendicular to y = x, the foot Q lies on y = x such that midpoint of PQ is R(h,k). Using perpendicularity condition and midpoint formula: h = (4a^2 + a + 1)/2 and k = (4a^2 + 1 + a)/2. Eliminating a from these equations yields: 2(3x - y)^2 + (x - 3y) + 2 = 0
