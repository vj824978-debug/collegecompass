Let α, β be the roots of the equation x^2 - ax - b = 0 with Im(α) < Im(β). Let P_n = α^n - β^n. If P_3 = -5√7 i, P_4 = -3√7 i, P_5 = 11√7 i and P_6 = 45√7 i, then |α^4 + β^4| is equal to ___.

Answer

Correct answer: 31

Solution

α + β = a, αβ = -b P_6 = aP_5 + bP_4 45√7 i = a × 11√7 i + b(-3√7 i) 45 = 11a - 3b ... (1) P_5 = aP_4 + bP_3 11√7 i = a(-3√7 i) + b(-5√7 i) 11 = -3a - 5b ... (2) From equations (1) and (2): Multiplying (2) by 11/3: (11/3)(11) = (11/3)(-3a - 5b) Solving the system: a = 3, b = -4 Now, |α^4 + β^4| = √[(α^4 - β^4)^2 + 4α^4β^4] = √[(α^4 - β^4)^2 + 4(αβ)^4] = √[(-63)^2 + 4(-4)^4] = √[3969 + 4.256] = √[-63 + 4.4^4] = √[-63 + 2024] = √961 = 31
