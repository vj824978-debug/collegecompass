Given below are two statements: Statement I: The number of pairs, from the following, in which both the ions are coloured in aqueous solution is 3. [Sc^(3+), Ti^(3+)], [Mn^(2+), Cr^(2+)], [Cu^(2+), Zn^(2+)] and [Ni^(2+), Ti^(4+)] Statement II: Th^(4+) is the strongest reducing agent among Th^(4+), Ce^(4+), Gd^(3+) and Eu^(2+). In the light of the above statements, choose the correct answer from the options given below

  1. (1) Statement I is true but Statement II is false
  2. (2) Statement I is false but Statement II is true
  3. (3) Both Statement I and Statement II are false
  4. (4) Both Statement I and Statement II are true

Answer

Correct answer: Option 3

Solution

Sc^(3+), Ti^(4+) and Zn^(2+) are colourless Ti^(3+) is coloured (d^1 configuration) Mn^(2+) is coloured (d^5 configuration) Cr^(2+) is coloured (d^4 configuration) Cu^(2+) is coloured (d^9 configuration) Ni^(2+) is coloured (d^8 configuration) Pairs with both ions coloured: [Mn^(2+), Cr^(2+)] - both coloured [Cu^(2+), Zn^(2+)] - only Cu^(2+) is coloured [Ni^(2+), Ti^(4+)] - only Ni^(2+) is coloured [Sc^(3+), Ti^(3+)] - only Ti^(3+) is coloured Only 1 pair has both ions coloured, not 3. So Statement I is FALSE. Th^(4+) cannot act as a reducing agent because Th is in +4 oxidation state (its highest stable state). A reducing agent needs to be oxidized to a higher state. Th^(4+) cannot be further oxidized. Ce^(4+), Gd^(3+), and Eu^(2+) can act as reducing agents: - Eu^(2+) can be oxidized to Eu^(3+) (strong reducing agent) - Ce^(4+) cannot be further oxidized - Gd^(3+) is stable and not a strong reducing agent Th^(4+) is NOT a reducing agent. So Statement II is FALSE. Both statements are false.
