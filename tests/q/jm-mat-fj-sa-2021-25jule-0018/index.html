If f(x) = integral from 0 to x of (5 + |1-t|)dt, x > 2 and f(x) = 5x + 1, x <= 2, then

  1. (1) f(x) is not continuous at x = 2
  2. (2) f(x) is not differentiable at x = 1
  3. (3) f(x) is continuous but not differentiable at x = 2
  4. (4) f(x) is everywhere differentiable

Answer

Correct answer: Option 3

Solution

For x > 2: Evaluate integral of (5 + |1-t|)dt from 0 to x. Split into two parts based on |1-t|. For t <= 1, |1-t| = 1-t; for t > 1, |1-t| = t-1. Integral from 0 to 1 of (5 + 1-t)dt plus integral from 1 to x of (5 + t-1)dt equals 6 - 1/2 + 4t + t^2/2 evaluated from 1 to x, which gives f(x) = x^2/2 + 4x + 1 for x > 2. For x <= 2: f(x) = 5x + 1. At x = 2: f(2-) = 5(2) + 1 = 11, f(2+) = 4/2 + 8 + 1 = 11. Left derivative f'(2-) = 5, right derivative f'(2+) = x + 4 = 6 at x = 2. Since left derivative (5) ≠ right derivative (6), f(x) is continuous but not differentiable at x = 2.
