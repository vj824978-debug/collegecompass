If the components of a = αi + βj + γk along and perpendicular to b = 3i + j - k respectively, are (16/11)(3i + j - k) and (1/11)(-4i - 5j - 17k), then α^2 + β^2 + γ^2 is equal to:

  1. (1) 23
  2. (2) 18
  3. (3) 16
  4. (4) 26

Answer

Correct answer: Option 4

Solution

Let a_∥ = component of a along b and a_⊥ = component of a perpendicular to b. Given: a_∥ = (16/11)(3i + j - k) and a_⊥ = (1/11)(-4i - 5j - 17k). Since a = a_∥ + a_⊥, we have: a = (16/11)(3i + j - k) + (1/11)(-4i - 5j - 17k) = (48i + 16j - 16k - 4i - 5j - 17k)/11 = (44i + 11j - 33k)/11 = 4i + j - 3k. Therefore α = 4, β = 1, γ = -3. Thus α^2 + β^2 + γ^2 = 16 + 1 + 9 = 26
