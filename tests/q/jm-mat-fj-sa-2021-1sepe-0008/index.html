Consider the system of linear equations: -x + y + 2z = 0, 3x - ay + 5z = 1, 2x - 2y - az = 7. Let S₁ be the set of all a ∈ R for which the system is inconsistent and S₂ be the set of all a ∈ R for which the system has infinitely many solutions. If n(S₁) and n(S₂) denote the number of elements in S₁ and S₂ respectively, then

  1. (1) n(S₁) = 1, n(S₂) = 0
  2. (2) n(S₁) = 0, n(S₂) = 2
  3. (3) n(S₁) = 2, n(S₂) = 0
  4. (4) n(S₁) = 2, n(S₂) = 2

Answer

Correct answer: Option 3

Solution

Using determinant method: Δ = 0 ⟹ a = 3, 4. For a = 3, no solution (inconsistent). For a = 4, no solution (inconsistent). n(S₁) = 2, n(S₂) = 0
