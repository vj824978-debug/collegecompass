A charge Q is distributed over three concentric spherical shells of radii a, b, c (a < b < c) such that their surface charge densities are equal to one another. The total potential at a point at distance r from their common centre, where r < a, would be -

  1. (1) Q(a^2 + b^2 + c^2) / (4*pi*epsilon_0*(a^3 + b^3 + c^3))
  2. (2) Q / (4*pi*epsilon_0*(a + b + c))
  3. (3) (Q / (12*pi*epsilon_0)) * (ab + bc + ca) / (abc)
  4. (4) Q(a + b + c) / (4*pi*epsilon_0*(a^2 + b^2 + c^2))

Answer

Correct answer: Option 4

Solution

Since the surface charge densities are equal for all three shells: x / (4*pi*a^2) = y / (4*pi*b^2) = z / (4*pi*c^2) (surface charge density for all are same) where x, y, z are charges on shells of radii a, b, c respectively. This gives: x : y : z = a^2 : b^2 : c^2 Since x + y + z = Q: x = a^2*Q / (a^2 + b^2 + c^2) y = b^2*Q / (a^2 + b^2 + c^2) z = c^2*Q / (a^2 + b^2 + c^2) For a point at distance r from the centre where r < a: The point is inside all three shells. V at r < a = kx/a + ky/b + kz/c = (1 / (4*pi*epsilon_0)) * [Qa / (a^2 + b^2 + c^2) + Qb / (a^2 + b^2 + c^2) + Qc / (a^2 + b^2 + c^2)] = (Q / (4*pi*epsilon_0)) * [(a + b + c) / (a^2 + b^2 + c^2)] = Q(a + b + c) / (4*pi*epsilon_0*(a^2 + b^2 + c^2))
