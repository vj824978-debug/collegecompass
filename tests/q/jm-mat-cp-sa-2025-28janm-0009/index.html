Let <a_n> be a sequence such that a_0 = 0, a_1 = 1/2 and 2a_(n+2) = 5a_(n+1) - 3a_n, n = 0, 1, 2, 3, .... Then sum_(k=1)^(100) a_k is equal to

  1. (1) 3a_99 - 100
  2. (2) 3a_100 - 100
  3. (3) 3a_100 + 100
  4. (4) 3a_99 + 100

Answer

Correct answer: Option 2

Solution

a_0 = 0, a_1 = 1/2 2a_(n+2) = 5a_(n+1) - 3a_n Characteristic equation: 2x^2 - 5x + 3 = 0 => (2x - 3)(x - 1) = 0 => x = 1, 3/2 Therefore, a_n = A(1)^n + B(3/2)^n Using initial conditions: n = 0: 0 = A + B => A = -1 n = 1: 1/2 = A + (3/2)B => B = 1 => a_n = -1 + (3/2)^n sum_(k=1)^(100) a_k = sum_(k=1)^(100) [-1 + (3/2)^k] = -100 + sum_(k=1)^(100) (3/2)^k = -100 + (3/2)[(3/2)^100 - 1]/[(3/2) - 1] = -100 + 3[(3/2)^100 - 1] = -100 + 3(3/2)^100 - 3 = 3(a_100) - 100
