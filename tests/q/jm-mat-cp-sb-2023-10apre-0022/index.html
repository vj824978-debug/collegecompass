In the figure, θ₁ + θ₂ = π/2 and sqrt(3) BE = 4(AB). If the area of triangle CAB is 2√3 - 3 unit², when θ₂/θ₁ is largest, then the perimeter (in unit) of triangle ACED is equal to ____.

Answer

Correct answer: 6

Solution

Let AB = x, BD = y. From sqrt(3) BE = 4AB, we get sqrt(3)(y + DE) = 4x, so DE = 4x/sqrt(3) - y. Area of triangle CAB = (1/2)xy = 2√3 - 3. Using tan(θ₂) = (4x/sqrt(3) - y)/x = 4/sqrt(3) - (4√3 - 6)/x² and tan(θ₁) = (y - 4√3 + 6)/x². From tan(θ₁)·tan(θ₂) = 1 (since θ₁ + θ₂ = π/2), solving gives x = 3 - √3 and θ₂ = 60°. Then DE = x√3 - 3√3 - 3, CD = x, CE = 2x - 6 - 2√3. Perimeter of triangle ACED = CD + DE + CE = x + (x√3 - 3√3 - 3) + (2x - 6 - 2√3) = 6.
