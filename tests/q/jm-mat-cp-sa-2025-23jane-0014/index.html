Let X = R × R. Define a relation R on X as: (a1, b1) R (a2, b2) ⟺ b1 = b2. Statement-I: R is an equivalence relation. Statement-II: For some (a, b) ∈ X, the set S = {(x, y) ∈ X : (x, y) R (a, b)} represents a line parallel to y = x. In the light of the above statements, choose the correct answer from the options given below:

  1. (1) Both Statement-I and Statement-II are false.
  2. (2) Statement-I is true but Statement-II is false.
  3. (3) Both Statement-I and Statement-II are true.
  4. (4) Statement-I is false but Statement-II is true.

Answer

Correct answer: Option 2

Solution

Statement – I : Reflexive : (a1,b1) R(a1, b1) ⟹ b1 = b1 True Symmetric : (a1, b1) R(a2, b2) ⟹ b1 = b2 (a2, b2) R(a1, b1) ⟹ b2 = b1 True Transitive : (a1, b1) R(a2, b2) ⟹ b1 = b2 & (a2, b2) R(a3, b3) ⟹ b2 = b3 ⟹ b1 = b3 ⟹ (a1, b1) R (a3, b3) ⟹ True Hence Relation R is an equivalence relation Statement-I is true. For statement -II ⟹ y = b so False
