If vectors a₁ = xi - j + k and a₂ = i + yj + zk are collinear, then a possible unit vector parallel to the vector xi + yj + zk is:

  1. (1) (1/sqrt(3))(i + j - k)
  2. (2) (1/sqrt(2))(-j + k)
  3. (3) (1/sqrt(3))(i - j + k)
  4. (4) (1/sqrt(2))(i - j)

Answer

Correct answer: Option 3

Solution

Given a₁ = xi - j + k and a₂ = i + yj + zk are collinear, so a₁ = λa₂. Expanding: (xi - j + k) = λ(i + yj + zk) = (x - λ)i - (1 + λy)j + (1 - λz)k = 0. Since i, j, k are linearly independent: x - λ = 0, 1 + λy = 0, 1 - λz = 0. Solving: x = λ, y = -1/λ, z = 1/λ. Therefore xi + yj + zk = λi - (1/λ)j + (1/λ)k. For λ = 1: xi + yj + zk = i - j + k. Magnitude = sqrt(1 + 1 + 1) = sqrt(3). Unit vector = (1/sqrt(3))(i - j + k).
