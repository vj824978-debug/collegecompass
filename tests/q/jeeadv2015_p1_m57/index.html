Let g : ℝ → ℝ be a differential function with g(0) = 0, g'(0) = 0 and g'(1) ≠ 0. Let f(x) = { (x/|x|) g(x), x ≠ 0 ; 0, x = 0 } and h(x) = e^(x|x|) for all x ∈ ℝ. Let (f ∘ h)(x) denote f(h(x)) and (h ∘ f)(x) denote h(f(x)). Then which of the following is/are true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (A) f is differentiable at x = 0
  2. (B) (B) h is differentiable at x = 0
  3. (C) (C) f ∘ h is differentiable at x = 0
  4. (D) (D) h ∘ f is differentiable at x = 0

Answer

Correct answer: AD

Solution

Differentiability of f(x) at x = 0 LHD f'(0⁻) = lim[δ→0] ((f(0) - f(0 - δ))/δ) = lim[δ→0] (0 + g(-δ))/δ = 0 RHD f'(0⁺) = lim[δ→0] ((f(0 + δ) - f(0))/δ) = lim[δ→0] g(δ)/δ = 0 ⟹ f(x) is differentiable at x = 0. Differentiability of h(x) at x = 0 h'(0⁺) = 1, h(x) is an even function hence non diff. at x = 0 Differentiability of f(h(x)) at x = 0 f(h(x)) = g(eˢ) ∀ x ∈ ℝ LHD f'(h(0⁻)) = lim[δ→0] ((f(h(0)) - f(h(0 - δ)))/δ) = lim[δ→0] (g(1) - g(eˢ))/δ = -g'(1) RHD f'(h(0⁺)) = lim[δ→0] ((f(h(0 + δ)) - f(h(0)))/δ) = lim[δ→0] (g(eˢ) - g(1))/δ = g'(1) Since g'(1) ≠ 0 ⟹ f(h(x)) is non diff. at x = 0 Differentiability of h(f(x)) at x = 0 h(f(x)) = {eˢ⁽ˣ⁾, x ≠ 0; 1, x = 0} LHD. h'(f(0⁻)) = lim[δ→0] ((h(f(0)) - h(f(0 - δ)))/δ) = lim[δ→0] ((1 - eˢ⁽⁻ᵟ⁾)/|g(-δ)|) · (|g(-δ)|/δ) = 0 RHD h'(f(0⁺)) = lim[δ→0] ((h(f(0 + δ)) - h(f(0)))/δ) = lim[δ→0] ((eˢ⁽ᵟ⁾ - 1)/g(δ)) · (|g(δ)|/δ) = 0.
