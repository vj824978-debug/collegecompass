Which of the following options are correct for the reaction? 2[Au(CN)2]^- (aq) + Zn(s) → 2Au(s) + [Zn(CN)4]^2- (aq) A. Redox reaction B. Displacement reaction C. Decomposition reaction D. Combination reaction Choose the correct answer from the options given below:

  1. (1) A only
  2. (2) A and D only
  3. (3) A and B only
  4. (4) C and D only

Answer

Correct answer: Option 3

Solution

(A) Oxidation state of zinc is changing from 0 to +2. (B) Zinc is displacing Au from complex. The reaction is both a redox reaction (as oxidation states change: Zn goes from 0 to +2, Au goes from +1 to 0) and a displacement reaction (as Zn displaces Au from the complex). Therefore, both A and B are correct.
