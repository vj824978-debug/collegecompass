Let a₀, a₁, ..., a₂₃ be real numbers such that (1 + (2/5)x)^23 = Σ(i=0 to 23) aᵢx^i for every real number x. Let aᵣ be the largest among the numbers aⱼ for 0 ≤ j ≤ 23. Then the value of r is ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 6

Solution

a₀, a₁, ..., a₂₃ are real numbers and (1 + (2/5)x)²³ = Σ(i=0 to 23) aᵢxⁱ aᵣ be the largest among the numbers aⱼ, 0 ≤ j ≤ 23 ⟹ we have to find numerically greatest term. m = (n + 1)/(1 + 1/(2x)) = 48/(7) = 6.85 ([m] + 1)ᵗʰ term is numerically greatest. ⟹ 7ᵗʰ term is numerically greatest ⟹ r = 6
