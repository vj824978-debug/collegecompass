If the function f(x) = [log_e(1-x+x^2) + log_e(1+x+x^2)] / (sec(x) - cos(x)) for x in (-π/2, π/2) - {0}, and f(x) = k for x = 0, is continuous at x = 0, then k is equal to

  1. (1) 1
  2. (2) -1
  3. (3) e
  4. (4) 0

Answer

Correct answer: Option 1

Solution

For continuity at x = 0, lim(x→0) f(x) = k. The limit gives 0/0 form. Using L'Hôpital's rule and algebraic manipulation: k = lim(x→0) [log_e(x^4 + x^2 + 1)] / x^2 = lim(x→0) [ln(1 + x^2 + x^4) / (x^2 + x^4)] × [(x^2 + x^4) / x^2] = 1 × 1 = 1
