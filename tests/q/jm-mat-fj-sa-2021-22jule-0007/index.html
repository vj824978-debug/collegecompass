Let a line L: 2x + y = k, k > 0 be a tangent to the hyperbola x^2 - y^2 = 3. If L is also a tangent to the parabola y^2 = alpha*x, then alpha is equal to:

  1. (1) 24
  2. (2) -24
  3. (3) -12
  4. (4) 12

Answer

Correct answer: Option 2

Solution

The line y = -2x + k is tangent to hyperbola x^2 - y^2 = 3. Substituting y = -2x + k into the hyperbola equation: x^2 - (-2x + k)^2 = 3, which gives x^2 - (4x^2 - 4kx + k^2) = 3. Simplifying: -3x^2 + 4kx - k^2 - 3 = 0. For tangency, discriminant = 0: (4k)^2 - 4(-3)(-k^2 - 3) = 0, which gives 16k^2 - 12k^2 - 36 = 0, so 4k^2 = 36, hence k = 3 (since k > 0). The line is y = -2x + 3. For this line to be tangent to parabola y^2 = alpha*x, substitute y = -2x + 3: (-2x + 3)^2 = alpha*x, which gives 4x^2 - 12x + 9 = alpha*x. Rearranging: 4x^2 - (12 + alpha)x + 9 = 0. For tangency, discriminant = 0: (12 + alpha)^2 - 4(4)(9) = 0, so (12 + alpha)^2 = 144, giving 12 + alpha = ±12. Thus alpha = 0 or alpha = -24. Since alpha must be non-zero, alpha = -24.
