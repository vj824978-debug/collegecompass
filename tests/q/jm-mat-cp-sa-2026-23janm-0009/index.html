Let f(x) = {4x^2 + 4x - 3 for x ≠ -3/2, 1/2; b for x = -3/2, 1/2}. If f(x) is continuous at x = -3/2 and f(x) = 7/5, then x is equal to:

  1. (1) 2
  2. (2) 1
  3. (3) 0
  4. (4) 1.4

Answer

Correct answer: Option 2

Solution

f(x) = {(ax^2 + 2ax + 3)/((2x-1)(2x+3)) for x ≠ -3/2, 1/2; b for x = -3/2, 1/2} For continuous at x = -3/2: LHL = RHL = f(-3/2) => lim(x→-3/2) [(ax^2 + 2ax + 3)/((2x-1)(2x+3))] At x = -3/2 => Numerator = 0 a(-3/2)^2 + 2a(-3/2) + 3 = 0 a(9/4) - 3a + 3 = 0 (9a/4) - 3a + 3 = 0 (3a/4) = 3 => a = 4 ∴ f(x) = {(4x^2 + 8x + 3)/((2x-1)(2x+3)) for x ≠ -3/2, 1/2; b for x = -3/2, 1/2} f(x) = {((2x+1)(2x+3))/((2x-1)(2x+3)) for x ≠ -3/2, 1/2; b for x = -3/2, 1/2} For f(x) = f((2x+1)/(2x-1)) = [2((2x+1)/(2x-1)) + 1]/[2((2x+1)/(2x-1)) - 1] = [(2(2x+1) + (2x-1))/(2x-1)]/[(2(2x+1) - (2x-1))/(2x-1)] = (6x + 1)/(2x + 3) = 7/5 So x = 1 Ans.
