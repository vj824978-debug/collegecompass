Let b be a nonzero real number. Suppose f: ℝ → ℝ is a differentiable function such that f(0) = 1. If the derivative f' of f satisfies the equation f'(x) = f(x)/(b² + x²) for all x ∈ ℝ, then which of the following statements is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) If b > 0, then f is an increasing function
  2. (B) If b < 0, then f is a decreasing function
  3. (C) f(x)·f(−x) = 1 for all x ∈ ℝ
  4. (D) f(x) − f(−x) = 0 for all x ∈ ℝ

Answer

Correct answer: AC

Solution

f'(x) = f(x)/(b² + x²) ∫[f'(x)/f(x)]dx = ∫[dx/(b² + x²)] ⟹ ln|f(x)| = (1/b)tan⁻¹(x/b) + c As f(0) = 1 ⟹ ln|1| = 0 + c ⟹ c = 0 ⟹ f(x) = e^[(1/b)tan⁻¹(x/b)] ⟹ f(x)·f(-x) = 1, Also f(x) is increasing ∀ b ∈ ℝ.
