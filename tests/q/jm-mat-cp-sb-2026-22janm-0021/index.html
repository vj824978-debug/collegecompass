Let α = (-1 + i*sqrt(3))/2 and β = (-1 - i*sqrt(3))/2, i = sqrt(-1). If (7 - 7α + 9β)^20 + (9 + 7α - 7β)^20 + (-7 + 9α + 7β)^20 + (14 + 7α + 7β)^20 = m^10, then m is ____.

Answer

Correct answer: 49

Solution

(7 - 7α + 9β)^20 + (9 + 7α - 7β)^20 + (-7 + 9α + 7β)^20 + (14 + 7α + 7β)^20 = m^10 Note: α and β are cube roots of unity where α = ω and β = ω^2, with ω = e^(2πi/3) Substituting ω for α and ω^2 for β: => (7ω - 7ω^2 + 9ω^3)^20 + (9 + 7ω - 7ω^2)^20 + (-7ω^2 + 9ω^3 + 7ω^4)^20 + (14 + 7(ω + ω^2))^20 = m^10 Using ω^3 = 1 and 1 + ω + ω^2 = 0: => ((7ω - 7ω^2 + 9ω^3)^20)/ω^50 + (9 + 7ω - 7ω^2)^20 + ((-7ω^2 + 9ω^3 + 7ω^4)^20)/ω^40 + (14 + 7(ω + ω^2))^20 = m^10 => (9 + 7ω - 7ω^2)^20 · ω + (9 + 7ω - 7ω^2)^20 + (9 + 7ω - 7ω^2)^20 · ω^2 + (14 - 7)^20 = m^10 => (9 + 7ω - 7ω^2)^20(ω + 1 + ω^2) + 7^20 = m^10 => 0 + 7^20 = m^10 => (7^2)^10 = m^10 => m^10 = 49^10 Hence, m = 49
