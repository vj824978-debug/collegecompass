If the foot of the perpendicular drawn from the point (1, 0, 3) on a line passing through (α, 7, 1) is (5/3, 7/3, 17/3), then α is equal to ________.

Answer

Correct answer: 4

Solution

Let P = (1, 0, 3) be the given point Let A = (α, 7, 1) be a point on the line Let D = (5/3, 7/3, 17/3) be the foot of the perpendicular from P to the line Since D is the foot of perpendicular from P to the line passing through A, we have: vector PD ⊥ vector AD Calculate vector PD: vector PD = D - P = (5/3 - 1, 7/3 - 0, 17/3 - 3) = (2/3, 7/3, 8/3) Calculate vector AD: vector AD = D - A = (5/3 - α, 7/3 - 7, 17/3 - 1) = (5/3 - α, -14/3, 14/3) For perpendicularity, vector PD · vector AD = 0: ((5/3 - α)i + (7/3 - 7)j + (17/3 - 1)k) · ((2/3)i + (7/3)j + (8/3)k) = 0 (5/3 - α)(2/3) + (7/3)(-14/3) + (14/3)(8/3) = 0 (5/3 - α)(2/3) + 7/3(-14/3) + 14 × 8/3 = 0 2(5 - 3α)/3 - 14 × 7/3 + 14 × 8/3 = 0 2(5 - 3α) - 14 × 7 + 14 × 8 = 0 10 - 6α - 98 + 112 = 0 5 - 3α - 49 + 56 = 0 3α = 12 α = 4
