As shown in the figure, a point charge Q is placed at the centre of conducting spherical shell of inner radius a and outer radius b. The electric field due to charge Q in three different regions I, II and III is given by: (I : r < a, II : a < r < b, III : r > a)

  1. (1) E_I ≠ 0, E_II = 0, E_III ≠ 0
  2. (2) E_I = 0, E_II = 0, E_III = 0
  3. (3) E_I ≠ 0, E_II = 0, E_III = 0
  4. (4) E_I = 0, E_II ≠ 0, E_III ≠ 0

Answer

Correct answer: Option 1

Solution

For a point charge Q at the centre of a conducting spherical shell: Region I (r < a - inside the cavity): The electric field is due to the point charge Q at the centre. Using Coulomb's law: E_I = KQ/r^2 ≠ 0 Region II (a < r < b - inside the conductor): Inside a conductor in electrostatic equilibrium, the electric field must be zero. E_II = 0 Region III (r > b - outside the conductor): Outside the conducting shell, the electric field is due to the total charge enclosed. Since the charge Q at the centre induces a charge -Q on the inner surface and +Q on the outer surface of the conductor, the net charge on the shell is zero, but the outer surface has charge +Q distributed on it. Using Gauss's law for r > b: E_III = KQ/r^2 ≠ 0 Therefore: E_I ≠ 0, E_II = 0, E_III ≠ 0
