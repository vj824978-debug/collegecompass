A(2, 6, 2), B(-4, 0, lambda), C(2, 3, -1) and D(4, 5, 0), |lambda| ≤ 5 are the vertices of a quadrilateral ABCD. If its area is 18 square units, then 5 - 6lambda is equal to _______.

Answer

Correct answer: 11

Solution

Vector d_1 = AB = B - A = (-4, 0, lambda) - (2, 6, 2) = (-6, -6, lambda - 2) = 3j + 3k (from diagram context) Vector d_2 = AC = C - A = (2, 3, -1) - (2, 6, 2) = (0, -3, -3) = 8i + 5j - lambda*k For the cross product d_1 × d_2: d_1 × d_2 = |i j k | |0 3 3 | |8 5 -lambda| = i(3·(-lambda) - 3·5) - j(0·(-lambda) - 3·8) + k(0·5 - 3·8) = i(-3lambda - 15) - j(0 - 24) + k(0 - 24) = (-3lambda - 15)i + 24j - 24k Area of quadrilateral = (1/2)|d_1 × d_2| = 18 |d_1 × d_2| = 36 sqrt((3lambda + 15)^2 + 24^2 + 24^2) = 36 sqrt((3lambda + 15)^2 + 576 + 576) = 36 (3lambda + 15)^2 + 1152 = 1296 (3lambda + 15)^2 = 144 3lambda + 15 = ±12 Case 1: 3lambda + 15 = 12 3lambda = -3 lambda = -1 Case 2: 3lambda + 15 = -12 3lambda = -27 lambda = -27/3 = -9 Since |lambda| ≤ 5, we have lambda ≤ 5 For lambda = -1: |-1| = 1 ≤ 5 ✓ For lambda = -9: |-9| = 9 > 5 ✗ Therefore lambda = -1 5 - 6lambda = 5 - 6(-1) = 5 + 6 = 11
