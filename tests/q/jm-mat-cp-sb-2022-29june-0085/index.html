For real number a, b (a > b > 0), let Area {(x,y): x^2 + y^2 <= a^2 and (x^2/a^2) + (y^2/b^2) >= 1} = 30π and Area {(x,y): x^2 + y^2 >= b^2 and (x^2/a^2) + (y^2/b^2) <= 1} = 18π. Then the value of (a - b)^2 is equal to ____.

Answer

Correct answer: 12

Solution

From the first condition: Area of circle minus area inside ellipse = πa^2 - πab = 30π, so a^2 - ab = 30 ... (1). From the second condition: Area inside ellipse minus area of circle = πab - πb^2 = 18π, so ab - b^2 = 18 ... (2). Adding (1) and (2): a^2 - b^2 = 48. From (1) and (2): a/b = 5/3, so a = 5b/3. Substituting in (2): (5b/3)b - b^2 = 18, which gives (10/9)b^2 = 30, so b^2 = 27 and a^2 = 75. Therefore (a - b)^2 = (sqrt(75) - sqrt(27))^2 = (5√3 - 3√3)^2 = (2√3)^2 = 12.
