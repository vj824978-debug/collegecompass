Let n₁ < n₂ < n₃ < n₄ < n₅ be positive integers such that n₁ + n₂ + n₃ + n₄ + n₅ = 20. Then the number of such distinct arrangements (n₁, n₂, n₃, n₄, n₅) is ________

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 7

Solution

When n₅ takes value from 10 to 6 the carry forward moves from 0 to 4 which can be arranged in ⁴C₀ + ⁴C₄ + ⁴C₃ + ⁴C₂ + ⁴C₁ = 7 Alternate solution Possible solutions are 1, 2, 3, 4, 10 1, 2, 3, 5, 9 1, 2, 3, 6, 8 1, 2, 4, 5, 8 1, 2, 4, 6, 7 1, 3, 4, 5, 7 2, 3, 4, 5, 6 Hence 7 solutions are there.
