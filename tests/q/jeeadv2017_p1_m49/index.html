The tangent to a suitable conic (Column 1) at (sqrt(3), 1/2) is found to be sqrt(3)x + 2y = 4, then which of the following options is the only CORRECT combination?

Single correct MCQ · Marks: +3 / -1.0

Passage:

  1. (A) [A] (I) (iii) (R)
  2. (B) [B] (I) (iv) (S)
  3. (C) [C] (IV) (iii) (S)
  4. (D) [D] (II) (iv) (R)

Answer

Correct answer: D

Solution

Tangent at (√3, 1/2) is √3x + 2y = 4 Since slope of tangent at (√3, 1/2) is -ve hence possible curve are (I), (II) only ⟹ equation of curve is x²/4 + y² = 1, i.e., x² + 4y² = 4 Hence equation of tangent is y = mx + √(a²m² + 1) And point of contact is (-a²m/√(a²m² + 1), 1/√(a²m² + 1))
