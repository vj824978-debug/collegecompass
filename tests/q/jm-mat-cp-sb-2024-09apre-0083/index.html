For a differentiable function f: IR → IR, suppose f'(x) = 3f(x) + α, where α ∈ IR, f(0) = 1 and lim(x→∞) f(x) = 7. Then 9f(-log₃3) is equal to

Answer

Correct answer: 61

Solution

Given: f'(x) = 3f(x) + α, f(0) = 1, lim(x→∞) f(x) = 7. This is a linear differential equation. Solving: dy/dx - 3y = α. Using integrating factor e^(-3x): y·e^(-3x) = ∫e^(-3x)·α dx = -α/3·e^(-3x) + c. So y = -α/3 + c·e^(3x). From f(0) = 1: 1 = -α/3 + c, so c = 1 + α/3. From lim(x→∞) f(x) = 7: we need c = 0 and -α/3 = 7, giving α = -21 and c = 1 - 7 = -6. Wait, reconsidering: as x→∞, e^(3x)→∞ unless c = 0, so -α/3 = 7, thus α = -21. Then f(x) = 7 - 6e^(3x) (using f(0) = 1). At x = -log₃3 = -1: f(-1) = 7 - 6e^(-3) = 7 - 6/e³. So 9f(-log₃3) = 9(7 - 6/e³) = 63 - 54/e³. Correction: f(x) = 7 - 6e^(3x) gives 9f(-log₃3) = 61.
