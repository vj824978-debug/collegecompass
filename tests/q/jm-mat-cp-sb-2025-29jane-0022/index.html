If lim(t→0) ∫[0 to t] (3x + 5)^t dx = α/(5e) * (8/5)^3, then α is equal to ___.

Answer

Correct answer: 64

Solution

1° form Now L = e^(lim(t→0) 1/t * [((3x + 5)^(t+1))/(3(t+1))|_0^t - 1]) = e^(lim(t→0) (8^(t+1) - 5^(t+1) - 3t - 3)/(3t(t+1))) = e^((8 ln 8 - 5 ln 5 - 3)/3) = (8/5)^(2/3) * (64/5) = α/(5e) * (8/5)^(2/3) On comparing α = 64
