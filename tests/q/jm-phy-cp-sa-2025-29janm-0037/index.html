A coil of area A and N turns is rotating with angular velocity ω in a uniform magnetic field B about an axis perpendicular to B. Magnetic flux φ and induced emf ε across it, at an instant when B is parallel to the plane of coil, are:

  1. (1) φ = AB, ε = 0
  2. (2) φ = 0, ε = NABω
  3. (3) φ = 0, ε = 0
  4. (4) φ = AB, ε = NABω

Answer

Correct answer: Option 2

Solution

The magnetic flux through the coil varies as the coil rotates: φ = BAN.cos(ωt) The induced emf is: ε = -dφ/dt = BAωN.sin(ωt) When B is parallel to the plane of coil, ωt = π/2 At this instant: cos(π/2) = 0, so φ = 0 sin(π/2) = 1, so ε = BAωN Therefore: φ = 0, ε = NABω
