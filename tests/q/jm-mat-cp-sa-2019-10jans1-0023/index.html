Let f : (−1, 1) → R be a function defined by f(x) = max{|x|, sqrt(1 − x^2)}. If K be the set of all points at which f is not differentiable, then K has exactly

  1. (1) one element
  2. (2) three elements
  3. (3) five elements
  4. (4) two elements

Answer

Correct answer: Option 2

Solution

We have f(x) = max{|x|, sqrt(1 − x^2)} for x ∈ (−1, 1). The function f is the maximum of two functions: - g(x) = |x| - h(x) = sqrt(1 − x^2) To find points of non-differentiability, we need to find where these two functions intersect and where the "max" switches from one to the other. Step 1: Find intersection points. We need |x| = sqrt(1 − x^2) Squaring both sides: x^2 = 1 − x^2 2x^2 = 1 x^2 = 1/2 x = ±1/sqrt(2) = ±sqrt(2)/2 Step 2: Analyze which function is larger in different regions. At x = 0: |0| = 0, sqrt(1 − 0) = 1, so sqrt(1 − x^2) > |x| At x = 0.9: |0.9| = 0.9, sqrt(1 − 0.81) = sqrt(0.19) ≈ 0.436, so |x| > sqrt(1 − x^2) So for x ∈ (−sqrt(2)/2, sqrt(2)/2), we have f(x) = sqrt(1 − x^2) For x ∈ (sqrt(2)/2, 1), we have f(x) = |x| = x For x ∈ (−1, −sqrt(2)/2), we have f(x) = |x| = −x Step 3: Check differentiability. - At x = 0: f(x) = sqrt(1 − x^2) in a neighborhood of 0. f'(x) = −x/sqrt(1 − x^2), and f'(0) = 0. The function is differentiable at x = 0. - At x = sqrt(2)/2: Left derivative: d/dx[sqrt(1 − x^2)]|_(x=sqrt(2)/2) = −(sqrt(2)/2)/sqrt(1/2) = −1 Right derivative: d/dx[x]|_(x=sqrt(2)/2) = 1 Since left derivative ≠ right derivative, f is not differentiable at x = sqrt(2)/2. - At x = −sqrt(2)/2: Left derivative: d/dx[−x]|_(x=−sqrt(2)/2) = −1 Right derivative: d/dx[sqrt(1 − x^2)]|_(x=−sqrt(2)/2) = −(−sqrt(2)/2)/sqrt(1/2) = 1 Since left derivative ≠ right derivative, f is not differentiable at x = −sqrt(2)/2. Therefore, K = {−sqrt(2)/2, sqrt(2)/2}, which has exactly two elements.
