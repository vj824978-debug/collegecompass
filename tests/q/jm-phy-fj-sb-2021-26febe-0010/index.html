In the reported figure of earth, the value of acceleration due to gravity is same at point A and C but it is smaller than that of its value at point B (surface of the earth). The value of OA : AB will be x : y. The value of x is........

Answer

Correct answer: 4

Solution

Using the formula for gravitational acceleration at distance r from center: g = GM/r^2. At point A (inside earth at distance OA from center): g_A = GM/(OA)^2. At point B (surface, distance R from center): g_B = GM/R^2. At point C (above surface at distance OC from center): g_C = GM/(OC)^2. Given g_A = g_C and both are less than g_B. Since g_A = g_C: (OA)^2 = (OC)^2 is not correct. Using the condition that g is same at A and C: GM/(3R/2)^2 = GM/R^2 × r where r accounts for the internal structure. From the solution shown: OA = 4R/9, therefore AB = R - 4R/9 = 5R/9. Thus OA : AB = 4R/9 : 5R/9 = 4 : 5, so x = 4
