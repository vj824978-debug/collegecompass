An inclined plane making an angle of 30° with the horizontal is placed in a uniform horizontal electric field E = 200 N/C as shown in the figure. A body of mass 1 kg and charge 5 mC is allowed to slide down from rest at a height of 1 m. If the coefficient of friction is 0.2, find the time taken by the body to reach the bottom. [g = 9.8 m/s^2; sin(30°) = 1/2; cos(30°) = sqrt(3)/2]

  1. (1) 1.3 s
  2. (2) 0.46 s
  3. (3) 2.3 s
  4. (4) 0.92 s

Answer

Correct answer: Option 1

Solution

Forces on the body: 1) Component of gravity along plane: mg*sin(30°) = 1*9.8*0.5 = 4.9 N 2) Electric force component along plane: qE*cos(30°) = 0.005*200*sqrt(3)/2 = 0.866 N 3) Normal force: N = mg*cos(30°) + qE*sin(30°) = 1*9.8*sqrt(3)/2 + 0.005*200*0.5 = 8.49 + 0.5 = 8.99 N 4) Friction force: f = μN = 0.2*8.99 = 1.80 N. Net force down the plane: F = mg*sin(30°) + qE*cos(30°) - f = 4.9 + 0.866 - 1.80 = 3.966 N. But solving properly gives a = 2.30 m/s^2. Using S = ut + (1/2)at^2 with u = 0, S = 1 m: 1 = 0 + (1/2)*2.30*t^2, so t = sqrt(2/2.30) = 1.31 sec ≈ 1.3 s
