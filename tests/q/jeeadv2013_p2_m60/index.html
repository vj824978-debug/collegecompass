Consider the lines L₁: (x-1)/2 = y/(-1) = (z+3)/1, L₂: (x-4)/1 = (y+3)/1 = (z+3)/2 and the planes P₁: 7x + y + 2z = 3, P₂: 3x + 5y - 6z = -4. Let ax + by + cz = d be the equation of the plane passing through the point of intersection of lines L₁ and L₂, and perpendicular to planes P₁ and P₂. Match List I with List II and select the correct answer using the code given below the lists: [TABLE] List - I | List - II P. | a = | 1. | 13 Q. | b = | 2. | -3 R. | c = | 3. | 1 S. | d = | 4. | -2 [/TABLE] Codes: (A) P→3, Q→2, R→4, S→1 (B) P→1, Q→3, R→4, S→2 (C) P→3, Q→2, R→1, S→4 (D) P→2, Q→4, R→1, S→3

Matrix match · Marks: +4 / -1.0

  1. (A) (A) P→3, Q→2, R→4, S→1
  2. (B) (B) P→1, Q→3, R→4, S→2
  3. (C) (C) P→3, Q→2, R→1, S→4
  4. (D) (D) P→2, Q→4, R→1, S→3

Answer

Correct answer: A

Solution

Sol. (A) Plane perpendicular to P₁ and P₂ has Direction Ratios of normal |i j k | |7 1 2| = -16i + 48j + 32k ... (1) |3 5 -6| For point of intersection of lines (2λ₁ + 1, -λ₁, λ₁ - 3) ≡ (λ₂ + 4, λ₂ - 3, 2λ₂ - 3) ⟹ 2λ₁ + 1 = λ₂ + 4 or 2λ₁ - λ₂ = 3 -λ₁ = λ₂ - 3 or λ₁ + λ₂ = 3 ⟹ λ₁ = 2, λ₂ = 1 ∴ Point is (5, -2, -1) ... (2) From (1) and (2), required plane is -1(x - 5) + 3(y + 2) + 2(z + 1) = 0 or -x + 3y + 2z = -13 or x - 3y - 2z = 13 ⟹ a = 1, b = -3, c = -2, d = 13.
