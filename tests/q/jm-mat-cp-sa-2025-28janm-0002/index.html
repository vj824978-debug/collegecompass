Let ABCD be a trapezium whose vertices lie on the parabola y^2 = 4x. Let the sides AD and BC of the trapezium be parallel to y-axis. If the diagonal AC is of length 25/4 and it passes through the point (1, 0), then the area of ABCD is:

  1. (1) 75/4
  2. (2) 25/2
  3. (3) 125/8
  4. (4) 75/8

Answer

Correct answer: Option 1

Solution

Since vertices lie on parabola y^2 = 4x, we can write points on parabola as (t^2, 2t). Since AD and BC are parallel to y-axis, A and D have same x-coordinate, and B and C have same x-coordinate. Let A(at_1^2, 2at_1) and D(at_1^2, -2at_1) where a = 1 Let C(a/t_1^2, -2a/t_1) and B(a/t_1^2, 2a/t_1) So: A(t_1^2, 2t_1), D(t_1^2, -2t_1), B(1/t_1^2, 2/t_1), C(1/t_1^2, -2/t_1) Diagonal AC passes through (1, 0): The line through A(t_1^2, 2t_1) and C(1/t_1^2, -2/t_1) must pass through (1, 0). Length AC = sqrt[(t_1^2 - 1/t_1^2)^2 + (2t_1 + 2/t_1)^2] = 25/4 Let u = t_1 + 1/t_1 Then (t_1 - 1/t_1)^2 = u^2 - 4 AC^2 = (t_1^2 - 1/t_1^2)^2 + 4(t_1 + 1/t_1)^2 = (t_1 - 1/t_1)^2(t_1 + 1/t_1)^2 + 4u^2 = (u^2 - 4)u^2 + 4u^2 = u^4 - 4u^2 + 4u^2 = u^4 So |u|^2 = 25/4, hence u = ±5/2 From the condition that AC passes through (1, 0): Using collinearity condition on A(t_1^2, 2t_1), (1, 0), C(1/t_1^2, -2/t_1): t_1 + 1/t_1 = ±5/2 For t_1 + 1/t_1 = 5/2: t_1 = 2 or t_1 = 1/2 Taking t_1 = 2: A(4, 4), D(4, -4), B(1/4, 1), C(1/4, -1) Wait, let me recalculate. If t_1 = 2, then: A(4, 4), D(4, -4), and for C we use 1/t_1 = 1/2: C(1/4, -1), B(1/4, 1) Area of trapezium = (1/2)(sum of parallel sides)(height) Parallel sides AD and BC have lengths: |AD| = |4 - (-4)| = 8 |BC| = |1 - (-1)| = 2 Height = distance between x = 4 and x = 1/4 = 4 - 1/4 = 15/4 Area = (1/2)(8 + 2)(15/4) = (1/2)(10)(15/4) = 75/4
