Let a = i + j + 2k, b = 2i - 3j + k and c = i - j + k be three given vectors. Let v be a vector in the plane of a and b whose projection on c is 2/sqrt(3). If v.j = 7, then v.(i + k) is equal to:

  1. (1) 6
  2. (2) 7
  3. (3) 8
  4. (4) 9

Answer

Correct answer: Option 4

Solution

Let v = λ₁a + λ₂b where λ₁, λ₂ ∈ R. Then v = (λ₁ + 2λ₂)i + (λ₁ - 3λ₂)j + (2λ₁ + λ₂)k. Projection of v on c is (v.c)/|c| = 2/sqrt(3). Since |c| = sqrt(3), we get v.c = 2. This gives λ₁ + 3λ₂ = 1 ... (i). From v.j = 7, we get λ₁ - 3λ₂ = 7 ... (ii). Solving (i) and (ii): λ₁ = 4, λ₂ = -1. Therefore v = 2i + 7j + 7k. Thus v.(i + k) = 2 + 7 = 9.
