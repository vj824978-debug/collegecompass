Let A, B, C and D be four non-empty sets. The contrapositive statement of "If A ⊆ B and B ⊆ D, then A ⊆ C" is:

  1. (1) If A ⊄ C, then A ⊆ B and B ⊆ D
  2. (2) If A ⊄ C, then A ⊄ B and B ⊆ D
  3. (3) If A ⊄ C, then A ⊄ B or B ⊄ D
  4. (4) If A ⊆ C, then B ⊂ A or D ⊂ B

Answer

Correct answer: Option 3

Solution

If A ⊆ B and B ⊆ D then A ⊆ C Contrapositive is If A ⊄ C, then A ⊄ B or B ⊄ D The contrapositive of a statement "If P then Q" is "If not Q then not P". Here P = (A ⊆ B and B ⊆ D) Q = A ⊆ C Negation of Q: not (A ⊆ C) = A ⊄ C Negation of P: not (A ⊆ B and B ⊆ D) = (A ⊄ B) or (B ⊄ D) Therefore the contrapositive is: If A ⊄ C, then A ⊄ B or B ⊄ D
