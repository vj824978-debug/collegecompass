The lines (x-2)/2 = y/(-2) = (z-7)/16 and (x+3)/4 = (y+2)/3 = (z+2)/1 intersect at the point P. If the distance of P from the line (x+1)/2 = (y-1)/3 = (z-1)/1 is ℓ, then 14ℓ² is equal to ____.

Answer

Correct answer: 108

Solution

Parametrize first line as (2+2λ, -2λ, 7+16λ) and second line as (-3+4t, -2+3t, -2+t). At intersection P: 2λ+2 = 4t-3, -2λ = 3t-2, 16λ+7 = t-2. Solving: λ = -1/2, t = 1. Therefore P(1, 1, -1). Direction vector of third line is b = 2i+3j+k. Vector AP = 2i-2k where A(-1,1,1). AM = |AP·b|/|b| = 2/√14, so AM² = 2/7. PM² = AP² - AM² = 8 - 2/7 = 54/7 = ℓ². Thus 14ℓ² = 108.
