Let w = i + j - 2k, and u and v be two vectors, such that u × v = w and v × w = u. Let α, β, γ, and t be real numbers such that u = αi + βj + γk, -tα + β + γ = 0, α - tβ + γ = 0, and α + β - tγ = 0. Match each entry in List-I to the correct entries in List-II and choose the correct option. List-I: (P) |v|² is equal to (Q) If α = √3, then γ² is equal to (R) If α = √3, then (β + γ)² is equal to (S) If α = √2, then t + 3 is equal to List-II: (1) 0 (2) 1 (3) 2 (4) 3 (5) 5 The correct option is:

Matrix match · Marks: +4 / -1.0

  1. (A) (P) → (2) (Q) → (1) (R) → (4) (S) → (5)
  2. (B) (P) → (2) (Q) → (4) (R) → (3) (S) → (5)
  3. (C) (P) → (2) (Q) → (1) (R) → (4) (S) → (3)
  4. (D) (P) → (5) (Q) → (4) (R) → (1) (S) → (3)

Answer

Correct answer: A

Solution

w = i + j - 2k u = αi + βj + γk and -tα + β + γ = 0, α + tβ + γ = 0, α + β - tγ = 0 so |−t 1 1| | 1 −t 1| = 0 | 1 1 −t| t = −1 or t = 2 Case 1: if t = −1 ⟹ α + β + γ = 0 given v × w = u ⟹ w ⊥ u, v ⊥ u u × v = w ⟹ v ⊥ w w·u = 0 (i + j − 2k)·(αi + βj + γk) = 0 α + β − 2γ = 0 ...(i) given (v × w) = u (v × w) × v = u × v ⟹ |v| = 1 ...(ii) given u × v = w u ⊥ v |u × v| = |w| |u| = √6 α² + β² + γ² = 6 ...(iii) Case 1: t = −1 α + β + γ = 0 α + β − 2γ = 0 so, γ = 0 and β = −α Case 2: t = 2, α = β = γ (P) |v| = 1 (Q) α + β + γ = 0 α + β − 2γ = 0 so, γ = 0 and β = −α (R) α = √3, so, β + γ = −α, (β + γ)² = 3 (S) α = √2, so, t + 3 = 2 + 3 = 5
