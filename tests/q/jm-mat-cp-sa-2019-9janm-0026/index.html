If both the roots of the quadratic equation x^2 - mx + 4 = 0 are real and distinct and they lie in the interval [1, 5], then m lies in the interval:

  1. (1) (4, 5)
  2. (2) (-5, -4)
  3. (3) (3, 4)
  4. (4) (5, 6)

Answer

Correct answer: Option 1

Solution

x^2 - mx + 4 = 0 Case-I: D > 0 m^2 - 16 > 0 => m ∈ (-∞, -4) ∪ (4, ∞) Case-II: => 1 < -b/(2a) < 5 => 1 < m/2 < 5 => m ∈ (2, 10) Case-III: f(1) > 0 and f(5) > 0 1 - m + 4 > 0 and 25 - 5m + 4 > 0 m < 5 and m < 29/5 Case-IV: Let one root is x = 1 1 - m + 4 = 0 m = 5 Now equation x^2 - 5x + 4 = 0 (x - 1)(x - 4) = 0 x = 1 i.e. m = 5 is also included hence m ∈ (4, 5] So given option is (4, 5)
