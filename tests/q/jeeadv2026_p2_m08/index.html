Let y = f(x) be the real valued function defined on the interval (0, ∞), satisfying y(1) = 0 and the differential equation x(dy/dx) = y - x³. Then which of the following statements is (are) TRUE ?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) The function f has a local minimum at x = 1/√3
  2. (B) The function f has a local maximum at x = 1/√3
  3. (C) The function f is increasing in the interval (1, 2)
  4. (D) If g(x) = 4x³ - 5x² + (3/2)x for x > 0, then the number of elements in the set {x ∈ (0, ∞) : f(x) = g(x)} is 2

Answer

Correct answer: B, D

Solution

Solution: The given differential equation is x(dy/dx) = y - x³. Dividing by x, we get: dy/dx - (1/x)y = -x² This is a linear differential equation of the form dy/dx + P(x)y = Q(x), where P(x) = -1/x and Q(x) = -x². Integrating Factor (IF) = e^∫(-1/x)dx = e^(-ln x) = 1/x Multiplying the differential equation by the IF: d/dx(y · 1/x) = -x Integrating both sides with respect to x: y/x = -x²/2 + C y = -x³/2 + Cx Given y(1) = 0: 0 = -1/2 + C ⟹ C = 1/2 Thus, f(x) = x/2 - x³/2. To find local extrema, we find f'(x): f'(x) = 1/2 - 3x²/2 Setting f'(x) = 0 gives 3x² = 1 ⟹ x = 1/√3 (since x > 0). Now, f''(x) = -3x. At x = 1/√3, f''(1/√3) = -√3 < 0. So, f(x) has a local maximum at x = 1/√3. For x ∈ (1,2), x² > 1, so f'(x) = (1 - 3x²)/2 < 0. Thus, f(x) is decreasing in (1,2). For the intersection of f(x) and g(x): x/2 - x³/2 = 4x³ - 5x² + 3x/2 x - x³ = 8x³ - 10x² + 3x 9x³ - 10x² + 2x = 0 x(9x² - 10x + 2) = 0 Since x ∈ (0, ∞), x ≠ 0. We solve 9x² - 10x + 2 = 0. Discriminant Δ = (-10)² - 4(9)(2) = 100 - 72 = 28 > 0. Sum of roots = 10/9 > 0 and Product of roots = 2/9 > 0. Both roots are real and positive. Therefore, there are exactly 2 elements in the set. Answer: The function f has a local maximum at x = 1/√3. If g(x) = 4x³ - 5x² + 3x/2 for x > 0, then the number of elements in the set {x ∈ (0, ∞) : f(x) = g(x)} is 2.
