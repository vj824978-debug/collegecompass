Let y(x) be a solution of the differential equation (1 + e^x)y' + ye^x = 1. If y(0) = 2, then which of the following statements is (are) true ?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) y(-4) = 0
  2. (B) y(-2) = 0
  3. (C) y(x) has a critical point in the interval (-1, 0)
  4. (D) y(x) has no critical point in the interval (-1, 0)

Answer

Correct answer: AC

Solution

dy/dx + ye/(1+e^x) = 1/(e^x+1) I.F. = e^(∫e^x/(1+e^x)dx) = e^(ln(1+e^x)) = 1+e^x ⟹ y(1+e^x) = ∫1dx y(1+e^x) = x+c y = (x+c)/(1+e^x) y(0) = 2 ⟹ c = 1 ⟹ y = (x+4)/(1+e^x) y(-4) = 0 ⟹ y' = [(1+e^x)-(x+4)e^x]/(1+e^x)^2 = 0 Let g(x) = [(1+e^x)-(x+4)e^x]/(1+e^x)^2 g(0) = (2-4)/2^2 < 0 g(-1) = [(1+1/e)·3/e - 1-2/e]/[1+1/e]^2 > 0 g(0)·g(-1) < 0. Hence g(x) has a root in between (-1, 0)
