If theta is in [-7pi/6, 4pi/3], then the number of solutions of sqrt(3)cosec^2(theta) - 2(sqrt(3)-1)cosec(theta) - 4 = 0 is equal to

  1. (1) 8
  2. (2) 6
  3. (3) 7
  4. (4) 10

Answer

Correct answer: Option 2

Solution

Let x = cosec(theta). The equation becomes sqrt(3)x^2 - 2(sqrt(3)-1)x - 4 = 0. Using quadratic formula: x = [2(sqrt(3)-1) ± sqrt(4(sqrt(3)-1)^2 + 16sqrt(3))]/(2sqrt(3)). Simplifying: x = [2(sqrt(3)-1) ± sqrt(4(3-2sqrt(3)+1) + 16sqrt(3))]/(2sqrt(3)) = [2(sqrt(3)-1) ± sqrt(16-8sqrt(3)+16sqrt(3))]/(2sqrt(3)) = [2(sqrt(3)-1) ± sqrt(16+8sqrt(3))]/(2sqrt(3)). This gives x = 2 or x = -2/sqrt(3). For cosec(theta) = 2, sin(theta) = 1/2 gives theta values in the given interval. For cosec(theta) = -2/sqrt(3), sin(theta) = -sqrt(3)/2 gives theta values in the given interval. Count all valid solutions in [-7pi/6, 4pi/3].
