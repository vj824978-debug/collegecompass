If the system of equations 3x + y + 4z = 3 2x + αy - z = -3 x + 2y + z = 4 has no solution, then the value of α is equal to:

  1. (1) 19
  2. (2) 4
  3. (3) 13
  4. (4) 23

Answer

Correct answer: Option 1

Solution

for no solution Δ = 0 |3 1 4| |2 α -1| = 0 |1 2 1| ⇒ 3(α + 2) + 1(-1 - 2) + 4(4 - α) = 0 ⇒ 3α + 6 - 1 - 3 + 16 - 4α = 0 ⇒ 19 - α = 0 ⇒ α = 19 & for α = 19 |3 1 4| Δ_x = |-3 19 -1| = 3(21) + 1(-1) + 4(-82) |4 2 1| ≠ 0 ∴ no solution for α = 19
