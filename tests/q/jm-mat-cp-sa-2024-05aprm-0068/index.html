The integral ∫[0 to π/4] (136sin x)/(3sin x + 5cos x) dx is equal to:

  1. (1) 3π - 50 log_e 2 + 20 log_e 5
  2. (2) 3π - 25 log_e 2 + 10 log_e 5
  3. (3) 3π - 10 log_e (2√2) + 10 log_e 5
  4. (4) 3π - 30 log_e 2 + 20 log_e 5

Answer

Correct answer: Option 1

Solution

Express 136sin x = A(3sin x + 5cos x) + B(3cos x - 5sin x). Comparing coefficients: 136 = 3A - 5B and 0 = 5A + 3B. Solving: A = 12, B = -20. Split integral into two parts: ∫A(3sin x + 5cos x)/(3sin x + 5cos x)dx + ∫B(3cos x - 5sin x)/(3sin x + 5cos x)dx = A·x + B·ln|3sin x + 5cos x| evaluated from 0 to π/4. Substitute limits: 12(π/4) - 20·ln(3/√2 + 5/√2) + 20·ln(5) = 3π - 20·ln(8/√2) + 20ln5 = 3π - 50log_e 2 + 20log_e 5
