Let the plane 2x + 3y + z + 20 = 0 be rotated through a right angle about its line of intersection with the plane x - 3y + 5z = 8. If the mirror image of the point (2, -1/2, 2) in the rotated plane is B(a, b, c), then:

  1. (1) a/8 = b/5 = c/(-4)
  2. (2) a/4 = b/5 = c/(-2)
  3. (3) a/8 = b/(-5) = c/4
  4. (4) a/4 = b/5 = c/2

Answer

Correct answer: Option 1

Solution

The rotated plane P is perpendicular to 2x + 3y + z + 20 = 0 and contains the line of intersection. Using the family of planes through the intersection line: P: (2x + 3y + z + 20) + λ(x - 3y + 5z - 8) = 0. For perpendicularity to the original plane, solving gives λ = 7. This yields P: x - 2y + 4z = 4. The mirror image of (2, -1/2, 2) in this plane, using the perpendicularity condition and the plane equation, gives a = 4/3, b = 5/6, c = -2/3. Therefore a:b:c = 8:5:-4.
