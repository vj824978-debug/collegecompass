The maximum value of term independent of 't' in the expansion of (tx^(1/3) + (1-x)^10/t) where x ∈ (0, 1) is:

  1. (1) 10!/(sqrt(3)(5!)^2)
  2. (2) 2·10!/(3·sqrt(3)(5!)^2)
  3. (3) 10!/(3(5!)^2)
  4. (4) 2·10!/(3(5!)^2)

Answer

Correct answer: Option 2

Solution

General term T_(r+1) = C(10,r)·(tx^(1/3))^(10-r)·((1-x)^10/t)^r = C(10,r)·t^(10-2r)·x^((10-r)/3)·(1-x)^(10r). For term independent of t: 10-2r = 0, so r = 5. For term independent of x: (10-r)/3 = 0, which gives r = 10 (contradiction). So we need term independent of t with r = 5: T_6 = C(10,5)·x^(5/3)·(1-x)^10. To maximize, find maximum of f(x) = x^(5/3)·(1-x)^(10). Taking derivative: f'(x) = (5/3)x^(2/3)(1-x)^10 - 10x^(5/3)(1-x)^9 = 0. This gives x^(2/3)(1-x)^9[(5/3)(1-x) - 10x] = 0. Solving: 5(1-x)/3 = 10x, so 5-5x = 30x, thus x = 2/3. Maximum value = C(10,5)·(2/3)^(5/3)·(1/3)^10 = 252·(2/3)^(5/3)·(1/3)^10 = 2·10!/(3·sqrt(3)(5!)^2).
