A tangent is drawn to the parabola y^2 = 6x which is perpendicular to the line 2x + y = 1. Which of the following points does NOT lie on it?

  1. (1) (5, 4)
  2. (2) (-6, 0)
  3. (3) (0, 3)
  4. (4) (4, 5)

Answer

Correct answer: Option 1

Solution

The line 2x + y = 1 has slope m1 = -2. A perpendicular line has slope m2 = 1/2. For parabola y^2 = 6x, using y = mx + a/m form with m = 1/2 and a = 3/2 (since 4a = 6), we get y = (1/2)x + 3. Testing the points: (5,4): 4 = 2.5 + 3 = 5.5 (NO); (-6,0): 0 = -3 + 3 = 0 (YES); (0,3): 3 = 0 + 3 = 3 (YES); (4,5): 5 = 2 + 3 = 5 (YES). Point (5,4) does not lie on the tangent.
