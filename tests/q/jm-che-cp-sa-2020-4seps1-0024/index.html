If 75% of a first order reaction was completed in 90 minutes, 60% of the same reaction would be completed in approximately (in minutes) ________. (Take: log 2 = 0.30; log 2.5 = 0.40)

Answer

Correct answer: 60

Solution

For a first order reaction: t_0.75 = 2 × (ln 2)/k = 90 k = (ln 2)/45 min^(-1) For 60% completion: kt = ln(1/(1-0.6)) = ln 2.5 (ln 2)/45 × t = ln 2.5 t = 45 × (log 2.5)/(log 2) = 45 × 0.4/0.3 = 60 min.
