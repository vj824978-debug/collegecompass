Let N denote the set of all natural numbers, and Z denote the set of all integers. Consider the functions f: N → Z and g: Z → N defined by f(n) = { (n+1)/2 if n is odd, (4-n)/2 if n is even } and g(n) = { 3+2n if n ≥ 0, -2n if n < 0 } Define (g ∘ f)(b) = g(f(n)) for all n ∈ N, and (f ∘ g(n)) = f(g(n)) for all n ∈ Z. Then which of the following statements is (are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) g ∘ f is NOT one-one and g ∘ f is NOT onto
  2. (B) f ∘ g is NOT one-one but f ∘ g is onto
  3. (C) g is one-one and g is onto
  4. (D) f is NOT one-one but f is onto

Answer

Correct answer: AD

Solution

f(n) = {(n+1)/2, n = odd natural number; 2 - n/2, n = even natural number} ⟹ (n+1)/2 ≥ 1 ∀ n = odd natural number 2 - n/2 ≤ 1 ∀ n = even natural number g(n) = 3 + 2n ≥ 3 for n ≥ 0 and is odd integer g(n) = -2n ≥ 2 ∀ n < 0 and is even integer ⟹ f(n) is many one and is onto function g(n) ≠ 1 hence is not onto f(g(n)) = {(3 + 2n + 1)/2 = 2 + n, n ≥ 0, n ∈ ℤ; 2 + n, n < 0, n ∈ ℤ} f(g(n)) = 2 + n, n ∈ ℤ is one-one. g(f(1)) = g(1) = g(f(2)) ⟹ g(f(n)) is many one. since g(n) ≠ 1 ⟹ g(f(n)) ≠ 1 hence not onto
