A → products (First order reaction). Three sets of experiment were performed for a reaction under similar experimental conditions. Run 1 ⇒ 100 mL of 10 M solution of reactant A. Run 2 ⇒ 200 mL of 10 M solution of reactant A. Run 3 ⇒ 100 mL of 10 M solution of reactant A + 100 mL of H₂O added. The correct variation of rate of reaction is

  1. (1) Run 1 = Run 2 = Run 3
  2. (2) Run 3 < Run 1 = Run 2
  3. (3) Run 3 < Run 1 < Run 2
  4. (4) Run 1 < Run 2 < Run 3

Answer

Correct answer: Option 2

Solution

For 1st order reaction Rate = k[A] with decrease in concentration of A, rate of reaction decreases. Run 1: 100 mL of 10 M solution of A Concentration of A = 10 M Rate₁ = k × 10 Run 2: 200 mL of 10 M solution of A Concentration of A = 10 M (same concentration, same volume dependence) Rate₂ = k × 10 Run 3: 100 mL of 10 M solution of A + 100 mL of H₂O Total volume = 200 mL Concentration of A = (100 × 10)/(100 + 100) = 1000/200 = 5 M Rate₃ = k × 5 Therefore: Rate₁ = Rate₂ = k × 10 Rate₃ = k × 5 So: Run 3 < Run 1 = Run 2
