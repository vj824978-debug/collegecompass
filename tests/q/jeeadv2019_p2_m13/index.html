Let |x| denote the number of elements in a set X. Let S = {1, 2, 3, 4, 5, 6} be a sample space, where each element is equally likely to occur. If A and B are independent events associated with S, then the number of ordered pairs (A, B) such that 1 ≤ |B| < |A|, equals ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 422.00

Solution

Let |A| = x, |B| = y, |A ∩ B| = P, then P/6 = x/6 · y/6 ⟹ 6P = xy If P = 1 ⟹ (i) x = 6, y = 1 ⟹ ⁶C₆ · ¹C₁ = 6 or ⟹ (ii) x = 3, y = 2 ⟹ ⁶C₃ · ²C₁ · ²C₁ = 180 If P = 2 ⟹ (i) x = 6, y = 2 ⟹ ⁶C₆ · ²C₂ = 15 or (ii) x = 4, y = 3 ⟹ ⁶C₄ · ³C₂ · ²C₁ = 180 If P = 3 ⟹ x = 6, y = 3 ⟹ ⁶C₆ · ³C₃ = 20 If P = 4 ⟹ x = 6, y = 4 ⟹ ⁶C₆ · ⁴C₄ = 15 If P = 5 ⟹ x = 6, y = 5 ⟹ ⁶C₆ · ⁵C₅ = 6 Hence total number of ordered pairs (A, B) = 422.
