Let P and Q be two distinct points on a circle which has center at C(2, 3) and which passes through origin O. If OC is perpendicular to both the line segments CP and CQ, then the set [P, Q] is equal to:

  1. (1) (-1, 5), (5, 1)
  2. (2) (2 + 2*sqrt(2), 3 + sqrt(5)), (2 - 2*sqrt(2), 3 - sqrt(5))
  3. (3) (2 + 2*sqrt(2), 3 - sqrt(5)), (2 - 2*sqrt(2), 3 + sqrt(5))
  4. (4) (4, 0), (0, 6)

Answer

Correct answer: Option 1

Solution

Circle has center C(2, 3) and passes through origin O(0, 0). Radius r = sqrt(4 + 9) = sqrt(13). Since OC is perpendicular to both CP and CQ, points P and Q lie on a line perpendicular to OC. The line OC has slope 3/2, so perpendicular line has slope -2/3. Using tan(angle) = -2/3 and the parametric form P, Q: (2 ± sqrt(13)*cos(theta), 3 ± sqrt(13)*sin(theta)). With the perpendicularity condition and solving the constraint equations, we get P, Q = (2 + 2*sqrt(2), 3 - sqrt(5)), (2 - 2*sqrt(2), 3 + sqrt(5)).
