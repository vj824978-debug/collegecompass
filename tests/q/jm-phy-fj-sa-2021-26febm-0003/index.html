Find the electric field at point P (as shown in figure) on the perpendicular bisector of a uniformly charged thin wire of length L carrying a charge Q. The distance of the point P from the centre of the rod is a = sqrt(3)/2 * L.

  1. (1) Q / (3*pi*epsilon_0*L^2)
  2. (2) Q / (2*sqrt(3)*pi*epsilon_0*L^2)
  3. (3) Q / (4*pi*epsilon_0*L^2)
  4. (4) sqrt(3)*Q / (4*pi*epsilon_0*L^2)

Answer

Correct answer: Option 2

Solution

Using the formula E = (lambda / 4*pi*epsilon_0*a) * [sin(alpha) + sin(alpha)] = (lambda*sin(alpha)) / (2*pi*epsilon_0*a). With Q = lambda*L and a = sqrt(3)/2 * L, we get E = Q / (L*2*pi*epsilon_0) * 1 / (sqrt(3)*L/2) = Q / (2*sqrt(3)*pi*epsilon_0*L^2). From geometry: tan(alpha) = (L/2) / (sqrt(3)*L/2) = 1/sqrt(3), so alpha = pi/6 and sin(alpha) = 1/2.
