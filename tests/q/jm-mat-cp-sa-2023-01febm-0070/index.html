For a triangle ABC, the value of cos2A + cos2B + cos2C is least. If its inradius is 3 and incentre is M, then which of the following is NOT correct?

  1. (1) MA · MB = −18
  2. (2) perimeter of △ABC is 18√3
  3. (3) area of △ABC is (27√3)/2
  4. (4) sin2A + sin2B + sin2C = sinA + sinB + sinC

Answer

Correct answer: Option 3

Solution

We know that cos2A + cos2B + cos2C ≥ −3/2 where equality holds for equilateral triangle r = △/s = (√3 a^2)/4 / (3a/2) = a/(2√3) Given r = 3, so a = 2√3 · r = 6√3 Area = (√3/4)a^2 = (√3/4)(6√3)^2 = (√3/4) · 108 = 27√3 For equilateral triangle with side a = 6√3: - Perimeter = 3a = 3(6√3) = 18√3 ✓ (option 2 is correct) - Area = 27√3 ✓ (option 3 is correct) For option (1): MA · MB = −18 In an equilateral triangle, this involves the product of distances from vertices to incentre. This requires verification through coordinate geometry or standard formulas for equilateral triangles. For option (4): sin2A + sin2B + sin2C = sinA + sinB + sinC For equilateral triangle: A = B = C = 60° LHS = sin120° + sin120° + sin120° = (√3/2) + (√3/2) + (√3/2) = 3√3/2 RHS = sin60° + sin60° + sin60° = (√3/2) + (√3/2) + (√3/2) = 3√3/2 So option (4) is correct for equilateral triangle. Area = 27√3, not (27√3)/2 as stated in option (3). Therefore option (3) is NOT correct.
