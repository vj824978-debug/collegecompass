If the equation of the plane passing through the line of intersection of the planes 2x - y + z = 3, 4x - 3y + 5z + 9 = 0 and parallel to the line (x+1)/(-2) = (y+3)/4 = (z-2)/5 is ax + by + cz + 6 = 0, then a + b + c is equal to-

  1. (1) 12
  2. (2) 14
  3. (3) 15
  4. (4) 13

Answer

Correct answer: Option 2

Solution

Family of planes through line of intersection: P₁ + λP₂ = 0, where P₁ = 2x - y + z - 3 and P₂ = 4x - 3y + 5z + 9. This gives P₃ = (2 + 4λ)x - (1 + 3λ)y + (1 + 5λ)z - (3 - 9λ) = 0. For P₃ parallel to the given line, the normal of P₃ must be perpendicular to the direction ratios (-2, 4, 5) of the line. So: -2(2 + 4λ) - 4(1 + 3λ) + 5(1 + 5λ) = 0. Solving: -3 + 5λ = 0, λ = 3/5. Substituting λ = 3/5: P₃ = 22x/5 - 14y/5 + 20z/5 + 12/5 = 0, which gives 11x - 7y + 10z + 6 = 0. Thus a = 11, b = -7, c = 10, and a + b + c = 14.
