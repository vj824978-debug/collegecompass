Let R be a relation defined on N as a R b if 2a + 3b is a multiple of 5, a, b ∈ N. Then R is

  1. (1) an equivalence relation
  2. (2) not reflexive
  3. (3) symmetric but not transitive
  4. (4) transitive but not symmetric

Answer

Correct answer: Option 1

Solution

a R b if 2a + 3b = 5m, m ∈ I (1) (a, a) ∈ R as 2a + 3a = 5a, a ∈ N Hence R is reflexive (2) If (a, b) ∈ R then 2a + 3b = 5m Now, 5(a + b) = 5n 3a + 2b + 2a + 3b = 5n 3a + 2b = 5(n - m) ∴ (b, a) ∈ R ∴ R is symmetric (3) If (a, b) ∈ R and (b, c) ∈ R then 2a + 3b = 5m, 2b + 3c = 5n ⟹ 2a + 5b + 3c = 5(m + n) ⟹ 2a + 3c = 5(m + n - b) ∴ (a, c) ∈ R ∴ R is transitive Hence R is equivalence relation. option (1) is correct.
