One mole of mono-atomic ideal gas is taken along two cyclic processes E→F→G→E and E→F→H→E as shown in the PV diagram. The processes involved are purely isochoric, isobaric, isothermal or adiabatic. [PV diagram showing a pressure-volume graph with point F at (V₀, 32P₁), point E at (V₀, P₁), point G at rightmost position on horizontal axis, and point H between E and G on the horizontal axis. Three paths are shown: E→F (vertical line up), F→G (curved line down and right), G→E (horizontal line left), F→H (curved line), and H→E (horizontal line left).] Match the paths in List I with the magnitudes of the work done in List II and select the correct answer using the codes given below the lists. List I: P. G→E, Q. G→H, R. F→H, S. F→G List II: 1. 160 P₀V₀ ln2, 2. 36 P₀V₀, 3. 24 P₀V₀, 4. 31 P₀V₀

Matrix match · Marks: +4 / -1.0

  1. (A) P→4, Q→3, R→2, S→1
  2. (B) P→4, Q→3, R→1, S→2
  3. (C) P→3, Q→1, R→2, S→4
  4. (D) P→1, Q→3, R→2, S→4

Answer

Correct answer: A

Solution

Sol. (A) P. → (4); Q. → (3); R. → (2); S. → (1) Apply PV^(1+2/3) = constant for F to H. (32P₀) V₀^(5/3) = P₀ V_H^(5/3) ⟹ V_H = 8V₀ For path FG PV = constant ⟹ (32P₀)V₀ = P₀V_G ⟹ V_G = 32V₀ Work done in GE = 31 P₀V₀ Work done in GH = 24 P₀V₀ Work done in FH = (P_F V_F - P_E V_E)/(-2/f) = 36P₀V₀ Work done in FG = RT ln(V_G/V_F) = 160P₀V₀ln2.
