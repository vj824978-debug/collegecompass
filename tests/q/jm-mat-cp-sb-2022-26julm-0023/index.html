The series of positive multiples of 3 is divided into sets: {3}, {6, 9, 12}, {15, 18, 21, 24, 27}, ...... Then the sum of the elements in the 11th set is equal to ________.

Answer

Correct answer: 6993

Solution

The sets are divided such that set n contains n elements. Set 1 has 1 element, set 2 has 3 elements, set 3 has 5 elements, etc. The 11th set will have 1 + (10)×2 = 21 elements. Up to the 10th set, total elements = 1 + 3 + 5 + ... + 19 = 100 elements. The 11th set starts with the 101st multiple of 3, which is 3×101. Set 11 = {3×101, 3×102, ..., 3×121}. Sum = 3×(101 + 102 + ... + 121) = 3 × (222 × 21)/2 = 3 × 2331 = 6993.
