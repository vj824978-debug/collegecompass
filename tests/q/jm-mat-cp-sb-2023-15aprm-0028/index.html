If the line x = y = z intersects the line xsinA + ysinB + zsinC - 18 = 0 = xsin2A + ysin2B + zsin2C - 9, where A, B, C are the angles of a triangle ABC, then 80(sin(A/2).sin(B/2).sin(C/2)) is equal to ____.

Answer

Correct answer: 5

Solution

Let x = y = z = k. From first line equation: k(sinA + sinB + sinC) = 18, which gives k(4cos(A/2).cos(B/2).cos(C/2)) = 18. From second line equation: k(sin2A + sin2B + sin2C) = 9, which gives k(4sinA.sinB.sinC) = 9. Dividing equation (ii) by equation (i): (8sin(A/2).sin(B/2).sin(C/2))/18 = 9/18. Therefore 80sin(A/2).sin(B/2).sin(C/2) = 5.
