Kjeldahl's method cannot be used to estimate nitrogen for which of the following compounds?

  1. (1) NH2 - C(=O) - NH2
  2. (2) C6H5NH2
  3. (3) C6H5NO2
  4. (4) CH3CH2 - C ≡ N

Answer

Correct answer: Option 3

Solution

Kjeldahl's method cannot be used to test nitrogen in nitro and diazo compounds present in ring because nitrogen in nitro compounds cannot convert into Ammonium sulphate. Hence, does not give test. Analysis of each option: (1) NH2 - C(=O) - NH2 (Urea): Contains amino nitrogen, can be estimated by Kjeldahl's method. (2) C6H5NH2 (Aniline): Contains amino nitrogen attached to benzene ring, can be estimated by Kjeldahl's method. (3) C6H5NO2 (Nitrobenzene): Contains nitrogen in the form of nitro group (-NO2) which is attached to the benzene ring. The nitrogen in nitro compounds cannot be converted to ammonium sulphate during the digestion process, so Kjeldahl's method cannot be used. (4) CH3CH2 - C ≡ N (Propionitrile): Contains nitrile nitrogen, can be estimated by Kjeldahl's method as the triple bonded nitrogen converts to ammonia during digestion. Therefore, option (3) C6H5NO2 is the correct answer as nitrogen in the nitro group cannot be estimated by Kjeldahl's method.
