  2. (2) (2/3)(20 log_e(2) + 9)
  3. (3) (2/3)(24 log_e(2) - 7)
  4. (4) (1/3)(40 log_e(2) + 27)

Answer

Correct answer: Option 3

Solution

The intersection point is (2, 4). The curves y = x^2 and y = 1 intersect when x^2 = 1, giving x = 1 (since x ≥ 0). The intersection point is (1, 1).
