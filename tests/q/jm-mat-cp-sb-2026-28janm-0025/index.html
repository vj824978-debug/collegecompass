Let PQR be a triangle such that PQ = -2i + 2k and PR = ai + bj - 4k, a,b ∈ Z. Let S be the point on QR, which is equidistant from the lines PQ and PR. If |PS| = 9 and PS = (-7j + 2k), then the value of 3a - 4b is

Answer

Correct answer: 37

Solution

PQ = -2i + 2k PR = ai + bj - 4k, a,b ∈ Z |PQ| = 0 a^2 + b^2 + 16 = 81 a^2 + b^2 = 65 ... (1) cos(θ) = (PQ · PS)/(|PQ||PS|) = (-2)(7) + 4 = -2 + 7 + 4 = 9/(3√6 × 3√6) = -2 + 7 + 4 = 9/(3√6) = 1/(√6) PS · PR/|PS||PR| = 3√6 - 9/(3√6 - 9) = 1/√6 PS is internal Angle bisector of ∠QPR hence 2PQ/PR = PQ + PR = |PQ| + |PR|/|PS||PR| = 3√6/9 = 3/√6 ⇒ cos θ = 2√6/(2√2) = [Not possible] Hence No such triangle is possible Alternatively, If the constraint is a·b = 7, b = -4 ∴ a = 7, b = -4 ∴ 3a - 4b = 21 + 16 = 37 But here PS is internal Angle bisector of ∠QPR hence 2PQ/PR = (PQ + PR) ⇒ |PQ|/|PR| = |PS|/|PR| ⇒ a = 7, b = -4 ∴ PQ = -2i - 4j - 4k ∴ PS = -7j + 2k
