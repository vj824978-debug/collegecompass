Let A = [aij] be a square matrix of order 3 such that aij = 2^(j-1), for all i, j = 1, 2, 3. Then, the matrix A^2 + A^3 + ... + A^10 is equal to:

  1. (1) ((3^10 - 3)/2)A
  2. (2) ((3^10 - 1)/2)A
  3. (3) ((3^10 + 1)/2)A
  4. (4) ((3^10 + 3)/2)A

Answer

Correct answer: Option 1

Solution

Matrix A has elements aij = 2^(j-1). Computing A^2 = 3A. Then A^3 = A·A^2 = A(3A) = 3A^2 = 3^2·A. By induction, A^n = 3^(n-1)·A. Therefore, A^2 + A^3 + ... + A^10 = A[3^1 + 3^2 + 3^3 + ... + 3^9] = A·(3(3^9 - 1))/(3 - 1) = A·(3(3^9 - 1))/2 = ((3^10 - 3)/2)A
