If the shortest distance between the lines (x-1)/2 = (y-2)/3 = (z-3)/4 and x/1 = y/alpha = (z-5)/1 is 5/sqrt(6), then the sum of all possible values of alpha is

  1. (1) -3
  2. (2) 3/2
  3. (3) 3
  4. (4) -3/2

Answer

Correct answer: Option 1

Solution

Using shortest distance formula between two skew lines: d = |(a-b)·(p1 × p2)| / |p1 × p2| = 5/sqrt(6). Here a-b = i + 2j - 2k and p1 × p2 = i(3-4a) - j(-2) + k(2a-3) = i(3-4a) + 2j + k(2a-3). Therefore (a-b)·(p1×p2) = 3 - 4a + 4 + 2a - 3 = 13 - 8a. Taking magnitude: |13-8a|/sqrt((3-4a)^2 + 4 + (2a-3)^2) = 5/sqrt(6). Squaring: 6(13-8a)^2 = 25(20a^2 - 36a + 22). Simplifying: 116a^2 + 348a - 464 = 0, or 29a^2 + 87a - 116 = 0. Sum of roots = -87/29 = -3.
