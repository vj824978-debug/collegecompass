Which one of the following options represents the magnetic field B at O due to the current flowing in the given wire segments lying on the xy plane? [Figure shows a wire configuration with: a vertical segment of length L, a horizontal segment of length L/2, another vertical segment of length 3L/4, a semicircular segment of radius L/4, and a quarter-circular segment of radius L/4, all connected. Point O is at the center of the semicircle. Current direction is marked with arrows.]

Single correct MCQ · Marks: +3 / -1.0

  1. (A) B = -μ₀I/L (3/2 + 1/(4√(2π))) k
  2. (B) B = -μ₀I/L (3/2 + 1/(2√(2π))) k
  3. (C) B = -μ₀I/L (1 + 1/(4√(2π))) k
  4. (D) B = -μ₀I/L (1 + 1/(4π)) k

Answer

Correct answer: C

Solution

[Diagram shows a 3D coordinate system with points A through G forming wire segments. Point A is at origin, B is distance L above A. From B, a segment L/2 goes to point C. From C, segments form a path through D, E, F to G, with distances L/4 marked. Total distance from C to G is 3L/4.] B_Net = B_AB + B_BC + B_CD + B_DE + B_EF + B_FG B_AB = B_DE = B_FG = 0 B_AB = (μ₀I)/(4πL) sin 45° [-k] B_CD = (μ₀I)/(4(L/2)) [-k] B_EF = (μ₀I)/(8(L/4)) [-k] ⟹ (C)
