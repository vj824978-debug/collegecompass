Let the system of linear equations x + y + kz = 2, 2x + 3y - z = 1, 3x + 4y + 2z = k have infinitely many solutions. Then the system (k + 1)x + 2(k - 1)y = 7, (2k + 1)x + (k + 5)y = 10 has:

  1. (1) Unique solution satisfying x + y = 1
  2. (2) Unique solution satisfying x - y = 1
  3. (3) Infinitely many solutions
  4. (4) No solution

Answer

Correct answer: Option 1

Solution

x + y + kz = 2 ...(1) 2x + 3y - z = 1 ...(2) 3x + 4y + 2z = k ...(3) (1) + (2) 3x + 4y + z(k - 1) = 3 Comparing with (3) k = 3 Now, 4x + 5y = 7 => 3x + 3y = 3 7x + 8y = 10 as 4/7 ≠ 5/8 ∴ unique solution satisfying x + y = 1
