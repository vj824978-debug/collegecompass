If the mean of the following probability distribution of a random variable X is 46/9, then the variance of the distribution is

  1. (1) 581/81
  2. (2) 566/81
  3. (3) 173/27
  4. (4) 151/27

Answer

Correct answer: Option 2

Solution

Given: P(X=0)=a, P(X=2)=2a, P(X=4)=a+b, P(X=6)=2b, P(X=8)=3b, E(X)=46/9. Step 1: Sum of probabilities = 1, so a + 2a + a + b + 2b + 3b = 1, which gives 4a + 6b = 1. Step 2: E(X) = 0(a) + 2(2a) + 4(a+b) + 6(2b) + 8(3b) = 46/9. This gives 8a + 40b = 46/9. Step 3: Solving equations: 4a + 20b = 23/9 (from equation II). Subtracting (I) from this gives b = 1/9 and a = 1/12. Step 4: E(X^2) = 0 + 4(2a) + 16(a+b) + 36(2b) + 64(3b) = 24a + 280b = 2 + 280/9 = 298/9. Step 5: Variance = E(X^2) - [E(X)]^2 = 298/9 - (46/9)^2 = 298/9 - 2116/81 = 566/81.
