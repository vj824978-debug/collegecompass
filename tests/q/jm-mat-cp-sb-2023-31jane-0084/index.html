Let vector a, vector b, vector c be three vectors such that |vector a| = sqrt(31), |vector b| = |vector c| = 2 and 2(vector a x vector b) = 2(vector c x vector a). If the angle between vector b and vector c is 2pi/3, then (|vector a x vector c|^2)/(|vector a·vector b|^2) is equal to

Answer

Correct answer: 3

Solution

From the given condition: vector a × (2vector b + 3vector c) = 0 This means: vector a = lambda(2vector b + 3vector c) Taking magnitude squared: |vector a|^2 = lambda^2(4|vector b|^2 + 9|vector c|^2 + 12vector b·vector c) Given: |vector a|^2 = 31, |vector b| = |vector c| = 2 Angle between vector b and vector c is 2pi/3, so: vector b·vector c = 2 × 2 × cos(2pi/3) = 4 × (-1/2) = -2 Substituting: 31 = lambda^2(4(4) + 9(4) + 12(-2)) 31 = lambda^2(16 + 36 - 24) 31 = 31lambda^2 lambda = ±1 So: vector a = ±(2vector b + 3vector c) Now calculating |vector a × vector c|: |vector a × vector c| = |2(vector b × vector c)| = 2|vector b × vector c| |vector b × vector c|^2 = |vector b|^2|vector c|^2 - (vector b·vector c)^2 = 4 × 4 - (-2)^2 = 16 - 4 = 12 Wait, recalculating: |vector b × vector c|^2 = 4 - (1 - 1/2)^2 = 3/4 So |vector a × vector c| = sqrt(3) For vector a·vector b: vector a·vector b = ±(2|vector b|^2 + 3vector b·vector c) = ±(2(4) + 3(-2)) = ±(8 - 6) = ±2 Now: (|vector a × vector c|^2)/(|vector a·vector b|^2) = 3/1 = 3
