Let A be the set of all points (u, β) such that the area of triangle formed by the points (5, 6), (3, 2) and (u, β) is 12 square units. Then the least possible length of a line segment joining the origin to a point in A, is:

  1. (1) 16/sqrt(5)
  2. (2) 4/sqrt(5)
  3. (3) 12/sqrt(5)
  4. (4) 8/sqrt(5)

Answer

Correct answer: Option 4

Solution

Using the area formula for a triangle with vertices (5,6), (3,2), and (u,β): |5(2-β) + 3(β-6) + u(6-2)| / 2 = 12. This gives 4u - 2β - 8 = ±24, leading to two cases: 4u - 2β = 32 or 4u - 2β = -16, which simplify to 2u - β = 16 or 2u - β = -8. The point (u,β) lies on one of these two lines. The distance from origin to line 2u - β = c is |c|/sqrt(5). For the first line: D = 16/sqrt(5). For the second line: D = 8/sqrt(5). The minimum distance is 8/sqrt(5).
