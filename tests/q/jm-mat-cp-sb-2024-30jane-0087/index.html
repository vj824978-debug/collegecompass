Let a line passing through the point (-1, 2, 3) intersect the lines L1: (x-1)/3 = (y-2)/2 = (z+1)/(-2) at M(α, β, γ) and L2: (x+2)/(-3) = (y-2)/(-2) = (z-1)/4 at N(a, b, c). Then the value of ((α+β+γ)^2)/((a+b+c)^2) equals ____.

Answer

Correct answer: 196

Solution

M ≡ (α, β, γ) = (3λ + 1, 2λ + 2, -2λ - 1); N ≡ (a, b, c) = (-3t - 2, -2t + 2, 4t + 1); A(-1, 2, 3); Direction ratios of line through A: 3λ + 2, 2λ, -2λ - 4 or -3t - 1, -2t, 4t - 2; Setting equal: (3λ + 2)/(-3t - 1) = (2λ)/(-2t) = (-2λ - 4)/(4t - 2); Solving: λ = 4, t = 2; Therefore M(13, 10, -9), N(-8, -2, 9); (α+β+γ)^2/(a+b+c)^2 = (13+10-9)^2/(-8-2+9)^2 = (14)^2/(-1)^2 = 196/1 = 196
