If AB4 molecule is a polar molecule, a possible geometry of AB4 is :

  1. (1) Square pyramidal
  2. (2) Tetrahedral
  3. (3) Square planar
  4. (4) Rectangular planar

Answer

Correct answer: Option 1

Solution

(1) If AB4 molecule is a square pyramidal then it has one lone pair and their structure should be: [diagram showing B atoms around A with one lone pair on A] and it should be polar because dipole moment of lone pair of 'A' never be cancelled by others. (2) If AB4 molecule is a tetrahedral then it has no lone pair and their structure should be: [diagram showing B atoms in tetrahedral arrangement around A] and it should be non polar due to perfect symmetry. (3) If AB4 molecule is a square planar then [diagram showing B atoms in square planar arrangement around A] it should be non polar because vector sum of dipole moment is zero. (4) If AB4 molecule is a rectangular planar then [diagram showing B atoms in rectangular planar arrangement around A] it should be non polar because vector sum of dipole moment is zero. Since AB4 is given to be a polar molecule, only square pyramidal geometry (option 1) satisfies this condition because the lone pair on the central atom A creates an asymmetric electron distribution that results in a net dipole moment that cannot be cancelled by the B-A bond dipoles.
