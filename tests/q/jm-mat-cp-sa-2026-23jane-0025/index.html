Let S denote the set of 4-digit numbers abcd such that a > b > c > d and P denote the set of 5-digit numbers having product of its digits equal to 20. Then n(S) + n(P) is equal to.

Answer

Correct answer: 260

Solution

For n(S): We need 4-digit numbers abcd where a > b > c > d and all are distinct digits. This is equivalent to choosing 4 distinct digits from {0, 1, 2, ..., 9} and arranging them in decreasing order. However, since it's a 4-digit number, a ≠ 0 (automatically satisfied since a is the largest). Therefore, n(S) = C(10,4) = 10!/(4!·6!) = 210 The two cases mentioned are: (5,4,1,1,1) and (5,2,2,1,1) For n(P): We need 5-digit numbers with product of digits equal to 20. Factorizations of 20 into single digits: 20 = 5×4×1×1×1 = 5×2×2×1×1 Case 1: (5,4,1,1,1) - digits are 5, 4, 1, 1, 1 Number of arrangements = 5!/(1!·1!·3!) = 120/6 = 20 Case 2: (5,2,2,1,1) - digits are 5, 2, 2, 1, 1 Number of arrangements = 5!/(1!·2!·2!) = 120/4 = 30 Therefore, n(P) = 20 + 30 = 50 n(S) + n(P) = 210 + 50 = 260
