Let α and β be the distinct roots of the equation x^2 + x - 1 = 0. Consider the set T = {1, α, β}. For a 3 × 3 matrix M = (a_{ij})_{3×3}, define R_i = a_{i1} + a_{i2} + a_{i3} and C_j = a_{1j} + a_{2j} + a_{3j} for i = 1, 2, 3 and j = 1, 2, 3. Match each entry in List-I to the correct entries in List-II. List - I: (P) The number of matrices M = (a_{ij})_{3×3} with all entries in T such that R_i = C_j = 0 for all i, j, is (Q) The number of symmetric matrices M = (a_{ij})_{3×3} with all entries in T such that C_j = 0 for all j, is (R) Let M = (a_{ij})_{3×3} be a skew symmetric matrix such that a_{ij} ∈ T for i > j. Then the number of elements in the set {[x; y; z] : x,y,z ∈ ℝ, M[x; y; z] = [a_{12}; 0; -a_{23}]} is (S) Let M = (a_{ij})_{3×3} be a matrix with all entries in T such that R_i = 0 for all i. Then the absolute value of determinant of M is List - II: (1) 1 (2) 12 (3) infinite (4) 6 (5) 0 The correct option is: (A) (P)→(4) (Q)→(2) (R)→(5) (S)→(1) (B) (P)→(2) (Q)→(4) (R)→(1) (S)→(5) (C) (P)→(2) (Q)→(4) (R)→(3) (S)→(5) (D) (P)→(1) (Q)→(5) (R)→(3) (S)→(4)

Matrix match · Marks: +3 / -1.0

  1. (A) (P)→(4) (Q)→(2) (R)→(5) (S)→(1)
  2. (B) (P)→(2) (Q)→(4) (R)→(1) (S)→(5)
  3. (C) (P)→(2) (Q)→(4) (R)→(3) (S)→(5)
  4. (D) (P)→(1) (Q)→(5) (R)→(3) (S)→(4)

Answer

Correct answer: C

Solution

α + β = -1 (P) Only possible when each row and each column of M is made of 1, α, β. Number of ways for first row = 3 × 2 × 1 = 6. Number of ways for second row = 2 × 1 × 1 = 2 Number of ways for third row = 1 × 1 × 1 = 1 Number of such matrices = 6 × 2 × 1 = 12 (Q) Each column should be made of 1, α, β. Since matrix is symmetric, after making column 1, other entries would be fixed by default. Number of ways = 6 (R) Let a₂₁ = a, a₃₁ = b, a₃₂ = c, where {a, b, c} ∈ T M = [0 -a -b] [a 0 -c] [b c 0] Then -ay - bz = -a ⟹ay + bz = a ax - cz = 0 ⟹ax = cz and bx + cy = c If a = b = c, then y + z = 1 x = z, x + y = 1 This has infinite solutions. (S) Each row is made of {1, α, β} Also, 1 + α + β = 0 C₁ → C₁ + C₂ + C₃ makes every element of column 1 as '0'. Hence determinant is 0.
