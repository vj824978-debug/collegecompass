Let P1 be the plane 3x - y - 7z = 11 and P2 be the plane passing through the points (2, -1, 0), (2, 0, -1), and (5, 1, 1). If the foot of the perpendicular drawn from the point (7, 4, -1) on the line of intersection of the planes P1 and P2 is (α, β, γ), then α + β + γ is equal to ____.

Answer

Correct answer: 11.00

Solution

First find equation of P2 using the three points. The direction vectors are (0, 1, -1) and (3, 1, 2). The normal vector to P2 is found using cross product: -6i - 4j - 2k, giving equation x - y - z = 3. The line of intersection has direction vector (-6, -4, -2) or equivalently (3, 2, 1) after simplification, with direction (-6, -4, -2). A point on the line is (4, 1, 0). The line can be written as (4 + 3λ, 1 + 2λ, λ). The perpendicular from (7, 4, -1) to this line satisfies: 3(3λ - 3) + 2(2λ - 3) + 1(λ + 1) = 0, giving 14λ = 14, so λ = 1. The foot of perpendicular is (7, 3, 1), so α + β + γ = 7 + 3 + 1 = 11.
