Given the masses of various atomic particles m_p = 1.0072u, m_n = 1.0087u, m_e = 0.000548u, m_v = 0, m_d = 2.0141u, where p ≡ proton, n ≡ neutron, e ≡ electron, v ≡ antineutrino and d ≡ deuteron. Which of the following process is allowed by momentum and energy conservation?

  1. (1) n + p → d + γ
  2. (2) e^+ + e^- → γ
  3. (3) n + n → deuterium atom (electron bound to the nucleus)
  4. (4) p → n + e^+ + v

Answer

Correct answer: Option 1

Solution

Only in case-1, M_LHS > M_RHS i.e. total mass on reactant side is greater than that on the product side. Hence it will only be allowed. For process (1): n + p → d + γ M_LHS = m_n + m_p = 1.0087 + 1.0072 = 2.0159u M_RHS = m_d + 0 = 2.0141u (photon has no rest mass) Since M_LHS > M_RHS, energy is released (Q-value is positive), and the process is allowed by both energy and momentum conservation.
