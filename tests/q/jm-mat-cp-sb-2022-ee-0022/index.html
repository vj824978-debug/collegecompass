Let S = {(-1, a; 0, b) | a, b ∈ {1, 2, ..., 100}} and let T_n = {A ∈ S : A^(n(n+1)) = I}. Then the number of elements in the intersection from n=1 to 100 of T_n is ___

Answer

Correct answer: 100

Solution

For A = (-1, a; 0, b), we need to find when A^(n(n+1)) = I. When n is even, n(n+1) is always even. Computing powers of A: A^2 = (1, -a-ab; 0, b^2). For A^(n(n+1)) = I with n(n+1) even, we need b = 1 and the exponent to be even. When b = 1, A becomes (-1, a; 0, 1) and even powers give identity matrix. For each value of a ∈ {1, 2, ..., 100}, with b = 1, the condition A^(n(n+1)) = I is satisfied for all n since n(n+1) is always even. Therefore, all 100 values of a with b = 1 are in the intersection of all T_n sets.
