A solid disc of radius 'a' and mass 'm' rolls down without slipping on an inclined plane making an angle θ with the horizontal. The acceleration of the will be (2gsinθ)/b where is --------. (Round off to the Nearest Integer) (g = acceleration due to gravity, θ = angle as shown in figure)

Answer

Correct answer: 3

Solution

For a solid disc rolling without slipping on an inclined plane: mgsinθ - f = ma, fR = Iα = (1/2)mR²α. Since no slipping: a = Rα, so f = (1/2)ma. Therefore: mgsinθ - (1/2)ma = ma, which gives a = (2gsinθ)/3. Comparing with given form a = (2gsinθ)/b, we get b = 3.
