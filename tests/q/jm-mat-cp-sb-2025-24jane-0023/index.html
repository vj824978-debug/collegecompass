Let y = y(x) be the solution of the differential equation 2cosx (dy/dx) = sin 2x - 4y sinx, x ∈ [0, π/2]. If y(π/3) = 0, then y'(π/4) + y(π/4) is equal to ____.

Answer

Correct answer: 1

Solution

Starting with the differential equation: 2cosx (dy/dx) = sin 2x - 4y sinx Divide both sides by 2cosx: dy/dx = (sin 2x)/(2cosx) - (4y sinx)/(2cosx) dy/dx = (2sinx cosx)/(2cosx) - 2y tanx dy/dx = sinx - 2y tanx Rearrange to standard form: dy/dx + 2y tanx = sinx This is a linear first-order ODE of the form dy/dx + P(x)y = Q(x) where P(x) = 2tanx and Q(x) = sinx Integrating factor: I.F. = e^(∫2tanx dx) = e^(2ln|secx|) = sec^2 x Multiply both sides by I.F.: sec^2 x (dy/dx) + 2y tanx sec^2 x = sinx sec^2 x The left side is d/dx(y sec^2 x): d/dx(y sec^2 x) = sinx sec^2 x Integrate both sides: y sec^2 x = ∫sinx sec^2 x dx = ∫tanx secx dx = secx + C Apply initial condition y(π/3) = 0: 0 · sec^2(π/3) = sec(π/3) + C 0 = 2 + C C = -2 Therefore: y sec^2 x = secx - 2 y = cosx - 2cos^2 x Find y'(x): y' = -sinx + 4cosx sinx = -sinx + 4cosx sinx Evaluate at x = π/4: y(π/4) = cos(π/4) - 2cos^2(π/4) = (1/√2) - 2(1/2) = (1/√2) - 1 y'(π/4) = -sin(π/4) + 4cos(π/4)sin(π/4) = -(1/√2) + 4(1/√2)(1/√2) = -(1/√2) + 2 Therefore: y'(π/4) + y(π/4) = [-(1/√2) + 2] + [(1/√2) - 1] = -(1/√2) + 2 + (1/√2) - 1 = 1
