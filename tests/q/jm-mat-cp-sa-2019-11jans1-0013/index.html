If integral of (x+1)/sqrt(2x-1) dx = f(x) sqrt(2x-1) + C, where C is a constant of integration, then f(x) is equal to:

  1. (1) (2/3)(x-4)
  2. (2) (1/3)(x+4)
  3. (3) (1/3)(x+1)
  4. (4) (2/3)(x+2)

Answer

Correct answer: Option 2

Solution

integral of (x+1)/sqrt(2x-1) dx Let sqrt(2x-1) = t 2x - 1 = t^2 2dx = 2t dt dx = t dt Also, x = (t^2 + 1)/2 So the integral becomes: integral of [(t^2 + 1)/2 + 1] × (1/t) × t dt = integral of [(t^2 + 1)/2 + 1] dt = integral of [(t^2 + 1 + 2)/2] dt = integral of [(t^2 + 3)/2] dt = (1/2) integral of (t^2 + 3) dt = (1/2)[t^3/3 + 3t] + c = t^3/6 + 3t/2 + c = (1/6)(2x-1)^(3/2) + (3/2)(2x-1)^(1/2) + c = sqrt(2x-1)[(1/6)(2x-1) + 3/2] + c = sqrt(2x-1)[(2x-1)/6 + 3/2] + c = sqrt(2x-1)[(2x-1+9)/6] + c = sqrt(2x-1)[(2x+8)/6] + c = sqrt(2x-1)[2(x+4)/6] + c = sqrt(2x-1)[(x+4)/3] + c Comparing with f(x)sqrt(2x-1) + C: f(x) = (x+4)/3 = (1/3)(x+4)
