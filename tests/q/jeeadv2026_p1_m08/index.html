Consider the matrix M = [2 -1; 1 0]. Let p, q, r, s, a, b, c and d be integers such that M²⁶ = [p q; r s] and Σₖ₌₁²⁶ Mᵏ = [a b; c d]. Then which of the following statements is (are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) There exists a 2 × 2 invertible matrix N with real entries such that MN = N[1 1; 0 1]
  2. (B) The value of a is 378
  3. (C) For any two given integers m and n, there exist unique integers x and y such that px + qy = m and rx + sy = n
  4. (D) For each positive real number t, the system of linear equations (a + t)x + by = 1 and cx + (d + t)y = -1 has a unique solution

Answer

Correct answer: A, C, D

Solution

Solution: The characteristic equation of M is given by det(M − λI) = 0: |2 − λ −1| |1 −λ| = λ² − 2λ + 1 = (λ − 1)² = 0 The only eigenvalue is λ = 1 with algebraic multiplicity 2. For the eigenvector, (M − I)X = 0 ⇒ |1 −1||x| |0| |1 −1||y| = |0| ⇒ x = y. Since there is only one linearly independent eigenvector, M is not diagonalizable but can be reduced to its Jordan canonical form J = |1 1| |0 1|. Thus, there exists an invertible matrix N such that M = NJN⁻¹ ⇒ MN = N|1 1|. |0 1| Statement (A) is TRUE. We can write M = I + A, where A = |1 −1| |1 −1|. Notice that A² = |1 −1||1 −1| = |0 0| |1 −1||1 −1| |0 0| Using the binomial theorem (since I and A commute), Mᵏ = (I + A)ᵏ = I + kA = |1 + k −k| |k 1 − k| For k = 26, M²⁶ = |27 −26| = |p q| |26 −25| |r s| The determinant of M²⁶ is ps − qr = 27(−25) − (−26)(26) = 1. Since det(M²⁶) = 1, its inverse has integer entries. Thus, for any integers m and n, the system |p q||x| = |m| |r s||y| |n| has a unique integer solution. Statement (C) is TRUE. Now, let's find Σᵏ₌₁²⁶ Mᵏ = Σᵏ₌₁²⁶ |1 + k −k| = |a b| |k 1 − k| |c d| a = Σᵏ₌₁²⁶(1 + k) = 2 + 3 + ⋯ + 27 = 26/2(2 + 27) = 13 × 29 = 377. Statement (B) is FALSE. We also have: b = Σᵏ₌₁²⁶(−k) = −351 c = Σᵏ₌₁²⁶ k = 351 d = Σᵏ₌₁²⁶(1 − k) = 26 − 351 = −325 For statement (D), the system of equations is |a + t b ||x| = |1| |c d + t||y| |−1| The determinant of the coefficient matrix is: Δ = (a + t)(d + t) − bc = (377 + t)(−325 + t) − (−351)(351) Δ = t² + 52t − 122525 + 123201 = t² + 52t + 676 = (t + 26)² For any positive real number t > 0, Δ = (t + 26)² > 0, meaning the determinant is non-zero. Hence, the system has a unique solution. Statement (D) is TRUE. Answer: There exists a 2 × 2 invertible matrix N with real entries such that MN = N|1 1|. For any two given integers m and n, there exist unique integers x and y such that px + qy = m and rx + sy = n. For each positive real number t, the system of linear equations (a + t)x + by = 1 and cx + (d + t)y = −1 has a unique solution.
