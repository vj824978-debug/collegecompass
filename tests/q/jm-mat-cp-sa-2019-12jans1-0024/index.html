If a straight line passing through the point P(-3, 4) is such that its intercepted portion between the coordinate axes is bisected at P, then its equation is:

  1. (1) x - y + 7 = 0
  2. (2) 4x - 3y + 24 = 0
  3. (3) 4x + 3y = 0
  4. (4) 3x - 4y + 25 = 0

Answer

Correct answer: Option 2

Solution

Let the line intersect the x-axis at (a, 0) and y-axis at (0, b). Since the intercepted portion between the coordinate axes is bisected at P(-3, 4), the point P is the midpoint of the line segment joining (a, 0) and (0, b). Using midpoint formula: -3 = (a + 0)/2 => a/2 = -3 => a = -6 4 = (0 + b)/2 => b/2 = 4 => b = 8 The line passes through (a, 0) = (-6, 0) and (0, b) = (0, 8) Equation of line in intercept form: x/a + y/b = 1 x/(-6) + y/8 = 1 Multiplying through by 24: -4x + 3y = 24 -4x + 3y - 24 = 0 Multiplying by -1: 4x - 3y + 24 = 0 Verification: Substituting P(-3, 4): 4(-3) - 3(4) + 24 = -12 - 12 + 24 = 0 ✓
