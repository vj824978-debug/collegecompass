Let z be a complex number such that |z - 6| = 5 and |z + 2 - 6i| = 5. Then the value of z^3 + 3z^2 - 15z + 141 is equal to

  1. (1) 42
  2. (2) 37
  3. (3) 50
  4. (4) 61

Answer

Correct answer: Option 3

Solution

Center of first circle C_1(6,0), r_1 = 5 Center of second circle C_2(-2,6), r_2 = 5 ∴ C_1C_2 = r_1 + r_2 ∴ common point Z is mid point of C_1 & C_2 Z = ((6 + (-2))/2, (0 + 6)/2) = (2, 3) ∴ z = 2 + 3i ∴ z^2 = (2 + 3i)^2 = 4 + 12i + 9i^2 = 4 + 12i - 9 = -5 + 12i ∴ z^2 = 4z - 13 ∴ z^3 = z · z^2 = (2 + 3i)(-5 + 12i) = -10 + 24i - 15i + 36i^2 = -10 + 9i - 36 = -46 + 9i ∴ z^3 = 3z - 52 ∴ z^3 + 3z^2 - 15z + 141 = (3z - 52) + 3(4z - 13) - 15z + 141 = 3z - 52 + 12z - 39 - 15z + 141 = (3 + 12 - 15)z + (-52 - 39 + 141) = 0 · z + 50 = 50
