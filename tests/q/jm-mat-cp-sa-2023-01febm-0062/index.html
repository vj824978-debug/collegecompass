The mean and variance of 5 observations are 5 and 8 respectively. If 3 observations are 1, 3, 5, then the sum of cubes of the remaining two observations is

  1. (1) 1456
  2. (2) 1216
  3. (3) 1792
  4. (4) 1072

Answer

Correct answer: Option 4

Solution

Let observations 1, 3, 5, a, b From mean = 5: (1 + 3 + 5 + a + b)/5 = 5 => 9 + a + b = 25 => a + b = 16 From variance = 8: (a^2 + b^2 + 35)/5 - 25 = 8 => a^2 + b^2 + 35 = 165 => a^2 + b^2 = 130 We have a + b = 16 and a^2 + b^2 = 130 Using (a + b)^2 = a^2 + 2ab + b^2: 256 = 130 + 2ab => 2ab = 126 => ab = 63 Now a^3 + b^3 = (a + b)^3 - 3ab(a + b) = 16^3 - 3(63)(16) = 4096 - 3024 = 1072 Alternatively, a and b are roots of t^2 - 16t + 63 = 0 Using quadratic formula or factoring: a = 7, b = 9 (or vice versa) Therefore: a^3 + b^3 = 7^3 + 9^3 = 343 + 729 = 1072
