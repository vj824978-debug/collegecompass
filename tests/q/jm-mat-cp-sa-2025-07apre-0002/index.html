If the orthocenter of the triangle formed by the lines y = x + 1, y = 4x - 8 and y = mx + c is at (3, -1), then m - c is:

  1. (1) -2
  2. (2) 0
  3. (3) 4
  4. (4) 2

Answer

Correct answer: Option 2

Solution

Find vertices of triangle from intersection of lines. Line 1: y = x + 1, Line 2: y = 4x - 8 intersect at (3, 4). Line 1 and Line 3 intersect at (k-1, k) where k is found using orthocenter condition. Line 2 and Line 3 intersect at ((k+8)/4, k). The altitude from vertex C is perpendicular to AB. Since AB has slope 1, altitude CR has slope -1, giving equation x + y - 2 = 0. Orthocenter H(3, -1) lies on this line: 3 - 1 - 2 = 0 ✓. For orthocenter at (3, -1), the line AC must pass through A(-1, 0) and be perpendicular to line 2 (slope 4). Line AC has slope -1/4, so y = 0 (horizontal). This means m = 0 and c = 0, but solving with orthocenter condition yields m = 2, c = 0. Therefore m - c = 2.
