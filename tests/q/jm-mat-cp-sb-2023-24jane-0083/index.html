The equations of the sides AB, BC and CA of a triangle ABC are: 2x + y = 0, x + py = 21a, (a ≠ 0) and x - y = 3 respectively. Let P(2, a) be the centroid of triangle ABC. Then (BC)^2 is equal to

Answer

Correct answer: 122

Solution

The vertices of the triangle are found by solving pairs of line equations. Vertex A (intersection of AB and CA): 2x + y = 0 and x - y = 3 Adding: 3x = 3, so x = 1 From x - y = 3: y = -2 Therefore A = (1, -2) Vertex B (intersection of AB and BC): 2x + y = 0 and x + py = 21a From first equation: y = -2x Substituting: x + p(-2x) = 21a x(1 - 2p) = 21a x = 21a/(1 - 2p) y = -42a/(1 - 2p) Therefore B = (21a/(1 - 2p), -42a/(1 - 2p)) Vertex C (intersection of BC and CA): x + py = 21a and x - y = 3 From second equation: x = y + 3 Substituting: y + 3 + py = 21a y(1 + p) = 21a - 3 y = (21a - 3)/(p + 1) x = (21a - 3)/(p + 1) + 3 = (21a - 3 + 3p + 3)/(p + 1) = (3p + 21a)/(p + 1) Therefore C = ((3p + 21a)/(p + 1), (21a - 3)/(p + 1)) Using centroid formula P(2, a): Centroid x-coordinate: [1 + 21a/(1 - 2p) + (3p + 21a)/(p + 1)]/3 = 2 Centroid y-coordinate: [-2 - 42a/(1 - 2p) + (21a - 3)/(p + 1)]/3 = a From x-coordinate: 21a/(1 - 2p) + (3p + 21a)/(p + 1) = 6 - 1 = 5 Multiplying and simplifying: 21a(p + 1) + (3p + 21a)(1 - 2p) = 5(1 - 2p)(p + 1) 21ap + 21a + 3p + 21a - 6p^2 - 42ap = 5(1 - 2p + p - 2p^2) 21a + 3p - 21ap - 6p^2 = 5 - 5p - 10p^2 This gives: 4p^2 - 21ap + 8p + 42a - 5 = 0 ... (1) From y-coordinate: -42a/(1 - 2p) + (21a - 3)/(p + 1) = 3a + 2 Simplifying similarly: 4p^2 - 81ap + 6ap^2 - 24a + 8p - 5 = 0 ... (2) Subtracting equation (1) from equation (2): 60ap + 66a - 6ap^2 = 0 Dividing by 6a (since a ≠ 0): p^2 - 10p - 11 = 0 (p + 1)(p - 11) = 0 p = -1 or p = 11 When p = 11: a = 3 With p = 11 and a = 3: B = (21(3)/(1 - 22), -42(3)/(1 - 22)) = (63/(-21), -126/(-21)) = (-3, 6) C = ((33 + 63)/12, (63 - 3)/12) = (96/12, 60/12) = (8, 5) (BC)^2 = (8 - (-3))^2 + (5 - 6)^2 = 11^2 + (-1)^2 = 121 + 1 = 122
