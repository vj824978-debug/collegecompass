Let S = {1, 2, 3, ..., 2022}. Then the probability that a randomly chosen number n from the set S such that HCF(n, 2022) = 1, is:

  1. (1) 128/1011
  2. (2) 166/1011
  3. (3) 127/337
  4. (4) 112/337

Answer

Correct answer: Option 4

Solution

2022 = 2 × 3 × 337. For HCF(n, 2022) = 1, n must be coprime to 2022, so not divisible by 2, 3, or 337. A = divisible by 2: n(A) = 1011. B = divisible by 3: n(B) = 674. A ∩ B = divisible by 6: n(A ∩ B) = 337. n(A ∪ B) = 1011 + 674 - 337 = 1348. C = divisible by 337: n(C) = {337, 674, 1011, 1348, 1685, 2022} with 4 already in A ∪ B, so 2 additional. Total divisible by 2, 3, or 337 = 1348 + 2 = 1350. Favorable cases = 2022 - 1350 = 672. Probability = 672/2022 = 112/337.
