Let A(4, -4) and B(9, 6) be points on the parabola, y^2 = 4x. Let C be chosen on the arc AOB of the parabola, where O is the origin, such that the area of triangle ACB is maximum. Then, the area (in sq. units) of triangle ACB, is:

  1. (1) 32
  2. (2) 31 + 3/4
  3. (3) 30 + 1/2
  4. (4) 31 + 1/4

Answer

Correct answer: Option 2

Solution

For parabola y^2 = 4x, we can parametrize points as (t^2, 2t). Point A(4, -4): y^2 = 16 = 4(4), so A corresponds to t = -2 Point B(9, 6): y^2 = 36 = 4(9), so B corresponds to t = 3 Let C(t^2, 2t) be a point on the arc AOB where -2 ≤ t ≤ 3. Area of triangle ACB using the determinant formula: Δ = (1/2)|x_A(y_B - y_C) + x_B(y_C - y_A) + x_C(y_A - y_B)| Δ = (1/2)|4(6 - 2t) + 9(2t - (-4)) + t^2((-4) - 6)| Δ = (1/2)|4(6 - 2t) + 9(2t + 4) + t^2(-10)| Δ = (1/2)|24 - 8t + 18t + 36 - 10t^2| Δ = (1/2)|60 + 10t - 10t^2| Δ = (1/2)|−10t^2 + 10t + 60| Δ = 5|−t^2 + t + 6| Since we need to maximize area on the arc AOB (where -2 ≤ t ≤ 3), we check the function: D = -t^2 + t + 6 To find maximum: dD/dt = -2t + 1 = 0 t = 1/2 Check second derivative: d^2D/dt^2 = -2 < 0, so this is a maximum. At t = 1/2: D = -(1/4) + (1/2) + 6 = -1/4 + 1/2 + 6 = 1/4 + 6 = 25/4 Maximum area = 5 × (25/4) = 125/4 = 31 + 1/4
