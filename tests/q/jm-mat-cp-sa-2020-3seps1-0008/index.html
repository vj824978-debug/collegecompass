If alpha and beta are the roots of the equation x^2 + px + 2 = 0 and 1/alpha and 1/beta are the roots of the equation 2x^2 + 2qx + 1 = 0, then (alpha - 1/alpha)(beta - 1/beta)(alpha + 1/beta)(beta + 1/alpha) is equal to-

  1. (1) (9/4)(9 - q^2)
  2. (2) (9/4)(9 + q^2)
  3. (3) (9/4)(9 - p^2)
  4. (4) (9/4)(9 + p^2)

Answer

Correct answer: Option 3

Solution

alpha, beta are roots of x^2 + px + 2 = 0 => alpha^2 + p*alpha + 2 = 0 & beta^2 + p*beta + 2 = 0 => 1/alpha, 1/beta are roots of 2x^2 + px + 1 = 0 But 1/alpha, 1/beta are roots of 2x^2 + 2qx + 1 = 0 => p = 2q Also alpha + beta = -p, alpha*beta = 2 (alpha - 1/alpha)(beta - 1/beta)(alpha + 1/beta)(beta + 1/alpha) = ((alpha^2 - 1)/alpha)((beta^2 - 1)/beta)((alpha*beta + 1)/beta)((alpha*beta + 1)/alpha) = ((-p*alpha - 3)(-p*beta - 3)(alpha*beta + 1)^2)/((alpha*beta)^2) = (9/4)(p*alpha*beta + 3p(alpha + beta) + 9) = (9/4)(9 - p^2) = (9/4)(9 - 4q^2)
