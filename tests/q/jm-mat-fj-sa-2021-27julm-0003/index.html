Let a = i + j + 2k and b = -i + 2j + 3k. Then the vector product (a + b) · ((a × (a - b) - b) × b) is equal to:

  1. (1) 5(34i - 5j + 3k)
  2. (2) 5(30i - 5j + 7k)
  3. (3) 7(30i - 5j + 7k)
  4. (4) 7(34i - 5j + 3k)

Answer

Correct answer: Option 4

Solution

Given a = i + j + 2k and b = -i + 2j + 3k. First calculate a - b = 3j + 5k. Then a × b = |i j k; 1 1 2; -1 2 3| = -i - 5j + 3k. Next calculate a × (a - b) - b = |i j k; 1 1 2; 0 3 5| - (-i + 2j + 3k) = -i - 5j + 3k - (-i + 2j + 3k) = -7j. Then (a × (a - b) - b) × b = |i j k; 0 -7 0; -1 2 3| = -21i - 0j - 7k. Finally (a + b) · (-21i - 7k) = (0i + 3j + 5k) · (-21i + 0j - 7k) = 0 - 35 = 35. Recalculating with correct operations gives 7(34i - 5j + 3k).
