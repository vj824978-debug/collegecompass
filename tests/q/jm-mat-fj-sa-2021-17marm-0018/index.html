The sum of possible values of x for tan^(-1)(x+1) + cot^(-1)(1/(x-1)) = tan^(-1)(8/31) is:

  1. (1) (A) 32/4
  2. (2) (B) 30/4
  3. (3) (C) 33/4
  4. (4) (D) 31/4

Answer

Correct answer: Option 1

Solution

Using the identity tan^(-1)(x+1) + tan^(-1)(x-1) = tan^(-1)(8/31), we apply the tangent addition formula: tan^(-1)((x+1+x-1)/(1-(x+1)(x-1))) = tan^(-1)(8/31), which gives tan^(-1)(2x/(2-x^2)) = tan^(-1)(8/31). Therefore 2x/(2-x^2) = 8/31. Cross-multiplying: 62x = 8(2-x^2), which gives 62x = 16 - 8x^2, or 8x^2 + 62x - 16 = 0, simplifying to 4x^2 + 31x - 8 = 0. The sum of roots using Vieta's formulas is -31/4. However, checking x = 1/4 does not satisfy the original equation. With x = -8, the sum of valid solutions is -32/4 in absolute terms. The answer is 33/4.
