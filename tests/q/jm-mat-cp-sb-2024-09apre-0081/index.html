Consider the circle C: x^2 + y^2 = 4 and the parabola P: y^2 = 8x. If the set of all values of a, for which three chords of the circle C on three distinct lines passing through the point (a, 0) are bisected by the parabola P is the interval (p, q), then (2q - p)^2 is equal to ____.

Answer

Correct answer: 80

Solution

For a chord of circle C with midpoint on parabola P: Let midpoint be (x1, y1) on parabola, so y1^2 = 8x1. Using the chord condition: xx1 + yy1 = x1^2 + y1^2. For chord through point (a, 0): ax1 = x1^2 + y1^2 = x1^2 + 8x1. This gives a = x1 + 8. For three distinct chords, we need three distinct points on parabola. Also, constraint from circle: 4t^4 + 16t^2 - 4 < 0 where t^2 = (a-8)/2. This gives t^2 = -2 + sqrt(5). Therefore a = 4 + 2*sqrt(5). The interval is (8, 4 + 2*sqrt(5)). So p = 8, q = 4 + 2*sqrt(5). (2q - p)^2 = (2(4 + 2*sqrt(5)) - 8)^2 = (8 + 4*sqrt(5) - 8)^2 = (4*sqrt(5))^2 = 80.
