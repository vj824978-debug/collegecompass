Let y = y(x) be the solution of the differential equation cosx(log(cosx))^2 dy + (sinx - 3ysinx log_(e)(cosx))dx = 0, x ∈ (0, π/2). If y(π/4) = -1/log_(e)(2), then y(π/6) is:

  1. (1) 2/(log_(e)(3) - log_(e)(4))
  2. (2) 1/(log_(e)(4) - log_(e)(3))
  3. (3) 1/log_(e)(4)
  4. (4) 1/(log_(e)(3) - log_(e)(4))

Answer

Correct answer: Option 4

Solution

cosx(ln(cosx))^2 dy + (sinx - 3y(sinx)ln(cosx))dx = 0 cosx(ln(cosx))^2 dy/dx - 3sinx·ln(cosx)y = -sinx dy/dx + (3tanx)/(ln(cosx))y = (-tanx)/(ln(cosx))^2 Also written as: dy/dx + (3tanx)/(ln(secx))y = (-tanx)/(ln(secx))^2 I.F. = e^(∫(3tanx)/(ln(secx))dx) = (ln(secx))^3 y × (ln(secx))^3 = ∫(-tanx)/(ln(secx))^2 · (ln(secx))^3 dx + C y × (ln(secx))^3 = -1/2(ln(secx))^2 + C Given: x = π/4, y = -1/ln(2) -1/ln(2) × (ln(√2))^3 = -1/2 × (ln(√2))^2 + C -1/ln(2) × (1/2·ln(2))^3 = -1/2 × (1/2·ln(2))^2 + C -1/ln(2) × 1/8·(ln(2))^3 = -1/2 × 1/4·(ln(2))^2 + C -1/8·(ln(2))^2 = -1/8·(ln(2))^2 + C ⟹ C = 0 ∴ y(ln(secx))^3 = -1/2(ln(secx))^2 + 0 y = -1/(2ln(secx)) y = 1/(2ln(cosx)) ∴ y(π/6) = 1/(2ln(cos(π/6))) = 1/(2ln(√3/2)) = 1/(2(ln(√3) - ln(2))) = 1/(2(1/2·ln(3) - ln(2))) = 1/(ln(3) - 2ln(2)) = 1/(ln(3) - ln(4))
