Let y = y(x) be a function of x satisfying y*sqrt(1-x^2) = k - x*sqrt(1-y^2) where k is a constant and y(1/2) = -1/4. Then dy/dx at x = 1/2, is equal to:

  1. (1) 2/sqrt(5)
  2. (2) sqrt(5)/2
  3. (3) -sqrt(5)/4
  4. (4) -sqrt(5)/2

Answer

Correct answer: Option 4

Solution

y*sqrt(1-x^2) = k - x*sqrt(1-y^2) On differentiating both sides with respect to x: y*(-2x)/(2*sqrt(1-x^2)) + sqrt(1-x^2)*y' = 0 - sqrt(1-y^2) - x*(2y*y')/(2*sqrt(1-y^2)) Simplifying: -xy/sqrt(1-x^2) + sqrt(1-x^2)*y' = -sqrt(1-y^2) - (x*y*y')/sqrt(1-y^2) Rearranging: sqrt(1-x^2)*y' + (x*y*y')/sqrt(1-y^2) = -sqrt(1-y^2) + xy/sqrt(1-x^2) y'[sqrt(1-x^2) + (x*y)/sqrt(1-y^2)] = -sqrt(1-y^2) + xy/sqrt(1-x^2) Put x = 1/2, y = -1/4 & x.y = -1/8 Calculating the required values: sqrt(1-x^2) = sqrt(1-1/4) = sqrt(3/4) = sqrt(3)/2 sqrt(1-y^2) = sqrt(1-1/16) = sqrt(15/16) = sqrt(15)/4 On solving we get: y' = -sqrt(5)/2
