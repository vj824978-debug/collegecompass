For the function f(x) = sin(x) + 3x - (2/π)(x^2 + x), where x ∈ [0, π/2]. Consider the following two statements: (I) f is increasing in (0, π/2) (II) f' is decreasing in (0, π/2)

  1. (1) only (I) is true
  2. (2) only (II) is true
  3. (3) neither (I) nor (II) is true
  4. (4) both (I) and (II) are true

Answer

Correct answer: Option 4

Solution

f(x) = sin(x) + 3x - (2/π)(x^2 + x). Taking derivative: f'(x) = cos(x) + 3 - (2/π)(2x + 1). For 0 < x < π/2, we have cos(x) > 0, and we can verify that 3 - (2/π)(2x + 1) > 0, so f'(x) > 0, meaning f is increasing. Taking second derivative: f''(x) = -sin(x) - (4/π) < 0 for 0 < x < π/2, meaning f' is decreasing. Both statements are true.
