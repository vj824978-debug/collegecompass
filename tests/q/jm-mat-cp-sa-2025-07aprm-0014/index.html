Let x1, x2, x3, x4 be in a geometric progression. If 2, 7, 9, 5 are subtracted respectively from x1, x2, x3, x4, then the resulting numbers are in an arithmetic progression. Then the value of (1/24)(x1 x2 x3 x4) is:

  1. (1) 72
  2. (2) 18
  3. (3) 216
  4. (4) 36

Answer

Correct answer: Option 3

Solution

Let x1 = a, x2 = ar, x3 = ar^2, x4 = ar^3. After subtraction: (a-2), (ar-7), (ar^2-9), (ar^3-5) form an A.P. Using condition a2-a1 = a3-a2 and a3-a2 = a4-a3, we get: a(r-1)(r-1) = -3 and a(r-1)(r^2-1) = -9. Dividing these equations: r+1 = 3, so r = 2. From a(1)(1) = -3, we get a = -3. Therefore x1 = -3, x2 = -6, x3 = -12, x4 = -24. Thus (1/24)(x1·x2·x3·x4) = (1/24)(-3)(-6)(-12)(-24) = (1/24)(5184) = 216
