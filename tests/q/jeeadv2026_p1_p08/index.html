The electric field associated with an electromagnetic wave travelling in vacuum is given by E₀ sin(3y + 4z + ωt) î, where ω is the angular frequency. All quantities are in SI units. The correct statement(s) about this wave is/are: [Given: speed of light in vacuum c = 3 × 10⁸ m s⁻¹.] (A) The wave is travelling in −1/5(3ĵ + 4k̂) direction. (B) The magnitude of the wave vector is 0.5 m⁻¹. (C) The value of ω is 1.5 × 10⁹ rad s⁻¹. (D) The magnetic field associated with this wave is given by E₀/c sin(3y + 4z + ωt)(4ĵ − 3k̂).

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) The wave is travelling in −1/5(3ĵ + 4k̂) direction.
  2. (B) The magnitude of the wave vector is 0.5 m⁻¹.
  3. (C) The value of ω is 1.5 × 10⁹ rad s⁻¹.
  4. (D) The magnetic field associated with this wave is given by E₀/c sin(3y + 4z + ωt)(4ĵ − 3k̂).

Answer

Correct answer: A, C

Solution

Solution: The given electric field is Ē = E₀ sin(3y + 4z + ωt) î. Comparing the phase φ = 3y + 4z + ωt with the standard wave equation phase k̄ · r̄ − ωt, we can rewrite it as −(−3y − 4z − ωt). Thus, the wave vector is k̄ = −3ĵ − 4k̂. The direction of wave propagation is given by the unit vector n̂: n̂ = k̄/|k̄| = (−3ĵ − 4k̂)/√(−3)² + (−4)² = −1/5(3ĵ + 4k̂) The magnitude of the wave vector is |k̄| = 5 m⁻¹. The angular frequency ω is: ω = c|k̄| = (3 × 10⁸) × 5 = 1.5 × 10⁹ rad s⁻¹ The magnetic field B̄ is given by: B̄ = 1/c(n̂ × Ē) = 1/c[−1/5(3ĵ + 4k̂)] × [E₀ sin(3y + 4z + ωt) î] B̄ = −E₀/(5c) sin(3y + 4z + ωt)[3(ĵ × î) + 4(k̂ × î)] B̄ = −E₀/(5c) sin(3y + 4z + ωt)(−3k̂ + 4ĵ) = E₀/(5c) sin(3y + 4z + ωt)(−4ĵ + 3k̂) Answer: The wave is travelling in the −1/5(3ĵ + 4k̂) direction.; The value of ω is 1.5 × 10⁹ rad s⁻¹.
