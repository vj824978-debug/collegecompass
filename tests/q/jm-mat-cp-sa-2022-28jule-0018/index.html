A horizontal park is in the shape of a triangle OAB with AB = 16. A vertical lamp post OP is erected at the point O such that angle PAO = angle PBO = 15° and angle PCO = 45°, where C is the midpoint of AB. Then (OP)² is equal to

  1. (1) (32/sqrt(3))(sqrt(3) - 1)
  2. (2) (32/sqrt(3))(2 - sqrt(3))
  3. (3) (16/sqrt(3))(sqrt(3) - 1)
  4. (4) (16/sqrt(3))(2 - sqrt(3))

Answer

Correct answer: Option 2

Solution

From the given conditions: OP = OA tan(15°) = OB tan(15°) (from condition i), so OA = OB (isosceles triangle). OP = OC tan(45°) implies OP = OC (from condition ii). Since C is midpoint of AB and AB = 16, we have AC = BC = 8. Using OC² + 8² = OA² and tan(15°) = 2 - sqrt(3), we get OP = OA tan(15°). Setting up the equation OP² + 64 = OP²[(sqrt(3) + 1)/(sqrt(3) - 1)]², solving yields OP² = (32/sqrt(3))(2 - sqrt(3)).
