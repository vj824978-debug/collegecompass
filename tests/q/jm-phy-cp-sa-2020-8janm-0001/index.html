The graph which depicts the results of Rutherford gold foil experiment with alpha-particles is: theta: Scattering angle, Y: Number of scattered alpha-particles detected (Plots are schematic and not to scale)

  1. (1) Graph (1) showing a bell curve peaking around theta and then decreasing
  2. (2) Graph (2) showing a sharp peak near 0 and then rapidly decreasing to a plateau
  3. (3) Graph (3) showing a gradual increase and then leveling off
  4. (4) Graph (4) showing a peak at theta = 0 and then decreasing linearly

Answer

Correct answer: Option 2

Solution

In the Rutherford gold foil experiment, alpha-particles are scattered by the nucleus of gold atoms. The number of scattered alpha-particles N as a function of scattering angle theta is given by: N proportional to 1/sin^4(theta/2). Analysis of this formula: 1. At theta = 0 (forward direction): sin(0) approaches 0, so N approaches infinity (theoretically very large). 2. At theta = pi/2: sin(pi/4) = 1/sqrt(2), giving a finite value. 3. At theta = pi (backward scattering): sin(pi/2) = 1, giving minimum value. The function 1/sin^4(theta/2) shows that: - The number of scattered particles is maximum at very small scattering angles (near theta = 0). - As theta increases, the number of scattered particles decreases sharply. - The decrease follows the 1/sin^4(theta/2) relationship (very steep at small angles, then levels off). This behavior is characteristic of Coulomb scattering from a point nucleus. Option (2) correctly shows this sharp peak near theta = 0 and rapid decrease, which matches the Rutherford scattering formula.
