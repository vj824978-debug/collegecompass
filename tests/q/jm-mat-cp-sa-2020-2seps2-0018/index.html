If a curve y = f(x), passing through the point (1, 2), is the solution of the differential equation 2x^2 dy = (2xy + y^2)dx, then f(1/2) is equal to:

  1. (1) 1/(1 - log_e 2)
  2. (2) 1/(1 + log_e 2)
  3. (3) -1/(1 + log_e 2)
  4. (4) 1 + log_e 2

Answer

Correct answer: Option 2

Solution

2x^2 dy = (2xy + y^2)dx => dy/dx = (2xy + y^2)/(2x^2) {Homogeneous D.E.} Let y = xt => dy/dx = t + x(dt/dx) => t + x(dt/dx) = (2x·xt + x^2t^2)/(2x^2) => t + x(dt/dx) = t + t^2/2 => x(dt/dx) = t^2/2 => 2∫(dt/t^2) = ∫(dx/x) => 2(-1/t) = ln(x) + C => -2x/y = ln(x) + C {Put t = y/x} Put x = 1 & y = 2: then we get C = -1 => -2x/y = ln(x) - 1 => y = 2x/(1 - ln(x)) => f(x) = 2x/(1 - log_e x) So, f(1/2) = 2(1/2)/(1 - log_e(1/2)) = 1/(1 - (log_e 1 - log_e 2)) = 1/(1 - (0 - log_e 2)) = 1/(1 + log_e 2)
