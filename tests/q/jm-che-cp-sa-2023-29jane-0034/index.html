Correct order of spin only magnetic moment of the following complex ions is (Given At. no. Fe : 26, Co : 27)

  1. (1) [Co(C2O4)3]3- > [CoF6]3- > [FeF6]3-
  2. (2) [FeF6]3- > [Co(C2O4)3]3- > [CoF6]3-
  3. (3) [FeF6]3- > [CoF6]3- > [Co(C2O4)3]3-
  4. (4) [CoF6]3- > [FeF6]3- > [Co(C2O4)3]3-

Answer

Correct answer: Option 3

Solution

[FeF6]3- -----> 5 unpaired electrons [Co(C2O4)3]3- -----> 0 unpaired electron [CoF6]3- -----> 4 unpaired electrons So, correct answer is : (3) Explanation: For [FeF6]3-: Fe is in +3 oxidation state, configuration is d5. F- is a weak field ligand, so it causes high spin configuration with 5 unpaired electrons. Magnetic moment = sqrt(n(n+2)) = sqrt(5(5+2)) = sqrt(35) For [Co(C2O4)3]3-: Co is in +3 oxidation state, configuration is d6. C2O4 (oxalate) is a strong field ligand, so it causes low spin configuration with 0 unpaired electrons. Magnetic moment = 0 For [CoF6]3-: Co is in +3 oxidation state, configuration is d6. F- is a weak field ligand, so it causes high spin configuration with 4 unpaired electrons. Magnetic moment = sqrt(4(4+2)) = sqrt(24) Order of magnetic moments: sqrt(35) > sqrt(24) > 0 Therefore: [FeF6]3- > [CoF6]3- > [Co(C2O4)3]3-
