Distance between object and its image (magnified by -1/3) is 30 cm. The focal length of the mirror used is (x/4) cm, where magnitude of value of x is ________

Answer

Correct answer: 45

Solution

For a concave mirror with magnification m = -1/3, we have m = -v/u = -1/3, so v = u/3. Distance between object and image: |u - v| = |u - u/3| = 2u/3 = 30 cm, giving u = 45 cm and v = 15 cm. Using mirror formula: 1/f = 1/u + 1/v = 1/45 + 1/15 = 1/45 + 3/45 = 4/45, so f = 45/4 cm. Given f = x/4, we have x/4 = 45/4, therefore x = 45.
