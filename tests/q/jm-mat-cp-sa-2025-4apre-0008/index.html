Let f(x) + 2f(1/x) = x^2 + 5 and 2g(x) - 3g(1/2) = x, where x > 0. If α = ∫₁² f(x)dx and β = ∫₁² g(x)dx, then the value of 9α + β is:

  1. (1) 11
  2. (2) 1
  3. (3) 10
  4. (4) 0

Answer

Correct answer: Option 1

Solution

From f(x) + 2f(1/x) = x^2 + 5, replacing x with 1/x gives: f(1/x) + 2f(x) = 1/x^2 + 5. Solving these two equations yields: 3f(x) = 2/x^2 - x^2 + 5, so f(x) = (1/3)(2/x^2 - x^2 + 5). Integrating from 1 to 2: α = (1/3)[-2/x - x^3/3 + 5x]₁² = (1/3)[(-1 - 8/3 + 10) - (-2 - 1/3 + 5)] = 11/9. From 2g(x) - 3g(1/2) = x and 2g(1/2) - 3g(x) = 1/x, solving yields g(x) = -(1/5)(2x + 3/x). Integrating from 1 to 2: β = -(1/5)[x^2 + 3ln(x)]₁² = 0. Therefore, 9α + β = 9(11/9) + 0 = 11.
