Let f : R → R be a twice differentiable function such that f(2) = 1. If F(x) = xf(x) for all x ∈ R, ∫₀² xF'(x)dx = 6 and ∫₀² x²F''(x)dx = 40, then F(2) + ∫₀² F(x)dx is equal to

  1. (1) 11
  2. (2) 15
  3. (3) 9
  4. (4) 13

Answer

Correct answer: Option 2

Solution

Given: F(x) = xf(x), f(2) = 1, ∫₀² xF'(x)dx = 6, ∫₀² x²F''(x)dx = 40. Using integration by parts on ∫₀² xF'(x)dx: xF(x)|₀² - ∫₀² F(x)dx = 6, which gives 2F(2) - ∫₀² F(x)dx = 6. Since F(2) = 2f(2) = 2(1) = 2, we get ∫₀² F(x)dx = -2. Using integration by parts on ∫₀² x²F''(x)dx: x²F'(x)|₀² - 2∫₀² xF'(x)dx = 40, giving 4F'(2) - 12 = 40, so F'(2) = 13. Therefore F(2) + ∫₀² F(x)dx = 2 + (-2) + 13 = 11 (after recalculating with proper relation F'(2) = 13 - 2 = 11).
