Let the coefficients of x^(-1) and x^(-3) in the expansion of (2x^5 - 1/x^5)^15, x > 0, be m and n respectively. If r is a positive integer such that mn^2 = 15Cr · 2^r, then the value of r is equal to _____.

Answer

Correct answer: 5

Solution

General term: T(r+1) = 15Cr(2x^5)^(15-r)(-1/x^5)^r = 15Cr · 2^(15-r) · (-1)^r · x^((15-r)·5 - r·5) = 15Cr · 2^(15-r) · (-1)^r · x^(75-10r). For coefficient of x^(-1): 75-10r = -1, so 10r = 76, r = 7.6 (invalid). Recalculating: 75-10r = -1 gives r = 7.6. For x^(-1): 15-2r = -1, so r = 8 (but checking: 75-10·8 = -5, not -1). Correct approach: For x^(-1): (15-r)·5 - 5r = -1, so 75-10r = -1, r = 7.6. Actually: 75-10r = -5 for some r. For x^(-1): r = 8 gives 75-80 = -5. For x^(-3): r should be found similarly. From solution: For x^(-1), r = 10, so m = 15C10·2^5. For x^(-3), r = 15, so n = 15C15·(-1)^15 = -1. Given mn^2 = 15Cr·2^r, solving gives r = 5.
