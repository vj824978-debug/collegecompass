In the figure given below, a block of mass M = 490 g placed on a frictionless table is connected with two springs having same spring constant (K = 2 N m^(-1)). If the block is horizontally displaced through 'X' m then the number of complete oscillations it will make in 14π seconds will be _________.

Answer

Correct answer: 20

Solution

k_net = k_1 + k_2 = 4 N/m T = 2π sqrt(m/k_net) = 2π sqrt(0.49/4) = (2π × 0.7)/2 = 7π/10 So number of oscillation completed: n = t/T = 14π/(7π/10) = 20
