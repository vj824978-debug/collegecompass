Let A = I₂ - 2MM^T, where M is a real matrix of order 2 × 1 such that the relation M^TM = 1 holds. If λ is a real number such that the relation AX = λX holds for some non-zero real matrix X of order 2 × 1, then the sum of squares of all possible values of λ is equal to ___.

Answer

Correct answer: 2

Solution

Given A = I₂ - 2MM^T and M^TM = 1. We need to find eigenvalues λ such that AX = λX. Computing A²: A² = (I₂ - 2MM^T)(I₂ - 2MM^T) = I₂ - 4MM^T + 4MM^TMM^T = I₂ - 4MM^T + 4MM^T = I₂. From AX = λX, we get A²X = λ²X, which gives X = λ²X, so λ² = 1, thus λ = ±1. The sum of squares of all possible values = (1)² + (-1)² = 1 + 1 = 2.
