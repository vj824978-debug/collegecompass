The solubility of Ca(OH)2 in water is: [Given: The solubility product of Ca(OH)2 in water = 5.5 x 10^-6]

  1. (1) 1.77 x 10^-2
  2. (2) 1.77 x 10^-6
  3. (3) 1.11 x 10^-2
  4. (4) 1.11 x 10^-6

Answer

Correct answer: Option 3

Solution

Ca(OH)2 dissociates as: Ca(OH)2 ⇌ Ca^2+ + 2OH^-. Let solubility = S. Then [Ca^2+] = S and [OH^-] = 2S. Ksp = [Ca^2+][OH^-]^2 = S(2S)^2 = 4S^3 = 5.5 x 10^-6. Therefore S = (5.5 x 10^-6 / 4)^(1/3) = (1.375 x 10^-6)^(1/3) = 1.11 x 10^-2 M
