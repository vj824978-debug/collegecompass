A ray of light coming form the point P(1, 2) gets reflected from the point Q on the x-axis and then passes through the point R(4, 3). If the point S(h, k) is such that PQRS is a parallelogram, then hk^2 is equal to

  1. (1) 80
  2. (2) 90
  3. (3) 60
  4. (4) 70

Answer

Correct answer: Option 4

Solution

Image of P wrt x-axis is P'(1, -2). The line joining P' and R has equation y - 3 = (5/3)(x - 4). This line meets x-axis at Q where y = 0, giving x = 11/5. So Q(11/5, 0). Since PQRS is a parallelogram, diagonals bisect each other: (4+1)/2 = (11/5 + h)/2 and (3+2)/2 = (0+k)/2. From first: h = 14/5. From second: k = 5. Therefore hk^2 = (14/5) × 5^2 = (14/5) × 25 = 70.
