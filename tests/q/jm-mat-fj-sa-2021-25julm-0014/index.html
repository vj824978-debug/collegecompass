Let the vectors (2+a+b)i+(a+2b+c)j-(b+c)k, (1+b)i+2bj-bk and (2+b)i+2bj+(1-b)k a,b,c ∈ R be co-planar. Then which of the following is true?

  1. (1) 2a = b + c
  2. (2) 2b = a + c
  3. (3) a = b + 2c
  4. (4) 3c = a + b

Answer

Correct answer: Option 2

Solution

For three vectors to be coplanar, their scalar triple product equals zero. Setting up the determinant condition with the three given vectors and solving the system of equations derived from the coplanarity condition. From equation (ii) and (iv): 2+2b(a+b) = (a+b)(1+2b). Simplifying yields 2 = a+b-5. From equation (i) and 2b+c = 2b(a+b) = 4b, we get a+2b+c = (a+b)(1+2b). Working through the algebra leads to the relation 2b = a+c.
