On the x-axis and at a distance x from the origin, the gravitational field due to a mass distribution is given by Ax/(x^2 + a^2)^(3/2) in the x-direction. The magnitude of gravitational potential on the x-axis at a distance x, taking its value to be zero at infinity, is-

  1. (1) A/(x^2 + a^2)^(3/2)
  2. (2) A(x^2 + a^2)^(1/2)
  3. (3) A(x^2 + a^2)^(2/3)
  4. (4) A/(x^2 + a^2)^(1/2)

Answer

Correct answer: Option 4

Solution

Given E_G = Ax/(x^2 + a^2)^(3/2), V_∞ = 0 V_x - V_∞ = -∫[∞ to x] E_G · dx V_x - 0 = -∫[∞ to x] Ax/(x^2 + a^2)^(3/2) dx put x^2 + a^2 = z 2x dx = dz V_x - 0 = -∫[∞ to x] (A dz)/(2(z)^(3/2)) = -[A/(z^(1/2))]_∞^x = -[A/(x^2 + a^2)^(1/2)]_∞^x V_x = A/(x^2 + a^2)^(1/2) - 0 = A/(x^2 + a^2)^(1/2)
