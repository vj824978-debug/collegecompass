Consider the following complexes. [CoCl(NH3)5]2+ (A), [Co(CN)6]3- (B), [Co(NH3)5(H2O)]3+ (C), [Cu(H2O)4]2+ (D). The correct order of A, B, C and D in terms of wavenumber of light absorbed is:

  1. (1) C < D < A < B
  2. (2) D < A < C < B
  3. (3) A < C < B < D
  4. (4) B < C < A < D

Answer

Correct answer: Option 2

Solution

As ligand field strength increases, light of more energy is absorbed. Energy is proportional to wavenumber. Ligand field strength order: H2O < NH3 < Cl < CN (spectrochemical series). For complex A [CoCl(NH3)5]2+: mixed ligands, intermediate field. For B [Co(CN)6]3-: strongest field ligand (CN-), highest wavenumber. For C [Co(NH3)5(H2O)]3+: NH3 and H2O (weaker than Cl). For D [Cu(H2O)4]2+: weakest field (only H2O), lowest wavenumber. Order: D < A < C < B
