Let sum from k=1 to n of a_k = alpha*n^2 + beta*n. If a_10 = 59 and a_6 = 7*a_1, then alpha + beta is equal to

  1. (1) 12
  2. (2) 3
  3. (3) 5
  4. (4) 7

Answer

Correct answer: Option 3

Solution

a_n = S_n - S_(n-1) = (alpha*n^2 + beta*n) - (alpha*(n-1)^2 + beta*(n-1)) = alpha*n^2 + beta*n - alpha*(n^2 - 2n + 1) - beta*n + beta = alpha*n^2 + beta*n - alpha*n^2 + 2*alpha*n - alpha - beta*n + beta = 2*alpha*n + beta - alpha (1) a_10 => 2*alpha*10 + beta - alpha = 59 => 20*alpha + beta - alpha = 59 => 19*alpha + beta = 59 (2) a_6 = 7*a_1 => 2*alpha*6 + beta - alpha = 7*(2*alpha*1 + beta - alpha) => 12*alpha + beta - alpha = 7*(2*alpha + beta - alpha) => 11*alpha + beta = 7*(alpha + beta) => 11*alpha + beta = 7*alpha + 7*beta => 4*alpha = 6*beta => 2*alpha = 3*beta From 2*alpha = 3*beta, we get alpha = (3*beta)/2 Substituting in 19*alpha + beta = 59: 19*(3*beta)/2 + beta = 59 (57*beta)/2 + beta = 59 (57*beta + 2*beta)/2 = 59 (59*beta)/2 = 59 beta = 2 Then alpha = (3*2)/2 = 3 alpha + beta = 3 + 2 = 5
