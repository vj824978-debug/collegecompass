Let α and β be the sum and the product of all the non-zero solutions of the equation (z̄)^2 + |z| = 0, z ∈ C. Then 4(α^2 + β^2) is equal to:

  1. (1) 6
  2. (2) 4
  3. (3) 8
  4. (4) 2

Answer

Correct answer: Option 2

Solution

Let z = x + iy, then z̄ = x - iy. We have (z̄)^2 = x^2 - y^2 - 2ixy and |z| = sqrt(x^2 + y^2). The equation becomes: x^2 - y^2 - 2ixy + sqrt(x^2 + y^2) = 0. Separating real and imaginary parts: x^2 - y^2 + sqrt(x^2 + y^2) = 0 and -2xy = 0. From -2xy = 0, either x = 0 or y = 0. If y = 0: x^2 + |x| = 0, which gives x = 0 (no non-zero solution). If x = 0: -y^2 + |y| = 0, so |y| = y^2, giving y = 0, ±1. The non-zero solutions are z = i and z = -i. Thus α = i + (-i) = 0 and β = i(-i) = 1. Therefore 4(α^2 + β^2) = 4(0 + 1) = 4.
