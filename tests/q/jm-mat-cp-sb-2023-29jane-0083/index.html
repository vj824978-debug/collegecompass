If the equation of the normal to the curve y = (x - a)/((x + b)(x - 2)) at the point (1, -3) is x - 4y = 13, then the value of a + b is equal to ________.

Answer

Correct answer: 04

Solution

Given curve: y = (x - a)/((x + b)(x - 2)) at (1, -3) Since the point (1, -3) lies on the curve: -3 = (1 - a)/((1 + b)(-1)) => -3 = (1 - a)/(-(1 + b)) => 3(1 + b) = 1 - a => 3 + 3b = 1 - a => a + 3b + 2 = 0 Finding the derivative: y = (x - a)/((x + b)(x - 2)) dy/dx = [(x - 2)(x + b) - (x - a)[(x + b) + (x - 2)]]/[(x + b)(x - 2)]^2 At (1, -3), the slope of the tangent is m_t: m_t = [(-1 - a)(b) - (1 + b - 1 - a)(1)]/(1 + b)^2 m_t = [-(1 + b) - (1 - a)(b)]/(1 + b)^2 m_t = [-(1 + b) + (1 - a)(b)]/(1 + b)^2 Simplifying at x = 1: m_t = [-(1 + b) - (b - ab)]/(1 + b)^2 m_t = [-(1 + b) - b(1 - a)]/(1 + b)^2 m_t = -(1 + b + b - ab)/(1 + b)^2 = -4 The equation of the normal is x - 4y = 13, which means the slope of the normal is 1/4. Since m_normal = -1/m_tangent: 1/4 = -1/m_t => m_t = -4 (confirmed) From m_t = -4: -(1 + b) - (1 - a)b = -4(1 + b)^2 => 1 + b + b - ab = 4(1 + b)^2 => 1 + 2b + b(3b + 2) = 4b^2 + 4 + 8b => 1 + 2b + 3b^2 + 2b = 4b^2 + 8b + 4 => 3b^2 + 4b + 1 = 4b^2 + 8b + 4 => b^2 + 4b + 3 = 0 => (b + 1)(b + 3) = 0 => b = -1 or b = -3 Since b ≠ -1 (from a + 3b + 2 = 0, if b = -1, then a + 3(-1) + 2 = 0 => a = 1, but we check: 1 + b ≠ 0 required): b = -3, then a + 3(-3) + 2 = 0 => a = 7 Therefore, a + b = 7 + (-3) = 04
