For the following reactions, equilibrium constants are given - S(s) + O2(g) ⇌ SO2(g); K1 = 10^52. 2S(s) + 3O2(g) ⇌ 2SO3(g); K2 = 10^129. The equilibrium constant for the reaction, 2SO2(g) + O2(g) ⇌ 2SO3(g) is

  1. (1) 10^154
  2. (2) 10^181
  3. (3) 10^25
  4. (4) 10^77

Answer

Correct answer: Option 3

Solution

S + O2 ⇌ SO2 ; K1 = 10^52 2S + 3O2 ⇌ 2SO3 ; K2 = 10^129 2SO2 + O2 ⇌ 2SO3 ; K3 = ? To find K3, we use Hess's Law for equilibrium constants: Multiply first equation by 2: 2S + 2O2 ⇌ 2SO2 ; K1^2 = (10^52)^2 = 10^104 Second equation as is: 2S + 3O2 ⇌ 2SO3 ; K2 = 10^129 Subtract first (multiplied by 2) from second: (2S + 3O2) - (2S + 2O2) ⇌ 2SO3 - 2SO2 O2 + 2SO2 ⇌ 2SO3 or 2SO2 + O2 ⇌ 2SO3 For this operation: K3 = K2 / K1^2 = 10^129 / 10^104 = 10^(129-104) = 10^25
