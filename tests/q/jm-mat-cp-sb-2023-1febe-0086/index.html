Number of integral solutions to the equation x + y + z = 21, where x ≥ 1, y ≥ 3, z ≥ 4, is equal to ____.

Answer

Correct answer: 105

Solution

x + y + z = 21 ∴ x ≥ 1, y ≥ 3, z ≥ 4 Let x₁ = x - 1, y₁ = y - 3, z₁ = z - 4 Then x₁ ≥ 0, y₁ ≥ 0, z₁ ≥ 0 (x₁ + 1) + (y₁ + 3) + (z₁ + 4) = 21 x₁ + y₁ + z₁ + 8 = 21 x₁ + y₁ + z₁ = 13 Number of non-negative integral solutions = C(13 + 3 - 1, 3 - 1) = C(15, 2) = 15!/(2! × 13!) = (15 × 14)/(2 × 1) = 210/2 = 105
