Expression for time in terms of G (universal gravitational constant), h (Planck constant) and c (speed of light) is proportional to:

  1. (1) sqrt(Gh/c^5)
  2. (2) sqrt(hc^5/G)
  3. (3) sqrt(Gh/c^3)
  4. (4) sqrt(c^3/Gh)

Answer

Correct answer: Option 1

Solution

T = kG^a h^b c^c [T] = [M^(-1)L^3T^(-2)]^a [ML^2T^(-1)]^b [LT^(-1)]^c [T] = M^(-a+b) L^(3a+2b+c) T^(-2a-b-c) Comparing with [T] = M^0 L^0 T^1: -a + b = 0 ...(1) 3a + 2b + c = 0 ...(2) -2a - b - c = 1 ...(3) From equation (1): a = b Substituting into equation (2): 3a + 2a + c = 0 5a + c = 0 c = -5a Substituting a = b and c = -5a into equation (3): -2a - a - (-5a) = 1 -3a + 5a = 1 2a = 1 a = 1/2 Therefore: a = b = 1/2 and c = -5/2 T ∝ G^(1/2) h^(1/2) c^(-5/2) T ∝ (G^(1/2) h^(1/2))/c^(5/2) T ∝ sqrt(Gh/c^5) Option (1)
