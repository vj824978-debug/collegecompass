Two resistors 2Ω and 3Ω are connected in the gaps of bridge as shown in figure. The null point is obtained with the contact of jockey at some point on wire XY. When an unknown resistor is connected in parallel with 3Ω resistor, the null point is shifted by 22.5 cm toward Y. The resistance of unknown resistor is Ω.

  1. (1) 3
  2. (2) 2
  3. (3) 4
  4. (4) 1

Answer

Correct answer: Option 2

Solution

Initially, for the bridge at null point: 2/3 = x/(100 - x) Cross multiplying: 2(100 - x) = 3x 200 - 2x = 3x 200 = 5x ⟹ x = 40 cm Now when 'R' is connected in parallel with 3Ω resistor: Effective resistance of 3Ω and R in parallel = 3R/(3 + R) The new null point is shifted by 22.5 cm toward Y, so the new position is: x' = 40 + 22.5 = 62.5 cm from X Remaining length = 100 - 62.5 = 37.5 cm toward Y At the new null point: 2/(3R/(3 + R)) = 62.5/37.5 2(3 + R)/(3R) = 62.5/37.5 2(3 + R)/(3R) = 5/3 Cross multiplying: 2(3 + R) × 3 = 3R × 5 6(3 + R) = 15R 18 + 6R = 15R 18 = 9R ⟹ R = 2Ω
