If the sum of the first 20 terms of the series log_(7^(1/2)) x + log_(7^(1/3)) x + log_(7^(1/4)) x + ... is 460, then x is equal to:

  1. (1) 7^(46/21)
  2. (2) 7^(1/2)
  3. (3) e^2
  4. (4) 7^2

Answer

Correct answer: Option 4

Solution

460 = log_7 x · (2 + 3 + 4 + ..... + 20 + 21) => 460 = log_7 x · ((21 × 22)/2 - 1) => 460 = 230 · log_7 x => log_7 x = 2 => x = 49 Note: 49 = 7^2, which corresponds to option (4)
