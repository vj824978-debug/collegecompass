Let a curve y = y(x) pass through the point (3, 3) and the area of the region under this curve, above the x-axis and between the abscissae 3 and x(> 3) be (y/3)^3. If this curve also passes through the point (α, 6*sqrt(10)) in the first quadrant, then α is equal to ___.

Answer

Correct answer: 6

Solution

Given that the area under curve from 3 to x is (y/3)^3. Differentiating with respect to x: f(x) = d/dx[(y/3)^3] = (y^2/3)*(dy/dx). This leads to a differential equation. After substituting y^2 = t and solving: y^2 = x^4/3 + Cx^2. Using the condition y(3) = 3: 9 = 81/3 + 9C, so C = -2. Thus y^2 = x^4/3 - 2x^2. For the point (α, 6*sqrt(10)): 360 = α^4/3 - 6α^2, which gives α^4 - 6α^2 - 1080 = 0. Solving yields α = 6.
