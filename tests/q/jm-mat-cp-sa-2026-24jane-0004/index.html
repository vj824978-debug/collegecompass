Let vector a = 2i - j - k, vector b = i + 3j - k and vector c = 2i + j + 3k. Let vector v be the vector in the plane of the vectors vector a and vector b, such that the length of its projection on the vector vector c is 1/sqrt(14). Then |vector v| is equal to

  1. (1) sqrt(21)/2
  2. (2) 13
  3. (3) sqrt(35)/2
  4. (4) 7

Answer

Correct answer: Option 1 or 2 or 3 or 4

Solution

vector v = x*vector a + y*vector b = x(2i - j - k) + y(i + 3j - k) vector v = (2x + y)i + (3y - x)j + (-x - y)k The projection of vector v on vector c is given by: |vector v · vector c| / |vector c| = 1/sqrt(14) vector v · vector c = 2(2x + y) + 3y - x - 3x - 3y = 2y |vector c| = sqrt(4 + 1 + 9) = sqrt(14) |2y| / sqrt(14) = 1/sqrt(14) |2y| = 1 |vector v| = sqrt((2x + y)^2 + (3y - x)^2 + (-x - y)^2) = sqrt(4x^2 + 4xy + y^2 + 9y^2 - 6xy + x^2 + x^2 + 2xy + y^2) = sqrt(6x^2 + 11y^2 + 4xy - 6xy + 2xy) = sqrt(6x^2 + 11y^2 + 4xy - 6xy + 2xy) = sqrt(6x^2 + 11y^2 + 4xy - 6xy + 2xy) = sqrt(6x^2 + (11/4)y^2 + 4xy - 6xy + 2xy) With |2y| = 1, we have y^2 = 1/4 However, complete information not provided to find vector v uniquely; we need an extra relation to calculate the value of x.
