Let vector a = 2i - j + k and vector b = λj + 2k, λ ∈ Z be two vectors. Let vector c = vector a × vector b and vector d be a vector of magnitude 2 in yz-plane. If |vector c| = sqrt(53), then the maximum possible value of (vector c · vector d)^2 is equal to:

  1. (1) 26
  2. (2) 104
  3. (3) 208
  4. (4) 52

Answer

Correct answer: Option 3

Solution

vector a = 2i - j + k vector b = λj + 2k; λ ∈ Z vector c = vector a × vector b = (-2 - λ)i - 4j + 2λk |vector c| = sqrt(53) Calculating magnitude: |vector c|^2 = (-2 - λ)^2 + 16 + 4λ^2 = 53 4 + 4λ + λ^2 + 16 + 4λ^2 = 53 5λ^2 + 4λ - 33 = 0 Using quadratic formula: λ = (-4 ± sqrt(16 + 660))/10 = (-4 ± sqrt(676))/10 = (-4 ± 26)/10 λ = 2.2 or -3 Since λ ∈ Z, we have λ = -3 vector c = i - 4j - 6k Let vector d = yj + zk (since d is in yz-plane) |vector d| = 2 ⟹ y^2 + z^2 = 4 vector c · vector d = -4y - 6z (vector c · vector d)^2 = (-4y - 6z)^2 = (4y + 6z)^2 By Cauchy-Schwarz inequality: (4y + 6z)^2 ≤ (4^2 + 6^2)(y^2 + z^2) = (16 + 36)(4) = 52 × 4 = 208 Therefore, the maximum possible value of (vector c · vector d)^2 is 208.
