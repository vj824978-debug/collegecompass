Let m1 and m2 be the slopes of the tangents drawn from the point P(4, 1) to the hyperbola H: y^2/25 - x^2/16 = 1. If Q is the point from which the tangents drawn to H have slopes |m1| and |m2| and they make positive intercepts α and β on the x-axis, then (PQ)^2/(αβ) is equal to ___.

Answer

Correct answer: 8

Solution

Tangent to hyperbola: y = mx + sqrt(25 - 16m^2). Since it passes through P(4,1): 1 = 4m + sqrt(25 - 16m^2). Squaring: (4m-1)^2 = 25 - 16m^2, which gives 4m^2 - m - 3 = 0. So m1 = 1, m2 = -3/4. Taking absolute values: |m1| = 1, |m2| = 3/4. Tangents with these slopes: y = x - 3 and y = (3/4)x - 4. These intersect at Q(-4, -7). x-intercepts: α = 3 (from first tangent), β = 16/3 (from second tangent). (PQ)^2 = (4-(-4))^2 + (1-(-7))^2 = 64 + 64 = 128. αβ = 3 × (16/3) = 16. (PQ)^2/(αβ) = 128/16 = 8.
