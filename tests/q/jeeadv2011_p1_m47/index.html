Let (x₀, y₀) be solution of the following equations (2x)^ln2 = (3y)^ln3 3^lnx = 2^lny Then x₀ is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 1/6
  2. (B) 1/3
  3. (C) 1/2
  4. (D) 6

Answer

Correct answer: C

Solution

Sol. (C) (2x)^(ln 2) = (3y)^(ln 3) ...(i) 3^(lnx) = 2^(lny) ...(ii) ⟹ (logx)(log3) = (logy)log2 ⟹ logy = (log x)(log 3)/(log 2) ...(iii) In (i) taking log both sides (log2){log2 + logx} = log3{log3 + logy} (log2)² + (log2)(logx) = (log3)² + (log3)²(log x)/(log 2) from (iii) ⟹ (log2)² - (log3)² = [(log3)² - (log 2)²]/(log 2) (logx) ⟹ -log2 = logx ⟹ x = 1/2 ⟹ x₀ = 1/2
