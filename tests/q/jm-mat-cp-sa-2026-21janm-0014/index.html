Let (α,β,γ) be the co-ordinates of the foot of the perpendicular drawn from the point (5,4,2) on the line r = (-i + 3j + k) + λ(2i + 3j - k). Then the length of the projection of the vector αi + βj + γk on the vector 6i + 2j + 3k is:

  1. (1) 15/7
  2. (2) 4
  3. (3) 18/7
  4. (4) 3

Answer

Correct answer: Option 3

Solution

The line can be written as (x+1)/2 = (y-3)/3 = (z-1)/(-1) = λ. Any general point P on the line is (2λ-1, 3λ+3, -λ+1). Vector AP = (2λ-6)i + (3λ-1)j + (-λ-1)k where A(5,4,2). For perpendicularity, AP · (2i+3j-k) = 0. This gives 2(2λ-6) + 3(3λ-1) - 1(-λ-1) = 0, so 4λ-12+9λ-3+λ+1 = 0, thus 14λ = 14, λ = 1. Therefore α = 1, β = 6, γ = 0.
