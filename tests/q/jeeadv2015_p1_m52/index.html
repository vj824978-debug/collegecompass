In ℝ³, consider the planes P₁: y = 0 and P₂: x + z = 1. Let P₃ be a plane, different from P₁ and P₂, which passes through the intersection of P₁ and P₂. If the distance of the point (0, 1, 0) from P₃ is 1 and the distance of a point (α, β, γ) from P₃ is 2, then which of the following relations is (are) true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) 2α + β + 2γ + 2 = 0
  2. (B) 2α - β + 2γ + 4 = 0
  3. (C) 2α + β - 2γ - 10 = 0
  4. (D) 2α - β + 2γ - 8 = 0

Answer

Correct answer: BD

Solution

Let the required plane be x + z + λy - 1 = 0 ⟹ |λ - 1|/√(λ² + 2) = 1 ⟹ λ = -1/2 ⟹ P₃ ≡ 2x - y + 2z - 2 = 0 Distance of P₃ from (α, β, γ) is 2 |2α - β + 2γ - 2|/√(4 + 1 + 4) = 2 ⟹ 2α - β + 2λ + 4 = 0 and 2α - β + 2λ - 8 = 0
