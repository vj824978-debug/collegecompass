An annular disk of mass M, inner radius a and outer radius b is placed on a horizontal surface with coefficient of friction μ, as shown in the figure. At some time, an impulse J₀x̂ is applied at a height h above the center of the disk. If h = h_m then the disk rolls without slipping along the x-axis. Which of the following statement(s) is(are) correct? [Figure shows an annular disk (ring shape) with inner radius a and outer radius b on a horizontal surface. An impulse J₀ is applied horizontally at height h above the center of the disk along the x-axis direction.]

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) For μ ≠ 0 and a → 0, h_m = b/2
  2. (B) For μ ≠ 0 and a → b, h_m = b
  3. (C) For h = h_m, the initial angular velocity does not depend on the inner radius a.
  4. (D) For μ = 0 and h = 0, the wheel always slides without rolling.

Answer

Correct answer: ABCD

Solution

J = Mv_cm ...(i) Jh = I_cm ω ...(ii) v_cm = bω ...(iii) h = I_cm/(Mb) (A) For μ ≠ 0, a = 0 the system will be a disc, for pure rolling of disc h = I_cm/(Mb) = b/2 (B) for μ ≠ 0, a = b wheel will be ring h = b (C) for μ = 0 and h = 0 wheel will slide without rolling (D) for h = h_m, v_cm = vω
