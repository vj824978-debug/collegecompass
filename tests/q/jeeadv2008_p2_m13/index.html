Let a solution y = y(x) of the differential equation x sqrt(x^2 - 1) dy - y sqrt(y^2 - 1) dx = 0 satisfy y(2) = 2/sqrt(3). STATEMENT-1: y(x) = sec(sec^(-1) x - π/6) and STATEMENT-2: y(x) is given by 1/y = 2*sqrt(3)/x * sqrt(1 - 1/x^2)

Assertion–Reason · Marks: +3 / -1.0

  1. (A) STATEMENT-1 is True, STATEMENT-2 is True; STATEMENT-2 is a correct explanation for STATEMENT-1
  2. (B) STATEMENT-1 is True, STATEMENT-2 is True; STATEMENT-2 is NOT a correct explanation for STATEMENT-1.
  3. (C) STATEMENT-1 is True, STATEMENT-2 is False
  4. (D) STATEMENT-1 is False, STATEMENT-2 is True

Answer

Correct answer: C

Solution

Sol. (C) ∫ dx/(x√(x²-1)) = ∫ dy/(y√(y²-1)) sec⁻¹x = sec⁻¹y + c sec⁻¹2 = sec⁻¹(2/√3) + c c = π/3 - π/6 = π/6 sec⁻¹x = sec⁻¹y + π/6 y = sec(sec⁻¹x - π/6) cos⁻¹(1/x) = cos⁻¹(1/y) + π/6 cos⁻¹(1/y) = cos⁻¹(1/x) - cos⁻¹(√3/2) 1/y = (√3)/(2x) · √(1 - 1/x²) · (1/2) 2/y = (√3)/x · √(1 - 1/x²)
