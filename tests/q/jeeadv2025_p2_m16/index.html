If α = integral from 1/2 to 2 of tan^(-1) x / (2x^2 - 3x + 2) dx, then the value of sqrt(7) tan(2α sqrt(7) / π) is ______ (Here, the inverse trigonometric function tan^(-1) x assumes values in (-π/2, π/2).)

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 21

Solution

α = ∫[1/2 to 2] (tan⁻¹ x)/(2x² - 3x + 2) dx Put z = 1/x α = ∫[1/2 to 2] (cot⁻¹(-z))(-dz)/(2z² - 3z + 2) α = ∫[1/2 to 2] (π/2 - tan⁻¹(z))/(2z² - 3z + 2) 2α = (π/2)∫[1/2 to 2] 1/(2z² - 3z + 2) dz 2α = (π/2) × (1/2)∫[1/2 to 2] 1/((z - 3/4)² + (√7/4)²) dz ⟹ Now using ∫ 1/(x² + a²) dx = (1/a)tan⁻¹(x/a) + c We have 2α = (π/√7)[tan⁻¹(5/√7) + tan⁻¹(1/√7)] ⟹ (2α√7)/π = tan⁻¹(3√7) tan((2α√7)/π) = 3√7 Now, √7 tan((2α√7)/π) = 21
