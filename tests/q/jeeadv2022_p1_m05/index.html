Let z̄ denote the complex conjugate of a complex number z and let i = √(-1). In the set of complex numbers, the number of distinct roots of the equation z̄ - z^2 = i(z̄ + z^2) is ________.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 4

Solution

Let z = x + iy x - iy - x² + y² - 2ixy = i(x - iy + x² - y² + 2ixy) (x - x² + y²) - i(y + 2xy) = (y - 2xy) + i(x + x² - y²) ⇒ x - x² + y² = y - 2xy ...(1) x + x² - y² = -y - 2xy ...(2) (1) + (2): 2x = -4xy ⇒ x = -2xy ⇒ x(1 + 2y) = 0 ⇒ x = 0 or y = -1/2 Put x = 0 in (1) or (2) we get y² = y ⇒ y = 0, 1 ∴ 2 complex numbers are possible 0 + 0i and 0 + i put y = -1/2 in (1) or (2): x - x² + 1/4 = -1/2 + x ⇒ x² = 3/4 ⇒ x = ±√3/2 ∴ √3/2 - i/2 and -√3/2 - i/2 are possible ∴ 4 solutions are possible.
