If c is a point at which Rolle's theorem holds for the function, f(x) = log_e((x + alpha)/(7x)) in the interval [3, 4], where alpha ∈ R, then f''(c) is equal to -

  1. (1) 1/24
  2. (2) 1/12
  3. (3) 1/12
  4. (4) sqrt(3)/7

Answer

Correct answer: Option 3

Solution

For Rolle's theorem to be applicable in [3, 4] f(3) = f(4) => log_e((9 + alpha)/21) = log_e((16 + alpha)/28) => log_e(((9 + alpha)/21) * (3/4)/(16 + alpha)) = 0 => (9 + alpha)/(16 + alpha) * (4/3) = 1 => 36 + 4alpha = 48 + 3alpha => alpha = 12 Applying Rolle's theorem => c ∈ (3, 4) s.t f'(c) = 0 f(x) = log_e((x + 12)/(7x)) = log_e(x + 12) - log_e(7x) f'(x) = 1/(x + 12) - 1/x = (1(2c))/(c^2 + 12) - 1/(7c) * 7 = 0 => 2c^2 = c^2 + 12 => c^2 = 12 Now f(x) = log_e(x^2 + 12) - log_e(7x) f'(x) = (2x)/(x^2 + 12) - 1/x f''(x) = (4x^2)/(x^2 + 12)^2 + 2/(x^2 + 12) + 1/x^2 f''(c) = (4(12))/(24)^2 + 2/24 + 1/12 = 1/12
