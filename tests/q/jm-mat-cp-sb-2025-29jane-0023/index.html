Let a1, a2, ..., a2024 be an Arithmetic Progression such that a1 + (a5 + a10 + a15 + ... + a2020) + a2024 = 2233. Then a1 + a2 + a3 + ... + a2024 is equal to

Answer

Correct answer: 11132

Solution

a1 + a5 + a10 + a15 + ... + a2020 + a2024 = 2233 In an A.P. the sum of terms equidistant from ends is equal. a1 + a2024 = a5 + a2020 = a10 + a2015 = ... The sequence a5, a10, a15, ..., a2020 contains terms: a5, a10, a15, ..., a2020 These are 404 terms (from 5 to 2020 in steps of 5: (2020-5)/5 + 1 = 404) We can pair them: a5 + a2020, a10 + a2015, etc. This gives us 202 pairs. Also, a1 + a2024 forms one more pair. Total: 203 pairs => 203(a1 + a2024) = 2233 Hence, S2024 = (2024/2)(a1 + a2024) = 1012 × (a1 + a2024) = 1012 × (2233/203) = 1012 × 11 = 11132
