Arrange the following gases in increasing order of van der Waals constant 'a': (A) Ar (B) CH4 (C) H2O (D) C6H6

  1. (1) D, C, B and A
  2. (2) B, C, D and A
  3. (3) C, D, B and A
  4. (4) A, B, C and D

Answer

Correct answer: Option 1

Solution

The van der Waals constant 'a' for the given gases are: Ar = 1.35 L^2 atm mol^-2, CH4 = 2.25 L^2 atm mol^-2, H2O = 5.536 L^2 atm mol^-2, C6H6 = 18.57 L^2 atm mol^-2. The constant 'a' represents the magnitude of intermolecular attractive forces. Arranging in increasing order: A < B < C < D, which gives Ar < CH4 < H2O < C6H6 or D, C, B and A in the reverse order.
