The balancing length for a cell is 560 cm in a potentiometer experiment. When an external resistance of 10Ω is connected in parallel to the cell, the balancing length changes by 60 cm. If the internal resistance of the cell is N/10 Ω, where N is an integer then value of N is ................

Answer

Correct answer: 12

Solution

From the potentiometer circuit diagram: Initially (without external resistance): E = 560x ......(i) where x is the potential gradient With internal resistance r and balancing length 560 cm: E - ir = 500x After connecting 10Ω in parallel to the cell: The equivalent resistance becomes: R_eq = (10 × r)/(10 + r) Current through potentiometer: i' = E/(R_eq + R_0) The new balancing length is 500 cm (changed by 60 cm from 560 cm) Using potentiometer principle: E = 560x ......(i) With 10Ω in parallel: 10E/(10 + r) = 500x ......(ii) Dividing (i) by (ii): [560x × (10 + r)]/(10 + r × 500x) = 560/(500x) × (10 + r)/(10) 560(10 + r)/(10E) = 500x 560(10 + r) = 500x × 10E 560(10 + r) = 5000xE From (i): E = 560x 560(10 + r) = 5000x × 560x Simplifying the equations: 10E/(10 + r) = 500x 10 × 560x/(10 + r) = 500x 5600x/(10 + r) = 500x 5600/(10 + r) = 500 5600 = 500(10 + r) 5600 = 5000 + 500r 600 = 500r r = 600/500 = 1.2 Ω r = N/10 = 1.2 N = 12
