For positive integers n, if 4a_n = (n^2 + 5n + 6) and S_n = sum from k=1 to n of (1/a_k), then the value of 507 S_2025 is:

  1. (1) 540
  2. (2) 1350
  3. (3) 675
  4. (4) 135

Answer

Correct answer: Option 3

Solution

a_n = (n^2 + 5n + 6)/4. S_n = sum of 1/a_k = sum of 4/(k^2 + 5k + 6) = 4*sum of 1/((k+2)(k+3)). Using partial fractions: 1/((k+2)(k+3)) = 1/(k+2) - 1/(k+3). This is a telescoping series that simplifies to S_n = 4(1/3 - 1/(n+3)) = 4n/(3(n+3)). For n = 2025: S_2025 = 4(2025)/(3(2028)) = (507*4*2025)/(3*2028) = 675. Therefore, 507*S_2025 = 675.
