If for the matrix A = [1, -u; u, beta], AA^T = I_2, then the value of alpha^4 + beta^4 is:

  1. (1) 3
  2. (2) 4
  3. (3) 2
  4. (4) 1

Answer

Correct answer: Option 4

Solution

Given AA^T = I_2 for matrix A = [1, -u; u, beta]. From the condition AA^T = I_2: 1 + u^2 = 1 so u = 0, and u^2 + beta^2 = 1 so beta^2 = 1, thus beta = ±1. Also u - u*beta = 0 implies u(1-beta) = 0, so either u = 0 or beta = 1. From u - u*beta = 0, we get alpha(1-beta) = 0, so alpha = 0 or beta = 1. Case 1: alpha = 0 and beta = 1, or alpha = 0 and beta = -1. Therefore alpha^4 + beta^4 = 0 + 1 = 1.
