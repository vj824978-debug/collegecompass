Let a, b and c be three non-zero vectors such that b and c are non-collinear. If a + 5b is collinear with c, b + 6c is collinear with a and a + alpha*b + beta*c = 0, then alpha + beta is equal to-

  1. (1) 35
  2. (2) -30
  3. (3) -25
  4. (4) 30

Answer

Correct answer: Option 1

Solution

From a + 5b collinear with c: a + 5b = lambda*c, so a = lambda*c - 5b ...(i). From b + 6c collinear with a: b + 6c = mu*a. Substituting (i): b + 6c = mu(lambda*c - 5b), which gives b + 6c = mu*lambda*c - 5mu*b. Rearranging: b(1 + 5mu) = c(mu*lambda - 6). Since b and c are non-collinear: 1 + 5mu = 0, so mu = -1/5 and mu*lambda - 6 = 0, giving lambda(-1/5) = 6, so lambda = -30. From equation (i): a + 5b + 30c = 0. Comparing with a + alpha*b + beta*c = 0: alpha = 5, beta = 30. Therefore alpha + beta = 35.
