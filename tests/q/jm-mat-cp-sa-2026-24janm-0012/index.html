Let R be a relation defined on the set {1,2,3,4} × {1,2,3,4} by R = {((a,b),(c,d)) : 2a + 3b = 3c + 4d}. Then the number of elements in R is

  1. (1) 6
  2. (2) 18
  3. (3) 12
  4. (4) 15

Answer

Correct answer: Option 3

Solution

We need to find all pairs ((a,b),(c,d)) where a,b,c,d ∈ {1,2,3,4} such that 2a + 3b = 3c + 4d. The relation pairs the ordered pair (a,b) with ordered pair (c,d) if 2a + 3b = 3c + 4d. Let us find all possible values of 2a + 3b for a,b ∈ {1,2,3,4}: - (1,1): 2(1) + 3(1) = 5 - (1,2): 2(1) + 3(2) = 8 - (1,3): 2(1) + 3(3) = 11 - (1,4): 2(1) + 3(4) = 14 - (2,1): 2(2) + 3(1) = 7 - (2,2): 2(2) + 3(2) = 10 - (2,3): 2(2) + 3(3) = 13 - (2,4): 2(2) + 3(4) = 16 - (3,1): 2(3) + 3(1) = 9 - (3,2): 2(3) + 3(2) = 12 - (3,3): 2(3) + 3(3) = 15 - (3,4): 2(3) + 3(4) = 18 - (4,1): 2(4) + 3(1) = 11 - (4,2): 2(4) + 3(2) = 14 - (4,3): 2(4) + 3(3) = 17 - (4,4): 2(4) + 3(4) = 20 Now find all possible values of 3c + 4d for c,d ∈ {1,2,3,4}: - (1,1): 3(1) + 4(1) = 7 - (1,2): 3(1) + 4(2) = 11 - (1,3): 3(1) + 4(3) = 15 - (1,4): 3(1) + 4(4) = 19 - (2,1): 3(2) + 4(1) = 10 - (2,2): 3(2) + 4(2) = 14 - (2,3): 3(2) + 4(3) = 18 - (2,4): 3(2) + 4(4) = 22 - (3,1): 3(3) + 4(1) = 13 - (3,2): 3(3) + 4(2) = 17 - (3,3): 3(3) + 4(3) = 21 - (3,4): 3(3) + 4(4) = 25 - (4,1): 3(4) + 4(1) = 16 - (4,2): 3(4) + 4(2) = 20 - (4,3): 3(4) + 4(3) = 24 - (4,4): 3(4) + 4(4) = 28 Matching values: - 2a+3b = 7: (2,1); 3c+4d = 7: (1,1) → 1 pair - 2a+3b = 10: (2,2); 3c+4d = 10: (2,1) → 1 pair - 2a+3b = 11: (1,3), (4,1); 3c+4d = 11: (1,2) → 2 pairs - 2a+3b = 13: (2,3); 3c+4d = 13: (3,1) → 1 pair - 2a+3b = 14: (1,4), (4,2); 3c+4d = 14: (2,2) → 2 pairs - 2a+3b = 15: (3,3); 3c+4d = 15: (1,3) → 1 pair - 2a+3b = 16: (2,4); 3c+4d = 16: (4,1) → 1 pair - 2a+3b = 17: (4,3); 3c+4d = 17: (3,2) → 1 pair - 2a+3b = 18: (3,4); 3c+4d = 18: (2,3) → 1 pair - 2a+3b = 20: (4,4); 3c+4d = 20: (4,2) → 1 pair Total = 1+1+2+1+2+1+1+1+1+1 = 12 elements in R
