The integral ∫(3x^13 + 2x^11)/(2x^4 + 3x^2 + 1)^4 dx is equal to : (where C is a constant of integration)

  1. (1) x^12/(6(2x^4 + 3x^2 + 1)^3) + C
  2. (2) x^4/(6(2x^4 + 3x^2 + 1)^3) + C
  3. (3) x^12/((2x^4 + 3x^2 + 1)^3) + C
  4. (4) x^4/((2x^4 + 3x^2 + 1)^3) + C

Answer

Correct answer: Option 1

Solution

∫(3x^13 + 2x^11)/(2x^4 + 3x^2 + 1)^4 dx = ∫(3x^13 + 2x^11)/((x^4)^4(2 + 3/x^2 + 1/x^4)^4) dx = ∫(3x^(-3) + 2x^(-5))/(2 + 3x^(-2) + x^(-4))^4 dx = -1/2 ∫dt/t^4 [Put t = 2 + 3x^(-2) + x^(-4)] where dt/dx = 0 - 6x^(-3) - 4x^(-5) dt/(-2) = (3x^(-3) + 2x^(-5))dx = -1/2 ∫t^(-4) dt = -1/2 · t^(-3)/(-3) + C = 1/(6t^3) + C = 1/(6(2 + 3/x^2 + 1/x^4)^3) + C = x^12/(6(2x^4 + 3x^2 + 1)^3) + C
