Let C be the circle in the complex plane with centre z_0 = (1+3i)/2 and radius r = 1. Let z_1 = 1+i and the complex number z_2 be outside circle C such that |z_1-z_0||z_2-z_0| = 1. If z_0, z_1 and z_2 are collinear, then the smaller value of |z_2|^2 is equal to

  1. (1) 5/2
  2. (2) 7/2
  3. (3) 13/2
  4. (4) 3/2

Answer

Correct answer: Option 1

Solution

Given: z_0 = (1+3i)/2, z_1 = 1+i, |z_1-z_0||z_2-z_0| = 1. First, |z_1-z_0| = |1+i-(1+3i)/2| = |(1-i)/2| = 1/sqrt(2). So |z_2-z_0| = sqrt(2). Since z_0, z_1, z_2 are collinear: (z_2-z_0)/(z_1-z_0) = ±2 (real). This gives z_2 = z_0 ± 2(z_1-z_0). Case 1: z_2 = 2z_1-z_0 = 2(1+i)-(1+3i)/2 = 3/2+i/2, so |z_2|^2 = 9/4+1/4 = 5/2. Case 2: z_2 = 3z_0-2z_1 = 3(1+3i)/2-2(1+i) = -1/2+5i/2, so |z_2|^2 = 1/4+25/4 = 13/2. The smaller value is 5/2.
