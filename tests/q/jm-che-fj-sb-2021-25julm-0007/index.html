For the reaction A + B ⇌ 2C, the value of equilibrium constant is 100 at 298K. If the initial concentration of all three species is 1M each, then the equilibrium concentration of C is x×10^(-y) M. The value of x is ___ (Nearest integer)

Answer

Correct answer: 25

Solution

For reaction A + B ⇌ 2C with Kc = 100. Initially [A] = [B] = [C] = 1M. Using ICE table: At equilibrium [A] = 1-x, [B] = 1-x, [C] = 1+2x. Kc = (1+2x)^2/((1-x)(1-x)) = 100. Taking square root: (1+2x)/(1-x) = 10. Solving: 1+2x = 10-10x, 12x = 9, x = 3/4. Therefore [C] = 1+2x = 1+2(3/4) = 1+3/2 = 5/2 = 2.5M = 25×10^(-1)M. So x = 25 (nearest integer).
