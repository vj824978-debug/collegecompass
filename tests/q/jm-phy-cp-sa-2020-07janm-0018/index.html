A thin lens made of glass (refractive index = 1.5) of focal length f = 16 cm is immersed in a liquid of refractive index 1.42. If its focal length in liquid is f_l, then the ratio f_l / f is closed to the integer

  1. (1) 1
  2. (2) 17
  3. (3) 9
  4. (4) 5

Answer

Correct answer: Option 3

Solution

Using the lensmaker's formula for a lens in a medium: 1/f = ((mu_2 - mu_1)/mu_1)(1/R_1 - 1/R_2) .....(i) For the lens in air (mu_1 = 1, mu_2 = 1.5): 1/f = (1.5 - 1)/1 * (1/R_1 - 1/R_2) = 0.5 * (1/R_1 - 1/R_2) For the lens immersed in liquid (mu_1 = 1.42, mu_2 = 1.5): 1/f_l = ((1.5 - 1.42)/1.42) * (1/R_1 - 1/R_2) .....(ii) Dividing equation (ii) by equation (i): (1/f_l)/(1/f) = ((1.5 - 1.42)/1.42) / (0.5) f/f_l = (0.5 * 1.42)/(0.08) = 0.71/0.08 = 8.875 f_l/f = 0.08/(0.5 * 1.42) = 0.08/0.71 ≈ 0.056 Wait, recalculating: f/f_l = (0.5)/(0.08/1.42) = (0.5 * 1.42)/0.08 = 0.71/0.08 ≈ 8.875 So f_l/f = 0.08/(0.5 * 1.42) = 0.08/0.71 ≈ 1/9 Actually: f_l/f = (0.5 * 1.42)/(1.5 - 1.42) = 0.71/0.08 ≈ 8.875 Let me recalculate more carefully: f_l/f = ((mu_2 - mu_1)/mu_1 in liquid) / ((mu_2 - mu_1)/mu_1 in air) = ((1.5 - 1.42)/1.42) / ((1.5 - 1)/1) = (0.08/1.42) / (0.5) = 0.08/(1.42 * 0.5) = 0.08/0.71 ≈ 0.113 Therefore f/f_l = 0.71/0.08 ≈ 8.875 ≈ 9 So f_l/f ≈ 1/9, meaning f/f_l ≈ 9
