The radii of curvature for a thin convex lens are 10cm and 15cm respectively. The focal length of the lens is 12cm. The refractive index of the lens material is

  1. (1) 1.4
  2. (2) 1.5
  3. (3) 1.2
  4. (4) 1.8

Answer

Correct answer: Option 2

Solution

Using lens maker's formula: 1/f = (n-1)(1/R1 - 1/R2). Given f = 12cm, R1 = 10cm, R2 = -15cm (convex lens). 1/12 = (n-1)(1/10 + 1/15) = (n-1)(5/30) = (n-1)/6. Therefore n-1 = 6/12 = 0.5, so n = 1.5
