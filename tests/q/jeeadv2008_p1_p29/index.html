Figure shows three resistor configurations R1, R2 and R3 connected to 3V battery. If the power dissipated by the configuration R1, R2 and R3 is P1, P2 and P3, respectively, then Figure: [Three circuit diagrams labeled R1, R2, and R3. R1 shows four 1Ω resistors in series-parallel configuration connected to 3V. R2 shows four 1Ω resistors in a diamond/bridge configuration connected to 3V. R3 shows four 1Ω resistors with one 1Ω resistor at bottom connected to 3V.]

Single correct MCQ · Marks: +3 / -1.0

  1. (A) P1 > P2 > P3
  2. (B) P1 > P3 > P2
  3. (C) P2 > P1 > P3
  4. (D) P3 > P2 > P1

Answer

Correct answer: C

Solution

Sol. (C) P = V²/R R₁ = 1 Ω, R₂ = 1/2 Ω, R₃ = 2 Ω ∴ P₂ > P₁ > P₃
