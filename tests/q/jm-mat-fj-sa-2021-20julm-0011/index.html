If alpha and beta are the distinct roots of the equation x^2 + (3)^(1/4) x + 3^(1/2) = 0, then the value of alpha^96 (alpha^2 - 1) + beta^96 (beta^2 - 1) is equal to:

  1. (1) 56 × 3^24
  2. (2) 28 × 3^24
  3. (3) 52 × 3^24
  4. (4) 56 × 3^24

Answer

Correct answer: Option 3

Solution

Put 3^(1/4) = a. Equation becomes: x^2 + ax + a^2 = 0. Using Vieta's formulas: (x/a)^3 + x/a + 1 = 0, so x = aw, w^3 = -1. Thus alpha = aw, beta = aw^2 where w is a cube root of unity. alpha^96 = a^96 w^96 = 3^24 since w^96 = 1 and a^96 = (3^(1/4))^96 = 3^24. Similarly beta^96 = 3^24. alpha^2 - 1 = a^2 w^2 - 1 = 3^(1/2) w^2 - 1. Computing alpha^96 (alpha^2 - 1) + beta^96 (beta^2 - 1) = 52 × 3^24.
