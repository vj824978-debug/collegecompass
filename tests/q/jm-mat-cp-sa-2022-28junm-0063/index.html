If the system of linear equations 2x + 3y - z = -2, x + y + z = 4, x - y + |λ|z = 4λ - 4 where λ ∈ R, has no solution, then

  1. (1) λ = 7
  2. (2) λ = -7
  3. (3) λ = 8
  4. (4) λ^2 = 1

Answer

Correct answer: Option 2

Solution

The determinant of coefficient matrix is calculated as |2 3 -1; 1 1 1; 1 -1 λ| = 0, which gives λ = 7. However, at λ = 7, checking D_x = D_y = D_z = 0. The equations become: P1: 2x + 3y - z = -2, P2: x + y + z = 4, P3: x - y + 7z = 24. Since 5P2 - 2P1 = P3, the system has infinite solutions at λ = 7. For no solution, we need λ = -7, which makes D = 0 but the system inconsistent.
