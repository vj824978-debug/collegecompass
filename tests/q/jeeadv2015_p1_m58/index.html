Let f(x) = sin(π/6 * sin(π/2 * sin(x))) for all x ∈ ℝ and g(x) = π/2 * sin(x) for all x ∈ ℝ. Let (f ∘ g)(x) denote f(g(x)) and (g ∘ f)(x) denote g(f(x)). Then which of the following is (are) true?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) Range of f is [-1/2, 1/2]
  2. (B) Range of f ∘ g is [-1/2, 1/2]
  3. (C) lim_{x→0} f(x)/g(x) = π/6
  4. (D) There is an x ∈ ℝ such that (g ∘ f)(x) = 1

Answer

Correct answer: ABC

Solution

Given g(x) = (π/2)sin x ∀ x ∈ ℝ f(x) = sin((1/3)g(g(x))) ⟹g(g(x)) ∈ [-π/2, π/2] ∀ x ∈ ℝ Also, g(g(g(x))) ∈ [-π/2, π/2] ∀ x ∈ ℝ Hence, f(x) and f(g(x)) ∈ [-1/2, 1/2] lim[x→0] f(x)/g(x) = lim[x→0] sin((1/3)g(g(x)))/(1/3)g(g(x)) · (1/3)g(g(x))/g(x) ⟹ lim[x→0] (π/6) · sin((π/2)sin x)/((π/2)sin x) = π/6 Range of g(f(x)) ∈ [-(π/2)sin(1/2), (π/2)sin(1/2)] ⟹ g(f(x)) ≠ 1.
