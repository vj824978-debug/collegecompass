The electric field and magnetic field components of an electromagnetic wave going through vacuum is described by E_x = E_0 sin(kz - ωt) and B_y = B_0 sin(kz - ωt). Then the correct relation between E_0 and B_0 is given by

  1. (1) ωE_0 = kB_0
  2. (2) E_0 = kB_0
  3. (3) kE_0 = ωB_0
  4. (4) E_0B_0 = ωk

Answer

Correct answer: Option 3

Solution

E_x = E_0 sin(kz - ωt) B_y = B_0 sin(kz - ωt) For an electromagnetic wave, the relationship between electric field and magnetic field is given by: velocity = E_0/B_0 Also, we know that ω/k = E_0/B_0 From the wave equation, the phase velocity is v = ω/k For electromagnetic waves in vacuum, v = c, so: ω/k = E_0/B_0 Cross-multiplying: ωB_0 = kE_0 Or equivalently: kE_0 = ωB_0
