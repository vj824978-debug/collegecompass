The number of solution of the equation x + 2tan x = pi/2 in the interval [0, 2pi] is:

  1. (1) 5
  2. (2) 4
  3. (3) 3
  4. (4) 2

Answer

Correct answer: Option 3

Solution

We need to find solutions to x + 2tan(x) = pi/2 in [0, 2pi]. This can be rewritten as 2tan(x) = pi/2 - x. We need to find intersection points of y = tan(x) and y = (pi/2 - x)/2. The equation 2tan(x) = pi/2 - x has solutions where these curves intersect. Analyzing the behavior: tan(x) has vertical asymptotes at pi/2, 3pi/2, etc. In [0, 2pi], we check intervals (0, pi/2), (pi/2, 3pi/2), (3pi/2, 2pi). The number of intersection points of y = tan x and y = pi/4 - x/2 is 3.
