Match the List - I with List - II. List - I contains: A) PF5, B) SF6, C) Ni(CO)4, D) [PtCl4]2-. List - II contains: I) dsp^2, II) sp^3d, III) sp^3d^2, IV) sp^3. Match the molecules/ions with their hybridization of central atom.

  1. (1) A - III, B - I, C - IV, D - II
  2. (2) A - IV, B - I, C - II, D - III
  3. (3) A - I, B - II, C - III, D - IV
  4. (4) A - II, B - III, C - IV, D - I

Answer

Correct answer: Option 4

Solution

PF5: 5 bonding pairs, trigonal bipyramidal, sp^3d hybridization → A - II. SF6: 6 bonding pairs, octahedral, sp^3d^2 hybridization → B - III. Ni(CO)4: Ni is in +2 state, square planar with 4 CO ligands, dsp^2 hybridization → C - I. [PtCl4]2-: Pt in +2 state, square planar, dsp^2 hybridization → D - I. Wait, rechecking: PF5 is sp^3d (A-II), SF6 is sp^3d^2 (B-III), Ni(CO)4 is sp^3 (tetrahedral, C-IV), [PtCl4]2- is dsp^2 (D-I). So A-II, B-III, C-IV, D-I matches option 4.
