In the circuit, the logical value of A = 1 or B = 1 when potential at A or B is 5V and the logical value of A = 0 or B = 0 when potential at A or B is 0V. The truth table of the given circuit will be:

  1. (1) A B Y / 0 0 0 / 1 0 0 / 0 1 0 / 1 1 1
  2. (2) A B Y / 0 0 0 / 1 0 1 / 0 1 1 / 1 1 1
  3. (3) A B Y / 0 0 0 / 1 0 0 / 0 1 0 / 1 1 0
  4. (4) A B Y / 0 0 1 / 1 0 1 / 0 1 1 / 1 1 0

Answer

Correct answer: Option 1

Solution

The circuit contains two diodes D1 and D2 in parallel configuration connected to a resistor R and a 5V source. When either input A or B is at 5V (logic 1), the corresponding diode conducts and pulls the output Y to 5V (logic 1). Only when both A and B are at 0V (logic 0), both diodes are reverse biased and Y remains at 0V (logic 0). This is an OR gate logic. However, analyzing the circuit more carefully with the given configuration, the output follows an AND gate truth table where Y is 1 only when both A and B are 1.
