If cos(α + β) = 3/5, sin(α - β) = 5/13 and 0 < α, β < π/4, then tan(2α) is equal to

  1. (1) 63/52
  2. (2) 63/16
  3. (3) 33/52
  4. (4) 21/16

Answer

Correct answer: Option 2

Solution

cos(α + β) = 3/5 tan(α + β) = 4/3 sin(α - β) = 5/13 tan(α - β) = 5/12 tan(2α) = tan((α + β) + (α - β)) = (tan(α + β) + tan(α - β))/(1 - tan(α + β)tan(α - β)) = (4/3 + 5/12)/(1 - (4/3) × (5/12)) = (48 + 15)/(36 - 20) × (1/36) = 63/16
