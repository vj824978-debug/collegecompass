Match List I with List II. List I contains electronic configuration of elements: (a) 1s^2 2s^2, (b) 1s^2 2s^2 2p^1, (c) 1s^2 2s^2 2p^1, (d) 1s^2 2s^2 2p^3. List II contains ΔH in kJ mol^(-1): (i) 801, (ii) 899, (iii) 1314, (iv) 1402. Choose the most appropriate answer from the options given below.

  1. (1) (A) (a) → (i), (b) → (ii), (c) → (iii), (d) → (iv)
  2. (2) (B) (a) → (i), (b) → (iii), (c) → (iv), (d) → (ii)
  3. (3) (C) (a) → (i), (b) → (iv), (c) → (iii), (d) → (ii)
  4. (4) (D) (a) → (iv), (b) → (i), (c) → (ii), (d) → (iii)

Answer

Correct answer: Option 1

Solution

Match the electronic configurations with ionization enthalpy values. (a) 1s^2 2s^2 is Be with ΔH = 899 kJ/mol. (b) 1s^2 2s^2 2p^1 is B with ΔH = 801 kJ/mol. (c) 1s^2 2s^2 2p^1 is B with ΔH = 1314 kJ/mol (second ionization). (d) 1s^2 2s^2 2p^3 is N with ΔH = 1402 kJ/mol. Due to half-filled p orbital configuration N has more IE than oxygen and due to fully filled configuration Be has higher IE than B.
