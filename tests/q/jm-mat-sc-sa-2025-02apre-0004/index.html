Let A = {1, 2, ..., 100} and R be a relation on A such that R = {(a,b) : a = 2b + 1}. Let (a1, a2), (a2, a3), (a3, a4), ..., (ak, a(k-1)) be a sequence of k elements of R such that the second entry of an ordered pair is equal to the first entry of the next ordered pair. Then the largest integer k, for which such a sequence exists, is equal to

  1. (1) 6
  2. (2) 5
  3. (3) 8
  4. (4) 7

Answer

Correct answer: Option 2

Solution

For (a, b) in R, we need a = 2b + 1, so b = (a-1)/2. Starting with any odd number a1 in A, we form a chain where each subsequent element is (a-1)/2. We need a sequence (a1, a2), (a2, a3), (a3, a4), ... where a2 = 2a1 + 1, a3 = 2a2 + 1, etc., but also each element must satisfy the relation constraint. Working backwards from the largest element ≤ 100: if we start with a1 and each next element is 2a_i + 1, we need a1 ≤ 100 and chain length maximized. Starting from a1 = 3: (3, 7), (7, 15), (15, 31), (31, 63), (63, 127 > 100). Starting from a1 = 1: (1, 3), (3, 7), (7, 15), (15, 31), (31, 63), (63, 127 > 100). This gives k = 6 pairs. Testing other starting points confirms k = 6 is maximum.
