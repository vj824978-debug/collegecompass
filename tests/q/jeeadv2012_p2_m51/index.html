Which of the following is correct ?

Comprehension · Marks: +4 / -1.0

Passage:

  1. (A) a₁₇ = a₁₆ + a₁₅
  2. (B) c₁₇ = c₁₆ + c₁₅
  3. (C) b₁₇ = b₁₆ + c₁₆
  4. (D) a₁₇ = c₁₇ + b₁₆

Answer

Correct answer: A
