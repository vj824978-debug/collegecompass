The number of ways of choosing 10 objects out of 31 objects of which 10 are identical and the remaining 21 are distinct is :

  1. (1) 2^20 - 1
  2. (2) 2^20
  3. (3) 2^21
  4. (4) 2^20 + 1

Answer

Correct answer: Option 2

Solution

total 31 => 21 distinct & 10 identical We need to choose 10 objects in total. Let k = number of identical objects chosen (where 0 <= k <= 10) Then we need to choose (10 - k) objects from the 21 distinct objects. For a fixed k, the number of ways to choose (10 - k) distinct objects from 21 distinct objects is C(21, 10-k) Total ways = sum from k=0 to 10 of C(21, 10-k) S = C(21, 10) + C(21, 9) + C(21, 8) + C(21, 7) + C(21, 6) + ... + C(21, 0) S = C(21, 10) + C(21, 9) + C(21, 8) + ... + C(21, 1) + C(21, 0) S = C(21, 11) + C(21, 12) + C(21, 13) + ... + C(21, 21) 2S = 2^21 S = 2^20
