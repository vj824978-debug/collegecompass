Let vector a, vector b and vector c be three unit vectors such that |vector a - vector b|^2 + |vector a - vector c|^2 = 8. Then |vector a - 2vector b|^2 + |vector a - 2vector c|^2 is equal to ________.

Answer

Correct answer: 2

Solution

|vector a| = |vector b| = |vector c| = 1 |vector a - vector b|^2 + |vector a - vector c|^2 = 8 => |vector a|^2 + |vector b|^2 - 2vector a·vector b + |vector a|^2 + |vector c|^2 - 2vector a·vector c = 8 => 4 - 2(vector a·vector b + vector a·vector c) = 8 => vector a·vector b + vector a·vector c = -2 |vector a - 2vector b|^2 + |vector a - 2vector c|^2 = |vector a|^2 + 4|vector b|^2 - 4vector a·vector b + |vector a|^2 + 4|vector c|^2 + 4vector a·vector c = 10 + 4(vector a·vector b + vector a·vector c) = 10 + 4(-2) = 10 - 8 = 2
