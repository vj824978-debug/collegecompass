For nonnegative integers s and r, let (s choose r) = {s!/(r!(s-r)!) if r ≤ s, 0 if r > s} For positive integers m and n, let g(m,n) = sum_{p=0}^{min(m,n)} f(m,n,p) / (n+p choose p) where for any nonnegative integer p, f(m,n,p) = sum_{i=0}^{p} (m choose i)((n+i) choose p)((p+n) choose (p-i)) Then which of the following statements is/are TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) g(m,n) = g(n,m) for all positive integers m, n
  2. (B) g(m, n+1) = g(m+1, n) for all positive integers m, n
  3. (C) g(2m, 2n) = 2g(m,n) for all positive integers m, n
  4. (D) g(2m, 2n) = (g(m,n))^2 for all positive integers m, n

Answer

Correct answer: ABD

Solution

f(m,n,p) = ∑[i=0 to p] (ᵐCᵢ · ⁿCₚ · ᵖ⁺ⁿCₚ₋ᵢ) = ∑[i=0 to p] [m!/(i!(m-i)!) · (n+i)!/(p!(n+i-p)!) · (p+n)!/((p-i)!(n+i)!)] = ∑[i=0 to p] ᵐCᵢ · ⁿ⁺ⁱCₙ · ⁿCₚ₋ᵢ = ⁿ⁺ᵖCₙ · ᵐ⁺ⁿCₚ g(m,n) = ∑[p=0 to m+n] (ᵐ⁺ⁿCₚ · ⁿ⁺ⁿCₙ)/(ⁿ⁺ᵖCₚ) = ∑[p=0 to m+n] ᵐ⁺ⁿCₚ = 2^(m+n)
