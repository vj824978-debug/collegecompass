The curve y(x) = ax^3 + bx^2 + cx + 5 touches the x-axis at the point P(-2, 0) and cuts the y-axis at the point Q, where y' is equal to 3. Then the local maximum value of y(x) is:

  1. (1) 27/4
  2. (2) 29/4
  3. (3) 37/4
  4. (4) 9/2

Answer

Correct answer: Option 1

Solution

Since y(x) passes through (-2, 0): 8a - 4b + 2c + 5 = 0 ... (1). Since curve touches x-axis at (-2, 0), y'(-2) = 0: 12a - 4b + c = 0 ... (2). At x = 0, y'(0) = 3: c = 3 ... (3). From (2) and (3): 12a - 4b + 3 = 0. From (1), (2), (3): a = -1/2, b = -3/4, c = 3. So y'(x) = -(3/2)x^2 - (3/2)x + 3. Setting y'(x) = 0: x^2 + x - 2 = 0, giving x = 1 or x = -2. Local maximum occurs at x = 1. y(1) = -1/2 - 3/4 + 3 + 5 = 27/4.
