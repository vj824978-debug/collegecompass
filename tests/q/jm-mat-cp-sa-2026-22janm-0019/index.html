Let the solution curve of the differential equation xdy - ydx = sqrt(x^2 + y^2)dx, x > 0, y(1) = 0, be y = y(x). Then y(3) is equal to

  1. (1) 4
  2. (2) 6
  3. (3) 1
  4. (4) 2

Answer

Correct answer: Option 1

Solution

(xdy - ydx)/x^2 = sqrt(x^2 + y^2)/x^2 dx d(y/x) = sqrt(1 + y^2/x^2) * (1/x) dx Integral of d(y/x)/sqrt(1 + (y/x)^2) = Integral of (1/x) dx ln(y/x + sqrt(1 + y^2/x^2)) = ln(x) + ln(k) = ln(kx) y + sqrt(x^2 + y^2) = kx^2 Applying initial condition y(1) = 0: 0 + 1 = k k = 1 Therefore: y + sqrt(x^2 + y^2) = x^2 At x = 3: y + sqrt(9 + y^2) = 9 sqrt(9 + y^2) = 9 - y Squaring both sides: 9 + y^2 = 81 - 18y + y^2 9 = 81 - 18y 18y = 72 y = 4 Wait, checking the solution provided in image: y + sqrt(9 + y^2) = 9 => y = 4 However, the answer given is [1].
