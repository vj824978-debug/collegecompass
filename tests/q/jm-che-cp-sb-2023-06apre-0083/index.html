The equilibrium composition for the reaction PCl3 + Cl2 ⇌ PCl5 at 298 K is given below: [PCl3]eq = 0.2 mol L^(-1), [Cl2]eq = 0.1 mol L^(-1), [PCl5]eq = 0.40 mol L^(-1). If 0.2 mol of Cl2 is added at the same temperature, the equilibrium concentrations of PCl5 is _____ × 10^(-2) mol L^(-1). Given: Kc for the reaction at 298 K is 20

Answer

Correct answer: 49

Solution

Initial equilibrium: [PCl3] = 0.2, [Cl2] = 0.1, [PCl5] = 0.4. Kc = 0.4/(0.2 × 0.1) = 20. After adding 0.2 mol of Cl2: [Cl2] becomes 0.3. Let x mol of PCl5 form. Using ICE table: Kc = (0.4 + x)/((0.2 - x)(0.3 - x)) = 20. This gives: 0.4 + x = 20(0.06 - 0.5x + x^2). Simplifying: 20x^2 - 11x + 0.8 = 0. Using quadratic formula: x = (11 ± sqrt(121 - 64))/40 = (11 ± 7.55)/40. Taking x = 0.08625. [PCl5] = 0.4 + 0.08625 = 0.48625 × 10^(-2) ≈ 49 × 10^(-2) mol L^(-1)
