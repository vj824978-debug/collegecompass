If y = y(x) is the solution of the differential equation dy/dx + (tan x)y = sin x, 0 ≤ x ≤ pi/3, with y(0) = 0, then y(pi/4) equal to:

  1. (1) (1/2)log_e(2)
  2. (2) (1/(2*sqrt(2)))log_e(2)
  3. (3) (1/4)log_e(2)
  4. (4) log_e(2)

Answer

Correct answer: Option 2

Solution

This is a first-order linear differential equation. Using integrating factor method with IF = e^(integral of tan x dx) = sec x. Multiply both sides by sec x: d/dx(y sec x) = sin x sec x = tan x. Integrate: y sec x = integral of tan x dx = ln(sec x) + c. Apply initial condition y(0) = 0: 0 = ln(1) + c, so c = 0. Thus y sec x = ln(sec x), which gives y = cos x ln(sec x). At x = pi/4: y(pi/4) = cos(pi/4) * ln(sec(pi/4)) = (1/sqrt(2)) * ln(sqrt(2)) = (1/sqrt(2)) * (1/2)ln(2) = (1/(2*sqrt(2)))ln(2).
