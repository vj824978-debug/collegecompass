Let f(x) = 15 - |x - 10|; x ∈ R. Then the set of all values of x, at which the function, g(x) = f(f(x)) is not differentiable, is :

  1. (1) {10, 15}
  2. (2) {5, 10, 15}
  3. (3) {10}
  4. (4) {5, 10, 15, 20}

Answer

Correct answer: Option 2

Solution

f(x) = 15 - |x - 10| g(x) = f[f(x)] = 15 - |f(x) - 10| = 15 - |15 - |x - 10| - 10| = 15 - |5 - |x - 10|| To find where g(x) is not differentiable, we need to identify points where the absolute value expressions change behavior. The expression |5 - |x - 10|| has critical points where: 1) |x - 10| = 0, which gives x = 10 2) 5 - |x - 10| = 0, which gives |x - 10| = 5 This means x - 10 = 5 or x - 10 = -5 So x = 15 or x = 5 From the graph shown: - At x = 5: g(x) has a sharp corner (value (5, 15)) - At x = 10: g(x) has a sharp corner (value (10, 10)) - At x = 15: g(x) has a sharp corner (value (15, 15)) Therefore, g(x) is not differentiable at x = 5, 10, 15. ∴ g(x) is not differentiable at x = 5, 10, 15
