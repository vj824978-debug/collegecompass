Mock Tests › JEE Advanced · Equilibrium › JEE Advanced 2018 Paper 2

For a reaction, A ⇌ P, the plots of [A] and [P] with time at temperatures T₁ and T₂ are given below. [Left graph shows [A] vs Time with two curves labeled T₂ and T₁, starting at 10 mol/L and decreasing to approximately 1-2 mol/L. Right graph shows [P] vs Time with two curves labeled T₁ and T₂, starting at 0 and increasing to approximately 8-9 mol/L. A horizontal dashed line at 5 mol/L is shown on both graphs.] If T₂ > T₁, the correct statement(s) is/are (Assume ΔH° and ΔS° are independent of temperature and ratio of lnK at T₁ to lnK at T₂ is greater than T₂/T₁. Here H, S, G and K are enthalpy, entropy, Gibbs energy and equilibrium constant, respectively.)

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (A) ΔH° < 0, ΔS° < 0
  2. (B) (B) ΔG° < 0, ΔH° > 0
  3. (C) (C) ΔG° < 0, ΔS° < 0
  4. (D) (D) ΔG° < 0, ΔS° > 0

Answer

Correct answer: AC

Solution

A ⇌ P (P)_eq > 5, (A)_eq < 5 K_eq = [P]/[A] > 1 ΔG° = -RT ln K_eq, ΔG° < 0 ln K_II / ln K_I > T₂/T₁ > 1 ⇒ K_II / K_I > 1 ⇒ K_I₂ < K_I₁ (exothermic) ΔH° < 0, since (P) at T₂ < at T₁. ΔG° = ΔH° - TAS° TAS° = ΔH° - ΔG° ΔS° = (ΔH° - ΔG°)/T; (ΔH°) > (ΔG°) ΔS° < 0 Also, -T₁ ln K_II < -T₂ ln K_I₂ II ΔG°_I₁ < ΔG°_I₂ ΔH°_I₁ - TAS°₁ < ΔH°_I₂ - TAS°_I₂ It is possible only if ΔS° < 0.
