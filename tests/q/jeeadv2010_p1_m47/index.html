Let S_k, k = 1, 2, ..., 100, denote the sum of the infinite geometric series whose first term is (k-1)/k! and the common ratio is 1/k. Then the value of 100^2/100! + sum_{k=1}^{100}(k^2 - 3k + 1)S_k is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 3

Solution

Sol. (3) S_k = (k-1)/(1 - 1/k) · k!/(k-1)! = 1/(k-1)! ∑(k=2 to 100) [(k² - 3k + 1) · 1/(k-1)!] = ∑(k=2 to 100) [(k-1)² - k]/[(k-1)!] = ∑[(k-1)/(k-2)! - k/(k-1)!] = [2/1! - 3/2!] + [3/2! - 4/3!] + ... = 2/1! + 1/0! + 2/1! + 3/2! + 3/2! + 4/3! + ... + 99/98! + 100/99! = 3 - 100/99!
