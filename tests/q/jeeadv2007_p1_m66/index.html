In the following [x] denotes the greatest integer less than or equal to x. Match the functions in Column I with the properties Column II Column I vs Column II matching: (A) x [x] — (p) continuous in (−1, 1) (B) sqrt([x]) — (q) differentiable in (−1, 1) (C) x + [x] — (r) strictly increasing in (−1, 1) (D) |x − 1| + |x + 1| — (s) not differentiable at least at one point in (−1, 1)

Matrix match · Marks: +4 / -1.0

  1. (A) A – p, q, r B – p, s C – r, s D – p, q
  2. (B) A – p, q B – p, s C – r, s D – q,r
  3. (C) A – r,s B – p,q, s C – r, s D – p, q
  4. (D) A – p, q, r B – q, s C – p, s D – p, q,r

Answer

Correct answer: A

Solution

Sol. A – p, q, r B – p, s C – r, s D – p, q (A). |x| is continuous, differentiable and strictly increasing in (−1, 1). (B). √|x| is continuous in (−1, 1) and not differentiable at x = 0. (C). x + [x] is strictly increasing in (−1, 1) and discontinuous at x = 0 ⇒ not differentiable at x = 0. (D). |x − 1| + |x + 1| = 2 in (−1, 1) ⇒ the function is continuous and differentiable in (−1, 1).
