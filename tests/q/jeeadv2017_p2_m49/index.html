Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) [A] 0 < α ≤ 1/2
  2. (B) [B] 1/2 < α < 1
  3. (C) [C] 2α⁴ - 4α² + 1 = 0

Correct answer: BC
