When a certain biased die is rolled, a particular face occurs with probability (1/6 - x) and its opposite face occurs with probability (1/6 + x). All other faces occur with probability 1/6. Note that opposite faces sum to 7 in any die. If 0 < x < 1/6, and the probability of obtaining total sum = 7, when such a die is rolled twice, is 13/96, then the value of x is:

  1. (1) 1/9
  2. (2) 1/16
  3. (3) 1/8
  4. (4) 1/12

Answer

Correct answer: Option 3

Solution

Let the particular face be k and its opposite face be (7-k). P(k) = 1/6 - x, P(7-k) = 1/6 + x, P(other faces) = 1/6 each. For sum = 7 when rolling twice: either first roll = i and second roll = (7-i). Required probability = 2[(1/6 - x)(1/6 + x) + (1/6)(1/6) + (1/6)(1/6) + (1/6)(1/6)] = 13/96. Simplifying: 2[(1/6 - x)(1/6 + x) + 3(1/36)] = 13/96. 2[(1/36 - x^2) + 1/12] = 13/96. 2[1/36 + 1/12 - x^2] = 13/96. 2[1/9 - x^2] = 13/96. Therefore x = 1/8.
