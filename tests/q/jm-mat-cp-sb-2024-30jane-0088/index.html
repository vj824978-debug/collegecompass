The variance σ² of the data: xi = 0, 1, 5, 6, 10, 12, 17 with frequencies fi = 3, 2, 3, 2, 6, 3, 3 is ____.

Answer

Correct answer: 29

Solution

First, calculate mean: x̄ = (3×0 + 2×1 + 3×5 + 2×6 + 6×10 + 3×12 + 3×17)/(3+2+3+2+6+3+3) = 176/22 = 8. Then calculate variance: σ² = (1/22)[3×(8-0)² + 2×(8-1)² + 3×(8-5)² + 2×(8-6)² + 6×(8-10)² + 3×(8-12)² + 3×(8-17)²] = (1/22)[3×64 + 2×49 + 3×9 + 2×4 + 6×4 + 3×16 + 3×81] = (1/22)(640) = 29.09 ≈ 29
