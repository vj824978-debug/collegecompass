If the plane P passes through the intersection of two mutually perpendicular planes 2x + ky - 5z = 1 and 3kx - ky + z = 5, k < 3 and intercepts a unit length on positive x-axis, then the intercept made by the plane P on the y-axis is

  1. (1) 1/11
  2. (2) 5/11
  3. (3) 6
  4. (4) 7

Answer

Correct answer: Option 4

Solution

For perpendicularity of P1 and P2: 2(3k) + k(-k) + (-5)(1) = 0 => 6k - k^2 - 5 = 0 => k^2 - 6k + 5 = 0 => k = 1 or 5. Since k < 3, k = 1. With k = 1: P1: 2x + y - 5z = 1 and P2: 3x - y + z = 5. Plane P through intersection: (2x + y - 5z - 1) + λ(3x - y + z - 5) = 0. For x-intercept = 1 (when y = 0, z = 0): (2(1) + 0 - 0 - 1) + λ(3(1) - 0 + 0 - 5) = 0 => 1 + λ(-2) = 0 => λ = 1/2. Plane P: 2x + y - 5z - 1 + (1/2)(3x - y + z - 5) = 0 => 7x + y - 4z - 7 = 0. For y-intercept (x = 0, z = 0): y - 7 = 0 => y = 7.
