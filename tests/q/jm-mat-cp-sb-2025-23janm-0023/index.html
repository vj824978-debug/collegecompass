Let the circle C touch the line x - y + 1 = 0, have the centre on the positive x-axis, and cut off a chord of length 4/sqrt(13) along the line -3x + 2y = 1. Let H be the hyperbola x^2/a^2 - y^2/b^2 = 1, whose one of the foci is the centre of C and the length of the transverse axis is the diameter of C. Then 2a^2 + 3b^2 is equal to ______.

Answer

Correct answer: 19

Solution

Let the centre of circle C be at (a, 0) on the positive x-axis with radius r. Since the circle touches the line x - y + 1 = 0, the perpendicular distance from (a, 0) to the line equals r: r = |a - 0 + 1|/sqrt(2) = (a + 1)/sqrt(2) .....(1) The chord of length 4/sqrt(13) is cut off along the line -3x + 2y = 1. Using the chord-distance formula: Distance from (a, 0) to the line -3x + 2y = 1 is: p = |-3a + 0 - 1|/sqrt(9 + 4) = |-3a - 1|/sqrt(13) = (3a + 1)/sqrt(13) For a chord of length l at distance p from centre: (l/2)^2 + p^2 = r^2 (2/sqrt(13))^2 + ((3a + 1)/sqrt(13))^2 = r^2 => (3a + 1)^2 + 4 = 13r^2 .....(2) From (1) & (2): (3a + 1)^2 + 4 = 13 × (a + 1)^2/2 => 2(3a + 1)^2 + 8 = 13(a + 1)^2 => 2(9a^2 + 6a + 1) + 8 = 13(a^2 + 2a + 1) => 18a^2 + 12a + 2 + 8 = 13a^2 + 26a + 13 => 5a^2 - 14a - 3 = 0 => 5a^2 - 15a + a - 3 = 0 => a = -1/5 or a = 3 Since a is on the positive x-axis, a = 3. => r = 2sqrt(2) For the hyperbola: One focus is at the centre of C: c = 3 Length of transverse axis = diameter of C = 2r = 4sqrt(2) => 2a = 4sqrt(2) => a = 2sqrt(2) => a^2 = 8 Using c^2 = a^2 + b^2: 9 = 8 + b^2 => b^2 = 1 Therefore: 2a^2 + 3b^2 = 2(8) + 3(1) = 16 + 3 = 19
