One mole of an ideal gas is taken through an adiabatic process where the temperature rises from 27 C to 37 C. If the ideal gas is composed of polyatomic molecules that has 4 vibrational modes, which of the following is true? [R = 8.314 J mol^(-1) K^(-1)]

  1. (1) Work done by the gas is close to 582J
  2. (2) Work done on the gas in close to 582J
  3. (3) Work done on the gas is close to 332J
  4. (4) Work done by the gas is close to 332J

Answer

Correct answer: Option 2

Solution

Degrees of freedom f = 3 translational + 3 rotational + 8 vibrational = 14. Using gamma = 1 + 2/f = 1 + 2/14 = 8/7. For adiabatic process, W = nR*Delta(T)/(gamma - 1) = 1 * 8.3 * 10 / (8/7 - 1) = 83 / (1/7) = 581J. Since Delta(T) > 0, work is done on the gas (W < 0 from gas perspective). Work done on the gas is close to 582J.
