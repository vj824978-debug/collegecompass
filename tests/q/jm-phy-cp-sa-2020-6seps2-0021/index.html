An engine operates by taking a monatomic ideal gas through the cycle shown in the figure. The percentage efficiency of the engine is close to ________.

Answer

Correct answer: 19

Solution

From the p-V diagram, we identify the four states: State A: (V_0, P_0) State B: (V_0, 3P_0) State C: (2V_0, 3P_0) State D: (2V_0, P_0) Process AB: Isochoric (constant volume) heating Process BC: Isobaric (constant pressure) expansion Process CD: Isochoric (constant volume) cooling Process DA: Isobaric (constant pressure) compression W_ABCDA = 2P_0V_0 (net work done by the cycle) Heat absorbed: Q_in = Q_AB + Q_BC For process AB (isochoric): Q_AB = nC_V(T_B - T_A) = (n3R/2)(T_B - T_A) = (3/2)(P_BV_B - P_AV_A) = (3/2)(3P_0V_0 - P_0V_0) = 3P_0V_0 For process BC (isobaric): Q_BC = nC_p(T_C - T_B) = (n5R/2)(T_C - T_B) = (5/2)(P_CV_C - P_BV_B) = (5/2)(6P_0V_0 - 3P_0V_0) = (15/2)P_0V_0 Total heat input: Q_in = 3P_0V_0 + (15/2)P_0V_0 = (21/2)P_0V_0 Efficiency: η = W/Q_in × 100 = 2P_0V_0 / [(21/2)P_0V_0] × 100 = (2 × 2/21) × 100 = (4/21) × 100 = 400/21 = 19.04 ≈ 19% η = 19
