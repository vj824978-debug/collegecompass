A straight line L at a distance of 4 units from the origin makes positive intercepts on the coordinate axes and the perpendicular from the origin to this line makes an angle of 60° with the line x + y = 0. Then an equation of the line L is:

  1. (1) x + sqrt(3) y = 8
  2. (2) sqrt(3) x + y = 8
  3. (3) (sqrt(3) + 1)x + (sqrt(3) - 1)y = 8*sqrt(2)
  4. (4) (sqrt(3) - 1)x + (sqrt(3) + 1)y = 8*sqrt(2)

Answer

Correct answer: Option 4

Solution

Let slope of OP = m The perpendicular OP makes an angle of 60° with the line x + y = 0. Slope of line x + y = 0 is -1. tan(60°) = |(m + 1)/(1 - m)| => sqrt(3) = |(m + 1)/(1 - m)| => (m + 1)/(1 - m) = sqrt(3) or (m + 1)/(1 - m) = -sqrt(3) => m + 1 = sqrt(3)(1 - m) or m + 1 = -sqrt(3)(1 - m) => m + 1 = sqrt(3) - sqrt(3)m or m + 1 = -sqrt(3) + sqrt(3)m => m(1 + sqrt(3)) = sqrt(3) - 1 or m(1 - sqrt(3)) = -sqrt(3) - 1 => m = (sqrt(3) - 1)/(1 + sqrt(3)) or m = (sqrt(3) + 1)/(sqrt(3) - 1) Rationalizing: m = (sqrt(3) - 1)/(sqrt(3) + 1) × (sqrt(3) - 1)/(sqrt(3) - 1) = (3 - 2*sqrt(3) + 1)/(3 - 1) = (4 - 2*sqrt(3))/2 = 2 - sqrt(3) or m = (sqrt(3) + 1)/(sqrt(3) - 1) × (sqrt(3) + 1)/(sqrt(3) + 1) = (3 + 2*sqrt(3) + 1)/(3 - 1) = (4 + 2*sqrt(3))/2 = 2 + sqrt(3) For a line at distance d = 4 from origin with slope m: tan(alpha) = (sqrt(3) + 1)/(sqrt(3) - 1) or tan(alpha) = (sqrt(3) - 1)/(sqrt(3) + 1) Equation of line: x*cos(alpha) + y*sin(alpha) = 4 For m = 2 + sqrt(3): tan(alpha) = (sqrt(3) + 1)/(sqrt(3) - 1) For m = 2 - sqrt(3): tan(alpha) = (sqrt(3) - 1)/(sqrt(3) + 1) The equations of the line L are: (sqrt(3) + 1)x + (sqrt(3) - 1)y = 8*sqrt(2) or (sqrt(3) - 1)x + (sqrt(3) + 1)y = 8*sqrt(2)
