The tangent to the curve y = x^2 - 5x + 5, parallel to the line 2y = 4x + 1, also passes through the point:

  1. (1) (1/4, 7/2)
  2. (2) (-1/8, 7)
  3. (3) (7/2, 1/4)
  4. (4) (1/8, -7)

Answer

Correct answer: Option 4

Solution

dy/dx = 2x - 5|_(x=x1) = 2 The tangent is parallel to 2y = 4x + 1, which can be written as y = 2x + 1/2, so the slope is 2. 2x1 = 7 => x1 = 7/2 y1 = (7/2)^2 - 5(7/2) + 5 y1 = 49/4 - 35/2 + 5 y1 = 49/4 - 70/4 + 20/4 = (49 - 70 + 20)/4 = -1/4 The equation of tangent is: y + 1/4 = 2(x - 7/2) y + 1/4 = 2x - 7 4y + 1 = 8x - 28 => 8x - 4y - 29 = 0 Now check options: x = 1/8, y = -7 8(1/8) - 4(-7) - 29 = 1 + 28 - 29 = 0 ✓ The point (1/8, -7) satisfies the equation.
