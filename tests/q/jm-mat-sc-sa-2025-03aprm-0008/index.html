Let a₁, a₂, a₃, ...... be a G.P. of increasing positive numbers. If a₃a₅ = 729 and a₂ + a₄ = 111/4, then 24(a₁ + a₂ + a₃) is equal to

  1. (1) 128
  2. (2) 129
  3. (3) 130
  4. (4) 131

Answer

Correct answer: Option 2

Solution

Let the G.P. have first term a and common ratio r (r > 1 since increasing). Then aₙ = ar^(n-1). From a₃a₅ = 729: ar²·ar⁴ = a²r⁶ = 729, so ar³ = 27 (taking positive root). From a₂ + a₄ = 111/4: ar + ar³ = 111/4, so ar + 27 = 111/4, thus ar = 111/4 - 27 = 111/4 - 108/4 = 3/4. Now ar³ = 27 and ar = 3/4 gives r² = 27/(3/4) = 36, so r = 6. Then a = 3/4÷6 = 1/8. So a₁ = 1/8, a₂ = 3/4, a₃ = 9/2. Then a₁ + a₂ + a₃ = 1/8 + 3/4 + 9/2 = 1/8 + 6/8 + 36/8 = 43/8. Therefore 24(a₁ + a₂ + a₃) = 24·43/8 = 3·43 = 129.
