Let ABC be a triangle formed by the lines 7x - 6y + 3 = 0, x + 2y - 31 = 0 and 9x - 2y - 19 = 0. Let the point (h,k) be the image of the centroid of triangle ABC in the line 3x + 6y - 53 = 0. Then h^2 + k^2 + hk is equal to:

  1. (1) 37
  2. (2) 47
  3. (3) 40
  4. (4) 36

Answer

Correct answer: Option 1

Solution

Finding the vertices of triangle ABC: Vertex A (intersection of 7x - 6y + 3 = 0 and x + 2y - 31 = 0): From x + 2y = 31, x = 31 - 2y Substituting: 7(31 - 2y) - 6y + 3 = 0 217 - 14y - 6y + 3 = 0 220 = 20y y = 11, x = 9 So A(9, 11) Vertex B (intersection of 7x - 6y + 3 = 0 and 9x - 2y - 19 = 0): 7x - 6y + 3 = 0 ... (i) 9x - 2y - 19 = 0 ... (ii) From (ii): 2y = 9x - 19 6y = 27x - 57 Substituting in (i): 7x - (27x - 57) + 3 = 0 7x - 27x + 57 + 3 = 0 -20x = -60 x = 3, y = 4 So B(3, 4) Vertex C (intersection of x + 2y - 31 = 0 and 9x - 2y - 19 = 0): Adding: 10x - 50 = 0 x = 5 From x + 2y = 31: 5 + 2y = 31 2y = 26, y = 13 So C(5, 13) Centroid of triangle ABC: G = ((9 + 3 + 5)/3, (11 + 4 + 13)/3) = (17/3, 28/3) Finding the image of G(17/3, 28/3) in the line 3x + 6y - 53 = 0: Let (h, k) be the image of G in the line 3x + 6y - 53 = 0. The line perpendicular to 3x + 6y - 53 = 0 has slope 2 (negative reciprocal of -1/2). Line through G perpendicular to the mirror line: y - 28/3 = 2(x - 17/3) Finding intersection of perpendicular with mirror line: 3x + 6y - 53 = 0 Substituting y - 28/3 = 2(x - 17/3): y = 2x - 34/3 + 28/3 = 2x - 2 3x + 6(2x - 2) - 53 = 0 3x + 12x - 12 - 53 = 0 15x = 65 x = 13/3, y = 26/3 - 2 = 20/3 Midpoint of G and (h, k) is (13/3, 20/3): (17/3 + h)/2 = 13/3 → 17/3 + h = 26/3 → h = 3 (28/3 + k)/2 = 20/3 → 28/3 + k = 40/3 → k = 4 Solving we get h = 3, k = 4 Therefore: h^2 + k^2 + hk = 9 + 16 + 12 = 37
