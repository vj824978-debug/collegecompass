The equation of one of the straight lines which passes through the point (1,3) and makes an angle tan^(-1)(sqrt(2)) with the straight line y+1 = 3sqrt(2)x is:

  1. (1) 4sqrt(2)x - 5y - (5 + 4sqrt(2)) = 0
  2. (2) 5sqrt(2)x + 4y - (15 + 4sqrt(2)) = 0
  3. (3) 4sqrt(2)x + 5y - 4sqrt(2) = 0
  4. (4) 4sqrt(2)x + 5y - (15 + 4sqrt(2)) = 0

Answer

Correct answer: Option 4

Solution

Given line y + 1 = 3sqrt(2)x has slope m1 = 3sqrt(2). Line passes through (1,3). Using angle between two lines formula: tan(angle) = |m - m1|/(1 + m*m1) where angle = tan^(-1)(sqrt(2)), so sqrt(2) = |m - 3sqrt(2)|/(1 + 3sqrt(2)m). Solving for both positive and negative cases: For +ve case: m = -4sqrt(2)/5. For -ve case: m = 2sqrt(2)/7. Using point-slope form y - 3 = m(x - 1) with m = -4sqrt(2)/5 gives equation 4sqrt(2)x + 5y - (15 + 4sqrt(2)) = 0.
