Match the statements given in Column I with the intervals/union of intervals given in Column II (A) The set {Re(2iz/(1-z^2)) : z is a complex number, |z| = 1, z ≠ ±1} is (B) The domain of the function f(x) = sin^(-1)(8(3)^(x-2)/(1-3^(2(x-1)))) is (C) If f(θ) = |1 - tan(θ), tan(θ), 1|; |-tan(θ), 1, tan(θ)|; |-1, -tan(θ), 1|, then the set {f(θ) : 0 ≤ θ < π/2} is (D) If f(x) = x^(3/5)(3x - 10), x ≥ 0, then f(x) is increasing in (p) (-∞, -1) ∪ (1, ∞) (q) (-∞, 0) ∪ (0, ∞) (r) [2, ∞) (s) (-∞, -1] ∪ [1, ∞) (t) (-∞, 0] ∪ [2, ∞)

Matrix match · Marks: +4 / -1.0

  1. (A) (A) → (s) (B) → (t) (C) → (p) (D) → (q)
  2. (B) (A) → (p) (B) → (s) (C) → (r) (D) → (r)
  3. (C) (A) → (s) (B) → (r) (C) → (t) (D) → (r)
  4. (D) (A) → (s) (B) → (t) (C) → (r) (D) → (r)

Answer

Correct answer: D

Solution

Sol. (A). z = 2i(x + iy)/(1-(x+iy)²) = 2i(x+iy)/(1-(x²-y²+2ixy)) Using 1 - x² = y² Z = (2ix-2y)/(2y²-2ixy) = 1/y. ∵ -1 ≤ y ≤ 1 ⟹ -1/y ≤ -1 or -1/y ≥ 1. (B). For domain -1 ≤ (8·3^(x-2))/(1-3^(2(x-1))) ≤ 1 ⟹ -1 ≤ (3^x - 3^(x-2))/(1-3^(2x-2)) ≤ 1. Case -I: (3^x - 3^(x-2))/(1-3^(2x-2)) - 1 ≤ 0 ⟹ ((3^x-1)(3^(x-2)-1))/((3^(2x-2)-1)) ≥ 0 ⟹ x ∈ (-∞, 0] ∪ (1, ∞). Case -II: (3^x - 3^(x-2))/(1-3^(2x-2)) + 1 ≥ 0 ⟹ ((3^(x-2)-1)(3^x+1))/((3^x·3^(x-2)-1)) ≥ 0 ⟹ x ∈ (-∞, 1) ∪ [2, ∞) So, x ∈ (-∞, 0] ∪ [2, ∞). (C). R₁ → R₁ + R₃ f(θ) = |0 0 2; -tan θ 1 tan θ; -1 -tan θ 1| = 2(tan²θ + 1) = 2 sec²θ. (D). f'(x) = (3/2)(x)^(1/2)(3x-10) + (x)^(1/2)×3 = (15/2)(x)^(1/2)(x-2) Increasing, when x ≥ 2.
