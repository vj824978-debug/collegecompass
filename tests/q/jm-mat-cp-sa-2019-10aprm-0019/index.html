Let a, b and c be in G.P. with common ratio r, where a ≠ 0 and 0 < r ≤ 1/2. If 3a, 7b and 15c are the first three terms of an A.P., then the 4th term of this A.P. is:

  1. (1) a
  2. (2) (7/3)a
  3. (3) (2/3)a
  4. (4) 5a

Answer

Correct answer: Option 1

Solution

a = a b = ar c = ar^2 3a, 7b, 15c —> A.P. 14b = 3a + 15c 14(ar) = 3a + 15(ar^2) 15r^2 - 14r + 3 = 0 ⇒ r = 1/3, 3/5 (rejected) Common difference = 7b - 3a = 7ar - 3a = 7a(1/3) - 3a = 7a/3 - 3a = -2a/3 4th term is ⇒ 15c - 2a/3 = 15(ar^2) - 2a/3 = 15a(1/9) - 2a/3 = 15a/9 - 2a/3 = 5a/3 - 2a/3 = a
