For α, β, z ∈ C and λ > 1, if sqrt(λ - 1) is the radius of the circle |z - α|^2 + |z - β|^2 = 2λ, then |α - β| is equal to ________.

Answer

Correct answer: 2

Solution

Starting from |z - α|^2 + |z - β|^2 = 2λ, expand to get (z - α)(z̄ - ᾱ) + (z - β)(z̄ - β̄) = 2λ. Simplify to z̄z - z(ᾱ + β̄) - z̄(α + β) + αᾱ + ββ̄ = 2λ. Rewrite as |z - (α + β)/2|^2 = λ - (αᾱ + ββ̄)/2 + |α + β|^2/4. The radius is sqrt(λ - 1), so: |α + β|^2/4 - (αᾱ + ββ̄)/2 - λ = -(λ - 1). This gives |α + β|^2 - 2(αᾱ + ββ̄) = -4, which simplifies to |α - β|^2 = 4, therefore |α - β| = 2.
