Let the sum of the maximum and the minimum values of the function f(x) = (2x^2 - 3x + 8)/(2x^2 + 3x + 8) be m/n where gcd(m, n) = 1. Then m + n is equal to:

  1. (1) 182
  2. (2) 217
  3. (3) 195
  4. (4) 201

Answer

Correct answer: Option 4

Solution

Set y = (2x^2 - 3x + 8)/(2x^2 + 3x + 8). Rearrange to get x^2(2y - 2) + x(3y + 3) + 8y - 8 = 0. For real x, discriminant D ≥ 0: (3y + 3)^2 - 4(2y - 2)(8y - 8) ≥ 0. Simplify to get (11y - 5)(5y - 11) ≤ 0, which gives y ∈ [5/11, 11/5]. Note y = 1 is also included. Maximum value = 11/5, minimum value = 5/11. Sum = 11/5 + 5/11 = (121 + 25)/55 = 146/55. Since gcd(146, 55) = 1, m = 146 and n = 55. Therefore m + n = 201.
