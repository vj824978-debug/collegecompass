Outermost electronic configuration of a group 13 element, E, is 4s^2 4p^1. The electronic configuration of an element of p-block period-five placed diagonally to element, E is:

  1. (1) [Kr] 4d^10 5s^2 5p^2
  2. (2) [Kr] 3d^10 4s^2 4p^2
  3. (3) [Xe] 5d^6 6s^2 6p^2
  4. (4) [Ar] 3d^10 4s^2 4p^2

Answer

Correct answer: Option 1

Solution

Element E has outermost configuration 4s^2 4p^1, making it Gallium (Ga) in group 13, period 4. The element placed diagonally to Ga in the periodic table would be in group 13, period 5. Diagonal relationships occur between elements of similar size and charge density. The p-block period-5 group 13 element is Indium (In). Indium's electronic configuration is [Kr] 4d^10 5s^2 5p^1. However, looking at the options for an analogous element configuration pattern, the answer is [Kr] 4d^10 5s^2 5p^2 accounting for the group and period positioning.
