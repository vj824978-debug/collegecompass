If the mean and variance of the following data: 6, 10, 7, 13, a, 12, b, 12 are 9 and 37/4 respectively, then (a - b)^2 is equal to:

  1. (1) 32
  2. (2) 24
  3. (3) 12
  4. (4) 16

Answer

Correct answer: Option 4

Solution

Mean = (6 + 10 + 7 + 13 + a + 12 + b + 12)/8 = 9, so 60 + a + b = 72, thus a + b = 12. Variance = (Σx^2)/n - (Σx/n)^2 = 37/4. Calculate Σx^2 = 36 + 100 + 49 + 169 + a^2 + 144 + b^2 + 144 = a^2 + b^2 + 642. Then (a^2 + b^2 + 642)/8 - 81 = 37/4. Solving: a^2 + b^2 = 80. Since (a + b)^2 = 144, we have a^2 + 2ab + b^2 = 144, so 80 + 2ab = 144, thus ab = 32. Therefore (a - b)^2 = (a + b)^2 - 4ab = 144 - 128 = 16.
