If sin^(-1)(alpha/17) + cos^(-1)(4/5) + tan^(-1)(77/36) = 0, 0 < alpha < 13, then sin^(-1)(sin(alpha)) + cos^(-1)(cos(alpha)) is equal to:

  1. (1) pi
  2. (2) 16 - 5*pi
  3. (3) 16
  4. (4) 0

Answer

Correct answer: Option 1

Solution

sin^(-1)(alpha/17) = -cos^(-1)(4/5) + tan^(-1)(77/36) Let cos^(-1)(4/5) = p and tan^(-1)(77/36) = q => sin(sin^(-1)(alpha/17)) = sin(q - p) = sin(q)*cos(p) - cos(q)*sin(p) => alpha/17 = (77/85)*(4/5) - (36/85)*(3/5) sin^(-1)(sin(8)) + cos^(-1)(cos(8)) => -8 + 3*pi + 8 - 2*pi = pi
