If for a > 0, the feet of perpendiculars from the points A(a, -2a, 3) and B(0, 4, 5) on the plane lx + my + nz = 0 are points C(0, -a, -1) and D respectively, then the length of line segment CD is equal to:

  1. (1) sqrt(41)
  2. (2) sqrt(31)
  3. (3) sqrt(66)
  4. (4) sqrt(55)

Answer

Correct answer: Option 3

Solution

AC is collinear with l, m, n. Using direction ratios: l/a = m/(-a) = n/4 = λ. Since (0, -a, -1) lies on lx + my + nz = 0, we get a = -n/m = -4λ/(-aλ), so a^2 = 4, thus a = 2 (since a > 0). Direction ratios of BD are 2, -2, 4. Equation of line BD: (x-0)/2 = (y-4)/(-2) = (z-5)/4 = t. Any point on BD is (2t, 4-2t, 5+4t). For this point to lie on plane 2x - 2y + 4z = 0: 4t - 2(4-2t) + 4(5+4t) = 0, which gives 4r - 2(4-2r) + 4(5+4r) = 0, so r = -1/2. Therefore D(-1, 5, 3) and C(0, -2, -1). CD = sqrt((0-(-1))^2 + (-2-5)^2 + (-1-3)^2) = sqrt(1 + 49 + 16) = sqrt(66)
