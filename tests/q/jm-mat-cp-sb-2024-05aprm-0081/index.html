From a lot of 10 items, which include 3 defective items, a sample of 5 items is drawn at random. Let the random variable X denote the number of defective items in the sample. If the variance of X is σ², then 96σ² is equal to ___.

Answer

Correct answer: 56

Solution

X follows a hypergeometric distribution. From the probability distribution table: P(X=0)=7/15, P(X=1)=5/12, P(X=2)=5/12, P(X=3)=1/12. Calculate mean: μ = Σ p_i x_i = 18/12. Calculate E(X²): Σ p_i x_i² = 34/12. Variance: σ² = E(X²) - (E(X))² = 34/12 - (18/12)² = 34/12 - 324/144 = 408/144 - 324/144 = 84/144 = 7/12. Therefore, 96σ² = 96 × (7/12) = 56.
