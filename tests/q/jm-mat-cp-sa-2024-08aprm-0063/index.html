Let the circles C1: (x - α)² + (y - β)² = r1² and C2: (x - 8)² + (y - 15/2)² = r2² touch each other externally at the point (6, 6). If the point (6, 6) divides the line segment joining the centres of the circles C1 and C2 internally in the ratio 2:1, then (α + β) + 4(r1² + r2²) equals

  1. (1) 110
  2. (2) 130
  3. (3) 125
  4. (4) 145

Answer

Correct answer: Option 2

Solution

Given that (6,6) divides the line segment joining centers (α,β) and (8, 15/2) in ratio 2:1. Using section formula: (16+α)/3 = 6 and (15+β)/3 = 6, which gives (α,β) = (2,3). Since circles touch externally at (6,6), the distance C1C2 = r1 + r2. Distance = sqrt((2-8)² + (3-15/2)²) = sqrt(36 + 81/4) = 2r2 + r2. This gives r2 = 5/2 and r1 = 2r2 = 5. Therefore (α+β) + 4(r1² + r2²) = 5 + 4(25 + 25/4) = 5 + 4(125/4) = 5 + 125 = 130
