Consider a region R = {(x, y) in R^2 : x^2 <= y <= 2x}. If a line y = alpha divides the area of region R into two equal parts, then which of the following is true ?

  1. (1) alpha^3 - 6alpha^2 + 16 = 0
  2. (2) 3alpha^2 - 8alpha + 8 = 0
  3. (3) alpha^3 - 6alpha^(3/2) - 16 = 0
  4. (4) 3alpha^2 - 8alpha^(3/2) + 8 = 0

Answer

Correct answer: Option 4

Solution

The region R is bounded by y = x^2 (parabola) and y = 2x (line). First, find the intersection points: x^2 = 2x => x(x - 2) = 0 => x = 0 or x = 2 At x = 2: y = 4, so intersection point B is (2, 4) Total area of region R: Area = integral from 0 to 2 of (2x - x^2) dx = [x^2 - x^3/3] from 0 to 2 = 4 - 8/3 = 4/3 For the line y = alpha to divide the region into two equal parts: Area below y = alpha = (1/2) * (4/3) = 2/3 The line y = alpha intersects: - y = x^2 at x = sqrt(alpha) - y = 2x at x = alpha/2 Area of region OABC (where A is on y = x^2 and C is on y = 2x at height alpha): Area = integral from 0 to alpha of (sqrt(y) - y/2) dy = 2/3 [2/3 * y^(3/2) - 1/4 * y^2] from 0 to alpha = 2/3 4/3 = 2[2/3 * alpha^(3/2) - 1/4 * alpha^2] 4/3 = 4/3 * alpha^(3/2) - 1/2 * alpha^2 Multiplying by 3: 4 = 4alpha^(3/2) - 3/2 * alpha^2 Multiplying by 2: 8 = 8alpha^(3/2) - 3alpha^2 3alpha^2 - 8alpha^(3/2) + 8 = 0
