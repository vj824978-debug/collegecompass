Let integers a, b ∈ [-3, 3] be such that a + b ≠ 0. Then the number of all possible ordered pairs (a, b), for which |z - a|/(z + b) = 1 and |z + 1, ω, ω^2; ω, z + ω^2, 1; ω^2, 1, z + ω| = 1, z ∈ C, where ω and ω^2 are the roots of x^2 + x + 1 = 0, is equal to

Answer

Correct answer: 10

Solution

a, b ∈ I, -3 ≤ a, b ≤ 3, a + b ≠ 0 From |z - a| = |z + b|, the locus of z lies on the perpendicular bisector of the line segment joining -b and a, so z = (a - b)/2 is on the real axis when z is real, or more generally |z - a| = |z + b|. For the determinant condition: |z + 1, ω, ω^2; ω, z + ω^2, 1; ω^2, 1, z + ω| = 1 Using row operations, subtract the first row from others: |z, z, z; ω, z + ω^2 - ω, 1 - ω^2; ω^2, 1 - ω, z + ω - ω^2| = 1 ⟹ z|1, 1, 1; ω, z + ω^2 - ω, 1 - ω^2; ω^2, 1 - ω, z + ω - ω^2| = 1 Applying column operations: |1, 0, 0; ω, z + ω^2 - ω - 1 + ω, 1 - ω^2 - 1; ω^2, 1 - ω^2, z + ω - ω^2 - ω| = 1 ⟹ z|1, 0, 0; ω, z + ω^2 - ω, 1 - ω^2; ω^2, 1 - ω^2, z + ω - ω^2| = 1 Expanding and simplifying (using ω^2 + ω + 1 = 0, so ω^2 + ω = -1, ω^3 = 1): ⟹ z^3 = 1 ⟹ z = ω, ω^2, 1 Now from |1 - a| = |1 + b|: For z = 1: |1 - a| = |1 + b| Possible pairs (a, b) where -3 ≤ a, b ≤ 3, a + b ≠ 0, and |1 - a| = |1 + b|: If 1 - a = 1 + b: a + b = 0 (excluded) If 1 - a = -(1 + b): 1 - a = -1 - b ⟹ a - b = 2 Pairs with a - b = 2: (-3, -5) ✗, (-2, -4) ✗, (-1, -3) ✓, (0, -2) ✓, (1, -1) ✓, (2, 0) ✓, (3, 1) ✓ Pairs with a - b = -2 (from |1 - a| = |1 + b| alternative): (-3, -1) ✓, (-2, 0) ✓, (-1, 1) ✓, (0, 2) ✓, (1, 3) ✓, (2, 4) ✗, (3, 5) ✗ Total: 5 + 5 = 10 pairs
