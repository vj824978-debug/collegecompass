Among the statements: (S1): 2023^2022 - 1999^2022 is divisible by 8. (S2): 13(13)^n - 11n - 13 is divisible by 144 for infinitely many n ∈ N

  1. (1) Only (S2) is correct
  2. (2) Only (S1) is correct
  3. (3) Both (S1) and (S2) are correct
  4. (4) Both (S1) and (S2) are incorrect

Answer

Correct answer: Option 2

Solution

(S1): Using (x - y) divides (x^n - y^n) for all n ∈ N. Since (2023 - 1999) = 24 divides (2023^2022 - 1999^2022), and 24 divides 2023^2022 - 1999^2022, therefore 8 will divide 2023^2022 - 1999^2022. So (S1) is correct. (S2): 13(13)^n - 11n - 13 = 13((1+12)^n - 1) - 11n using binomial expansion equals 12 × 13n - 11n + 12λ = 145n + 144λ, which is not divisible by 144. So (S2) is incorrect.
