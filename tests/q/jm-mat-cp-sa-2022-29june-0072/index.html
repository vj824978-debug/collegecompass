Let (x-2)/3 = (y+1)/(-2) = (z+3)/(-1) lie on the plane px - qy + z = 5, for some p,q ∈ R. The shortest distance of the plane from the origin is:

  1. (1) sqrt(3/100)
  2. (2) sqrt(5/142)
  3. (3) 5/sqrt(71)
  4. (4) 1/sqrt(142)

Answer

Correct answer: Option 2

Solution

Let (x-2)/3 = (y+1)/(-2) = (z+3)/(-1) = λ. Then point on line is (3λ+2, -2λ-1, -λ-3). This lies on plane px - qy + z = 5, so p(3λ+2) - q(-2λ-1) + (-λ-3) = 5. Expanding: λ(3p + 2q - 1) + (2p + q - 8) = 0. For all λ: 3p + 2q - 1 = 0 and 2p + q - 8 = 0. Solving: p = 15, q = -22. Plane equation: 15x - 22y + z - 5 = 0. Distance from origin = |0 - 0 + 0 - 5|/sqrt(15² + 22² + 1) = 5/sqrt(225 + 484 + 1) = 5/sqrt(710) = sqrt(5/142).
