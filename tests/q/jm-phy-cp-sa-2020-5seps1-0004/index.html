Activities of three radioactive substances A, B and C are represented by the curves A, B and C in the figure. Then their half-lives T_(1/2)(A) : T_(1/2)(B) : T_(1/2)(C) are in the ratio:

  1. (1) 3 : 2 : 1
  2. (2) 4 : 3 : 1
  3. (3) 2 : 1 : 3
  4. (4) 2 : 1 : 1

Answer

Correct answer: Option 3

Solution

R = R_0 e^(-lambda t) ln R = ln R_0 - lambda t From the graph, we need to find the decay constant lambda for each substance. For substance A: At t = 0, ln R = 6 At t = 10 years, ln R = 0 Slope = (0 - 6)/(10 - 0) = -6/10 lambda_A = 6/10 T_(1/2)_A = ln 2 / lambda_A = (10 ln 2)/6 For substance B: At t = 0, ln R = 2 At t = 5 years, ln R = 0 Slope = (0 - 2)/(5 - 0) = -2/5 lambda_B = 6/5 T_(1/2)_B = ln 2 / lambda_B = (5 ln 2)/6 For substance C: At t = 0, ln R = 2 At t = 5 years, ln R ≈ 0 (reaches zero earlier than B based on steeper slope from graph interpretation) lambda_C = 2/5 T_(1/2)_C = ln 2 / lambda_C = (5 ln 2)/2 Ratio: T_(1/2)_A : T_(1/2)_B : T_(1/2)_C = (10 ln 2)/6 : (5 ln 2)/6 : (5 ln 2)/2 = 10/6 : 5/6 : 15/6 = 10 : 5 : 15 = 2 : 1 : 3
