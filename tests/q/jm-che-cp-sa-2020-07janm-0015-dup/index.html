Let the tangents drawn from the origin to the circle, x^2 + y^2 - 8x - 4y + 16 = 0 touch it at the points A and B. The (AB)^2 is equal to:

  1. (1) 56/5
  2. (2) 64/5
  3. (3) 32/5
  4. (4) 52/5

Answer

Correct answer: Option 2

Solution

First, rewrite the circle equation in standard form: x^2 + y^2 - 8x - 4y + 16 = 0 (x^2 - 8x) + (y^2 - 4y) + 16 = 0 (x^2 - 8x + 16) + (y^2 - 4y + 4) + 16 - 16 - 4 = 0 (x - 4)^2 + (y - 2)^2 = 4 Center C = (4, 2) and Radius R = 2 Distance from origin O(0,0) to center C(4,2): OC = sqrt(4^2 + 2^2) = sqrt(16 + 4) = sqrt(20) = 2sqrt(5) Let L denote the length of tangent from O to the circle: L = sqrt(OC^2 - R^2) = sqrt(20 - 4) = sqrt(16) = 4 Since OA and OB are tangents from O to the circle: - OA = OB = 4 - CA ⊥ OA and CB ⊥ OB (radius perpendicular to tangent) - CA = CB = 2 - In right triangle OAC: OA^2 + CA^2 = OC^2 ✓ (16 + 4 = 20) For finding AB, use the formula: Length of AB = (2RL)/sqrt(L^2 + R^2) where L = distance of center from origin along the chord AB direction. Alternatively, in quadrilateral OACB: - ∠OAC = ∠OBC = 90° - OA = OB = 4, CA = CB = 2, OC = 2sqrt(5) Using the formula for chord length when two tangents are drawn: AB = (2 × R × L)/sqrt(L^2 + R^2) = (2 × 2 × 4)/sqrt(16 + 4) = 16/sqrt(20) = 16/(2sqrt(5)) = 8/sqrt(5) Wait, using correct approach: In triangle OAC: OA = 4, AC = 2, OC = 2sqrt(5) Angle ∠AOC = cos^(-1)(OA/OC) = cos^(-1)(4/(2sqrt(5))) = cos^(-1)(2/sqrt(5)) Similarly ∠BOC = cos^(-1)(2/sqrt(5)) Using the formula: AB^2 = 2R^2(1 - cos(∠ACB)) where ∠ACB = 2π - 2∠OAC - 2∠OCA Simpler approach using formula: AB^2 = (2RL)^2/(L^2 + R^2) where L is length of tangent AB^2 = (2 × 2 × 4)^2/(16 + 4) = (16)^2/20 = 256/20 = 64/5
