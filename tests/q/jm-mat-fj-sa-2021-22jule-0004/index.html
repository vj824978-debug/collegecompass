If ∫[0 to 100π] (sin²x / (x·[x])) dx = (1 + 4π²)/(α), α ∈ ℝ, where [x] is the greatest integer less than or equal to x, then the value of α is:

  1. (1) 100(1 - e)
  2. (2) 150(e^(-1) - 1)
  3. (3) 200(1 - e^(-1))
  4. (4) 50(e - 1)

Answer

Correct answer: Option 3

Solution

The function f(x) = sin²x / e^([x]) is periodic with period π. The integral is split over intervals where [x] is constant. For each interval [nπ, (n+1)π], the integral equals (1/e^n)∫[0 to π] sin²x dx = π/(2e^n). The sum over n = 0 to 99 gives π/2 · Σ(1/e^n) = π/2 · (1 - (1/e)^100)/(1 - 1/e) = π/2 · e(1 - 1/e^100)/(e - 1). After simplification and comparison with (1 + 4π²)/α, we get α = 200(1 - e^(-1)).
