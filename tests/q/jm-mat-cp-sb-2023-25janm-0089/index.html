Let A1, A2, A3 be three A.P. with the same common difference d and having their first terms as A, A + 1, A + 2, respectively. Let a, b, c be the 7th, 9th, 17th terms of A1, A2, A3, respectively such that |a 7 1; 2b 17 1; c 17 1| + 70 = 0. If a = 29, then the sum of first 20 terms of an A.P. whose first term is c - a - b and common difference is d/12, is equal to _____.

Answer

Correct answer: 495

Solution

a = A + 6d b = A + 8d + 1 c = A + 16d + 2 From the determinant condition: |A + 6d 7 1; 2A + 16d + 2 17 1; A + 16d + 2 17 1| = -70 Applying row operations R1 → R3 - R2, R2 → R2 - R1: |A + 6d 7 1; A + 10d + 2 10 0; -A 0 0| = -70 Expanding the determinant: A(10 × 1 - 0 × 0) - 0 + 0 = -70 A(10) = -70 A = -7 Given a = 29: a = A + 6d = 29 -7 + 6d = 29 6d = 36 d = 6 Finding b and c: b = A + 8d + 1 = -7 + 48 + 1 = 42 c = A + 16d + 2 = -7 + 96 + 2 = 91 First term of required A.P.: c - a - b = 91 - 29 - 42 = 20 Common difference of required A.P.: d/12 = 6/12 = 1/2 Sum of first 20 terms: S20 = (20/2)[2(20) + 19 × (1/2)] S20 = 10[40 + 19/2] S20 = 10[80/2 + 19/2] S20 = 10[99/2] S20 = 495
