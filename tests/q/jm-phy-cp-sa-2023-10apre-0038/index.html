A person travels x distance with velocity v1 and then x distance with velocity v2 in the same direction. The average velocity of the person is v, then the relation between v, v1 and v2 will be -

  1. (1) v = (v1 + v2)/2
  2. (2) 1/v = 1/v1 + 1/v2
  3. (3) v = v1 + v2
  4. (4) 2/v = 1/v1 + 1/v2

Answer

Correct answer: Option 4

Solution

Average velocity = Total distance / Total time. Total distance = x + x = 2x. Time for first part = x/v1, Time for second part = x/v2. Total time = x/v1 + x/v2 = x(v1 + v2)/(v1*v2). Therefore, v_avg = 2x / [x(v1 + v2)/(v1*v2)] = 2v1*v2/(v1 + v2). This can be rewritten as 2/v = 1/v1 + 1/v2, which is option (4).
