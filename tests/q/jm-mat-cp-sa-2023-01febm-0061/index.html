If the orthocenter of the triangle, whose vertices are (1, 2), (2, 3) and (3, 1) is (alpha, beta), then the quadratic equation whose roots are alpha + 4*beta and 4*alpha + beta, is

  1. (1) x^2 - 20x + 99 = 0
  2. (2) x^2 - 19x + 90 = 0
  3. (3) x^2 - 22x + 120 = 0
  4. (4) x^2 - 18x + 99 = 0

Answer

Correct answer: Option 1

Solution

Given vertices: A(1, 2), B(2, 3), C(3, 1) Slope of BC = (1 - 3)/(3 - 2) = -2/1 = -2 Slope of AB = (3 - 2)/(2 - 1) = 1/1 = 1 Altitude of BC is perpendicular to BC: Slope of altitude from A = -1/(-2) = 1/2 Equation of altitude from A through (1, 2): y - 2 = (1/2)(x - 1) => x - 2y + 3 = 0 Altitude of AB is perpendicular to AB: Slope of altitude from C = -1/1 = -1 Equation of altitude from C through (3, 1): y - 1 = (-1)(x - 3) => x + y = 4 To find orthocenter, solve: x - 2y + 3 = 0 ... (1) x + y = 4 ... (2) From (2): x = 4 - y Substitute in (1): (4 - y) - 2y + 3 = 0 7 - 3y = 0 y = 7/3 Then x = 4 - 7/3 = 12/3 - 7/3 = 5/3 Orthocenter = (5/3, 7/3) Therefore alpha = 5/3, beta = 7/3 alpha + 4*beta = 5/3 + 4(7/3) = 5/3 + 28/3 = 33/3 = 11 4*alpha + beta = 4(5/3) + 7/3 = 20/3 + 7/3 = 27/3 = 9 The quadratic equation with roots 11 and 9 is: (x - 11)(x - 9) = 0 x^2 - 9x - 11x + 99 = 0 x^2 - 20x + 99 = 0
