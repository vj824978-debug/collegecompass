The number of real roots of the equation e^(4x) + e^(3x) - 4e^(2x) + e^x + 1 = 0 is

  1. (1) 4
  2. (2) 1
  3. (3) 3
  4. (4) 2

Answer

Correct answer: Option 2

Solution

Let e^x = t where t ∈ (0, ∞) Given equation: e^(4x) + e^(3x) - 4e^(2x) + e^x + 1 = 0 Becomes: t^4 + t^3 - 4t^2 + t + 1 = 0 Dividing by t^2: t^2 + t - 4 + 1/t + 1/t^2 = 0 Rearranging: (t^2 + 1/t^2) + (t + 1/t) - 4 = 0 Let t + 1/t = z Then t^2 + 1/t^2 = (t + 1/t)^2 - 2 = z^2 - 2 Substituting: (z^2 - 2) + z - 4 = 0 z^2 + z - 6 = 0 Factoring: (z + 3)(z - 2) = 0 z = -3 or z = 2 For z = -3: t + 1/t = -3 t^2 + 3t + 1 = 0 Discriminant = 9 - 4 = 5 > 0 Roots are t = (-3 ± sqrt(5))/2 Both roots are negative (since -3 - sqrt(5) < 0 and -3 + sqrt(5) < 0) Since t = e^x > 0, these roots are rejected. For z = 2: t + 1/t = 2 e^x + e^(-x) = 2 This occurs when e^x = 1, which gives x = 0 as the only solution. Therefore, the number of real roots is 1. Note: The answer key shows [2], but based on the solution work shown, x = 0 is the only solution, giving 1 real root. There appears to be a discrepancy between the stated answer and the work shown.
