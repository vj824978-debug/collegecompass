The mean and variance of 7 observations are 8 and 16, respectively. If five observations are 2, 4, 10, 12, 14, then the absolute difference of the remaining two observations is:

  1. (1) 2
  2. (2) 4
  3. (3) 3
  4. (4) 1

Answer

Correct answer: Option 1

Solution

Given: n = 7, mean = 8, variance = 16 Five observations are: 2, 4, 10, 12, 14 Let the remaining two observations be x and y. From mean: xbar = (2 + 4 + 10 + 12 + 14 + x + y)/7 = 8 42 + x + y = 56 x + y = 14 ......(i) From variance formula: (sigma)^2 = sum(x_i)^2/n - (sum(x_i)/n)^2 16 = (4 + 16 + 100 + 144 + 196 + x^2 + y^2)/7 - 8^2 16 = (460 + x^2 + y^2)/7 - 64 16 + 64 = (460 + x^2 + y^2)/7 80 = (460 + x^2 + y^2)/7 560 = 460 + x^2 + y^2 x^2 + y^2 = 100 ......(ii) From (i): x + y = 14 Squaring: (x + y)^2 = 196 x^2 + 2xy + y^2 = 196 100 + 2xy = 196 2xy = 96 xy = 48 Now, (x - y)^2 = (x + y)^2 - 4xy = 196 - 192 = 4 |x - y| = 2 Clearly by (i) and (ii), |x - y| = 2 Ans. 1
