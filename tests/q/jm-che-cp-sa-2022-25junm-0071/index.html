Let A = [0 -2; 2 0]. If M and N are two matrices given by M = sum(k=1 to 10) A^(2k) and N = sum(k=1 to 10) A^(2k-1), then MN^2 is:

  1. (1) a non-identity symmetric matrix
  2. (2) a skew-symmetric matrix
  3. (3) neither symmetric nor skew-symmetric matrix
  4. (4) an identity matrix

Answer

Correct answer: Option 1

Solution

First compute A^2 = [-4 0; 0 -4] = -4I. Then M = A^2 + A^4 + A^6 + ... + A^20 = -4I + 16I - 64I + ... (10 terms) = -I[4 - 16 + 64 - ... up to 10 terms] = -I * 4((-4)^10 - 1)/(-4-1) = (4/5)(2^20 - 1)I. N = A + A^3 + A^5 + ... + A^19 = A(1 - 4 + 16 - ... up to 10 terms) = A(((-4)^10 - 1)/(-4-1)) = ((2^10 - 1)/5)A. N^2 = ((2^10 - 1)^2/25)A^2 = (-4/25)(2^20 - 1)I. MN^2 = (4/5)(2^20 - 1)I * (-4/25)(2^20 - 1)I = (-16/125)(2^20 - 1)^3 I = KI where K ≠ ±1. This is a non-identity symmetric matrix.
