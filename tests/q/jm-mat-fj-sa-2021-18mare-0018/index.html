The area bounded by the curve 4y^2 = x^2(4-x)(x-2) is equal to:

  1. (1) pi/16
  2. (2) pi/8
  3. (3) 3pi/2
  4. (4) 3pi/8

Answer

Correct answer: Option 3

Solution

From 4y^2 = x^2(4-x)(x-2) >= 0, we get x in [2,4]. The curve is y = ±(1/2)x*sqrt((4-x)(x-2)). The area A = (1/2)∫[2 to 4] x*sqrt((4-x)(x-2))dx. Simplifying: A = (1/2)∫[2 to 4] x*sqrt(6x-x^2-8)dx = (1/2)∫[2 to 4] (x-3+3)*sqrt(1-(x-3)^2)dx. Splitting into two parts: (1/2)∫(x-3)*sqrt(1-(x-3)^2)dx + (3/2)∫sqrt(1-(x-3)^2)dx. Using substitution x-3 = sin(θ), the integrals evaluate to: 0 + (3/2)∫cos^2(θ)dθ = (3/2)[θ + sin(2θ)/2] from 0 to pi/2 = 3pi/4. Total area = 2A = 3pi/2.
