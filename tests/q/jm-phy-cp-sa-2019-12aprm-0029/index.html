Three particles of masses 50 g, 100 g and 150 g are placed at the vertices of an equilateral triangle of side 1 m (as shown in the figure). The (x, y) coordinates of the centre of mass will be :

  1. (1) (sqrt(3)/8 m, 7/12 m)
  2. (2) (sqrt(3)/4 m, 5/12 m)
  3. (3) (7/12 m, sqrt(3)/8 m)
  4. (4) (7/12 m, sqrt(3)/4 m)

Answer

Correct answer: Option 4

Solution

m1 = 50 g, m2 = 100 g, m3 = 150 g From the figure: x1 = 0, y1 = 0 x2 = 1 m, y2 = 0 x3 = 0.5 m, y3 = sqrt(3)/2 Using centre of mass formula: x_COM = (m1*x1 + m2*x2 + m3*x3)/(m1 + m2 + m3) = (0 + (100)(1) + (150)(0.5))/300 = (100 + 75)/300 = 175/300 = 7/12 m y_COM = (m1*y1 + m2*y2 + m3*y3)/(m1 + m2 + m3) = (0 + (100)(0) + (150)(sqrt(3)/2))/300 = (75*sqrt(3))/300 = 75*sqrt(3)/300 = 3*sqrt(3)/12 = sqrt(3)/4 m Therefore, (x_COM, y_COM) = (7/12, sqrt(3)/4)
