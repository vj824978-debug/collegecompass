If three distinct numbers a, b, c are in G.P. and the equations ax^2 + 2bx + c = 0 and dx^2 + 2ex + f = 0 have a common root, then which one of the following statements is correct?

  1. (1) d, e, f are in A.P.
  2. (2) d/a, e/b, f/c are in A.P.
  3. (3) d, e, f are in G.P.
  4. (4) d/a, e/b, f/c are in G.P.

Answer

Correct answer: Option 2

Solution

ax^2 + 2bx + c = 0 (b^2 = ac) dx^2 + 2ex + f = 0 (af - cd)^2 = (2ae - 2bd)(2bf - 2ec) a^2f^2 + c^2d^2 - 2a + cd = 4aebf - 4ae^2c - 4b^2df + 4bdec a^2f^2 + c^2d^2 + 4b^2e^2 + 2afcd - 4aebf - 4bdec = 0 (af + cd - 2be)^2 = 0 af + cd = 2be af/b^2 + cd/b^2 = 2be/b^2 af/(ac) + cd/(ac) = 2(e/b) f/c + d/a = 2(e/b) d/a, e/b, f/c are in A.P.
