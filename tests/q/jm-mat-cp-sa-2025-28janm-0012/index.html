If the image of the point (4, 4, 3) in the line (x-1)/2 = (y-2)/1 = (z-1)/3 is (alpha, beta, gamma), then alpha + beta + gamma is equal to

  1. (1) 9
  2. (2) 12
  3. (3) 8
  4. (4) 7

Answer

Correct answer: Option 1

Solution

The line is given by (x-1)/2 = (y-2)/1 = (z-1)/3. Direction vector of line: vector d = (2i + j + 3k) A general point on the line Q can be written as: Q(2lambda + 1, lambda + 2, 3lambda + 1) Vector PQ = Q - P = (2lambda + 1 - 4, lambda + 2 - 4, 3lambda + 1 - 3) = (2lambda - 3, lambda - 2, 3lambda - 2) For the image point, PQ must be perpendicular to the direction vector of the line. So, vector PQ · vector d = 0 2(2lambda - 3) + 1(lambda - 2) + 3(3lambda - 2) = 0 4lambda - 6 + lambda - 2 + 9lambda - 6 = 0 14lambda - 14 = 0 lambda = 1 So, Q(2(1) + 1, 1 + 2, 3(1) + 1) = Q(3, 3, 4) The image R(alpha, beta, gamma) is the reflection of P(4, 4, 3) about point Q(3, 3, 4). Using midpoint formula: (alpha + 4)/2 = 3 => alpha + 4 = 6 => alpha = 2 (beta + 4)/2 = 3 => beta + 4 = 6 => beta = 2 (gamma + 3)/2 = 4 => gamma + 3 = 8 => gamma = 5 (alpha, beta, gamma) = (2, 2, 5) alpha + beta + gamma = 2 + 2 + 5 = 9
