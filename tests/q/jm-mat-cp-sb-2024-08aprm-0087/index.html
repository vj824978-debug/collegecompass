Let α = Σ(r=0 to n) (4r² + 2r + 1)^n C_r and β = (Σ(r=0 to n) ^n C_r/(r+1)) + 1/(n+1). If 140 < 2α/β < 281, then the value of n is ___.

Answer

Correct answer: 5

Solution

First, α = Σ(4r² + 2r + 1)^n C_r is simplified using binomial identities. After algebraic manipulation: α = 2n(n+1)². Next, β = Σ^n C_r/(r+1) + 1/(n+1) = 2^(n+1)/(n+1). Then 2α/β = 2n(n+1)²/2^(n+1) · (n+1) = n(n+1)³/2^n. The constraint 140 < (n+1)³ < 281 is checked: For n=4: (5)³ = 125 < 140. For n=5: (6)³ = 216 satisfies 140 < 216 < 281. For n=6: (7)³ = 343 > 281. Therefore n = 5.
