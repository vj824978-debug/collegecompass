Let f(x) = x^2 + 9, g(x) = x/(x-9) and a = fog(10), b = gof(3). If e and ℓ denote the eccentricity and the length of the latus rectum of the ellipse x^2/a + y^2/b = 1, then 8e^2 + ℓ^2 is equal to

  1. (1) 16
  2. (2) 8
  3. (3) 6
  4. (4) 12

Answer

Correct answer: Option 2

Solution

Calculate a = f(g(10)) = f(10/(10-9)) = f(10) = 100 + 9 = 109. Calculate b = g(f(3)) = g(9+9) = g(18) = 18/(18-9) = 18/9 = 2. Ellipse equation: x^2/109 + y^2/2 = 1. Here a=109, b=2. Calculate e^2 = 1 - b/a = 1 - 2/109 = 107/109. Calculate ℓ = 2b/√a = 2(2)/√109 = 4/√109, so ℓ^2 = 16/109. Therefore 8e^2 + ℓ^2 = 8(107/109) + 16/109 = (856 + 16)/109 = 872/109 = 8.
