For the reaction 2Fe^3+(aq) + 2I^-(aq) → 2Fe^2+(aq) + I2(s). The magnitude of the standard molar free energy change, ΔrG°m = __________ kJ (Round off to the nearest integer).

Answer

Correct answer: 45

Solution

Given: E°(Fe^3+/Fe^2+) = -0.440 V, E°(Fe^3+/Fe(s)) = -0.036 V, E°(I2/I-) = 0.539 V, F = 96500 C. The cell potential is calculated as E°cell = E°cathode - E°anode = 0.772 V. Using ΔG° = -nE°cell·F where n = 2 electrons: ΔG° = -2 × 96.5 × 0.233 = -45 kJ (approximately). The magnitude is 45 kJ.
