An object of mass 'm' is projected from origin in a vertical xy plane at an angle 45° with the x-axis with an initial velocity v₀. The magnitude and direction of the angular momentum of the object with respect to origin, when it reaches at the maximum height, will be [g is acceleration due to gravity]

  1. (1) mv₀³/(2√(2g)) along negative z-axis
  2. (2) mv₀³/(2√(2g)) along positive z-axis
  3. (3) mv₀³/(4√(2g)) along positive z-axis
  4. (4) mv₀³/(4√(2g)) along negative z-axis

Answer

Correct answer: Option 4

Solution

At maximum height H, the vertical component of velocity becomes zero, and only horizontal component remains. Initial velocity components: vₓ = v₀ cos(45°) = v₀/√2 vᵧ = v₀ sin(45°) = v₀/√2 At maximum height: vₓ = v₀/√2 (remains constant) vᵧ = 0 Maximum height: H = (vᵧ)²/(2g) = (v₀/√2)²/(2g) = v₀²/(4g) Position at maximum height: x = vₓ × t, where t is time to reach maximum height t = vᵧ/g = (v₀/√2)/g x = (v₀/√2) × (v₀/√2)/g = v₀²/(2g) Position vector: vector r = (v₀²/(2g)) î + (v₀²/(4g)) ĵ Velocity vector at maximum height: vector v = (v₀/√2) î + 0 ĵ Angular momentum: vector L = vector r × m(vector v) vector L = m[(v₀²/(2g)) î + (v₀²/(4g)) ĵ] × (v₀/√2) î vector L = m × (v₀²/(4g)) ĵ × (v₀/√2) î vector L = m × (v₀³)/(4g√2) × (ĵ × î) vector L = -m × (v₀³)/(4g√2) k̂ vector L = -(mv₀³)/(4√(2g)) k̂ Magnitude: L = mv₀³/(4√(2g)) Direction: Along negative z-axis
