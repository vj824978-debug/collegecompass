Electrolysis of 600 mL aqueous solution of NaCl for 5 min changes the pH of the solution to 12. The current in Amperes used for the given electrolysis is ____. (Nearest integer).

Answer

Correct answer: 2

Solution

Electrolysis of NaCl: NaCl + H2O (aq) → NaOH (aq) + (1/2)Cl2 (g) + (1/2)H2 (g). Since pH changes to 12, [OH-] = 10^-2 M. Using Faraday's law: moles of NaOH formed = 10^-2 × 600/1000 = 0.006 mol. Charge required = 0.006 × 96500 = 579 C. Current I = Charge/(time) = 579/(5×60) = 579/300 = 1.93 A ≈ 2 A (nearest integer).
