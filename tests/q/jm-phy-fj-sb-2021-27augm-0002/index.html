A transmitting antenna has a height of 320 m and that of receiving antenna is 2000 m. The maximum distance between them for satisfactory communication in line of sight mode is 'd'. The value of d is ......... km.

Answer

Correct answer: 224

Solution

Using the formula for maximum line of sight distance: d = sqrt(2Rh1) + sqrt(2Rh2), where R = 6400 x 10^6 m (Earth's radius), h1 = 320 m (transmitting antenna height), h2 = 2000 m (receiving antenna height). Therefore, dm = sqrt(2 x 6400 x 10^6 x 320) + sqrt(2 x 6400 x 10^6 x 2000).
