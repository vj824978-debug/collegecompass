Let y = y(x) be the solution curve of the differential equation dy/dx = (y/x)(1 + xy^2(1 + log(x))), x > 0, y(1) = 3. Then y^2(x)/9 is equal to

  1. (1) x^2 / (7 - 3x^3(2 + log_e(x^2)))
  2. (2) x^2 / (2x^3(2 + log_e(x^3)) - 3)
  3. (3) x^2 / (5 - 2x^3(2 + log_e(x^3)))
  4. (4) x^2 / (3x^3(1 + log_e(x^2)) - 2)

Answer

Correct answer: Option 3

Solution

dy/dx = (y/x)(1 + xy^2(1 + log(x))), y(1) = 3 Dividing both sides by y^3: (1/y^3)(dy/dx) - (1/(xy^2)) = 1 + ln(x) Let t = 1/y^2, then: (1/2)(dt/dx) + t/x = 1 + ln(x) dt/dx + (2t)/x = 2(1 + ln(x)) Integrating factor: IF = x^2 t·x^2 = ∫(1 + ln(x))x^2 dx = 2[x^3/3(1 + ln(x)) - x^3/9] + c Using y(1) = 3: 1/9 = 2[1/3(1 + 0) - 1/9] + c 1/9 = 2[1/3 - 1/9] + c 1/9 = 2[2/9] + c 1/9 = 4/9 + c c = -5/9 Therefore: x^2/y^2 = 2[x^3/3(1 + ln(x)) - x^3/9] - 5/9 Simplifying: y^2/9 = x^2 / (5 - 2x^3(2 + ln(x^3)))
