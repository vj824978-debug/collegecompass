The number of integral terms in the expansion of (5^(1/2) + 7^(1/8))^1016 is

  1. (1) 127
  2. (2) 128
  3. (3) 129
  4. (4) 130

Answer

Correct answer: Option 2

Solution

General term T_{r+1} = 1016*C_r * (7^(1/8))^r * (5^(1/2))^(1016-r) = 1016*C_r * 7^(r/8) * 5^((1016-r)/2). For T_{r+1} to be integral, both r/8 and (1016-r)/2 must be integers. This requires: r/8 is integer => 8 divides r, and (1016-r)/2 is integer => 1016-r is even, which is always true since 1016 is even. So r must be multiple of 8: r = 0, 8, 16, ..., 1016. Number of such values = 1016/8 + 1 = 127 + 1 = 128.
