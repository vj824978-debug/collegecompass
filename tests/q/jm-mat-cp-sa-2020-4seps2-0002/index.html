Let lambda ≠ 0 be in R. If alpha and beta are the roots of the equation x^2 - x + 2*lambda = 0 and alpha and gamma are the roots of the equation 3*x^2 - 10*x + 27*lambda = 0, then beta*gamma/lambda is equal to:

  1. (1) 36
  2. (2) 18
  3. (3) 9
  4. (4) 27

Answer

Correct answer: Option 2

Solution

From the equation x^2 - x + 2*lambda = 0 where alpha and beta are roots: alpha + beta = 1, alpha*beta = 2*lambda From the equation 3*x^2 - 10*x + 27*lambda = 0 where alpha and gamma are roots: alpha + gamma = 10/3, alpha*gamma = 27*lambda/3 = 9*lambda From alpha + beta = 1 and alpha + gamma = 10/3: gamma - beta = 10/3 - 1 = 7/3 From the ratio gamma/beta = 9/2: gamma = (9/2)*beta Substituting into gamma - beta = 7/3: (9/2)*beta - beta = 7/3 (9/2 - 1)*beta = 7/3 (7/2)*beta = 7/3 beta = 2/3 From gamma = (9/2)*beta: gamma = (9/2) * (2/3) = 3 From alpha + beta = 1: alpha = 1 - 2/3 = 1/3 From alpha*beta = 2*lambda: (1/3) * (2/3) = 2*lambda 2/9 = 2*lambda lambda = 1/9 Therefore: beta*gamma/lambda = (2/3) * 3 / (1/9) = 2 * 9 = 18
