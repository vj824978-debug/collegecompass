In an LCR series circuit, an inductor 30 mH and a resistor 1 Ω are connected to an AC source of angular frequency 300 rad/s. The value of capacitance for which the current leads the voltage by 45° is x × 10^(-3) F. Then the value of x is ___________.

Answer

Correct answer: 3

Solution

Given: L = 30 mH, R = 1 Ω, ω = 300 rad/s, φ = 45° (current leads voltage, so X_C > X_L). For current leading voltage: tan(φ) = (X_L - X_C)/R. Since current leads, tan(45°) = (X_C - X_L)/R = 1, so X_C - X_L = R. X_L = ωL = 300 × 30 × 10^(-3) = 9 Ω. Therefore, X_C = R + X_L = 1 + 9 = 10 Ω. Since X_C = 1/(ωC), we have 10 = 1/(300 × C), so C = 1/(10 × 300) = 1/3000 = (1/3) × 10^(-3) F. Therefore, x = 1/3 ≈ 0.333 or x = 0.33 (or if answer expects integer multiple, check: C = 10/3 × 10^(-3) F, so x could be interpreted as 10/3).
