A wire of resistance R is bent to form a square ABCD as shown in the figure. The effective resistance between E and C is: (E is mid-point of arm CD)

  1. (1) (3/4)R
  2. (2) (1/16)R
  3. (3) (7/64)R
  4. (4) R

Answer

Correct answer: Option 3

Solution

The wire of total resistance R is bent into a square ABCD. Since the square has 4 equal sides, each side has resistance R/4. E is the midpoint of CD, so: - Resistance from D to E: R/8 - Resistance from E to C: R/8 To find effective resistance between E and C: There are two parallel paths from E to C: Path 1: Direct path EC with resistance R/8 Path 2: Path E → D → A → B → C Resistance of path EDABC: R_EDABC = R/8 + R/4 + R/4 + R/4 = R/8 + 3R/4 = R/8 + 6R/8 = 7R/8 These two paths are in parallel: R_EC = (R/8) × (7R/8) / (R/8 + 7R/8) R_EC = (7R/64) / (8R/8) R_EC = (7R/64) / R R_EC = 7R/64
