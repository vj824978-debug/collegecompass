If the tangent to the curve, y = e^x at a point (c, e^c) and the normal to the parabola, y^2 = 4x at the point (1, 2) intersect at the same point on the x-axis, then the value of c is .................. .

Answer

Correct answer: 4

Solution

y = e^x => dy/dx = e^x m = (dy/dx)|(c,e^c) = e^c => Tangent at (c, e^c) y - e^c = e^c(x - c) it intersect x-axis Put y = 0 => x = c - 1 .....(1) Now y^2 = 4x => dy/dx = 2/y => (dy/dx)|(1,2) = 1 => Slope of normal = -1 Equation of normal: y - 2 = -1(x - 1) x + y = 3 it intersect x-axis Put y = 0 => x = 3 .....(2) Points are same => x = c - 1 = 3 => c = 4
