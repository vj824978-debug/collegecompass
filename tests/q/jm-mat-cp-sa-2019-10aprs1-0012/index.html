If a directrix of a hyperbola centred at the origin and passing through the point (4, -2*sqrt(3)) is 5x = 4*sqrt(5) and its eccentricity is e, then:

  1. (1) 4e^4 - 24e^2 + 27 = 0
  2. (2) 4e^4 - 24e^2 + 35 = 0
  3. (3) 4e^4 - 12e^2 - 27 = 0
  4. (4) 4e^4 + 8e^2 - 35 = 0

Answer

Correct answer: Option 2

Solution

Let hyperbola be (x^2)/(a^2) - (y^2)/(b^2) = 1 & passes through (4, -2*sqrt(3)) therefore 16/a^2 - 12/b^2 = 1 .....(i) Also, b^2 = a^2(e^2 - 1) Directrix: x = 4*sqrt(5)/5 = a/e Therefore, a^2 = (16/5)*e^2 .....(ii) Substituting (ii) in (i): 16/(16*e^2/5) - 12/(a^2(e^2 - 1)) = 1 5/(e^2) - 12/((16*e^2/5)*(e^2 - 1)) = 1 5/(e^2) - 60/(16*e^2(e^2 - 1)) = 1 5/(e^2) - 15/(4*e^2(e^2 - 1)) = 1 Multiplying by 4*e^2(e^2 - 1): 20(e^2 - 1) - 15 = 4*e^2(e^2 - 1) 20*e^2 - 20 - 15 = 4*e^4 - 4*e^2 20*e^2 - 35 = 4*e^4 - 4*e^2 0 = 4*e^4 - 24*e^2 + 35 Therefore: 4e^4 - 24e^2 + 35 = 0
