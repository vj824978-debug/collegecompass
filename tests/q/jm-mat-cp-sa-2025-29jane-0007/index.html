Let S = N ∪ {0}. Define a relation R from S to R by: R = {(x,y): log_y = x log_e(2/5), x ∈ S, y ∈ R}. Then, the sum of all the elements in the range of R is equal to

  1. (1) 3/2
  2. (2) 5/3
  3. (3) 10/9
  4. (4) 5/2

Answer

Correct answer: Option 2

Solution

S = {0, 1, 2, 3, .....} log_e(y) = x log_e(2/5) ⇒ y = (2/5)^x For different values of x ∈ S: When x = 0: y = (2/5)^0 = 1 When x = 1: y = (2/5)^1 = 2/5 When x = 2: y = (2/5)^2 When x = 3: y = (2/5)^3 And so on... Range of R = {1, 2/5, (2/5)^2, (2/5)^3, .....} Required Sum = 1 + (2/5) + (2/5)^2 + (2/5)^3 + ..... = 1/(1 - 2/5) = 1/(3/5) = 5/3
