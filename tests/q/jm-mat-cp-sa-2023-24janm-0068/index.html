The relation R = {(a, b) : gcd(a, b) = 1, 2a ≠ b, a, b ∈ Z} is

  1. (1) Reflexive but not symmetric
  2. (2) Neither symmetric nor transitive
  3. (3) Symmetric but not transitive
  4. (4) Transitive but not reflexive

Answer

Correct answer: Option 3

Solution

gcd(a, a) = a so (a, a) so ∉ R ⟹ not reflexive If gcd(a, b) = 1 ⟹ gcd(b, a) = 1 ∴ (b, a) ∈ R ⟹ Symmetric If gcd(a, b) = 1 and gcd(b, c) = 1 ⟹ gcd(a, c) = 1 ∴ R is not transitive
