If the sum of squares of all real values of a, for which the lines 2x - y + 3 = 0, 6x + 3y + 1 = 0 and ax + 2y - 2 = 0 do not form a triangle is p, then the greatest integer less than or equal to p is _____.

Answer

Correct answer: 32

Solution

Triangle will not form if at least two lines are parallel or all three lines are concurrent. Case I: If lines (1) and (3) are parallel: 2/a = -1/2, so a = -4. If lines (2) and (3) are parallel: 6/a = 3/2, so a = 4. Case II: If lines are concurrent, determinant of coefficients equals zero: |2 -1 3; 6 3 1; a 2 -2| = 0, which gives 8 - 10a = 0, so a = 4/5. Sum of squares: p = (-4)^2 + 4^2 + (4/5)^2 = 16 + 16 + 16/25 = 32.64. Greatest integer ≤ p is 32.
