max{x - 2sin(x)cos(x) + (1/3)sin(3x)} for 0≤x≤π

  1. (1) (π + 2 - 3√3)/6
  2. (2) π
  3. (3) 0
  4. (4) (5π + 2 + 3√3)/6

Answer

Correct answer: Option 4

Solution

f'(x) = 1 - 2cos(2x) + cos(3x). Setting f'(x) = 0 and simplifying: (2cos(x) + √3)(2cos(x) - √3)(cos(x) - 1) = 0. Critical points: x = 5π/6, π/6, 0. Using second derivative test: f''(5π/6) = -2√3 - √3 < 0 (local maximum), f''(π/6) = 2√3 - √3 > 0 (local minimum), f''(0) = 0. Maximum value at x = 5π/6: f(5π/6) = 5π/6 + √3/2 + 1/3 = (5π + 2 + 3√3)/6
