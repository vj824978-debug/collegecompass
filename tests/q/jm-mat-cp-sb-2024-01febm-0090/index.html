Let the line of the shortest distance between the lines L1: r = (i + 2j + 3k) + λ(i - j + k) and L2: r = (4i + 5j + 6k) + μ(i + j - k) intersect L1 and L2 at P and Q respectively. If (α, β, γ) is the mid point of the line segment PQ, then 2(α + β + γ) is equal to ______.

Answer

Correct answer: 21

Solution

L1: r = (1, 2, 3) + λ(1, -1, 1). L2: r = (4, 5, 6) + μ(1, 1, -1). Point P on L1: (λ + 1, -λ + 2, λ + 3). Point Q on L2: (μ + 4, μ + 5, -μ + 6). Vector PQ = (μ - λ + 3, μ + λ + 3, -μ - λ + 3). For shortest distance, PQ ⊥ b1 and PQ ⊥ b2. PQ · (1, -1, 1) = 0 gives 3λ + μ = 3 (equation i). PQ · (1, 1, -1) = 0 gives 3μ + λ = 3 (equation ii). Solving: λ = 1, μ = 0. P = (5/2, 1/2, 9/2), Q = (5/2, 7/2, 15/2). Mid point (α, β, γ) = (5/2, 4/2, 12/2) = (5/2, 2, 6). Therefore 2(α + β + γ) = 2(5/2 + 2 + 6) = 2(21/2) = 21.
