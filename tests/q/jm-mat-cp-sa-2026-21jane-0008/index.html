Let the line L_1 be parallel to the vector -3i + 2j + 4k and pass through the point (2, 6, 7) and the line L_2 be parallel to the vector 2i + j + 3k and pass through the point (4, 3, 5). If the line L_3 is parallel to the vector -3i + 5j + 16k and intersects the lines L_1 and L_2 at the points C and D, respectively, then |CD|^2 is equal to

  1. (1) 171
  2. (2) 290
  3. (3) 312
  4. (4) 89

Answer

Correct answer: Option 2

Solution

L_1: (x - 2)/(-3) = (y - 6)/2 = (z - 7)/4 Point C on L_1: (-3*lambda_1 + 2, 2*lambda_1 + 6, 4*lambda_1 + 7) L_2: (x - 4)/2 = (y - 3)/1 = (z - 5)/3 Point D on L_2: (2*lambda_2 + 4, lambda_2 + 3, 3*lambda_2 + 5) Direction ratios of line L_3: L_3: (2*lambda_2 + 3*lambda_1 + 2)/(-3) = (lambda_2 - 2*lambda_1 - 3)/5 = (3*lambda_2 - 4*lambda_1 - 2)/16 From the first two ratios: 5(2*lambda_2 + 3*lambda_1 + 2) = -3(lambda_2 - 2*lambda_1 - 3) 10*lambda_2 + 15*lambda_1 + 10 = -3*lambda_2 + 6*lambda_1 + 9 13*lambda_2 + 9*lambda_1 = -1 ... (1) From the second and third ratios: 16(lambda_2 - 2*lambda_1 - 3) = 5(3*lambda_2 - 4*lambda_1 - 2) 16*lambda_2 - 32*lambda_1 - 48 = 15*lambda_2 - 20*lambda_1 - 10 lambda_2 - 12*lambda_1 = 38 ... (2) From equation (2): lambda_2 = 12*lambda_1 + 38 Substituting in equation (1): 13(12*lambda_1 + 38) + 9*lambda_1 = -1 156*lambda_1 + 494 + 9*lambda_1 = -1 165*lambda_1 = -495 lambda_1 = -3 lambda_2 = 12(-3) + 38 = 2 C: (-3(-3) + 2, 2(-3) + 6, 4(-3) + 7) = (11, 0, -5) D: (2(2) + 4, 2 + 3, 3(2) + 5) = (8, 5, 11) |CD|^2 = (11 - 8)^2 + (0 - 5)^2 + (-5 - 11)^2 |CD|^2 = 3^2 + 5^2 + 16^2 |CD|^2 = 9 + 25 + 256 = 290
