The increasing basicity order of the following compounds is: (A) CH3CH2NH2 (B) CH3CH2-NH with CH2CH3 above N (C) H3C-N-CH3 with CH3 above N (D) Ph-N-H with CH3 above N

  1. (1) (A) < (B) < (C) < (D)
  2. (2) (D) < (C) < (B) < (A)
  3. (3) (D) < (C) < (A) < (B)
  4. (4) (A) < (B) < (D) < (C)

Answer

Correct answer: Option 3

Solution

Basic strength is determined by the availability of lone pair on nitrogen for protonation. The order of basicity based on lone pair availability and resonance effects: CH3-CH2-CH2-NH-CH2CH3 (secondary amine, 2°) > CH3-CH2-NH2 (primary amine, 1°) > CH3-N(CH3)2 (tertiary amine, l.p. participate in resonance) > Ph-N(H)-CH3 (aromatic amine, l.p. participate in resonance) Therefore: B > A > C > D This corresponds to the order: (D) < (C) < (A) < (B) The key factors: - Secondary amines (B) are more basic than primary amines (A) due to better stabilization of conjugate acid by alkyl groups - Primary amines (A) are more basic than tertiary amines (C) because in C, the lone pair participates in resonance with the nitrogen, making it less available - Tertiary amines (C) are more basic than aromatic amines (D) because in D, the lone pair participates in resonance with the benzene ring, significantly reducing basicity
