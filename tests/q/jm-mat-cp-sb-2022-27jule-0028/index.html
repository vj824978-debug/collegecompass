Let f be a differential function satisfying f(x) = (2/sqrt(3)) * integral from 0 to sqrt(3)x of f(λx/3) dλ, x > 0 and f(1) = sqrt(3). If y = f(x) passes through the point (α, 6), then α is equal to ____.

Answer

Correct answer: 12

Solution

Differentiate the given integral equation with respect to x to get f'(x). Apply Leibniz rule for differentiation under integral sign. Simplify to get sqrt(3)f'(x) = sqrt(f(x)) - (sqrt(3)/2)f(x). This gives xf'(x) = f(x)/2. Integrating: ln(y) = (1/2)ln(x) + ln(c). From f(1) = sqrt(3), we get c = sqrt(3). So f(x) = sqrt(3x). Since the curve passes through (α, 6): 6 = sqrt(3α), which gives α = 12.
