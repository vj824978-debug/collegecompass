Given below are two statements: Statement I: Among [Cu(NH3)4]^2+, [Ni(en)3]^2+, [Ni(NH3)6]^2+ and [Mn(H2O)6]^2+, [Mn(H2O)6]^2+ has the maximum number of unpaired electrons. Statement II: The number of pairs among [NiCl4]^2-, [Ni(CO)4], [NiCl4]^2- and [Ni(CN)4]^2- and [Ni(CO)4], [Ni(CN)4]^2- that contain only diamagnetic species is two. In the light of the above statements, choose the correct answer from the options given below:

  1. (1) Statement I is false but Statement II is true
  2. (2) Both Statement I and Statement II are true
  3. (3) Both Statement I and Statement II are false
  4. (4) Statement I is true but Statement II is false

Answer

Correct answer: Option 4

Solution

[Cu(NH3)4]^2+ has d^9, dsp^2 configuration with one unpaired electron. [Ni(en)3]^2+ has d^8, sp^3 d^2 configuration with two unpaired electrons. [Ni(NH3)6]^2+ has d^8, sp^3 d^2 configuration with two unpaired electrons. [Mn(H2O)6]^2+ has d^5, sp^3 d^2 configuration with five unpaired electrons. So Statement I is TRUE. For Statement II: [Ni(CO)4] is diamagnetic, [NiCl4]^2- is paramagnetic, [Ni(CN)4]^2- is diamagnetic. Only one pair ([Ni(CO)4], [Ni(CN)4]^2-) contains only diamagnetic species, not two. So Statement II is FALSE.
