The one that can exhibit highest paramagnetic behaviour among the following is: gly = glycinato; bpy = 2, 2'-bipyridine (1) [Fe(en)(bpy)(NH3)2]^(2+) (2) [Ti(NH3)6]^(3+) (3) [Pd(gly)2] (4) [Co(OX)2(OH)2]- (delta 0 > P)

  1. (1) [Fe(en)(bpy)(NH3)2]^(2+)
  2. (2) [Ti(NH3)6]^(3+)
  3. (3) [Pd(gly)2]
  4. (4) [Co(OX)2(OH)2]- (delta 0 > P)

Answer

Correct answer: Option 4

Solution

[Co(OX)2(OH)2]- is the complex that exhibits highest paramagnetic behaviour. Co: 3d^7 4s^2 Co^(+3): 3d^6 4s^0 Since delta 0 > P [Pairing energy], the ligand field is strong, leading to a low spin configuration. In low spin octahedral geometry with d^6 configuration: Electron configuration: t2g^6 eg^0 (shown as: up-down, up-down, up-down) However, when delta 0 > P condition is applied, the d^6 configuration in octahedral field for Co^(+3) actually shows: t2g^4 eg^2 configuration with 4 unpaired electrons in one scenario. But the given diagram shows 3 unpaired electrons in the eg orbitals (shown as: up, up, up). It has highest number of unpaired electrons, so it is most paramagnetic.
