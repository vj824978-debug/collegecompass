Young's moduli of two wires A and B are in the ratio 7 : 4. Wire A is 2 m long and has radius R. Wire B is 1.5 m long and has radius 2 mm. If the two wires stretch by the same length for a given load, then the value of R is close to -

  1. (1) 1.9 mm
  2. (2) 1.7 mm
  3. (3) 1.3 mm
  4. (4) 1.5 mm

Answer

Correct answer: Option 2

Solution

F/A = Y * (delta_l / l) F ∝ AY / l Since both wires stretch by the same length (delta_l) for the same load F: (A_1 * Y_1) / l_1 = (A_2 * Y_2) / l_2 For wire A: A_1 = pi * R^2, Y_1 corresponds to modulus ratio 7, l_1 = 2 m For wire B: A_2 = pi * (2 mm)^2, Y_2 corresponds to modulus ratio 4, l_2 = 1.5 m (pi * R^2 * 7) / 2 = (pi * 2^2 * 4) / 1.5 (R^2 * 7) / 2 = (4 * 4) / 1.5 (R^2 * 7) / 2 = 16 / 1.5 R^2 * 7 * 1.5 = 16 * 2 R^2 * 10.5 = 32 R^2 = 32 / 10.5 = 3.048 R = sqrt(3.048) = 1.74 mm R ≈ 1.7 mm
