Let for n = 1, 2, ..., 50, Sₙ be the sum of the infinite geometric progression whose first term is n² and whose common ratio is 1/(n+1)². Then the value of 1/26 + Σ(n=1 to 50)[Sₙ + 2/(n+1) - n - 1] is equal to ______.

Answer

Correct answer: 41651

Solution

First, find Sₙ using the infinite geometric series formula: Sₙ = n²/(1 - 1/(n+1)²) = n²·(n+1)²/(n+1)² - 1 = n(n+1)²/(n+2) = (n² + n) + 2/(n+2). Then compute 1/26 + Σ(n=1 to 50)[Sₙ + 2/(n+1) - n - 1] = 1/26 + Σ(n=1 to 50)[(n² - n) + 2(1/(n+1) - 1/(n+2))]. Split the sum: Σ(n² - n) = 50·51·101/6 - 50·51/2 = 42925 - 1275 = 41650. And 2Σ(1/(n+1) - 1/(n+2)) = 2(1/2 - 1/52) = 25/26. Therefore: 1/26 + 41650 + 25/26 = 1 + 41650 = 41651.
