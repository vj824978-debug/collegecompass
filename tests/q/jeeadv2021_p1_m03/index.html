Consider three sets E₁ = {1, 2, 3}, F₁ = {1, 3, 4} and G₁ = {2, 3, 4, 5}. Two elements are chosen at random, without replacement, from the set E₁ and let S₁ denote the set of these chose elements. Let E₂ = E₁ - S₁ and F₂ = F₁ ∪ S₁. Now two elements are chosen at random, without replacement, from the set F₂ and let S₂ denote the set of these chosen elements. Let G₂ = F₁ ∪ S₂. Finally, two elements are chosen at random, without replacement, from the set G₂ and let S₃ denote the set of these chosen elements. Let E₃ = E₂ ∪ S₃. Given that E₁ = E₃, let p be the conditional probability of the event S₁ = {1, 2}. Then the value of p is

Single correct MCQ · Marks: +3 / -1.0

  1. (A) 1/5
  2. (B) 3/5
  3. (C) 1/2
  4. (D) 2/5

Answer

Correct answer: A

Solution

Sol. A (i) S₁ = {1, 2}, F₂ = F₁ ∪ S₁ = {1, 2, 3, 4}, S₂ = {1, x}, G₁ ∪ S₂ = G₂ = {1, 2, 3, 4, 5}, S₃ = {1, 2} (ii) S₁ = {2, 3}, F₂ = F₁ ∪ S₁ = {1, 2, 3, 4}, S₂ = {1, x} or {x, y} (where x and y are other than 1), G₁ ∪ S₂ = G₂ = {1, 2, 3, 4, 5} or {2, 3, 4, 5}, S₃ = {2, 3} (iii) S₁ = {1, 3}, F₂ = F₁ ∪ S₁ = {1, 3, 4}, S₂ = {1, x} (where x and y are other than 1), G₁ ∪ S₂ = G₂ = {1, 2, 3, 4, 5}, S₃ = {1, 3} (i) P₁ = (²C₂/³C₂) × (³C₁/⁴C₂) × (²C₁/⁵C₂) = 1/60 (ii) P₂ = 1/3 × [(³C₁/⁴C₂) × (²C₂/⁵C₂) + (³C₂/⁴C₂) × (²C₂/⁴C₂)] = 2/45 (iii) P₃ = 1/(³C₁) × (²C₁/³C₂) × (²C₂/⁵C₂) = 1/45 Conditional probability = P₁/(P₁ + P₂ + P₃) = 1/5
