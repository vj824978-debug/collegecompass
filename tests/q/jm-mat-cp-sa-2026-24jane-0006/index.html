Let the image of parabola x^2 = 4y, in the line x - y = 1 be (y + a)^2 = b(x - c), a, b, c ∈ N. Then a + b + c is equal to

  1. (1) 12
  2. (2) 4
  3. (3) 6
  4. (4) 8

Answer

Correct answer: Option 3

Solution

Parametric point P on x^2 = 4y is P(2t, t^2) ∴ mirror image of P in x - y = 1 is Q ≡ (2t - 2·1·(2t - t^2 - 1)/2, t^2 + 2·2(1)·(2t - t^2 - 1)/2) Q ≡ (t^2 + 1, 2t - 1) ≡ (h, k) ∴ locus of Q is x = (y + 1)^2/4 + 1 which is the required parabola. ∴ (y + 1)^2 = 4(x - 1) ∴ a = 1, b = 4, c = 1 ∴ a + b + c = 6
