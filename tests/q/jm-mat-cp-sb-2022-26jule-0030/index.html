The number of matrices A = [a b; c d], where a, b, c, d ∈ {-1, 0, 1, 2, 3, ..., 10}, such that A = A^(-1), is

Answer

Correct answer: 50

Solution

For A^(-1) to exist: ad - bc ≠ 0. Since A = A^(-1), we have A^2 = I. Computing A^2 = [a^2 + bc, b(a+d); c(a+d), bc + d^2]. For A^2 = I: (i) a^2 + bc = d^2 + bc = 1, (ii) b(a+d) = c(a+d) = 0. From (ii): either a = -d or b = c = 0. Case I: When a = d = 0, then b^2 = c^2 = -1 (impossible from (i)). With a = d and a ≠ 0, from (i): a^2 - 1 = bc. Possible values of (b,c) are (1,1), (-1,1), (1,-1), (-1,-1). Total 4 matrices. Case II: When a = -d, then a^2 - 1 = -bc, so bc = 1 - a^2. For a, d ∈ {-1, 0, 1, 2, 3, ..., 10}, (a,d) can be (1,-1) or (-1,1). For each, there are 12 + 11 = 23 possible values of (b,c) satisfying bc = 1 - a^2. Total: 23 × 2 = 46. Total possible matrices = 46 + 4 = 50
