If α = integral from 0 to 1 of (e^(9x+3tan^(-1)x)) * ((12+9x^2)/(1+x^2)) dx where tan^(-1)x takes only principal values, then the value of log_e|1+α| - 3π/4 is

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 9

Solution

α = ∫₀^∞ e^(9x+3tan⁻¹x) · (12+9x)/(1+x²) dx Put 9x + 3 tan⁻¹x = t ⟹ (9 + 3/(1+x²)) dx = dt ⟹ α = ∫₀^(9+3π/4) e^t dt = e^(9+3π/4) - 1 ⟹ log_e |1 + α| - (3π/4) = 9
