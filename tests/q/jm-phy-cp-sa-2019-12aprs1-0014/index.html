A galvanometer of resistance 100 Ω has 50 divisions on its scale and has sensitivity of 20 μA/division. It is to be converted to a voltmeter with three ranges of 0-2V, 0-10 V and 0-20 V. The appropriate circuit to do so is

  1. (1) Circuit with R₁ = 1900Ω, R₂ = 8000Ω, R₃ = 10000Ω
  2. (2) Circuit with R₁ = 19900Ω, R₂ = 9900Ω, R₃ = 1900Ω
  3. (3) Circuit with R₁ = 1900Ω, R₂ = 9900Ω, R₃ = 19900Ω
  4. (4) Circuit with R₁ = 2000Ω, R₂ = 8000Ω, R₃ = 10000Ω

Answer

Correct answer: Option 1

Solution

Given: Sensitivity = 20 μA/division Total divisions = 50 RG = 100Ω Maximum current through galvanometer: I_max = (50)(20 μA) = 10^(-3) A = 1 mA For 0-2V range: I_max = V/(RG + R₁) 10^(-3) = 2/(100 + R₁) 2/10^(-3) = 100 + R₁ 2000 = 100 + R₁ R₁ = 1900Ω For 0-10V range: I_max = V/(RG + R₁ + R₂) 10^(-3) = 10/(100 + 1900 + R₂) 10/10^(-3) = 2000 + R₂ 10000 = 2000 + R₂ R₂ = 8000Ω For 0-20V range: I_max = V/(RG + R₁ + R₂ + R₃) 10^(-3) = 20/(100 + 1900 + 8000 + R₃) 20/10^(-3) = 10000 + R₃ 20000 = 10000 + R₃ R₃ = 10000Ω Therefore: R₁ = 1900Ω, R₂ = 8000Ω, R₃ = 10000Ω
