Let the first term of series be T₁ = 6 and its rth term Tr = 3·Tr-1 + 6^r, r = 2, 3, ..., n. If the sum of the first n terms of this series is (1/5)(n² - 12n + 39)(4·6^n - 5·3^n + 1). Then n is equal to ____.

Answer

Correct answer: 6

Solution

Given: T₁ = 6 and Tr = 3·Tr-1 + 6^r for r = 2, 3, ..., n Dividing by 3^r: Tr/3^r = Tr-1/3^(r-1) + (6/3)^r = Tr-1/3^(r-1) + 2^r Let Ur = Tr/3^r, then Ur = Ur-1 + 2^r Summing: Ur = U₁ + (2² + 2³ + ... + 2^r) = 2 + (4(2^r - 1))/(2-1) = 2(6^r - 3^r)/3 Therefore: Tr = 2(6^r - 3^r) Sn = 2∑(6^r - 3^r) = 2[6(6^n - 1)/5 - 3(3^n - 1)/2] Simplifying: Sn = (3/5)[4·6^n - 5·3^n + 1] Given: Sn = (1/5)(n² - 12n + 39)(4·6^n - 5·3^n + 1) Comparing: (3/5) = (1/5)(n² - 12n + 39) 3 = n² - 12n + 39 n² - 12n + 36 = 0 (n - 6)² = 0 n = 6
