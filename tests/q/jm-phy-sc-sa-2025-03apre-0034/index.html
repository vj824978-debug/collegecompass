A particle is projected with velocity u so that its horizontal range is three times the maximum height attained by it. The horizontal range of the projectile is given as mu^2/(25g), where value of n is: (g is acceleration due to gravity)

  1. (1) 12
  2. (2) 24
  3. (3) 18
  4. (4) 6

Answer

Correct answer: Option 2

Solution

For projectile motion: Range R = u^2*sin(2θ)/g and Max height H = u^2*sin^2(θ)/(2g). Given R = 3H, so u^2*sin(2θ)/g = 3*u^2*sin^2(θ)/(2g). This gives 2*sin(θ)*cos(θ) = (3/2)*sin^2(θ), so tan(θ) = 4/3. Thus sin(θ) = 4/5 and cos(θ) = 3/5. Range R = u^2*sin(2θ)/g = u^2*(2*4/5*3/5)/g = 24u^2/(25g). Comparing with mu^2/(25g), we get m = 24.
