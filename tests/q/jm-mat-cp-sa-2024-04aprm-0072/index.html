Let the first three terms 2, p and q, with q ≠ 2, of a G.P. be respectively the 7th, 8th and 13th terms of an A.P. If the 5th term of the G.P. is the nth term of the A.P., then n is equal to

  1. (1) 151
  2. (2) 169
  3. (3) 177
  4. (4) 163

Answer

Correct answer: Option 4

Solution

From G.P.: 2, p, q with common ratio r. So p = 2r, q = 2r^2. From A.P. condition: 2 = a + 6d (7th term), p = a + 7d (8th term), q = a + 12d (13th term). From first two: p - 2 = d. From last two: q - p = 5d. So q - p = 5(p - 2), giving q = 6p - 10. Using p^2 = 2q (G.P. property): p^2 = 2(6p - 10), so p^2 - 12p + 20 = 0, giving p = 10 or p = 2. Since q ≠ 2, we take p = 10, q = 50, d = 8, a = -46. The 5th term of G.P. is 2r^4 = 2(5)^4 = 1250. Using ar^n = a + (n-1)d: 1250 = -46 + (n-1)8, so n = 163.
