Let a = 4i - j + k, b = 11i - j + k and c be a vector such that (a + b) × c = c × (-2a + 3b). If (2a + 3b) · c = 1670, then |c|^2 is equal to:

  1. (1) 1627
  2. (2) 1618
  3. (3) 1600
  4. (4) 1609

Answer

Correct answer: Option 2

Solution

From (a + b) × c = c × (-2a + 3b), we get (a + b) × c - c × (-2a + 3b) = 0, which gives (a + b - 2a - 3b) × c = 0, so (-a - 2b) × c = 0. This means c = λ(4b - a). Computing: 4b - a = (44i - 4j + 4k) - (4i - j + k) = 40i - 3j + 3k. So c = λ(40i - 3j + 3k). Using (2a + 3b) · c = 1670: (8i - 2j + 2k + 33i - 3j + 3k) · λ(40i - 3j + 3k) = 1670, which gives (41i - 5j + 5k) · λ(40i - 3j + 3k) = 1670. This yields (1640 + 15 + 15)λ = 1670, so λ = 1. Therefore c = 40i - 3j - 3k, and |c|^2 = 1600 + 9 + 9 = 1618.
