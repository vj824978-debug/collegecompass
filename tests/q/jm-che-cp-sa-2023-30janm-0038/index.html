For OF2 molecule consider the following A. Number of lone pairs on oxygen is 2. B. FOF angle is less than 104.5°. C. Oxidation state of O is -2. D. Molecule is bent 'V' shaped E. Molecular geometry is linear.

  1. (1) C, D, E only
  2. (2) B, E, A only
  3. (3) A, C, D only
  4. (4) A, B, D only

Answer

Correct answer: Option 4

Solution

For OF2 molecule: Lewis structure shows O as central atom with 2 F atoms bonded to it. A: Number of lone pairs on oxygen = 2 Oxygen has 6 valence electrons. 2 are used for bonding with 2 F atoms, leaving 4 electrons = 2 lone pairs. Statement A is TRUE. B: FOF angle is less than 104.5° The molecule has 2 bonding pairs and 2 lone pairs around central oxygen. Electron geometry is tetrahedral, molecular geometry is bent. Lone pairs repel more than bonding pairs, so the bond angle < 109.5° Actual FOF angle ≈ 103° which is less than 104.5°. Statement B is TRUE. C: Oxidation state of O is -2 In OF2, F has oxidation state -1 (more electronegative than O) Let oxidation state of O = x x + 2(-1) = 0 x = +2 Oxidation state of O is +2, not -2. Statement C is FALSE. D: Molecule is bent 'V' shaped With 2 bonding pairs and 2 lone pairs, the molecular geometry is bent/V-shaped. Statement D is TRUE. E: Molecular geometry is linear Molecular geometry is bent, not linear. Statement E is FALSE. Therefore, statements A, B, D are correct. Correct option is (4) A, B, D only
