Given below two statements: Statement I: 25^13 + 20^13 + 8^13 + 3^13 is divisible by 7. Statement II: The integral part of (7 + 4*sqrt(3))^25 is an odd number. In the light of the above statements, choose the correct answer from the options given below:

  1. (1) Both Statement I and Statement II are false.
  2. (2) Both Statement I and Statement II are true.
  3. (3) Statement I is false but Statement II is true.
  4. (4) Statement I is true but Statement II is false.

Answer

Correct answer: Option 2

Solution

Statement I: 25^13 + 3^13 + 20^13 + 8^13 Grouped as: (25^13 + 3^13) + (20^13 + 8^13) For (25^13 + 3^13): divisible by (25 + 3) = 28 = 4 × 7 For (20^13 + 8^13): divisible by (20 + 8) = 28 = 4 × 7 Therefore: 25^13 + 20^13 + 8^13 + 3^13 is divisible by 7 ✓ Statement II: Let R = (7 + 4*sqrt(3))^25 = I + f (where I is integral part, 0 < f < 1) Let R' = (7 - 4*sqrt(3))^25 = f' (where 0 < f' < 1, since 7 - 4*sqrt(3) ≈ 0.07) R + R' = 2[^25C_0 * 7^25 + ^25C_2 * 7^23 * (4*sqrt(3))^2 + ...] This expansion contains only even powers of sqrt(3), making the sum an even integer. Therefore: I + f + f' = even integer ∴ I = even integer - (f + f') Since 0 < f + f' < 2 and I must be an integer: f + f' = 1 ∴ I = even integer - 1 = odd integer ✓ Both statements are correct.
