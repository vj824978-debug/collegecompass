A survey shows that 63% of the people in a city read newspaper A whereas 76% read newspaper B. If x% of the people read both the newspapers, then a possible value of x can be:

  1. (1) 55
  2. (2) 37
  3. (3) 29
  4. (4) 65

Answer

Correct answer: Option 1

Solution

n(B) ≤ n(A ∪ B) ≤ n(U) ⇒ 76 ≤ 76 + 63 - x ≤ 100 ⇒ -63 ≤ -x ≤ -39 ⇒ 63 ≥ x ≥ 39 Using the principle: n(A ∪ B) = n(A) + n(B) - n(A ∩ B) Where n(A) = 63, n(B) = 76, n(A ∩ B) = x For a valid solution: - The union cannot exceed 100%: 63 + 76 - x ≤ 100 ⇒ x ≥ 39 - The intersection cannot exceed either individual set: x ≤ 63 and x ≤ 76 - The intersection must be at least as large as max(n(A) + n(B) - 100, 0) = max(39, 0) = 39 Therefore: 39 ≤ x ≤ 63 Among the given options: (1) 55 ✓ (lies in [39, 63]) (2) 37 ✗ (less than 39) (3) 29 ✗ (less than 39) (4) 65 ✗ (greater than 63) The possible value is 55.
