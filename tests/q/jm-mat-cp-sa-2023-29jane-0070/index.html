Let y = y(x) be the solution of the differential equation x log(x) * dy/dx + y = x^2 * log(x), (x > 1). If y(2) = 2, then y(e) is equal to

  1. (1) (1 + e^2)/2
  2. (2) (1 + e^2)/4
  3. (3) (4 + e^2)/4
  4. (4) (2 + e^2)/2

Answer

Correct answer: Option 3

Solution

x ln(x) * dy/dx + y = x^2 * ln(x) Dividing by x ln(x): dy/dx + 1/(x ln(x)) * y = x This is a linear differential equation of the form dy/dx + P(x)*y = Q(x) where P(x) = 1/(x ln(x)) and Q(x) = x Integrating factor: IF = e^(∫ 1/(x ln(x)) dx) Let t = ln(x), then dt = 1/x * dx ∫ 1/(x ln(x)) dx = ∫ 1/t * dt = ln(t) = ln(ln(x)) Therefore, IF = e^(ln(ln(x))) = ln(x) Multiplying the equation by ln(x): y * ln(x) = ∫ x * ln(x) dx Using integration by parts: ∫ x * ln(x) dx = (x^2/2) * ln(x) - ∫ (x^2/2) * (1/x) dx = (x^2/2) * ln(x) - ∫ x/2 dx = (x^2/2) * ln(x) - x^2/4 + C Therefore: y * ln(x) = (x^2/2) * ln(x) - x^2/4 + C .....(i) Applying initial condition y(2) = 2: 2 * ln(2) = (4/2) * ln(2) - 4/4 + C 2 * ln(2) = 2 * ln(2) - 1 + C C = 1 Putting x = e in equation (i): y * ln(e) = (e^2/2) * ln(e) - e^2/4 + 1 y * 1 = (e^2/2) * 1 - e^2/4 + 1 y = e^2/2 - e^2/4 + 1 y = 2e^2/4 - e^2/4 + 1 y = e^2/4 + 1 y = (4 + e^2)/4
