Let the straight line y = 2x touch a circle with centre (0, a), a > 0, and radius r at a point A₁. Let B₁ be the point on the circle such the line segment A₁B₁ is a diameter of the circle. Let a + r = 5 + sqrt(5). Match each entry in List-I to the correct entries in List-II. List – I: (P) α equals (Q) r equals (R) A₁ equals (S) B₁ equals List – II: (1) (−2, 4) (2) sqrt(5) (3) (−2, 6) (4) 5 (5) (2, 4) The correct option is:

Matrix match · Marks: +3 / -1.0

  1. (A) (P) → (4) (Q) → (2) (R) → (1) (S) → (3)
  2. (B) (P) → (2) (Q) → (4) (R) → (1) (S) → (3)
  3. (C) (P) → (4) (Q) → (2) (R) → (5) (S) → (3)
  4. (D) (P) → (2) (Q) → (4) (R) → (3) (S) → (5)

Answer

Correct answer: C

Solution

OA₁ = |2·0 - α|/√5 = r ⇒ α = r√5 given α + r = 5 + √5 ⇒ r(1 + √5) = √5(1 + √5) ⇒ r = √5, hence α = 5 Now, A₁B₁ = 2r = 2√5 A₁(2, 4) and B₁(-2, 6) from elimination.
