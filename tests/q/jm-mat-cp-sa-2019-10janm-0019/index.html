If the area enclosed between the curves y = kx^2 and x = ky^2, (k > 0), is 1 square unit. Then k is -

  1. (1) sqrt(3)
  2. (2) sqrt(3)/2
  3. (3) 2/sqrt(3)
  4. (4) 1/sqrt(3)

Answer

Correct answer: Option 4

Solution

From the curves y = kx^2 and x = ky^2, we find their intersection points. Substituting y = kx^2 into x = ky^2: x = k(kx^2)^2 = k(k^2x^4) = k^3x^4 This gives k^3x^4 - x = 0, so x(k^3x^3 - 1) = 0 Therefore x = 0 or x = 1/k When x = 1/k, y = k(1/k)^2 = 1/k The curves intersect at (0,0) and (1/k, 1/k). For 0 ≤ x ≤ 1/k, the curve x = ky^2 can be written as y = sqrt(x/k), which lies above y = kx^2. Area = ∫[0 to 1/k] (sqrt(x/k) - kx^2) dx = ∫[0 to 1/k] sqrt(x/k) dx - k∫[0 to 1/k] x^2 dx = (1/sqrt(k)) · (x^(3/2))/(3/2)|[0 to 1/k] - k · (x^3)/3|[0 to 1/k] = (1/sqrt(k)) · (2/3) · (1/k)^(3/2) - k · (1/3) · (1/k)^3 = (2/3) · (1/k)/(sqrt(k)) - (1/3k^2) = (2/(3k^(3/2))) - (1/(3k^2)) = (2k^(1/2))/(3k^2) - (1/(3k^2)) = (2)/(3k^(3/2)) - (1)/(3k^2) = (2k^(1/2) - 1)/(3k^2) Simplifying: (2)/(3k^(3/2)) - (1)/(3k^2) = 1 Multiplying through: 2k^(1/2) - 1 = 3k^2 Let's recalculate more carefully: Area = (2/3) · (1/k)^(3/2) / (1/sqrt(k)) - (1/3) · (1/k)^3 / k = (2/3) · (1/k^(3/2)) · sqrt(k) - (1/3k^2) = (2/(3k)) - (1/(3k^2)) = (2k - 1)/(3k^2) = 1 Therefore: 2k - 1 = 3k^2 3k^2 - 2k + 1 = 0 Wait, recalculating the integral: Area = (1/sqrt(k)) · (2/3) · (1/k)^(3/2) - k · (1/3) · (1/k)^3 = (2/3k) - (1/(3k^2)) = (2k - 1)/(3k^2) = 1 So 2k - 1 = 3k^2, which gives 3k^2 - 2k + 1 = 0. This doesn't factor nicely. Rechecking: (2/3) · (1/sqrt(k)) · (1/k)^(3/2) - (1/3k) · (1/k)^3 = (2/3) · (1/k^2) - (1/3k^2) = (2/(3k^2)) - (1/(3k^2)) = 1/(3k^2) = 1 This gives k^2 = 1/3, so k = 1/sqrt(3)
