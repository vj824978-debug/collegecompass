Let the equation of plane passing through the line of intersection of the planes x + 2y + az = 2 and x - y + z = 3be 5x - 11y + bz = 6a - 1. For c∈Z, if the distance of this plane from the point (a, -c, c) is 2/sqrt(a), then (a + b)/c is equal to

  1. (1) 2
  2. (2) 4
  3. (3) -4
  4. (4) -2

Answer

Correct answer: Option 3

Solution

The plane passing through intersection of two planes is: x + 2y + az - 2 + λ(x - y + z - 3) = 0. Rearranging: λ(λ + 1) + y(2 - λ) + z(a + λ) - 2 - 3λ = 0. Comparing with 5x - 11y + bz = 6a - 1, we get λ = -7/2. From the coefficients: a = 3, b = 1. Using the distance formula with point (3, -c, c) and plane 5x - 11y + z = 17, we get |15 + 11c + c - 17|/sqrt(147) = 2/sqrt(3). Solving: |12c - 2| = 14, which gives c = -1 (since c ∈ Z). Therefore (a + b)/c = (3 + 1)/(-1) = -4.
