A coin is tossed three times. Let X denote the number of times a tail follows a head. If μ and σ^2 denote the mean and variance of X, then the value of 64(μ + σ^2) is :

  1. (1) 51
  2. (2) 48
  3. (3) 32
  4. (4) 64

Answer

Correct answer: Option 2

Solution

When a coin is tossed three times, we have 8 possible outcomes: HHH, HHT, HTH, HTT, THH, THT, TTH, TTT. X denotes the number of times a tail follows a head. For each outcome, count tails that follow heads: - HHH: 0 (no tail after any head) - HHT: 1 (one tail follows the last head) - HTH: 1 (one tail follows the first head) - HTT: 1 (one tail follows the head) - THH: 0 (no tail follows any head) - THT: 1 (one tail follows the head) - TTH: 0 (no tail follows the head) - TTT: 0 (no heads, so no tail follows a head) Probability distribution: X = 0 appears in 4 outcomes (HHH, THH, TTH, TTT), so P(X=0) = 4/8 = 1/2 X = 1 appears in 4 outcomes (HHT, HTH, HTT, THT), so P(X=1) = 4/8 = 1/2 Mean: μ = Σ x_i p_i = 0(1/2) + 1(1/2) = 1/2 Variance: σ^2 = Σ x_i^2 p_i - μ^2 = 0^2(1/2) + 1^2(1/2) - (1/2)^2 = 1/2 - 1/4 = 1/4 Therefore: 64(μ + σ^2) = 64(1/2 + 1/4) = 64(3/4) = 48
