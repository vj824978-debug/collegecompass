A faulty thermometer reads 5°C in melting ice and 95°C in steam. The correct temperature on absolute scale will be __________ K when the faulty thermometer reads 41°C.

Answer

Correct answer: 313

Solution

Let the correct temperature be X°C The faulty thermometer has a linear error. We establish the relationship using the two calibration points: - At melting ice (correct 0°C), faulty reads 5°C - At steam (correct 100°C), faulty reads 95°C Using linear relationship: (X - 0)/(100 - 0) = (41 - 5)/(95 - 5) X/100 = 36/90 X/100 = 41 - 5/(95 - 5) X = 40°C Converting to absolute scale (Kelvin): Temperature = 273 + 40 K = 313 K
