If the area of the larger portion bounded between the curves x^2 + y^2 = 25 and y = |x - 1| is 1/4(bπ + c), b, c ∈ N, then b + c is equal to ________.

Answer

Correct answer: 77

Solution

The circle x^2 + y^2 = 25 has radius 5 centered at origin. The line y = |x - 1| consists of two rays: y = x - 1 for x ≥ 1 and y = -(x - 1) = -x + 1 for x < 1. Finding intersection points: For y = x - 1: x^2 + (x - 1)^2 = 25 ⟹ x^2 + x^2 - 2x + 1 = 25 ⟹ 2x^2 - 2x - 24 = 0 ⟹ x^2 - x - 12 = 0 ⟹ (x - 4)(x + 3) = 0 So x = 4 (intersection point (4, 3)) and x = -3 (intersection point (-3, -4)). For y = -x + 1: x^2 + (-x + 1)^2 = 25 ⟹ x^2 + x^2 - 2x + 1 = 25 ⟹ x^2 - x - 12 = 0 So x = 4 (intersection point (4, -3)) and x = -3 (intersection point (-3, 4)). The area of the larger portion is: A = 25π - ∫_{-3}^{4} sqrt(25 - x^2) dx + (1/2) × 4 × 4 + (1/2) × 3 × 3 A = 25π - [x/2 × sqrt(25 - x^2) + 25/2 × sin^(-1)(x/5)]_{-3}^{4} + 8 + 4.5 Evaluating the antiderivative: At x = 4: (4/2)sqrt(25 - 16) + (25/2)sin^(-1)(4/5) = 2 × 3 + (25/2)sin^(-1)(4/5) = 6 + (25/2)sin^(-1)(4/5) At x = -3: (-3/2)sqrt(25 - 9) + (25/2)sin^(-1)(-3/5) = (-3/2) × 4 + (25/2)sin^(-1)(-3/5) = -6 + (25/2)sin^(-1)(-3/5) A = 25π + 25/2[6 + (25/2)sin^(-1)(4/5) - (-6 + (25/2)sin^(-1)(-3/5))] + 12.5 A = 25π + 25/2[6 + (25/2)sin^(-1)(4/5) + 6 - (25/2)sin^(-1)(-3/5)] + 12.5 A = 25π + (1/2) × 25 × [12 + (25/2)(sin^(-1)(4/5) + sin^(-1)(3/5))] + 12.5 Since sin^(-1)(4/5) + sin^(-1)(3/5) = π/2: A = 25π + (25/2)[6 + (25/2) × (π/2)] + 6 A = 25π + (75π/4) + (1/2) A = (100π + 75π)/4 + 1/2 = 175π/4 + 1/2 = (1/4)(175π + 2) Therefore b = 75, c = 2 b + c = 75 + 2 = 77
