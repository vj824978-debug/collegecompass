Let a tangent to the curve 9x^2 + 16y^2 = 144 intersect the coordinate axes at the points A and B. Then, the minimum length of the line segment AB is ___________

Answer

Correct answer: 7

Solution

Given curve: 9x^2 + 16y^2 = 144 Rewriting in standard form: x^2/16 + y^2/9 = 1 Let P(4cos(theta), 3sin(theta)) be any point on the ellipse. Equation of tangent at P: (x cos(theta))/4 + (y sin(theta))/3 = 1 Finding intercepts on coordinate axes: When y = 0: x cos(theta)/4 = 1, so A = (4sec(theta), 0) When x = 0: y sin(theta)/3 = 1, so B = (0, 3cosec(theta)) Length of AB: AB = sqrt((4sec(theta))^2 + (3cosec(theta))^2) AB = sqrt(16sec^2(theta) + 9cosec^2(theta)) AB = sqrt(16sec^2(theta) + 9cosec^2(theta)) AB = sqrt(16 + 9 + 16tan^2(theta) + 9cot^2(theta)) AB = sqrt(25 + 16tan^2(theta) + 9cot^2(theta)) Using AM-GM inequality: 16tan^2(theta) + 9cot^2(theta) >= 2*sqrt(16tan^2(theta)*9cot^2(theta)) = 2*sqrt(144) = 2*12 = 24 Equality holds when 16tan^2(theta) = 9cot^2(theta), which gives tan^2(theta) = 3/4 Therefore: AB_min = sqrt(25 + 24) = sqrt(49) = 7
