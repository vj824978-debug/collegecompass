Let a = alpha*i + j - k and b = 2i + j - alpha*k, alpha > 0. If the projection of a × b on the vector -i + 2j - 2k is 30, then alpha is equal to

  1. (1) 15/2
  2. (2) 8
  3. (3) 13/2
  4. (4) 7

Answer

Correct answer: Option 4

Solution

Given a = (alpha, 1, -1) and b = (2, 1, -alpha). Calculate a × b = (-alpha + 1)i + (alpha^2 - 2)j + (alpha - 2)k. The projection of c on d = -i + 2j - 2k is |c·d|/|d| = 30. Calculate c·d = |-alpha - 1 - 4 + 2alpha^2 - 2alpha - 4| = |2alpha^2 - 3alpha - 9|. With |d| = sqrt(1 + 4 + 4) = 3, we get |2alpha^2 - 3alpha - 9|/3 = 30, so |2alpha^2 - 3alpha - 9| = 90. Solving 2alpha^2 - 3alpha - 9 = 90 gives 2alpha^2 - 3alpha - 99 = 0 or alpha = -13/2 (rejected) and alpha = 7. Also 2alpha^2 - 3alpha - 9 = -90 gives alpha = -13/2 (rejected). Thus alpha = 7.
