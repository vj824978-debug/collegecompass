A reversible cyclic process for an ideal gas is shown below. Here, P, V, and T are pressure, volume and temperature, respectively. The thermodynamic parameters q, w, H and U are heat, work, enthalpy and internal energy, respectively. [Graph showing V-T diagram with three points: A(P₁,V₁,T₁), B(P₂,V₂,T₁), and C(P₂,V₁,T₂), forming a triangular cycle] The correct option(s) is (are)

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) (A) q_AC = ΔU_BC and w_AB = P₂(V₂−V₁)
  2. (B) (B) w_BC = P₂(V₂−V₁) and q_BC = ΔH_AC
  3. (C) (C) ΔH_CA < ΔU_CA and q_AC = ΔU_BC
  4. (D) (D) q_BC = ΔH_AC and ΔH_CA > ΔU_CA

Answer

Correct answer: BC

Solution

ΔH_AC + ΔH_CB + ΔH_BA = 0 ΔH_BA = 0 (Temperature is constant) ΔH_AC = ΔH_BC ... (1) We know that q_p = ΔH (in path BC, P = constant) Hence q_BC = ΔH_BC From Eq. (1) q_BC = ΔH_AC (B) q_BC = -P₂(V₁ - V₂) = P₂(V₂ - V₁) (C) ΔH_CA = nC_p(T₁ - T₂) = -nC_p(T₂ - T₁) ΔU_CA = nC_V(T₁ - T₂) = -nC_V(T₂ - T₁) As, C_p > C_V So, ΔH_CA < ΔU_CA
