Treatment of buta-1,3-diene with NaNH₂ (2 equivalents), followed by reaction with excess of trans-CH₃-CH=CH-CH₂-Br gives X as the major product. The maximum number of carbon atoms that are collinear (in a straight line) in X is ____.

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 6

Solution

Solution: Buta-1,3-diyne (HC ≡ C − C ≡ CH) reacts with 2 equivalents of NaNH₂ to undergo double deprotonation, forming the acetylide dianion: HC ≡ C − C ≡ CH + 2NaNH₂ → ⊖C ≡ C − C ≡ C⊖ + 2NH₃ This dianion acts as a strong nucleophile and undergoes an Sₙ2 reaction with the primary allylic halide, trans-CH₃-CH=CH-CH₂-Br (excess ensures both sides react): ⊖C ≡ C − C ≡ C⊖ + 2CH₃-CH=CH-CH₂-Br → CH₃-CH=CH-CH₂ − C ≡ C − C ≡ C − CH₂-CH=CH-CH₃ In the major product X, the central diyne unit consists of four sp hybridized carbon atoms. The geometry around sp hybridized carbons is linear (bond angle 180°). The two sp³ hybridized −CH₂− carbons attached directly to the sp carbons also lie on this same linear axis. Thus, the sequence of collinear carbon atoms is: −CH₂ − C ≡ C − C ≡ C − CH₂− The carbon atoms beyond the −CH₂− groups are attached at a tetrahedral angle (∼ 109.5°) and are not collinear with the central axis. Therefore, the maximum number of collinear carbon atoms in X is 6. Answer: 6
