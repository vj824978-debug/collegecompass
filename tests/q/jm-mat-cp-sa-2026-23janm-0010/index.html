The value of the integral ∫[π/24 to 5π/24] dx/(1 + ∛(tan 2x)) is :

  1. (1) π/12
  2. (2) π/18
  3. (3) π/6
  4. (4) π/3

Answer

Correct answer: Option 1

Solution

I = ∫[π/24 to 5π/24] dx/(1 + ∛(tan 2x)) .....(1) Apply king property: I = ∫[π/24 to 5π/24] dx/(1 + ∛(tan 2(π/4 - x))) = ∫[π/24 to 5π/24] dx/(1 + ∛(cot 2x)) .....(2) Add (1) + (2) ⇒ 2I = ∫[π/24 to 5π/24] (1)dx I = (1/2)(π/6) = π/12
