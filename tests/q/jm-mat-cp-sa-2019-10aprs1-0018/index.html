If Q(0, -1, -3) is the image of the point P in the plane 3x - y + 4z = 2 and R is the point (3, -1, -2), then the area (in sq. units) of triangle PQR is:

  1. (1) sqrt(65)/2
  2. (2) 2*sqrt(13)
  3. (3) sqrt(91)/2
  4. (4) sqrt(91)/4

Answer

Correct answer: Option 3

Solution

To find point P, we use the fact that Q is the reflection of P in the plane 3x - y + 4z = 2. The normal to the plane is vector n = (3, -1, 4). Let P = (p1, p2, p3). The midpoint M of PQ lies on the plane: M = ((p1 + 0)/2, (p2 - 1)/2, (p3 - 3)/2) Since M lies on the plane: 3(p1/2) - (p2 - 1)/2 + 4(p3 - 3)/2 = 2 3p1 - p2 + 1 + 4p3 - 12 = 4 3p1 - p2 + 4p3 = 15 ... (1) Also, PQ is perpendicular to the plane, so PQ is parallel to the normal: (0 - p1, -1 - p2, -3 - p3) = k(3, -1, 4) for some scalar k From this: -p1 = 3k => p1 = -3k -1 - p2 = -k => p2 = -1 + k -3 - p3 = 4k => p3 = -3 - 4k Substituting in equation (1): 3(-3k) - (-1 + k) + 4(-3 - 4k) = 15 -9k + 1 - k - 12 - 16k = 15 -26k - 11 = 15 -26k = 26 k = -1 So: p1 = 3, p2 = -2, p3 = 1 Therefore P = (3, -2, 1) Now we find the area of triangle PQR with: P = (3, -2, 1), Q = (0, -1, -3), R = (3, -1, -2) Vector PQ = Q - P = (-3, 1, -4) Vector PR = R - P = (0, 1, -3) Cross product PQ × PR: PQ × PR = |i j k | |-3 1 -4| |0 1 -3| = i(1(-3) - (-4)(1)) - j((-3)(-3) - (-4)(0)) + k((-3)(1) - 1(0)) = i(-3 + 4) - j(9 - 0) + k(-3 - 0) = i(1) - j(9) + k(-3) = (1, -9, -3) |PQ × PR| = sqrt(1 + 81 + 9) = sqrt(91) Area of triangle PQR = (1/2)|PQ × PR| = sqrt(91)/2
