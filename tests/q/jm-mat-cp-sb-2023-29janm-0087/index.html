Let the coefficients of three consecutive terms in the binomial expansion of (1 + 2x)^n be in the ratio 2 : 5 : 8. Then the coefficient of the term, which is in the middle of these three terms, is _______.

Answer

Correct answer: 1120

Solution

Let the three consecutive terms have coefficients ^n C_r * 2^r, ^n C_(r+1) * 2^(r+1), and ^n C_(r+2) * 2^(r+2). Given that these are in ratio 2 : 5 : 8. From the first two terms: (^n C_r * 2^r) / (^n C_(r+1) * 2^(r+1)) = 2/5 Simplifying: (^n C_r * 2^r) / (^n C_(r+1) * 2^(r+1)) = (r + 1) / (n - r) * 1/2 = 2/5 Therefore: (r + 1)/(n - r) = 4/5 .......(i) From the second and third terms: (^n C_(r+1) * 2^(r+1)) / (^n C_(r+2) * 2^(r+2)) = 5/8 Simplifying: (^n C_(r+1) * 2^(r+1)) / (^n C_(r+2) * 2^(r+2)) = (r + 2) / (n - r - 1) * 1/2 = 5/8 Therefore: (r + 2)/(n - r - 1) = 5/4 .......(ii) Solving equation (i): 5(r + 1) = 4(n - r) 5r + 5 = 4n - 4r 9r + 5 = 4n n = (9r + 5)/4 Solving equation (ii): 4(r + 2) = 5(n - r - 1) 4r + 8 = 5n - 5r - 5 9r + 13 = 5n n = (9r + 13)/5 Equating the two expressions for n: (9r + 5)/4 = (9r + 13)/5 5(9r + 5) = 4(9r + 13) 45r + 25 = 36r + 52 9r = 27 r = 3 Substituting r = 3 into n = (9r + 5)/4: n = (9(3) + 5)/4 = (27 + 5)/4 = 32/4 = 8 The middle term of the three consecutive terms is the (r+1)th term. So we need the coefficient of the (r+1)th = 4th term. Middle term = ^n C_(r+1) * 2^(r+1) = ^8 C_4 * 2^4 ^8 C_4 = 8!/(4! * 4!) = (8 * 7 * 6 * 5)/(4 * 3 * 2 * 1) = 1680/24 = 70 Coefficient = 70 * 2^4 = 70 * 16 = 1120
