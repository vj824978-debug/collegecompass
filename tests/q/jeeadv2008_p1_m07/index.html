Let f(x) be a non-constant twice differentiable function defined on (-∞, ∞) such that f(x) = f(1-x) and f'(1/4) = 0. Then

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) f''(x) vanishes at least twice on [0, 1]
  2. (B) f'(1/2) = 0
  3. (C) integral from -1/2 to 1/2 of f(x + 1/2)sin(x) dx = 0
  4. (D) integral from 0 to 1/2 of f(t)e^(sin(πt)) dt = integral from 1/2 to 1 of f(1-t)e^(sin(πt)) dt

Answer

Correct answer: ABCD

Solution

f(x) = f(1 - x) Put x = 1/2 + x f(1/2 + x) = f(1/2 - x) Hence f(x + 1/2) is an even function or f(x + 1/2) sin x is an odd function. Also, f'(x) = -f'(1 - x) and for x = 1/2, we have f'(1/2) = 0. Also, ∫[0 to 1] f(1-t)e^(iπ·y)dt = -∫[1 to 0] f(y)e^(iπ·y)dy (obtained by putting, 1 - t = y). Since f'(1/4) = 0, f'(3/4) = 0. Also f'(1/2) = 0 → f''(x) = 0 at least twice in [0, 1] (Rolle's Theorem) [Graph showing a curve with maximum at 1/4, minimum at 1/2, and maximum at 3/4, with values marked on x-axis] IIT-JEE2008-PAPER-1-4
