Let C be the largest circle centred at (2, 0) and inscribed in the ellipse x^2/36 + y^2/16 = 1. If (1, alpha) lies on C, then 10*alpha^2 is equal to ________

Answer

Correct answer: 118.00

Solution

x^2/36 + y^2/16 = 1 r^2 = (x - 2)^2 + y^2 Solving simultaneously - 5x^2 + 36x + (9r^2 - 180) = 0 D = 0 r^2 = 128/10 Distance between (1, alpha) and (2, 0) should be r 1 + alpha^2 = 128/10 alpha^2 = 118/10 = 118.00 10*alpha^2 = 118.00
