Let A, B and C be sets such that φ ≠ A ∩ B ⊆ C. Then which of the following statements is not true?

  1. (1) If (A - B) ⊆ C, then A ⊆ C
  2. (2) B ∩ C ≠ φ
  3. (3) (C ∪ A) ∩ (C ∪ B) = C
  4. (4) If (A - C) ⊆ B, then A ⊆ B

Answer

Correct answer: Option 4

Solution

Let A = {1, 2, 3, 4}, B = {3, 4, 5, 6}, C = {1, 2, 3, 4, 7, 8} Here A ∩ B = {3, 4} ⊆ C A - C = φ ⊆ B but A ⊄ B So not true (wrong) statement is 4th If A - C ⊆ B then A ⊆ B
