Consider the region R = {(x,y): x ≤ y ≤ 9 - (11/3)x^2, x ≥ 0}. The area of the largest rectangle of sides parallel to the coordinate axes and inscribed in R, is:

  1. (1) 625/111
  2. (2) 730/119
  3. (3) 567/121
  4. (4) 821/123

Answer

Correct answer: Option 3

Solution

Let the rectangle have vertices at (0,0), (t,0), (t,y), (0,y) where 0 ≤ t and the top side lies on the parabola y = 9 - (11/3)x^2 or the line y = x. From the diagram, the rectangle has width t and height is determined by the constraint that the top-right corner (t,t) lies on the parabola boundary or y = x. For the rectangle inscribed with sides parallel to axes: - Width = t - Height = 9 - (11/3)t^2 - t Area A = t(9 - (11/3)t^2 - t) = 9t - t^2 - (11/3)t^3 Taking derivative: dA/dt = 9 - 2t - 11t^2 Setting dA/dt = 0: 11t^2 + 2t - 9 = 0 11t^2 + 11t - 9t - 9 = 0 11t(t + 1) - 9(t + 1) = 0 (11t - 9)(t + 1) = 0 So t = -1 or t = 9/11 Since t ≥ 0, we have t = 9/11 Checking second derivative: d^2A/dt^2 = -2 - 22t < 0 at t = 9/11, confirming maximum. Maximum area = (9/11)(9 - (11/3)(9/11)^2 - 9/11) = (9/11)(9 - (11/3)(81/121) - 9/11) = (9/11)(9 - 81/11 - 9/11) = (9/11)(99/11 - 81/11 - 9/11) = (9/11)(9/11) = (9/11)(99 - 81 - 9)/11 = (9/11)(9/11) Recalculating more carefully: At t = 9/11: A = 9(9/11) - (9/11)^2 - (11/3)(9/11)^3 = 81/11 - 81/121 - (11/3)(729/1331) = 81/11 - 81/121 - 729/363 = 81/11 - 81/121 - 243/121 = 891/121 - 81/121 - 243/121 = 567/121
