Let X have a binomial distribution B(n, p) such that the sum and the product of the mean and variance of X are 24 and 128 respectively. If P(X > n - 3) = k / 2^n, then k is equal to

  1. (1) 528
  2. (2) 529
  3. (3) 629
  4. (4) 630

Answer

Correct answer: Option 2

Solution

For binomial distribution B(n, p): Mean = np, Variance = npq. Given: np + npq = 24 and np * npq = 128. From first equation: np(1 + q) = 24, so np(p + q) = 24, thus np = 24/p. From second: (np)^2 * q = 128. Solving: (np)^2 * q = 128 and np + npq = 24. Let np = m, then m + mq = 24 and m^2 * q = 128. From first: m(1 + q) = 24. From second: m^2 * q = 128. Dividing: mq/(1+q) = 128/24 = 16/3. Solving gives q = p = 1/2 and n = 32. P(X > n - 3) = P(X > 29) = P(X = 30) + P(X = 31) + P(X = 32) = (C(32,30) + C(32,31) + C(32,32)) * (1/2)^32 = (496 + 32 + 1) / 2^32 = 529 / 2^32. Therefore k = 529.
