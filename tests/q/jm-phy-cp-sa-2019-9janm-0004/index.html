A rod of mass 'M' and length '2L' is suspended at its middle by a wire. It exhibits torsional oscillations; If two masses each of 'm' are attached at distance 'L/2' from its centre on both sides, it reduces the oscillation frequency by 20%. The value of ratio m/M is close to:

  1. (1) 0.37
  2. (2) 0.57
  3. (3) 0.77
  4. (4) 0.17

Answer

Correct answer: Option 1

Solution

T = 2*pi*sqrt(I/C) For torsional oscillations, the period T = 2*pi*sqrt(I/C), where I is moment of inertia and C is torsional constant. Initial case (rod alone): I = M(2L)^2/12 = ML^2/3 T = 2*pi*sqrt(I/C) Final case (rod with two masses): I' = M(2L)^2/12 + 2m(L/2)^2 = ML^2/3 + mL^2/2 T' = 2*pi*sqrt(I'/C) Given that frequency reduces by 20%, which means period increases by 25% (since f = 1/T, if f becomes 0.8f, then T becomes T/0.8 = 1.25T) Wait, let me recalculate. If frequency reduces by 20%: f' = 0.8f T'/T = f/f' = 1/0.8 = 1.25 But the solution shows T/T' = 0.8: T/T' = sqrt(I/I') = sqrt(I'/I) = 0.8f/f = 0.8 So: sqrt(I'/I) = 0.8 I'/I = 0.64 ML^2/3 + mL^2/2 = 0.64 * ML^2/3 ML^2/3 + mL^2/2 = 0.64ML^2/3 mL^2/2 = 0.64ML^2/3 - ML^2/3 mL^2/2 = ML^2(0.64/3 - 1/3) mL^2/2 = ML^2(0.64 - 1)/3 m/2 = -0.36M/3 (This is wrong) Let me use the correct equation from solution: M(2L)^2/12 = 0.64[M(2L)^2/12 + 2m(L/2)^2] ML^2/3 = 0.64[ML^2/3 + mL^2/2] ML^2/3 = 0.64ML^2/3 + 0.64mL^2/2 ML^2/3 - 0.64ML^2/3 = 0.64mL^2/2 0.36ML^2/3 = 0.64mL^2/2 M/1.92 = m/2 * (0.64/0.36) = m * 1.78/2 M/1.92 = M/3 + m/2 m/M = (1/3 - 1/1.92)/0.5 = (1/3 - 1/1.92) * 2 m/M = 1.08*2/(3*1.92) = 2.16/5.76 ≈ 0.37
