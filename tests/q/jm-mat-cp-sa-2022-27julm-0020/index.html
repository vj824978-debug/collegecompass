Let a function f: R → R be defined as: f(x) = {∫[0 to x](5−|t−3|)dt, x > 4; x^2 + bx, x ≤ 4}. Where b ∈ R, if f is continuous at x = 4 then which of the following statements is NOT true?

  1. (1) f is not differentiable at x = 4
  2. (2) f'(3) + f'(5) = 35/4
  3. (3) f is increasing on (−∞, 1/8) ∪ (8, ∞)
  4. (4) f has a local minima at x = 1/8

Answer

Correct answer: Option 3

Solution

From continuity at x = 4: f(4−) = f(4+) gives 16 + 4b = ∫[0 to 4](5−|t−3|)dt. Evaluating the integral yields b = −1/4. So f(x) = x^2 − x/4 for x ≤ 4. Then f'(x) = 5−|x−3| for x > 4 and f'(x) = 2x − 1/4 for x ≤ 4. This gives f'(3) + f'(5) = 6 − 1/4 = 35/4 (option 2 is true). f'(x) < 0 when 8−x < 0 (x > 4) or 2x − 1/4 < 0 (x < 1/8). So f is increasing on (−∞, 1/8) ∪ (8, ∞) actually means f'(x) > 0 there, but the condition f'(x) < 0 defines where f is decreasing. At x = 1/8, f'(x) = 0 gives local minima (option 4 is true). Option 3 is NOT true because the sign analysis is incorrect.
