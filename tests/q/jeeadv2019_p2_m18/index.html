Which of the following is the only INCORRECT combination?

Matrix match · Marks: +4 / -1.0

Passage:

  1. (A) (IV), (S)
  2. (B) (III), (R)
  3. (C) (IV), (U)
  4. (D) (I), (P)

Answer

Correct answer: A
