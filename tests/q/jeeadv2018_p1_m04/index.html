For every twice differentiable function f: ℝ → [-2, 2] with (f(0))² + (f'(0))² = 85, which of the following statement(s) is(are) TRUE?

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) There exist r, s ∈ ℝ, where r < s, such that f is one-one on the open interval (r, s)
  2. (B) There exists x₀ ∈ (-4, 0) such that |f'(x₀)| ≤ 1
  3. (C) lim_{x→+∞} f(x) = 1
  4. (D) There exist α ∈ (-4, 4) such that f(α) + f''(α) = 0 and f'(α) ≠ 0

Answer

Correct answer: ABD

Solution

L.M.V.T. in [-4, 0] (f(0) - f(-4))/4 = f'(x₀) |f'(x₀)| ≤ (|f(0)| + |f(-4)|)/4 ≤ 1 If f(x) periodic then lim f(x) ≠ 1 x→∞ Similarly |f'(x₁)| ≤ 1 for some x₁ ∈ (0, 4) g(x) = (f(x))² + (f'(x))² g(x₀) ≤ 5, g(x₁) ≤ 5 g(0) = 85 it has a local maximum having value ≥ 85 Say α g'(α) = 0, g''(α) ≤ 0 2f(α)f'(α) + 2f'(α)f''(α) = 0 f'(α)(f(α) + f''(α)) = 0 as f'(α) ≠ 0
