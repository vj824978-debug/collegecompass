Three harmonic waves having equal frequency ν and same intensity I₀, have phase angles 0, π/4 and -π/4 respectively. When they are superimposed the intensity of the resultant wave is close to-

  1. (1) 3I₀
  2. (2) 5.8I₀
  3. (3) I₀
  4. (4) 0.2I₀

Answer

Correct answer: Option 2

Solution

Given: - Three harmonic waves with equal frequency ν and same intensity I₀ - Phase angles: 0, π/4, and -π/4 Since intensity I₀ ∝ A₀² for each wave, all three waves have the same amplitude A₀. For phasor addition: - First wave: amplitude A₀ at phase 0° - Second wave: amplitude A₀ at phase π/4 - Third wave: amplitude A₀ at phase -π/4 Phasor diagram: The second and third waves are at ±π/4 from the first wave. Resultant amplitude calculation: - Component along 0° direction: A₀ + A₀cos(π/4) + A₀cos(-π/4) = A₀ + A₀/√2 + A₀/√2 = A₀(1 + 2/√2) = A₀(1 + √2) - Component perpendicular to 0°: 0 + A₀sin(π/4) + A₀sin(-π/4) = A₀/√2 - A₀/√2 = 0 Resultant Amplitude: A = √[A₀²(1 + √2)²] = A₀(1 + √2) A = A₀(1 + √2) Resultant Intensity: I_resultant ∝ A² = A₀²(1 + √2)² I_resultant ∝ A₀²(1 + 2√2 + 2) I_resultant ∝ A₀²(3 + 2√2) I_resultant = I₀(3 + 2√2) I_resultant = I₀(3 + 2 × 1.414) I_resultant = I₀(3 + 2.828) I_resultant ≈ 5.8I₀
