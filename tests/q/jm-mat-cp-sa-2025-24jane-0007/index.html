Let [x] denote the greatest integer function, and let m and n respectively be the numbers of the points, where the function f(x) = [x] + |x - 2|, -2 < x < 3, is not continuous and not differentiable. Then m + n is equal to:

  1. (1) 6
  2. (2) 9
  3. (3) 8
  4. (4) 7

Answer

Correct answer: Option 3

Solution

f(x) = [x] + |x - 2|, -2 < x < 3 We need to rewrite this by considering the greatest integer function and absolute value separately. For -2 < x < 3: The greatest integer function [x] has discontinuities at x = -1, 0, 1, 2 The absolute value |x - 2| changes form at x = 2 Breaking into intervals: For -2 < x < -1: [x] = -2, |x - 2| = 2 - x, so f(x) = -2 + (2 - x) = -x For -1 ≤ x < 0: [x] = -1, |x - 2| = 2 - x, so f(x) = -1 + (2 - x) = -x + 1 For 0 ≤ x < 1: [x] = 0, |x - 2| = 2 - x, so f(x) = 0 + (2 - x) = -x + 2 For 1 ≤ x < 2: [x] = 1, |x - 2| = 2 - x, so f(x) = 1 + (2 - x) = -x + 3 For 2 ≤ x < 3: [x] = 2, |x - 2| = x - 2, so f(x) = 2 + (x - 2) = x f(x) = { -x, -2 < x < -1 -x + 1, -1 ≤ x < 0 -x + 2, 0 ≤ x < 1 -x + 3, 1 ≤ x < 2 x, 2 ≤ x < 3 } Points of discontinuity (where f is not continuous): At x = -1: lim(x→-1-) = -(-1) = 1, but f(-1) = -(-1) + 1 = 2. Discontinuous. At x = 0: lim(x→0-) = -(0) + 1 = 1, but f(0) = -(0) + 2 = 2. Discontinuous. At x = 1: lim(x→1-) = -(1) + 2 = 1, but f(1) = -(1) + 3 = 2. Discontinuous. At x = 2: lim(x→2-) = -(2) + 3 = 1, but f(2) = 2. Discontinuous. So f is discontinuous at 4 points: x = -1, 0, 1, 2 Thus m = 4 Points of non-differentiability: At points where f is discontinuous, it is also not differentiable: x = -1, 0, 1, 2 At x = 2, additionally the derivative changes from -1 to +1 (corner point). All 4 points of discontinuity are also points of non-differentiability. Thus n = 4 Therefore m + n = 4 + 4 = 8
