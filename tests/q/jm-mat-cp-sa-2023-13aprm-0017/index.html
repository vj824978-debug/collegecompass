Integral from 0 to 6 of [6 / (e^(3x) + 6e^(2x) + 11e^x + 6)] dx =

  1. (1) log(32/27)
  2. (2) log(512/81)
  3. (3) log(256/81)
  4. (4) log(64/27)

Answer

Correct answer: Option 1

Solution

Let e^x = t, then x = ln(t), dx = (1/t)dt. When x=0, t=1; when x=6, t=e^6. Rewrite denominator as t(t+1)(t+2)(t+3). Use partial fractions: 6/[t(t+1)(t+2)(t+3)] = 1/t - 3/(t+1) + 3/(t+2) - 1/(t+3). Integrate from 1 to e^6: ln(t) - 3ln(t+1) + 3ln(t+2) - ln(t+3) evaluated at limits. At e^6: ln(e^6) - 3ln(e^6+1) + 3ln(e^6+2) - ln(e^6+3). At 1: ln(1) - 3ln(2) + 3ln(3) - ln(4) = -3ln(2) + 3ln(3) - ln(4). For large e^6 terms, approximately ln(e^6) - 3ln(e^6) + 3ln(e^6) - ln(e^6) = ln((e^6(e^6+2)^3)/((e^6+1)^3(e^6+3))) ≈ ln(32/27) after careful evaluation.
