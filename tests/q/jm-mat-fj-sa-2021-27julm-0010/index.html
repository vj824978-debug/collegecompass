A ray of light through (2, 1) is reflected at a point P on the y-axis and then passes through the point (5, 3). If this reflected ray is the directrix of any ellipse with eccentricity 1/3 and the distance of the nearer focus from this directrix is 8/sqrt(53), then the equation of the other directrix can be:

  1. (1) 2x - 7y - 39 = 0 or 2x - 7y - 7 = 0
  2. (2) 11x + 7y + 8 = 0 or 11x + 7y - 15 = 0
  3. (3) 2x - 7y + 29 = 0 or 2x - 7y - 7 = 0
  4. (4) 11x - 7y - 8 = 0 or 11x + 7y + 15 = 0

Answer

Correct answer: Option 3

Solution

First, find the equation of reflected ray through (2,1) and (5,3): slope = (3-1)/(5-2) = 2/3, equation is 2x - 3y + c = 0 passing through (2,1) gives 2x - 3y - 1 = 8n. For reflected ray from y-axis, slope becomes -2/3, equation is 2x + 3y = k. Using reflection property and the fact that this is a directrix with e = 1/3, distance from focus to directrix = 8/sqrt(53). Using a/e - ae = 8/sqrt(53) and solving with eccentricity condition gives the other directrix equations. The reflected ray equation simplifies to 2x - 7y + 11 = 0. Using the directrix property and distance formula, the other directrix is found to be either 2x - 7y - 39 = 0 or 2x - 7y - 7 = 0.
