The area (in sq. units) of the region {(x, y) : 0 ≤ y ≤ x^2 + 1, 0 ≤ y ≤ x + 1, 1/2 ≤ x ≤ 2} is

  1. (1) 23/6
  2. (2) 79/24
  3. (3) 79/16
  4. (4) 23/16

Answer

Correct answer: Option 2

Solution

0 ≤ y ≤ x^2 + 1, 0 ≤ y ≤ x + 1, 1/2 ≤ x ≤ 2 For the given region, we need to find where the boundaries intersect and determine which constraint is active. The region is bounded by: - y = x^2 + 1 (parabola) - y = x + 1 (line) - x = 1/2 to x = 2 The line y = x + 1 is below the parabola y = x^2 + 1 for x > 0 (since x^2 + 1 > x + 1 when x^2 - x > 0, which is true for x > 1 or x < 0). For 1/2 ≤ x ≤ 1: the line y = x + 1 is above the parabola For 1 ≤ x ≤ 2: the parabola y = x^2 + 1 is above the line The required area consists of: 1. From x = 1/2 to x = 1: area between y = 0 and y = x + 1 2. From x = 1 to x = 2: area between y = 0 and y = x^2 + 1 3. Additional rectangular area Required area = ∫(1/2 to 1) (x^2 + 1)dx + 1/2(2 + 3) × 1 = [x^3/3 + x] from 1/2 to 1 + 5/2 = [(1/3 + 1) - (1/24 + 1/2)] + 5/2 = [4/3 - 13/24] + 5/2 = 19/24 + 5/2 = 19/24 + 60/24 = 79/24
