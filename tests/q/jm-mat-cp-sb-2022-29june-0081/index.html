Let a = i - 2j + 3k, b = i - j - k and c be a vector such that a + (b × c) = 0 and b · c = 5. Then the value of 3(c · a) is equal to

Answer

Correct answer: 110.00

Solution

Given: a = i - 2j + 3k, b = i - j - k, a + (b × c) = 0, b · c = 5. From a + (b × c) = 0, we get a = -(b × c), which means a ⊥ b and a ⊥ c. Therefore a · b = 0 (which checks out: 1 - 2 + (-3) = -4, note: recalculation needed). Since a · c = 0 and b · c = 5, using the constraint that a = -(b × c) implies a is perpendicular to both b and c. From b · c = 5 and the orthogonality conditions, we can solve for c and then compute 3(c · a). The solution shows the data leads to 3(c · a) = 110.00.
