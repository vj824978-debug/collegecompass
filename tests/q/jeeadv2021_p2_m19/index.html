For any real number x, let [x] denote the largest integer less than or equal to x. If I = integral from 0 to 10 of sqrt(10x/(x+1)) * [10x/(x+1)] dx, then the value of 9I is ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 182

Solution

I = ∫₀¹⁰ [10x/√(x+1)] dx [10x/√(x+1)] = n ⟹ n²/(10-n²) ≤ x < (n+1)²/(10-(n+1)²) where n ∈ ℤ For n = 0, 0 ≤ x < 1/9 n = 1; 1/9 ≤ x < 2/3 n = 2; 2/3 ≤ x < 9, n = 3, x ≥ 9 ⟹ I = ∫₀^(1/9) 0·dx + ∫_(1/9)^(2/3) 1·dx + ∫_(2/3)^9 2·dx + ∫₉¹⁰ 3·dx = (2/3 - 1/9) + 2(9 - 2/3) + 3(10 - 9) = 182/9 + 91 = 182
