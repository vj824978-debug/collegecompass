Let f : ℝ → ℝ be a function such that f(x + y) = f(x) + f(y) for all x, y ∈ ℝ, and g : ℝ → (0, ∞) be a function such that g(x + y) = g(x)g(y) for all x, y ∈ ℝ. If f(-3/5) = 12 and g(-1/3) = 2, then the value of (f(1/4) + g(-2) - 8)g(0) is ____

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 51

Solution

f(x) = kx, g(x) = aˣ f(-3/5) = 12, g(-1/3) = 2 -3k/5 = 12, a^(-1/3) = 2 k = -20, 1/a = 8 ⟹ a = 1/8 f(x) = -20x, g(x) = (1/8)ˣ, g(0) = 1 f(1/4) = -20 × 1/4 = -5, g(-2) = (1/8)^(-2) = 64 f(1/4) + g(-2) - 8 = -5 + 64 - 8 = 51 [f(1/4) + g(-2) - 8] = 51
