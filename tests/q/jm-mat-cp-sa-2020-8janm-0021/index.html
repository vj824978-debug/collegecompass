The number of all 3 × 3 matrices A, with enteries from the set {-1, 0, 1} such that the sum of the diagonal elements of AA^T is 3, is ___________.

Answer

Correct answer: 672

Solution

Let A = [[a1, a2, a3], [b1, b2, b3], [c1, c2, c3]]; A^T = [[a1, b1, c1], [a2, b2, c2], [a3, b3, c3]] The diagonal elements of AA^T are a1^2 + a2^2 + a3^2, b1^2 + b2^2 + b3^2, c1^2 + c2^2 + c3^2 Sum = (a1^2 + a2^2 + a3^2) + (b1^2 + b2^2 + b3^2) + (c1^2 + c2^2 + c3^2) = 3 Since each entry is from {-1, 0, 1}, each squared entry is either 0 or 1. For the sum to equal 3, exactly three entries must be either 1 or -1, and the rest must be 0. This means: in each row, the sum of squares must contribute to the total of 3. Since we have three rows, we need exactly three entries (counting all positions) to be non-zero (either ±1). ⇒ three entries must be either 1 or −1 ⇒ number of matrices = ^9C_3 × 2 × 2 × 2 = (9 × 8 × 7)/(3 × 2) × 2 × 2 × 2 = 84 × 2 × 2 × 2 = 672
