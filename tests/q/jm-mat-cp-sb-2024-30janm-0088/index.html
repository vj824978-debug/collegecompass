Let the latus rectum of the hyperbola x^2/9 - y^2/b^2 = 1 subtend an angle of pi/3 at the centre of the hyperbola. If b^2 is equal to ℓ/m (1 + sqrt(n)), where ℓ and m are co-prime numbers, then ℓ^2 + m^2 + n^2 is equal to ___.

Answer

Correct answer: 182

Solution

For hyperbola x^2/9 - y^2/b^2 = 1, a = 3. The latus rectum endpoints are (ae, b^2/a) and (ae, -b^2/a). These subtend angle pi/3 at origin. Using tan(pi/6) = b^2/(a^2*e) = 1/sqrt(3), we get b^2/(9e) = 1/sqrt(3), so e = sqrt(3)*b^2/9. Since e^2 = 1 + b^2/a^2 = 1 + b^2/9, we have 3b^4/81 = 1 + b^2/9. This gives b^4 - 3b^2 - 27 = 0. Using quadratic formula: b^2 = (3 ± sqrt(9 + 108))/2 = (3 ± sqrt(117))/2 = (3 ± 3*sqrt(13))/2 = (3/2)(1 + sqrt(13)). Therefore ℓ = 3, m = 2, n = 13. Thus ℓ^2 + m^2 + n^2 = 9 + 4 + 169 = 182.
