Match List I with List II List-I: (a) Angular momentum (b) Torque (c) Stress (d) Pressure gradient List-II: (i) [ML^2T^(-2)] (ii) [ML^(-2)T^(-2)] (iii) [ML^2T^(-1)] (iv) [ML^(-1)T^(-2)] Options: (1) A - I, B - IV, C - III, D - II (2) A - II, B - III, C - IV, D - I (3) A - IV, B- II, C - I, D - III (4) A - III, B - I, C - IV, D - II

  1. (1) A - I, B - IV, C - III, D - II
  2. (2) A - II, B - III, C - IV, D - I
  3. (3) A - IV, B- II, C - I, D - III
  4. (4) A - III, B - I, C - IV, D - II

Answer

Correct answer: Option 4

Solution

Angular momentum: L = r x P => [L] = [M^0L^1T^0][M^1L^1T^(-1)] = [M^1L^2T^(-1)] = (iii) Torque: τ = r x F => [τ] = [L^1][MLT^(-2)] = [ML^2T^(-2)] = (i) Stress ≡ Pressure = F/A => [Stress] = [ML^(-1)T^(-2)] = (iv) Pressure Gradient = dP/dx => [Pressure Gradient] = [ML^(-1)T^(-2)]/[L] = [ML^(-2)T^(-2)] = (ii) Therefore: (a) Angular momentum matches (iii) (b) Torque matches (i) (c) Stress matches (iv) (d) Pressure gradient matches (ii) So: A - III, B - I, C - IV, D - II
