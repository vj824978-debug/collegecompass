For n ∈ N, let Sn = {z ∈ C : |z - 3 + 2i| = n/4} and Tn = {z ∈ C : |z - 2 + 3i| = 1/n}. Then the number of elements in the set {n ∈ N : Sn ∩ Tn = φ} is:

  1. (1) 0
  2. (2) 2
  3. (3) 3
  4. (4) 4

Answer

Correct answer: Option 2

Solution

Sn is a circle with centre C1(3, -2) and radius n/4. Tn is a circle with centre C2(2, -3) and radius 1/n. Distance between centres: C1C2 = sqrt((3-2)^2 + (-2-(-3))^2) = sqrt(2). For Sn ∩ Tn = φ, circles don't intersect. Case 1: C1C2 > n/4 + 1/n, giving sqrt(2) > n/4 + 1/n. Testing n = 1,2,3,4 satisfies this condition. Case 2: C1C2 < |n/4 - 1/n|, giving sqrt(2) < |n^2 - 4|/(4n), which has infinite solutions. From Case 1, n = 1, 2, 3, 4 are valid but checking more carefully, n = 2 and n = 3 satisfy the condition for disjoint circles.
