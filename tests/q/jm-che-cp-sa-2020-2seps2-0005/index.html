Two compounds A and B with same molecular formula (C3H6O) undergo Grignard's reaction with methylmagnesium bromide to give products C and D. Products C and D show following chemical tests. Test results table: Ceric ammonium nitrate Test: C - Positive, D - Positive Lucas Test: C - Turbidity obtained after five minutes, D - Turbidity obtained immediately Iodoform Test: C - Positive, D - Negative C and D respectively are:

  1. (1) C=H2C-C(-CH3)(-OH)-CH3; D=H3C-CH2-CH2-CH2-OH
  2. (2) C=H2C-CH2-CH2-CH2-OH; D=H3C-C(-CH3)(-OH)-CH3
  3. (3) C=H2C-CH2-CH(-OH)-CH3; D=H3C-C(-OH)(-CH3)-CH3
  4. (4) C=H2C-C(-CH2)-CH2-CH2-OH; D=H3C-CH2-CH(-OH)-CH3

Answer

Correct answer: Option 3

Solution

Given: Two compounds A and B with molecular formula C3H6O undergo Grignard's reaction with methylmagnesium bromide to give products C and D. Analyzing the chemical tests: 1) Ceric ammonium nitrate Test (CAN test for alcohols): Both C and D are positive - This indicates both C and D contain alcohol (-OH) groups 2) Lucas Test: - C shows turbidity after five minutes (slower reaction) - D shows turbidity immediately (faster reaction) - Lucas test rate: Primary alcohol (slow) < Secondary alcohol (faster) < Tertiary alcohol (immediate) - Therefore: C is a secondary alcohol, D is a tertiary alcohol 3) Iodoform Test: - C is positive (gives iodoform precipitate) - D is negative (no iodoform precipitate) - Iodoform test is positive for compounds having CH3-CH(OH)- or CH3-CO- group - Therefore: C must have CH3-CH(OH)- group, D does not have this structure Since both A and B are C3H6O and react with CH3MgBr to form alcohols: A and B must be aldehydes or ketones (C3H6O) Possible structures for A and B: - Propanal: CH3CH2CHO - Propionaldehyde derivative - Acetone: CH3COCH3 - Allyl aldehyde: H2C=CH-CHO For product C (secondary alcohol with iodoform test positive): Reactant A must be: H2C=CH-CHO (acrolein/allyl aldehyde) Product C after Grignard reaction: H2C=CH-CH(OH)-CH3 (secondary alcohol with CH3-CH(OH)- group) For product D (tertiary alcohol with iodoform test negative): Reactant B must be: CH3-CO-CH3 (acetone) Product D after Grignard reaction: CH3-C(-OH)(-CH3)-CH3 (tertiary alcohol) Therefore: C = H2C=CH-CH(-OH)-CH3 D = H3C-C(-OH)(-CH3)-CH3 Verification: - C is secondary alcohol (Lucas test: 5 minutes) ✓ - D is tertiary alcohol (Lucas test: immediate) ✓ - C has CH3-CH(OH)- group (Iodoform test: positive) ✓ - D does not have CH3-CH(OH)- or CH3-CO- (Iodoform test: negative) ✓
