Let f be a real-valued differentiable function on ℝ (the set of all real numbers) such that f(1) = 1. If the y-intercept of the tangent at any point P(x, y) on the curve y = f(x) is equal to the cube of the abscissa of P, then the value of f(−3) is equal to

Numerical (NAT) · Marks: +4 / 0.0

Answer

Correct answer: 9

Solution

Sol. (9) y - y₁ = m(x - x₁) Put x = 0, to get y intercept y₁ - mx₁ = x₁³ y₁ - x₁(dy/dx) = x₁³ x(dy/dx) - y = -x³ dy/dx - y/x = -x² e^(∫-1/x dx) = e^(-ln x) = 1/x y × 1/x = ∫-x² × 1/x dx y/x = -∫x dx ⟹ y/x = -x²/2 + c ⟹ f(x) = -x³/2 + 3x/2 ∴ f(-3) = 9.
