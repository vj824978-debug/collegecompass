Passage: Consider the curve C₁ given by y = e^(-x) for x ∈ [0, 10π], and the curve C₂ given by y = e^(-x)(sin x + cos x) for x ∈ [0, 10π]. Let n be the total number of points of intersection of the curves C₁ and C₂. Suppose that α₁, α₂, ..., αₙ ∈ [0, 10π] are the x-coordinates of the points of intersection of the curves C₁ and C₂ such that α₁ < α₂ < ... < αₙ. Question: Let β be the area of the region enclosed between the curves C₁, C₂, and the lines x = α₁ and x = α₄. Then the value of -1/π log_e(β - 2e^(-α₄)) is _______.

Comprehension · Marks: +3 / 0.0

Passage:

Answer

Correct answer: 2.5

Solution

Solution: To find the points of intersection of the curves C₁ and C₂, we equate their equations: eˣ = e⁻ˣ(sin x + cos x) Since eˣ ≠ 0, we have: sin x + cos x = 1 ⇒ √2 sin(x + π/4) − 1 = sin(x + π/4) = 1/√2 The general solution is x + π/4 = 2kπ + π/4 or x + π/4 = 2kπ + 3π/4 for any integer k. Thus, x = 2kπ or x = 2kπ + π/2 For x ∈ [0, 10π], the first points of intersection are: α₁ = 0 α₂ = π/2 α₃ = 2π α₄ = 2π + π/2 = 5π/2 The area A enclosed between the curves from x = α₁ to x = α₁ is given by: β = ∫₀^(5π/2) |eˣ(sin x + cos x − 1)|dx We analyze the sign of sin x + cos x − 1 in the intervals (0, π/2), (π/2, 2π), and (2π, 5π/2). For x ∈ (0, π/2), sin x + cos x > 1 For x ∈ (π/2, 2π), sin x + cos x < 1 For x ∈ (2π, 5π/2), sin x + cos x > 1 Let I = ∫ eˣ(sin x + cos x − 1)dx. Using integration by parts or standard formulas, we get: ∫ eˣ sin x dx = −(e^x/2)(sin x + cos x) ∫ eˣ cos x dx = (e^x/2)(sin x − cos x) ⇒ ∫ eˣ(sin x + cos x)dx = −eˣ cos x Thus, I = −eˣ cos x + eˣ = eˣ(1 − cos x). Now, we evaluate the area β by splitting the integral: β = ∫₀^(π/2) eˣ(sin x + cos x − 1)dx − ∫_(π/2)^(2π) eˣ(sin x + cos x − 1)dx + ∫_(2π)^(5π/2) eˣ(sin x + cos x − 1)dx β = [eˣ(1 − cos x)]₀^(π/2) − [eˣ(1 − cos x)]_(π/2)^(2π) + [eˣ(1 − cos x)]_(2π)^(5π/2) β = (e^(π/2) − 0) − (e^(2π) − e^(π/2)) + (e^(5π/2) − e^(2π)) β = 2e^(π/2) + e^(5π/2) We are required to find the value of −(1/π) log(β − 2e^(5π/2)). β − 2e^(π/2) = e^(5π/2) ⇒ −(1/π) log(e^(5π/2)) = −(1/π) × (5π/2) = −5/2 = 2.5 Answer: 2.5
