For the reaction – Fe4N(s) + (3/2)H2(g) ⇌ 2Fe(s) + NH3(g)

  1. (1) Kc = Kp(RT)
  2. (2) Kc = Kp(RT)^(-3/2)
  3. (3) Kc = Kp(RT)^(-1/2)
  4. (4) Kc = Kp(RT)^(1/2)

Answer

Correct answer: Option 4

Solution

To find the relationship between Kc and Kp, we use the equation: Kp = Kc(RT)^(Δn) where Δn = (moles of gaseous products) - (moles of gaseous reactants) From the reaction: Fe4N(s) + (3/2)H2(g) ⇌ 2Fe(s) + NH3(g) Gaseous products: NH3 = 1 mole Gaseous reactants: H2 = 3/2 moles Δn = 1 - 3/2 = -1/2 Therefore: Kp = Kc(RT)^(-1/2) Solving for Kc: Kc = Kp(RT)^(1/2) Alternatively, using Kp = Kc(RT)^(Δn): Kc = Kp/(RT)^(Δn) = Kp(RT)^(-Δn) = Kp(RT)^(1/2)
