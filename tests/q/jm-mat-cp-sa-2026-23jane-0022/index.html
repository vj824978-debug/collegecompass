If the image of the point P(a,2,a) in the line x/2 = (y+a)/1 = z/1 is Q and the of the image of Q in the line (x-2b)/2 = (y-a)/1 = (z+2b)/(-5) is P', then a + b is equal to.

Answer

Correct answer: 3

Solution

Q. (4λ-a, 2λ-2a-2, 2λ-a) Now, (x-2b)/2 = (y-a)/1 = (z+2b)/(-5) Point P' lies on this line: P'(2μ+2b, μ+a, -5μ-2b) and (a+4λ-a)/2 = 2μ+2b and (2λ-2a-2+2)/2 = μ+a and (2λ-a+a)/2 = -5μ-2b ⟹ λ-μ = b λ-μ = 2a λ+5μ = -2b ⟹ b = 2a and λ = a, μ = -a P(a, 2, a) x/2 = (y+a)/1 = z/1 = 2i + j + k (2λ, λ-a, λ) For λ = a (2a, 0, a) (ai-2j+0k)·(2i+j+k) = 0 2a-2 = 0 a = 1 b = 2a = 2×1 = 2 a+b = 1+2 = 3
