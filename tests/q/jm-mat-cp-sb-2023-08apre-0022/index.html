Let the area enclosed by the lines x + y = 2, y = 0, x = 0 and the curve f(x) = min{x^2 + 3/4, 1 + [x]}, where [x] denotes the greatest integer <= x, be A. Then the value of 12A is ________.

Answer

Correct answer: 17

Solution

The area is calculated by splitting the region into parts. From x = 0 to x = 1/2, the curve follows y = x^2 + 3/4. From x = 1/2 to x = 2, the curve follows y = 1 + [x] = 1 (for 0 < x < 1) and y = 2 (for 1 <= x < 2). The total area A is computed as: A = integral from 0 to 1/2 of (x^2 + 3/4) dx + (1/2)(1/2 + 3/2) × 1 = 5/12 + 1 = 17/12. Therefore, 12A = 17.
