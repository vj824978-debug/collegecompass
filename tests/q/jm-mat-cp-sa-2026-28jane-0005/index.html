Let f(x) = lim_{theta->0} [cos(theta*x) - x*sin(x-1)] / [1 + x^(2/theta)](x-1), x in R. Consider the following two statements: (I) f(x) is discontinuous at x = 1. (II) f(x) is continuous at x = -1. Then,

  1. (1) Neither (I) nor (II) is True
  2. (2) Both (I) and (II) are True
  3. (3) Only (II) is True
  4. (4) Only (I) is True

Answer

Correct answer: Option 1

Solution

f(x) = {cos(pi*x), x -> 1^-, 0 < x < 1 -> x^infinity = 0; x = 1 -> x^infinity = 1; x > 1 -> x^infinity = infinity; -sin(x-1)/(x-1), x -> 1^+} RHL = lim_{x->1^+} [-sin(x-1)/(x-1)] = -1 LHL = lim_{x->1^-} cos(pi*x) = -1, f(1) = -1 f(x) is continuous at x = 1 f(x) = {-sin(x-1)/(x-1), x -> -1^-; cos(pi*x), x -> -1^+} RHL = lim_{x->-1^+} cos(pi*x) = -1 LHL = lim_{x->-1^-} [-sin(x-1)/(x-1)] = sin(2)/(-2) = -sin(2)/2 f(x) is discontinuous at x = -1 Therefore, neither (I) nor (II) is true.
