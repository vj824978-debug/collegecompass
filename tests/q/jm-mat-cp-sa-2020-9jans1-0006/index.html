If x = sum_{n=0}^{infinity} (-1)^n tan^(2n) theta and y = sum_{n=0}^{infinity} cos^(2n) theta, for 0 < theta < pi/4, then

  1. (1) y(1 - x) = 1
  2. (2) x(1 - y) = 1
  3. (3) y(1 + x) = 1
  4. (4) x(1 + y) = 1

Answer

Correct answer: Option 1

Solution

x = sum_{n=0}^{infinity} (-1)^n tan^(2n) theta => x = 1 - tan^2(theta) + tan^4(theta) - tan^6(theta) ...... This is a geometric series with first term 1 and common ratio -tan^2(theta) => x = 1/(1 + tan^2(theta)) = cos^2(theta) ....(1) and y = sum_{n=0}^{infinity} cos^(2n) theta y = 1 + cos^2(theta) + cos^4(theta) + cos^6(theta) + .... This is a geometric series with first term 1 and common ratio cos^2(theta) y = 1/(1 - cos^2(theta)) = 1/sin^2(theta) => sin^2(theta) = 1/y .....(2) Adding (1) & (2), we get, cos^2(theta) + sin^2(theta) = x + 1/y 1 = x + 1/y => x + 1/y = 1 Multiplying by y: xy + 1 = y => y - xy = 1 => y(1 - x) = 1
