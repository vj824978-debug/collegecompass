Match the List-I with List-II. List-I contains Redox Reactions: (A) CH4(g) + 2O2(g) → CO2(g) + 2H2O(l), (B) 2NaH(s) → 2Na(s) + H2(g), (C) V2O5(s) + 5Ca(s) → 2V(s) + 5CaO(s), (D) 2H2O2(aq) → 2H2O(l) + O2(g). List-II contains Type of Redox Reaction: (I) Disproportionation reaction, (II) Combustion reaction, (III) Decomposition reaction, (IV) Displacement reaction.

  1. (1) A-II, B-III, C-IV, D-I
  2. (2) A-II, B-III, C-I, D-IV
  3. (3) A-III, B-IV, C-I, D-II
  4. (4) A-IV, B-I, C-II, D-III

Answer

Correct answer: Option 1

Solution

(A) Combustion of hydrocarbon: CH4(g) + 2O2(g) → CO2(g) + 2H2O(l) is a combustion reaction where hydrocarbons burn in oxygen to produce CO2 and H2O. This matches with (II) Combustion reaction. (B) Decomposition into gaseous product: 2NaH(s) → 2Na(s) + H2(g) is a decomposition reaction where a single compound breaks down into simpler products. This matches with (III) Decomposition reaction. (C) Displacement of 'V' by 'Ca' atom: V2O5(s) + 5Ca(s) → 2V(s) + 5CaO(s) is a displacement reaction where calcium displaces vanadium from vanadium oxide. This matches with (IV) Displacement reaction. (D) Disproportionation of H2O2 into O^(-2) and O^(0) oxidation states: 2H2O2(aq) → 2H2O(l) + O2(g) is a disproportionation reaction where hydrogen peroxide undergoes both oxidation and reduction simultaneously (oxygen goes from -1 to 0 and -2 states). This matches with (I) Disproportionation reaction. Therefore: A-II, B-III, C-IV, D-I
