Let A, B and C be three events such that the probability that exactly one of A and B occurs is (1 - k), the probability that exactly one of B and C occurs is (1 - 2k), the probability that exactly one of C and A occurs is (1 - k) and the probability that all A, B and C occur simultaneously is k^2, where 0 < k < 1. Then the probability that at least one of A, B and C occur is

  1. (1) greater than 1/2
  2. (2) greater than 1/4 but less than 1/2
  3. (3) exactly equal to 1/2
  4. (4) greater than 1/8 but less than 1/4

Answer

Correct answer: Option 1

Solution

From given conditions: P(A ∩ B) + P(A ∩ B) = 1 - k, P(B ∩ C) + P(B ∩ C) = 1 - 2k, P(C ∩ A) + P(C ∩ A) = 1 - k, P(A ∩ B ∩ C) = k^2. Using P(A) + P(B) - 2P(A ∩ B) = 1 - k, P(B) + P(C) - 2P(B ∩ C) = 1 - k, P(A) + P(C) - 2P(A ∩ C) = 1 - 2k. Adding these equations and using the constraint that P(A ∪ B ∪ C) = (4k + 3)/2 - k^2 = (2k - 1)^2 + 1)/2, we get P(A ∪ B ∪ C) > 1/2.
