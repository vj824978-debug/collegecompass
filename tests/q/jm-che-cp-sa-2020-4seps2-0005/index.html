The shortest wavelength of H atoms in the Lyman series is λ₁. The longest wavelength in the Balmer series of He⁺ is :

  1. (1) 9λ₁/5
  2. (2) 27λ₁/5
  3. (3) 36λ₁/5
  4. (4) 5λ₁/9

Answer

Correct answer: Option 1

Solution

As we know ΔE = hc/λ So λ = hc/ΔE for λ minimum i.e. shortest; ΔE = maximum for Lyman series n = 1 & for ΔE_max Transition must be form n = ∞ to n = 1 So 1/λ = R_H Z²[1/n₁² - 1/n₂²] 1/λ = R_H Z²(1 - 0) 1/λ₁ = R × (1)² ⇒ λ₁ = 1/R For longest wavelength ΔE = minimum for Blamer series n = 3 to n = 2 will have ΔE minimum for He⁺ Z = 2 So 1/λ₂ = R_H × Z²[1/n₁² - 1/n₂²] 1/λ₂ = R_H × 4[1/4 - 1/9] 1/λ₂ = R_H × 5/9 λ₂ = λ₁ × 9/5
