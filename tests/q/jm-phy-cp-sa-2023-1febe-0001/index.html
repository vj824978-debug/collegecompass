Figures (a), (b), (c) and (d) show variation of force with time. The impulse is highest in

  1. (1) Fig. (d)
  2. (2) Fig. (c)
  3. (3) Fig. (b)
  4. (4) Fig (a)

Answer

Correct answer: Option 3

Solution

Impulse is defined as the area under the (F-t) graph, i.e., Impulse = integral of F dt over time. Calculating impulse for each graph: Fig (a): Triangular shape with base = 1.0 s and height = 0.5 N Impulse (a) = (1/2) × base × height = (1/2) × 1.0 × 0.5 = 0.25 N·s Fig (b): Rectangular shape with width = 2.0 s and height = 0.5 N Impulse (b) = width × height = 2.0 × 0.5 = 1.0 N·s Fig (c): Triangular shape with base = 1.0 s and height = 0.75 N Impulse (c) = (1/2) × base × height = (1/2) × 1.0 × 0.75 = 0.375 N·s Fig (d): Triangular shape with base = 2.0 s and height = 0.5 N Impulse (d) = (1/2) × base × height = (1/2) × 2.0 × 0.5 = 0.5 N·s Comparing all impulses: Impulse (b) = 1.0 N·s (maximum) Impulse (d) = 0.5 N·s Impulse (c) = 0.375 N·s Impulse (a) = 0.25 N·s Therefore, impulse is maximum for Fig. (b).
