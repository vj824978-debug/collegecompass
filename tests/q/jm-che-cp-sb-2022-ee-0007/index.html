Which of the following chemical reactions represents Hall-Heroult Process? (1) Cr2O3 + 2Al → Al2O3 + 2Cr (2) 2Al2O3 + 3C → 4Al + 3CO2 (3) FeO + CO → Fe + CO2 (4) [2Au(CN)2]_(aq) + Zn(S) → 2Au(s) + [Zn(CN4)]^2

  1. (1) Cr2O3 + 2Al → Al2O3 + 2Cr
  2. (2) 2Al2O3 + 3C → 4Al + 3CO2
  3. (3) FeO + CO → Fe + CO2
  4. (4) [2Au(CN)2]_(aq) + Zn(S) → 2Au(s) + [Zn(CN4)]^2

Answer

Correct answer: Option 2

Solution

Hall-Heroult process is used for the extraction of aluminium by electrolysis of molten Al2O3. The reaction is 2Al2O3 + 3C → 4Al + 3CO2. This represents the industrial production of aluminium from its oxide using carbon electrodes.
