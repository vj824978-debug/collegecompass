Let |vector A₁| = 3, |vector A₂| = 5 and |vector A₁ + vector A₂| = 5. The value of (2vector A₁ + 3vector A₂) • (3vector A₁ - 2vector A₂) is -

  1. (1) -112.5
  2. (2) -106.5
  3. (3) -118.5
  4. (4) -99.5

Answer

Correct answer: Option 3

Solution

(2vector A₁ + 3vector A₂) • (3vector A₁ - 2vector A₂) = 6vector A₁² - 4vector A₁ • vector A₂ + 9vector A₁ • vector A₂ - 6vector A₂² = 6(vector A₁² - vector A₂²) + 5vector A₁ • vector A₂ cos(theta) = 6(9 - 25) + 5vector A₁vector A₂ cos(theta) = -96 + 5vector A₁vector A₂ cos(theta) Using |vector A₁ + vector A₂|² = vector A₁² + vector A₂² + 2vector A₁vector A₂ cos(theta): 25 = 9 + 25 + 2vector A₁vector A₂ cos(theta) 25 = 34 + 2vector A₁vector A₂ cos(theta) vector A₁vector A₂ cos(theta) = -9/2 = -96 + 5 × (-9/2) = -96 - 45/2 = -118.5
