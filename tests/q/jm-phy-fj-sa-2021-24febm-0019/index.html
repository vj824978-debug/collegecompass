If Y, K and n are the value of Young's modulus, bulk modulus of rigidity of any material respectively. Choose the correct relation for these parameters

  1. (1) Y = 9Kn/(2n + 3K) N/m²
  2. (2) K = Yn/(9n - 3Y) N/m²
  3. (3) n = 3YK/(9K + Y) N/m²
  4. (4) Y = 9Kn/(3K - n) N/m²

Answer

Correct answer: Option 2

Solution

Using Poisson's ratio relations: Y = 3K(1 - 2μ) and n = 2η(1 + μ). From these equations, we can derive: 3/Y - 1/n + 1/(3K) = K = ηY/(9η - 3Y). Testing the options against standard elasticity relations where Young's modulus, bulk modulus, and modulus of rigidity are related through Poisson's ratio, option (B) K = Yn/(9n - 3Y) is the correct relation.
