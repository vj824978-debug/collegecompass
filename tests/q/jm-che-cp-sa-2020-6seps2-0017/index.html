A set of solutions is prepared using 180 g of water as a solvent and 10 g of different non-volatile solutes A, B and C. The relative lowering of vapour pressure in the presence of these solutes are in the order [Given, molar mass of A = 100 g mol^(-1); B = 200 g mol^(-1); C = 10,000 g mol^(-1)]

  1. (1) A > B > C
  2. (2) A > C > B
  3. (3) C > B > A
  4. (4) B > C > A

Answer

Correct answer: Option 1

Solution

Relative lowering of V.P. = ΔP/p^0 = x_solute For solute A: (ΔP/p^0)_A = (10/100)/(10/100 + 180/18) = (10/100)/(10/100 + 10) = (10/100)/(10/100 + 180/18) For solute B: (ΔP/p^0)_B = (10/200)/(10/200 + 180/18) For solute C: (ΔP/p^0)_C = (10/10,000)/(10/10,000 + 180/18) Since the number of moles is inversely proportional to molar mass for a fixed mass (10 g), and the relative lowering of vapour pressure depends on the mole fraction of solute: For A: n_A = 10/100 = 0.1 mol For B: n_B = 10/200 = 0.05 mol For C: n_C = 10/10,000 = 0.001 mol Moles of water = 180/18 = 10 mol x_A = 0.1/(0.1 + 10) = 0.1/10.1 x_B = 0.05/(0.05 + 10) = 0.05/10.05 x_C = 0.001/(0.001 + 10) = 0.001/10.001 Clearly, x_A > x_B > x_C Therefore, (ΔP/p^0)_A > (ΔP/p^0)_B > (ΔP/p^0)_C Hence A > B > C
