Let w = zz + k₁z + k₂iz + λ(1 + i), k₁, k₂ ∈ R. Let Re(w) = 0 be the circle C of radius 1 in the first quadrant touching the line y = 1 and the y-axis. If the curve Im(w) = 0 intersects C at A and B, then 30(AB)^2 is equal to ______.

Answer

Correct answer: 24

Solution

From Re(w) = 0: x^2 + y^2 + k₁x - k₂y + λ = 0. Circle C has radius 1, touches y = 1 and y-axis in first quadrant, so center is at (1, 0) with equation x^2 + y^2 - 2x - 4y + 4 = 0. Comparing: k₁ = -2, k₂ = 4, λ = 4. From Im(w) = 0: k₁y + k₂x + λ = 0 becomes -2y + 4x + 4 = 0 or -2y + 4x + 4 = 0. This line intersects circle C at points (0, 2) and (2/5, 14/5). Distance AB = sqrt((2/5)^2 + (14/5 - 2)^2) = sqrt(4/25 + 16/25) = sqrt(20/25) = 2/sqrt(5). Therefore 30(AB)^2 = 30 × 4/5 = 24.
