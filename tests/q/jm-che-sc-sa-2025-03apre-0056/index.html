Fat soluble vitamins are: A. Vitamin B1, B. Vitamin C, C. Vitamin E, D. Vitamin B12, E. Vitamin K. Choose the correct answer from the options given below:

  1. (1) B & C only
  2. (2) C & D only
  3. (3) A & B only
  4. (4) C & E only

Answer

Correct answer: Option 4

Solution

Fat soluble vitamins are those that dissolve in fats and are stored in body tissues. These include Vitamin A, D, E, and K. From the given options: Vitamin B1 (water soluble), Vitamin C (water soluble), Vitamin E (fat soluble), Vitamin B12 (water soluble), Vitamin K (fat soluble). Therefore, the correct answer is C & E only.
