Three rotten apples are accidentally mixed with fifteen good apples. Assuming the random variable x to be the number of rotten apples in a draw of two apples, the variance of x is

  1. (1) 57/153
  2. (2) 37/153
  3. (3) 47/153
  4. (4) 40/153

Answer

Correct answer: Option 4

Solution

Total apples = 18 (3 rotten + 15 good). Drawing 2 apples, x can be 0, 1, or 2. P(X=0) = C(15,2)/C(18,2) = 35/51. P(X=1) = C(3,1)*C(15,1)/C(18,2) = 15/51. P(X=2) = C(3,2)/C(18,2) = 1/51. E(X) = 0*(35/51) + 1*(15/51) + 2*(1/51) = 17/51. E(X^2) = 0*(35/51) + 1*(15/51) + 4*(1/51) = 19/51. Variance = E(X^2) - [E(X)]^2 = 19/51 - (17/51)^2 = 19/51 - 289/2601 = (19*51 - 289)/2601 = (969 - 289)/2601 = 680/2601 = 40/153.
