Match List-I with List-II.

  1. (1) (A)-II, (B)-I, (C)-IV, (D)-III
  2. (2) (A)-III, (B)-I, (C)-II, (D)-IV
  3. (3) (A)-III, (B)-I, (C)-IV, (D)-II
  4. (4) (A)-I, (B)-II, (C)-IV, (D)-III

Answer

Correct answer: Option 2

Solution

Narrow spectrum antibiotic → Penicillin G Antiseptic → Furacin Disinfectants → Sulphur dioxide Broad spectrum antibiotic → chloramphenicol ∴ Correct matching is : A → III, B → I, C → II, D → IV
