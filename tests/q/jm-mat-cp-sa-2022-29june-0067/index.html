Let f be a real valued continuous function on [0, 1] and f(x) = x + ∫(x-t)f(t)dt from 0 to x. Then, which of the following points (x, y) lies one the curve y = f(x)?

  1. (1) (2, 4)
  2. (2) (1, 2)
  3. (3) (4, 17)
  4. (4) (6, 8)

Answer

Correct answer: Option 4

Solution

Starting with f(x) = x + ∫(x-t)f(t)dt from 0 to x, expand to get f(x) = x + x∫f(t)dt - ∫tf(t)dt. Let a = 1 + ∫f(t)dt and b = ∫tf(t)dt, so f(x) = ax - b. Using the constraint that a = 1 + ∫(at-b)dt = 1 + a/2 - b, we get a/2 + b = 1. From b = ∫(at-b)dt = a/3 - b/2, we get 3b/2 = a/3, so b = 2a/9. Substituting: a/2 + 2a/9 = 1, which gives 9a + 4a = 18, so a = 18/13 and b = 4/13. Therefore f(x) = (18x - 4)/13. Checking option (4): f(6) = (18(6) - 4)/13 = (108 - 4)/13 = 104/13 = 8. ✓
