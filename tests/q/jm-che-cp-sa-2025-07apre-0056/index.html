A(g) → B(g) + C(g) is a first order reaction. The reaction was started with reactant A only. At time t, pressure is pt and at time infinity, pressure is p_infinity. Which of the following expression is correct for rate constant k?

  1. (1) k = (1/t) ln(p_infinity/pt)
  2. (2) k = (1/t) ln(p_infinity/(p_infinity - pt))
  3. (3) k = (1/t) ln(2(p_infinity - pt)/pt)
  4. (4) k = (1/t) ln(p_infinity/(2(p_infinity - pt)))

Answer

Correct answer: Option 4

Solution

For first order reaction A(g) → B(g) + C(g): At t=0, pressure = p0 (only A); At t=t, pressure = pt = p0 - p + p = p0 where p is pressure of products; At t=∞, p_infinity = p0 + p0 = 2p0. From stoichiometry: p0 - p = pt and 2p0 = p_infinity, so p0 = p_infinity/2. Therefore p = p_infinity/2 - pt. For first order: k = (1/t) ln([A]0/[A]t) = (1/t) ln(p0/(p0-p)) = (1/t) ln(p_infinity/(2(p_infinity - pt)))
