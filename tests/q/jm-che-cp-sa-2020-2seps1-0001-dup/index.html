If |x| < 1, |y| < 1 and x ≠ y, then the sum to infinity of the following series (x + y) + (x^2 + xy + y^2) + (x^3 + x^2y + xy^2 + y^3) + ......

  1. (1) (x + y - xy)/((1 - x)(1 - y))
  2. (2) (x + y - xy)/((1 + x)(1 + y))
  3. (3) (x + y + xy)/((1 + x)(1 + y))
  4. (4) (x + y + xy)/((1 - x)(1 - y))

Answer

Correct answer: Option 1

Solution

|x| < 1, |y| < 1, x ≠ y (x + y) + (x^2 + xy + y^2) + (x^3 + x^2y + xy^2 + y^3) + ........ By multiplying and dividing x - y: [(x^2 - y^2) + (x^3 - y^3) + (x^4 - y^4) + .....] / (x - y) = [(x^2 + x^3 + x^4 + ......) - (y^2 + y^3 + y^4 + .....)] / (x - y) = [x^2/(1 - x) - y^2/(1 - y)] / (x - y) = [(x^2(1 - y) - y^2(1 - x)) / ((1 - x)(1 - y))] / (x - y) = [x^2 - x^2y - y^2 + xy^2] / [(1 - x)(1 - y)(x - y)] = [(x^2 - y^2) - xy(x - y)] / [(1 - x)(1 - y)(x - y)] = [(x - y)(x + y) - xy(x - y)] / [(1 - x)(1 - y)(x - y)] = (x + y - xy) / [(1 - x)(1 - y)]
