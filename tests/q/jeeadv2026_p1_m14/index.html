Match each entry in List-I to the correct entry in List-II and choose the correct option. List-I: (P) The number of elements in the set {x ∈ [-π, π] : sin⁸ x + cos⁴ x = 1} (Q) The number of elements in the set {x ∈ [-π/2, π/2] : sin² x + cos⁶ x = 1} (R) The number of elements in the set {x ∈ [-π, π] : cos²(x/2) - sin² x = 1/2} (S) The number of elements in the set {x ∈ [-2π, 2π] : 6 sin²(x/2) - cos 3x = 3} List-II: (1) is 1 (2) is 2 (3) is 3 (4) is 4 (5) is 5

Matrix match · Marks: +4 / -1.0

  1. (A) (P) → (2), (Q) → (5), (R) → (3), (S) → (4)
  2. (B) (P) → (5), (Q) → (3), (R) → (2), (S) → (4)
  3. (C) (P) → (5), (Q) → (4), (R) → (1), (S) → (3)
  4. (D) (P) → (4), (Q) → (3), (R) → (2), (S) → (5)

Answer

Correct answer: B

Solution

Solution: For (P): sin⁶ x + cos⁴ x = 1 sin⁶ x + (1 - sin² x)² = 1 sin⁶ x + 1 - 2 sin² x + sin⁴ x = 1 sin² x(sin⁴ x + sin² x - 2) = 0 sin² x(sin² x - 1)(sin² x + 2) = 0 This gives sin² x = 0 or sin² x = 1. In the interval [-π, π], the solutions are x ∈ {-π, -π/2, 0, π/2, π}. Number of solutions = 5. For (Q): sin² x + cos⁸ x = 1 1 - cos² x + cos⁸ x = 1 cos⁸ x(cos⁴ x - 1) = 0 This gives cos² x = 0 or cos² x = 1. In the interval [-π/2, π/2], the solutions are x ∈ {-π/2, 0, π/2}. Number of solutions = 3. For (R): cos²(x/2) - sin² x = 1/2 (1 + cos x)/2 - (1 - cos² x) = 1/2 1 + cos x - 2 + 2cos² x = 1 2cos² x + cos x - 2 = 0 Solving the quadratic equation for cos x, we get: cos x = (-1 ± √17)/4 Since cos x ∈ [-1, 1], we reject the negative root. Thus, cos x = (√17 - 1)/4. Since 0 < (√17 - 1)/4 < 1, there are exactly 2 solutions in [-π, π]. Number of solutions = 2. For (S): 6 sin²(x/2) - cos 3x = 3 3(1 - cos x) - (4cos³ x - 3 cos x) = 3 3 - 3 cos x - 4cos³ x + 3 cos x = 3 -4cos³ x = 0 ⇒ cos x = 0 In the interval [-2π, 2π], the solutions are x ∈ {-3π/2, -π/2, π/2, 3π/2}. Number of solutions = 4. Therefore, the correct matching is (P) → (5), (Q) → (3), (R) → (2), (S) → (4). Answer: (P) → (5), (Q) → (3), (R) → (2), (S) → (4)
