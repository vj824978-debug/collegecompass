A long straight wire of a circular cross-section with radius 'a' carries a steady current I. The current I is a uniformly distributed across this cross-section. The plot of magnitude of magnetic field B with distance r from the centre of the wire is given by:

  1. (1) Graph (1): B increases linearly from origin to point a, then decreases with r after point a
  2. (2) Graph (2): B has a discontinuity at r = a, constant before a, then decreases after a
  3. (3) Graph (3): B has maximum at r = 0, decreases continuously, with a marked change in slope at r = a
  4. (4) Graph (4): B is constant from 0 to a, then decreases after point a

Answer

Correct answer: Option 1

Solution

For a long straight wire carrying uniformly distributed current I: Inside the wire (r < a): Using Ampere's law for a circular path of radius r: B(2πr) = μ₀ * I_enclosed Since current is uniformly distributed: I_enclosed = I * (r²/a²) Therefore: B = (μ₀Ir)/(2πa²) This shows B ∝ r (linear relationship) At r = 0: B = 0 At r = a: B = (μ₀I)/(2πa) Outside the wire (r > a): Using Ampere's law: B(2πr) = μ₀I Therefore: B = (μ₀I)/(2πr) This shows B ∝ 1/r (inverse relationship) At r = a: B = (μ₀I)/(2πa) (continuous) As r → ∞: B → 0 Characteristics of B vs r graph: 1. For r < a: B increases linearly from 0 to (μ₀I)/(2πa) 2. For r > a: B decreases hyperbolically as 1/r 3. At r = a: B is continuous but has a change in slope (derivative discontinuity) 4. The graph reaches maximum at r = a This matches Graph (1), which shows linear increase up to 'a' followed by hyperbolic decrease.
