In the given circuit, the AC source has ω = 100 rad/s. considering the inductor and capacitor to be ideal, the correct choice (s) is(are) [Circuit diagram showing: 20V AC source connected to a circuit with 100μF capacitor in series with 100Ω resistor on top branch, 0.5H inductor in series with 50Ω resistor on bottom branch, with current I marked]

Multiple correct (MSQ) · Marks: +4 / -1.0

  1. (A) The current through the circuit, I is 0.3 A
  2. (B) The current through the circuit, I is 0.3√2 A
  3. (C) The voltage across 100Ω resistor = 10√2 V
  4. (D) The voltage across 50Ω resistor = 10V

Answer

Correct answer: AC

Solution

C = 100 μF, 1/(ωC) = 1/((100)(100 × 10⁻⁶)) X_c = 100 Ω, X_L = ωL = (100)(.5) = 50 Ω Z₁ = √(X_c² + 100²) = 100√(2Ω) Z₂ = √(X_L² + 50²) = √(50² + 50²) = 50√2 ε = 20√2 sin ωt i₁ = (20√2)/(100√2) sin (ωt + π/4) i₁ = (1/5) sin (ωt + π/4) i₂ = (20√2)/(50√2) sin (ωt - π/4) I = √((2)² + (.4)²) = (.2)√(1 + 4) = (1/5)√5 = 1/√5 (I)_rms = 1/(√2√5) = 1/√10 = √10/10 ≈ 0.3 A (V_100Ω)_rms = (I₁)_rms × 100 = (0.2/√2) × 100 = 20/√2 = 10√2 V V_50Ω)_rms = (0.4/√2) × 50 = 20/√2 = 10√2 V Since I_rms ≈ 0.3 A so A may or may not be correct.
