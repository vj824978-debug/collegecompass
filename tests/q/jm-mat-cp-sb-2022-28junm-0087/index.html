Let A = {1, a1, a2,...,a18, 77} be a set of integers with 1 < a1 < a2 < ... < a18 < 77. Let the set A + A = {x + y : x, y ∈ A} contain exactly 39 elements. Then, the value of a1 + a2 + ... + a18 is equal to ____.

Answer

Correct answer: 702.00

Solution

If elements of A + A contain exactly 39 distinct elements, we can find them as: 1 + 1, 1 + a1, 1 + a2,..., 1 + a18, 1 + 77, a1 + 77, a2 + 77,..., a18 + 77, 77 + 77. All other sums must already be present in these 39 values, which is only possible if all numbers are in A.P. with common difference d. Given 77 = 1 + 19d, we get d = 4. So A = {1, 5, 9, 13, ..., 73, 77}. Sum = (18/2)[2a1 + 17d] = 9[10 + 68] = 702.
