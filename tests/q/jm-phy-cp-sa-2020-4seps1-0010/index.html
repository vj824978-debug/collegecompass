For a transverse wave travelling along a straight line, the distance between two peaks (crests) is 5m, while the distance between one crest and one trough is 1.5 m. The possible wavelengths (in m) of the waves are

  1. (1) 1, 2, 3, .....
  2. (2) 1/1, 1/3, 1/5, .....
  3. (3) 1/2, 1/4, 1/6, .....
  4. (4) 1, 3, 5, .....

Answer

Correct answer: Option 2

Solution

Given T to C = 1.5 m C to C = 5m T to C = (2n₁ + 1) lambda/2 C to C = n₂*lambda 1.5/5 = (2n₁ + 1)/(2n₂) => 3n₂ = 10n₁ + 5 n₁ = 1 ; n₂ = 5 => lambda = 1 n₁ = 4 ; n₂ = 15 => lambda = 1/3 n₁ = 7 ; n₂ = 25 => lambda = 1/5
