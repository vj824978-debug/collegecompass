For a first order reaction, the ratio of the time for 75% completion of a reaction to the time for 50% completion is _______ (Integer answer)

Answer

Correct answer: 2

Solution

For a first order reaction, t = (2.303/k) * log(C0/(C0-x)). For 75% completion: t75% = (2.303/k) * log(C0/(C0/4)) = (2 × 2.303/k) * log2. For 50% completion: t50% = (2.303/k) * log(C0/(C0/2)) = (2.303/k) * log2. Therefore, t75%/t50% = 2.
