Let σ be the uniform surface charge density of two infinite thin plane sheets shown in figure. Then the electric fields in three different region E_I, E_II and E_III are:

  1. (1) E_I = 0, E_II = σ/ε_0 n̂, E_III = 0
  2. (2) E_I = -σ/ε_0 n̂, E_II = 0, E_III = σ/ε_0 n̂
  3. (3) E_I = 2σ/(2ε_0) n̂, E_II = 0, E_III = 2σ/ε_0 n̂
  4. (4) E_I = -σ/(2ε_0) n̂, E_II = 0, E_III = σ/ε_0 n̂

Answer

Correct answer: Option 2

Solution

From the figure: E_1 = σ/(2ε_0) + σ/(2ε_0) (Leftward) E_2 = σ/(2ε_0) - σ/(2ε_0) E_3 = σ/(2ε_0) + σ/(2ε_0) (Rightward) For two infinite parallel sheets with same charge density σ: Each sheet produces electric field of magnitude σ/(2ε_0) perpendicular to it. In region I (left of both sheets): Both fields point leftward (away from positive charges), so E_I = σ/(2ε_0) + σ/(2ε_0) = σ/ε_0 pointing left, which is -σ/ε_0 n̂ (taking rightward as positive direction) In region II (between the sheets): Fields point in opposite directions and cancel, so E_II = σ/(2ε_0) - σ/(2ε_0) = 0 In region III (right of both sheets): Both fields point rightward (away from positive charges), so E_III = σ/(2ε_0) + σ/(2ε_0) = σ/ε_0 pointing right, which is σ/ε_0 n̂ Therefore: E_I = -σ/ε_0 n̂, E_II = 0, E_III = σ/ε_0 n̂
