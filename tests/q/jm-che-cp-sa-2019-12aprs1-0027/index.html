An example of a disproportionation reaction is:

  1. (1) 2NaBr + Cl2 -----> 2NaCl + Br2
  2. (2) 2KMnO4 -----> 2KMnO4 + MnO2 + O2
  3. (3) 2CuBr -----> CuBr2 + Cu
  4. (4) 2MnO4^- + 10I^- + 16H^+ -----> 2Mn^(2+) + 5I2 + 8H2O

Answer

Correct answer: Option 3

Solution

A disproportionation reaction is one in which a single element in one oxidation state is converted into two different oxidation states (one higher and one lower). Let's analyze each option: (1) 2NaBr + Cl2 -----> 2NaCl + Br2 Here, Br^- (oxidation state -1) is oxidized to Br2 (oxidation state 0). Cl2 (oxidation state 0) is reduced to Cl^- (oxidation state -1). This is a redox reaction but not a disproportionation because the same element doesn't appear in multiple oxidation states on the same side. (2) 2KMnO4 -----> 2KMnO4 + MnO2 + O2 This equation is not balanced and seems incorrect. It shows the same compound on both sides which doesn't make sense. (3) 2CuBr -----> CuBr2 + Cu Cu in CuBr has oxidation state +1. On the right side: - In CuBr2, Cu has oxidation state +2 - In Cu, Cu has oxidation state 0 So Cu^+ is simultaneously oxidized to Cu^(2+) and reduced to Cu^0. This is a disproportionation reaction as Cu appears in three different oxidation states: +1 (reactant), +2 and 0 (products). (4) 2MnO4^- + 10I^- + 16H^+ -----> 2Mn^(2+) + 5I2 + 8H2O Here MnO4^- (Mn has +7) is reduced to Mn^(2+) (+2), and I^- (-1) is oxidized to I2 (0). Different elements are undergoing oxidation and reduction, so this is not a disproportionation reaction. Therefore, option (3) is the correct answer.
