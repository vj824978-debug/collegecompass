Which of the following gives a reversible operation?

  1. (1) OR gate with 2 inputs and 1 output
  2. (2) OR gate with 2 inputs and 1 output
  3. (3) AND gate with 2 inputs and 1 output
  4. (4) NAND gate with 2 inputs and 1 output

Answer

Correct answer: Option 4

Solution

A reversible operation is one where the output uniquely determines the input. In other words, given the output, we can uniquely recover the input. Let us analyze each gate: (1) OR gate: For inputs A and B, output B = A OR (something). This is not reversible because multiple input combinations can produce the same output. For example, (0,1) and (1,1) both give output 1. (2) OR gate: Same as (1), not reversible. (3) AND gate: For inputs A and B, output B = A AND (something). This is not reversible because multiple input combinations produce the same output. For example, (0,0), (0,1), and (1,0) all give output 0. (4) NAND gate: This behaves as a NOT gate. The truth table is: A | B 0 | 1 1 | 0 For each output value, there is exactly one input value that produces it. If output is 1, input must be 0. If output is 0, input must be 1. Therefore, given the output, we can uniquely determine the input. It will behave as a NOT gate. Hence gives reversible operation.
