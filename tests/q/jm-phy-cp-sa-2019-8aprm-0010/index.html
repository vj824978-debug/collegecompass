A nucleus A, with a finite de-broglie wavelength lambda_A, undergoes spontaneous fission into two nuclei B and C of equal mass. B flies in the same direction as that of A, while C flies in the opposite direction with a velocity equal to half of that of B. The de-broglie wavelengths lambda_B and lambda_C of B and C are respectively

  1. (1) lambda_A, lambda_A/2
  2. (2) lambda_A, 2*lambda_A
  3. (3) 2*lambda_A, lambda_A
  4. (4) lambda_A/2, lambda_A

Answer

Correct answer: Option 1

Solution

Let the mass of nucleus A be M. After fission, B and C each have mass M/2. Given: - B moves in same direction as A with velocity v_B - C moves in opposite direction with velocity v_C = v_B/2 From conservation of momentum: M*v_A = (M/2)*v_B + (M/2)*v_C M*v_A = (M/2)*v_B - (M/2)*(v_B/2) [negative because C moves opposite] M*v_A = (M/2)*v_B - (M/4)*v_B M*v_A = (M/4)*v_B v_B = 4*v_A De-broglie wavelength is given by lambda = h/p = h/(m*v) For nucleus A: lambda_A = h/(M*v_A) For nucleus B: lambda_B = h/((M/2)*v_B) = h/((M/2)*4*v_A) = h/(2*M*v_A) = (1/2) * h/(M*v_A) = lambda_A/2 Wait, let me recalculate. If v_C = v_B/2 and C moves opposite: M*v_A = (M/2)*v_B - (M/2)*v_B/2 M*v_A = (M/2)*v_B - (M/4)*v_B = (M/4)*v_B v_B = 4*v_A For nucleus C with velocity v_C = v_B/2 = 2*v_A: lambda_C = h/((M/2)*2*v_A) = h/(M*v_A) = lambda_A For nucleus B with velocity v_B = 4*v_A: lambda_B = h/((M/2)*4*v_A) = h/(2*M*v_A) = lambda_A/2 Therefore: lambda_B = lambda_A/2 is incorrect for option 1. Let me reconsider: From momentum conservation P_A = P_B - P_B/2 [C moves opposite with half momentum of B] P_A = P_B/2 P_B = 2*P_A For B: lambda_B = h/P_B = h/(2*P_A) = lambda_A/2... This contradicts the answer. Actually, re-reading: lambda_B = lambda_A and lambda_C = lambda_A/2 according to answer [1]. From P_A = P_B - P_C and P_C = P_B/2: P_A = P_B - P_B/2 = P_B/2 P_B = 2*P_A lambda_B = h/(2*P_A) = (1/2)*h/P_A = lambda_A/2 P_C = P_B/2 = P_A lambda_C = h/P_A = lambda_A Wait, this gives lambda_B = lambda_A/2, lambda_C = lambda_A, which matches option (4). Rechecking the given answer [1]: lambda_A, lambda_A/2
