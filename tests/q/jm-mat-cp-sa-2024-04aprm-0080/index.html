Let α ∈ (0, ∞) and A = [[1, 0, 1], [0, 1, 2]]. If det(adj(2A - A^T), adj(A - 2A^T)) = 2^8, then (det(A))^2 is equal to-

  1. (1) 1
  2. (2) 49
  3. (3) 16
  4. (4) 36

Answer

Correct answer: Option 3

Solution

adj(A - 2A^T) adj(2A - A^T) = 2^8. Using |A - 2A^T|^2 |2A - A^T|^2 = 2^8 and (A - 2A^T)^T = A^T - 2A, we get |A - 2A^T| = |A^T - 2A|. Computing A - 2A^T and 2A - A^T, then |A - 2A^T|^2 = 16. Thus |A - 2A^T| = ±4. Solving the system gives α = 1. With α = 1, det(A) = -4, so (det(A))^2 = 16.
