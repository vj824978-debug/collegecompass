Let E^C denote the complement of an event E. Let E₁, E₂ and E₃ be any pairwise independent events with P(E₁) > 0 and P(E₁ ∩ E₂ ∩ E₃) = 0. Then P(E₂^C ∩ E₃^C / E₁) is equal to:

  1. (1) P(E₃^C) - P(E₂)
  2. (2) P(E₂^C) + P(E₃)
  3. (3) P(E₃^C) - P(E₂^C)
  4. (4) P(E₃) - P(E₂^C)

Answer

Correct answer: Option 1

Solution

Given E₁, E₂, E₃ are pairwise independent events so P(E₁ ∩ E₂) = P(E₁).P(E₂) and P(E₂ ∩ E₃) = P(E₂).P(E₃) and P(E₃ ∩ E₁) = P(E₃).P(E₁) & P(E₁ ∩ E₂ ∩ E₃) = 0 Now P(E₂^C ∩ E₃^C / E₁) = P[E₁ ∩ (E₂^C ∩ E₃^C)] / P(E₁) = P(E₁) - [P(E₁ ∩ E₂) + P(E₁ ∩ E₃) - P(E₁ ∩ E₂ ∩ E₃)] / P(E₁) = [P(E₁) - P(E₁).P(E₂) - P(E₁)P(E₃) - 0] / P(E₁) = 1 - P(E₂) - P(E₃) = [1 - P(E₃) - P(E₂)] = P(E₃^C) - P(E₂)
