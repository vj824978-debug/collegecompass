Let [x] denote the greatest integer <= x. Consider the function f(x) = max{x^2, 1 + [x]}. Then the value of the integral ∫[0 to 2] f(x)dx is

  1. (1) (1 + 5√2)/3
  2. (2) (5 + 4√2)/3
  3. (3) (8 + 4√2)/3
  4. (4) (4 + 5√2)/3

Answer

Correct answer: Option 2

Solution

We need to find where x^2 = 1 + [x] to determine which function is the maximum in different intervals. For x ∈ [0, 1): [x] = 0, so 1 + [x] = 1. We need x^2 vs 1. At x = 1, x^2 = 1. For x ∈ [0, 1), x^2 ≤ 1, so f(x) = 1. For x ∈ [1, √2): [x] = 1, so 1 + [x] = 2. We need x^2 vs 2. At x = √2, x^2 = 2. For x ∈ [1, √2), x^2 < 2, so f(x) = 2. For x ∈ [√2, 2]: [x] = 1 for x ∈ [√2, 2), so 1 + [x] = 2. For x ∈ [√2, 2], x^2 ≥ 2, so f(x) = x^2. Therefore: f(x) = 1 for x ∈ [0, 1) f(x) = 2 for x ∈ [1, √2) f(x) = x^2 for x ∈ [√2, 2] ∴ ∫[0 to 2] f(x)dx = ∫[0 to 1] 1dx + ∫[1 to √2] 2dx + ∫[√2 to 2] x^2dx = 1 + 2(√2 - 1) + [x^3/3]|[√2 to 2] = 1 + 2√2 - 2 + (8/3 - (√2)^3/3) = 1 + 2√2 - 2 + 8/3 - 2√2/3 = 2√2 - 1 + 8/3 - 2√2/3 = 2√2 - 1 + (8 - 2√2)/3 = (5 + 4√2)/3
