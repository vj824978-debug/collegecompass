A simple pendulum, made of a string of length l and a bob of mass m, is released from a small angle theta_0. It strikes a block of mass M, kept on a horizontal surface at its lowest point of oscillations, elastically. It bounces back and goes up to an angle theta_1. Then M is given by:

  1. (1) m[(theta_0 + theta_1)/(2(theta_0 - theta_1))]
  2. (2) m[(theta_0 - theta_1)/(2(theta_0 + theta_1))]
  3. (3) m[(theta_0 + theta_1)/(theta_0 - theta_1)]
  4. (4) m[(theta_0 - theta_1)/(theta_0 + theta_1)]

Answer

Correct answer: Option 3

Solution

The pendulum bob of mass m is released from angle theta_0. At the lowest point, using conservation of energy: mgh = (1/2)mv^2, where h = l(1 - cos(theta_0)). So velocity at lowest point: v_0 = sqrt(2gl(1 - cos(theta_0))). After elastic collision with block M, the bob bounces back with velocity v_f and goes up to angle theta_1. Using conservation of energy for return motion: (1/2)mv_f^2 = mgl(1 - cos(theta_1)) So: v_f = sqrt(2gl(1 - cos(theta_1))) For elastic collision between m (velocity v_0) and M (initially at rest): v_f = [(m - M)/(m + M)]v_0 Therefore: sqrt(2gl(1 - cos(theta_1))) = [(m - M)/(m + M)]sqrt(2gl(1 - cos(theta_0))) Simplifying: sqrt(1 - cos(theta_1)) = [(m - M)/(m + M)]sqrt(1 - cos(theta_0)) Squaring: 1 - cos(theta_1) = [(m - M)/(m + M)]^2(1 - cos(theta_0)) Using approximation for small angles: 1 - cos(theta) ≈ theta^2/2 sin(theta_1/2) = [(m - M)/(m + M)]sin(theta_0/2) For small angles: theta_1/2 = [(m - M)/(m + M)](theta_0/2) Therefore: theta_1/theta_0 = (m - M)/(m + M) Cross-multiplying: theta_1(m + M) = theta_0(m - M) theta_1(m + M) = theta_0(m - M) (theta_1 + theta_0)/(theta_1 - theta_0) = M/(-m) (theta_0 + theta_1)/(theta_0 - theta_1) = M/m Therefore: M = m[(theta_0 + theta_1)/(theta_0 - theta_1)]
