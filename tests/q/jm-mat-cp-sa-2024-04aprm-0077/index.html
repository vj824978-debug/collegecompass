A square is inscribed in the circle x^2 + y^2 - 10x - 6y + 30 = 0. One side of this square is parallel to y = x + 3. If (x_i, y_i) are the vertices of the square, then Σ(x_i^2 + y_i^2) is equal to:

  1. (1) 148
  2. (2) 156
  3. (3) 160
  4. (4) 152

Answer

Correct answer: Option 4

Solution

Circle equation: x^2 + y^2 - 10x - 6y + 30 = 0. Rewrite as (x-5)^2 + (y-3)^2 = 4. Center: (5,3), Radius: 2. One side parallel to y = x + 3 means slope = 1. The square has sides at 45° to axes. Distance from center to side = 2/sqrt(2) = sqrt(2). Two opposite sides are y = x + c and x + y = d. Distance formula: |5 - 3 - c|/sqrt(2) = sqrt(2) gives c + 2 = 2, so c = 0 or -4. Distance formula: |8 + d|/sqrt(2) = sqrt(2) gives 8 + d = ±2, so d = -10 or -6. Using c = 0, d = -10: sides are y = x and x + y = -10. Vertices found: (5,5), (3,3), (7,3), (5,1). Calculate Σ(x_i^2 + y_i^2) = 25 + 25 + 9 + 9 + 49 + 9 + 25 + 1 = 152.
