100 g of propane is completely reacted with 1000 g of oxygen. The mole fraction of carbon dioxide in the resulting mixture is x × 10^(-2). The value of x is _______. (Nearest integer) [Atomic weight: H = 1.008; C = 12.00; O = 16.00]

Answer

Correct answer: 19

Solution

The reaction is C3H8(g) + 5O2(g) → 3CO2(g) + 4H2O(l). Moles of propane = 100/44 = 2.27 mol. Moles of oxygen = 1000/32 = 31.25 mol. At t=∞, propane is completely consumed (0 mol), oxygen remaining = 19.9 mol, CO2 produced = 6.81 mol, H2O produced = 9.08 mol. Total moles = 0 + 19.9 + 6.81 + 9.08 = 35.79 mol. Mole fraction of CO2 = 6.81/35.79 = 0.1902 = 19.02 × 10^(-2). Therefore, x = 19 (nearest integer).
