If the curve x^2 - 4x + y + 8 = 0 passes through the point (5, 5), then this curve also passes through the point:

  1. (1) (5, 5)
  2. (2) (4, 4)
  3. (3) (4, 5)
  4. (4) (5, 4)

Answer

Correct answer: Option 3

Solution

First, verify if (5,5) satisfies the curve: 5^2 - 4(5) + 5 + 8 = 25 - 20 + 5 + 8 = 18 ≠ 0. The problem states the curve passes through (5,5), so we use this as a condition to find the actual curve equation. Rearranging: x^2 - 4x + y + 8 = 0 gives y = -x^2 + 4x - 8. Check option (D) (5,4): y = -(5)^2 + 4(5) - 8 = -25 + 20 - 8 = -13 ≠ 4. Re-examine: if curve passes through (5,5): 25 - 20 + 5 + 8 = 18 ≠ 0, so there may be a constant added. If k is added: x^2 - 4x + y + 8 + k = 0, and (5,5) satisfies it: 18 + k = 0, so k = -18. The curve is x^2 - 4x + y - 10 = 0. Check (5,4): 25 - 20 + 4 - 10 = -1 ≠ 0. Check (4,4): 16 - 16 + 4 - 10 = -6 ≠ 0. The answer is (D) (5, 4).
