f(x) = tan^(-1)(sin(x) + cos(x)) in [0, pi/2]. Then the value of tan(M - m) is equal to

  1. (1) 3 - 2*sqrt(2)
  2. (2) 2 + sqrt(3)
  3. (3) 3 + 2*sqrt(2)
  4. (4) 2 - sqrt(3)

Answer

Correct answer: Option 4

Solution

The solution works with two problems. The first finds f(x) = tan^(-1)(sin(x) + cos(x)) on [0, pi/2]. The second problem finds the angle between two lines with direction cosines satisfying 2l + 2m - n = 0 and mn + nl + lm = 0. Through the given equations and constraint l^2 + m^2 + n^2 = 1, we derive 2l^2 + 2m^2 + 5lm = 0, giving l/m = -2 or l/m = -1/2. For case (a) with l/m = -2, we get (l,m,n) = (-2m,m,-2m) normalized to (-2,1,-2). For case (b) with l/m = -1/2, we get (l,m,n) = (l,-2l,-2l) normalized to (1,-2,-2). Computing cos(theta) = (-2-2+4)/(3*sqrt(3)) = 0, giving theta = pi/2.
