The parameters of the unit cell of substance are a = 2.5, b = 3.0, c = 4.0, alpha = 90°, beta = 120°, gamma = 90°. The crystal system of the substance is:

  1. (1) Monoclinic
  2. (2) Triclinic
  3. (3) Orthorhombic
  4. (4) Hexagonal

Answer

Correct answer: Option 1

Solution

To determine the crystal system, we analyze the unit cell parameters: a = 2.5, b = 3.0, c = 4.0 (all different), and angles alpha = 90°, beta = 120°, gamma = 90°. In a monoclinic system, two angles equal 90° and one angle is not 90°, with all three axes of different lengths. Here we have alpha = 90°, gamma = 90°, and beta = 120° (not 90°), with a ≠ b ≠ c. This matches the monoclinic crystal system definition.
