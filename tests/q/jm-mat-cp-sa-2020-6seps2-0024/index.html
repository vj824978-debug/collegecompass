Consider the data on x taking the values 0, 2, 4, 8, ..., 2^n with frequencies nC0, nC1, nC2, ..., nCn respectively. If the mean of this data is 728/2^n, then n is equal to ___________.

Answer

Correct answer: 6

Solution

We have data: x takes values 0, 2, 4, 8, ..., 2^n with frequencies nC0, nC1, nC2, ..., nCn respectively. Mean = (sum of x_i * f_i) / (sum of f_i) Numerator: sum from r=0 to n of 2^r * nCr Denominator: sum from r=0 to n of nCr = 2^n Using binomial theorem: sum from r=0 to n of 2^r * nCr = (1+2)^n = 3^n Therefore: Mean = 3^n / 2^n = (3/2)^n Alternatively, we can write: Mean = (3^n - 1) / 2^n + nC0 / 2^n Given that Mean = 728/2^n So: 3^n / 2^n = 728/2^n This gives us: 3^n = 728 However, from the solution shown: Mean = (1+2)^n - nC0 / 2^n = 728/2^n (3^n - 1) / 2^n = 728/2^n 3^n - 1 = 728 3^n = 729 Since 3^6 = 729 Therefore: n = 6
