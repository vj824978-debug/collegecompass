Which of the following relation is not correct?

  1. (1) ΔH = ΔU + PΔV
  2. (2) ΔU = q + W
  3. (3) ΔS_sys + ΔS_surr ≥ 0
  4. (4) ΔG = ΔH - TΔS

Answer

Correct answer: Option 1

Solution

The correct relation for enthalpy is ΔH = ΔU + PΔV (or ΔH = ΔU + Δ(PV)). Option (A) states ΔH = ΔU - PΔV which is incorrect due to the negative sign. The correct sign should be positive (+). Options (B), (C), and (D) are all correct thermodynamic relations.
