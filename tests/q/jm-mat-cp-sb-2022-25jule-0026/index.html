Let f be a twice differentiable functions on R. If f'(0) = 4 and f(x) + integral from 0 to x of (x - t)f'(t)dt = (e^x + e^(2x))cos(2x) + (2x)/a, then (2a + 1)^5 * a^2 is equal to

Answer

Correct answer: 8

Solution

Given: f(x) + integral from 0 to x of (x - t)f'(t)dt = (e^x + e^(2x))cos(2x) + (2x)/a and f'(0) = 4. From the integral condition, f(0) = 2. Differentiating the equation w.r.t. x: f'(x) + f(x) - f(0) = 2(e^x - e^(2x))cos(2x) - 2(e^x + e^(2x))sin(2x) + 2/a. Substituting x = 0: f'(0) + f(0) - f(0) = 2/a, so 4 = 2/a, giving a = 1/2. Therefore (2a + 1)^5 * a^2 = (2(1/2) + 1)^5 * (1/2)^2 = 2^5 * (1/4) = 32 * (1/4) = 8.
