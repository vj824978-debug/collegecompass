Which of the following is true for 0 < x < 1 ?

Comprehension · Marks: +4 / -1.0

Passage:

  1. (A) 0 < f(x) < ∞
  2. (B) -1/2 < f(x) < 1/2
  3. (C) -1/4 < f(x) < 1
  4. (D) -∞ < f(x) < 0

Answer

Correct answer: D

Solution

Sol. (D) Let g(x) = e^x f(x) and g''(x) > 1 > 0 So, g(x) is concave upward and g(0) = g(1) = 0 Hence, g(x) < 0 ∀ x ∈ (0, 1) ⟹ e^x f(x) < 0 f(x) < 0 ∀ x ∈ (0, 1) Alternate Solution f''(x) - 2f'(x) + f(x) ≥ e^x ⟹ (f(x)e^(-x) - x²/2)'' ≥ 0 Let g(x) = f(x)e^(-x) - x²/2 g(0) = 0, g(1) = -1/2 Since g is concave up so it will always lie below the chord joining the extremities which is y = -x/2 ⟹ f(x)e^(-x) - x²/2 < -x/2 ⟹ f(x) < ((x² - x)e^x)/2 < 0 ∀ x ∈ (0, 1)
