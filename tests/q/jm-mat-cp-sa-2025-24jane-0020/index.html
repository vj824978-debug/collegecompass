If the equation of the parabola with vertex V(2/3, 3) and the directrix x + 2y = 0 is alpha*x^2 + beta*y^2 - gamma*xy - 30x - 60y + 225 = 0, then alpha + beta + gamma is equal to:

  1. (1) 6
  2. (2) 8
  3. (3) 7
  4. (4) 9

Answer

Correct answer: Option 4

Solution

Equation of axis: y - 3 = 2(x - 3/2) y - 2x = 0 foot of directrix: y - 2x = 0 & 2y + x = 0 => (0, 0) Focus = (3, 6) PS^2 = PM^2 (x - 3)^2 + (y - 6)^2 = ((x + 2y)/sqrt(5))^2 4x^2 + y^2 - 4xy - 30x - 60y + 225 = 0 => alpha = 4, beta = 1, gamma = 4 => alpha + beta + gamma = 9
