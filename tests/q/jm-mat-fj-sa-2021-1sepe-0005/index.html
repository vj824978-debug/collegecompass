Let a1, a2, ......, a21 be an AP such that sum from i=1 to 20 of 1/(a_i * a_(i+1)) = 4/9. If the sum of this AP is 189, then a4*a18 is equal to:

  1. (1) 57
  2. (2) 36
  3. (3) 48
  4. (4) 72

Answer

Correct answer: Option 4

Solution

Given: Sum from i=1 to 20 of 1/(a_i * a_(i+1)) = 4/9. Using telescoping series: (1/d) * (1/a1 - 1/a21) = 4/9, where d is common difference. From this: 20/(a1*a21) = 4/9, so a1*a21 = 45. Sum of AP: (21/2) * (2a1 + 20d) = 189, which gives a1(a + 20d) = 45. Solving: a + 10d = 9. Also a1*a21 = (a + 5d)(a + 15d) = a^2 + 20ad + 75d^2 = 45 + 75d^2 = 45. Therefore d^2 = 36/100. Thus a4*a18 = (a + 3d)(a + 17d) = a^2 + 20ad + 51d^2 = 45 + 51*(36/100) = 45 + 18.36 ≈ 72.
