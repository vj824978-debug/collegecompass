The increasing order of basicity for the following intermediates is (from weak to strong) (i) H3C-C(theta) with CH3 groups (ii) H2C=CH-CH2(theta) (iii) HC≡C(theta) (iv) CH3(theta) (v) (theta)CN

  1. (1) (v) < (iii) < (ii) < (iv) < (i)
  2. (2) (iii) < (i) < (ii) < (iv) < (v)
  3. (3) (v) < (i) < (iv) < (ii) < (iii)
  4. (4) (iii) < (iv) < (ii) < (i) < (v)

Answer

Correct answer: Option 1

Solution

Basicity is inversely proportional to electronegativity The order of basicity from weakest to strongest is: H3C-C(theta) with CH3 groups > CH3(theta) > H2C=CH-CH2(theta) > HC≡C(theta) > (theta)CN (i) > (iv) > (ii) > (iii) > (v) Therefore: (v) < (iii) < (ii) < (iv) < (i) Explanation: - (v) (theta)CN: Least basic because CN is highly electronegative and withdraws electron density through the triple bond - (iii) HC≡C(theta): sp hybridized carbon is more electronegative than sp2 or sp3, making the carbanion less stable - (ii) H2C=CH-CH2(theta): sp2 hybridized carbon is more electronegative than sp3 - (iv) CH3(theta): Methyl anion with sp3 carbon - (i) H3C-C(theta) with CH3 groups: tert-Butyl carbanion is most basic because the negative charge is stabilized by three methyl groups which are alkyl groups that donate electron density through inductive effects
