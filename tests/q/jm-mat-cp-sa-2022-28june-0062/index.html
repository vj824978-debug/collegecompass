Let f(x) be a quadratic polynomial such that f(-2) + f(3) = 0. If one of the roots of f(x) = 0 is -1, then the sum of the roots of f(x) = 0 is equal to:

  1. (1) 11/3
  2. (2) 7/3
  3. (3) 13/3
  4. (4) 14/3

Answer

Correct answer: Option 1

Solution

Let x = -1 be one root of f(x) = 0. Then f(x) = A(x + 1)(x - b) for some constants A and b. Using f(-2) + f(3) = 0: A[-1(-2 - b) + 4(3 - b)] = 0, which gives A[-1(-2 - b) + 4(3 - b)] = 0. Solving: -(-2 - b) + 4(3 - b) = 0, so (2 + b) + (12 - 4b) = 0, giving 14 - 3b = 0, hence b = 14/3. The second root is 14/3. Sum of roots = -1 + 14/3 = 11/3.
