let f(x) = x cos^(-1)(-sin(x)), x in [-pi/2, pi/2], then which of the following is true?

  1. (1) f is not differentiable at x = 0
  2. (2) f' is increasing in (-pi/2, 0) and decreasing in (0, pi/2)
  3. (3) f' is decreasing in (-pi/2, 0) and increasing in (0, pi/2)
  4. (4) f'(0) = -pi/2

Answer

Correct answer: Option 3

Solution

f(x) = x cos^(-1)(-sin(x)) (a) for pi/2 >= x >= 0: f(x) = x cos^(-1)(-sin(x)) = x(pi - cos^(-1)(sin(x))) = x(pi - (pi/2 - sin^(-1)(sin(x)))) = x(pi - pi/2 + sin^(-1)(sin(x))) = x(pi/2 + sin^(-1)(sin(x))) = x(pi/2 + x) because x in [0, pi/2] (b) for -pi/2 <= x < 0: f(x) = x cos^(-1)(-sin(-x)) = x cos^(-1)(sin(x)) = x(pi/2 - sin^(-1)(sin(x))) = x(pi/2 - x) f(x) = {x(pi/2 + x^2); x in [0, pi/2], x(pi/2) - x^2; x in [-pi/2, 0)} f'(x) = {pi/2 + 2x; x in (0, pi/2), pi/2 - 2x; x in (-pi/2, 0)} f''(x) = {2; x in (0, pi/2), -2; x in (-pi/2, 0)} Option (1) & (4): LHD at (x = 0) = -pi/2, RHD at (x = 0) = pi/2 Option (2) & (3): f''(x) > 0 for x in (0, pi/2), f''(x) < 0 for x in (-pi/2, 0) => f' is decreasing in (-pi/2, 0) and increasing in (0, pi/2). f(x) is differentiable at x = 0 and f'(0) = pi/2.
