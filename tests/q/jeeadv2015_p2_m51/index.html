If α = 3sin^(-1)(6/11) and β = 3cos^(-1)(4/9), where the inverse trigonometric functions take only the principal values, then the correct option(s) is(are)

Multiple correct (MSQ) · Marks: +4 / -2.0

  1. (A) cosβ > 0
  2. (B) sinβ < 0
  3. (C) cos(α + β) > 0
  4. (D) cosα < 0

Answer

Correct answer: BCD

Solution

π/2 < α < π, π < β < 3π/2 ⟹ 3π/2 < α + β < 5π/2 ⟹ sin β < 0; cos α < 0 ⟹ cos(α + β) > 0
