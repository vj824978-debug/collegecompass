Match the rate expressions in LIST-I for the decomposition of X with the corresponding profiles provided in LIST-II. X, and k are constants having appropriate units. LIST-I (I) rate = k[X]/(X_s + [X]) under all possible initial concentrations of X (II) rate = k[X]/(X_s + [X]) where initial concentrations of X are much less than X_s (III) rate = k[X]/(X_s + [X]) where initial concentrations of X are much higher than X_s (IV) rate = k[X]^2/(X_s + [X]) where initial concentration of X is much higher than X_s LIST-II (P) [Graph showing half-life (t_{1/2}) vs initial concentration of X: linear relationship with positive slope] (Q) [Graph showing half-life (t_{1/2}) vs initial concentration of X: horizontal line (constant)] (R) [Graph showing rate vs initial concentration of X: curve approaching horizontal asymptote] (S) [Graph showing [X] vs time: decreasing linear relationship] (T) [Graph showing ln[X] vs time: decreasing linear relationship] (A) I → P; II → Q; III → S; IV → R (B) I → R; II → S; III → Q; IV → T (C) I → P; II → Q; III → Q; IV → R (D) I → R; II → S; III → Q; IV → R

Matrix match · Marks: +4 / -1.0

  1. (A) I → P; II → Q; III → S; IV → R
  2. (B) I → R; II → S; III → Q; IV → T
  3. (C) I → P; II → Q; III → Q; IV → R

Answer

Correct answer: A

Solution

I → Rate = k[X]/(Xs + [X]) If [X] is low, then it follows first order kinetic ie. t1/2 is constant (OA part in graph) If [X] is high, then it follows zero order kinetics. So half life (t1/2) varies linearly with [X] as shown in graph. [Graph showing half life (t1/2) vs Initial conc.of [X]. Y-axis labeled 'half life(t1/2)', X-axis labeled 'Initial conc.of [X]→'.
