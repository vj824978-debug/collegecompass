Let L1 : (x-1)/2 = (y-2)/3 = (z-3)/4 and L2 : (x-2)/3 = (y-4)/4 = (z-5)/5 be two lines. Then which of the following points lies on the line of the shortest distance between L1 and L2?

  1. (1) (-5/3, -7, 1)
  2. (2) (2 + 3, 8/3)
  3. (3) (8/3, -1, 1/3)
  4. (4) (14/3, -3, -22/3)

Answer

Correct answer: Option 4

Solution

P(2λ + 1, 3λ + 2, 4λ + 3) on L1 Q(3μ + 2, 4μ + 4, 5μ + 5) on L2 Dr's of PQ = 3μ - 2λ + 1, 4μ - 3λ + 2, 5μ - 4λ + 2 PQ ⊥ L1 ⇒ (3μ - 2λ + 1)2 + (4μ - 3λ + 2)3 + (5μ - 4λ + 2)4 = 0 38μ - 29λ + 16 = 0 ...(1) PQ ⊥ L2 ⇒ (3μ - 2λ + 1)3 + (4μ - 3λ + 2)4 + (5μ - 4λ + 2)5 = 0 50μ - 38λ + 21 = 0 ...(2) By (1) & (2) λ = 1/3, μ = -1/6 ∴ P(5/3, 3, 13/3) & Q(3/2, 10/3, 25/6) Line PQ (x - 5/3)/1 = (y - 3)/(-2) = (z - 13/3)/1 Alternatively: (x - 5/3)/1 = (y - 3)/(-2) = (z - 13/3)/1 Point (14/3, -3, -22/3) Lies on the line PQ
