Match List-I with List-II. List-I contains: A) [Ni(CO)4], B) [Ni(CN)4]^2-, C) [NiCl4]^2-, D) [MnBr4]^2-. List-II contains: I) Tetrahedral, 2.8 BM, II) Square planar, 0 BM, III) Tetrahedral, 0 BM, IV) Tetrahedral, 5.9 BM. Choose the correct answer from options given below: (1) A(III), B(II), C(I), D(IV) (2) A(I), B(II), C(III), D(IV) (3) A(IV), B(I), C(III), D(II) (4) A(III), B(IV), C(II), D(I)

  1. (1) A(III), B(II), C(I), D(IV)
  2. (2) A(I), B(II), C(III), D(IV)
  3. (3) A(IV), B(I), C(III), D(II)
  4. (4) A(III), B(IV), C(II), D(I)

Answer

Correct answer: Option 1

Solution

A) Ni(CO)4 → Ni(0) ⇒ sp³ tetrahedral, 0 BM (pairing), 3d¹⁰. Matches III. B) [Ni(CN)4]^2- → Ni²⁺ ⇒ dsp² square planar, 0 BM (pairing), 3d¹⁰. Matches II. C) [NiCl4]^2- → Ni²⁺ (no pairing) ⇒ sp³ tetrahedral 2.8 BM, 3d⁸. Matches I. D) [MnBr4]^2- → Mn²⁺, 3d⁵ (no pairing), μ = 5.9 BM. Matches IV. Answer: A(III), B(II), C(I), D(IV)
