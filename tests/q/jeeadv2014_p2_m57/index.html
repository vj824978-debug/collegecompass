Match the following: List - I: (P) The number of polynomials f(x) with non-negative integer coefficients of degree ≤ 2, satisfying f(0) = 0 and integral_0^1 f(x)dx = 1, is (Q) The number of points in the interval [-sqrt(13), sqrt(13)] at which f(x) = sin(x^2) + cos(x^2) attains its maximum value, is (R) integral_{-2}^2 (3x^2)/(1+e^x) dx equals (S) (integral_{-1/2}^{1/2} cos(2x)·log((1+x)/(1-x)) dx) / (integral_0^{1/2} cos(2x)·log((1+x)/(1-x)) dx) equals List - II: (1) 8 (2) 2 (3) 4 (4) 0 Codes: (A) P→3, Q→2, R→4, S→1 (B) P→2, Q→3, R→4, S→1 (C) P→3, Q→2, R→1, S→4 (D) P→2, Q→3, R→1, S→4

Matrix match · Marks: +4 / -1.0

  1. (A) P→3, Q→2, R→4, S→1
  2. (B) P→2, Q→3, R→4, S→1
  3. (C) P→3, Q→2, R→1, S→4
  4. (D) P→2, Q→3, R→1, S→4

Answer

Correct answer: D

Solution

(P) f(x) = ax² + bx, ∫f(x)dx = 1 from 0 to 1 ⇒ 2a + 3b = 6 ⇒ (a, b) = (0, 2) and (3, 0). (Q) f(x) = √2 cos(x² - π/4) For maximum value, x² - π/4 = 2nπ ⇒ x² = 2nπ + π/4 ⇒ x = ±√(π/4 ± √(9π/4)) as x ∈ [-√3, √13]. (R) ∫₀¹ (3x²/(1+eˣ) + 3x²/(1+e⁻ˣ))dx = ∫₀¹ 3x²dx = 8. (S) ∫₋₁/₂^(1/2) cos 2x ln((1+x)/(1-x)) dx = 0 as it is an odd function.
