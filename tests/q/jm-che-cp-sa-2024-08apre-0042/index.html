Given below are two statements: Statement (I): A Buffer solution is the mixture of a salt and an acid or a base mixed in any particular quantities. Statement (II): Blood is naturally occurring buffer solution whose pH is maintained by H2CO3/HCO3- concentrations. In the light of the above statements, choose the correct answer from the options given below.

  1. (1) Statement I is false but Statement II is true
  2. (2) Both Statement I and Statement II is true
  3. (3) Both Statement I and Statement II is false
  4. (4) Statement I is true but Statement II is false

Answer

Correct answer: Option 1

Solution

Buffer solution is a mixture of either weak acid/weak base and its respective conjugate. The quantities must be in appropriate ratios, not 'any particular quantities'. So Statement I is false. Blood is a buffer solution of carbonic acid H2CO3 and bicarbonate HCO3- which maintains pH. So Statement II is true. Answer is (1).
